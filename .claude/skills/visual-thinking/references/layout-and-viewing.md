# 排版与视觉检查

以已认可的样张为审美基准：细线、开放构图、充分留白、明显的文字层级，图形承担关系。不要把规范数字当成设计答案；几何结构、比例与文字应一起推敲。

## 先看整张图

- 主关系应一眼可辨。文字贴近发生关系的位置，避免主图被解释段落挤成插图。
- 圆的大小由含义与内容共同决定，不把所有节点做成同样大的按钮；色面只承担必要分区，不以大面积填色代替设计。
- 标题区采用简洁的中英两行：中文标题在上，准确自然的英文译题在下一行；去掉标题之前非必要的分类、编号或概念栏。当前 1200 px 宽画布的中文标题可从约 45 px 起步（比原 68 px 缩小约三分之一），英文约 26 px，保持次要层级。中文优先简洁地排成一行；确实过长时先精简措辞，不靠无限缩字硬塞。
- 标题、节点、关系词、小字各有层级，允许明显的字号差异。不要为了统一可读性而把所有字放大，或把画面拆成纵向课件。
- 统一对齐基准、线条轻重与局部间距；也保留构图需要的不对称和空白。更多框线、节点与图例不自动增加结构性。
- 常规出图保持一张完整构图，不额外生成设备适配版，不设置强制显示字号门槛。局部放大只在用户需要解释某个区域时提供。
- 未要求换肤时保持默认黑白几何；测试多个问题不等于测试多个皮肤。主题变化也不能替代构图质量。

## 再检查局部

采用可用的中文字体，按短意群断行；避免拆开词语、数值单位与引用编号。多行说明保持自然行距，问号不单独挤进连线。

根据实际文字轮廓留出节点内边距；圆形同时检查四角，必要时将说明移到圈外。关系标签与分岔、箭头、其他文字错开。发现碰撞就移位或绕线，不扩大遮罩来遮住问题。

主图整体与上方引导文字、下方总结或资料区之间，至少留出一行大标题高度的完整空白带；以已确认的 1200 px 宽画布为例，净间距约 100 px，整体缩放时同比调整；后来缩小标题时，不随之收紧已经确认的留白。以文字实际轮廓和主图最外沿（包括图内标签）测量，不能只留 30 px 或满足不碰撞。优先增加画布高度，让主图保持原有结构与比例。此要求针对主图与上下文字区的分隔；图内关系标签仍贴近对应关系，保留舒适局部间距，圈内标签按节点内边距处理。

以图谱为主、标题和图例收在角落的版式，应大胆增加主图上下的空白带；1400 px 宽画布可从约 240–260 px 的上下净空起步。保留主图大小与结构，通过增加画布高度和移动外围信息区获得留白，不把图缩小凑空白，也不以装饰填满空白。

关系连接默认采用日常流程图的正交走线：水平线、垂直线和 12 px 小圆角（按 SVG 画布坐标，整体缩放时同比调整）。跨位置连接也通过折线走向目标，不直接用斜线相连；分支使用清楚的公共主干和分叉点，避免多条线重复叠画。转角用相切的 `A12 12` 四分之一圆，避免大圆角、自由曲线和为装饰而绕弯。进出节点优先对齐上、下、左、右端口，箭头沿最后一段直线，统一端点间隙与大小。先检查完整路径的轴线、分叉和方向，再检查单个转角。图形本身的圆、集合边界和有明确语义且经用户认可的圆弧不因连线规则被改成方框；真实数据曲线不受该规则限制。

来源在图底用小字注明；已知、假设与待查关系仍在图中就地标清。缩小补充文字不能删掉关键条件。

## 概念普及与结构图

适用于结构有用，但读者不熟悉图内概念或看不懂关系的情况。先判断具体门槛，不给所有问题加一堂知识课。

- **对象旁说明是什么。**保留正式名称，接一小句日常释义；如“负债：欠别人的钱”。需要时补通用例子，但不编造用户经历或金额。
- **关系处说明意味着什么。**在发生变化的线段或区域写清结果；如“还本金：现金减少，欠款也减少”。不能只贴名词定义，或只问“你怎么看”。
- **分清读者容易混淆的量。**例如每月现金进出与期末家底、当前表现与长期能力、付款与消费。用区域、标签和连接就地解释，不让读者自己猜口径。
- **理解后再留思考入口。**在已解释的对象旁问可代入的具体问题，如“还款压力减轻了吗”。必要概念和已知机制可以明确教，个人条件、实际变化与结论仍留给用户。

每处只补理解当前关系需要的内容，减少同义重复。保持图形主体、字号层级和上下留白；不在图旁另写文章，不把几何构件替换为段落。修订时优先保留已认可的骨架、比例、位置与有意义的穿越路线。

自查时先略去图外的总结与检查清单：读者是否仍能从对象、区域和连接读出主要意思？若必须读完下方一篇说明才懂图，先把必要解释放回对应关系，删去重复旁文；不要只缩短字句，或将说明全部改成抽象问句。来源和短总结仍可留在底部。

**结构示意与具体算例分开。**没有提供个人数据时，通用图要让读者直接代入自己的处境；不能仅为方便讲解就新增工资、支出、家庭或资产案例。标了“假设”也不自动说明算例适合本题。用户明确要计算、数值本身决定关系，或确需演示数量操作时才使用充分标明的算例，且不把它当作用户的诊断。

**前后对照不制造虚假差异。**先看要比较哪一层。前后路径相同、重点在入口或各区变化时，可共用路线，把“前→后”和待核对的变化放在原位置；不强制复制整图或画多条错位线。路径确实不同、需要同轴趋势或多方案对照时仍分别绘制。图中上下、宽窄、线宽和面积若承担比较，就须有明确含义；不能靠说明“只是排版”补救无依据的高低暗示。

穿越区域本身表达资源经历时，保留内部轨迹，整理转角、分岔与标签即可；不能为套用端口规范，把它改成仅在框外连接的对象关系图。连接是否穿越由关系含义决定，12 px 圆角规范只约束走线几何。

## 根据反馈改什么

| 问题 | 优先修改 |
| --- | --- |
| 概念陌生，但关系看得懂 | 在原位置补短释义，保留结构 |
| 方向、包含或交叠看不懂 | 修复几何语义与关系词 |
| 文字、箭头、遮罩碰撞 | 局部移动、绕线与留白 |
| 变粗、变满、像课件 | 回到已确认样张，调整图文比例、线宽与节点尺度；删多余解释 |
| 漂亮但无法推演 | 返回选图与机制，检查可改变的条件 |

局部连线缺乏几何感时，只修对应分支的走线、切向衔接和必要端点；保留已认可的斜向排列、重复轮廓、圆弧回路及不对称构图。几何统一不等于全部改成水平流程或圆角矩形。用户圈画范围须先辨清是肯定还是指出缺陷，不能默认把圈内全部重排。

自动诊断只定位排版疑点，不能评价设计好坏。实际查看整图与拥挤局部；先判断结构和整体视觉是否成立，再处理细节。不要以“所有检查项通过”代替对图片的判断。
