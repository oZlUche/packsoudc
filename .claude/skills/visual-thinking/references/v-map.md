# V Map：让研究问题、认识与证据相互校核

本页用于选择和填写 V 图，不要求日常出图加载全部文献。通用骨架为 [14 研究 V 图](../assets/skeletons/14-研究V图.svg)。原法、相关变体和实证的阅读范围见[研究来源与边界](v-map-sources.md)。

## 先判断它是否适合

V Map 的核心工作是：**围绕一个明确的问题，把已有认识、概念、调查办法和所得发现联系起来，检查答案是怎样得到的。**它既能在研究前帮助设计调查，也能在研究后暴露推断缺口；不是只有研究日程，也不是将已知答案重新排成 V。

优先用于“怎样查清这个问题”“这项研究凭什么得出结论”“我的判断还缺哪类证据”。仅想知道一个主题的全貌，不自动用 V；用户只问简单问题，也不自动要求其开展研究或填七个区。先自行查阅可取得的资料，明确哪些是公开证据、哪些仍需个人观察。

调研完成后再核对交付目的：V 的研究字段能说明答案的来历，但未必能呈现题目本身的运行关系。若用户要形成可用于判断的理解，且允许重新选图，按[研究结构与问题结构](structure-selection.md#研究结构与问题结构分开选)重组主图；不能只往七区增加结论，也不因这次不适配就认定 V 不能用于研究结果分析。

### 用途与适用边界

| 思考任务 | 可以怎样使用 | 依据及边界 |
|---|---|---|
| 规划实验、社会调查或实地观察 | 明确对象与问题，让概念决定需要观察什么，方法与计划对应取证 | 原书直接用途，包含访谈与问卷，并不限于实验室。[V1] |
| 整理实验报告或已完成调查 | 将实际记录、分析办法、所得发现与原问题对应，回查概念或方法是否支持解释 | 相关经典 Vee 用途；14 仍保留本书字段，不冒称经典原版。[V2–V3] |
| 阅读论文、研究报告、带证据的主张 | 分清作者的问题、概念、研究设计、数据与推断；定位没有交代的环节 | 原作者讨论知识文本分析，另有科学阅读的教学研究。[V2、V5] |
| 学习数学与解释解题依据 | 使定义、条件、所用定理、推导步骤和结论对应，追问每步为何合法 | 数学 Vee 的相关应用，非本书模板原例；若转译 14，须说明扩展。有限试算不能代替证明。[V6] |
| 教学中的交流与过程反馈 | 对照学生实际画出的概念、取证与解释，讨论某条联系为什么成立 | 可作为讨论材料，不由图的完整或美观判断智力、真实想法或长期学习效果。[V3、V7] |
| 复盘一次求知过程 | 比较最初认识、计划与实际发现，查出改变判断的具体证据，以及没有解决的问题 | 相关改进型 Vee 明确区分计划、实际实施和评价；不能把计划当成已完成。[V4] |
| 综合相互冲突的资料、审查 AI 给出的结论 | 按同一问题核对来源、对象、概念口径、方法与反证，保留分歧 | 本 skill 的自主扩展，不称为原书既有应用或已验证的 AI 查证技术。引用不代替核对。 |
| 检验生活、工作中的一个事实假设 | 将可观察的一小段问题放入 V，如某种安排与完成情况的关系；明确未控制条件 | 自主扩展，不承诺识别因果；涉及整体人生选择时，仅承担其中的事实查证，不能替代价值取舍。 |

“适合做”不等于“效果已充分证实”。不同学科需要不同的论证标准，不强求所有问题都做实验、设数值或形成因果假说。

### 与相邻图式的选择

- **KWHL／24**：主要工作是唤起已有认识、提出学习疑问、安排了解和记录收获。若不需要详细检查概念—方法—证据的对应，四栏通常更轻。
- **5W1H／12**：展开一个主题的基本提问方向；尚未形成具体调查问题时适合先用。V Map 进一步检查“用什么取得什么证据，能支持哪种回答”。
- **概念定义／11、概念关系／04**：主要难点是概念含义或概念之间的关系，先用概念图；不为讲一个定义安排虚假的研究。
- **Compare Map／08**：比较选择在共同标准下的表现。只有某一关键表现未知、需要设计查证时，V 才可作为局部探索，仍保留返回原选择的入口。
- **信息冰山／50**：公共事件的片段、背景与不同视角构成主要关系时优先。用户明确要核验其中一项说法，才考虑 V；不将全貌问题缩成研究计划。
- **原因图、时间线、执行路径**：分别解释候选机制、经过和行动依赖。V 的分区不等于这些关系，也不应充当所有“为什么”的默认图。

| **Gowin Knowledge Vee** | 左侧概念／理论，右侧记录、转换与知识主张；焦点问题在上方中央，对象／事件在尖端 | 相关的知识建构方法，不能把 14 的底部问题说成该体系的底部对象。需要此版时另行标明、独立绘制。[V2–V3] |

| **Argumentation Vee Diagram** | 为争议议题组织双方论据并形成综合判断 | 是另一项论证任务，不将 14 左右两侧改成赞成／反对后仍称相同原法。相关结果不能直接作为 14 的效果证据。[V9] |

未核实本书对 Gowin 的直接承袭关系，不补写起源故事。V Map 不是 Venn 图，也不是工程开发的 V 模型。来源的教学步骤是使用建议，不代表现实调查只能线性前进。

## 14 七个区域，分别应该做什么

| 区域与位置 | 应承载的内容 | 必须避免的替代 |
|---|---|---|
| 顶端：研究主题 | 本次调查的范围；原问题很大时保留所属整体与本次切口 | 只剩没有范围的口号；悄悄缩小用户的大问题。 |
| 左上：我已知道什么 | 用户明确提供的认识，或本轮可核查的相关知识／观察；各自注明归属和来源 | 凭背景预填“你已经知道”；把模型的常识当成用户经历；把猜测写成事实。 |
| 左下：关键概念 | 与问题有关的定义、原理、条件；有假设时就地标“待检验” | 罗列名词；将常见相关性当定律；让概念含义在两侧悄悄改变。 |
| V 内：研究工具 | 能取得适当证据的资料、仪器或办法，并说明各自承担的工作 | 只写“上网、问 AI、访谈”，不说明去哪里、找什么、怎样判断。 |
| 右下：研究计划 | 日期／阶段、对象、活动和实施方法；进行中或事后注明实际实施及偏离 | 随意承诺样本足够；把“准备做”当“已经做”；只列时间表。 |
| 右上：结论与发现 | 经研究得到的记录摘要、分析、回答及限制；未取得材料时保留待查 | 为填满版面预写结论；只有判断，没有对应证据和分析。 |
| 尖端下：研究问题 | 一个范围明确、可用相应学科方法探究的问题，必要时列关联子问 | 把主题换个问号；同时塞进无关问题；预设原因或正确答案。 |

“已知”指研究起点，不是永远正确。资料不足时允许为空或写有名称的缺口，不强求每区一样满。14 中已有认识、概念与研究计划同为当前问题服务，不表示两侧天然对立。

## 填写之前：检查方法与问题是否匹配

在后台完成以下校核，再把必要内容压成图中的短标签，不将本节整段塞进图片。

1. **问题对象是什么。**调查谁／什么、在何种情境与时间内？“更好、有效、理解”等词在本次问题中怎样辨认？不强迫质性、解释性问题转成数值题。
2. **什么材料能够回答。**公共文献、实际观察、测量、访谈、档案或形式推导各有用途。受访者的说法可说明其报告的体验，不直接证明行为或客观效果；二手材料不能冒称自己观察。
3. **工具各司其职。**区分资料来源、收集方法、具体工具与分析方法。例如网站是来源、访谈是收集办法、提纲是工具、按主题编码是分析；不要求图上机械列四栏，但应能说明怎样由它们得到答案。
4. **概念会怎样影响取证。**若“会阅读”指复述、迁移应用或批判论证，就需要不同任务和记录；不能用阅读时长直接替代理解。定义改变时，回查方法与结论。
5. **预先留出修正可能。**什么观察会使当前假设减弱，什么结果仍不足以区分竞争解释？不把“未找到支持”写成“已经证伪”，也不预定所有证据都会支持同一立场。

分析既有论文时，上述字段记录的是**作者实际报告了什么**；缺失写“未交代”，批评标为本轮评估，不替作者补出更严谨的方法。数学或逻辑论证使用假设、定理与有效推导，不把实验数据当成唯一证据形式。

## 研究阶段决定可以填什么

| 当前阶段 | 图面应呈现 | 不得越过的边界 |
|---|---|---|
| 准备研究 | 有来源的起点、待检验假设、问题、方法与拟议计划；右上标“待研究”，可写将检查什么 | 判断依据与可能结果只能标为预案／判据，不能伪装发现；假设例子也不能成为用户实际结果。 |
| 研究进行中 | 已取得的资料、初步整理、未补齐的证据与调整后的计划 | 区分临时解释与已有发现；不因最早几条记录就断言完成或找到原因。 |
| 已完成研究／复盘 | 实际实施、实际材料及其来源、分析方法、结论和限制；必要时保留原计划以比较 | 现实做法与原计划不同要说明；不能用写得更好的计划覆盖实施缺陷。 |
| 阅读一项已有研究 | 作者的问题与概念、研究对象和设计、报告的数据、分析和作者结论 | 不冒称独立重复验证；原文缺失、读者疑问与作者主张分别标明。 |
| 跨资料查证／综述 | 每项证据的对象、口径与来源独立性，以及相互支持和冲突的位置 | 属于自主扩展；不把多个同源转载当作多项研究，不用引用数量替代证据质量。 |

图中可在副标题附近用一个短阶段标签帮助辨认，无需新增大色块或阶段卡片。“研究计划”在事后可以加小注“实际实施”，仍保留它与发现的区别。

## 最关键的推断：记录不等于结论

右上原本就包含数据分析、结论与启示，不应只填最后一句话。[V1] 使用相关 Vee 理论时尤其检查：**取得了什么记录 → 怎样整理或推导 → 支持什么回答 → 哪些仍说不出来。**[V2]

不必为这四项增加四个框；可用短句、对应编号、一小段原始记录或必要的微型数据图，使关键回答能回溯到依据。原始数据较多时链接原资料，不用庞大表格吞掉主体。无真实数据不画看似实测的趋势或比例。

- 观察到先后或差异，不直接证明因果；混杂、样本选择和测量口径按本题识别，不机械堆一套术语。
- “资料显示什么”与“这对我意味着什么”分开；事实回答不能自动决定价值取舍。
- 数学题用可检查的推导依据替代经验性记录链；例子有助理解，不能由几个正例推出一般命题。
- 没有结果也可能是当前有效状态。明确“还差什么材料才能判断”，胜过用流畅结论填满右侧。

## 怎样启发用户沿图思考

基本入口仍遵循本书：从主题与已有认识进入，厘清概念，形成底部具体问题，再选择工具和计划，研究后填写发现。实际使用允许来回修订，不画成不可回返的七步流水线。

根据本次材料选择一个动作，放在关系附近或右下短说明中即可：

- **从答案倒查**：指向一条发现，回查它用了哪项材料、哪种分析和哪个概念；哪里一断，判断应怎样收窄？
- **换一个定义**：如果“理解”改成“能解决陌生例子”，哪些取证与结论必须一起修改？
- **找区分性材料**：当前两种解释都能说明这条观察，下一次查什么才能分开它们？
- **比较预期与实际**：这次真正改变认识的是哪条证据，哪些只是原有信念换了说法？
- **定位尚不能知道的事**：图中哪一区缺内容，具体阻止了哪一种结论？

这些是图内可进行的思考，不是要求用户回复的问卷。AI 可补上已查清的公共知识和局部机制，让用户有足够起点；不把未知个人条件填成确定答案。

## 图形与设计约束

沿用 14 的 V 形主体、七个字段相对位置和黑白默认皮肤。V 的两条直斜边是**语义边界**，不是自由连接线，因此不套正交折线规则；若另加关系连接，遵循直线／正交折线及 12px 圆角。

左右分区与共同问题的对应就是主体结构。正式图保留这套分区，让材料在其中有清楚位置，不改成七张孤立卡片。V 不表示流量收窄、等级、数量、时间长短或成功概率；上下次序也不自动表示因果。书写线与短提示可随内容删减，必要证据链不能删除。

主题、主体与底部说明之间继续大胆留白；每区短标题与够用注释即可。完整性落实在后台的选题、检索与推断检查中，不靠每张图填满所有理论名词来表达。源图是通用骨架，已填案例另存案例区。图底区分**图式方法来源**与**本题事实来源**，不让方法引用冒充具体结论的证据。

## 交付前的专项检查

1. 这题真的需要检查求知／取证，还是概念、选择、全貌或执行问题被硬套成研究？
2. 使用哪一种 V？字段与声明的版本相符吗？
3. 研究问题、概念和取证对象是否对应；有没有先定答案再选择证据？
4. 个人起点、理论假设、公开资料、真实记录与模型评估是否区分？
5. 工具和实施方式能否得到所需证据；右侧回答能否回溯到材料和分析？
6. 未完成研究是否没有冒写结果；论文解读是否没有冒称独立验证？
7. 读者能否指着图找到一个可修正的环节；图形是否仍为简单、有留白的 V 主体？

相关前向测试见[行为验证](evaluation.md#v-map-专项验证)。这里的核对约束输出质量，不证明用户的长期思考能力已被提升。
