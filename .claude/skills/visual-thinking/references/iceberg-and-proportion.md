# 冰山与比例：简单结构的两种用途

## 冰山：当前所见与待探索背景

适用：从一个表现或信息片段，探索尚需了解的背景。一个连续轮廓跨过一条可见边界，少量层次帮助定位查证方向；水下不是自动成立的隐藏真相。

- **素质探索**：可见知识技能／待了解的综合能力、情境中的倾向、动机与目标。以实际经历和跨情境表现核查，不用单次行为定义人格，不以深度表示决定性或不可改变。
- **信息探索**：当前片段／原始材料／前后情境／独立证据、反例和不同解释。回到原说法，标明哪些已核实、哪些需修正、哪些仍未知。允许横向查证，不必机械地逐层下潜。
- 固定的是可见边界，不是层数或标签。系统思考、心理探索、文学等冰山模型各有用途，不把它们的层次混成同一个理论。
- 深浅与面积是隐喻，不表示因果权重、事实总量或 10%／90% 的测量。找到了材料也不等于解释了原因或看到了全部真相。

### 公共事件：先展开，再解释

“某人为什么做这件事”“分析一下这件事”等没有限定切口的提问，通常先需要知道事件怎么回事。主关系是已见片段与被省略的背景时，优先使用信息冰山；用户明确只问时间线、人物关系或局部机制时，保留其他图式。不是依据新闻题材强制选冰山，也不把一般个人困惑自动当成公共事件。

- **水上定位消息**：谁在何时说了或做了什么；引述、自称与已独立核实的行为分别标明。不让标题先替事实定性。
- **水下填入查到的背景**：公开理由、前后经过、既往往来、各方说法及传播情境，按本题所需取舍。不能只填“查背景、看证据”等空泛任务，也不能为了填满层次编出完整故事。已查到的背景与待查材料可同在水下，就地注明状态。
- **不同视角保持归属**：一方对约定、冲突和动机的描述不等于双方共同确认；此前文章不冒充当下回应。支持、照顾与当前冲突可以并存，不能用其中一项自动抵消或证明另一项。
- **缺口具体可定位**：尚缺哪一方的回应、哪段原始材料、什么约定或后续？本轮未查得不等于不存在。没有证据时保留缺口，不用一般心理理论、人格判断或社会标签代填动机。
- **让补证据能改变判断**：读者应能指出“加入哪条背景或不同说法，会使当前解释需要修改”。图内保留这样的回看入口；不是列完材料后由助手宣布唯一深层原因。

全貌的范围验收：图中能定位当前发生了什么、哪些前情可能改变理解、相关各方的说法，以及仍缺的关键材料。未查得某方回应可以标出缺口；若只画了直接理由或某条局部机制，应补查、补画或明确缩小题目范围，不能称为全貌分析。上述内容是覆盖检查，不是固定四层或固定数量的要求。

保留一座连续冰山、一条可见边界及少量有意义的层次；事实和短注解锚定在对应位置，不退化为几段文字配冰山图标。层数和标签随材料调整，不固定为上述清单。水下表示标题之外的信息，既不表示更可靠，也不表示秘密、真正动机或决定性原因。底部引用本次事件资料，关键证据归属与未知仍在图中可见；研究要求见[事件材料的查证](research-planning.md#事件材料的查证)。

## 比例与分配：不需要箭头也能结构化

比例关系可支持“辨认整体 → 看分配 → 找集中或失衡 → 试想重新分配”。无需把这句话额外画成流程。区别总量与占比、期望与实际、分配差异与价值判断。

| 问题中的关系 | 优先考虑 | 保留的辨认条件 |
|---|---|---|
| 一个整体由哪些部分组成 | 饼图或分区条 | 各部分共用分母，互斥且覆盖整体；未知份额明确标出 |
| 比较多个占比或小差异 | 共用基线的条形 | 同一尺度，注明分母；不同总量时同时标注总量 |
| 两种分配对应或错配 | 两个并排的饼图／条形 | 相同项目保持相同标识，明确两侧分母；对应不表示因果 |
| 比较改变前后 | 同尺寸、同顺序的并排分区 | 同一对象可追踪；预期分配标为假设 |
| 检查贡献集中 | 按贡献排序；必要时画累计占比 | 先有指标、时段和数据，不预填“关键少数” |

常见应用：时间组成、收入来源、资源分配与目标的匹配、调整前后结构。没有数值时，用待填写框架或显著标为假设的示意；不能凭感觉画成用户实际比例。饼图不适合非整体关系、负值、重叠类别或无法加总的量。

## 80/20 是比例与分配的一种应用

讲解模型本身时，两个并排饼图就足以表达“少数项目可能对应多数贡献”，无需增加折线路径、重复节点或多段说明。一个饼图可以说明一个整体的划分；涉及项目数量与贡献两种不同分母时，分别标清，不能把两者画成同一个整体的互补份额。

[简化双饼图 PNG](../assets/skeletons/30-80-20模型.png) · [SVG](../assets/skeletons/30-80-20模型.svg)。图中比例明确为模型示意。实际使用应统一指标与时段、收集数据、排序并核算，再考虑干预成本、可改变性及其他项目的必要支撑。真实比例不必是 80/20；少数项目的贡献不等于只需少量努力，也不意味着其余项目都能删除。实际数据需要细比或累计分析时再使用帕累托图，不机械坚持饼图。

- 信息查证动作：[Mike Caulfield (2019), SIFT (The Four Moves)](https://hapgood.us/2019/06/19/sift-the-four-moves/)。读取作者正文；冰山层次为自主组合，不是 SIFT 官方图式，也不替代其全部方法。
- 80/20 概念：[Juran Institute, Pareto Principle & Pareto Analysis Guide](https://www.juran.com/blog/a-guide-to-the-pareto-principle-80-20-rule-pareto-analysis/)。仅核对过搜索摘要，未称全文研究。
- 数据绘制：[ASQ, What Is a Pareto Chart?](https://asq.org/quality-resources/pareto)。读取正文，用于指标、时间范围、排序和累计贡献的要求。
