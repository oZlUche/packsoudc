# 骨架库：按关系选，不按编号套

骨架是对象、边界、分区和连接的组织方式。先确定要比较、追查或改变什么，再选一个主体结构；不能按题材预定鱼骨、循环或网络。

按编号查[逐项用途与深化卡](skeleton-use-cards.md)，初选后实际查看[视觉辨认参考](visual-recognition.md)的相关PNG，再核对原骨架；同一轮已查看的可复用。来源与阅读范围见[研究记录](skeleton-research-sources.md)，本轮完整性核对见[Graphic Organizers 覆盖](graphic-organizer-coverage.md)。

## 每个骨架的几何保留要求

| 编号 | 正式图必须继承的图形工作 |
|---|---|
| 01 | 三个圆是检查节点；小点是入口与回看点。 |
| 02 | 各级圆是树中的对象；连线保持层级。 |
| 03 | 横向主干为共同来路，扇形线为去向，端点圆为对象；可增加有意义的转交。圆径无数据时仅为构图。 |
| 04 | 矩形是概念对象；主干与跨分支连接带可读关系词。未证实的跨连接不能画成已知事实。 |
| 05 | 大圆是比较对象；中间与外侧小圆分别是共有、独有项。 |
| 06 | 圆周是集合边界；交叠是同属两集合的区域。 |
| 07 | 四个圆周均为条件集合；中心是四者真实共同交集。四圆只能画四个集合的部分交集格局，不宣称穷尽全部组合。 |
| 08 | 左右圆是比较对象，中央各方框是共同使用的比较标准。每一横向位置分别给出双方在该标准下的表现或例证；纵向主干保持对象身份。保留圆、标准框和连接，不改成共有与独有图；标准数量和例证区尺寸随材料调整，不默认评分、排序或选赢家。 |
| 09 | 四个圆是两组具体对象；横线比较同一种关系。 |
| 10 | 四区是实际承载区域，中心为同一个概念；保留定义、特征、例子、反例之间的对应，不额外堆回路。 |
| 11 | 中央方框为概念，上方定义框、右侧属性框、下方实例圆及各自归类理由框均保持图形身份。每个实例须有依据说明其如何符合当前定义；常见属性不自动成为充分或必要条件。节点数量和比例可调整，不改为四区表格，也不丢掉归类理由。 |
| 12 | 中心圆代表同一个核心问题；六个方框是实际承载内容的提问区，连接表示共同主题，不表示顺序、因果或各区答案已知。允许扩展区域和替换局部提示，不把圆和方框移除成六段文字；不额外添加交叉网络。 |
| 13 | 四栏是实际承载区域；K、W、H、L 是各区标签。 |
| 14 | V 形直斜边划分同一研究的字段：主题在上，已有认识与概念在左，工具在 V 内，发现与计划在右，具体问题在尖端下。正式图保持分区和共同问题的身份；可按阶段调整提示与书写区，不画成漏斗、七卡片或强制线性流程。V 边不是关系箭头；面积、位置不表示数量、等级或因果。 |
| 15 | 实圆是主张；矩形为证据、推理依据、依据支撑与例外；边为支持或检验，非发生顺序。 |
| 16 | 圆是候选原因；主干端点是待解释结果。 |
| 17 | 两侧圆是原因与后果；中心圆是事件。 |
| 18 | 实心圆是结果；空心圆是倒查的条件。 |
| 19 | 环是不同控制，开口是示意弱点，同一条错误路径在对照中保持身份；替换一层必须改变检查依据或作用，不能只换名字。 |
| 21 | 同心圆是范围；小点是范围中的对象。 |
| 22 | 中心是系统或活动，同心边界是扩展的角色范围，点是角色；同一角色可多重归属。环距不是重要性，中心不能悄悄换为最重要的人。 |
| 23 | 两个并列圆是同级直接情境，重复标识指同一对象，联系线承担中间系统的一项联系，外框及间接条件分别有定义；不能套成家庭包含学校。 |
| 24 | 矩形是观察范围；标记点是同一对象，外圆是关联对象。 |
| 25 | 方形是过去投入；点是今天；右圆是未来候选。 |
| 26 | 虚圆是尚未定位的对象；得到依据后移动圆，保留其形状。 |
| 27 | 轴线保留；分布线只能由数据生成，不能臆画。 |
| 28 | 两块矩形区分已有与新增；小圆是结果检查点。 |
| 29 | 两圆都是做法集合边界；交集仍是图形区域。 |
| 30 | 两圆均是整体；扇区表达明确标注的示意份额。 |
| 31 | 方框是带单位的因素，实圆为结果量；运算符和等号表达经核实的数量关系。虚线为同一因素的调整对照；不按面积编码数量。 |
| 32 | 螺旋为连续试做轨迹，截面为留下的版本；固定相位对应同类动作。环径不编码质量，不强制三环等大。 |
| 33 | 外框是共同情境，圆是人物与事件状态；冲突接向实际尝试，结果回到人物目标检查。先后不直接宣称因果。 |
| 34 | 大圆为活动场域，方框为物品停放点；同一底图叠加人、物与边界。线型和交叉的含义就地标明。 |
| 35 | 轨道共用时间轴；点为时点、条为区间、竖虚线为对齐。无时间数据时只表达顺序并声明间距无量义。 |
| 36 | 圆是状态／事件，闭合路径是重复顺序；必须说明重入条件，不将圆环自动当作强化或进步。 |
| 37 | 冰山轮廓与分层保留；小圆是引出注释的锚点。 |
| 38 | 冰山轮廓与分层保留；小圆是引出注释的锚点。 |
| 40 | 两轴保留时间与同一结果口径；线是变化轨迹而非对象间因果连线。曲线形状依据材料重画，不保留示意升降或排名；图例与就地说明交代各线、条件和延迟。 |


## 方法与素材分别管理

按需查[教育基础关系](education-foundations.md)、[芒格模型](munger-models.md)、[心理倾向](munger-psychology.md)和[设计探索](dschool-design-thinking.md)。方法目录不因删掉构图而失效，也不意味着每个方法都需要专用骨架。现有关系可以承载时，优先补用途和局部操作；不能以覆盖为由恢复退役方案。
