# 公开前检查

用于维护与发布，不是每次出图都要追加的流程。维护目录和公开预览分别检查；文件可读不等于已获得第三方再分发许可。

## 先生成隔离的公开预览

在skill根目录运行：

```sh
python3 scripts/export-public.py /tmp/visual-thinking-release
```

输出目录必须位于维护skill之外，且不能覆盖既有导出。脚本保留公开索引中的38个条目，排除本地来源参考素材和对应选图入口，清理隐藏缓存，检查文件、索引、相对链接、锚点与绝对私人路径，再生成预览ZIP。它不会上传GitHub、安装依赖、替用户选择许可证或认定图片已经脱敏。当前原创内容已由维护者选择MIT授权；后续导出须同时保留LICENSE及来源说明。

构图的来源身份保留在文档中。公开条目沿用稳定编号，缺少本地条目的编号不代表损坏；不重编号既有素材。不能只删除图片而保留调用这些文件的指令。

## 确认可用与可分享

- **文件与运行**：检查frontmatter、所有素材路径、SVG／PNG配对和环境说明。实际在公开候选里调用，不能只测试维护目录。修改编号可见文字后重新渲染，保留已确认几何及原PNG尺寸。
- **产出质量**：至少覆盖一个整体问题、一个解释／机制问题与一个基础图谱；保留一次新上下文试用的真实记录。没有新检索、真实读者或跨平台测试时分别注明，不把脚本通过说成效果验证。
- **隐私**：检查正文、配置、文件名、SVG文本／元数据和PNG像素；不带私人经历、身份组合、本机路径、未公开计划及健康信息。文本扫描和历史脱敏不能替代图片检查。
- **实现与来源**：不导入外部技能的明确模板、文案、代码、图版或字体；学术方法的必要署名保留，不把转述来源当成原创资产或机构背书。
- **授权范围**：当前原创文字、脚本与自绘图形采用MIT，保留LICENSE及ATTRIBUTION。新增材料须核对是否属于这一范围；来源参考的本地限制不因MIT而取消，不替第三方再授权。
- **历史与远端**：旧Git提交、附件和缓存另查。新公开仓库不自动包含上传个人旧历史的授权；预览ZIP不等于线上发布。

## 小范围试用

按[真实读者试用方法](evaluation.md#陌生读者小范围试用)由维护者邀请愿意参与的人；不由AI自行联系。记录读者能否找到入口、说出关系、代入处境或指出具体疑问。作者检查与独立代理试用保留各自身份，不写成已经完成读者测试。先根据卡点修改，不为了发布继续扩充模型数量。
