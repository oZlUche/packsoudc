# 美国早期教育中的视觉思考：核实记录

结论：存在从学前与 kindergarten 阶段开始的学校实践，也有政府教学资源和教育研究；不能据此说全美统一实施、所有儿童都学过，或已证明能改善成人所有日常判断。美国 preschool 与 kindergarten 属不同阶段，两者各有实例，不能把同一证据混称为所有幼儿园。

## 几条传统需要区分

| 传统 | 实际侧重 | 值得吸收之处 |
| --- | --- | --- |
| Graphic Organizers | 图形组织器的广义称呼；包括顺序、比较、概念、叙事等。 | 外化关系、降低文字门槛；不能只变成填表。 |
| Thinking Maps® | David Hyerle 开发、以八种常用图式对应思考过程的教学体系。 | 思考动作与可辨认图形保持一致，而非每次换一套装饰。 |
| Project Zero Visible Thinking / Thinking Routines | 思考提示、可见记录与反思组成的教育方法；不要求固定绘图外形。 | 区分观察与解释、给依据、换视角、回看修正。 |
| IHMC / Novak 与 Cañas 的概念图 | 围绕焦点问题，用有关系词的连接构成有意义命题。 | 边要能说清关系；不能把任意关联都画成原因。 |

PZ 官方介绍还说明 Visible Thinking 的早期工作在瑞典学校开展。它虽由美国哈佛的研究团队发展，不宜描述成纯粹美国发明；这些方法也不只用于美国。

## 方法来源与原始实例

- [Thinking Maps 官方介绍](https://www.thinkingmaps.com/products/thinking-maps/)：用于核实八图框架和名称。页面销售宣传、案例和增长倍数不作为本 skill 的效果证据；学生实例可查上面的 Lexington 页面。
- [PZ 思考工具箱](https://pz.harvard.edu/thinking-routines-archive)：按思考目标选方法、重复使用并回看学习记录。不是穷尽的形状分类。
- [PZ Visible Thinking 项目](https://pz.harvard.edu/projects/visible-thinking)：思考动作、记录和反思的背景；不限于视觉海报。
- [IHMC：概念图理论与构建](https://cmap.ihmc.us/docs/theory-of-concept-maps)：原作者技术报告，含概念图图例、焦点问题与交叉连接。
- [PZ 幼儿版 Parts, People, Interactions](https://pz.harvard.edu/resources/parts-people-interactions-younger-children)：明确讨论系统边界、参与者及移除／改变后的影响，可用画图、照片、游戏等表达。
- [PZ 幼儿版 Imagine If](https://pz.harvard.edu/resources/imagine-if-younger-children)：从熟悉的具体事物尝试改变条件、生成可能。

## 效果证据的实际范围

- [Schroeder 等：Studying and Constructing Concept Maps，2018 卷期](https://link.springer.com/article/10.1007/s10648-017-9403-9)，2017 在线。摘要综合 142 个独立效应量、11,814 名参与者，报告学习上的总体中等正向效果；构建图和阅读图的分组结果不同。这里的分组差异不等于一项直接随机比较，也不是针对我们这套自绘几何图。
- [Wang 等：STEM 概念图元分析，2025](https://link.springer.com/article/10.1186/s40594-025-00554-2)，综合 2004–2023 年的 37 项研究，报告学习成绩总体正向但受实施情境影响。不能把它转述成“幼儿从小画图便终身更理性”。
- 教师引导、材料知识、学习者主动构建、练习与反馈是教学情境的一部分。我们只提供图像时，不能把整套教学效果归给图片的外观。

## 转化与归属

借鉴通用的比较、分类、观察、论证、修正等思考方法，并以本 skill 的黑白几何语言自绘。品牌名称用于说明来源，不把自己的图称为官方模板或认证课程，不复制机构图纸、徽标或整份提示卡。PZ 下载材料具有各自的署名与许可说明；引用或转发原件时保留说明，本 skill 的独立表述与新图另行标明为自绘，不冒充原作。

核心判断：学校实例足以确认“确实有人从小这样学”；教学指导和研究让方法值得借鉴；成年开放问题上的实际效果仍需检验。
