# 斯坦福 d.school：研究、选用与视觉转译

目的：为启发式视觉思考补充可选方法，不改为设计咨询、工作坊主持或项目交付流程。官方材料说明方法是什么；下文的几何画法、触发判断和样张是本 skill 的自主改编，不是官方图卡或经验证的教学干预。

## 判断与新增价值

值得吸收。现有基础图式擅长表达关系，芒格目录擅长检查判断；d.school 补充“原来的问题是否值得这样问”“除了这一个做法，还有什么”“怎样让猜想接触现实反馈”。这是便于选用的比较，不表示三个来源各自只处理这些事情，也不要求每张图依次使用三套方法。

优先吸收问题重构、抽象层级切换、生成不同做法和原型学习。观察、旅程、矩阵和类比与已有目录重叠，补充来源和使用边界即可，不另建重复模型库。拒绝把五种模式画成所有问题的标准五步。

## 五种模式与八项能力：分清层级

[S1] 把 Empathize、Define、Ideate、Prototype、Test 称为五种模式，工具卡可从任意处开始；不是必须依序走完的清单。

| 模式 | 本 skill 可借用的方向 | 不能替代的事 |
| --- | --- | --- |
| 同理／理解人的处境 | 给不同参与者留下视角与经历的位置 | AI 不能凭空知道他人的感受和需要 |
| 定义 | 检查题目、对象、范围和隐含前提 | 不能把重述当作已经找到真问题 |
| 构思 | 暂时打开不同做法，再按依据比较 | 候选多不代表好，不替用户选完 |
| 原型 | 用可修改的草图外化一个猜想 | 图做得精致不表示方案已经可行 |
| 测试 | 留出观察入口和返回修订的路径 | 脑内试想不能代替现实反馈 |

[S2] 另列八项能力。下表后栏均为本 skill 的应用判断，不是官方能力量表。

| 官方能力名 | 本 skill 的应用 |
| --- | --- |
| Navigate Ambiguity | 允许暂不闭合，辨认现在可以推进的一个未知 |
| Learn from Others (People and Contexts) | 不把单方视角当全部；标明待向真实处境学习的位置 |
| Synthesize Information | 让已有观察重组出关系，保留反例和出处 |
| Experiment Rapidly | 试摆少量实质不同的草图，不追求一次画全 |
| Move Between Concrete and Abstract | 在具体做法与目的之间往返，寻找别的实现路径 |
| Build and Craft Intentionally | 清楚知道此图要帮助检验什么，按此控制细节 |
| Communicate Deliberately | 图形、文字与实际阅读顺序一致，独立可懂 |
| Design Your Design Work | 选当前需要的方法，不让框架反过来规定问题 |

八项能力与五种模式是不同视角的组织方式，不能简单一一对应，也不作新旧完全替代的断言。

## 优先调用：六种思考动作

以下“图中动作”“自思考提示”“适用边界”为自主改编。模型名留在后台，普通交付不展示整张方法表。

| 何时调用 | 方法依据与原理简述 | 图中动作 | 自思考提示与边界 |
| --- | --- | --- | --- |
| 被“做不做某物”卡住，做法已被当成目的 | Why–How Laddering [S3 卡10]；Ladder of Meaning [S4]：往返于目的与实现方式 | 从一个具体做法上移到待辨认的目的，再分出其他实现方式 | “我借它想实现什么？还有什么做法？”不替用户填写深层动机；更抽象不自动更正确 |
| 题目过大、过小或暗藏了方案 | POV [S3 卡11]、How Might We [S5]：换一个有范围、可生成可能性的问法 | 保留原题，移动取景框；展开少量不同问法，每个显示改变了什么 | “我在替谁解决什么？这个问法已经指定答案了吗？”新题是候选，不默默替换用户原题 |
| 一上来只剩赞成／反对，想不到其他做法 | Idea Expedition [S6]：扩展可能后再选择发展 | 同一个目的通向实质不同的路线，另留比较依据的位置 | “这些路在什么条件下各自成立？”先生成与后比较可分开；不强求菱形、三条路或最终赢家 |
| 只在一个尺度理解问题 | Powers of Ten [S3 卡8]、Map the Problem Space [S7]：改变尺度或层次检查联系 | 保持同一对象，扩大／缩小时间、人数或处境范围；显出跨边界的新关系 | “一次成立，长期还成立吗？对个人和周围人一样吗？”改变尺度是试想，不添加假数据；不默认复制六层填表 |
| 反复猜测某个做法是否有效 | Experiment Expedition [S8]、Creative Essentials [S9]：通过可体验的东西学习 | 将一个待检验的连接画成缺口，选一个片段或简易表示接触现实，再返回修订 | “这次到底想知道什么？什么观察会让我改判断？”画出观察入口而非代写结果；不自动建立应用或执行试验 |
| 感觉已知道别人怎么想 | Ethnography Field Guide [S10]、What? How? Why? [S3 卡2]：从可见材料到待核实解释 | 分开观察与动机猜想，解释用虚线连接，留下查证或其他解释的位置 | “看见了什么？哪些是我猜的？”视角模拟不是真实同理证据；不把用户或他人的性格当结论 |

## 按需补充，避免重复造目录

这些来自 [S3] 工具卡，可与本 skill 已有思考动作合并使用：

- **Journey Map（卡7）**：拆开一次经历。画具体过程的接触点和停点；与确认关口图兼容，但时间先后不代表因果。不能编造经历与情绪曲线。
- **2×2 Matrix（卡9）**：用两个有依据的维度检查关系。放置同一对象，换轴后再看；无测量时不画精确坐标或分数，空象限不自动是机会。
- **Design Guidelines（卡12）**：将想保留的品质与某个具体方案分开。可画“几种做法都要满足的边界”；未核实的用户需要不能直接升级成标准。
- **Impose Constraints（卡18）**：临时改变一个限制，观察是否打开新做法。用可移动边界与原边界对照；区分现实硬约束与为探索临时加的条件。
- **Identify a Variable（卡24）**：聚焦一个待辨认因素。保留相同元素，只改目标因素；这让比较清楚，但一张图或一次非正式试用不能证明因果。
- **User-Driven Prototyping（卡25）**：给足够的支架让人自己生成。让关系可补、可移动，不把整张图填成答案；不强迫填写、回答或操作。
- **Feedback Capture Matrix（卡27）**：区分喜欢之处、改进、疑问和新想法。用于读懂反馈，不默认把探索地图做成四格反馈表；喜好不等于可行性或有效性。
- **Analogous Empathy（卡36）**：从别处寻找相似关系。画“对应关系”及无法迁移的边界；类比只能打开解释，不能替代事实或证明。

这里是选择性目录，不声称穷尽 d.school 方法，也不声称这些方法全由斯坦福首创。

## 必须保留的适配边界

1. **不追问仍成立。**官方工具常需访谈、团队讨论和反馈；本 skill 把启发转为图内自思考提示。助手不能用编出的访谈、人物画像或角色扮演填补缺少的真实材料。
2. **不把所有问题变成可设计的问题。**对事实、风险概率、不可逆人生选择、伦理与权利冲突，设计思维只能帮助界定、生成或探索；不能仅靠用户偏好、一次试用或换个问法裁决。
3. **三种状态分清：**画在图上可检视的结构；脑内推演的假设；接触现实得到的观察。只有第三种才可称已观察到的反馈。图的使用反馈只能说明此图的可读性或体验，不能证明图中主张为真。
4. **不强行乐观。**并非每个困境都能通过创新解决，未知可能暂时无法消除。Ambiguity Journey Map [S11] 可用于回看不确定感变化，但“进入不适就会抵达发现”不能当作必然路径。
5. **保持黑白几何基线。**借用方法，不复制彩色六边形、便利贴墙或教学工作表。图仍需具体对象、可辨认的关系和推演方向；方法名称不增加理解时不放进图内。
6. **不以校名背书。**方法有明确来源，不能据此宣称本 skill、黑白画风或单张图已被证明有效，也不追求让读者因权威感而深信不疑。
7. **区分出处。**Double Diamond 的此名称与常见四阶段框架由英国 Design Council 传播，不能归为斯坦福五模式图 [S12]。同理心图等常见图式也不能未经核实全部归到斯坦福。

## 研究证据：能说到哪里

官方工具说明与案例属于方法资料，不是此 skill 的效果试验。直接相关的新研究为 2026 年 DANI 原始论文 [S13]：它开发和检验的是设计教育情境中的不确定性应对自评工具，区分态度和行动策略。论文报告的课程前后变化不能外推为所有设计思维方法、独立图示或所有人生判断的因果效果。

作者说明：量表主要适合群体层面的课程评价；个体误差较大，依赖自评，未完成效标效度及重测信度评估，也未验证预测未来设计成功。不要把它移植为用户心理评分，不把“愿意面对未知”和“有办法推进未知”混为一谈。

对本 skill 的实际验证仍是：能否独立读图、能否跟随关系主动生成想法、是否清楚区分推演与事实。可参考[五张几何样例](examples.md#dschool-五问题几何转译)；视觉可读性不证明图中假设成立或本 skill 有普遍效果。
