# 从推理风险到图中的检查动作

这是一套为此 skill 整理的实用索引，不是完整的心理学分类、流行程度排名或已验证的去偏方案。研究与限制见 [证据与覆盖边界](evidence-and-boundaries.md)。

## 先识别缺的是什么

- 概念混在一起：先区分，未必需要更多证据。
- 有事实但推断跳跃：把推理步骤和替代解释画出来。
- 关键数据缺失：让缺口可见，不用图形补成答案。
- 愿望或价值冲突：呈现代价与条件，不把其中一端纠正掉。
- 想法清楚但行为未改变：图最多指出可验证处，不能代替体验、行动、练习或外部条件改变。

不要按关键词给用户贴偏差标签。以下自述均为示例，不是诊断标准。

## 代表性问题与可执行动作

| 推理风险或常见卡点 | 示例 | 在图中做什么 | 图以外仍需要什么 |
| --- | --- | --- | --- |
| 假两难、遗漏选项（逻辑问题） | “不开新频道，就只能憋着。” | 把想达到的目的与已列出的手段分开；补上确实不同的中间方案或可逆尝试。 | 各方案是否实际可行。不要捏造一个必然优越的第三方案。 |
| 概念替换、目标与手段混淆（分析问题） | “结婚就是不孤独”“换工具就能写好。” | 分列想得到的生活、选择的安排、二者之间尚缺的条件；允许同一词拆出不同含义。 | 真实体验、对方意愿或实际使用反馈。不能保证某手段满足某愿望。 |
| 确认偏误、动机性推理 | “这些例子都说明我该做。” | 把观察、解释、支持、反例和未知分开；列一个有区分力的替代解释，以及什么观察会让原解释改变。 | 获取反证或新信息。不得为凑正反两栏编造证据。 |
| 可得性、显著性与近期信息影响 | “最近满眼都是成功转型的人。” | 将最容易想起的例子与总体、时间窗口、信息获取途径分开。 | 更系统的样本；图不能推断曝光率就是发生率。 |
| 幸存者偏差、选择偏差、忽略分母与基率 | “看到三位成功者，所以成功率很高。” | 在成功数旁放尝试总数、失败/退出者、观察范围。未知写未知；不能画虚构数量的失败者来反驳。 | 总体或可比样本；没有分母不计算实际成功概率。 |
| 框架、锚定、参照点影响 | “原价很贵，所以现在划算。” | 固定同一事实，比较不同表述；单独列参照点、可用替代项、实际付出与收益。 | 独立的参照资料和用户真实标准。不要悄悄换分母或把不同命题称为等价。 |
| 因果误判、单因解释、归因过度 | “换了封面就火了”“他没回复就是不在乎。” | 分开观察、时间先后和原因假设；标出可能的共同原因或竞争解释，以及能区分解释的观察。 | 数据、比较、沟通或检验。增加几条箭头不构成因果证明。 |
| 过度确定、概率与影响混淆 | “一定会失败”“损失很大，所以概率一定很高。” | 将发生可能性、影响大小和可应对程度分开。数据足够时给范围、同分母频数或情景；不足时注明。 | 可信估计与事后校准。没有数字时不画有刻度的假概率轴。 |
| 沉没成本、承诺升级 | “已经投入半年，现在停就全白费。” | 用“从今天起”切开过去投入与未来继续/调整/停止各自新增的代价、收益；可复用资产单列。 | 未来成本与效益。既有经验、退出成本、合同责任等真实未来影响仍要保留。 |
| 维持现状、忽略机会成本 | “不做就没有代价”“再加一件事也没关系。” | 在同一资源约束下并列新增选择和被挤占的活动；把维持现状的未来代价也写出来。 | 实际可用时间、资金或注意力。不能假定改变总是优于不变。 |
| 当下偏好、跨状态预测偏差 | “现在很烦，所以以后也不会喜欢。” | 在当前状态、另一种状态和较长时间范围中保留同一选择，区分暂时感受与持久偏好假设。 | 不同状态下的观察。感受不是错误，也不能靠画图消除。 |
| 计划谬误、低估不确定性 | “这次两天肯定完成。” | 并列当前计划与可比任务的真实耗时；标出依赖、等待、返工和估计范围。 | 可比记录。不要用凭空编出的“悲观情景”冒充外部基线。 |
| 事后聪明、结果偏误 | “结果不好，说明当时的决定很蠢。” | 把当时可知的信息、当时可选方案，与后来结果分时呈现；区分决策过程和运气。 | 当时的记录与可知条件。不能仅凭好结果证明过程正确。 |
| 从众、权威与光环、投射 | “大家都说该这样”“我喜欢，他肯定也喜欢。” | 分列谁的判断、依据是什么、与当前任务是否相关；将自己的偏好与对他人的猜测分开。 | 对方表达、独立证据。社会期待和专家建议可以是有价值的信息。 |
| 全称化、自我标签、把感受当事实（非诊断性思维模式） | “我总是迷茫”“我就是做不好。” | 从抽象标签落到有限情境；并列已知事例、反例和仍未知的范围，区分感受/事件/解释。 | 具体记录。不能替用户编造反例，也不推断心理病因。 |
| 完美解、分析停滞、手段吞掉目标（决策过程问题） | “想清一生才开始”“先把工具配完再写。” | 分开不可逆承诺与可逆尝试；画出最小可检验部分及其能减少的不确定性。 | 真实尝试与反馈。不要替用户执行未经授权的实验，也不把所有谨慎都当拖延。 |

## 选择表达，不绑定一种图形

- **区分和补齐：**嵌套、交叠、分开的定义、开放分支；在图上写明各区域的含义。
- **比较和换框：**同一标准对照、固定同一事实的不同表述、显式参照点。不得以图形对称暗示证据相等。
- **检验证据：**观察→解释→待核实条件，旁列反例或未知；标明每条联系的证据状态。
- **补分母和概率：**同分母点阵、频数树、包含总体的计数；有真实/明确假设数据才按数量绘制。黑白可用填充和轮廓区分。
- **拆因果：**先用两条易读的解释路径，再按需展示第三变量或回路。每条路径都能读成完整短句。
- **拉开时间：**过去/现在决策点/未来代价，或预期与实际的并列轨迹。时间间距无数据时不编码耗时。
- **资源和替代：**同一时间或资源底盘上的不同占用；没有测量值时用定性并列，避免假面积比例。
- **表达未知与验证边界：**把未知放到具体格子里，如“尝试总人数未知”，而不是在中心放一个泛泛问号。说明它限制了什么判断，不默认追问用户。

不同动作可共用几何元素。一次通常只处理一两处具体跳跃，避免把整张图变成偏差百科。

## 自解释示例：只有成功者，能不能推成功率

假设情境：“只看到三家新店经营成功，能否推断同类店普遍容易成功？”

图中可直接呈现：

- 已看到：3 位成功者。
- 未知：总共有多少人尝试；失败或退出者是否可见；这些人与自己是否可比。
- 目前可说：这条路有人走通。
- 目前不能据此说：普遍容易成功，或自己成功概率高。

这张图的任务是补上推断所缺的条件，而不是反过来宣布“成功率一定很低”。没有真实总体，就不画“3/100”之类的真实概率。

## 自解释示例：半年投入，还应不应该继续

输入：“已经做了半年，停下是不是前功尽弃？”

在图中用“今天”作为分界：过去半年不能撤回，但已有成果、能力或合同对未来可能仍有影响；从今天比较继续、缩小/调整、停止的新增投入、可复用部分和机会成本。未知的收益不填假数字，也不替用户选“停止”。

## 跨学科扩展

需要模型原理、条件变化或新的思考角度时，查[芒格模型路由](munger-models.md)；心理倾向与本页有交叉，合并为一个具体检查动作，不为了覆盖重复绘图。
