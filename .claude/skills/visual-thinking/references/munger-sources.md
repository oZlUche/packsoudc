# 芒格模型：来源、图示与覆盖边界

只把公开原文、官方教育资料作为归属和原理依据；不依赖互相转抄的“100 个芒格模型”清单。

## 这次整合覆盖什么

- 以出版社公开的《穷查理宝典》原文为核心，按工作需要整理 37 项方法／学科模型；部分属于编者概括，逐项注明。它们不是 37 个互不重叠的原创发明。
- 第十一讲列出的 25 项心理倾向逐项纳入后台索引。中文名称是工作译述，不冒充权威中文版的固定译名。好奇、公平、练习、状态等不应统统称作认知偏差。
- 未发现由芒格本人封闭编号、逐一界定的完整模型目录。原文提到大量跨学科模型；“都考量”在这里指扩大候选范围和检查盲点，不声称已收齐他一生所有言论。
- 图形、提问、模型分组与实际使用规则是本 skill 的改编，不能署为“芒格原图”。模型名称与学科原理不是芒格独创的同义词。

## 哪些只作为扩展，不冒充原文模型

贝叶斯更新、瓶颈分析、可逆实验等可以帮助完成具体推演，但不能因为常见于后人模型库就全部标为芒格原始条目。若使用，应另附其学科依据；本次没有把它们计入 37 项目录。网络效应不能直接等同于规模经济，自催化不能直接等同于所有正反馈，逆向也不是悲观情景的别名。

## 整合的效果边界

归属核实、文件格式验证、图像渲染与真实改善决策是四种不同验证。这次完成前三类中的相应检查，没有证明“用了芒格模型便能改善所有思考”。历史演讲中的心理学例证也不自动代表今天的完整实证结论；涉及具体因果、健康、药物、年龄与金融选择时，仍需相应领域的新证据。
