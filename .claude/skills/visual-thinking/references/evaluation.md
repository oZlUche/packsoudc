# 用真实问题验证

修改规则、脚本或主题后，按变动选择有关检查；日常出图不向用户展示测试问卷。只根据当前[骨架索引](../assets/skeleton-index.json)和[用途卡](skeleton-use-cards.md)判定候选，不沿用历史轮次编号。旧改版日志已移出执行说明，不能拿它们恢复旧骨架。

## 验证层次分别记录

| 层次 | 能检查什么 | 不能声称什么 |
|---|---|---|
| 文件与脚本 | frontmatter、文件、链接、渲染与碰撞诊断 | 选图正确或读者学会了 |
| 作者制图自查 | 主体、范围、解释、路径与版式 | 无上下文也能稳定复现 |
| 独立代理试用 | 新上下文能否按同一skill选图、出图、自查 | 真实人类读懂或长期变好 |
| 真实读者试用 | 能否找到入口、复述关系、定位处境与疑问 | 长期学习或决策改善 |
| 长期效果研究 | 在相应设计和数据下比较变化 | 由一张好看的样图替代研究 |

## 本轮任务怎样验收

先检查[成图价值](structure-selection.md#成图价值检查)，再看排版。语义检查不以“有圆有箭头”通过，视觉检查不以“没有碰撞”通过。结构好的图若只是文字不清，优先修文字；一句话能解释的小问题不扩成复杂图。

| 请求 | 应观察到的行为 | 失败信号 |
|---|---|---|
| 从零了解一个新领域，从哪里展开？ | 保留全景、局部案例、证据与返回关系；未知有位置 | 缩成某个岗位或学习清单 |
| 为什么越赶工作，返工越多？ | 先核对机制；如比较两种做法的时间后果，同一坐标、口径和起点 | 只有“赶工→出错→返工”的同义回环，或无数据伪造趋势 |
| 我想换工作，但又怕后悔 | 区分想改善的条件、真实代价、可逆试做与待查信息，不预填个人背景 | 泛泛问句成圈、强迫二选一或凭空评分 |
| AI做对了题，算我学会了吗？ | 区分产出正确与独立完成／迁移表现，用最少结构检验 | 将一项条件区分扩成庞大网络 |
| 给一个最基本KWHL | 当前四栏学习框架，K/W/H/L功能可辨，未调查不预填L | 错用扩大观察尺度或加复杂回路 |
| 用5W1H策划一场读书活动 | 中心与六问保持共同主题，允许择需进入；设想与事实分开 | 六问变成因果或步骤，基础图式被装饰淹没 |
| 用Compare Map比较两个安排 | 同一标准同时看两边，各自表现和例证可读 | 中央标准被当共同点，两边说不同维度 |
| 用Concept Definition Map讲机会成本 | 定义、属性、实例与成立理由互相对应；具体例子确有解释作用 | 只列名词、把属性全当必要条件或改成能力测评 |
| 一则公共争议怎么回事？ | 先查背景、各方说法、时间与缺失视角；可考虑信息冰山 | 直接诊断动机，水下内容一概当真相 |
| 用V Map调查一个具体主张 | 区分计划和发现，让问题、概念、取证与结论可追溯 | 因为研究过就把普通理解任务也画成研究记录 |
| 搜索结果等于全部资料吗？ | 以真实包含／检索范围检查已查与未知，不预填完整总体 | 将内圈当真相或未查到等于不存在 |
| 借熟悉关系理解新问题 | 区分关系类比与表面相似，标出失配与待查推论 | 使用沉没成本分岔代替类比 |
| 只换主题，保留结构 | 对象、文字、位置、方向和证据状态不变 | 换肤顺便换了逻辑 |
| 这处说明看不懂，结构很好 | 在原关系旁补足主语、动作和后果 | 变成文章路径、另造工资或家庭算例 |

## 图形与语义检查

- 圆、方框、边界、交叠和连接在正式图中保持其对象身份；不能由一组文字标题代替。
- 核心连接可以读成完整意思。非箭头图用分区、共轴、包含、相交或数量口径解释，不强行加箭头。
- 对象位置、顺序、路径或条件变化后，读者能指出具体哪处需要重查；概念图也可以通过实例归类、非例或关系复述体现价值，不强求每张都做条件实验。
- 比较保持同一尺度；研究不足不补造事实，未熟悉概念要就地解释。来源仅支持它实际论证的关系。
- 主体和留白成立后，再修局部碰撞。刻意穿越圆后与误穿文字分别处理。

## 陌生读者小范围试用

先由维护者邀请少量愿意参与的人；AI不得自行发送邀请。每人任选一个自己关心的问题，独立在新会话调用，不给其看理想答案或冗长使用教程。

读完后观察四件事：能否指出入口；能否用自己的话说清一处关系；能否把自己的情况放进相应位置；能否提出一个比原题更具体的下一问。询问卡住的是词语、关系还是图形。允许指出“文字就够了，没必要画图”。

用现有笔记记录：原请求、实际图片、读者原话、卡点及后续修改；不建立新的收集系统。没有真实读者参与就记为“未开展”，不能把作者或代理自评分写成通过。

## 技术复核

- 格式：使用当前环境可用的skill校验器。
- 链接：检查Markdown和HTML相对路径、锚点，以及索引中实际素材。
- 脚本：按[渲染说明](rendering.md#回归测试)运行布局与换肤测试。
- 图片：实际打开有关PNG；已认可骨架未改几何时可比对文件一致性，不为验证再重绘。
- 公开候选：在移除本地扩展后重新检查链接、索引、安装说明和出图；不能只检查维护目录。

实际运行记录留在当次工作区，不堆进skill。具体平台、测试范围和未验证事项需说明；不宣称跨平台、长期或全题材效果已经通过。

## V Map 专项验证

研究计划、论文解读和已完成调查分别验证：计划不预填发现；解读注明实际材料与阅读范围，不冒称独立实验；完成调查时，回答能追溯到概念、取证工具、材料及限制。保留同一个问题和各区功能，V形不是漏斗或因果箭头。

未指定V Map而希望形成可应用的理解时，研究后重新按问题中的关系选最终图；明确指定V Map时保留图式要求。不能由一次AI使用案例失败推断V Map不适合所有真实问题。
