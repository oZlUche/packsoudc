# Visual Thinking · 视觉思考辅助

把一个问题，变成一张可以沿着思考的图。

它帮助AI先辨认问题里的关系，再选择和绘制结构：看清整体与局部、比较共同条件、追踪资源与限制、核对证据，或保留不同可能。图应提供必要解释，也留出由你代入情境、继续判断的空间。

## 第一次使用

1. 将整个文件夹命名为`visual-thinking`，放入Codex个人skills目录；默认位置为`~/.codex/skills/`，自定义位置则为`${CODEX_HOME}/skills/`。保留目录结构，不要只复制SKILL.md；替换已有版本前自行备份。
2. 在新的会话中调用：

```text
$visual-thinking 我想从零了解一个新领域，可以从哪些方面展开？
```

3. 对着实际图继续修改，例如“保留结构，把这条关系说直白些”“用同一标准再比较另一种安排”。你不需要先学会模型名称。

也可以试：

```text
$visual-thinking 给一个最基本的KWHL图，用贴纸学习板。
$visual-thinking 请解释为什么会出现这个现象，先查关键机制和替代解释，再画图，来源放在图底。
$visual-thinking 保留刚才的对象、关系和位置，只换成彩色积木主题。
```

默认不先用问卷追问；未知会有清楚位置，不会被补成你的事实。简单问题用最少结构；探索题保留取舍；解释题把关键机制画清，不能只堆问题。

## 环境与渲染

需要能够读取本地skill、生成SVG并显示或渲染图片的AI环境；事实研究另需检索能力。三个主题是黑白几何（默认）、彩色积木和贴纸学习板，后者没有绿色外沿。

附带渲染器使用Node.js、Playwright和Chromium或本机Chrome。它是可选助手，依赖需单独安装，见[安装、首次渲染与故障处理](references/rendering.md)。没有渲染环境时不把SVG源码当成已验证的图片；其他客户端是否自动识别skill取决于客户端。

## 骨架与方法

本公开版本包含38个可用条目。以[当前索引](assets/skeleton-index.json)中的名称和实际文件为准。编号是稳定身份，不是能力排名，公开包排除本地条目后保留空位。不要从旧导出、历史聊天或归档选择骨架。



方法按具体缺口选用，来源和实际阅读范围见[ATTRIBUTION.md](ATTRIBUTION.md)。研究充分不等于每张图必须交付研究过程；不能从静态图中推断真实因果、人格或未来结果。本skill未获得思考能力提升、去偏或长期决策效果的系统验证。
