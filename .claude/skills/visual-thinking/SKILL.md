# 视觉思考辅助

把问题中的对象、关系与未知画成可沿着思考的空间。帮助用户理解、推演和修正判断；必要机制要讲清，个人取舍不代为预填。默认直接出图，不先用问卷索要个人经历。用户只讨论文字时不强行绘图；本 skill 的视觉探索中，“再试试”继续交付图片。

## 1．辨认本题要做什么

- **探索与选择**：保留主要方向、真实约束和不同可能；让读者能将自己的情况放进去。相关个人背景可帮助判断重点，但推测不能写成已确认需求。
- **解释与理解**：先说明事情怎样发生、什么牵动什么，再画结构。已知机制可以明确教；不把解释改成一圈“你觉得呢”。
- **基础图谱与简单问题**：沿用明确指定图式的常见用途与简单结构。若一句话或小图已能说清，不靠增加节点制造价值；用户明确要求图时仍给最简够用的图。

保留问题的层级：全屋需求不能自动缩成一条局部动线，整体教育选择不能只剩一项价值。公共事件未限定角度时，先按了解全貌处理，核对公开结果、各方理由、前后背景和缺失视角；见[信息冰山](references/iceberg-and-proportion.md#公共事件先展开再解释)。大问题不等于必须穷尽所有内容，局部探索须有清楚范围。

## 2．先说清关系，再选图

在内部用两三句日常语言写清：本题涉及什么对象；核心联系是什么；读者看图后能进一步判断什么。说不清就继续分析或查证，不先用好看的骨架装进去。这段是制图前的判断，不强制作为图外文章交付。

按[选图卡](references/structure-selection.md)确定思考动作，再查[骨架索引](assets/skeleton-index.json)、[用途卡](references/skeleton-use-cards.md)及所涉[视觉辨认入口](references/visual-recognition.md)。以当前索引中的实际文件与名称为准；只读有关条目，不整套加载，不按最近使用的骨架惯性选图，不从历史归档恢复旧稿。索引不限制方法上限；新关系确有需要时可独立绘制，但不能冒称某种原版模板。

按[成图价值检查](references/structure-selection.md#成图价值检查)判断图的必要性：

- 几何是否直接呈现共同标准、包含、资源去向、依赖、变化或其他真实关系？
- 关键连接能否用完整短句读出，或由明确的空间／数量编码理解？
- 除了看到提示问题，读者能否追踪一处关系、定位自己的情况或发现一个具体未知？

开放图可以以问题为主，但分组和连接仍须有说明；不能所有节点都是互不相关的问句。机制图须把驱动力、资源、限制或积累画出来；换一个条件只是检验手段，不是原因解释的替代品。

比较同一结果随时间怎样变化，读[时间图指南](references/time-trends.md)；事件先后、持续、重复和反馈须分别判断。研究怎样组织与问题怎样理解也分开选：V Map 适合调查与证据追溯，不因做了研究就把最终答案画成研究记录。具名教学图式先按[原法核对](references/graphic-organizer-coverage.md#对照原书21种图谱)明确用途，再应用或标明扩展。



## 3．按证据需要研究

价值探索不自动变成文献综述。解释原因、回答事实或用户要求深度研究时，先读[检索构思与证据覆盖](references/research-planning.md)：提出候选机制和竞争解释，识别关键关系需要什么证据，再检索；不只取题目里的几个关键词，也不先认定一个模型找支持。

核对基础原理与具体情境，区分实证、理论、外推、假设及个人未知。研究充分性取决于关键联系是否有支撑，不取决于文献数量。覆盖不足就补查或缩小主张；只能读到摘要时如实注明。图底列本轮实际使用的直接来源，必要时在关系处对应编号；来源与关键不确定性不能被小字埋掉。纯探索图不虚构引用。

## 4．让几何与文字一起解释

按[几何语言](references/visual-language.md)保留对象、边界、交叠、分区及路径的真实身份；圆和方框给对象命名，不能删成文章标题。一个主体结构承载主要关系，必要的局部操作仍属于同一整体。不要以几幅孤立小例子替代全屋、全景或系统关系。

对象要指得出，关系词要说得通。对必要的陌生概念，就地解释“是什么、发生后意味着什么”；未知则写明缺哪类材料，而非只放问号。语言自然具体，不用抽象词串、模型名称或过度缩写让读者补出主语和动作。例子只在帮助当前理解时使用；不虚构工资、经历、家庭需求或数据替代用户处境。

无数据，不以面积、距离、深浅、数量或线宽暗示权重、概率和重要性。相近不等于支持，先后不等于因果，回路不自动证明反馈。前后路径相同可以共用路线，变化在原位置核对；真实路线或趋势不同则保留多线，不为排版制造无依据的高低差。静态试摆不等于现实验证，不由情绪措辞诊断人格、偏差或疾病。

## 5．保留审美，实际检查后出图

只有[黑白几何／彩色积木／贴纸学习板](references/skins.md)三个主题，默认黑白，同轮修订不擅自换肤。主体、比例、层级与留白优先；基础KWHL、5W1H不额外叠网络。贴纸学习板无绿色外沿，不生成额外设备适配版。

按[排版与走线](references/layout-and-viewing.md)使用简洁中英标题、明显字号层级和主图上下完整空白带。通常用正交线与12px小圆角；**已确认骨架的几何身份和有意义路径优先于通用走线偏好**。集合轮廓、螺旋、时间曲线和经认可的贯穿弧线不能被改成流程图；例外限于本图，不推广为装饰性自由曲线。

精确关系图优先SVG；按[出图说明](references/rendering.md)渲染PNG，实际查看全图及拥挤局部，修复文字／路径遮挡、圆内边距、隐藏箭头和裁切。自动检查仅定位疑点，未标注的路径不能声称通过。保留可编辑源；在聊天中直接展示PNG与必要的短解释，不能只给文件链接。不能预览时如实说明。

最后核对：问题范围是否保留；核心联系能否从图内读出；事实、条件与未知是否清楚；用户能否定位自己的情况或提出更具体的下一问。修复相应失败，不靠图外长文章补救，也不为完成检查再加一轮装饰。

## 修订与维护

用户认可结构而说难懂，先修就地文字和阅读入口；只改审美时保留关系；结构选错才换图。深化先补驱动力、限制和后果，不把每题都改成换条件。明确的局部修改只动相关部分，较新版本不自动替代已认可的图。

改规则或工具后按[行为验证](references/evaluation.md)做相称检查。格式、图像检查、独立代理试用、真实读者理解及长期训练效果分别记录，不互相冒充；没有用户授权，不联系他人做试用。需要分享时读[发布检查](references/release-checklist.md)。

公开材料仅含通用或明确授权的内容；检查文本、配置、文件名、SVG元数据与PNG像素。私人回复不等于公开授权，改名仍可识别时替换整个案例。来源与许可见[ATTRIBUTION.md](ATTRIBUTION.md)；不复制外部技能的明确资产、内容或实现，也不借删除署名制造原创印象。
