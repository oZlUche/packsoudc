# 概念与神明：可纳入的抽象概念与它们能做成的玩法（提议）

> 世界观文件夹的第二份文档。前提是 [worldview.md](worldview.md) 第一节作者定的神话主线：**概念 → 神 → 物质与生物**，每位神就是一个概念的化身。
> 作者的要求：从现有的神明信仰出发，列举**可以纳入的抽象概念 —— 要求跟人类活动无关**，并探讨能做成的玩法。
> 这份文档是**提议**，不是设定稿：第二节的每个概念都要作者一句「要 / 不要 / 改」，定了再回写 worldview.md 第一节，再进数据。
> 玩法部分只用已经有的构件说话（`docs/effect-catalog.md` 的时机 / 效果、`FaithDeed`、`RunBuffDef`、事件构件），需要新构件的地方单独标出来。

## 一、从现有的信仰出发：先看清「概念」在这个世界里是什么

### 已登记的神与祂们的概念

| 信仰（`data/authoring/faiths/`） | 概念 | 概念的性质 | 沾了多少人性 | 信力行为（现状） |
|---|---|---|---|---|
| 暴力之神（力量之神） | 力 / 冲撞 | **自然的**：石头砸下来也是暴力 | 少：北境蛮族信祂，祂不管事 | 打一场 +1 |
| 战争之神 | 战争 | **人类活动**：有了军团才有战争 | 多：军团的神，有偏好、有荣誉 | 打赢 +1、每花 20 币 +1 |
| 技巧之神 | 技巧 / 精确 | **人类活动**（工艺、格挡） | 多：收供奉 | 置入值钱的 +1、献祭 +2 |
| 狩猎之神 | 追猎 | **半自然**：狼也狩猎，人把它当作概念信 | 中 | 搜一次 +1、每进账 15 币 +1 |
| 太阳与火之神（原恒常之神） | **恒常 → 周期循环** → 被人推向太阳、又夺了火 | **自然的**（作者定的例子：一个抽象概念被人类用自然现象绑定） | 被推动过，有人性 | 每走 2 步 +1 |
| 元素之神（已陨落） | 物质 / 移动 / 吸收 / 释放 → 元素 → 魔法 | **自然的**四个概念被绑定成元素 | 生来就充满人性 | —（魔法独立了） |
| 新教的唯一神 | **未定** | — | — | 事件里做选择 +1 |

三点观察，决定了下面怎么挑概念：

1. **现有的神里，人类活动出身的（战争、技巧）已经占了一半。** 作者要的「跟人类活动无关」正好补另一半：**自然本身就在演示的概念** —— 落下、变冷、腐朽、重复、边界、空无。这类神更接近作者定义的「神性 = 绝对理智」：祂们不需要人类做什么才存在，所以更**静**，是舞台而不是角色。
2. **作者已经给了模板：恒常之神。** 一个纯抽象的概念（恒常 = 周期循环）被人类绑定到一个自然现象（太阳），神就有了「脸」。所以每个候选概念都按同一格式写：**概念 → 人类绑定的自然现象 → 权柄（祂管什么）**。绑定现象不等于概念本身（太阳神不是太阳），这是给道具与事件文字留的空间。
3. **概念不是元素。** 元素之神是四个概念**融合**出的新概念，说明概念之间能有「谁包含谁、谁生出谁」的关系。下面的清单按**族**分组，族内可融合、族间有克制，这本身就是玩法（第三节）。

### 挑选的标尺（作者的规则翻译成筛子）

- **自然里找得到**：没有人类也在发生（下落、结冰、腐烂、回声、日夜）。战争、交易、技艺、律法、谎言（作者定：还没有谎言之神）都不合格。
- **能落在道具与战斗上**：概念的权柄要能翻译成 effect-catalog 里已有的时机与效果，至少能翻译成一条新的 `FaithDeed`。翻不过去的概念（美、真）不要。
- **和已有的神不重叠**：力（暴力）、周期（太阳）、四元素（陨落）已占；「速度」与「移动」重叠、「热」与「火」重叠，不单列，写成已有神的另一面。
- **每个族给一位就够**：demo 之后一两个章节的量，是三到五位新神，不是十二位。

## 二、可纳入的抽象概念（清单）

写法统一：**概念** → 人类绑定的自然现象 → 权柄 → 神性 / 人性 → 赐福的样子（道具族 / 种族天赋）→ 信力行为 → 在一局里的表现 → 和其他神的关系。
「现有构件」栏写它能不能用今天的效果树直接做；标 **新** 的是要加构件的。

### 甲族 · 落与压：**重量**

- **概念**：重 / 沉 / 向下。石头往下落，水往低处流，山把自己压成岩。
- **绑定的现象**：山岳、深渊（人把「重」推给了山）。
- **权柄**：负担、迟缓、坚固、不可移动。**祂是暴力之神的兄弟**：暴力是力向外撞，重量是力向下压。
- **神性**：极静。祂什么都不要，只是压在那里 —— 是「自认弱的神安心居于其下」的典型。
- **赐福的样子**：**沉重之物**道具族 —— 大件、占格多、`haste` 低、`armor` / `damage` 高；「越重越好」：护甲随身上占的格数成长。种族天赋：山民（背包多 N 格，但耐力消耗评估上调一档）。
- **信力行为**：**背负**（新 deed `carry_weight`：离开一个点时棋盘上占格 ≥ N 给 1）；**不动**（`travel` 的反面：在一个点上做完所有事再走）。
- **在一局里**：休息点的变体「石座」（坐下 = 耐力回满但下一步耗双倍）；侵蚀的重量版 = 背包每层多占一格（作者定侵蚀是神弃的加深，重量之神的神弃就是「越来越沉」）。
- **克制**：压制流血 / 中毒这类「流动」的东西（叠层的 buff 施加 −1）；被移动（元素残留的「移动」之物）克制。
- **现有构件**：护甲随格数成长要 **新** 属性源（`armor_per_cell`，编译期可算，不必进战斗时）；其余 `mods` / `apply_status` 够用。

### 乙族 · 变与散：**腐朽**

- **概念**：衰变 / 降解 / 归尘。一切放着不管就会烂。
- **绑定的现象**：霉、锈、落叶（人把「一切都会坏」推给了秋天）。
- **权柄**：持续伤害、损耗、时间的代价、**也是消化 —— 把一样东西变成另一样**。
- **神性 / 人性**：**这一位应当是诸神里最重要的一位新神，因为祂就在 worldview 的主线里**：元素之神陨落后的残留「过于庞杂又混杂人性，诸神不敢浸染，只能任其**自然降解**」—— 降解本身就是一个概念。祂是诅咒之地真正的主人：侵蚀不是随机的坏运气，是腐朽之神在消化神陨的遗物。因为祂正吞着满是人性的残留，祂**正在沾染人性** —— 一位「越来越有戏」的神，剧情最好的位置。
- **赐福的样子**：**腐蚀之物**道具族 —— 中毒 / 流血的升级版：`poison` 伤害 `per_stack`、敌人护甲被削（`remove_status` 削「结界」、`modify_damage` 忽视护甲）；「腐朽的祝福」= 用久了的道具反而更强（新 deed 见下）。种族天赋：沼地人（对 poison / bleed 伤害 −50%）。
- **信力行为**：**让东西坏掉** —— 走出一个点时**扔在地上没带走的道具**按价值给信力（现有的 `place_item` 反过来：`abandon_item`，**新**，接 `RunState` 清地上那一刻）；**消化** —— 合成（`craft_done`，**新** deed，一行接线）。这一条把 084 定的「地上离开就消失」和 085 的合成都变成了信仰行为。
- **在一局里**：**祂就是侵蚀**（075）：侵蚀的三种效果（扣体力、损坏道具、掉钱）改写成「腐朽之神的注视」；信腐朽之神的玩家**被侵蚀时反而攒信力**（deed `eroded`，**新**），这是「与诅咒同行」的玩法。事件：腐朽的祭坛 —— 献上一件道具，换它「烂成」一件随机同稀有度的道具（重掷，用现有 `grant_item` / 一个新的 `reroll_item` 后果）。
- **克制**：克恒常（周期被打断：太阳系道具的「每 N 步」不给）、克重量（再沉的也会锈）；被火克（火是释放，烧掉腐朽）。
- **现有构件**：poison / bleed 已是永续叠层（085），`per_stack` 有；缺的是几条 deed 与一个 `reroll_item` 事件后果。

### 丙族 · 冷与止：**寒冷**

- **概念**：冷 / 静止 / 凝固 / 保存。热是释放（元素之神拿走了），冷是**释放的缺席**。
- **绑定的现象**：冬、冰、北境的雪（北境蛮族信暴力之神，但他们的土地属于寒冷 —— 两位神共享一片信众，事件里能写）。
- **权柄**：减速、冻结、**保存**（不腐坏）、忍耐。
- **神性**：静。**祂和腐朽是一对**：腐朽让一切变，寒冷让一切停。诸神里两位最静的神，正好是诅咒之地的两极 —— 外环冷（保存着完整的遗物），内核烂（残留活化）。
- **赐福的样子**：**凝霜之物**道具族 —— 施加「冻僵」（不可叠层、有时长的 debuff：对手 `haste` −30%，作者定的「不可叠层的才可以过期」正好）；「冰甲」= 开战时 `max_shield` 一大块但不回；「保鲜」= 口粮 / 伤药类消耗品在寒冷之神下不占背包格（编译期把 `consumable` 标签的道具算作 0 格 —— **新**，但只是布局层）。种族天赋：北境人（第一次受伤前 `armor` +N）。
- **信力行为**：**等待** —— 战斗里 N 秒不出手（**新** deed `idle_battle`，从回放里数）；**不搜第二次** —— 在搜索点只搜一次就走（现有 `explore` 反过来，看 `search_stage`）。
- **在一局里**：**冻住的节点** —— 一个新的节点修饰而不是节点类型：被冻住的搜索点第一次搜必空，第二次开始全出（把 085 的搜索曲线整体右移一格，是数据不是代码）；冻住的敌人：战前准备屏里显示它「僵着」，开战前 3 秒不动（`on_battle_start` 施加冻僵）。
- **克制**：克移动（速度）、克流血（冻住不流）；被火克。
- **现有构件**：`apply_status` 冻僵、`max_shield` 都有；「等待」deed 与「消耗品 0 格」是新的。

### 丁族 · 复与应：**回响**

- **概念**：重复 / 反射 / 共鸣。一声喊出去，山谷送回来；一块石头落水，波纹一圈圈。
- **绑定的现象**：山谷、水面、雷之后的滚声。
- **权柄**：连带、反弹、**第二次**。
- **神性**：静，但**是诸神里最「像镜子」的一位**：祂不制造，只复制。神话里可以写：元素之神欺骗诸神时，唯一「察觉」的是回响之神 —— 因为谎言没有回声（作者定：还没有谎言之神，回响之神不能识破谎言，只是「听不到回声」，所以沉默）。这给了祂一个不动手却在场的位置。
- **赐福的样子**：**回响之物**道具族，是**现有效果树最擅长的那类**：`on_item_fired`（连带触发）、`reflect_damage`（反伤）、`charge`（攒够 N 次放一发）—— 三样构件都在 effect-catalog 里躺着，没有人带。「回声弓」= 相邻武器出手后 40% 概率跟着射一箭；「共鸣盾」= 反弹 25%；「二度符」= 第二次施加同一个 buff 时多叠一层。种族天赋：谷地人（第一件出手的武器每场多打一次）。
- **信力行为**：**重复** —— 同一个节点类型连走两次（**新** deed `repeat_node_type`，看 travel 的上两步）；**反伤** —— 战斗里 reflect 类型伤害累计每 N 点给 1（`battle` deed 加个 `damage_type` 过滤，小改）。
- **在一局里**：**回声节点** —— 传送点（076 的 8-1）的神话解释：走进去，从「同一个形状」的另一个点出来；事件「山谷」：你在这里说的话 —— 选的选项 —— 下一个事件点会「回来」（同一个选项标签再出现一次，走 `EventOption.tags`）。
- **克制**：克暴力（撞得越狠弹回越多）；被寒冷克（冻住的东西没有回声）、被腐朽克（烂掉的东西不响）。
- **现有构件**：几乎全有。**这是最便宜的一位新神。**

### 戊族 · 多与群：**繁多**

- **概念**：数量 / 群 / 堆叠。蚁群、蜂群、雨滴、沙。一个不算什么，一万个是另一回事。
- **绑定的现象**：蚁、蝗、沙暴。
- **权柄**：叠层、数量压倒质量、小而多。
- **神性**：静。**这一位是「叠层」这个机制的神**：作者刚定「buff 的叠层没有上限」，繁多之神就是这句话的化身。
- **赐福的样子**：**群之物**道具族 —— 小件（1 格、2 格），单个弱，`on_stacks_at_least` 出效果；「蚁符」= 每有一件 `swarm` 标签的道具在包里，全体 `swarm` 道具 `damage` +1（编译期数标签，**新**属性源 `count_tag`，和重量的 `armor_per_cell` 是同一种东西：**按布局算的属性**）；「沙漏」（078 的沙漏格阵正好）。种族天赋：多产者（开局包多 1 格但所有道具稀有度 −1）。
- **信力行为**：**塞满** —— 离开点时棋盘空格 ≤ N 给 1（和重量的 `carry_weight` 是同一条 deed 的两个参数）；**叠够** —— 战斗里某个 buff 叠到 N 层（`stacks_reached`，**新**，从回放里数）。
- **在一局里**：**群敌** —— 一个「敌人」是三个小棋盘轮上（现有战斗是 1v1，这要 **新** 的战斗形态，先不做；便宜的替代：一个敌人带三把同样的小武器，`swarm` 标签）。掉落规则里 `min_drops` 高但稀有度低。
- **克制**：克寒冷（数量融化冰）、克技巧（一个精确的格挡挡不住一群）；被重量克（一压就全没）、被火克。
- **现有构件**：`on_stacks_at_least`、`per_stack` 都有；按标签计数的属性源是新的。

### 己族 · 界与门：**边界**

- **概念**：分隔 / 阈 / 内外 / 尽头。海岸线、地平线、皮肤、壳。
- **绑定的现象**：海岸、山脊、天际线。
- **权柄**：护盾（**皮肤就是边界**）、进出、撤离、门。
- **神性**：极静，但**在游戏结构里到处都是祂**：出生点是进去的门，撤离点是出来的门，环形地图的每一环是一道界，背包的格子是界，地上与棋盘之间是界。作者定「诅咒之地是神陨之地」—— 是谁把神陨之地和帝国**隔开**的？边界之神。祂是诸神里唯一「参与了」诅咒之地的一位：不是出手，只是划了一条线。
- **赐福的样子**：**界之物**道具族 —— 护盾（`max_shield`、`on_before_damage` 的 `cancel`：第一次受伤免疫）、**棋盘边缘的道具更强**（编译期看格子位置，**新**属性源 `on_edge`，与前两个是同一族）；「门符」= 撤离费减免（`extract_fee`，现有占位符已经有它的字）。种族天赋：岸民（撤离点的撤离事件多一个选项：免费但丢地上）。
- **信力行为**：**越界** —— 每进一环 / 每过一个传送点给（`travel` deed 加 `ring_change` 参数，小改）；**撤离**（`extracted`，**新**，结算时给下一局 —— 信力跨局，正好接作者说的「继承」）。
- **在一局里**：**祂管撤离**。撤离点的对话（085 用 `extract` 后果做的）就是边界之神的祭司在把门。事件：「界石」—— 付钱把下一环的一个节点提前看到类型（现有 `NodeTooltip` 的信息，只是提前揭示）。
- **克制**：克繁多（门一次只过一个）、克移动；被腐朽克（界会烂）。
- **现有构件**：护盾、免疫、撤离都有；`on_edge` 属性源与跨局信力是新的。

### 庚族 · 无与缺：**空缺**（给新教的唯一神的候选）

- **概念**：无 / 缺席 / 沉默。不是黑暗（黑暗是光的绑定物），是**「那里本来该有东西」**。
- **绑定的现象**：没有 —— 这正是祂的特点：**空缺之神没有脸**。人类没有把祂推向任何自然现象，所以祂是唯一一位「纯概念」的神。
- **为什么是新教的候选**：worldview 第六节问「新教信的唯一神是什么概念」。按作者定的新神规则（人类有这个概念 + 信仰它 + 传播度与持续时间），无信者的存在本身制造了一个概念：**「没有神的位置」**。尼禄用制度让无信者活了下来并聚成一支部队（持续时间），当前皇帝在贫民 / 奴隶 / 行商间宣教（传播度）—— 条件正在凑齐。**新教信的「唯一神」就是空缺：祂从「不信任何神」这件事里诞生**，这是诸神最恐惧的一位新神，因为祂的权柄是**取消**。这一条也回答了「新教与诸神天然互斥」为什么是世界观事实而不只是规则。
- **神性 / 人性**：祂应当**完全没有人性** —— 却是被人性（尼禄的集权欲）催生的。这个矛盾留给剧情。
- **赐福的样子**：**无之物**道具族 —— **不是加，是减**：「空袖」= 对手的下一件出手的武器这一次不生效（`remove_status` 的武器版，**新**效果 `cancel_next_fire`）；「静默符」= 敌人的 buff 规则不触发 N 秒；「空格」= 一件 0 格的道具（占位但不占格，编译时算一件 —— 给繁多族的计数、给套装的计数都算），这是「缺席也是一种在场」的机制表达。种族天赋：无信者（不受任何信仰道具的休眠影响 —— 所有信仰道具都是凡物：没有加成也没有休眠）。
- **信力行为**：**不做** —— 事件里选「离开」类选项（`event_choice` 加 `tag: leave`，数据够）；**空手** —— 打赢却一件不拿（**新** deed `loot_untouched`）。
- **在一局里**：**祂克一切信仰道具**：信空缺的玩家身边，敌人的信仰加成（081 的 `faith_tiers`）不生效。这是新教对抗诸神的机制表达。事件：「无名的祭坛」—— 什么都不献，什么都不拿，走。
- **克制**：克所有赐福之物；被凡物（不归信仰的）克 —— 空缺对没有信仰的东西没办法。
- **现有构件**：`event_choice` 够；其余是新的，而且是**「取消」类**效果 —— 效果树里目前只有 `cancel` 一个取消型，要扩。

### 没选的，写明为什么

| 概念 | 不选的理由 |
|---|---|
| 光 / 暗 | 光是太阳的绑定物，暗是光的缺席 —— 都被太阳与火之神与空缺之神覆盖了 |
| 时间 | 恒常（周期）已经是时间的一面；「时长」在 buff 上作者定为例外，别让一位神围着它转 |
| 生长 / 生命 | 在这个世界里生命是神造的**物**，不是概念；「回复」已经分散在口粮、休息点、腐朽（消化）上 |
| 死亡 / 终结 | 战败后果是六种（069），不是一位神；边界之神已经管「尽头」 |
| 机运 / 偶然 | 随机是引擎的事；一位「掌管随机」的神会让玩家觉得掉率被剧情操纵 |
| 速度 / 热 | 与元素之神的「移动」「释放」重叠；写成元素残留 |
| 谎言、秩序、律法、美 | 人类活动出身（作者定：还没有谎言之神） |

## 三、这些概念能做成的玩法

按「用今天的构件就能做」到「要加系统」排序。每一条写清楚它接在哪。

### 3.1 直接能做的（数据 + 一两条构件）

1. **每族一个道具族 + 一位神的信仰文件。** `data/authoring/faiths/<id>.json`（`god`、`thresholds`、`deeds`）+ 三到五件带 `faith` / `faith:<id>` 标签的道具，每件两阶 `faith_bonuses`。**回响**族一行新代码都不用：`on_item_fired`、`reflect_damage`、`charge` 都在等人用。
2. **概念的克制，写成 `faith_bonuses` 的条件。** 现在的阶只看信力；加一个 `against`（对手的信仰标签）就能写「回响之物对暴力之神的信徒反伤翻倍」—— 编译器已经有对手的信息（敌人只信一个神，081）。这是「诸神争端体现为造物之间的厮杀」最直接的表达。
3. **祭坛按神分。** 现有祭坛事件的「献上」选项标了 `offering`；给每位神一个祭坛事件（`events_by_type.event` 里加），选项条件用 `has_item.tag = faith:<id>`。腐朽的祭坛做「重掷」，边界的做「提前看下一环」，空缺的做「什么都不做」。
4. **新的信力行为。** `FaithDeed` 是注册表构件，一条 deed 是一个 20 行的脚本 + 一行接线：`carry_weight` / `abandon_item` / `craft_done` / `eroded` / `idle_battle` / `repeat_node_type` / `stacks_reached` / `loot_untouched` / `extracted`。**建议先做 `abandon_item`、`craft_done`、`extracted` 三条**：前两条把 084 / 085 已有的机制（地上消失、合成）变成有意义的选择，第三条给「信力继承」一个落点。

### 3.2 要加一个属性源：**按布局算的属性**

重量（`armor_per_cell`）、繁多（`count_tag`）、边界（`on_edge`）三族要的是同一件事：**编译期看棋盘布局给属性**。现在的编译器已经看邻接（插槽配对），看「占几格 / 在不在边缘 / 包里有几件某标签」是同一层的事，加一个 `LayoutMod` 构件（`stat`、`per`：`cell` / `tag:<x>` / `edge`），挂在 `ItemDef.faith_bonuses[].layout_mods` 上。做一次，三族都有了 —— 而且它让**背包整理本身**成为信仰的表达：信重量的玩家把包塞满大件，信繁多的塞满小件，信边界的贴边放。**这是这份清单里最值得做的一条**，因为它把「背包搜打撤」的名字里第一个字和神话接上了。

### 3.3 本局的天象：诸神争端的现状（worldview 第六节第 3 问）

作者问过「诸神还在争吗，会不会影响一局」。答案可以是：**每一局开局掷一位「今日占上风的神」**，做成一条 `RunBuffDef`（局内 buff 已经是构件）：那一族的赐福之物 +1 阶、那一族的敌人多出现（敌人池按 `faith` 标签加权，`EnemyPool` 已经有权重）、那位神的祭坛必出一次。开局屏 / intro 事件里说一句「今夜山很沉」（重量）「霜下来了」（寒冷）。神性的神不偏心，所以天象是**轮转**不是偏爱 —— 和「诸神按秩序分配资源」一致。这一条不新增系统，只是把三个已有的权重接到一个开局掷的结果上。

### 3.4 信力的继承与「亲缘」

作者定切换信仰将来可以继承信力（还没做）。有了概念的族谱，继承就有了规则：**族内全继承，克制关系半继承，其余不继承** —— 从暴力换到重量（兄弟）一分不少，从火换到腐朽（火克腐朽）折半，从战争换到空缺归零。这让「先信谁、再信谁」成为路线规划，而且规则来自世界观而不是数值表。实现是 `FaithPower` 切换时查一张 `faith_kinship.json`（谁和谁是一族、谁克谁），十几行。

### 3.5 腐朽之神与侵蚀：让侵蚀有一张脸

侵蚀（075）现在是无名的推进。把它写成腐朽之神：地图上侵蚀线的文字、侵蚀效果的日志、被侵蚀时的事件（「腐朽的低语」：献一件道具让侵蚀这一层跳过你 —— 现有 `erosion` 效果接一个事件后果 `skip_erosion`），以及**信腐朽之神反而从侵蚀里得信力**。这不改侵蚀的机制，只给它世界观与一个反向的玩家选择。

### 3.6 造神：局外成长的骨架（8-5 的候选）

作者定「人类为概念造神」是新神诞生的规则。这直接是一个**局外系统**：玩家跨局的行为累计成「传播度」（每局结算把 `FaithPower` 的池子按比例进 meta），某个还没有神的概念（第二节里作者没选的那些也能放进来当「未诞生的概念」）累计到阈值 → **一位新神诞生，一个新的信仰文件解锁**。这是仓库之外第二条局外成长线，而且完全由玩法驱动：玩家用自己的打法「信」出了一位神。空缺之神的诞生可以做成第一个例子 —— 玩家在教程之后第一次「一件不拿」时，日志里出现一句没有来源的话。

### 3.7 要新战斗形态的，先不做

繁多族的「群敌」（一个敌人是三个小棋盘）和空缺族的「取消下一次出手」都要碰战斗内核（1v1 与效果树的取消型）。写在这里是为了让作者知道这两族的上限在哪，demo 阶段用替代方案（三把同样的小武器；`remove_status` 削 buff）。

## 五、要作者拍板的

1. **七个概念要哪几个**：重量、腐朽、寒冷、回响、繁多、边界、空缺。每个「要 / 不要 / 改名 / 改概念」一句。
2. **腐朽之神是不是诅咒之地的主人**（侵蚀 = 祂在消化神陨的残留）。这一条会写进 worldview 第一节第 8 点旁边。
3. **新教的唯一神是不是空缺**。是 → 第六节第 5 问关掉；不是 → 空缺之神仍可作为「无信者将来的专属体系」（081 留着的那条）。
4. **神的名字**：现在都是「X 之神」。要不要像皇帝那样给拉丁名 / 古王国露西卡语名？我可以拟，作者挑。
5. **元素之神吞并了哪些权柄**（第六节第 1 问）：清单里的概念可以反过来用 —— 祂吞的是「热」（所以寒冷之神幸存而热没有独立的神）、「光」（所以没有光之神，太阳神只剩周期与火）。这样两个「为什么没有 X 之神」的问题有了同一个答案。
