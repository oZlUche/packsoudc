## 数据与内容管线

`data/authoring/<kind>/*.json`（人写，进 git）→ `tools/import_content.gd` → `data/<kind>/*.tres`（引擎读，也进 git）。
种类与导入顺序：`buffs → sets → run_buffs → faiths → items → recipes → loadouts → characters → difficulties → events → enemies → enemy_pools → hunters → drop_rules → node_rules → economy_rules → meta_rules → chapters`（后者按 id 引用前者）。
`tools/normalize_content.gd` 把作者数据重写成导出器的格式（仓库里的 JSON 是往返不动点，测试逐字节比）。

现有内容：22 件道具（三个流派标签 `burst` / `rapid` / `bleed`）、3 套开局装备（标准 / 拾荒者 / 打手；标准也是仓库空的第一套）、3 个角色（作者定，082：安德烈乌斯 = 躲避 + 免罚一败；布鲁图斯 = 坚韧；马库斯 = 突击；数占位）、6 个信仰（各有攒信力的行为与阈值）、2 档难度（普通、进阶 1 占位：侵蚀空壳 + 一个追猎者 + 体力上限 -1）、2 种猎手（追猎者、守路人，占位，指定专属池 `hunters`、按段位定档）、6 种敌人、1 个敌人池、
掉落 / 节点 / 经济 / 局外规则各 1 份、4 个测试用的 buff（坚韧 / 幸运 / 被盯上了 / 虚弱）、6 个占位事件（搜索点默认、上锁的箱子、陌生人、熟面孔、歇脚处、动静）、章节 3 份（序章：预设的一条路；序章二：分岔的预设图 + 十四个教程事件、七件新道具、四个针对性敌人、一条配方；第一章：环形图，序章二通关解锁）、手绘地图 2 份。
**数值全是占位**（见下）。

## 沙盒与工具

**主场景是正式游戏** `ui/game/game.tscn`：主菜单（新的一局 / 继续上次 / 仓库与战绩 / 设置 / 开发工具）→ 开局（挑章、挑角色、从仓库往初始包里拖、种子）→ 地图（B 开背包、走出发生过事的点前提醒暂存区、撤离点上撤离、存档并回主菜单）
⇄ 叠层（战斗回放、战利品、搜索、商店、事件、休息）→ 结算 → 仓库与战绩。F1 回启动选择器。
启动选择器（开发期入口）：正式游戏、背包沙盒、战斗沙盒、道具编辑器、事件编辑器（写文字、导入配图、拼选项、挂进节点规则）、地图编辑器（随机生成或手绘，改完存回章节）。
命令行：`bash tools/test.sh`（全套测试，先 `--import` 重建类缓存）、`import_content`、`normalize_content`、`check_scripts`、`map_stats`、
`capture_scene`（截图；`DEMO_SCREEN=setup / map / bag / prebattle / battle / loot / search / result / meta` 把正式游戏推到那一屏）。
