# 197 讨论稿：主菜单重做（背景、按钮排布）与游戏标题方案

> 2026-10-18 深夜，架构设计。作者 21:43：「头脑风暴一下现在的游戏主菜单，太简陋了，既要一个背景图，也要各种按钮合理的排布（放在中间没有美感，那是demo时期的权宜举措）。然后游戏标题其实也可以想一想，《背包搜打撤》只是我最初用来形容特点的代称，生成几个方案，明早我来看」。
> 这是**讨论稿**：§2 三个排布方向、§3 标题方案，各带推荐；作者圈定后再写落地报告（美术出样 → 执行）。已请「UI替换美术」按 §2 画三张概念图，明早一起看。

## 1. 现状

`ui/game/main_menu.gd`（60 行）：整块石板（`_slab_screen`），正中一列 420 宽：马善政 40 号「背包搜打撤」、一行六个数的战绩（`menu.stats`）、备份 / 对账提示、分隔线、按钮自上而下 —— 继续（有存档）、读取存档（有任何存档）、新的游戏、仓库与战绩、百科、设置、语言：中文（点击切换 English）、分隔线、开发工具（开发版）、退出。十样东西挤在屏心一列，字号 18 / 14 / 13 三档，没有主次之分，没有画面。启动屏（`ui/boot.gd`）先画一遍游戏名再切过来。

已有能借的美术：开局三页的整屏画（`assets/ui/setup/bg_hall` 等，1920 × 1200 cover + json tone）、基地的木牌按钮 `assets/ui/home/btn_wood*`（九宫格 96 × 48，常态 / 悬停 / 按下 / 禁用 / 主档）、196 的夜晚营地切图（路标 `sign`、篝火、帐篷）。

## 2. 排布：三个方向

共同的底：整屏一幅画（`GameScreen._painted_screen`，和开局屏同一套），**不要石板**；标题用马善政；按钮分三档 —— 主档（继续、新的游戏）大而亮，次档（读取存档、仓库与战绩、百科、设置）中，末档（语言、开发工具、退出）小字贴边。战绩那一行从菜单拿掉，搬进「仓库与战绩」的家页（它本来就在那）；备份 / 对账提示改成右下角一行小字，没有就不占位。

### 甲 营地路牌柱（推荐）

- **画面**：诅咒之地边缘的夜晚营地 —— 就是 196 的那片地，但往右看：近处一根木路牌柱，远处是营火、几顶帐篷与军团的篝火点点，再远是黑黢黢的旧王国废墟轮廓与月牙。玩家每局从这里走进去，菜单就是「出发前」。
- **标题**：左上 1/3 处，马善政 72 号两行或一行，底下一道黄铜细线；英文名小字在线下。
- **按钮 = 路牌柱上的木牌**：柱子在左 1/3，牌子从上到下挂，像 196 的路标那样钉着。主档两块大牌（继续 / 新的游戏，`btn_wood_primary` 的琥珀木），次档四块普通木牌（`btn_wood`），牌子略有倾斜与错位（±3°、±8 px），悬停微微晃一下、亮一道边（已有 `btn_wood_hover`）。末档三项是柱脚下一行小字，不做牌。
- **为什么推荐**：和 196 同一个世界、同一批素材，美术成本最低；左重右轻的构图把中间留给画；木牌天然分主次（大小、木色）。
- **风险**：牌子多了像杂货店 —— 所以牌只挂六块；「继续」不显示时位置空出来会不整齐 → 没有「继续」时主牌只剩一块、往上收拢，不留空钉。

### 乙 边营登记处（军团视角）

- **画面**：帝国军队在诅咒影响范围边缘的驻地（世界观第二节），白天或黄昏：一张登记桌，桌后是军团的旗与栅门，门外是诅咒之地。
- **标题**：横幅挂在栅门上方（画里），马善政压在布上。
- **按钮**：桌上一本翻开的登记册占右下 1/3，菜单项是册页上的条目（朱雀仿宋 24 号，前面一枚蜡印 / 勾），悬停条目下划一道墨线。主档用红蜡印、次档用墨字、末档是页脚小字。
- **好处**：有「身份 / 立场」的味道（奴隶、自由民、军团士兵都在这里登记），以后开局屏的角色身份能接上。
- **代价**：要一张全新的大画，与现有基地（木屋）、营地（夜）第三种场景；文字按钮没有木牌直观。

### 丙 地图桌俯视

- **画面**：俯视一张桌面 —— 和地图屏的桌面木纹同款（192 的 `desk` 瓷砖）：摊开的羊皮纸地图占画面中部偏右，桌边放着背包、油灯、匕首、骨骰子（都是游戏里有的道具）。
- **标题**：烙在羊皮纸地图上方（马善政 + 烙痕）。
- **按钮**：主档两项是地图上的两枚蜡封（继续 = 已拆封的信，新的游戏 = 未拆封），次档是桌边物件（背包 = 仓库与战绩、书 = 百科、油灯 = 设置、骰子 = 语言），悬停时物件亮起并出一块小纸签写名字（170 悬浮窗）。末档退出 / 开发工具是桌角小字。
- **好处**：最有「物件即按钮」的趣味，和 196 的营地一脉。
- **代价**：八个物件要玩家猜用途（首次打开发现成本高）；美术最贵；窗口比例变了物件会挤。

**推荐甲**；若作者想要更有故事感，乙；丙适合作为日后「基地」屏的方向而不是主菜单。

### 共同的细节

- 分辩率：画按 1920 × 1200 cover；按钮区锚在左边、随高度等比缩放；最窄 1280 × 720 时木牌缩到 0.75。
- 键位不变：Esc 退出前确认、Enter = 继续 / 新的游戏（第一块牌）。
- 「语言」按钮：现在一行长字（「语言：中文（点击切换 English）」），改成「中 / EN」两个字的小开关，放末档。
- 启动屏 `ui/boot.gd`：画同一张背景图的压暗版 + 标题，让启动到菜单是一次渐亮，不换画面。

## 3. 标题方案

《背包搜打撤》是「背包 + 搜打撤（搜刮、打、撤离）」的功能描述，当代称准确，当名字缺少世界与情绪。标题要做到三件事：说出**这个世界**（被神抛弃的魔法王国旧地）、说出**玩法的核心**（背着一个包进去、再活着带出来）、**四字以内**好写成马善政的大字。下面按三个路子给，每条附英文与一句理由，最后是推荐。

**路子一：说这片地（情绪、世界）**

| 中文 | 英文 | 理由 / 顾虑 |
| --- | --- | --- |
| 《神弃之地》 | *Godforsaken* | 世界观里「诅咒之地 = 被神抛弃的土地」的直译；四字、有重量、马善政写出来好看。顾虑：同名作品不少，辨识度靠副标题补 |
| 《弃土》 | *The Forsaken Ground* | 两个字更凶、更冷。顾虑：太短，搜索不友好 |
| 《诅咒边境》 | *The Cursed Frontier* | 点出「帝国边境旁」，有「去边境讨生活」的味道。顾虑：偏泛 |

**路子二：说那个包（玩法、身份）**

| 中文 | 英文 | 理由 / 顾虑 |
| --- | --- | --- |
| 《负重者》 | *The Burdened* | 背包、负重、拾荒、奴隶与雇佣的探索者 —— 全在「负重」两个字里；也是游戏里真有的机制（129 负重）。三字，写成大字有力。顾虑：略沉 |
| 《囊中物》 | *Bag and Baggage* | 成语「囊中之物」反用：你带出来的才是你的；也暗指包里的空间争夺（棋盘）。轻巧、有记忆点。顾虑：不够「险」 |
| 《行囊》 | *Pack* | 最干净。顾虑：太素，像工具软件 |

**路子三：合起来（世界 + 包）**

| 中文 | 英文 | 理由 / 顾虑 |
| --- | --- | --- |
| 《弃土行囊》 | *Satchel of the Forsaken* | 两边都有，四字对仗，念起来顺。顾虑：「行囊」文气，和「搜打撤」的狠劲差一点 |
| 《神弃拾荒》 | *Scavengers of the Forsaken* | 「拾荒」就是搜打撤里的搜；比「探索者」低一截、更像奴隶出身。顾虑：五个字里两个「神 / 荒」都重 |
| 《背囊远征》 | *Pack Expedition* | 直白。顾虑：没有世界感，和原名差别不大 |

**副标题**：不管正名选哪个，建议保留「背包搜打撤」作**副标题 / 类型说明**（商店页、启动屏小字）：它是最准确的功能描述，玩家一眼知道这是什么游戏；正名负责情绪与世界。写法如 **《神弃之地：背包搜打撤》**、**《负重者 —— 背包搜打撤》**。

**推荐**：正名 **《神弃之地》**（世界第一、四字、好写大字），副标题「背包搜打撤」，英文 *Godforsaken: Pack, Loot, Extract*。备选 **《负重者》**（更独特、更贴身份，英文 *The Burdened* 也漂亮）。两者都能和 §2 甲的夜晚营地画面站在一起：标题是地名或人名，画面就是那片地与要进去的人。

改名牵涉：`project.godot` 的 `config/name`、`export_presets.cfg` 的 `product_name`、`ui/boot.gd` 与主菜单的游戏名、字体字集（马善政子集要补标题的字，168 的 `tools/subset_fonts.sh`）、英文名进 `UiText`、存档路径 **不改**（`user://` 目录名跟 `config/name` 走，改名会换目录 —— 落地时要把 `application/config/custom_user_dir_name` 钉成现在的名字，否则老存档找不到）。
