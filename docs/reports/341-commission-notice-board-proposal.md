# 341 委托改成告示栏：方案（等作者和审阅确认）

> 日期：2026-11-20。作者 2026-11-20 14:27：看过委托页截图后提出「改成一张告示栏，上面贴着各种不同委托，会定期刷新（每局回来空位有概率刷新，每个委托接取前有时限，接取后一直存在且不会被刷走），不同任务可以提升不同阵营的声望，并获得道具和/或金钱奖励。从现有的机制出发，改编成我提出的方向，生成一份方案」。
> 基线：main v6.62。现有委托做到 W1（报告 336、337，v6.57–v6.60）。原方案见 [docs/plans/2026-11-19-factions-and-commissions.md](../plans/2026-11-19-factions-and-commissions.md)，规格见[报告 335](335-factions-commissions-exec-spec.md)。
> 这份只是方案，没有改代码。文中的数都是候选，作者定了再动手。

## 一、一句话

基地「委托」页从「按阵营分栏的固定任务簿」改成**一块告示栏**：栏上有几个钉位，钉着来自不同阵营的委托纸条；没接的纸条过几局会被撤下，空出来的钉位每局回营按概率补上新纸条；接下的纸条挪到「手头」一栏，一直留到办完或玩家自己放弃，不会被刷走。办成给对应阵营声望，再给金币和 / 或道具。

## 二、和现在比，变的是什么

| | 现在（W1） | 告示栏 |
|---|---|---|
| 任务从哪来 | 每个阵营一串固定的具名委托，全列在阵营页里 | 从委托池里抽，钉在告示栏上；栏位有限，不全列 |
| 怎么挑 | 先点阵营，再看这一方的卡 | 一眼看全栏，纸条上印着是哪一方的 |
| 时限 | 没有 | 没接的纸条有「还剩几局」，到期撤下；接下后没有时限 |
| 刷新 | 不刷新 | 每局回营，空钉位按概率补新的 |
| 同时接几份 | 2 份，全部带进局 | 手头最多 3 份（候选），都带进局 |
| 声望 | 只给委托所属那一方 | 同左；少数纸条给两方（主方多、副方少） |
| 报酬 | 金币 + 声望 | 声望 + 金币和 / 或道具，纸条上写明 |
| 声望有什么用 | 开放下一份具名委托 | 决定栏上会出现哪些等级的纸条、报酬档次，以及阵营服务（沿用原方案） |

不变的：一局里怎么做（查验、交信、打造……）、现场的事败退也算、带回的东西要撤离或托付才算、委托物不能卖 / 献祭 / 赐福 / 合成、统一教程没完和试玩切片不显示、结算屏的「委托」段落、地图左上的小牌。

## 三、告示栏怎么运转

### 3.1 栏位与手头

- **告示栏 6 个钉位**（候选）。每个钉位要么空着，要么钉一张没接的纸条。
- **手头最多 3 份**（候选）。从栏上接下一张，纸条从钉位挪到手头，钉位空出来。
- 手头满了，栏上的纸条照样能看，「接下」灰着写「手头满了」。
- 手头的委托**全部带进每一局**（不再另外选哪两份带）。理由：告示栏本身已经限量，再多一道「选带哪几份」就重复了。要保留「出征前选带哪几份」见第八节问题 3。

### 3.2 时限（只管没接的）

- 每张纸条贴上时带一个时限，写成「还剩 N 局」，候选 **3 局**（高级纸条 2 局）。
- 每结算一局（撤离、败退都算），栏上每张没接的纸条减 1，到 0 就撤下，钉位空出来。
- **接下之后不再有时限**，也不会被刷走，直到办成或玩家按「放弃」。
- 放弃的纸条不回到栏上（也不扣声望，沿用「不罚绕开的人」的原则）。

### 3.3 刷新

- 每局回营结算时，先扣时限、撤下到期的，再给**每个空钉位独立掷一次**：候选 **50%** 补一张新纸条。
- **保底**：补完之后栏上没接的纸条少于 2 张，就补到 2 张。避免运气差时整块栏空着。
- 第一次打开告示栏（新档或旧档升上来）直接贴满 4 张，留 2 个空位给之后的刷新。
- 刷新只在「回营结算」时发生，跟局走，不跟现实时间走。同一局结算两次不会刷两次（沿用 `settled_runs` 去重）。
- 抽什么、补不补都用「存档种子 + 第几局」定死：读档重进不会刷出不同的结果，也没法靠读档反复刷。

### 3.4 抽什么

- 从**委托池**里按权重抽。池里每张委托有：属于哪一方、要几级声望才会出现、权重。
- 已经钉在栏上、已经在手头的不再抽。一次性的具名委托办成后不再出现；模板委托（见第四节）可以反复出现。
- **阵营轮转**：同一次刷新里，优先补栏上还没有的阵营，免得满栏都是同一方。
- 声望越高，越可能抽到这一方的高级纸条；陌生阶段只会出现入门级。

## 四、委托池：从现有内容改编

沿用现有的 `CommissionDef`（阶段、目标、在哪完成、报酬），加几项告示栏要用的字段。池里分两种：

### 4.1 具名委托（一次性）

原方案五方各 5 份、共 25 份，照旧写、照旧一次性。改的只是**入口**：不再常驻阵营页，而是够声望后有机会出现在告示栏上。

- 入门、调查、结案三级照旧，结案前置（要先办完同线的调查）照旧，用来决定它「能不能被抽到」。
- 具名委托权重高于模板，候选：同等条件下是模板的 3 倍，让故事线不会被模板淹没。
- 错过（到期撤下）的具名委托**会回到池里**，以后还能再贴出来；只有办成才算用掉。这样时限只是「这一张现在要不要」，不会让人永远错过一段故事。
- W1 的三份原型（两条回路、照抄也要做得出、无人署名的信）原样进池。

### 4.2 模板委托（可反复）

首批可重复委托采用第十一节的三类数量模板。下表保留为可扩展的任务动作清单，代送、打造等仍可用于具名委托。

原方案说的「三种可复用模板」扩成告示栏的主力，贴出时现掷参数（要什么、要几件、报酬多少）。只用现有机制能判定的目标：

| 模板 | 玩家做什么 | 在哪完成 | 判定靠什么（已有） | 主方 |
|---|---|---|---|---|
| 交料 | 从仓库交 N 件某类材料（布、木、矿……） | 营地当场 | 仓库实例 + 材料标签 | 军团 / 灰灯 |
| 带回 | 撤离时背出某类东西 N 件 | 要带回 | 结算的背出清单 | 协会 |
| 查验 | 在 N 处不同撤离点「查验」 | 局内现场 | W1 的查验（`CommissionModule`） | 军团 |
| 代送 | 带一封信 / 一包药，交给免费撤离点的接应员 | 局内现场 | W1 的交信 | 灰灯 |
| 清剿 | 打赢 N 场某类敌人（蛮兵、机械……） | 局内现场 | `battle_finished` 信号 + 敌人种类 | 军团 / 猎盟 |
| 搜查 | 在某类地点搜完 N 次 | 局内现场 | `search_closed` 信号 + 点的类型 | 协会 / 使团 |
| 打造 | 在铁匠铺照一张现在能打的配方打一次 | 营地当场 | W1 的打造记账 | 协会 |

- 模板的阵营标签只是主方；同一模板换个阵营，台词（委托人原话）换成那一方的口吻，候选每方每模板写 2–3 句。
- 模板不能把声望推过「熟面」（原方案的规矩：后两级要靠具名委托），避免刷模板一口气刷满。

## 五、报酬

- **声望**：入门 / 模板 +1，调查 +2，结案 +3（沿用原方案）。少数纸条写「主方 +2，副方 +1」，用来给跨阵营的事（例如灰灯托军团捎信）。
- **金币**：按「玩家为它多花了什么」定。营地当场的交料按那几件的卖价再加一成到两成，免得买来交单白赚；局内现场的按绕路步数和占的格子，对照同章节一次普通搜索的收入。
- **道具**：从「已知、能用的」里出，不出红武、不出独一的、不出封存的、不出委托物。三种出法，纸条上写明是哪种：
  - 指定一件（具名委托用，作者挑）；
  - 一包材料（按阵营：军团给工艺、协会给魔法、灰灯给自然……候选）；
  - 一件某稀有度的随机装备（模板用，按声望等级定档）。
- 每张纸条至少有声望 + 金币或道具其中一样；纸条上金币用金币图，不写「币」。
- 见识仍只从单局结算来，委托不发见识（沿用原方案）。

## 六、界面（占位先行，样张请 UI 设计出）

- 基地「委托」页签保留，页面换成**一块软木告示栏**：左大块是栏，6 个钉位，每张纸条是一张钉着的小纸片，纸色或印章表示阵营，右下角写「还剩 N 局」。
- 点一张纸条，旁边展开详情：委托人原话、做什么、在哪完成、报酬、「接下」。详情就是现在任务卡的五栏，挪到这里。
- 栏的右边（或下方）是**「手头」**一列，接下的纸条钉在这里，写进度；键是「放弃」。
- 栏顶是三方（以后五方）的**声望条**：阵营印章 + 几级 + 离下一级还差几点。原来左边那列阵营键去掉。
- 回营后栏上新贴的纸条角上标一个「新」，看过就消失。
- 局内小牌、结算屏段落不变。

## 八、请作者 / 审阅定的事

1. **数**：栏位 6、手头 3、没接的时限 3 局（高级 2 局）、空位刷新 50%、保底 2 张、首次贴 4 张。哪个要改？
2. **具名委托还要不要**：
   - A（推荐）：要。25 份具名照写，够声望后混进告示栏，错过会再出现；模板做日常。故事和刷新都有。
   - B：不要。全部是模板，阵营只靠台词区分。做得快，但阵营的故事线没了。
   - C：具名的不进告示栏，单独钉在栏顶一条「要事」位，常驻不刷新；告示栏只放模板。
3. **手头的全带进局，还是出征前选**：
   - A（推荐）：全带。少一步操作，手头上限就是限制。
   - B：出征前从手头选至多 2 份带进去，没选的这局不推进。
4. **到期撤下的具名委托**：A（推荐）回池里以后还能贴出来；B 错过就没了（更有「错过」的分量，但会让人卡在某一方升不上去）。
5. **跨阵营纸条**（一张给两方声望）要不要做；要的话首版做几张。
6. **道具报酬**三种出法（指定 / 一包材料 / 按档随机装备）够不够，阵营和材料的对应要不要按候选来。
7. 原方案里的「局内现场请求」（随机事件里的一步跑腿，不占手头）还要不要；告示栏之后它和告示栏的关系是：A（推荐）保留，现场请求做完只给钱和这一方 +1，不进告示栏；B 去掉，统一走告示栏。

## 十、审阅时可以重点看

- 刷新 + 时限 + 保底这一套，在「一局十几分钟」的节奏下会不会太快或太慢：按候选数，一张没接的纸条最多挂 3 局，6 个钉位平均每局补约 1–2 张。
- 手头 3 份全带进局，加上局内现场请求，一局里同时追的目标会不会太多。
- 模板的金币报酬会不会和卖东西、搜查抢收益，或被「营地买料 → 交料」套利。
- 时限只对没接的纸条生效，玩家会不会养成「看见就先接、手头占满」的习惯，导致栏上的时限形同虚设（缓解办法：手头上限 + 放弃不罚，接了不做的代价只是占位）。


## 十一、首批数量模板（2026-11-20 补充）

作者确定消灭敌人、提交物品、访问节点三类可批量生成的委托。每张纸条在贴出时抽出目标与要求数量，同一目标按数量划难度和报酬。以下数量、计价和机会筛选是首测建议。具名剧情沿用独立的阶段与结局。

| 模板 | 短单 | 常规单 | 长单 | 计数时机 |
|---|---|---|---|---|
| 消灭某类普通敌人 | 1～2 名 | 3～4 名 | 5～6 名 | 接取后实际击败合格敌人，每个被击败的敌人记一次 |
| 提交某种常见材料 | 1～2 件 | 3～5 件 | 6～8 件 | 营地确认交付、实际消耗合格实例时记数，允许分批 |
| 访问某类节点 | 1 处 | 2 处 | 3～4 处 | 实际抵达时记数，同局同节点只记一次，下一局的新节点可继续累计 |

“难度”在纸条上表示完成这份委托的工作量，地图进阶另行显示。每个目标可独立缩小范围，例如只有少量合理遭遇机会的敌人使用自己的数量表。首轮先投常见目标。案例：军团招募巡路者，消灭 4 名指定普通敌人属常规单；协会收集 7 件常见材料属长单；灰灯探望沿途营地，访问 2 处不同休息点属常规单。每张显示阵营、适用章节、数量、难度、报酬与计数条件。

**生成顺序。** 补空位时，从玩家已开放章节与阵营的合格目标中抽一个，按该目标的整数数量权重抽 N，再按区间查档。配置须覆盖每个可抽数量且每个数量只落入一档。统计地图上目标出现频率，剔除无来源目标，按期望局数限制稀少目标的 N。纸条实例冻结目标、N、档位、进度与奖励；同目标同数量同阵营的纸条避免同时上栏。候选不足时只贴合法份数。接下后允许跨局累计，未接倒计时与已接持久化沿用第三节。

**报酬计算。** 每种目标配置单份酬值 u（以金币衡量），每单预算取整为 N × u × 档系数，首轮短／常规／长分别试 1.00／1.05／1.10。击败与访问的 u 参考对应章节的额外风险或绕路成本；交付的 u 参考该物品正常出售价值。若允许多种价值悬殊的替代物，应拆成不同目标。预算按金币、合法道具或两者组合发放；混合奖励从同一预算扣除道具估值。例：试算 u=10 的目标，2／4／6 个分别落在三档时，预算约 20／42／66；示例只说明算法。校验同目标数量越多总报酬越高、跨档增幅可解释。用实际折扣后最低买价复核营地买入交单的净利，含材料包与装备可兑现价值。阵营声望沿用模板 +1、最多至熟面，达到上限时纸条显示实际增量；数量主要改变物质报酬。

**结算与验收。** 已完成的击败和抵达在败退后保留。同一战斗结果或抵达事件重播只记一次；交货预览排除锁定、唯一、任务占用物，分批交货前提示已交材料的放弃处理规则（建议已交不退）。提交物品不能用同一实例重复交给两单。对每个目标测数量区间两端、相邻档分界、跨局完成、接单前行为、重复进入、读档与满仓待领取。试玩按类型和数量记录完成所需局数、行动数、放弃率与可兑现报酬；若长单主要意味着反复刷同一目标，优先缩小数量范围。
