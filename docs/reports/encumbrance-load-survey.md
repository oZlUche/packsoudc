# 负重测算：每局撤离时背了多重（给负重三档门槛定数用）

- 日期：2026-10-12
- 性质：测试 · 统计报告（只跑模拟，不改游戏代码；结论交架构设计写方案）
- 作者原话：「最高级的负重惩罚应该在200%以后才出现，现在太容易达成了，对此你可以开一个测试用的线程来看看每局平均负重（在武器不大于三且配有至少两件防御性道具，并带有不少于一定数量的珍贵材料或道具时)」
- 脚本：`tools/sim/encumbrance_sim.gd`（真实 `GameFlow` / `RunState` 跑自由模式），原始数据 469 局。

## 一、结论

1. **现行规则下最高档几乎人人都到**：撤离时 91% 的局在「寸步难行」（> 上限 × 1.5，含包），符合画像的局 96%；整局有六成多的步数是在三级里走的。负重到上限的 1.5 倍只要背包装满就会发生，不需要刻意贪重。
2. **一满包的重量大约是上限的 1.9 倍（含包）/ 1.6 倍（不含包）**。机器人几乎每局都把棋盘塞满（撤离时平均只剩 1～2 格空），所以负重的天花板是棋盘格数，不是玩家的取舍。包本身平均占 15.7 重（约 5.7 个包），去掉它就能把倍数整体压低约 0.3。
3. **画像局（武器 1～3 件、防御道具 ≥ 2 件、珍贵物品 ≥ 3 件）**：撤离时的负重 / 上限
   - 含包（现行）：平均 **2.06**，中位 2.05，P90 2.48
   - 不含包（161 版）：平均 **1.74**，中位 1.73，P90 2.12
   - 珍贵 ≥ 6 件这一档几乎一样（平均 2.04 / 1.71）：珍贵物品中位数每局有 10 件，「≥ 3」「≥ 6」都不是卡人的条件。真正卡人的是「防御道具 ≥ 2」（只有约 18% 的局满足），而盾很重，所以画像局比全体重约 0.15～0.2 倍。
4. **按 161 的口径（包不算重，门槛 1.0 / 1.5 / 2.0）**：最高档从 91% 降到全体 **10%**、画像局 **19%**。也就是说作者「200% 以后才出现」的要求在包不算重之后基本成立：只有塞满重货（盾、金属武器、锭和矿）才会过 2 倍。
5. 若希望最高档更少见（画像局 ≤ 10%），门槛要再往外推到约 **2.2**（见第三节的 1.2 / 1.6 / 2.2）。

## 二、怎么测的

- **地图**：自由模式，小型和中型两种规模；**角色**：安德烈乌斯（上限 40）、马库斯（48）、布鲁图斯（56），开局都用「标准」初始包；没有局外科技（「扛重」不加上限）。每个角色 × 规模 40 个种子 × 两种拿法 = 480 局，469 局撤离成功（其余 11 局没撤出来，不计入）。
- **路线**：从出生点起每次去最近的没去过的有东西的点（搜索 / 战斗 / 精英 / 宝箱 / 事件 / 随机），倒计时剩的步数只够走到最近的开着的撤离点时去撤离（按当时的行动点倍率算，也就是三级时走一步算两步）。平均一局走 25 步。
- **战斗**：一律按赢了算（秒杀），只看搜刮，掉落、珍宝照常掷。搜索点搜满，事件随机选能选的。商店、休息、保险箱、神坛直接走。
- **拿东西**：机器人**不看负重**，按「价值 / 格」从高到低往棋盘放，有空包就拿包；放不下时把棋盘上更不值钱的一两件扔到地上换。约束：武器至多 3 件；防御道具（盾 / 防具标签）不足 2 件时优先拿，且不会被换到少于 2 件。
  - 「贪」= 放得下就拿；「挑」= 白色（稀有度 0）的不拿（包、缺的防御道具除外）。两种拿法结果几乎一样（平均 1.90 对 1.91），因为两种都会把棋盘塞满，只是塞的东西不同。下文合并统计。
- **珍贵**：稀有度 ≥ 2（蓝及以上）、且不是武器 / 盾 / 防具的道具（材料、珍宝、其他）。
- **负重 / 上限**：撤离那一刻的棋盘。「含包」= 现行规则（包本身算重）；「不含包」= 161 的口径（只把包的重量减掉，其余道具相同）。

## 四、口径与局限

- 机器人永远把包塞满，代表的是「捡到什么都想带走」的玩家，是负重的**上沿**；真实玩家会在撤离前扔掉一些、把东西放进保险箱（保险箱不算重，模拟里没用）、或者为了不翻倍走路少拿。
- 没有科技「扛重」（+6 / +12 / +20），点满之后上限多 20，倍数会明显下降（安德烈乌斯 40 → 60）。
- 战斗必赢，所以精英、遭遇的掉落都拿到了；商店不买东西。
- 「防御道具」按盾 / 防具标签算；开局的贴身内甲不带防具标签，所以不算。

## 五、给架构设计的建议

- **包不算重**是这次最有效的一刀（最高档 91% → 10%），建议保留。
- 门槛：作者要的是「最高档在 200% 以后」，**1.0 / 1.5 / 2.0** 已经满足（画像局 19% 到顶）。如果还嫌多，取 **1.2 / 1.6 / 2.2**（画像局 7%、全体 4%），同时一档不再是「刚出门就吃力」（全体轻装从 4% 升到 10%）。
- 一档的门槛 1.0 下几乎所有局（96%）撤离时都至少「吃力」，若希望一档也有一点「装得克制就不罚」的空间，把一档提到 1.2～1.25。
