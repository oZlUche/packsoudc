# 351 地图协会与材料倾向（B3 第一步，按报告 342）

> 日期：2026-11-20。按[报告 342](342-base-nav-reputation-map-growers-exec-spec.md) 第三节做 B3 的前一半；河滩垦户社和苗圃是 B3 第二步。

## 一、地图协会什么时候来

教程走完后，第一次**有实际探索**的正式出征结算时（走出过起点，胜败都算；教程章、没走出起点的空跑不算），地图协会来营地，委托页多一方，首单自动接上。老档也一样：更新后第一次正式探索结算时来。

| 剧情 | 做法 | 声望 |
|---|---|---|
| 《把路画回来》 | 营地【办理】一次（登记这一趟到过的地形）；办成开**材料倾向** | +10 |
| 《两条回路》 | 两处不同的撤离点各查验一次（从后勤部队挪过来，原话照旧） | +5 |
| 《核实矿脉》 | 走到一处矿点 | +5 |
| 《提交路标》（许可单） | 走过五处地方（要前两份都办完） | +5 |

- 到 25 并办完许可单后，告示栏开始贴地图协会的纸条：到访搜索点、交石料、打赢普通的仗。
- 名字、委托人、一句说明是初稿，委托人原话（除《两条回路》）留空。
- 老档里办成过《两条回路》的，照旧记办成，不重发奖。

## 二、材料倾向

- 出征第三页（地图）之后多一页「本次准备」，列 无倾向 / 矿物 / 草木 / 工艺 / 兽材 / 晶石，默认无倾向，不选也能出发。这张图普通搜索里没有某一类、或者材料全是那一类时，那一项压灰，悬浮窗写原因。倾向没开时这一页整页跳过，流程和以前一样。
- 只在**普通搜索点**、只在材料里重分：目标那一类 ×1.5，然后按稀有度逐档缩放回原来的总量。材料总出现率、每档稀有度的份额、搜出几件都不变。材料点、敌人、首领保底、宝箱、商店、事件奖励不受影响。
- 出发后定到本局结束，跟着这一局存档（局内存档升到 v7，老档读进来是无倾向）。
- 「晶石」方向认魔晶石、碎晶和四种新晶石（报告 343 第七节第 4 条）。
- 页面是占位排版，样张请 UI设计出。有第四页时出发不播地图化开的转场（转场要从第三页的预览起）。

## 三、倍率的配对试验

工具：`tools/material_bias_trial.gd`。每章种子 1..60，每个搜索点都按正式会话搜满、不遭遇，是地图机会的上限，不是玩家真拿得到的量。全表在[附录](351-cartographers-material-bias/trial-60.md)。每张图的材料总数、稀有度分布在各倍率下都不变（差在 1% 以内）。

**自由模式**（普通搜索点多）：

| 方向 | 每图目标材料（无 → ×1.25 → ×1.5） | 其中普通搜索点 |
|---|---|---|
| 矿物 | 12.2 → 12.6 → 13.1 | 2.3 → 2.8 → 3.2 |
| 草木 | 6.8 → 7.2 → 7.7 | 3.2 → 3.6 → 4.1 |
| 工艺 | 14.9 → 15.9 → 16.5 | 8.1 → 9.1 → 9.7 |
| 兽材 | 5.2 → 5.9 → 6.1 | 2.8 → 3.5 → 3.7 |
| 晶石 | 22.6 → 23.1 → 23.7 | 3.4 → 3.9 → 4.5 |

**沙漏章**：普通搜索点里的目标材料每图只有 0.2～1.2 件，×1.5 只多 0.05～0.4 件，几乎感觉不到；矿物、晶石 95% 以上来自材料点。

结论：自由模式 ×1.5 让普通搜索点里的目标材料多四成左右，整张图多 1～1.6 件，能感觉到但不会盖过材料点；沙漏章基本没作用。

## 四、请作者定

1. **倍率**：建议定 ×1.5（现在就是）。×1.25 在自由模式只多半件，偏弱。
2. **沙漏章**：要么接受「沙漏章倾向几乎没用」，要么沙漏章的倾向改成同时作用于材料点里「从普通池抽」的那 25%。我建议先接受，等 50 档「显示受益分区」时一起看。
3. 四份剧情的名字和一句说明（第一节）。
