## 〇 一句话

图标用字标里已经有的那只皮背包（197 定稿字标 `背包搜打撤` 里「背」字下半那只）做主体，单独立起来当徽记；推荐在包盖上缝出一格一格的针脚，把「格子背包」这个玩法一眼带出来。美术出三个方向的样，作者选一个。

## 一、现状

- 仓库根目录的 `icon.svg` 还是 Godot 自带的蓝色机器人；`project.godot` 的 `config/icon` 指着它，所以窗口标题栏、任务栏、Alt-Tab 里现在都是 Godot 头像。
- `export_presets.cfg` 两个预设（玩家版 / 开发版）的 `application/icon` 都是空的，导出的 `packsoudc.exe` 用的是 Godot 模板自带的图标；`application/file_description` 也空着。
- 字标已定稿（197，作者 2026-10-19 10:01）：`assets/ui/menu/title.png`，「背包」皮革、「搜打撤」黄铜，「背」字的下半（月）画成一只带铜扣的皮背包，「打」字里藏一把剑。启动屏也用它（`ui/boot.gd`，`title_boot.png`）。
- 局内的背包道具（`assets/items/bag_leather.png`）是方形皮包，一道缝线、顶上一枚铜扣 —— 和字标里那只是同一个物件。

## 二、图标要满足什么

1. **三个尺寸都要认得出**：256（商店页、大图标）、48 / 32（桌面、任务栏）、16（标题栏、文件列表）。16 像素只剩轮廓加一两块颜色，所以主体只能是**一个物件**，不能靠细节。
2. **不带字**。中英文共用一张；字到 32 像素就糊了（这也是不推荐纯字型方案的原因）。
3. **按美术规范走**（`art/style-guide.md` A 墨线平涂）：墨线勾形、平涂、不渐变不发光不投影，光从左上来；颜色从色表取 —— 皮 `#A8743F` / 亮面 `#C99863`、深皮 `#5B3B25`、黄铜 `#C9A54C` / `#E6C878`、墨 `#2E2219`。
4. **背景自己带**。桌面和任务栏底色不定，图标得有自己的地：要么透明底、物件本身够实（推荐），要么垫一块盘（圆 / 盾 / 圆角方）。盘到 16 像素会吃掉物件，所以小尺寸即使有盘也要去掉。
5. **和字标一家人**：从字标里取物件、取材质，玩家在启动屏看到字标、在任务栏看到图标，认得是同一个游戏。

## 三、头脑风暴（七个方向）

| | 方向 | 读出来是什么 | 16 像素 | 和字标的关系 | 风险 |
|---|---|---|---|---|---|
| 甲 | **字标里的那只皮背包** 单独立起来：方形皮包、包盖、顶上铜扣、一圈针脚 | 「背包」 | 能认（方 + 扣） | 直接取自「背」字下半 | 只说了「背包」，没说「搜打撤」 |
| 乙 | **背包 + 剑**：背包正面，「打」字里那把剑从包后斜出 | 「背包 + 打」 | 剑变成一根斜线，勉强 | 两个物件都来自字标 | 两个主体，小尺寸抢 |
| 丙 | **格子背包**：皮包正面是一块三乘三的格子，里面卡着一件东西（一把刀或一瓶药） | 「格子收纳」= 本作玩法 | 格子到 16 像素变成网纹，仍看得出是「格子」 | 包是字标的，格子是棋盘的 | 画成九宫格会像日历 / 计算器 |
| 丁 | **撤离旗**：231 那面桂冠战旗，旗面一个包 | 「撤 / 胜利」 | 旗能认，包认不出 | 来自战斗继续键 | 读不出「背包」 |
| 戊 | **「包」字印章**：一枚黄铜方印，印文就是字标的「包」 | 「包」 | 字糊掉 | 直接取字 | 英文市场读不出；违反第二条 |
| 己 | **军团鹰抓背包**：帝国鹰旗（美术规范 Imperial 板①）爪下抓一只包 | 「帝国 + 包」 | 鹰糊成一团 | 世界观纹样 | 复杂，和同类游戏的鹰徽撞 |
| 庚 | **盘上背包**：甲放在一块圆石盘 / 木牌上 | 「背包」+ 质感 | 盘吃掉物件 | 盘来自 UI 套件 | 只适合 256 的商店页 |

**推荐：甲为底、丙为点睛 —— 「包盖上缝格子的皮背包」。** 皮包是字标的物件，一眼连上字标；包盖（或包身正面）上用针脚缝出 2 × 2 或 3 × 2 的格，格里不放东西（放了 16 像素就糊），格线用深皮色不用墨线，近看是「收纳格」，远看只是缝线，不会变成日历。铜扣留着当唯一的亮点（黄铜色只用这一处，和 224 账单「只有一处用别的色」同一道理）。备选乙（包 + 剑）给作者对比：更「搜打撤」，但两个主体。

不推荐：丁戊己庚 —— 各有一条过不了第二 / 三 / 一条。

## 四、交给美术设计的规格

- **出样三张**：甲（纯背包）、甲 + 丙（缝格背包，推荐）、乙（背包 + 剑）。每张给 256 的主图，加一张对照板：同一图标放在 **16 / 32 / 48 / 256** 四档，分别压在深色桌面和浅色桌面上（两种底各一行），作者就按对照板上的 16 和 32 判。
- **画法**：按 §二.3；主图 1024 × 1024 画、透明底；物件占画布的 80 % 左右，四边留 10 % 透明（系统会再裁圆角）。16 和 32 两档**单独手调**（去针脚、线加粗到 2 像素、只留包形 + 扣），不是缩放。
- **可选第四张**：推荐款加一块圆石盘的「商店页」版，只出 256，看作者要不要。
- **交付**：`/mnt/project-files/art/ui/icon/`，README + `out/icon_1024.png`、`out/icon_256.png`、`out/icon_48.png`、`out/icon_32.png`、`out/icon_16.png`；`.ico` 由执行打包（§五），美术不用做。
- 作者选定在美术设计线程的方向卡上（照 232 / 233 的做法）；选完美术直接把定稿交执行。
