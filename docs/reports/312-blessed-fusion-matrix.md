# 312 赐福异体参与合成：第一步「配方 × 赐福来源」矩阵

> 日期：2026-11-12。依据：[执行方案](../plans/2026-11-12-blessed-fusion-review-actions.md) §6、§8.5、§8.6（矩阵先行，再动代码）；[308](308-blessed-variants-in-fusion.md)。
> 只读统计，没有改任何玩法。数据是 v5.99（合成改造 C 批完成后）的 23 张拼接配方。

## 一、三个数

| 要的数（§8.6） | 组合数 | 涉及 |
|---|---|---|
| 会丢赐福的组合（成品没有那位神的赐福版，回落普通） | **13**（9 组「配方 + 神」） | 全是自然神 |
| 落入禁忌待办的组合（两把武器分属两位神） | **12** | 双刀、双斧、双手剑、巨棒 |
| 非武器的异神组合（按择神规则走） | **13** | 武器 + 自然神材料 |

全部 145 组里另有 107 组可以照规则直接出成品（含 23 组两件都普通），0 组成品缺失。

**现状**：合成按道具 id 精确匹配，赐福版 id 不同，所以今天赐福过的道具贴着放**根本不出锤**。下面说的都是方案落地后会发生的事。

## 二、会丢赐福的 9 组

成品没有自然神的赐福版（自然神的模板不覆盖这几类成品）：

| 配方 | 带自然赐福的那件 |
|---|---|
| 解毒药囊 | 干草药束 |
| 放血刀 | 兽牙 |
| 角弓 | 短弓、鹿角（任一或两件） |
| 轻弩 | 木棍 |
| 长矛、长柄斧、短矛 | 木棍 |
| 石锤 | 木棍、燧石（任一或两件） |
| 万灵药 | 止血敷料 |

照方案这些组合可以合，成品是普通版，确认窗多一句「本次合成不会保留赐福」。

## 三、禁忌待办的 12 组

都是两把同类武器各带一位神：匕首 + 匕首（双刀）、手斧 + 手斧（双斧）、短剑 + 短剑（双手剑）各 2 组（蛮神 × 太阳神，两种顺序），木棒 + 木棒（巨棒）6 组（蛮神 / 大地神 / 太阳神两两）。照 §8.1 显示「两位神的赐福互不相容」，不出合成按钮。

## 四、非武器的异神组合 13 组

武器带蛮神 / 太阳神 / 大地神、另一件材料带自然神（放血刀、角弓、轻弩、长矛、长柄斧、短矛）。按 §1 的择神规则（当前信仰在两神之中优先，否则看定价，再看神 id），成品有那位神的赐福版就保留它，并提示另一份不叠加。

## 五、赐福把材料抬一档（§8.5）

赐福版稀有度高一档，铁匠配方按档取料，所以赐福材料能顶更高一档的格。共 31 件材料的赐福版比原件高一档（30 件自然神、1 件大地神），和 C 批铁匠配方有关的：

| 赐福版 | 原件 → 赐福 | 新增的取料路径 |
|---|---|---|
| 铁木枝（自然） | 蓝 → 紫 | 唯一的紫档木材；大魔导杖要的「木 ≥蓝 ×2」也能用它 |
| 兽爪（自然） | 蓝 → 紫 | 骨 ≥蓝 的格（3 件骨材金武） |
| 鹿角、兽牙（自然） | 绿 → 蓝 | **绿骨变成能顶「骨 ≥蓝」**：骨材金武多一条来路 |
| 银矿石（自然） | 蓝 → 紫 | 金属 ≥蓝 的格 |
| 铁矿石（自然） | 绿 → 蓝 | 绿铁矿变成能顶「金属 ≥蓝」 |

金属 ≥金（帝国佩剑）没有赐福路径。今天铁匠铺已经认赐福材料（按材质和稀有度判，赐福版带着原件的材质），这不是新改动带来的，只是 C 批加了件数之后更显眼。要不要让铁匠铺只按原件档次算，等作者定；方案 §7 说打造如何继承赐福另议，我没动。
