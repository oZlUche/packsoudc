# 315 合成改成「拖到上面 → 确认窗」：落地

> 日期：2026-11-12。依据：[方案 314](314-drag-to-fuse-with-confirm-and-pickup-marks.md)（作者 2026-11-12 14:56），按其中的建议初值实装。

## 一、做了什么

- **拖放触发**：拿起一件，松手在能和它合成的另一件上（棋盘里正好压着它一件，或地上光标下就是它），不顶替，先弹确认窗（`FuseNote`）。手上那件先回到拿起前的位置、原处先不画，半透明的残影留在松手处。
- **合成**：两件消耗，成品落在被压那件的位置：先放进它原来的格，再加上手上那件在棋盘上的格，再盖住它的某一格往四周伸，再在棋盘上找空。被压那件在地上，成品落在地上同一处。都放不下原样不动，提示「背包里没有空间放」。
- **取消 / Esc / 点窗外**：什么都没变，不记配方。
- **拿起时标小锤**：棋盘和地上能和手上这件合的道具身上画一枚小锤（作者选 A：现有铜徽 `bag/fuse_badge`，边长格宽 × 0.66、最小 32，画在那件正中，静止）；放下收。确认窗开着时被压那件的小锤画亮的。锁定、扎根、随身之物，商店没成交的货不标。没合成过的配方也标，成品照旧打问号。
- **接缝小锤删了**：`InventoryView` 的接缝绘制与点击、`Fusion.pairs`、`CraftingModule.fusion_pairs` 都去掉。赐福解析、`Fusion.spendable`、配方发现记录不动；两把武器分属两位神照样标、弹窗写「两位神的赐福互不相容。」、没有合成键。
- **文字**：帮助页「合成」「拖放与旋转」、词条「合成」、序章三处教程句、九张配方说明、铁匠的一句台词，中英文一起改。

## 二、和方案不同的地方

- 方案说确认窗开着时「不要先放回去再弹窗」。实现上手上那件逻辑上已经回到原处（这样取消不用再做事、合成也只认两件都在容器里），画面上原处先不画、残影留在松手处，看起来和没放回去一样。地上拿起的那件回到地上时照常画（地层没有「先不画」）。
- 被压那件在地上、成品落在同一处；方案没写这一格，取的是对称做法。

## 三、没做

- 切片 S2 的引导字句还没有写到合成，现在没有要改的；以后写时照拖放说法。
