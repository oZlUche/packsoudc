# 314 合成改成「拖到上面 → 确认窗」，拿起时标出能合的那几件（方案）

> 日期：2026-11-12。作者 2026-11-12 14:56（架构设计线程）：改成拖到上面时弹出确认窗比较好；另外拿起道具时，应该让其他可合成道具显示一个提示。
> 基线：main v6.06。现状是 v5.97（报告 310）定的「贴着放 → 点接缝小锤 → 确认窗」，全部 29 张配方同一套；「拖上去立刻合」与拿起时的高光在 v5.97 删了。
> 作者直接提出的改动，按下面的建议初值交执行线程；作者改了哪条再跟着改。

## 一、改成什么

**1. 触发方式换成拖放。** 拿起一件，松手在能和它合成的另一件上：不合成、不顶替，先弹确认窗。确认窗就是现在这张羊皮纸条（`FuseNote`），内容、未知成品问号、赐福提示都不变。

- 点「合成」：两件消耗，成品落在被压那件的位置；放不下就在棋盘上找位，再放不下原样不动并提醒。
- 点「取消」、按 Esc、点窗外：手里那件回到拿起前的位置，什么都没发生，不记配方。

**2. 拿起时标出搭档。** 拿起一件的瞬间，棋盘和地上凡是能和它合成的道具，身上出现一个小锤标记；放下或合成后消失。不加任何文字。

**3. 接缝小锤取消。** 两件贴着放不再出锤。合成只有「拖到上面」这一种方式，教程和帮助只讲一种。

## 二、几条边界（建议初值）

| 情况 | 处理 |
|---|---|
| 没合成过的配方 | 照样标小锤、照样弹窗，成品打问号。现在贴着放出锤时也不看是否发现过，信息量一样，只是不用玩家自己凑位置 |
| 被压的那件锁定、扎根、是随身之物 | 不标、不弹窗，按普通拖放处理（和现在不出锤一致） |
| 手里那件锁定 | 不标（锁定件本来就不被合掉） |
| 两把武器分属两位神 | 标小锤；弹窗写「两位神的赐福互不相容。」，没有合成键（v6.03 现状） |
| 搭档在哪里才算 | 玩家自己的棋盘和地上的都算；商店里没成交的货不算（v5.97 现状） |
| 从哪里拿起都行 | 棋盘、包里、地上、战利品拿起的都能压到搭档上合 |
| 想把一件压到搭档上只做顶替 | 不再支持；弹窗里点取消后另找位置放。合成比顶替常用 |
| 同名两件（匕首 + 匕首） | 拿起一把，其余每一把都标 |
