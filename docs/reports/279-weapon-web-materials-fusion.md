# 279 通用武器网状升级（拼接 × 材质 × 部位）

作者 2026-11-04 16:12（接 276）：「关于武器的进化，我想的是不仅局外铁匠铺，局内收集到对应道具后，也可以在休息点的铸造区升级，为此，需要设计一套比较通用的武器网状升级路线，比如绿色武器+骨素材=蓝色骨质武器，后续可以根据加入的素材呈现更多种不同的状态：纯骨制，骨+金属，骨+木等等。这种设计都可以应用在短兵、单手、双持、长柄、双手武器中，另外基础武器（白色品质）可以在包内直接通过拼接变成绿色武器，比如匕首+匕首=双刀，木棍+短剑=长枪等等（参考背包乱斗）」。

取代 276 的手写 25 把清单；276 的新家族变成这里的「类别」，战锤调数那条保留。

## 〇 一句话

一把武器 = **类别 × 层 × 材质组合**，升层就是往部位里填材质：白 →（包内拼接）→ 绿 →（刃 / 头填一种材质）→ 蓝 →（柄填一种材质）→ 紫 →（镶一颗魔晶）→ 橙。材质四种（骨 / 金属 / 木 / 石）各有自己的刃效果和柄效果，组合出的武器名字、画、效果都由脚本生成，不手写；升级在休息点的铁炉和基地铁匠铺用同一套砧，拼接在任何棋盘上都能做。材料库 58 件终于有了去处。

## 二、模型

### 1. 五个类别与四层

| 类别 | 白（基础件） | 绿（拼接成） | 层的形状 | 节奏模板（绿） |
|---|---|---|---|---|
| 短兵 | 匕首 | 匕首 + 磨刀石 = 短刃（唯一不靠两把合的） | 1×2 全程 | 5 / 0.6 s / 3 |
| 单手 | 短剑（降为白，待定 5）、手斧 **新白** | 短剑 + 手斧 = 阔剑；手斧 + 手斧 = 战斧 | 1×3 → 1×4 | 12 / 1.0 / 5 |
| 双持 | — | 匕首 + 匕首 = 双刀；手斧 + 手斧 = 双斧（待定 4：同配方归双持还是单手） | 2×2 | 两段出手各 6 / 0.7 / 3 |
| 长柄 | 木棍（现有材料） | 木棍 + 匕首 = 短矛；木棍 + 短剑 = 长枪；木棍 + 手斧 = 长柄斧 | 1×4 → 1×5 | 14 / 1.3 / 6，开局先刺一下 |
| 双手 | 棍棒 **新白** | 短剑 + 短剑 = 双手剑；棍棒 + 棍棒 = 大棒；木棍 + 燧石 = 石锤 | 2×3 → 3×3 | 30 / 2.4 / 11，命中减速 1 层 |

层：白 0 → 绿 1 → 蓝 2 → 紫 3 → 橙 4。**类别决定形状、节奏、识别句；层决定倍率（绿 1.0 / 蓝 1.3 / 紫 1.6 / 橙 2.0）；材质决定加的那几句。**

### 2. 材质与部位

一把武器有三个部位：**刃 / 头**（蓝时填）、**柄**（紫时填）、**镶嵌**（橙时填，只收魔晶）。填进去的材质决定效果和画：

| 材质 | 填在刃 / 头 | 填在柄 | 画法（换色） | 收哪些材料 |
|---|---|---|---|---|
| 骨 | 命中流血 1 层 | 暴击率 +5%（锐目轴） | 象牙白 + 骨纹 | `material: bone`（兽牙 / 兽爪 / 鹿角 / 碎骨串 / 骨骰子…） |
| 金属 | 伤害 +20%，其中 3 点直伤 | 格挡 +2（加固轴） | 钢灰 / 秘银银白 | `material: metal`（铁矿 / 铜锭 / 钢锭 / 银锭 / 秘银锭…） |
| 木 | 耐力消耗 −20%（灵巧轴） | 出手 −10% 冷却 | 橡木棕 / 铁木深棕 | `material: wood`（橡木 / 硬木板 / 铁木枝…） |
| 石 | 命中减速 1 层（震慑） | 受伤 −10%（坚韧轴） | 花岗灰 | `material: stone`（燧石 / 磨刀石 / 花岗石臼…） |
| 魔晶（只镶嵌） | 命中施加对应元素 1 层（灼烧 / 寒冷 / 麻痹） | — | 刃上一点元素光 | 现有三色魔晶 |

- 同一材质填两个部位 = 「纯骨」「纯钢」：效果叠满两句，名字用「纯」字。
- 材料件的稀有度 ≥ 目标层 − 1 才收（蓝要 ≥ 绿材料，紫要 ≥ 蓝材料，橙要紫魔晶）；高稀有度材料顶替低的，白材料只够拼接（待定 3）。
- 材质效果全部走现有构件：`apply_status`、`deal_damage.direct_override`、`shift_axis`（锐目 / 加固 / 灵巧 / 坚韧 / 攻速）、`on_battle_start`。

### 3. 状态数与命名

状态 = (类别, 层, 刃材, 柄材, 镶嵌)。四材质 + 三元素：每类 绿 1 + 蓝 4 + 紫 16 + 橙 48 = 69，五类 345 把。**先少再多**：第一批只做 骨 / 金属 / 木 三材质、不做镶嵌 → 每类 1 + 3 + 9 = 13，五类 65 把，加白 5 把；石与魔晶第二批。

名字按模板生成（`display_name` 与 en 一起），**说明字段留空给作者**：
- 蓝：`{刃材}{类名}` → 骨短矛 / 钢阔剑 / 木双刀（木刃 = 硬木，照样成立）
- 紫：`{刃材}刃{柄材}柄{类名}` 太长，用 `{刃材}{柄材}{类名}`：骨钢短矛、钢木阔剑；同材 = `纯{材}{类名}`：纯骨短矛
- 橙：`{元素}{紫名}`：焰纹纯骨短矛 / 霜纹骨钢阔剑 / 雷纹…（元素字待美术 / 作者）

### 4. 画

每类每层一张底图（SVG，刃 / 头、柄、镶嵌点三组图层打上 id），材质 = 一套换色表（骨 / 钢 / 木 / 石各一组 fill），镶嵌 = 刃上叠一枚元素小亮点。`tools/gen_weapons.py` 读底图 + 换色表 → 每把生成一张 svg → `gen.py` 出 png 与 @2x。美术要画的只有：5 类 × 层形状（绿 / 蓝紫同形 / 橙同形，部分类升层加一格 → 约 8–10 张底图）+ 5 把白 + 三枚元素亮点。玩家在包里一眼看出「这是骨刃、钢柄」，不需要文字。

### 5. 拼接（包内，白 → 绿）

- 配方表 `data/authoring/fusions/<id>.json`：`{inputs: [a, b], output}`，无序，第一批 9 条（见 §二.1）。
- 两件在同一棋盘上**相邻**（任一格贴边，转向无关）且匹配配方 → 两件描亮边、接缝处浮一枚小锤徽（无字）；点徽 = 合成：两件消失，成品放在两件的并集脚印上（放不下 → 进手里让玩家摆，再放不下落地）。**不自动合**（待定 2），放错一次毁两把太伤。
- 任何棋盘都行：局内背包、基地仓库、商店格。合成不花钱、不花耐力。

### 6. 升级（砧）

- 局内：休息点铁炉的铸牌炉旁加一张**砧**：武器槽 + 材料槽，放对了亮，显示成品名和多出来的那句，点锤 → 换成成品，材料消失。不花钱；铁炉「一次就熄」只管铸牌，砧每个休息点可用一次（待定 7）。
- 基地：铁匠铺顶部同一张砧，吃仓库，收工钱（绿→蓝 60、蓝→紫 150、紫→橙 300）；铺子级数照旧 = 档次上限，秘银锭等紫材料仍要「秘银冶炼」。
- 现有手写改铸配方（秘银附魔长剑等）保留为特例节点，不受砧影响。

### 7. 现有 19 把怎么进网

| 现有 | 映射 | 处理 |
|---|---|---|
| 匕首 / 短剑 / 木棍 | 白基础件 | 短剑 r1 → r0（待定 5） |
| 长剑、弯刀、剁刀、战锤、短弓、长弓 | 各自类别的「有名绿 / 蓝」节点（长剑 = 单手绿·钢；弯刀 = 单手绿·骨刃…） | 名字、画、数值不动；砧能接着往上升（它们的空部位按映射填） |
| 放血刀 / 溃烂之刃 / 涂毒匕首 / 秘银附魔长剑 / 钟摆刃 / 胫骨大棒 / 猎神长弓 / 四根法杖 | 特例节点（信仰、机关、法杖另有体系） | 不进网；法杖按 273 |
| 弓 | 远程不在这五类里 | 第二批单开「弓」类（短弓 + 短弓 = 长弓？待作者） |

## 三、改动清单（执行，分四步，每步可单独合）

1. **数据与生成器**：`weapon_classes/*.json`（五类：各层形状、节奏模板、识别句、底图名）、`weapon_materials/*.json`（四材 + 魔晶：刃句、柄句、换色表、名字字）、`tools/gen_weapons.py` 写出 `data/authoring/items/gen/*.json`（authoring 仍是正本，生成文件入库）与 svg；`ItemDef` 加 `weapon_class / tier / parts {head, grip, inlay}`；242 估力台跑全网，DPS 落 276 的阶梯。
2. **拼接**：`fusions/*.json` + `GridInventory.fusion_pairs()` + 描边与小锤徽 + 合成；帮助页「拖动与旋转」加一句。
3. **砧**：`AnvilPanel`（武器槽 + 材料槽 + 锤），休息点铁炉与基地铁匠铺各挂一张；`WeaponWeb.upgrade(weapon, material) → ItemDef`；基地收工钱。
4. **美术**：底图 8–10 张 + 白 5 把 + 元素亮点 3 枚（美术设计）；砧、小锤徽、拼接描边（UI替换美术）；执行先用现有画换色占位。

## 四、待定（没回音按推荐）

1. 层数规则：绿→蓝填刃、蓝→紫填柄、紫→橙镶嵌 —— **推荐**（和作者「绿 + 骨 = 蓝骨质」一致）。
2. 拼接要点徽确认，不自动合 —— **推荐点徽**。
3. 材料稀有度 ≥ 目标层 − 1 —— **推荐**（给紫材料用处）。
4. 手斧 + 手斧 归双持（双斧）还是单手（战斧）—— **推荐双持**，单手用 短剑 + 手斧。
5. 制式短剑 r1 → r0 当白基础件 —— **推荐降**。
6. 第一批三材质无镶嵌（65 把）—— **推荐**，石与魔晶第二批。
7. 休息点砧每点一次、不花钱 —— **推荐**。
8. 紫的两个部位顺序固定（先刃后柄）—— **推荐固定**，玩家不用选部位。
