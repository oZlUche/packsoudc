# 091 · 计划书：带剧情的生涯模式 × 肉鸽，怎么取舍

> 提议 ｜ 等作者拍板 ｜ 前一步：[090 开局屏暂存区等](090-setup-stash.md)、[086 序章三提案](086-demo-gaps-and-tutorial3.md)、[世界观](../worldview/worldview.md)

作者的话：既想做带剧情的生涯模式，也想做肉鸽；要一份评估风险、收益、成本的取舍计划，并收集近几年玩家画像里对剧情的重视程度（作者预判：比较低）。

## 〇、结论先行

1. **肉鸽是主体，剧情做「壳」不做「骨」。** 证据（第三节）说这个品类的玩家把剧情排在玩法、构筑、重玩性之后，但**不是零**：做得好的剧情（哈迪斯式「每局一小口」）是加分项与口碑差异点，做得重的剧情（线性战役、长对话）是减分项与工期黑洞。
2. **推荐方案 B：肉鸽本体 + 低剂量生涯壳。** 生涯 = 身份 + 章节推进 + 随局滴灌的碎片叙事 + 一个结局；不做脚本化的线性剧情关卡链。新机制只要一样（局外旗标进事件条件 / 后果），其余全是数据与文字。
3. **顺序：先把肉鸽本体做完（序章三、第一章内容、信仰道具族、局外成长），再做叙事最小集，中间设一道决策门**：用 demo 的跳过率与问卷决定要不要再往剧情里加钱。剧情永远可跳、二周目免看，任何时候能停在「壳」这一层而不留残件。
4. **不要做的：**有配音的对话、立绘演出、多结局分支树、必须看完剧情才解锁的玩法。这些是 C 方案（剧情战役）的成本大头，收益在这个品类里最不确定。

## 一、先说清两个词各指什么

「生涯模式」在作者这里可能是三样东西里的任意一种，成本差一个量级，所以先拆开：

| 含义 | 是什么 | 参照 | 成本级别 |
|---|---|---|---|
| **G1 叙事框架** | 有世界观、有开场与结局、道具 / 敌人 / 图鉴各有一句来历；不要求任何脚本关卡 | 杀戮尖塔、小丑牌（几乎没有）、死亡细胞（碎片） | 低：全是文字 |
| **G2 生涯壳** | 玩家扮演一个**身份**（奴隶探索者 / 自由民 / 军团士兵……），一局局地进诅咒之地，局外攒军功 / 钱 / 神的青睐换成长；章节按进度解锁；营地里的人随进度说新话；有一个终局 | 哈迪斯（每局回家一句新话）、暗黑地牢 1（庄园 + 章节 BOSS）、循环英雄（每局回营地推进一小段） | 中：一个小机制 + 大量短文本 |
| **G3 剧情战役** | 固定顺序的章节，每章预设图 + 脚本事件 + 角色对话，有分支与多结局；随机一局作为「自由模式」并列 | 月圆之夜、Griftlands、Inscryption | 高：内容量与演出量都是数倍 |

「肉鸽」在这里 = 现在已经在做的：随机图、随机搜索与掉落、一局定生死、局外仓库与解锁。**不存在「二选一」**：G1 已经在做（世界观文档、序章、图鉴），问题只是要不要 G2、以及要不要 G3。

## 三、项目现状：为生涯模式已经有什么、还缺什么

这决定成本。盘一遍引擎与内容：

### 已经有的（可以直接当生涯模式的零件）

| 零件 | 现状 | 生涯模式里能当什么 |
|---|---|---|
| 章节串联 | `ChapterDef.next_chapter` / `requires_unlock` / `grants_unlock` / `hidden_by_unlock`（083、085） | 章节按进度解锁、通关顶上下一章 —— **生涯的骨架已在** |
| 预设图 | `line` 布局带 row（分岔再归一），两张序章都是 | 脚本化的剧情章节 |
| 事件层 | 10 种条件、21 种后果、`next_event` 串接、`intro_event`（077、083、084） | 对话 = 事件屏（文字 + 图 + 选项）；后果能给道具 / 改点 / 传送 / 开战 / 撤离 |
| 文本占位符与样式码 | `TextTemplate`（084） | 角色名、数值进对白 |
| 特殊道具（望远镜） | `keepsake`：不进背包、图鉴点亮、代表能力（088） | **剧情关键物 / 能力解锁的容器** |
| 角色 | 三个角色、技能、初始包（067、082） | 身份的载体 |
| 信仰 / 信力 | 六个信仰、行为攒点、阶（081、082） | 「神的青睐」这条成长线 |
| 局外 | 仓库、图鉴、解锁旗标 `MetaState.unlocks`、钱、战绩、三个存档位（061、089） | 生涯档 |
| 多语言 | `display_names` + `UiText`（088） | 剧情文本可本地化的前提 |
| 世界观 | `docs/worldview/` 约 5 万字设定，主线与信仰体系作者已定 | 一切文字的依据 |
| 现有内容量 | 40 个事件（约 2500 汉字）、50 件道具、10 个敌人、3 章、6 信仰、3 角色 | 序章两张 ≈ 24 个事件、约 1500 字 —— **一张教程章的文字量就这么多**，是估算的基准 |

### 缺的（做 G2 要补的）

| 缺口 | 做法 | 量级 |
|---|---|---|
| **局外旗标进事件** | `MetaState.flags`（字符串集合 / 计数）；条件 `has_flag` / 后果 `set_flag`；跟局外存档 | 1 天。G2 唯一必须的新机制 |
| 身份 | `CharacterDef` 加身份字段（开局文本、报酬形式、进出口文字）；或身份就是角色 | 0.5 天机制 + 文字 |
| 营地 / 基地的「人」 | 基地屏加一块「营地」：几位固定 NPC，各按旗标与进度挑一句话（哈迪斯的方式，没有演出） | 1 天机制 + 每人 20～40 句 |
| 章节完成态与结局 | `grants_unlock` 已能表达；结局 = 一个事件 + 一屏结算文字 | 0.5 天 |
| 剧情可跳过 / 已读标记 | 事件屏「跳过」+ 局外记已读；二周目默认略过 | 0.5 天 |
| 敌人 / 猎手 / 道具的一句来历 | `description` 字段已有（088），填字 | 纯文字 |

### 做 G3 还要再补的

对话演出（立绘、表情、镜头）、人物 / 好感 / 分支变量、章节脚本图 × N、多结局的测试矩阵、可能的配音与大量本地化。这一层每一项都是「新系统 + 新内容 + 新美术」，估算见第四节。

## 四、三个方案：成本、收益、风险

工时按「作者 + 现在这套开发方式」估，单位是工作日；文字量按汉字数。每条都给区间，取上限做预算。

| | **A 纯肉鸽 + 叙事框架（G1）** | **B 肉鸽本体 + 生涯壳（G2，推荐）** | **C 剧情战役为主（G3）+ 自由模式** |
|---|---|---|---|
| 做什么 | 把已定的世界观落到道具 / 敌人 / 图鉴 / 事件的一句话里；开场一段、结局一段 | A 的全部 + 身份 + 营地 NPC 随进度说话 + 章节按生涯推进 + 一个终局 + 旗标机制 | B 的全部 + 3 幕 × 3～4 章的脚本章节（预设图 + 脚本事件 + 对话）+ 分支与 2～3 个结局 + 演出 |
| 新机制 | 无 | 旗标 1 天、营地 1 天、身份 0.5、跳过 / 已读 0.5 | B 的 + 对话演出系统 5～10 天、变量 / 好感 3 天、章节脚本工具 3～5 天 |
| 文字量 | 0.6～1 万字（50 件道具 × 40 字 + 10 敌 × 80 字 + 事件 40 × 60 字 + 开场结局） | 2～4 万字（A + NPC 4 人 × 40 句 × 40 字 + 每章 intro / outro + 身份文本） | 10～20 万字（哈迪斯约 30 万字英文，Griftlands 更多 —— 见第二节） |
| 工时（机制 + 文字 + 接入 + 测试） | **3～6 天** | **12～20 天** | **60～120 天**（不含美术与配音） |
| 美术需求 | 无新增 | NPC 头像 4～6 张（可先用色块 / 剪影） | 立绘 × 人物 × 表情、场景图、UI —— 外包或长期 |
| 本地化（做英文） | 0.6～1 万字 | 2～4 万字 | 10～20 万字，成本按字数线性翻 |
| 对重玩性的影响 | 无 | 略正（进度感、营地新话是每局回来的钩子）；剧情可跳，不锁玩法 | **负风险**：脚本章节看一次就没了；玩家在「剧情章」里被剥夺随机性；自由模式反而成了「附赠」 |
| 收益 | 世界观有味道；宣发有东西可说；图鉴有内容 | 差异化标签（「有故事的背包搜打撤」）；留存钩子；Steam 评测里的「氛围好」一类正评；为 C 留门 | 若做成：叙事口碑与话题（哈迪斯那种）；若做不成：全部沉没 |
| 主要风险 | 几乎无 | 文字质量（写不好比不写更扣分）；世界观第六节 9 问没定就写不了 | 工期翻倍以上；剧情与随机生成打架；分支测试；美术与配音的外部依赖；**品类玩家不看**（第二节） |
| 可回退性 | — | 高：随时停在 A + 旗标，营地文本不再加，不留残件 | 低：半成品的战役比没有更糟 |

**成本对比一句话：C 的成本是 B 的 5～8 倍，收益的不确定性最高；B 的成本是 A 的 3～4 倍，但把「生涯」这个作者想要的感觉给出来了，并且给 C 留了门。**

| R9 | 多结局测试矩阵 | 高（C） | 中 | B 只一个结局；C 若做，结局差异只在最后一屏文字 |

## 七、推荐路线与里程碑

```
阶段 0  世界观定稿（作者答第六节 9 问 + 身份清单）        ← 不写代码，先答题
阶段 1  肉鸽本体收口：序章三（086）、第一章事件文字、信仰道具族、8-5 局外成长（仓库怎么花）
阶段 2  叙事最小集 = 方案 A：道具 / 敌人 / 图鉴一句来历、开场与结局各一段            3～6 天
阶段 3  生涯壳 = 方案 B 的机制层：旗标、营地、身份、跳过 / 已读                      3～4 天
阶段 4  生涯壳的文字：营地 4 人 × 40 句、每章 intro / outro、身份文本                 6～10 天
   ── 决策门 ──  demo 发出去：看跳过率、文本停留、问卷（第八节）
阶段 5（可选）剧情章：只做 1 章脚本章试水（预设图 + 6～10 个事件），再决定要不要 C
```

- 阶段 1 与剧情无关，是无论如何都要做的；把它放在前面是为了**任何时候停下来都有一个完整的肉鸽**。
- 阶段 2～4 加起来是方案 B 的全部（12～20 天）。阶段 3 的机制只有一样是真正的新东西（旗标），其余是拼装。
- 决策门不过（跳过率 > 70%、问卷里剧情排最后且没人提），就停在 B，不再加字；过了，再评估 C，且 C 从**一章**开始。

## 八、决策门的量化指标（demo 阶段就能采）

| 指标 | 怎么采 | 停在 B 的阈值 | 继续往 C 走的阈值 |
|---|---|---|---|
| 事件文字跳过率 | 事件屏记「文字展开到选项按下」的时长；< 2 秒算跳过 | > 70% | < 40% |
| 营地对话点开率 | 基地屏 NPC 点击 / 进基地次数 | < 20% | > 50% |
| 问卷「你最在意的三项」 | demo 结尾一页，选项：构筑 / 搜刮撤离的紧张 / 重玩 / 剧情与世界观 / 美术 / 数值 | 剧情不进前三且被选率 < 15% | 剧情进前三 |
| 评测关键词 | Steam / TapTap 评测里「剧情 / 世界观 / 氛围」正负向计数 | 提及 < 10% | 正向提及 > 25% |
| 完成率 | 序章三 → 第一章通关的人数比 | 与剧情无关，但低于 30% 说明先修玩法 | — |

这些埋点都是几行日志（`CalibrationRecorder` 已经在每步记玩家配置，加几个字段即可）。

## 九、请作者定

1. **「生涯模式」你心里的是 G1 / G2 / G3 哪一个？** 本计划按 G2 推荐；若是 G3，请先看第四节 C 列的成本与第五节 R2 / R4 / R7。
2. **世界观第六节的 9 问**（神明清单、赐福形式、诸神争端现状、玩家的信仰、神陨表现与新教、魔法、身份清单、封存物）—— 阶段 0 的全部工作，不答就写不了字。

4. **字数预算**是否接受：B 方案 4 万字上限（含营地 160 句）。
5. **决策门的阈值**（第八节）认不认。
6. **英文**：剧情文字要不要本地化；不做就只做界面英文。
