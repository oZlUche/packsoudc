# 377 万神院：营地新势力，出征前选这一局奉哪位神（方案，待作者定）

> 日期：2026-11-21。基线：main，v7.60。只有文档，没有改代码。
> 作者 22:15：「关于神明，我想在营地加入【万神院】势力（拉丁文名应该是【诸神的祭司集体】，帮我构思），它可以给予玩家出征前选择这一局信仰神明的机会，这样一来神的信物就在这个势力引入后解锁，休息点的祭坛也是，前期玩家只有无信仰玩法，这样一来新手教程也要删改」
> 同一条里：不奉神的路线【人文主义】改叫【以人为本】（已改进报告 372）。
> 上面是作者定的。下面的到来条件、信赖各档给什么、教程怎么改，都是我填的建议初值。

## 一、一句话

游戏前期没有神。玩家只有【以人为本】一条路，靠经验值升级、从通用牌里选。打过几局以后，万神院来到营地，从此出征前可以在万神院选这一局奉哪位神；神的信物、休息点的祭坛、局内的神召事件，都从这一刻起才出现。

## 二、现状（查数据所得）

- 营地现在有五方挂牌的势力：后勤部队、魔法师协会、灰灯互助会、地图协会、河滩垦户社。地图协会和垦户社是「教程后第一次正式探索结算时」才来的，其余一开始就在。每方五档信赖，门槛 0、10、25、50、100，各带一个设施和一张许可。
- 六位神各有一件信物（蛮神、技巧之神、狩猎之神、大地之神、日神、自然之神）。现在信物是普通道具：带进局、在开局屏上选定，就奉这位神。
- 局内有神召事件（祭坛上放着一件信物，可以拿）和休息点的祭坛（献祭）。
- 序章三「祭坛」整章在教信仰：开局发蛮神、日神两件信物，章里有神召、休息点献祭的讲解。切片的基地清单里也列了这两件信物。

## 三、名字

作者要的意思是「诸神的祭司集体」。古罗马的祭司团体叫 collegium，祭司是 sacerdos（泛称）或 pontifex（大祭司团的成员）。三个候选：

- A（建议）**Collegium Sacerdotum Omnium Deorum**，直译「所有神的祭司的团体」，意思和作者说的一字不差。界面上地方小的时候用简称 **Collegium Deorum**（诸神团）。
- B **Collegium Pantheum**，「万神的团体」，短，和中文「万神院」对得最齐，但 Pantheum 当形容词用是自造的拉丁文。
- C **Collegium Pontificum**，历史上真有的「大祭司团」，最地道，但没有「诸神」的意思。

## 四、规则

### 1. 什么时候来

- 新档开始时万神院不在营地。营地里看不到它的牌子，也不预告。
- 到来条件（初值）：教程之后，**第 3 次成功撤离**结算时到来，和地图协会、垦户社「第一次正式探索后到来」是同一套机制，只是晚两局。这样玩家先用【以人为本】打几局，熟了升级选牌，再接触神。
- 到来那一刻在结算后的营地里放一段到来的过场（一页文字加势力的牌子亮起），然后营地导览多一步，带玩家进万神院看一眼。

### 2. 万神院做什么

- **出征前选神**（作者定）。万神院是营地里的一个设施页。里面一排神龛，每位已解锁的神一座，点一座就是「这一局奉这位神」，再点一次取消。不选就是【以人为本】。
- 选定以后，出征页上显示这一局奉的神。原来开局屏上「从带进来的信物里选神」的那一步取消，改成只在万神院选。
- **信物**（作者定：势力引入后解锁）。选了神，这位神的信物在出征时自动放进背包，照旧占格、照旧是赐福道具的锚点；不用玩家自己去攒去带。局结束后信物不带回仓库。初值：不收钱。
- **休息点的祭坛、局内的神召事件**（作者定：势力引入后解锁）。万神院到来之前，地图上不生成祭坛，神召事件不进事件池；到来之后才有。
- 万神院到来之前，仓库、市场、掉落、图鉴里都不出现信物和赐福相关的道具。

### 3. 信赖各档给什么（初值）

沿用五档门槛 0、10、25、50、100。

| 档 | 给什么 |
|---|---|
| 一（到来即有） | 两位神可选：蛮神、日神。休息点祭坛、神召事件开放 |
| 二 | 再开两位：技巧之神、狩猎之神 |
| 三 | 再开两位：大地之神、自然之神 |
| 四 | 许可：出征时这位神的第一张神牌必出（第一次升级的神牌位不随机落空） |
| 五 | 局内可以在祭坛改奉另一位已解锁的神，一局一次，等级和已拿的通用牌保留，神牌作废 |

- 先开蛮神、日神，是因为它们的机制最直白（怒气、烈日窗口），而且现在教程用的就是这两位，文字和讲解可以挪过来用。
- 第四、五档是我补的，纯属候选；也可以改成给刷新次数、给经验加成之类。

### 4. 万神院的委托（初值，照现有势力的写法各三条常驻）

- 献祭：在祭坛献祭若干次。
- 修行：奉任意一位神升到若干级后撤离。
- 见证：奉一位这个存档里还没奉过的神完成一局。

### 5. 和局内成长（报告 372）怎么接

- 万神院到来之前，升级的三张牌全是通用牌，逢 5 级多选一次通用，也就是报告 372 里【以人为本】的规则。祭坛祷告、各神的额外经验来源都不存在。
- 到来之后选了神，才有神牌、质变牌、神的额外经验来源。
- 所以报告 372 的三批里，第一批（等级、通用经验来源、通用牌、选牌界面）正好就是「前期的完整玩法」，可以先做先上；万神院和第二批（神牌、质变）一起上。

### 6. 新手教程怎么改

现在三章序章：一教战斗和搜索，二教商店和岔路，三「祭坛」教信仰。前期没有神以后：

- **序章三改教升级。** 章名、地图骨架、休息点保留；发信物、神召、献祭的内容删掉，换成「打赢拿经验、升级三选一、逢 5 级多选一次」的讲解。这一章本来就是教「局内变强」，换个载体。
- **信仰的教学挪到万神院到来时。** 到来的过场之后，第一次进万神院有一段导览（选神、信物进背包）；选了神的第一局，在第一次升级出神牌、第一次到祭坛时各有一句提示。原来序章三里讲信仰的文字改一改挪过来。
- **要动的东西**：序章三的事件（开场、两次休息点、神召、搜索收尾）、章里发的两件信物、统一教程的奖励账本里对应的条目、切片基地清单里的两件信物、帮助页和图鉴里信仰相关的入口（到来前藏起来）。
- 具体删哪几步、新讲解写什么，由执行线程照这个方向出逐步清单给作者过目，不在这份方案里逐句定。

### 7. 老存档

- 已经通过序章三、或者仓库里有信物、或者奉过神的存档：直接算万神院已到来，信赖按第一档起；仓库里已有的信物换成等值金币（信物以后不再是仓库道具）。
- 奉过的六位神是否全部直接可选，见文末问题。

## 五、界面

- 营地多一块万神院的牌子和设施页：一排神龛，已解锁的亮、未解锁的暗；每座神龛上是神像和名字，点开看这位神的核心机制一句话。
- 出征页显示这一局奉的神（或【以人为本】）。
- 牌子、神龛、到来过场的画面请 UI设计 出样张，先用占位。无裸文字、面板声明明暗照旧。新字（比如「院」「龛」）要确认在字库子集里。

## 六、实现要点（给执行线程）

- 势力数据照现有格式加一方：到来方式新增一种「第 N 次成功撤离后」，N 写在数据里；设施是万神院页；许可是第四档那张。
- 「信仰开没开」做成一个统一的开关，由万神院到没到来决定：地图生成（祭坛）、事件池（神召）、掉落和市场（信物、赐福道具）、图鉴和帮助页、升级出牌（神牌位）都读它。
- 选神从开局屏挪到万神院页；出征时按选的神发信物进背包并定下这一局的神。信物不再进仓库、不再能买卖。
- 教程：序章三的事件和发放清单重做；切片基地清单去掉信物；到来过场和导览走现有的教练层。
- 存档迁移：老档按第四节第 7 条处理。
- 分两批：先做开关、到来、万神院页和选神（神还是现有机制也能用）；再改序章三和信仰教学。和报告 372 的批次怎么穿插，派执行时一起排。

## 七、担忧

1. **前期只有通用牌，会不会太素。** 通用牌只有 15 张三类，前三局全靠它们。要保证报告 372 的通用牌够有意思，否则玩家还没见到神就腻了。
2. **序章三重做是不小的工作量**，而且统一教程刚在 11 月 18 日做完一轮，切片演示也依赖它。
3. **切片演示**现在是带信仰的。切片只有一张图、几局的长度，等不到万神院到来；要么切片里直接算万神院已到，要么切片也改成没有神。见文末问题。
4. **选神不要钱以后，信物没有了「攒」的过程。** 这符合作者不要材料驱动的方向，但信物作为道具的存在感会变弱，只剩占格和锚点两个作用。

## 八、请作者定

1. 拉丁文名：A Collegium Sacerdotum Omnium Deorum，简称 Collegium Deorum（建议）；B Collegium Pantheum；C Collegium Pontificum。
2. 什么时候来：A 教程后第 3 次成功撤离（建议）；B 第 1 次正式探索后就来，和地图协会一起；C 局内捡到一件无主的信物带回来才来。
3. 选神要不要代价：A 不要（建议）；B 要金币；C 要信赖档位才能选更多的神，但选本身不要钱（现在的初值其实就是 C 加 A）。
4. 信赖各档先开哪些神：初值是蛮神、日神，然后技巧、狩猎，然后大地、自然。行不行。
5. 第四、五档给什么：初值是「第一张神牌必出」和「局内可改奉一次」，纯候选。
6. 序章三：A 改成教升级三选一，信仰教学挪到万神院到来时（建议）；B 整章删掉，教程只剩两章。
7. 切片演示：A 切片里算万神院已到，照旧带信仰（建议，改动最小）；B 切片也改成没有神。
8. 老存档里奉过的神：A 六位全部直接可选（建议，不收回玩家已有的东西）；B 也按信赖档位重新开。
