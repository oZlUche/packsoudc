## 一、一句话

游戏前期没有神。玩家只有【无信者】一条路，靠经验值升级、从通用牌里选。打过几局以后，万神院来到营地，从此出征前可以在万神院选这一局奉哪位神；神的信物、休息点的祭坛、局内的神召事件，都从这一刻起才出现。

## 二、现状（查数据所得）

- 营地现在有五方挂牌的势力：后勤部队、魔法师协会、灰灯互助会、地图协会、河滩垦户社。地图协会和垦户社是「教程后第一次正式探索结算时」才来的，其余一开始就在。每方五档信赖，门槛 0、10、25、50、100，各带一个设施和一张许可。
- 六位神各有一件信物（蛮神、技巧之神、狩猎之神、大地之神、日神、自然之神）。现在信物是普通道具：带进局、在开局屏上选定，就奉这位神。
- 局内有神召事件（祭坛上放着一件信物，可以拿）和休息点的祭坛（献祭）。
- 序章三「祭坛」整章在教信仰：开局发蛮神、日神两件信物，章里有神召、休息点献祭的讲解。切片的基地清单里也列了这两件信物。

## 三、名字

**Senatus Panthei**（作者 11-22 定）。Senatus 是元老院、议事的长老团，Panthei 是 Pantheum（万神殿）的属格，合起来是「万神殿的元老院」。中文名万神院不变。

之前的三个候选（Collegium Sacerdotum Omnium Deorum、Collegium Pantheum、Collegium Pontificum）作废。

## 四、规则

### 1. 什么时候来

- 新档开始时万神院不在营地。营地里看不到它的牌子，也不预告。
- 到来条件（作者 11-22：先按这个，以后可调）：教程之后，**第 3 次成功撤离**结算时到来，和地图协会、垦户社「第一次正式探索后到来」是同一套机制，只是晚两局。这样玩家先用【无信者】打几局，熟了升级选牌，再接触神。
- 到来那一刻在结算后的营地里放一段到来的过场（一页文字加势力的牌子亮起），到来的通知用样张 B 的风格（作者 11-22 22:53）。

### 2. 万神院做什么

- **出征时选神**（作者 11-22 22:53 改）。选神不是营地里常驻的一页，而是出征时跳出来的一步：万神院到来以后，点出征就先跳到选神界面，上面是各位神，已解锁的可以点，没解锁的显示「？？？？」（不露名字和神像）；点一位就是这一局奉这位神。不想奉神就走【无信者】，它只是界面上的一个选项，不做成神龛（不奉神就没有可侍奉的对象）。万神院到来之前没有这一步，出征流程和现在一样。
- 选完直接进入后面的出征流程。原来开局屏上「从带进来的信物里选神」的那一步取消，并进这一步。
- 营地里万神院的牌子照常有（信赖档位、委托都在那里看），但里面不放选神的神龛页。它的设施页放什么是我的初值：只列已解锁的神和各档给什么，纯查看。
- **信物**（作者定：势力引入后解锁）。选了神，这位神的信物在出征时自动放进背包，照旧占格、照旧是赐福道具的锚点；不用玩家自己去攒去带。局结束后信物不带回仓库。选神不要任何代价（作者 11-22）。
- **休息点的祭坛、局内的神召事件**（作者定：势力引入后解锁）。万神院到来之前，地图上不生成祭坛，神召事件不进事件池；到来之后才有。
- 万神院到来之前，仓库、市场、掉落、图鉴里都不出现信物和赐福相关的道具。

### 3. 信赖各档给什么（作者 11-22 定了各档的方向，数值是我的初值）

沿用五档门槛 0、10、25、50、100。

| 档 | 给什么 |
|---|---|
| 一（到来即有） | 三位神可选：蛮神、日神、技巧之神。休息点祭坛、神召事件开放 |
| 二 | 其余三位全部开放：狩猎之神、大地之神、自然之神。设定是新的祭司到了营地 |
| 三 | 信神时经验值涨得更快。初值：奉神的局里所有途径的经验值加 10% |
| 四 | 解锁【赐福】选项。在祭坛上多出「赐福」这一项，给一件道具加上所奉之神的赐福 |
| 五 | 信神出征时，一进局内先选一次特殊能力。初值：开局就从这位神的质变牌里三选一，不占后面逢 5 级的那几次 |

- 第一档蛮神、日神、技巧之神，第二档狩猎、大地、自然（作者 11-22：可以）。
- 第四档的赐福：祈愿删掉以后（报告 372），祭坛赐福在 372 里是一张带次数的质变牌。按这一条，它改成万神院四档的解锁项。解锁前祭坛上没有赐福这一项；解锁后每座祭坛一次，不再做成质变牌（作者 11-22：可以）。蛮神的神罚仍然是带次数的质变牌。
- 第三档只对奉神的局生效，【无信者】的局不加。这会让奉神比不奉神升得快，是有意的：万神院信赖高了，奉神就该更值。

### 4. 万神院的委托（初值，照现有势力的写法各三条常驻）

- 献祭：在祭坛献祭若干次。
- 修行：奉任意一位神升到若干级后撤离。
- 见证：奉一位这个存档里还没奉过的神完成一局。

### 5. 和局内成长（报告 372）怎么接

- 万神院到来之前，升级的三张牌全是通用牌，逢 5 级多选一次通用，也就是报告 372 里【无信者】的规则。祭坛祷告、各神的额外经验来源都不存在。
- 到来之后选了神，才有神牌、质变牌、神的额外经验来源。
- 所以报告 372 的三批里，第一批（等级、通用经验来源、通用牌、选牌界面）正好就是「前期的完整玩法」，可以先做先上；万神院和第二批（神牌、质变）一起上。

### 6. 新手教程怎么改（作者 11-22：序章三删掉，教学改成解锁后的界面教学）

- **序章三「祭坛」整章删掉。** 教程只剩序章一（战斗和搜索）、序章二（商店和岔路）。序章三发的两件信物、章里的事件、统一教程奖励账本里的对应条目、解锁链里「通过序章三」这一环，都跟着去掉；原来要求通过序章三才开的东西，改成通过序章二就开。
- **升级三选一怎么教。** 序章三没有了，局内升级是全新的核心系统，得有个地方教。初值：第一次升级弹出三张牌时，用现有的教练层讲一遍（三张挑一张、可以重复拿、刷新和删除在哪）。它可以发生在序章一或序章二里，因为这两章也有战斗、也会升级。
- **信仰的教学**：万神院到来以后，用界面教学，也就是一页页的截图加文字说明。
- **截图加文字说明行不行**（作者问的）：可以，而且比做一章教程便宜得多。游戏里已经有帮助页这套东西，可以直接往里加带图的页。要注意三点。第一，截图里有界面文字，中文和英文各要一套。第二，界面一改截图就过期，所以截图要用现成的截图脚本自动出，不要手工截，改了界面重跑一遍。第三，截图只能看不能点，所以关键的那一步（第一次出征时在选神界面上选神）我建议仍然用教练层在真界面上指一下，其余的（信物是什么、祭坛怎么用、神牌和质变牌的区别）用截图页讲。
- 万神院到来后第一次跳到选神界面时自动翻开这几页，之后在帮助页里随时能再看。

### 7. 老存档

- 已经通过序章三、或者仓库里有信物、或者奉过神的存档：直接算万神院已到来，信赖按第一档起；奉过的神全部直接可选，不受档位限制（作者 11-22）；仓库里已有的信物换成等值金币（信物以后不再是仓库道具）。

## 五、界面

- 营地多一块万神院的牌子；设施页只做查看（已解锁的神、各档给什么），不在这里选神。
- 出征时的选神界面：各位神排开，已解锁的亮，没解锁的显示「？？？？」；另有【无信者】一个选项，不做神龛。风格按样张 B（作者 11-22 22:53）。
- 万神院到来的通知按样张 B；其他阵营和功能解锁以后也用同一种通知风格（作者 11-22 22:53）。
- 牌子、选神界面、到来通知的画面请 UI设计 出样张，先用占位。无裸文字、面板声明明暗照旧。新字（比如「院」「龛」）要确认在字库子集里。

## 六、实现要点（给执行线程）

- 势力数据照现有格式加一方：到来方式新增一种「第 N 次成功撤离后」，N 写在数据里；设施是只做查看的万神院页；许可是第四档那张。
- 「信仰开没开」做成一个统一的开关，由万神院到没到来决定：地图生成（祭坛）、事件池（神召）、掉落和市场（信物、赐福道具）、图鉴和帮助页、升级出牌（神牌位）都读它。
- 选神从开局屏挪到出征时跳出的选神界面（不在万神院页里）；出征时按选的神发信物进背包并定下这一局的神。信物不再进仓库、不再能买卖。
- 教程：序章三整章和它的事件、发放清单删除，解锁链改接序章二；切片基地清单去掉信物；第一次升级的讲解和进万神院选神走现有的教练层；信仰说明做成带截图的帮助页，截图由脚本出，中英各一套。
- 切片（作者 11-22）：基础切片不展示万神院，没有神、没有祭坛、没有信物；只加入局内升级系统（经验值、通用牌、选牌界面）。
- 存档迁移：老档按第四节第 7 条处理。
- 分两批：先做开关、到来、万神院牌子和出征时的选神界面（神还是现有机制也能用）；再删序章三、做界面教学。和报告 372 的批次怎么穿插，派执行时一起排。

## 七、担忧

1. **前期只有通用牌，会不会太素。** 通用牌只有 15 张三类，前三局全靠它们。要保证报告 372 的通用牌够有意思，否则玩家还没见到神就腻了。
2. **删掉序章三以后，升级系统没有专门的一章来教。** 靠第一次升级时的讲解顶上，要在新玩家身上试一下够不够。
3. **切片演示**不带万神院（作者定），所以切片里的信仰内容要整个摘掉，切片的基地清单、教程清单都要跟着改。
4. **选神不要钱以后，信物没有了「攒」的过程。** 这符合作者不要材料驱动的方向，但信物作为道具的存在感会变弱，只剩占格和锚点两个作用。
