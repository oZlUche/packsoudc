# 323 统一教程 C 批：教学卡分「看过」和「做过」，回放谁停谁放

> 日期：2026-11-18。依据：[统一教程方案](../plans/2026-11-18-unified-tutorial-and-base-return.md) §3、§11 C 批（PR #651）；接 [报告 321](321-unified-tutorial-batch-a.md)、[报告 322](322-unified-tutorial-batch-b.md)。作者 2026-11-18 09:24：「根据 PR651 的新增方案，优化切片 demo」。
> 本批只改教学卡这层壳，不改现有教程的步骤内容。动作步的内容在 D、E 批写进各段教程。

## 一、教学卡（`CoachOverlay`）

| | 以前 | 现在 |
|---|---|---|
| 下一步 | 点任意处、按任意键 | 纸上的「知道了」，或回车 / 空格 |
| 退回 | 没有 | 「上一步」（第一步不显示） |
| 收掉 | 只能点到最后一步 | 「收起」或 Esc：没看完先收掉，不记看过，下次还放 |
| 点阴影 | 算下一步 | 吞掉，不算（不误触、不穿透） |
| 别的键 | 算下一步 | 解说步吞掉不算；动作步等着时照常给游戏 |

新增 `closed` 信号：看完或收起都会发，各屏用它收尾（放开回放、清掉引用）。`finished` 仍然只在看完时发，各屏照旧用它记看过。

## 二、动作步：看过 ≠ 做过

- 步骤数据里可以写 `"action"`，值是教学动作的 id。点「知道了」只算看过：阴影撤掉，真实操作放开，纸条留在原处当目标提示（目标照样框着）。等玩家真的做成了，才进下一步。
- 做成的判断是真实的成功事件，`GameFlow.note_action` 记进 `MetaState.coach_done`（和 `coach_seen` 分开存）。这一批接了两种动作：
  - 合成成了：`ACTION_FUSE`，合成模块的 `done` 信号。
  - 带回来的东西放进仓库：`ACTION_STORE`，一键置入、双击、拖进去都算。
- 已经做过的动作步直接跳过。没点「知道了」先做了也算。

## 三、回放谁停谁放（`BattleView.hold / release`）

停回放的有三方：开战过场（`HOLD_INTRO`）、教程（`HOLD_COACH`）、反应讲解（`HOLD_REACTION`）。各方只放开自己那一份，所有人都放开了才接着播。以前是一个开关，过场演完会把教程的停一起放掉；现在关掉一张卡，别人压着的停不会跟着失效。

## 四、重看

地图暂停菜单多了「重看教程」：关掉暂停菜单，从头放这一章的地图教程，看过的也放，不改进度和奖励。

## 五、测试

- 新增 `tests/ui/test_unified_tutorial_c.gd`，33 项断言，覆盖四块：
  - 教学卡：回车、上一步、Esc 收起，别的键不算；
  - 动作步：要真做成才算，做过的跳过，没点「知道了」先做也算，存档带着；
  - 回放停的几方：放开一方、别人还压着就继续停；
  - 真实事件记动作和暂停菜单重看。
- `test_map_screen_166` 改了一条断言：点阴影不再算下一步，改按「知道了」。
