- **页签**：左列六个，顺序 出征 / 仓库 / 科技 / 委托 / 后勤 / 书架（`MetaScreen.TABS`）。委托页签的显示规则不变（统一教程走完、不是试玩切片）。

- **旧入口**：`show_tab("tech")` 和开基地时指定 `tab: "tech"` 现在直接落到科技页签。代码里没有别的地方开科技窗（结算的见识、追踪都不经过书架）。没有键盘快捷键要改。
