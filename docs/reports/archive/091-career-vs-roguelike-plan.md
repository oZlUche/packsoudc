# 091 · 计划书：带剧情的生涯模式 × 肉鸽，怎么取舍

> 提议 ｜ 等作者拍板 ｜ 前一步：[090 开局屏暂存区等](../090-setup-stash.md)、[086 序章三提案](../086-demo-scope-proposal.md)、[世界观](../../worldview/worldview.md)

作者的话：既想做带剧情的生涯模式，也想做肉鸽；要一份评估风险、收益、成本的取舍计划，并收集近几年玩家画像里对剧情的重视程度（作者预判：比较低）。

## 〇、结论先行

1. **肉鸽是主体，剧情做「壳」不做「骨」。** 证据（第二节，附录 A / B）说这个品类的玩家把剧情排在玩法、构筑、重玩性之后 —— 零剧情的杀戮尖塔 / 小丑牌 / 死亡细胞简中好评 94～98%、近期评测提剧情 0%，「没剧情」不在任何差评理由里 —— 但**不是零**：做得好的剧情（哈迪斯式「每局一小口」）是加分项与口碑差异点，做得重的剧情（线性战役、长对话、追加的故事模式）是减分项与工期黑洞（背包英雄 1.0 的故事 / 城镇模式是最贴的反例：好评率掉到 79%，评测里提它的多在骂拖沓）。**没有终局 / 目标感**倒是会被扣分，所以「零叙事」也不是最优解。
2. **推荐方案 B：肉鸽本体 + 低剂量生涯壳。** 生涯 = 身份 + 章节推进 + 随局滴灌的碎片叙事 + 一个结局；不做脚本化的线性剧情关卡链。新机制只要一样（局外旗标进事件条件 / 后果），其余全是数据与文字。
3. **顺序：先把肉鸽本体做完（序章三、第一章内容、信仰道具族、局外成长），再做叙事最小集，中间设一道决策门**：用 demo 的跳过率与问卷决定要不要再往剧情里加钱。剧情永远可跳、二周目免看，任何时候能停在「壳」这一层而不留残件。
4. **不要做的：**有配音的对话、立绘演出、多结局分支树、必须看完剧情才解锁的玩法。这些是 C 方案（剧情战役）的成本大头，收益在这个品类里最不确定。

## 一、先说清两个词各指什么

「生涯模式」在作者这里可能是三样东西里的任意一种，成本差一个量级，所以先拆开：

| 含义 | 是什么 | 参照 | 成本级别 |
|---|---|---|---|
| **G1 叙事框架** | 有世界观、有开场与结局、道具 / 敌人 / 图鉴各有一句来历；不要求任何脚本关卡 | 杀戮尖塔、小丑牌（几乎没有）、死亡细胞（碎片） | 低：全是文字 |
| **G2 生涯壳** | 玩家扮演一个**身份**（奴隶探索者 / 自由民 / 军团士兵……），一局局地进诅咒之地，局外攒军功 / 钱 / 神的青睐换成长；章节按进度解锁；营地里的人随进度说新话；有一个终局 | 哈迪斯（每局回家一句新话）、暗黑地牢 1（庄园 + 章节 BOSS）、循环英雄（每局回营地推进一小段） | 中：一个小机制 + 大量短文本 |
| **G3 剧情战役** | 固定顺序的章节，每章预设图 + 脚本事件 + 角色对话，有分支与多结局；随机一局作为「自由模式」并列 | 月圆之夜、Griftlands、Inscryption | 高：内容量与演出量都是数倍 |

「肉鸽」在这里 = 现在已经在做的：随机图、随机搜索与掉落、一局定生死、局外仓库与解锁。**不存在「二选一」**：G1 已经在做（世界观文档、序章、图鉴），问题只是要不要 G2、以及要不要 G3。

## 二、玩家画像与证据：这个品类的玩家多在乎剧情

> 数据来自两轮资料搜集（国内 [附录 A](091-appendix-a-china-evidence.md)、海外 [附录 B](091-appendix-b-west-evidence.md)），来源与年份在附录里逐条给出；这里只放结论用得上的。硬数据与观点分开写。

### 2.1 全体玩家层面：剧情是「三分之一到一半的人在意、但排在玩法之后」

| 来源 | 年份 | 数据 |
|---|---|---|
| 伽马数据《2024 中国游戏产业趋势报告》 | 2023 | 36.3% 的用户选择游戏时受剧情影响（全体玩家） |
| 澎湃研究所玩家问卷（n=1027） | 2025 | 最看重的是玩法和画面；游玩目的里「体验剧情故事」约 50%，与「竞技挑战」持平，低于「放松娱乐」86.8% |
| Quantic Foundry 玩家动机模型（46.6 万样本） | 2024–2025 | 12 项动机里 Story 十年间「保持稳定」，从未进入任一性别的前两位首要动机；**没有公开 roguelike 品类的切片** |
| Humble × Interpret 独立游戏玩家调研（n>4800，6 国，非中国） | 2024 | 「剧情和叙事是重中之重」；独立买家偏好原创 IP 与有深度的故事，同时显著偏好 Roguelike / 卡牌构筑 |

**没有任何一份针对「肉鸽玩家」的剧情偏好调研**，国内外都没有。所以下面用评测与销量做替代指标。

### 2.2 评测里的替代指标：品类玩家不因「没剧情」扣分，做好了会被少数人重点表扬

Steam 简中近期评测各 100 条的关键词抓样（附录 A 第 4 节，2026-09-27）：

| 游戏 | 叙事投入 | 简中好评率 | 提及剧情类词 |
|---|---|---|---|
| 杀戮尖塔 / 小丑牌 / 死亡细胞 / 吸血鬼幸存者 / Brotato | 无或极简 | 94～98% | **0%** |
| 背包乱斗 | 无 | 88% | 1%（「剧情我都跳过」） |
| 逃离鸭科夫（搜打撤） | 碎片 + 4 结局 | 81% | 3%；提「任务」8%（多为「又臭又长」） |
| 暖雪 | 见闻录碎片 | 93% | 8～9%，7/8 正向 |
| 循环英雄 | 轻 lore | 90% | 10%，全部正向 |
| 背包英雄 | 1.0 追加故事 / 城镇模式 | **79%**（表中最低） | 13%，**多数在批评故事模式拖沓** |
| 哈迪斯 | 30 万词、全配音 | 97% | 16～18%，约 3/4 正向 |

读法：提及比例只跟「投入了多少剧情」相关（0% → 18%），跟好评率无关 —— 零剧情的几款好评率反而最高。「没剧情」没有出现在任何一款的差评理由里。海外的方面情感分析（附录 B 1.2）给出同样的结构：叙事被提及时多为正面，负评极少因「没故事」，**但会因「没有终局 / 目标感」**（Curse of the Dead Gods 被多家媒体集中扣分「无故事无终局」；Arc Raiders 任务线「没有结论」被抱怨）。

### 2.3 销量层面：无叙事作品占着品类前列，重叙事的回报集中在一家

- 近三年品类销量前列几乎全是弱叙事：小丑牌 500 万+、杀戮尖塔 2 首月约 500 万（估）、吸血鬼幸存者 600 万+、死亡细胞 1000 万、背包乱斗首月 64 万（中国占 48%）、Against the Storm 150 万。
- 重叙事成功的只有 Supergiant：哈迪斯 30 万词 / 2.1 万配音行，破 100 万；哈迪斯 2 40 万词，EA 一年半 200 万+。同为重叙事的 Griftlands（Klei，好评 93%）历史峰值在线只有杀戮尖塔的 1/7；Inscryption 卖得好，却因玩家大量要求而**反向追加了纯肉鸽无尽模式**。
- 哈迪斯自己的数据也说明「故事对多数买家影响不明」：70 万 EA 销量是在**没有结局**的状态下卖出的；首次逃出（看到第一段结局）的成就全局解锁率只有 48.8%；哈迪斯 2 的 1.0 结局引发大范围不满，官方重写 —— 一旦走重叙事路线，玩家就用故事游戏的标准审视你。

### 2.4 与本项目最像的先例：背包英雄追加故事 / 城镇模式，反馈偏负

Backpack Hero 在 1.0（2023-11）加了故事模式（重建小镇 + 寻母主线）并保留经典模式。Metacritic 76 / OpenCritic 63% 推荐；简中好评率 79%，是抓样表里最低的；简中评测里 13% 提到故事模式，多数是「剧情粗糙没啥必要」「故事模式把有趣的设计揉碎了放在平庸的局外养成里，太拖沓」「不如快速模式好玩」；海外媒体评「story mode falls flat」「小镇是硬塞的填充物」。它的教训不是「不该有故事」，而是**故事模式迫使玩家做重复的杂务（刷资源建镇）来换剧情**。

国内同类翻车：《无尽梦回》把主线绑在肉鸽战斗上，「对肉鸽玩家来说点跳过键都点得手累」；《克瑞因的纷争》卡牌玩家嫌跑图和剧情多；《明日方舟》集成战略「界园」的 NGA 主流意见是「一把两个小时就为了看几分钟剧情，肉鸽剧情才是最没用的」。

### 2.5 被夸的剧情有共同点：长在循环上，每局一小口

哈迪斯（死一次回家、每个人说一句新话）、循环英雄（每局回营地推进一小段）、暖雪（见闻录随进度解锁、剧情解释「为什么能无限复活」）、月圆之夜（每个角色一段短故事，TapTap「剧情跌宕」标签排第 3）。暖雪制作人的复盘最贴本项目的处境：「立项时准备了丰富的世界观与剧本，很想做经典 RPG，因经费与人力未能实现」「剧情围绕 Rogue 玩法做补全」「Rogue 游戏没办法深度表演刻画角色，用历史人物影子让玩家快速联想」「人手不足去做大量剧情演出 + 丰富战斗玩法本身就不现实」—— 于是把预算砸在 Boss 战，文字走碎片。

### 2.6 搜打撤这一支：要的是任务链与目标感，不是剧情

鸭科夫 100 条好评里剧情 1～2 条、任务 8 条、MOD 21 条；塔科夫 2026 年的官方「故事任务」问卷问的是任务是否重复、目标是否清楚、时限是否压迫；Hunt 把游戏内 lore 书搬去官网也没伤在线人数；暗区突围的剧情 PVE 被策划定位为「休闲零食」，价值主要在 PV 与二创传播。

### 2.8 证据的薄弱处

没有肉鸽玩家专属的动机调研；Steam 关键词抓样是单日 100 条近期短评，以词频代态度；没有能把「叙事滴灌」与「数值元进度」的留存贡献分开的公开数据；Griftlands「卖得差」只是社区推测加在线人数侧证。相互矛盾的一处：海外独立玩家调研说剧情「重中之重」，评测行为却显示几乎不影响评分 —— 可能是「声称偏好」与「实际行为」的差距，也可能是文化与品类差异；同时火山的女儿、月圆之夜证明中国玩家愿为剧情买单，但剧情一有瑕疵就集中挨打 —— **做了就必须做好，风险不对称**。

## 三、项目现状：为生涯模式已经有什么、还缺什么

这决定成本。盘一遍引擎与内容：

### 已经有的（可以直接当生涯模式的零件）

| 零件 | 现状 | 生涯模式里能当什么 |
|---|---|---|
| 章节串联 | `ChapterDef.next_chapter` / `requires_unlock` / `grants_unlock` / `hidden_by_unlock`（083、085） | 章节按进度解锁、通关顶上下一章 —— **生涯的骨架已在** |
| 预设图 | `line` 布局带 row（分岔再归一），两张序章都是 | 脚本化的剧情章节 |
| 事件层 | 10 种条件、21 种后果、`next_event` 串接、`intro_event`（077、083、084） | 对话 = 事件屏（文字 + 图 + 选项）；后果能给道具 / 改点 / 传送 / 开战 / 撤离 |
| 文本占位符与样式码 | `TextTemplate`（084） | 角色名、数值进对白 |
| 特殊道具（望远镜） | `keepsake`：不进背包、图鉴点亮、代表能力（088） | **剧情关键物 / 能力解锁的容器** |
| 角色 | 三个角色、技能、初始包（067、082） | 身份的载体 |
| 信仰 / 信力 | 六个信仰、行为攒点、阶（081、082） | 「神的青睐」这条成长线 |
| 局外 | 仓库、图鉴、解锁旗标 `MetaState.unlocks`、钱、战绩、三个存档位（061、089） | 生涯档 |
| 多语言 | `display_names` + `UiText`（088） | 剧情文本可本地化的前提 |
| 世界观 | `docs/worldview/` 约 5 万字设定，主线与信仰体系作者已定 | 一切文字的依据 |
| 现有内容量 | 40 个事件（约 2500 汉字）、50 件道具、10 个敌人、3 章、6 信仰、3 角色 | 序章两张 ≈ 24 个事件、约 1500 字 —— **一张教程章的文字量就这么多**，是估算的基准 |

### 缺的（做 G2 要补的）

| 缺口 | 做法 | 量级 |
|---|---|---|
| **局外旗标进事件** | `MetaState.flags`（字符串集合 / 计数）；条件 `has_flag` / 后果 `set_flag`；跟局外存档 | 1 天。G2 唯一必须的新机制 |
| 身份 | `CharacterDef` 加身份字段（开局文本、报酬形式、进出口文字）；或身份就是角色 | 0.5 天机制 + 文字 |
| 营地 / 基地的「人」 | 基地屏加一块「营地」：几位固定 NPC，各按旗标与进度挑一句话（哈迪斯的方式，没有演出） | 1 天机制 + 每人 20～40 句 |
| 章节完成态与结局 | `grants_unlock` 已能表达；结局 = 一个事件 + 一屏结算文字 | 0.5 天 |
| 剧情可跳过 / 已读标记 | 事件屏「跳过」+ 局外记已读；二周目默认略过 | 0.5 天 |
| 敌人 / 猎手 / 道具的一句来历 | `description` 字段已有（088），填字 | 纯文字 |

### 做 G3 还要再补的

对话演出（立绘、表情、镜头）、人物 / 好感 / 分支变量、章节脚本图 × N、多结局的测试矩阵、可能的配音与大量本地化。这一层每一项都是「新系统 + 新内容 + 新美术」，估算见第四节。

## 四、三个方案：成本、收益、风险

工时按「作者 + 现在这套开发方式」估，单位是工作日；文字量按汉字数。每条都给区间，取上限做预算。

| | **A 纯肉鸽 + 叙事框架（G1）** | **B 肉鸽本体 + 生涯壳（G2，推荐）** | **C 剧情战役为主（G3）+ 自由模式** |
|---|---|---|---|
| 做什么 | 把已定的世界观落到道具 / 敌人 / 图鉴 / 事件的一句话里；开场一段、结局一段 | A 的全部 + 身份 + 营地 NPC 随进度说话 + 章节按生涯推进 + 一个终局 + 旗标机制 | B 的全部 + 3 幕 × 3～4 章的脚本章节（预设图 + 脚本事件 + 对话）+ 分支与 2～3 个结局 + 演出 |
| 新机制 | 无 | 旗标 1 天、营地 1 天、身份 0.5、跳过 / 已读 0.5 | B 的 + 对话演出系统 5～10 天、变量 / 好感 3 天、章节脚本工具 3～5 天 |
| 文字量 | 0.6～1 万字（50 件道具 × 40 字 + 10 敌 × 80 字 + 事件 40 × 60 字 + 开场结局） | 2～4 万字（A + NPC 4 人 × 40 句 × 40 字 + 每章 intro / outro + 身份文本） | 10～20 万字（哈迪斯约 30 万字英文，Griftlands 更多 —— 见第二节） |
| 工时（机制 + 文字 + 接入 + 测试） | **3～6 天** | **12～20 天** | **60～120 天**（不含美术与配音） |
| 美术需求 | 无新增 | NPC 头像 4～6 张（可先用色块 / 剪影） | 立绘 × 人物 × 表情、场景图、UI —— 外包或长期 |
| 本地化（做英文） | 0.6～1 万字 | 2～4 万字 | 10～20 万字，成本按字数线性翻 |
| 对重玩性的影响 | 无 | 略正（进度感、营地新话是每局回来的钩子）；剧情可跳，不锁玩法 | **负风险**：脚本章节看一次就没了；玩家在「剧情章」里被剥夺随机性；自由模式反而成了「附赠」 |
| 收益 | 世界观有味道；宣发有东西可说；图鉴有内容 | 差异化标签（「有故事的背包搜打撤」）；留存钩子；Steam 评测里的「氛围好」一类正评；为 C 留门 | 若做成：叙事口碑与话题（哈迪斯那种）；若做不成：全部沉没 |
| 主要风险 | 几乎无 | 文字质量（写不好比不写更扣分）；世界观第六节 9 问没定就写不了 | 工期翻倍以上；剧情与随机生成打架；分支测试；美术与配音的外部依赖；**品类玩家不看**（第二节） |
| 可回退性 | — | 高：随时停在 A + 旗标，营地文本不再加，不留残件 | 低：半成品的战役比没有更糟 |

**成本对比一句话：C 的成本是 B 的 5～8 倍，收益的不确定性最高；B 的成本是 A 的 3～4 倍，但把「生涯」这个作者想要的感觉给出来了，并且给 C 留了门。**

## 五、风险登记册

## 六、收益评估：剧情在这个品类里能换来什么

按第二节的证据，把「收益」拆成能核验的几项，并标出每项要多少剧情才拿得到：

| 收益 | 证据 | 拿到它最少要做到哪一层 |
|---|---|---|
| **不被扣分的底线：有终局、有目标感** | 「没剧情」不在任何差评理由里，但「无故事无终局」（Curse of the Dead Gods）、「任务线没有结论」（Arc Raiders）会被集中扣分；搜打撤玩家对任务链敏感 | **G1 即可**：一条看得见的目标链（章节解锁 → 一个结局），几段开场 / 结局文字 |
| **少数人的强口碑** | 剧情被主动提及且正向的上限约 15～20% 的评测（哈迪斯 16～18%、循环英雄 10%、暖雪 8～9%）；TapTap「剧情跌宕」能排到第 3 标签（暖雪、月圆之夜） | **G2**：剧情长在循环上 —— 每局回基地有一句新话、章节 intro / outro、身份文本。文字量 2～4 万字 |
| **每局回来的钩子（留存）** | Kasavin：目标是「把死亡重开的痛苦拿掉」、让玩家感到「游戏在注意你」；玩家：「再死一次看看他们说什么 —— 比任何数值奖励都能留住人」。**但没有公开数据能把它与数值元进度的贡献分开** | G2 的营地对话表 + 旗标；预算内做得到，效果要靶点 demo 自己量（第八节） |
| **差异化标签与宣发素材** | 「有故事的背包搜打撤」是现在市面上没有的组合；暖雪的前传动画 543 万播放、暗区突围的剧情 PV 登 B 站全站第 7 —— 世界观的传播价值主要在**游戏外**（PV、二创、图鉴） | G1 + 世界观文档已有的 5 万字；不需要 G3 |
| **重叙事的上限（哈迪斯式话题与口碑）** | 只有 Supergiant 一家做到；Griftlands 口碑好但在线只有尖塔的 1/7；追加故事模式的背包英雄好评率反而最低 | **G3**，且要顶级执行力 + 数十万字 + 配音 + 美术；对本项目是不同预算级别的另一款游戏 |

**收益与成本对照的结论**：前四项收益用 A + B（G1 + G2，12～20 天、≤ 4 万字）就能拿到大部分；第五项要 C（G3，60～120 天起，不含美术配音），而且证据说它在这个品类里的兑现概率最低、失败时（半成品战役、剧情锁玩法）反而变成扣分项。**边际收益在 G2 之后急剧下降，边际成本在 G2 之后急剧上升**，这就是推荐停在 B 并设决策门的理由。

一个必须写进去的反向提醒：证据也说「做了就必须做好」（火山的女儿 3% 差评里 1/3 骂某条角色线；哈迪斯 2 因结局重写）。所以 B 方案的文字量宁少勿多，每句过读者的眼（第五节 R8）；写不好就退回 A，A 的收益（底线 + 宣发素材）并不依赖文笔。

## 十、追问：不用剧情当门，怎么兼顾新手教程与地图自由

作者：原设计是靠剧情解锁新地图（每张图玩法不同）；若放弃「必须过剧情才开新图」，教程与地图自由怎么兼顾，还是像杀戮尖塔那样放弃教程？

### 10.1 先拆开：剧情、教程、解锁顺序是三件事

原设计让剧情同时承担教程与解锁两个职责。第二节的证据反对的只是「剧情当门」，不反对有教程、也不反对有序解锁。

杀戮尖塔并不是「没教程也没门」：首局有提示气泡教程，角色靠打过一局解锁，卡池按局数放开，进阶靠通关解锁；小丑牌的牌组、哈迪斯的武器同样是玩出来的。这类游戏放弃的是**线性剧情门**，保留的是**玩法里程碑门 + 首局即时提示**。

### 10.2 做法

| # | 做法 | 引擎现状 | 量级 |
|---|---|---|---|
| 1 | **解锁靠玩法里程碑，剧情跟在后面。** 每张图一条一句话可预告的规则：「在魔法古迹撤离一次 → 沙漏开放」「沙漏里带回 300 币或击败核心 → 塔开放」。解锁那一刻再给章节 intro 事件：剧情是奖励，解释「为什么这片地开了」 | `requires_unlock / grants_unlock / hidden_by_unlock` 已有；缺「按局外战绩自动发解锁」（撤离次数、带回价值、核心击杀 → `MetaState.absorb` 时按 `ChapterDef.unlock_when` 发） | 1 天 |
| 2 | **序章保留，改成可选、可跳、有奖不锁。** 新档第一次开局问「先走一遍序章（约 15 分钟）还是直接开始」；主菜单留「教程」入口。序章通关给图鉴点亮、望远镜这类特殊道具，不锁地图 | `skip_setup / intro_event / starting_keepsakes` 已有；改 `chapter_01.requires_unlock` 为里程碑；主菜单 + 首次提示 | 1 天 |
| 3 | **每张图自带「第一次」。** 首次进图弹一页「本图规则」卡（≤ 3 条：塔「上了一层不能下」、沙漏「撤离点在对侧」），暂停菜单里能再看；加节点浮窗与 intro 事件。「怎么摆」（邻接、套装）也在这里就地教，不再靠序章三 | `intro_event`、`tooltip_texts`、暂停菜单（090 七·二）已有；规则卡是一个事件 + 一页 | 0.5 天 + 文字 |
| 4 | **给老手一个开关。** 设置里「全部解锁」（小丑牌有），或存档位级别的「自由模式」，代价是成就不计 | `MetaState.unlocks` + 设置一项 | 0.5 天 |

### 10.3 不推荐的两端

- **完全放弃教程**：搜打撤这个循环（搜、暂存区、走了就没、撤离）不像出牌那么自明；demo 反馈里已经出现过「不知道走了东西就没」。5～15 分钟的可选序章值得留。
- **序章做成必经门**：证据说会被跳过、被骂；而且把最不确定的剧情投入放在了流失最高的前 15 分钟。

### 10.4 用 demo 数据定

序章选择率与完成率；直接开始的玩家在第一张图的撤离率。若跳过序章的人撤离率明显更低，说明 10.2 第 3 条的就地教学不够 —— **加规则卡与浮窗，不加长序章**。

### 10.5 对前面方案的影响

方案 B 的「章节按进度解锁」改为「按玩法里程碑解锁」，剧情只挂在解锁那一刻与基地；序章三（086）的「摆位与营地」拆成第一章的规则卡与浮窗文字，不再是必经的第三段。总工时不变（机制合计约 3 天，已含在阶段 3）。
