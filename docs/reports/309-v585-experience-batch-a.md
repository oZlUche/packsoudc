## 二、本批改了什么（E01）

1. **教学供给不再被换成赐福版**：节点内容里写死的必掉（`guaranteed_drops`）原样给出，只有随机掉落照旧按概率换赐福版。普通地图的祝福替换和精确配方都没动。搜索里的固定收获（毒药瓶）本来就不走替换。
2. **新条件 `recipe_ready`**：在棋盘和地上数某张局内配方的原料，件数够才算凑齐。赐福异体不能顶替（配方本来就按 id 精确匹配），锁着的件也不算（和 Fusion.spendable 一致）。`missing` 反过来用。
3. **守卫门口三条路**：
   - 正门「进入战前准备」：手里有涂毒匕首才开（没变）。
   - 退路改名为「当前没有可用的合成组合，直接准备战斗」：只在凑不齐原料、也没有成品时出现。不再写「没有匕首」，选了就记 `tut_craft_skipped`。
   - 新增「补领一把普通匕首」：只在有毒药、没有普通匕首、没有成品、也没领过的时候出现（服务旧档里只有赐福匕首的情况）。给一把普通匕首放到地上，记 `tut_knife_given`，然后回地图，合成完再来。这个机会只有一次，丢掉或卖掉匕首也不再给。赐福匕首原样不动。
4. **三种状态分开记**：持有成品可以进门；真正合成过照常由合成记账（局内配方知识和战绩里的 crafts）；选了跳过只记 `tut_craft_skipped`，不算合成过。

## 二·B、B 批改了什么（E02 / E03）

1. **战记的防御说法对齐 305**：格挡和护甲分开写，格挡写「格挡抵消 X」，护甲写「护甲吸收 X」，最后写这一下真正扣的生命（「生命 −X」，一点没扣就写「生命未受损」）。穿透的伤害多写一句「穿透护甲」。数字都从伤害事件里取，narrator 不再自己算减伤；伤害事件新带了 `penetration` 标记。中英文同口径。
2. **守卫教学按真实圆盾讲格挡**：守卫带的是圆盾，所以改成「它举着圆盾：格挡会把刀剑的每一下抵掉一截；涂毒匕首留下的毒是身上自己发作的，不吃格挡」。搜索时那句「前面那个守卫披着甲」也改成了「举着盾」。没有给敌人加护甲。
3. **生命和体力分开说**：第一次战前准备的事件末尾加了一句「战斗里掉的是这一场的生命，下一场重新满血；打输了才扣地图上的体力」。
4. **反应讲解改成事件驱动**：头一回打出反应时不再当场停住回放，而是等同一时刻的事件都放完再停。停住后讲解指向反应弹出的那行字，而不是状态那一排，因为状态可能已经被反应吃掉了；弹字的淡出也跟着停，放开后再接着淡出。弹字不在时退回指向挨反应那一方的状态行。拖动时间轴会取消还没弹出的讲解。「整个存档只讲一次」的记录和回放重看都没改。



## 二·C、C 批改了什么（E04 / E05）

1. **商店首访提示**：每个存档位第一次进店时说一句「双击挑选商品；点自己的钱袋补差价；按成交确认」，记在局外的 `coach_seen`（`shop_first_visit`），之后不再弹。点自己的钱袋补差时：桌上已经不差钱，就说「不用补钱，按成交就行」；钱不够，就照旧把钱全放上去，再说还差多少。交易规则和撤销挂账没动。
2. **教程进度**：多步的教程纸条在字后面写「　2/4」，一步的不写。
3. **首轮强制说明盘点**（序章，第一场战斗看完之前，按出现顺序）：

| 出现处 | 强制几步 | 讲什么 | 玩家要做的第一个动作 |
|---|---|---|---|
| 进图事件 tut_intro | 1 页 | 背景、怎么走 | 点相邻的点 |
| 地图教程 prologue_map | 4 步 | 体力、货币、背包键、放大镜 | 同上（4 步都在动手之前） |
| 搜索事件 tut_search_1 / again / done | 3 页 | 搜索、地上、护甲 | 按搜索、拖进包 |
| 背包教程 prologue_bag | 4 步 | 放包、转向 / 右键放回、双击挪、底下三枚签 | 把包放上棋盘 |
| 战前事件 tut_battle | 1 页 | 战前准备、生命与体力 | 进战前准备 |
| 战前教程 prologue_prebattle | 3 步 | 对手棋盘、估算签、按开战 | 按开战 |
| 战斗教程 prologue_battle | 4 步 | 时间轴、播放键、状态行、继续 | 看回放 / 按继续 |

第一次自己动手（点相邻的点）之前要读 1 页事件和 4 步地图教程；第一次开战之前一共是 5 页事件和 11 步教程。动作驱动的改造（例如「先把包放上去」等玩家真放了才进下一步）会改动这些步骤和文字，已请作者定范围。
