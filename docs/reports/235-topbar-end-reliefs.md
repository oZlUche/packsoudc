# 235 · 方案：顶端栏两头的浮雕 —— 去掉，还是给它功能

> 架构设计线程，2026-10-22。作者 10:10 在美术设计原话：「我又担心两侧的浮雕图案会误导玩家，以为是按钮，让架构设计头脑风暴一下应该去掉，还是干脆让两侧的浮雕拥有功能。」美术设计把问题转来，附了三个方向。本文只做方案；美术按推荐出图，代码由执行落。
> 同一条里作者还说回纹带要沿日晷弧边连通 —— 那是画法，美术已接，不在本文里。

## 〇 一句话

**两头都做成真按钮，同一条规矩**：右头的背包浮雕就是背包按钮（右槽那枚小背包钮并掉），左头改成本局菜单的入口（现在暂停菜单只有 Esc 能呼出，屏上没有门）。凸起的石块 = 能按，和凯撒 3 的斜面规矩一致；浮雕既然像按钮，就让它是按钮。要是作者不想给左头功能，退回方向 2（两头浮雕平刻、不凸起、悬停无反应），千万别一头能按一头不能。

## 一、现状（v4.03 核过）

- 顶端栏是读数层的一件（`hud_bar`，190 的长槽皮）；左右各留 `bar_side()` = max(16, 屏宽 × 0.1)，组在中间排。美术的丙款（`art/ui/topbar/mocks/stone3_bar_player.png`）两头各一块凸起石块（左 x 8..88 双剑、右 x 1512..1592 背包），心 / 金币 / 信力紧贴左块排，日晷在正中和栏连成一块石头。
- 右槽（`HudLayout.BAR_RIGHT`）：`bag_button`（打开背包窗，`hud/icon_bag`）、`reopen_button`（放大镜，重开上一扇窗，没得开时灰）、`skills`（166 起对玩家隐藏）、`dev_drawer`（调试台箭头，只在 `DevGate.on()`）。玩家版右槽 = 背包 + 放大镜；开发版 = 背包 + 放大镜 + 箭头。
- 读数层可以摆（150）：玩家能拖、能藏任一件，包括 `bag_button`；藏了之后屏上就没有背包入口（只剩事件屏里的 B 键和各屏自己的按钮）。
- 暂停菜单（090）：Esc 呼出，继续 / 设置 / 存档并回主菜单；屏上没有按钮。
- 保存的布局文件里出现仓库不认识的 id，整份退回默认（`HudLayout.from_dict` → `load_for`）—— 并掉 `bag_button` 时要留意。

## 二、三个方向比较

| | 1 素面石块 | 2 平刻浮雕、不凸起、无悬停 | 3 两头都是按钮 |
|---|---|---|---|
| 玩家会不会误按 | 不会（什么都没有） | 会少一点：没有凸起就少了「能按」的暗示，但一个图案摆在工具栏两端仍会被点一次；点了没反应，学一次就记住 | 不会误：点了就有事发生，和它长的样子一致 |
| 和现有按钮重不重复 | 不涉及 | 不涉及 | 右头和小背包钮重复 → 并掉小钮，右槽少一件；左头不和任何东西重复（暂停菜单屏上本来没门） |
| 玩家版 / 开发版 | 一样 | 一样 | 一样：两头固定，开发版只多一枚箭头在右槽 |
| 代价 | 美术改图 | 美术改图 | 美术出两头各三态；执行一单（栏两头接点击、并钮、布局迁移、暂停菜单入口） |
| 丢了什么 | 两头各 80 像素空着，栏头轻 | 装饰保住，但是「摆着好看的图案」 | 左头的双剑要换成和功能对得上的纹样（§三.3） |

- **1** 最省，但两头各 80 像素的石块只剩收边，栏头发轻，而且作者 09:48 刚把两头定成浮雕，没必要全退。
- **2** 是不想加功能时的正解：浮雕平刻进栏面（像 224 账单那种半透明光影），不单独凸起，悬停、按下都不响应。守住一条：**凸起 = 能按**，平的 = 装饰。这条和凯撒 3 的参考一致（框、按钮凸，列表凹），以后所有石面控件都按它走。
- **3** 最好：两个最容易被误点的位置变成两个最常用的门，右槽少一件，暂停菜单第一次有了屏上入口，80 × 80 的石块也比 48 的小钮好点。

## 三、推荐细则（方向 3）

1. **右头 = 背包**。整块石头（含浮雕）是热区；按下石块变凹（斜面翻转，亮暗对调），松开弹回；悬停只提亮浮雕一档，不加色不发光（按钮要平的那条是给小功能钮的，石块按凯撒 3 的斜面来）。悬浮窗 `背包`（沿用 `map.bag` 那套字）。右槽的 `bag_button` 删掉：`HudWidgets.KINDS` 去掉它，`HudLayout` 加一张 `RETIRED` 名单，读到旧布局里的 `bag_button` 静默丢掉而不是整份退回默认。
2. **左头 = 本局菜单**（就是 090 的暂停菜单：继续 / 设置 / 存档并回主菜单）。点它 = Esc。有了门，Esc 照旧。
3. **左头的纹样换**：双剑读作「打」，按下去出来的是菜单，对不上。换成**军团鹰**（美术规范 Imperial 板①：鹰爪抓四元素阵）—— 「军团」= 这一局、这支队伍，徽记 = 总入口，和多数游戏「徽记 = 菜单」的习惯一致；右头背包正好是 234 的游戏图标，左徽右包，一头是「这局」一头是「身上的东西」。要是作者更想留双剑，也行，悬浮窗写 `本局` 就不会迷路，只是第一次点会意外。
4. **读数层不管两头**：两头是栏皮的一部分，不进 150 的布局（不能拖、不能藏），所以玩家再也藏不掉背包入口。
5. **缩放**：两头随栏高等比（栏 88 高，石块 80），不随屏宽伸缩；`bar_side()` 改成从栏皮的 json 读「两头宽 + 间隙」，不再用屏宽 × 0.1（作者 10-17 的「往中间收」在丙款里已由美术的摆位代替，心紧贴左块）。
6. **开发版**：右槽剩放大镜 + 箭头；玩家版剩放大镜一枚。放大镜灰着的时候孤零零一枚，可以接受；真嫌空就把放大镜挪到日晷右边，另说。
