# 214 头像与铭牌尺寸：肖像位 64 → 96，开局角色卡单独大头像，源图 256

作者 2026-10-20 12:43：「现在需要给几个角色和敌人设计头像，先看下当前排版，是否有必要扩大铭牌在界面中的面积？」本篇是排版核查与尺寸建议；美术画头像、执行改尺寸都等作者点头。

## 1 现状

- 铭牌 `Nameplate`（157 / 157 补充二，`ui/widgets/nameplate.gd`）：铜狗牌底（`nameplate_bronze.png` 九宫格，margin 22 / 18 / 22 / 18，深底亮字），一行三块：左 **肖像位 64×64**（`PortraitSlot`，框 `portrait_frame.png` 外扩 4 px，没图放 `portrait_empty.png` 剪影）、中 名字 20 号 + 副行 13 号、右 徽记位 32×32（阵营，至今空着）。整块约 100 px 高。
- 用在三处：战前准备（左对手 / 右自己两列顶上）、战斗回放（两方面板顶上，`BattleView.set_nameplate`）、开局第一页的角色卡（`setup_screen._rebuild_card` 第一行）。
- 肖像文件：`assets/portraits/{characters,enemies}/<id>.png`，README 写 64×64；目录现在是空的（一张都没有）。
- 从 `screenshots/nameplate_bronze/after_*.png`（1280×800 缩图，根窗口 1600×1000）量：战前两块铭牌分别约 410 / 840 px 宽；战斗两块各约 560 px 宽；铭牌下面是血条 / 耐力条，再下面是事件行与棋盘，棋盘区右侧与事件行都有余量。
- 要画的量：角色 3（安德烈乌斯 / 马库斯 / 布鲁图斯），敌人 30（人类 20、机关 5、魔兽 5）。

## 2 判断

**有必要，但只扩肖像那一块，不动铭牌的宽度与字。** 64 px 和地图节点图标一个大小，只够认出是个人；要让头像有辨识度（脸、发式、头盔、机关的面罩、魔兽的头），96 px 是能看清五官的下限。名字 20 号、徽记 32 都够用，铭牌变宽没有收益。

开局第一页另算：那是玩家唯一会盯着角色看的地方，角色卡上值得放一张**大头像**，不靠铭牌。

## 3 方案

| 处 | 现在 | 建议 |
|---|---|---|
| 源图 | 64×64 | **256×256**（`@2x/` 512），正方形半身像，透明底或自带暗底；一次画完，各处按位子缩放，以后位子改尺寸不用重画 |
| 战前 / 战斗铭牌肖像位 | 64 | **96**（铭牌高 100 → 132，+32 px；两屏竖向都有余量，见 §1） |
| 开局角色卡 | 铭牌里 64 | 铭牌上方加一块 **160×160** 独立肖像位（`PortraitSlot.new(160, face)`），铭牌照旧 96 |
| 徽记位 | 32，空 | 不动（阵营数据有了再填） |
| 地图屏敌人提示 / 图鉴 | 没有 | 本篇不加；以后按 64 位复用同一张源图 |

- `Nameplate.PORTRAIT_SIZE` 64 → 96；`PortraitSlot` 不改（边长是参数）。`portrait_frame.png` 是九宫格，拉到 96 / 160 都行；美术确认一下 4 px 外扩在 160 上够不够粗，不够就给一张 `portrait_frame_l.png`。
- 美术画头像时按 157 风格基准（墨线平涂），角色三张先画，敌人按出场频率：人类 20 → 机关 5 → 魔兽 5。文件名就是 `<id>.png`，放进目录即生效（`Nameplate._face` 按存在性加载，不用改代码）。
- 战斗屏两块铭牌加高 32 px 后，`CombatantPanel` 下面的棋盘区往下挪 32；`BattleView` 的面板是 VBox，不用改布局代码，只要确认 1600×1000 下「跳过并继续」按钮不被顶出去（从截图看底部还有约 40 px）。

## 7 落地（v3.58，2026-10-20）

按 4.1～4.4 推荐落地（肖像位 96、开局大头像 160、源图 256 + @2x 512），和方案的差别一处：

1. **开局大头像放在铭牌左边同一行，不在铭牌上方**。放上方时角色卡整张高约 170，1600×1000 下卡底右角压到「回主菜单」按钮；改成一行（160 头像 + 铭牌竖向居中）只多 28 px，三个角色都不碰按钮。
2. 战前准备、战斗回放截图核过：铭牌 +32 后「开战」「跳过并继续」都还在框里。
3. 美术图还没交：`assets/portraits/{characters,enemies}/<id>.png` 放进去即生效，没图照旧是剪影。

## 8 头像定稿落地（v3.60，2026-10-20）

美术设计交图（`art/portraits/final/`）。作者 2026-10-20 15:26 选乙「罗马铜币侧像」，并说「既然选择钱币的话，肖像框可以改成圆形的」。

1. **头像**：3 个角色、30 个敌人的 256 图拷进 `assets/portraits/characters|enemies/`，文件名就是 id（敌人 id 和 `data/authoring/enemies` 逐个对过）。`@2x`（512）没拷：游戏只读 256，显示最大 160，用不上，留在美术源目录。
2. **圆框和空位**：`assets/ui/portrait_frame.*` 换成深铜圆框，json 的 `margin` 是 `[0,0,0,0]`、`inset` 是 0，`PortraitSlot` 原有代码读到 0 就整张等比缩放、不外扩，不用改代码。`portrait_empty.*` 换成一枚磨平的暗旧币。徽记位（32）用同一张框，变成一个小圆圈。
3. **mipmap**：源图 256 缩到 96 / 160 / 32，不开 mipmap 币缘的细纹会起锯齿。
   - 导入：这 33 张头像和框、空位的 `.import` 都改成 `mipmaps/generate=true`。以后新加头像，照抄已有的 `.import`。
   - 显示：`PortraitSlot` 自己设 `texture_filter = LINEAR_WITH_MIPMAPS`，图、占位、框跟着它。
4. 测试 157：框外扩改按 json 的 `inset` 验（原来写死 4）；战前名牌那条从「没图先放占位」改成「有图放图、没图放占位」；加验肖像位按 mipmap 缩小、框图导入开了 mipmap。
