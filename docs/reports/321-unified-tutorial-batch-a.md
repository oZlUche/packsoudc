# 321 统一教程 A 批：三段都回基地、出战只开最早没通的一段、切片也走教程

> 日期：2026-11-18。依据：[统一教程方案](../plans/2026-11-18-unified-tutorial-and-base-return.md) §2、§8、§11 A 批、§12.1（PR #651）。作者 2026-11-18 09:24：「根据 PR651 的新增方案，优化切片 demo」。
> 本批只改流程与状态，不改教学内容、奖励和界面文案；B～F 批见第五节。

## 一、改了什么

| 地方 | 以前 | 现在 |
|---|---|---|
| 结算页「继续」（`ResultScreen.proceed`） | 有下一段教程就直接开 | 一律回基地 |
| `GameFlow.start_next_chapter` | 自动入库后直接开下一段 | 删掉；`next_chapter()` 只留作教程先后 |
| 主菜单「继续」（`continue_game` / `continue_run`） | 没有局内存档时直接开下一段教程 | 有存档读档；没有就进基地 |
| 出征页「出战」（`new_run_target`） | 教程没全通就从第一段重来 | 开最早一段没通的（`next_tutorial`） |
| 开局屏能列的章（`available_chapters`） | 列不出来就全列 | 教程没全通只列那一段，兜底也不绕过 |
| 开局后端（`start_refusal`） | 不看教程 | 教程没全通时开别的章被拦（`tutorial_allows`） |
| 开场一问选【不需要】（`decline_tutorial`） | 补发后开新一局（落到开局屏） | 补发后回基地 |
| 章节档案（`ChapterDef.profile`） | 空 / `slice` | 新增 `shared`：三段序章两档都列 |
| 切片地图 `slice_ruins` | 新档直接能出 | 要 `prologue3_done`（三段通了或跳过） |

## 二、切片老档

切片以前没有教程。出过远征、没问过教程的切片档，第一次读档时补上第三段的解锁，并记 `slice_legacy_open`：常规出战不被锁，不发教程金币和物品，不算跳过。正式版老档不受影响。

## 三、测试

- 新增 `tests/run/test_unified_tutorial_a.gd`：切片新档只开第一段、切片地图被锁、跳过后开；老切片档不锁、不发奖励；「继续」和跳过都回基地。
- 旧断言按新规则改了：`test_prologue`（结算回基地、常规图被拦）、`test_tutorial2`（出战开最早没通的一段，「继续」不开章，读档照旧）、`test_skip_prologue_221`（跳过回基地）、两份切片 313 测试（切片表里多了共用的三段）。
- 直接开常规图的几个测试（087、218、236、267、277 ×2）先把教程记成通过（`flow_support.pass_tutorials`）；它们测的不是教程。
