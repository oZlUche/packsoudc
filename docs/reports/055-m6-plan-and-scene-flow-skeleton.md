## 三、几条决定

**状态机是纯逻辑的，导演只是皮。** 架构文档 2 节的草图里 `GameDirector` / `RunState` / `EventBus` 是三个 autoload；1 节又说核心逻辑层没有全局状态。
按后者：`GameFlow` 是 `RefCounted`，只发 `screen_changed(screen, payload)`；`GameDirector` 是主场景的根，不是 autoload；没有 EventBus，
每一屏订阅自己要的信号。测试驱动 flow 走完整条流程（开局 → 打一场 → 拾取 → 存档 → 继续 → 撤离 → 结算 → 局外）一屏都不用画，
导演另有一组帧测试证明它真的换屏。

**节点事件排成队。** 事件是同步发生的：`step_to` 一步之内可能连着来「打了一场 → 掉了东西 → 进账」。flow 把它们排成队，走完这一步按顺序看；
一步之内可能来两份战利品（打赢的尸体 + 搜索收获），`RunState` 已经并成一份，队里留一个；一局结束了只有那一场的回放还值得看，其余跳过，最后一定是结算。
搜索 / 商店会话结束由 flow 自己接着往下走（`session.ended` / `closed`）—— 连接顺序保证 `NodeEvents` 先处理完（遭遇的那一场、收获），flow 再看队。

**开局装备是内容，不是常量。** 沙盒里的 `KIT` 常量改成 `LoadoutDef`，走管线，排在道具之后（清单对着道具查）。校验比引擎严格：每件得存在、至少一个包 ——
棋盘上只有包里的东西参战（3.2），没有包一格都用不了。只是清单不写位置：包先上棋盘、其余往包里放、放不下进暂存区，摆法出发之后在地图上按「背包」调。

**结算只算棋盘上的。** 暂存区里的道具 = 不存在（3.4），撤离时连同里面的东西一起消失；结算屏提一句「遗落了 n 件」，是提示不是挽留。
背出去的是棋盘上的全部（含包）按价值（6.4）计。

**保留规则只在一处。** 15 节第 4 项「撤离后的保留规则」现在的假设是：撤离 = 棋盘上的全进仓库、钱全带出；战败 = 全失。
这条规则只写在 `MetaState.absorb()` 里，作者改主意时改那一处。钱带不带出去文档没说，这里先带（搜打撤的惯例），列进「留给作者定的」。

**仓库有自己的 uid 空间。** 每局的 uid 从 1 重编，第二次撤离的东西和第一次撞号；进仓库时重新编号，测试守着「撞号的也全进了仓库、uid 两两不同」。
将来从仓库带进一局时再造新实例（M6-3）。

**全屏铺满要 `set_anchors_and_offsets_preset`。** 程序造的 Control 用 `set_anchors_preset(FULL_RECT)` 只改锚点、偏移按当前矩形折算 ——
父节点已经有尺寸时子节点算出来是零大小，整屏挤在左上角一千像素里。沙盒没踩到是因为它们的根在 `_ready` 时父节点还没量过。
同理背包面板是 `MarginContainer` 而不是 `Control`：普通 Control 不从子节点算最小尺寸，放进竖排布局会被压成零高。

## 四、验证

```
bash tools/test.sh
通过  6556 项断言，39 个套件，耗时 77 秒
```

- 开局装备：导出再导入逐字节一致；空清单 / 不存在的道具 / 没有包都报错，单独导一份时对着道具查的两条跳过；三份作者文件导得进、是往返不动点、资产在；
  开局按清单发 —— 清单里几个包棋盘上就几个包，其余不在棋盘就在暂存区。
- 结算与局外：没结束算不出账；撤离 = 棋盘上的全部、价值 = 每件 `ItemValue` 之和、暂存区记成遗落；战败没有背出去的、没有钱；进仓库件数 / 钱 / 累计 / 单局最高 /
  几局几撤几败；撞号的也全进仓库、uid 两两不同；存档往返逐字节相同、版本不对 / 坏文件 → null、真写 `user://` 再读回。
- 状态机：主菜单 → 开局屏 → 地图（挑出生点）→ 走上战斗点 → 回放（带结果、双方单位、对手内容）→ 战利品全拿 → 地图；存档回主菜单 → 继续上次还站在原地、计数跟着存档。
  搜索点与商店是叠层，会话结束流程自己回到地图。打输战败：回放 → 结算（战败）→ 局外记一败、这一局的存档删掉、再按一次不记两遍。
  走到最近的免费撤离点撤离：一路把叠层看完，结算（撤离）的背出去的 = 棋盘上的、局外仓库里就是那些、钱带出来、局外存了读回来一样。
- 导演：真的换屏 —— 主菜单 → 开局屏（挑装备、定种子、出发）→ 地图（挑出生点、背包叠上 / 收起）→ 战斗叠层（地图还在底下）→ 看完撤掉 → 存档回主菜单 → 继续 → 局外屏。
- 截图（`tools/capture_scene.gd`，`DEMO_SCREEN=setup / map / bag / battle / result / meta`）：六屏都画出来了，没有脚本错误。
