## 一、逐条

### 1. 「为什么出现了敌人倒下两次的情况，敌人第一次倒下时血量还没归零」

**排查**：截图里 1.40 秒神射手「受到 18 → 倒下」，之后还在叠毒、还在受伤，2.60 秒又「倒下」。原因：血到 0 时发 `DIED`，但**没有把它记成死的**；它身上的伤药（`on_resource_below 40%` 回 25）在同一时刻触发、把血治回来 —— 模拟器只看 `hp > 0` 判存活，于是它活过来接着打，直到第二次被打死。回放面板显示的是治疗之后的血，所以看起来「倒下时血没归零」。
**改**：**倒下是终局**。`CombatantRuntime.dead` 记死（`mark_dead()` 只第一次返回真），`is_alive()` = 没死且血 > 0；伤害管线与资源效果对死的单位不再扣、不再治、不再发第二次 `DIED`。测试：长剑 vs 匕首 + 两瓶伤药、血 12 的对手 —— 只倒下一次、倒下后没有回血、终局血 0。

### 2. 「神射手的装备配置应该是远程武器才对吧？根据敌人的名字确认身份，分配相关道具标签，只从相关道具中随机选择，并根据档位获得不同的道具」

**改**（`EnemyDef` 两个新字段，[EnemyPlacer] 全程过滤）：
- **`item_tags`（身份标签）**：这个身份能背的道具标签；流派池、通用池、补件、保底武器**都只在带任一身份标签的道具里抽**（`EnemyDef.allows_item`）。空 = 不限（老路）。
- **`signature_by_strength`（按档位换招牌）**：档位 → 那一档起必带的道具（取 ≤ 实际档位的最高一档），和 `signature` 一起算招牌（`signature_at(strength)`）。
- 导入器：招牌必须在身份圈里；身份标签得圈得住东西，圈里没武器警告。
- **数据**（按名字定身份）：神射手 `ranged / ammo / consumable`，流派改 `ranged`，招牌 0 档短弓 / 1 档长弓 / 2 档赐福的长弓，自己的包（两个长条包 + 小包）与 6×4 棋盘（长弓 1×4 只装得进长条包）；拾荒者 `rapid / melee / consumable / tool / material`；屠夫 `bleed / melee / consumable`；蛮兵 `barbarian / bleed / burst / gear / consumable`；守卫 `imperial / shield / gear / consumable`；核心守卫 `enchanted / imperial / heavy / shield / part / consumable`；重击手 `burst / heavy / consumable`；持符者 `sigil / shield / rapid / melee`；游兵 `rapid / melee`；药师 `consumable / tool / reagent / material / rapid / melee`。
- 测试：每个有身份标签的敌人 × 四档 × 三个种子，背的每件都带身份标签、都有武器、带着这一档的招牌；神射手不背匕首、背箭矢；往返与校验。

### 3. 「背包也要可以放入暂存区或者容器，背包可以替换背包」

**改**（[DragLayer]）：
- **包进暂存区**：列表没有坐标，装不下「包 + 内容物的相对位置」—— 现在照样能进：包一行、内容物打散各一行（`items_shed`），得都装得下。放到棋盘外（= 暂存区）同样。
- **包进自由容器**（战利品箱、出售区……）：包当普通物品放进去，内容物脱落进暂存区；预览标「有代价」。
- **包替换包**：手上的包（空的或带东西的）压到棋盘上另一个包上：新包每格在界内、压到的包恰好一个、压到的普通道具全是那个包的东西、那些东西有地方去（暂存区）→ 旧包连内容物摘下，新包（连自己的内容物）放上，旧包的东西进暂存区，**旧包拿在手上**（和顶替一件道具同一套感觉）；预览标着要替换谁。
- [InventoryService] 也会搬带东西的包（尸体容器里包当背景时「全部拾取」要搬得动）：内容物先各自进目标、再进包；`transfer_all` 把作为包生效的排最后。

### 4. 「战利品里的非背包道具可以放在背包上，背包不用探明直接作为背景显示」

**改**：`DropResolver.corpse_of` —— 敌人的包掉了就**照它的棋盘摆**：包按原位当背景，掉的道具回到原位（在包上），珍宝与原位被占的自动找位；没有包掉下来或摆不下走老路（自由容器，会加高）。[LootView]：包一开始就亮着（不参与揭示），上面还有没亮的东西时包拖不走。两份战利品并成一份时（搜索收获 + 遭遇的尸体）往一块够大的自由容器里搬，放不下加高，一件不丢。

### 5. 「暂存区改为每个节点独立保留，玩家可以返回拿取（修改相关的提示文本）」

**改**：`RunState.node_storages`（点 → 留着的东西，跟存档）。离开一个点时暂存区里的东西**留在那个点**（`storage_dropped` 的含义改成「留在了那里」），回到那个点（走一步、传送、头一回踩上）取回暂存区（新信号 `storage_restored`）。撤离仍不带走暂存区里的东西。提示文本全改：背包面板「留在这个点（回来能拿）」、离开前的确认「走了它们就留在这个点上……回到这个点还能拿」、按钮「照走，留在这里」、地图日志「留在了那里（回来能拿）」「回到点 X：留在这里的 N 件回到了暂存区」、合成放不下的提示、三个教程事件的文字。

### 6. 「道具名称过长会提前暴露真实身份，改成未探明前完全不显示名称；扩大所有区域和格子的显示大小，左上角战利品 / 搜索容器区域，右上背包，右下暂存区」

**改**：[InventoryView] 多一个可覆盖的 `_label_visible(item)`，[LootView] 没亮的不画名字（剪影上什么字都没有）。格子 `InventoryView.CELL` 48 → 60。[InventoryPanel] 改成**棋盘在上、暂存区在下**（暂存区列表跟棋盘一样宽），容器屏因此就是左上容器、右上背包、右下暂存区；地图上的背包浮窗、事件屏、战前准备屏、商店屏跟着这个布局。测试里写死的 48 改成读 `InventoryView.CELL`。

### 7. 「道具的稀有度不通过边框，而是通过整个格子的底色体现；在仓库和结算画面也要可以通过鼠标悬浮查看道具具体属性 —— 道具这个实体本身就拥有悬浮窗显示能力」

**改**：`ItemPainter.body_color` = 稀有度色往面板色压一点（整格底色就是稀有度），描边同色稍亮，名字的颜色按底色明暗选（白 / 金底深字，其余浅字，`label_color`）。**容器视图自带悬浮窗**：[ContainerView] 进树之后自己找一个 [HoverTip] 登记（`HoverTip.ensure_for`：沿祖先找谁的直接子节点里有悬浮窗就用它，一路没有就在最顶层的 Control 祖先下造一个）—— 仓库、结算屏、开局屏、商店栏位……停在道具上都能看属性，屏自己造的悬浮窗优先、不会重复。`auto_tooltip = false` 可关。

### 8. 「当鼠标移动到信仰上时，悬浮窗显示具体效果和信力增长方式」

**改**：[FaithTooltip.describe]（神与说明、**信力怎么涨**（行为各一句）、阈值与现在几点第几阶、这个信仰的道具各阶解锁什么、休眠规则一句）。地图 HUD 与背包面板的「信仰：X　信力 …」单独成一个标签，停上去开悬浮窗。

### 9. 「max power 有什么用」（作者问）

**答**：`max_power` 是一个属性键，有它就派生出 `power` 资源（和 `max_shield → shield` 同一机制）。现在带它的道具：魔晶石（30）、破碎的魔晶石（10）、封存的电池（20）与能量核心（60）；**消耗它的只有封存的无人机**（`resource_key: power`）—— 所以在正式内容里它目前什么都不做，魔晶石只是多了一条没人用的资源。世界观文档（三节）说过「魔晶石 = 元素之力的容器，power 就是它，名字改成魔力」，而属性表里另有 `max_mana` / `mana`。**建议**（等作者定）：二选一 —— 把 power 并进 mana（魔晶石改给 `max_mana`，将来的法术书 / 阵盘消耗 mana），或者把 mana 删掉、power 改名魔力。我没有改数据。

### 10. 「战败时体力没有正常扣除？布鲁图斯没有逃跑技能，应该就是正常扣血才对」（作者问）

**排查**：写了探针在序章二用布鲁图斯空手打游兵 —— 打输之后体力 8 → 7，**机制在扣**（`loss_cost.battle = 1`；序章二给了 2 点体力上限加成，所以是 8）。免罚败仗只有安德烈乌斯有（`free_losses`），布鲁图斯的 `losses_forgiven` 是 0。可能看到「没扣」的情形：**输给猎手**（第一章的伪 PVP）不走体力，走猎手定义里的战败后果（被赶回上一个点、丢东西、逃跑失败才扣体力 `flee_fail_vitality`）—— 截图里的神射手正是猎手池里的敌人。作者要是在序章里也见到没扣，请说一下是哪一场、体力从几到几，我再查。
