# 081 · 信仰体系（作者定，已实施）：信仰标签、最后置入决定激活、休眠、敌人只信一个神

> 第 8 阶段 8-4 ｜ 架构文档 3.8（新）、4.2、6.0、10.1、16（v1.79）｜ 前一步：[080 信仰提议](080-faith-system-proposal.md)｜ 世界观：[docs/worldview/worldview.md](../worldview/worldview.md) 第六节

作者答了 080 的七个问题，又补了一条关于「流派」的话；本报告按答案实施。

## 一、作者定的

| 问 | 答 |
|---|---|
| 别的信仰的道具 | **通常情况下完全不起作用**（休眠） |
| 「两个大类」 | 准确说是**信仰标签的有无**：用不用带信仰标签的道具，就决定了玩家有没有选信仰 |
| 无信仰之物 | 信仰者可以用，不冲突 |
| 不信者 | 目前只是「没激活任何信仰」；将来加专门体系，同样走标签 |
| 切换代价 | 没有；将来甚至可以继承积攒的**信力**（还没做，留着） |
| 敌人 | 按出身信仰：信暴力之神的北境蛮族、信火焰之神的西方蛮族，掉的是那一系 |
| 标签机制 | 信仰道具先带一个 `faith` 标签，再按信仰对象带对应标签；新教也有 `faith` + 专属标签 |
| 流派 | **不提倡除套装以外的明确流派，不要写在纸上**；道具的联动让玩家自然组成流派 |

最后一条纠正了 080 里「流派 = 信仰」的说法：信仰是道具的一级分类，不是流派；敌人组装备用的 `schools` 字段只是内部的组装偏好，不是给玩家看的流派，文档里不再这么写。

## 二、标签与数据

- 信仰道具带 `faith` + 恰好一个对象标签 `faith:<id>`（`FaithDef.TAG_PREFIX`）。**机制只看标签**（不用注册表也能算），注册表给名字、阵营、说明。
- 新内容种类 **`faiths`**（`FaithDef`：id、display_name、camp = GODS / CHURCH、god、description），管线顺序在 run_buffs 之后、items 之前 ——
  导入道具时对象标签对着它查。六份占位：暴力之神 `violence`、战争之神 `war`、太阳与火之神 `sunfire`、技巧之神 `skill`、狩猎之神 `hunt`、新教 `church`（阵营 CHURCH，体系还没做）。
- 导入器：带 `faith` 得恰好一个对象标签；有对象标签没 `faith` 报错；对象得是登记过的信仰；信仰 id 里不许带前缀或冒号。
- 第一批道具归类：制式短剑 / 长剑 / 圆盾 / 贴身内甲 → 战争之神；弯刀 / 皮甲 / 力量的符号 → 暴力之神；长弓 / 短弓（新）/ 箭矢 / 狩猎之神的长弓 → 狩猎之神；
  技巧之神的盾牌 → 技巧之神；伤药 / 纱布 / 口粮 / 匕首 / 剁刀 / 魔晶石 / 附魔长剑 / 黑曜石 / 碎片 / 项链 / 包 → 无信仰。世界观标签那一层（imperial / barbarian / blessed）撤掉，信仰标签就是它。

## 三、激活规则（`FaithState`，纯静态）

- **置入序号**：`GridInventory.place` 在道具**从别的容器进来**时（`inst.container_id != id`）把计数 +1 盖到 `ItemInstance.placed_seq` 上。
  同容器内挪位置（`InventoryService.move` 同源同目标）、顶替时原样放回（`_put_back`）、同容器里挪包（`detach_bag` 的载荷记 `from`，`attach` 认出是自己的就不盖）都不算。
  跟着存档走：道具字典写 `seq`，容器写 `place_seq`；读档先放回再把序号写回去。
- **激活的信仰** = 棋盘上有 `faith` 标签的道具里 `placed_seq` 最大的那件的对象标签；一件都没有 = 没激活（不信者）。
- **休眠** = 有信仰、且不是激活的那个。`BattleCompiler.compile` 第一步就跳过休眠的（不参战、不给也不吃邻接）；`SetTracker.recount` 不计休眠的；占格照占、价值照算。
- 切换 = 挪到暂存区再挪回（暂存区一移动就清，见 080 第一节，所以只能在一个点上做）。开局屏的棋盘同一条规则：带哪件最后放进去，进图就是哪个信仰。

## 四、界面

棋盘视图把休眠的画灰、标「休眠」（战利品 / 货架那种不参战的视图不标）；背包面板的读数第一句「信仰：战争之神（1 件休眠）」；地图 HUD 一句；开局屏「信仰：…　最后放进去的信仰道具决定」。

## 五、敌人

- `EnemyDef.schools` 改写成信仰标签：蛮兵 / 屠夫 `faith:violence`、神射手 `faith:hunt`、守卫 / 核心守卫 `faith:war`；拾荒者照旧 `rapid`（内部偏好，不是流派）。
- 流派池按信仰分之后里面有护甲、零件，纯靠抽会抽出一个只穿甲不拿刀的敌人，两条组装规则进 `EnemyLoadout`（都是数据）：
  **`single_faith`**（默认开）—— 一个敌人只信一个神：信仰 = 流派标签里的那个，没有就是招牌 / 第一件信仰道具的，别的信仰的换成同信仰或无信仰的；
  **`min_weapons` / `weapon_tag`**（默认 1 / `weapon`）—— 至少一件会打的，不够就把末尾的非招牌非武器换成武器。
- 招牌换成同信仰或无信仰的：守卫 → 圆盾，核心守卫 → 秘银附魔长剑。

## 六、暂存区规则是它的前提

080 第一节实施的「一移动就清」正是为它：换信仰靠暂存区，暂存区只在节点内。

## 七、测试

新套件 `tests/test_faith.gd`（四组，8813 项断言 / 56 个套件全过）：定义走管线、六个信仰、标签往返；每件信仰道具恰好一个登记过的对象标签、无信仰之物没有对象标签；
导入器拦四种错标签、放行合法的；激活按最后置入、无信仰之物不影响、同容器挪位置 / 顶替放回 / 同容器挪包不算、挪到暂存区再挪回切换、清空 = 无；
编译跳过休眠（切换之后另一边活过来）、套装不计休眠；一局里开局顺序定信仰、HUD 一句、存档往返序号与激活；敌人流派池只有那一系、蛮兵按暴力之神组装备。
连带改的：三套开局装备都是单一信仰（标准 = 战争之神：短剑、内甲；打手 = 暴力之神：弯刀、剁刀、皮甲）—— 之前标准套里皮甲后放让短剑休眠，玩家打不出伤害，场景流测试当场抓住了；
敌人池测试改成「流派池里至少一件会打的」。

## 八、留着的

- 信力（切换时继承的积攒）与不信者的专门体系；新教只有占位。
- 太阳与火之神还没有道具（火焰魔法）。
- 界面上的「能量」字样、敌人名字、事件文字仍等世界观定稿。

## 九、作者补（同日）

- **凡物不归信仰**：像皮甲、短刀这些现实里也能存在的东西不归任何信仰。第一批里九件（制式短剑、长剑、弯刀、长弓、短弓、箭矢、圆盾、皮甲、贴身内甲）撤掉信仰标签，
  只剩技巧之神的盾、狩猎之神的长弓、力量的符号三件信仰道具；敌人的组装偏好回到内部的机制标签（信仰池太小，且那本来就不是给玩家看的流派）。
  `single_faith` / `min_weapons` 照旧生效；测试改成对每个敌人组装六次验「只信一个神、至少一件武器」。8918 项断言 / 56 个套件。
- **神话主线定了**（世界观文档第一节重写，以它为准）：概念 → 神 → 物质与生物；争端 = 造物厮杀；诸神合造人类让其选信仰；信力反噬让神堕落获人性；
  大地 / 风 / 水 / 火（物质 / 移动 / 吸收 / 释放）融合成元素之神、吞并诸神、败露后被诸神联手击杀、分裂夺取权柄而陨落 —— 魔法王国因此灭亡。要点与新问题见文档。
- **神话补充定义**（同日，世界观第一节已改）：神性 = 绝对的理智（清楚边界、认可秩序、不渴望更强也不恐惧变弱）；人性 = 信力带来的欲望、恐惧、情绪；
  不是只有四种元素 —— 四种概念被人类用自然现象绑定，「元素」的概念随之诞生，元素之神是被人类推动诞生、充满人性的神，靠欺骗（诸神从未被同类骗过）吞并了别的权柄、制造了魔法；
  陨落后一部分元素被诸神回收、更多的随死前一击落在人间，庞杂又混着人性，诸神不敢碰、任其降解，魔法因此被人类消化、独立于诸神；
  新神诞生的两个必要条件 = 人类有这个概念 + 人类为它造神并信仰（传播度与持续时间），所以还没有谎言之神。
