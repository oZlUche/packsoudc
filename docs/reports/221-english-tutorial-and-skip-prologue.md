## 一、F：教程英文版

### 1.1 查过的现状

能用的底子（085 / 091 / 096 已铺好）：

- **语言开关有**：主菜单脚注「语言」切 `GameSettings.language`，`UiText.lang` 跟着改并存盘。
- **名字基本有英文**：道具 152 件里 149 件有 `display_names.en`（缺的三件：胫骨大棒、都行、果果之心）；敌人 30、buff 14、标签 56、信仰 7、反应 10、章节 5 全有英文名；标签的说明也 56 条全有英文。`{item:…}` `{faith:…}` `{enemy:…}` 占位符走 `Names.of`，界面切英文时名字自动换。
- **事件结构早留了位**：`EventDef.titles` / `texts`、`EventOption.labels` 都收 `{"en": "…"}`，事件屏按当前语言取、没写回落中文（091）。只是**一条都没填**：58 条事件（含 37 条教程、「军团的交代」）英文全空。

- 字库：英文字母已经在子集里（主菜单有英文）；`tools/font_charset.py` 扫 `data/` 下全部 json，所以新英文照 168 的流程重跑一次 `subset_fonts.sh` 就行，不用另外登记。

拦路的（这就是 085 注释里说的「别的屏还是写死的中文，逐屏换成 `UiText.t()`」那条待办，一直没做）：

- **`UiText` 只有 86 个键、8 个文件在用**（主菜单、存档位屏、地图屏一部分、存档报告）。教程要玩家看的那几屏 —— 顶栏 / 背包窗 / 战前屏 / 回放屏 / 开局屏 / 事件屏 / 结算屏 —— 字都写死在代码里。粗数（去掉编辑器、导入器、`UiText` 表本身），玩家能见到的中文字符串字面量约 **1 800 条、340 个文件**，最密的是地图屏 96、道具悬浮窗 70、局外屏 69、开局屏 52、设置屏 49、属性轴 45、回放屏 36。
- **道具说明 0 / 95 有英文**（悬浮窗第二行）；`Glossary.TERMS` 词条解释基本只有中文；百科自动页（词条 / 标签 / 伤害类型 / 反应）的拼接句一半有中英、一半没有。
- `{ui:…}` `{zone:…}` 的英文表 `TextTemplate.TERMS_EN` 只登了九个词（搜索 / 开战 / 战前准备 / 迎战 / 撤离 / 地上 / 仓库 / 棋盘 / 包）；教程里还用了 背包、百科、自由模式、出发、本图规则、休息 等，没登记的照原文（中文）出。
- 教练步骤（`data/authoring/coach/*.json` 的 `steps[].text`）**没有语言字段**；`EventOption.hint_when_hidden` 也是单一字串。

一句话：**事件和百科翻了，界面还是中文**，玩家会读到 "click Search" 而按钮上写着「搜索」。所以 F 不是一件翻译活，是「界面文字过一遍 `UiText`」+「内容翻译」两件。

### 1.3 写法与检查

- **口吻一致**：交代、教练、事件的英文照中文的接应者口吻写（218 的规矩），不是说明书；百科页照中文的手册口吻。英文由执行直接写，不走机器翻译；先在 `docs/text-glossary-en.md` 定一张核心词表再动手，以数据里已有的英文名为准，只补没有的：信力 Faith、阶 Rank、信物 Token、火漆签 wax seal、负重 Encumbrance、耐力 Stamina、估算输出 est. damage、格挡 Block、护甲 Armor、侵蚀 Erosion、魔晶石 Crystal、相邻 Adjacency、反应 Reaction、撤离 Extract、军团 the Legion、接应者 the handler。

## 二、G：主菜单「跳过序章」

### 2.1 序章留下的东西（查过）

打完三张序章，一份存档里多出来的只有这些：

| 东西 | 来源 | 跳过时怎么补 |
|---|---|---|
| 解锁 `prologue_done` / `prologue2_done` / `prologue3_done` | 三章的 `grants_unlock` | `meta.grant_unlock` 三次（自由模式和沙漏都 `requires_unlock: prologue3_done`） |
| 特殊道具望远镜 `spyglass`（节点情报） | 序章二 / 三的 `starting_keepsakes` → `meta.grant_keepsake`，局外永久 | `meta.grant_keepsake(&"spyglass")` |
| 两枚信物 `charm_brute` / `charm_sun` 在仓库 | 序章三事件放进包、撤离时随包回仓库 | `meta.grant([两件 ItemDef])`（`MetaState.grant` 已有，直接进仓库） |
| 图鉴里见过的序章道具、四份教练的 `coach_seen` | 顺带 | **不补**：图鉴空着没影响；序章教练以后也用不上 |

和跳过**无关**、照旧会发生的：「军团的交代」（`briefing_seen` 另记，第一次点出发前照弹）、自由模式三步教练（`coach_seen` 没有 `free_mode_map`）、反应第一次触发的暂停。所以跳过序章的老玩家仍然会被交代一遍自由模式的规矩 —— 这正好。

### 2.2 做法

- **入口**：主菜单「新的游戏」正下方加一行小字「跳过序章」（次级字号，`menu.skip_prologue`，en "Skip the prologue"）。永远显示：它开的是一份新存档，和当前存档打到哪无关。只放主菜单，存档位屏不加（推荐）。
- **流程**：和「新的游戏」完全一样走 `start_new_game` / `new_game_in(n)`（存档位满了同样跳去存档位屏），只是开新存档之后、开第一局之前先调 `GameFlow.skip_prologue()`：三个解锁 + 望远镜 + 两枚信物进仓库，存局外；然后照 `new_run_target()` 往下走 —— 此时教程全通，可选的是自由模式和机关沙漏两章，所以落在**开局屏**。
- **确认**：跳过在这份存档里不可逆（三章 `hidden_by_unlock` 收起，作者定过不做「重温序章」），所以照存档位屏删档的样子，**再点一次确认**：第一次点把这一行改成「再点一次：这份存档不再有序章」，几秒不点恢复原样。
- **不碰的**：开发版的「全部解锁」开关照旧，两者独立；成就不发；`unlock_all` 不影响这里。
