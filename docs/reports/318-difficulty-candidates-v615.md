# 318 难度候选 D1–D5：在改造 D 批之后重测，补做 D4 / D5

> 日期：2026-11-13。接报告 [303](303-events-materials-difficulty.md) 第 5 步（材料与难度方案 §7.2）。改造 D 批（[316](316-fusion-reform-batch-d-remove-anvil.md)，v6.15）落地后重测。
> 只出候选表，**不改任何资产**；正式值等作者定。原始表在 `docs/reports/balance/difficulty/2026-11-13-v615/`。

## 一、结论

| 实验 | 结果 | 要作者定的 |
|---|---|---|
| D1 蛮兵生命 / 格挡 −10% | 和 v5.84 **逐格相同**：生命 −10% 同阶段 +2.6～+5.6 个百分点；格挡 −10% 几乎不动 | 要不要给蛮兵生命 −10% |
| D2 猎手档位 | 原始输出和 v5.84 **逐行相同**：第 0～4 步档 0 玩家 100% 赢；5～19 步升一档就从八成掉到两成以下 | 第 0～4 步要不要改成档 1 |
| D3 双方生命 ×1.15 / ×1.30 | 和 v5.84 **逐格相同** | 选不选、选哪个（要真机看节奏） |
| D4 处决巨刃 | 处决那一条对普通敌人**几乎没用**：一刀 250 已经打死所有档的所有敌人。木桩 DPS 低不是它弱的证据，**不建议加伤害** | 无需定值；见第四节 |
| D5 品质 1 / 2 | 品质 1 同阶段 +3～+10 个百分点，品质 2 +5～+19；**快攻流涨得最多**（品质 2 段 2 +41），爆发流最少 | 现在新游戏里拿不到品质（见第五节），先不动 |

D1–D3 没变是对的：D 批拆的是砧和升级配方，木桩（108 份）本来就全是品质 0、全是随机来源能拿到的东西（逐件查过），敌人也没改。所以 D 批没有改变这几张表的基线，303 里的候选照旧有效。

## 二、做了什么

- 重跑：同 v5.84 那一轮的命令、木桩、种子（`tools/difficulty_candidates.gd -- --exp=D1 / D3`，`tools/bench_hunters.gd -- hunter_1 100 res://data/authoring/calibration/archetypes.json free_mode ascension_3`），跑在 v6.15 上。
- D5：`difficulty_candidates.gd` 加 `--exp=D5`。木桩副本里带「武器 / 护甲 / 盾」标签的道具品质全设成 1 或 2（铁匠铺打得出来的那几类），敌人不动，频率测试，逐场配对。
- D4：新工具 `tools/execution_phase.gd`（`ExecutionPhase`）。焰纹处刑巨刃单独一件，玩家生命打不死（只量武器），对每个池的每种敌人、每档打 20 场；敌人开场生命先降到 100% / 60% / 29%；同一场有处决、去掉处决各打一遍配对。另附打不死木桩（`PowerBench`）的 DPS。
- 测试：`test_difficulty_candidates_303` 加两条（D5 只改武器 / 护甲 / 盾、原件不动；D4 去掉处决只少那一条规则）。

## 四、D4 处决巨刃

| 敌人池 | 有处决 / 去掉处决打死比例 | 用时中位 | 处决有作用的格 |
|---|---|---|---|
| 废墟（standard_ruins） | 全档 100% / 100% | 4.80 秒 | 没有 |
| 机关（clockwork） | 全档 100% / 100% | 4.80 秒 | 档 2、档 3 满血开场：平均快 0.36 / 1.23 秒（少数敌人第一刀没死） |
| 猎手（hunters） | 全档 100% / 100% | 4.80 秒 | 没有 |

- 第一刀在第 4.8 秒，250 点，所有档的敌人都一刀死。敌人已经掉到 60% 或 29% 也一样，因为本来就一刀。处决那一条只在「第一刀没死」时才有机会出手，目前只有机关档 2 / 3 的个别敌人。
- 打不死木桩上有处决、去掉处决都是每秒 22.7：木桩生命永远在高位，处决从不出手；这个 DPS 主要被耐力卡住（一刀 50 耐力，耐力 65、每秒回 5）。
- 所以方案说的「不根据木桩 DPS 低给它加伤害」成立：真实对局里它是过量伤害。它真正的代价是**第一刀要等 4.8 秒**。冒烟试跑里（每格 2 场，小样本）55 血、只带巨刃的玩家在档 1 以上常常等不到第一刀就倒了。
- 建议：数值不动。处决那一条要有意义，得等更厚的敌人（首领）出来再看。

## 五、D5 品质 0 / 1 / 2

同阶段（段 = 档）胜率变化，百分点：

| 段 = 档 | 基线 | 品质 1 | 品质 2 |
|---|---|---|---|
| 0 | 90% | +3.1 | +5.4 |
| 1 | 75% | +7.8 | +13.8 |
| 2 | 61% | +10.0 | +19.3 |
| 3 | 42% | +9.4 | +16.2 |

品质 2 按流派（同阶段，段 2 / 段 3）：快攻 +41 / +32，流血 +19 / +18，护甲 +24 / +19，刀剑 +17 / +17，盾 +13 / +10，爆发 +7 / +11。

- 方案担心的「每下叠层照加让少数叠层路线占优」确实存在：品质每档给每次施加的层数、每下的固定伤害 +1，出手越多的流派吃得越多，快攻最明显。
- **现在新游戏里拿不到品质 1 / 2 了**：D 批之后铁匠铺 34 张配方都用新的材料格（不升品质），也不吃带品质的武器；局内也没有别的入口写品质。只有旧档里锤过的武器还带着品质。
- 建议：先不动品质规则。以后如果要重新给品质来源，再按这张表看要不要把「每下 +1」限到一次性效果，或者给快攻单独打折。

## 六、限制

- 都是模拟器结果；D3 节奏和 D4「等第一刀」的感受要游戏测试线程在真机上看。
- D2 每档 100 场只是初筛，方案要求的 400 场复核没有做（基线没变，等作者决定要不要改第 0～4 步再做）。
- D4 只量了这一把，玩家打不死；D5 是全身同一档品质的上限情形，不是玩家真拿到的组合。
- 结果跑在 v6.15 上；之后的 v6.16 / v6.17（报告 317）只改切片的界面、开局、引导和路线，不碰战斗数值。
