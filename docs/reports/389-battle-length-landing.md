# 389 战斗时长拉到 10~20 秒：落实记录（报告 388 第二节）

> 2026-11-24。落实作者 11-24 第 1 条「提升敌人和角色的基础生命值，保证每场战斗时长大概在 10~20 秒……先设置一个你认为合理的值，然后继续调整」。
> 方案见 [388 第二节](388-god-cards-landing.md)。这一份记每一轮改了什么、测出来什么、最后定在哪，和还没达标、要作者定的地方。

## 一、结论

| | 调整前 | 现在 | 388 的验收线 |
|---|---|---|---|
| 普通战斗平均时长 | 4.6 秒（中位 3.6） | **12.8 秒**（中位 10.5） | 10~14 秒 ✓ |
| 精英战斗平均时长 | 4.9 秒（中位 2.8） | **11.6 秒**（中位 7.8） | 14~18 秒 ✗ 偏短 |
| 首领战斗平均时长 | 5.0 秒（中位 2.6） | **11.5 秒**（中位 7.0） | 18~25 秒 ✗ 偏短 |
| 安德鲁斯 / 马库斯 / 布鲁图斯 胜率 | 59% / 64% / 76% | 58% / 66% / 75% | 相差不超过 5 个百分点 ✓ |
| 我方耐力打空的场（普通 / 精英 / 首领） | 1% / 4% / 4% | 1% / 4% / 4% | 不明显上升 ✓ |

普通战斗达标，胜率守住了；精英和首领拉长到原来的 2.3 倍，但没到验收线。原因和可选的做法见第四节，**这一处请作者定**。

| 改的东西 | 倍数 | 例子 |
|---|---|---|

| 道具加的耐力上限、耐力回复（口粮、熏鱼、腌肉、行军军粮、主发条） | ×2 | 口粮 40 / 2 → 80 / 4 |

进阶难度的生命加成、档位倍率、所有按百分比算的效果都没动，照原样叠在上面。

**没有跟着放大的**（理由见第三节第 3 轮）：每次出手的回血、每秒回血、格挡、反伤、伤害、耐力消耗、按秒叠的护甲（护符那类）、叠层状态。

## 三、每一轮

测法：`tools/bench_matrix.gd` 的频率测试，照正式开局在标准遗迹（A0 = 普通难度）生成 20 张图，取图上真的战斗点（带类型），108 份流派木桩换上三位角色各自的基础属性（324 份，被动技能木桩本来就不带），每格 30 场，共 12960 场；只看「同段同档」的 3240 场。按节点类型分：普通、精英（`elite`）、首领（`core`）。耐力打空 = 这一场至少有一次冷却走完、付不起耗费没出手。出表用 `tools/battle_length.py`（这次新加的）。

| 轮 | 生命 | 耐力 | 道具护甲 / 生命上限 | 普通 / 精英 / 首领 平均时长 | 普通 / 精英 / 首领 胜率 | 三人胜率 | 我方 / 敌方耐力打空（首领） |
|---|---|---|---|---|---|---|---|
| 0 调整前 | ×1 | ×1 | ×1 | 4.6 / 4.9 / 5.0 | 72% / 60% / 19% | 59 / 64 / 76 | 4% / 17% |
| 1 | ×2.5 | ×1 | ×1 | 10.4 / 11.1 / 17.6 | 75% / 62% / 34% | 59 / 67 / 83 | 26% / 77% |
| 2 | ×2.5 | ×2 | ×1 | 9.0 / 7.6 / 5.6 | 71% / 53% / 8% | 55 / 62 / 72 | 1% / 7% |
| 3 | ×2.5 | ×1.5 | ×1 | 9.3 / 8.5 / 8.3 | 71% / 55% / 14% | 56 / 63 / 74 | 8% / 27% |
| 4 | ×3.5 | ×1.5 | ×1 | 12.6 / 11.6 / 12.5 | 71% / 55% / 18% | 54 / 64 / 76 | 12% / 55% |
| 5 | ×3.5 | ×2 | ×1 | 12.1 / 10.1 / 8.7 | 70% / 53% / 14% | 53 / 63 / 73 | 4% / 22% |
| **6 定稿** | ×3.5 | ×2 | ×3.5 | 12.8 / 11.6 / 11.5 | 73% / 56% / 17% | 58 / 66 / 75 | 4% / 27% |
| 7 试验 | 第 5 轮 + 道具护甲 / 生命上限 ×3.5，精英和首领生命再 ×1.4 | | | 12.6 / 13.2 / 12.4 | 74% / 49% / 14% | 56 / 64 / 73 | 6% / 27% |

1. **只乘生命 ×2.5**：时长上来了，但敌人的耐力先打空（首领战 17% → 77%）—— 敌人卡着打不出手，玩家打首领的胜率从 19% 白涨到 34%，布鲁图斯涨了 7 个百分点。388 说的「耐力是首要观察项」应验了。
2. **耐力 ×2**：打空比例压回调整前，但时长掉回去（原来一部分「长」是卡耐力卡出来的），首领胜率掉到 8%。×1.5 介于两者之间。
3. **生命提到 ×3.5**：普通战斗进了 10~14 秒。这时耐力 ×1.5 又不够（打空 12% / 55%），换回 ×2，打空回到调整前。两边都放大以后精英、首领胜率还低 4~5 个点 —— 看下来是护甲：护甲是开战时一次充满的一池，和生命一样，生命 ×3.5 而护甲不动，就等于防具砍到不到三分之一。护甲上限、道具加的生命上限跟着 ×3.5 以后（第 6 轮），三人胜率都回到调整前 ±2 以内。
   388 原来写的「固定数值的回血、护甲、格挡、食物加的生命跟着放大，系数先取 2」，测下来只该放大**一次性的池子**（护甲上限、生命上限），而且和生命同倍；**按次、按秒给的**（每次回血、每秒回血、格挡、按秒叠的护甲）不用动：对面每秒打出来的伤害没变，它们抵掉的那份伤害也没变，战斗变长它们还自然多生效几次。
4. 精英和首领还短，见第四节。

## 四、精英和首领为什么还短，要作者定

看输赢分开的时长（第 6 轮）：

| | 赢的场中位 | 输的场中位 | 输的比例 |
|---|---|---|---|
| 普通 | 10.9 秒 | 9.9 秒 | 27% |
| 精英 | 7.2 秒 | 8.2 秒 | 44% |
| 首领 | 7.8 秒 | 6.0 秒 | 83% |

精英、首领战短，一是**玩家输得快**（首领战八成是输，输的那些 6 秒就倒了），二是**赢的那些精英本身倒得快**。只放大双方生命，这两样都按同样比例变长，到不了 14~18 秒、18~25 秒。要再拉长，只能让精英、首领比普通敌人多拿一份生命，代价是更难打：第 7 轮试了精英、首领生命再 ×1.4，精英战平均 13.2 秒，但精英胜率从 56% 掉到 49%（比调整前低 11 个点），首领战时长几乎不动（输的那些还是 6 秒倒）。

可选：

- **A（推荐）：先这样。** 普通战斗达标、胜率不动；精英、首领比原来长 2.3 倍，等神的牌（第 1~3 批）上了再一起看 —— 牌会让玩家撑得更久，精英、首领自然变长。
- B：精英、首领多一份生命（例如 ×1.4），接受精英变难。要新加「按节点类型的生命倍率」（现在只有进阶难度的首领倍率），一处数据。
- C：首领和精英改成按自己的时长目标单独调（生命、伤害一起改），工作量大，等内容定了再做。

## 五、连带的改动

- **存档**：存档里没有「当前生命」（每场开战都按上限充满），老档要换算的只有写死在图上的敌人数值（序章、教程、试玩切片的预设图，和停在战前屏、求饶屏的那一场）。新档多写一个 `battle_scale: 388`；读到没有这个键的老档，就把这些写死的生命 ×3.5（取整到 5）、耐力 ×2（`RunState.rescale_content`）。不升存档版本。
- **基准数据**：`archetypes.json` 的木桩基线换成马库斯的新数（195 / 130 / 10），`docs/characters.md` 的三人面板表跟着改。
- **战斗记录指标**：`BattleMetrics` 多记两项 `skipped`（付不起耗费没出手的次数）、`first_skip`（第一次的时刻），给这次的耐力观察用，以后平衡也能看。
- **测试**：写死旧数值的断言改成新数（三人面板、法师生命、护甲件、兽皮、主发条、调息牌面、估算器的耐力例子）；编译金样重录（只有耐力四个数变了）；两条要接着走下去的流程测试改成挑「第一场打得赢」的种子（原来挑第一个有战斗的种子，默认第一位安德鲁斯这一场现在输了，走去了求饶屏）。新加 `tests/run/test_battle_length_388.gd`：三人新数值、老档换算。

## 六、没动、留给别处的

- **日夜时长 6 秒**（388 第三节）：那是新日神的「日夜」机制，属于第 2 批（日神），现在库里的日神还是旧的「烈日窗口」（每 4 秒开 2 秒），这次没动。做日神那一批时直接按 6 秒写。
- **按百分比算的效果**：388 说「不变、不动」，照做。但要知道：按最大生命百分比打的伤害（如猎兽长矛）和按百分比的回血，对着 3.5 倍的生命，实际打出 / 回上的点数也是 3.5 倍，而普通伤害没变 —— 相对普通伤害，这类效果变强了。目前这类道具很少，先看数据。
- **叠层类、每秒回复、生命偷取**：388 定的「先不压，看数据」，照做。
- **旧信仰里的固定生命 / 护甲 / 耐力**（大地、自然的旧阶层奖励，蛮神神坛献祭生命上限）：这些整套要被三位神的新牌表换掉，这次没动。
- 战斗力估算里的「假定对手生命」（100）没改，按百分比伤害的武器估值照旧。
