## 〇 一句话

三处各站一位 NPC（局内商店的店主、集市散货摊的摊主、铁匠铺的铁匠）：点头像弹一张小纸条、说一句闲话，一句一句往下翻；话分「世界观」与「指引」两类，按条件开放、不重复；**台词全部留空给作者写**（道具说明那条规则同样适用）。铁匠铺满级后点铁匠 = 【破晓】任务链的起点：一段专属对话、给一件任务道具，后面的流程留白记进待办。

## 二、做法

### 2.1 数据：`data/authoring/npcs/<id>.json`（新内容种类 `npcs`）

```json
{
  "id": "shopkeeper",
  "name": "", "names": {"en": ""},
  "portrait": "npc_shopkeeper",
  "lines": [
    {"id": "lore_1", "kind": "lore", "text": "", "texts": {"en": ""}},
    {"id": "guide_sell", "kind": "guide", "text": "", "texts": {"en": ""}, "requires": [{"type": "has_unlock", "id": "prologue_done"}]}
  ],
  "special": []
}
```

- 三个 NPC：`shopkeeper`（局内商店）、`stall_keeper`（集市散货摊）、`blacksmith`（铁匠铺）。名字和每一句都留空，作者填；导出器照 v5.02 的做法总是写出空键。
- `kind`：`lore` 世界观 / `guide` 指引。`requires` 用事件那套条件（`has_unlock` / `has_item` / `flag` …），没条件的随时能说。
- 掷句（作者 12:48）：闲聊和指引**可以重复，只保证十句内不重复**——每个 NPC 记最近说过的 10 句 id（`meta.npc_said[<npc>]` 定长队列），掷句时排除这 10 句、其余随机；开放句不足 11 句时排除到池空为止再放开。每点一次换一句。
- `special`：带条件的专属对话（见 2.3），命中时**优先于闲聊**、只触发一次（`meta.npc_done`）。

### 2.2 界面

- 头像 96 一块，位置写进各页 `layout.json`（`npc` 矩形）；鼠标悬停微亮，点一下弹纸条。
- 纸条 = `RecipeScroll` 的卷轴皮（铁匠铺用铁砧深色皮、另两处用纸色），只有一行字和右下角一个「……」（再点 = 下一句）；点别处收起。不写 NPC 名（奥卡姆：头像在，名字作者填了才显示在纸条左上一角）。
- 不打断买卖：纸条开着也能拖货。

### 2.3 【破晓】的起点（作者定）

- 条件：铁匠铺 **3 级**（科技「高级配方」点满）+ 仓库 / 背包 / 局内都没有破晓或破晓的任务道具。
- 点铁匠 → 走 `special` 一段对话（文字留空，一个「……」占位，作者要多页就接下一段）→ 给一件任务道具 **`poxiao_token`**（1×1，`unique`，不能卖、不能附魔，占位图），进仓库。
- 之后的流程**留白**：281 §四.3 破晓那行改为「起点 = 铁匠铺对话（282）；其后待办」，记进 `/mnt/project-files/reference/待做-系统.md`。架构设计原拟的猎手线作废。
