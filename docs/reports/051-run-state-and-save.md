# 051 · M5 运行状态与存档

> 阶段 6 · M5 ｜ 架构文档 7 节（v1.49）｜ 前一步：[049 M4 回顾](049-m4-review.md)

M4 回顾的最后一句是「M4 的每一样都已经有 `to_dict` 或跟着图存，只差一个装它们的壳」。M5 就是那个壳。

## 产出

| 文件 | 职责 |
|---|---|
| `core/run/run_state.gd` | `RunState`：一局的全部状态。开局（生成图 → 放敌人 → 标付费撤离点 → 棋盘与暂存区 → 节点事件接线）、挑出生点、走、撤离、战败；战利品 / 买的 / 事件给的落到哪；玩家从棋盘编译；`to_dict` / `from_dict` |
| `core/run/run_rng.gd` | `RunRNG`：1.4 的分流随机源，每个流的第 i 次用 hash(种子, 流名, i)，序号跟着存档 |

| `ui/map/map_sandbox.gd` | 改成 `RunState` 的一层皮：开局装备是一个清单；存档 / 读档 / 撤离三个按钮；拾取自动全进暂存区；HUD 多「暂存区 n 件」 |
| `tests/test_run_state.gd` | 5 组 |

## 几条决定

**纯 `RefCounted`，不是 autoload。** 架构文档 7 节的草图写的是 `autoload/run_state.gd`；1 节又说核心逻辑层没有全局状态。
按后者：`RunState` 由持有方创建、传递，测试里可以同时开两局互相比对（读档往返的测试就是这么做的）。M6 的 `GameDirector` 持有它。

**内容库不进存档。** 存档只写章节、道具、敌人的 id，读档时由调用方给内容库（3.1：存档只写 id，绝不写资源路径）。
内容改了旧存档照样读得回来；定义被删的道具由 `ItemInstance.from_dict` 告警后丢弃。

**开着的会话不存。** 商店、搜索会话存档那一刻视为离开了那个点 —— 随时可以离开本来就是规则（5.4），货架与搜索进度在图的内容里，
读档回来点已用过、进度还在。

**战利品先到「待拾取」。** 尸体容器、搜索收获不直接进暂存区：搜刮界面（6.2、M6）要让玩家挑；沙盒没有那个界面，就全拿。
上一份还没处理又来一份就并进去，一件不丢。买的、事件给的没有挑的余地，直接进暂存区。

**玩家开战时才编译。** `NodeEvents.player_spec = compile_player`：棋盘随时在变，编译是纯函数（4.2），套装效果从绑在棋盘上的 `SetTracker` 取。

**读档之后接着走，和没存过一样。** 测试把同一局存下来再读回，两份走同样的路走六步，语义签名（图的内容与状态、旅程、体力、钱、
棋盘、暂存区、待拾取、随机流序号）逐字相同。新建道具的 uid 从存档里最大的接着编，和没存过的那份编号不同，但那不是状态。

**`RunRNG` 先立着。** 节点内容的随机已经各按节点 `content_seed` 派生，现在没有一处 run 级的随机；流的序号跟着存档，
将来带选项的事件、局外奖励用它，读档后接着抽出来的和没存过一样。

## 验证

```
bash tools/test.sh
通过  6088 项断言，38 个套件，耗时 77 秒
```

- 开局：有图、敌人放好、付费撤离点标好、钱来自经济规则、体力满、棋盘是棋盘模式、两个包上了棋盘、其余的不在棋盘就在暂存区、
  玩家编译出来会打、套装追踪器绑好；不是出生点挑不了、没开局走不了、开局之后不能再挑；没有套装库也能开局。
- 战利品与商店：走上战斗点赢了进账、点用过；有掉落时发 `loot_pending`、拿一件进暂存区、剩下全拿、待拾取清空、一件不少；
  没有待拾取拿不到；两份并成一份、丢掉；买的进暂存区、关门；暂存区 ↔ 棋盘。
- 结束：空手一血、体力只剩一格，输一场 → 战败、原因、结束了走不了、发了 `phase_changed`；免费撤离点撤了；付费的没钱撤不了、钱够扣正好。
- 存档：带版本号、章节只写 id、读得回来、语义签名一致、再存逐字节相同、阶段接着、事件重新接上、玩家编译一样；
  走六步之后签名仍一致；版本不对 / 坏文件 / 章节不在 → null；真写 `user://` 再读回一样、删掉；开着店存档读回来店关了、货架进度在。
- 随机流：同种子同流同序号一样、别的流不影响、种子不同不一样、序号跟着存档。

## 没做的

- 撤离结算（背出去的东西按价值计分、进 meta）、战败结算：M6 的 `ExtractResult` / `DeathResult`。
- 侵蚀（第 7 阶段）：`RunState` 里给它留的位置是 `travel.erosion`。
- 角色系统：`player_baseline`、体力上限、棋盘尺寸都还是占位。
- 多存档位：`RunSave` 收路径参数，一个位就是一个文件。
