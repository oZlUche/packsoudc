## 一、结论

1. **切片不需要新系统。** 现有的「章节 + 预设地图」已经能写死每个点的敌人、敌人棋盘、搜索出什么、必掉什么、弹哪个事件（序章就是这么做的）。切片 = 一张新章节 + 一张预设地图 + 四张小规则表，全部走正式流程。
2. **要新写的代码只有四处**（第五节）：切片档案开关与独立存档目录、商店固定货架、清单核对工具、切片引导配置。
3. **两条配方卡在合成改革 C 批上。** 涂毒匕首和绷带卷现在还是拖上去立刻合、没有确认窗；C 批（执行（新）正在做）把它们迁到相邻加确认。S1 骨架不等 C 批，S2 的「四条配方统一确认」要等。
4. **顺带多出第五条配方。** 匕首和磨刀石同时在场，「淬火匕首」就能拼，配方是全局的。建议直接收进切片当第五条：它让一把匕首有三种去向（双刀、涂毒、淬火），一块磨刀石有两种去向（阔剑、淬火），正是方案要的取舍。

## 三、内容清单

**章节**：新章节 `slice_ruins`，显示名沿用「魔法废墟」，主题、场景与节点美术全部复用。角色只列安德烈乌斯（生命 45、体力 3、棋盘 7×6、两个皮革包、偷袭三次、求饶）。体力只有 3，这本身就是撤离取舍的来源。

**开局道具**：匕首、纱布、口粮（在角色自带的两个皮革包之上）。首版只有这一个基础预设；第二个防御取向预设（圆盾、皮甲、剁刀）等首轮之后再加。

**配方（5 条）**

| 配方 | 现在的交互 | 两件原料的保证来源 |
|---|---|---|
| 匕首 + 匕首 → 双刀 | 相邻加确认 | 开局一把；第一战拾荒者必掉一把 |
| 制式短剑 + 磨刀石 → 阔剑 | 相邻加确认 | 短剑只在商店；磨刀石在第二个搜索点 |
| 匕首 + 磨刀石 → 淬火匕首 | 相邻加确认 | 同上两件 |
| 匕首 + 毒药瓶 → 涂毒匕首 | 拖合，等 C 批 | 毒药瓶在商店，另有一处搜索可出 |
| 纱布 + 亚麻布卷 → 绷带卷 | 拖合，等 C 批 | 纱布开局一份；亚麻布卷在第二个搜索点 |

第一次合成机会是双刀：两把匕首在第一战之后一定到手，成本低，而且玩家手里总还剩得下武器（合成后是双刀，不合是两把匕首）。短剑全图只放一把，这样「短剑 + 短剑 → 双手剑」拼不出来，不会多出第六条。

**玩家可得道具（20 件）**

| 类 | 道具 |
|---|---|
| 武器 8 | 匕首、制式短剑、弯刀、剁刀、双刀、淬火匕首、阔剑、涂毒匕首 |
| 防具与盾 2 | 圆盾、皮甲 |
| 组件 3 | 磨刀石、毒药瓶、亚麻布卷 |
| 恢复 5 | 纱布、绷带卷、伤药、浓缩伤药、口粮 |
| 包 2 | 皮革包、小背包 |

低于方案的 25 到 35 上限，留出事件奖励的余量。事件给的东西在 S1 逐个核对后补进清单，不在清单里的奖励要换掉。

**敌人**（棋盘与数值在预设地图里写死，掉落因此受控）

| 位置 | 敌人 | 身上带的 | 要让玩家看到的 |
|---|---|---|---|
| 基准战 | 拾荒者 | 匕首、伤药 | 最简单的胜负；必掉匕首 |
| 普通 | 蛮兵 | 弯刀、伤药、浓缩伤药 | 自带格挡，快攻打不动的感觉 |
| 普通 | 屠夫 | 剁刀、匕首 | 流血 |
| 可选精英 | 盾卫 | 圆盾、剁刀（不带短剑，免得全图出现第二把） | 高格挡；涂毒匕首是答案 |
| 终点守卫 | 守卫 | 圆盾、弯刀（同样不带短剑） | 战前看得到盾；玩家用流血加中毒能打出反应 |

五个都是现有敌人，用的都是它们现有的装备思路。具体数值（序章给守卫的是生命 36、格挡 3）由 S1 用现有战斗工具按「开局预设 / 双刀 / 涂毒匕首 / 加盾甲」四种玩家配置对打后定，本报告不拍数。

**事件 2 个（候选）**：「补衣人的针」（交出亚麻布卷或皮子换钱，和绷带卷配方抢同一件原料）、「倒墙后的担架」（花时间或花钱处理伤处）。两个都是 v5.73 的现有事件。另设一个歇脚点、一家商店。

**商店货架（写死）**：制式短剑、毒药瓶、磨刀石、圆盾、皮甲、伤药、纱布、口粮。玩家的钱买不全，这是资金取舍。

**结局三种**：中途免费撤离点撤离；打过守卫后从终点撤离；体力耗尽失败。首版不设付费撤离。

## 四、路线与出口

13 个点（出生点、两个撤离点，加 10 个内容点），一条主干加一处分支：

```
出生 ─ 基准战(拾荒者) ─ 搜索一 ─ 普通战(蛮兵) ─┬─ 商店 ─ 事件(补衣人) ─┬─ 歇脚 ─ 免费撤离
                                              └─ 精英(盾卫) ─ 搜索二 ─┘        │
                                                                    事件(担架) ─ 守卫 ─ 终点撤离
```

- 搜索一：磨刀石、亚麻布卷；再搜一次出皮甲。
- 搜索二（精英之后）：毒药瓶、圆盾。走商店线的人要花钱买这两样，走精英线的人白拿但要先打盾卫。
- 屠夫放在搜索一「再搜一次」的遭遇里，贪多才会碰上。
- 免费撤离点在歇脚之后，任何路线都到得了，不依赖金币。到了那里再决定要不要去打守卫。
- 倒计时首版给得宽（建议 20 步，全图走完约 12 步），只防止无限来回，不制造时间压力。
