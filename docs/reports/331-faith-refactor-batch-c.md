# 331 信仰重构 C 批：技巧「巧劲」、狩猎「拆解」、大地「承托」

- 来源：作者 2026-11-19 要求按 `handoff/2026-11-19-faith-system-implementation.md`（PR #663）实施信仰系统重构。本文是 C 批（方案 §5、§6.4–§6.6、§9 C）。A、B 批见报告 329、330。
- 版本：v6.47
- 范围：三位神换上新机制、换三阶阈值（候选 20 / 60 / 120）、换新的信力行为。蛮神、日神、自然不动（D 批）。

## 1. 共同做法（方案 §5）

- **一位神的整套战斗机制是一条单位级规则**：扳机 `FaithMechanicTrigger` 订阅几条事件、全部放行，效果自己按事件名分流。状态放在这条规则自己的 `RuleContext.state()` 里，战斗结束就没了。
- **perk 只往 `CompileInput` 放东西**（规则、按 uid 的修饰），编译还是纯函数。开战时的阶决定开到哪一层。
- **看得见**：巧劲是本方的 buff，拆解是对手身上的 debuff，都走现有的叠层与 buff 栏。到档、连携、承托写进战记：`EFFECT_RESOLVED {effect: faith_mechanic, key, arg|count}`，`BattleNarrator` 认它。没有新增回放事件类型，所以老回放照旧复现。
- **信仰窗一阶一行**：同一种 perk 按 `part` 写几条。0 是基础，奉神即有（tier 0），只有它编译；其余几条只负责写那一阶多出来的那句。
- **信力行为**（方案 §3.2）：三位神都改成「打赢 +6」加「机制真发生了几次」。新构件 `MechanicDeed` 读战斗账的 `mechanic`，即本方开战之后叠上的 buff 层数和 `faith_mechanic` 的次数。输了也保留已经真完成的特色行为，但不给胜利分。
- **改源表**：`docs/gods.xlsx`（神明总表、信力行为、等级效果三张表）→ `tools/gods_xlsx_to_json.gd` → JSON → 导入。
- **命名**：方案里的「巧势」改叫「巧劲」，因为「势」不在字库子集里，换字比重切字库省事。D 批蛮神的「怒势」同理会换名。

## 2. 技巧之神：巧劲（方案 §6.5）

| 阶 | 效果（候选数） |
|---|---|
| 基础 | 近战、远程、施法换一类出手，和上一下间隔 ≤ 4 秒，攒 1 层巧劲，最多 2 层；同类不加；开战送 1 层 |
| 一阶 | 武器打出的直接伤害用掉全部巧劲：每层 +5%，两层那一下穿透护甲 |
| 二阶 | 格挡真的挡下直接伤害，算一次防御动作（间隔 ≥ 1 秒） |
| 三阶 | 本场头一回「防御 → 攻击 → 另一类攻击」，追加最后那一击 30% 的伤害，一场一次 |

- 类别按标签判：法杖算施法（优先），其次远程、近战。不认名字。
- 先用后攒：出手事件排在伤害结算之后，所以同一下不会自产自用。
- 连带出手（事件带 `chain`）不算原始动作。追加的那一下来源是 0，不攒巧劲，也不推进组合。
- 信力行为：打赢 +6；一场里攒到巧劲 +2（开战送的那层不算），攒到 3 次再 +2；本局头一回得到一种工艺道具 +3（按种去重）。

## 3. 狩猎之神：拆解（方案 §6.6）

| 阶 | 效果（候选数） |
|---|---|
| 基础 | 开战按对手的本事挑标记：护甲 → 恢复 → 攻击节奏 → 暴露（第一个适用的）。武器的原始直接命中给对手攒拆解，全单位每秒最多 1 点。3 点拆掉半档 |
| 一阶 | 3 点第一档：标记的那项削弱 10%（暴露：受到伤害 +5%） |
| 二阶 | 6 点第二档：总计削弱 20%（暴露 10%） |
| 三阶 | 拆完第二档并打赢，这一场的珍宝往兽材、素材偏（`LootContext.category_bias`，换掉一份普通的，不多给一件） |

- 削弱怎么落：
  - 护甲：按上限的比例拆掉当前值。
  - 恢复：按每秒回血的比例给失血轴。
  - 攻击节奏：减速轴。
  - 暴露：易伤轴。
- 轴的层数按总量折算，分两档落不会因为各自取整少一层。所有削弱只在这一场。
- 首领照样能拆，削弱有上限，不会封禁攻击或治疗。
- 信力行为：打赢 +6；一场里拆到第一档 +2；本局头一回置入一种兽材照旧 2^稀有度 + 1。原来「进战斗按点类型 5 / 20 / 30 / 50」取消。

## 4. 大地之神：承托（方案 §6.4）

| 阶 | 效果（候选数） |
|---|---|
| 基础 | 占格 ≥ 5 的大件，每有一件不同的有效道具和它正交贴边，多 1 层承托，最多 2 层。武器每层耐力消耗 −4%；盾每层格挡 +4%，防具每层护甲上限 +4% |
| 一阶 | 4 格的中件也算 |
| 二阶 | 神坛锻炼：棋盘 +1 行（**过渡**，见 §6） |
| 三阶 | 开战每件受承托的大件给最大生命 2% 的护甲，最多 10% |

- 承托在编译期按摆放算（`EarthSupport.layers`，纯函数）。规则：
  - 角接触不算。
  - 同一个邻居有多条边相接，只算一次。
  - 包、标了不参战的、整件休眠的，既不算大件也不算邻居。
  - 邻居必须有战斗定义。
- 修饰按 uid 放进新的 `CompileInput.item_mods`，编译第 7 步按 uid 升序并入。结果与放置先后无关。
- 混合物品按武器走，不双领。
- 原来的一阶耐力上限 +20、三阶踩点赐物、四阶改造此点都从大地身上摘掉了。构件还在注册表里，测试照旧验构件本身。玩家已经锻炼出来的行数原样保留（B 批定的「付过费的持久结果」）。
- 信力行为：打赢 +6；一场里有大件受承托 +2，到 2 件再 +2。原来「大件出手 +8」「踩岔路 +20」取消。

## 6. 与方案的差异

- **狩猎手动换标记**：没做。战前屏现有的 perk 按钮是写死给秒杀用的，要换就得动 `prebattle_screen.gd`，这个文件「落实局内界面布局方案」线程正在改战前摘要。这批先按推荐自动挑；`HuntDismantle.mark` 已经留了口子，等战前屏样张定了再接上。
- **狩猎三阶「两项择一」**：先做成掉落偏向（不多给一件），因为择一要战利品屏加界面。
- **狩猎「首次击败该类别 +2」**：没做。这一条要按局记敌人种类，跟着 E 批的回归再看要不要。
- **大地二阶「付祈愿做一次等面积改形」**：要完整的预览和提交界面，先留旧的「锻炼加一行」过渡。
- **技巧一阶「有限破甲」**：做成「攒满两层那一下穿透护甲」，用的是现有的穿透旗，没有另造一套减伤。
- **技巧「单类武器开场一层」**：做成不管带几类武器都送一层。只看单类会多一个判定，送给所有人也不会刷，一场就一次。
- **拆解基础半档的暴露**：易伤轴一层是 5%，半档 2.5% 落不下去，按最少一层算。
- **技巧「本场不同有效组合 +2」**：用「攒到 3 次巧劲再 +2」代替，没有逐对记组合。
