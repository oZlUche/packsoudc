## 二、品质照加（卡片答案）

- 恢复「个数 +1 / 档」对每下触发的规则也生效：`quality_rules` 去掉 v5.12 加的每下判别，一次性和每下一视同仁。
- **不压基数**。卡片当时说要压戟 / 钢枪的基数是为了守橙带，现在橙带本身要抬，紫武器两档品质打到 40–50 正好落在新的紫 → 橙之间，不越档。
- 敌人手里的武器品质恒为 0，敌人池、档位上限、木桩 ★ 基线都不动。

## 三、橙带 28–32 → 48–56

- 17 把橙的伤害数按带重写（大致 ×1.7），冷却、耐力不动；弓弩按装木箭量。
- 橙的元素句改回**每下施加 1 层**，并保留现在的「开战施加 3 层」——橙允许两句每下叠层（紫仍只许一句，v5.13 口径不变）。
- 橙只从砧上来，不掉落、不进敌人池，所以抬橙不碰任何敌人数值；紫 20–24 → 橙 48–56 这一跳就是「大幅度」本身。
- 台架：power 表橙列进 48–56；木桩 ★ 不量橙（假人配置里没有橙，照旧）。

### 3. 来路 A：任务链（每把三步，魔兽橙武式）

| 步 | 做法 |
|---|---|
| ① 线索 | 章 ≥2 的随机事件池加「线索」事件（`event_red_clue`）：每局最多出一次，基础 6% × (1 + 进阶级)；只给**仓库里没有、残片也没有**的那几把里随机一把的「X 之残片」——1×1 遗物类任务物，无战斗效果，带出局进仓库，不可出售。事件文字留空给作者。 |
| ② 试炼 | 残片在仓库时，对应试炼才开始计（成就系统新增 8 个 `kind`，进度在局外成就页显示，和现有成就同一张表）：刹那 = 一局累计叠出 200 层流血；断水 = 一局击败 3 个护甲 ≥ 20 的敌人；双生 = 带双持武器一局击杀 15 个；贯日 = 一局用开局先刺直接打死 5 个；崩山 = 一局单次伤害 ≥ 250 三次；坠星 = 一局射出 150 支箭；破晓 = 带弩打赢一个核心 BOSS；寂灭 = 一局用法杖施加四种元素各 20 层。 |
| ③ 铸成 | 试炼完成后，铁匠铺 **3 级**出现一次性配方：残片 + 两件指定紫材料（表随落地定）+ 1000 币 → 红武。配方不在常规列表里，残片 + 试炼都满足才显示；打完配方消失。这不是「常规合成」——没有残片和试炼谁也打不出来。 |

### 4. 来路 B：BOSS 持有（极低概率，随难度涨）

- 章 ≥2 的**核心 BOSS** 和**猎手**开战前各掷一次：持有 p = 1% × (1 + 进阶级)，上限 5%；只掷仓库 / 本局都没有的红武，按 BOSS 的武器类配（没有对应类就不掷）。
- 持有时它真的拿这把打（放进它的棋盘，替掉同类武器），战前准备屏能看见——这是给玩家的预警，也是「从它手里抢」的味道。
- 打赢它才掷掉落：p = 20% + 10% × 进阶级（总掉落 0.2% – 1.5%）。掉了直接给，任务链对这把作废（残片从仓库移除，试炼清零）。
- 常规掉落表、商店、敌人池都不收 `unique`。

## 五、极端武器（两条线，6 把，蓝到橙）

设计口径：**单次伤害 = 同带普通武器的 4–5 倍，冷却 4.4–5.0 秒，一下的耐力 = 基线上限的六到十成**。基线（50 / 回 4）下第一下必出、第二下常常付不起（跳过且冷却照走），实际 DPS 只有标称的六成左右；配上耐力上限 / 回复的件就能每次冷却都出手——这是它们的 build 条件，不是 bug。每一下都是「大锤」：对格挡（按下吸收）和护甲都比碎刀划得多。红不在这两条线里（红只有 §四 的八把，「崩山」就是红里的极端件）。

|---|---|---|---|---|---|---|
| 蓝 | 斩首巨刃 **新** | 双手 2×3 | 2 章起掉落 / 商店 | 75 / 4.5 / 35 | 16.7 | 其中 15 点真实伤害 |
| 紫 | 处刑巨刃 **新** | 双手 3×3 | 斩首巨刃 + 骨 | 110 / 4.6 / 42 | 23.9 | + 对手血 <30% 时伤害 ×2 |
| 橙 | 焰纹处刑巨刃 **新** | 双手 3×3 | 处刑巨刃 + 火晶 | 250 / 4.8 / 52 | 52.1 | + 灼烧 3 层 |
| 蓝 | 破城矛 **新** | 长柄 1×5 | 2 章起掉落 / 商店 | 70 / 4.4 / 33 | 15.9 | 开局先刺 + 其中 12 点真实伤害 |
| 紫 | 龙骨破城矛 **新** | 长柄 1×5 | 破城矛 + 骨 | 100 / 4.4 / 40 | 22.7 | + 命中减速 3 层 |
| 橙 | 雷纹破城矛 **新** | 长柄 1×5 | 龙骨破城矛 + 雷晶 | 240 / 4.6 / 50 | 52.2 | + 麻痹 1 层 |

- 标签 `extreme`：不进三个敌人池（敌人池按标签收件，不加就不收），不进 151 估算器的常规档（估算器对一下 250 的件会估高，列 KNOWN_OFF）。
- 木材质那条「省耐力」升级句对极端武器**不**出现（它们没有木分支），耐力只能靠别的件补。
- 蓝两把进 2 章掉落表和商店；紫起走砧；橙 `forged_only`。
- 美术设计新画 6 张：巨刃 = 一整块厚背刃、几乎没有护手；破城矛 = 矛头比枪头宽一倍、杆子带铆箍；橙同形加纹。
