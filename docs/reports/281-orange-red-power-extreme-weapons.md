# 281 橙 / 红威力大幅上调与极端武器（279 补充三）

作者 2026-11-05 08:11：「照加，大幅度提升橙及红的综合威力」「另外设计一些比较极端的武器（耐力消耗极大，单次伤害也极大）」。

「照加」答的是 279 第四步台架发出的选择卡（品质要不要给每下命中的叠层加层）：**照加**。三件事写在一份里，都是作者直接指派，待定按推荐直接派执行。

## 〇 一句话

品质对每下叠层**照加**、不再压基数；橙的 DPS 带从 28–32 抬到 **48–56**，并把橙的元素句改回每下施加；新开**红档**（稀有度 5，现有色板第六档，暂无武器）= 橙 + 第二颗不同元素的魔晶，带 **80–95**；再加两条**极端武器**线（8 把，蓝起到红）：一下打普通武器四五下的量，一下也吃掉大半管耐力。

## 二、品质照加（卡片答案）

- 恢复「个数 +1 / 档」对每下触发的规则也生效：`quality_rules` 去掉 v5.12 加的每下判别，一次性和每下一视同仁。
- **不压基数**。卡片当时说要压戟 / 钢枪的基数是为了守橙带，现在橙带本身要抬，紫武器两档品质打到 40–50 正好落在新的紫 → 橙之间，不越档。
- 敌人手里的武器品质恒为 0，敌人池、档位上限、木桩 ★ 基线都不动。

## 三、橙带 28–32 → 48–56

- 17 把橙的伤害数按带重写（大致 ×1.7），冷却、耐力不动；弓弩按装木箭量。
- 橙的元素句改回**每下施加 1 层**，并保留现在的「开战施加 3 层」——橙允许两句每下叠层（紫仍只许一句，v5.13 口径不变）。
- 橙只从砧上来，不掉落、不进敌人池，所以抬橙不碰任何敌人数值；紫 20–24 → 橙 48–56 这一跳就是「大幅度」本身。
- 台架：power 表橙列进 48–56；木桩 ★ 不量橙（假人配置里没有橙，照旧）。

## 四、红档（稀有度 5）

### 1. 来路与门

- **红 = 橙 + 第二颗不同元素的紫魔晶**（焰纹 + 冰晶 / 雷晶……），只在**基地铁匠铺 3 级**打，600 金币；营地砧不打红（砧的「可升为」便条不列红）。
- 配方照 279 的 `material_inputs` 写法：`{material: crystal, min_rarity: 3, exclude_element: 本身元素}`——比橙多一个「排除同元素」字段。
- 品质沿橙取较高，不另加。`forged_only` 照橙；图鉴照列。

### 2. 规模与数值

- 279 的 14 把橙 + 焰纹复合弓 + 雷纹重弩 各出一把红，**16 把**。名字 = 「双纹」+ 去掉元素前缀的紫名（焰纹刽子手巨斧 → 双纹刽子手巨斧）；两颗魔晶哪两种元素，产物都是同一把（句子里写「第二元素」，落地时按所放魔晶写进这一件的 `state.element2`，提示框显示实际元素）。
- 带 **80–95**，伤害数 ≈ 橙 ×1.7，冷却、耐力不动。
- 每把加两句：**第二元素每下 1 层**（照所放魔晶）+ **够 6 层任一元素时这一下 ×1.5**（「够 N 层追加」已有的写法）。
- 说明字段留空（作者填）。

### 3. 美术

- 红不新画：橙图 + 红色纹路色变体（205 起「变体复用底图」的写法），由美术设计出一张对照确认即可。

## 五、极端武器（两条线，8 把）

设计口径：**单次伤害 = 同带普通武器的 4–5 倍，冷却 4.4–5.0 秒，一下的耐力 = 基线上限的六到十三成**。基线（50 / 回 4）下第一下必出、第二下常常付不起（跳过且冷却照走），实际 DPS 只有标称的六成左右；配上耐力上限 / 回复的件就能每次冷却都出手——这是它们的 build 条件，不是 bug。每一下都是「大锤」：对格挡（按下吸收）和护甲都比碎刀划得多。

- 蓝两把进 2 章掉落表和商店；紫起走砧；橙 / 红 `forged_only`。

## 六、改动清单（执行，三步可单独合）
