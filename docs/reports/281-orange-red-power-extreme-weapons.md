### 3. 来路 A：每把一条独一无二的路（作者 10:47：公式化的「线索 → 试炼 → 配方」作废）

作者给了寂灭（10:47）、刹那与断水（11:37）三条路（原文）；其余五把由架构设计各拟一条同样的写法——都绕着这把武器的名字和机制来，没有两条重样；每条都是「长期积累 → 东西起变化 → 带着它走一段专属试炼 → 一次性的取得仪式」。五条拟稿等作者挑或改写，作者给了原文的才派执行。共同规则：试炼战战败不掉体力、每局只能挑战一次；取得时红武落在被消耗掉的那些件腾出的格子里，不会没格子。

### 4. 来路 B：BOSS 持有**劣化版**（作者 10:48）

- 章 ≥2（按点的档位 ≥3）的核心 BOSS 和猎手开战前各掷一次：持有 p = 1% × (1 + 进阶级)，上限 5%，按 BOSS 的武器类配（没有对应类就不掷）。
- BOSS 拿的是**劣化版**（`<id>_lesser`）：面板和本体完全相同（伤害 / 冷却 / 耐力 / 常规句），**没有独有机制**，**不是 `unique`**——可以同时拥有多把，和本体是两个 id，本体的全局一件不受它影响。名字同两字，图用本体图压暗（暗红），提示框不加字（少了独有那一行就够分辨）。可出售（卖价照橙 ×2），不上砧、不附魔、不吃品质。
- 持有时它真的拿这把打（替掉同类武器，战前准备屏可见）。打赢才掷掉落：p = 20% + 10% × 进阶级（总 0.2%–1.5%），掉的也是劣化版。
- 破晓的首领「黎明」是例外：拿的是本体，固定掉（§四.3）。
- 常规掉落表、商店、敌人池都不收 `unique`，也不收 `_lesser`。

### 6. 三条作者路的评估（作者 11:40：复杂度、隐蔽程度、别太机械）

口径：**复杂度** = 玩家要走的段数 + 要新写的系统数；**隐蔽度** 1–5（1 = 明摆着，5 = 没攻略几乎碰不到）；**机械感** = 纯刷次数的段、靠小概率的段。局数按魔法废墟一局走 10–14 个节点、河边节点约占四分之一估（底图 ruins.png 的河从左下斜到右上，穿过路网中间）。

| 路 | 段数 | 新系统 | 预计局数 | 隐蔽度 | 纯刷 / 小概率 |
|---|---|---|---|---|---|
| 寂灭 | 5（累积 → 变黑 → 四图试炼 → 无信仰献祭 → 结算动画） | 5（实例计数 + 变色、章节特殊节点 + 单元素战、神坛献祭、残余意识界面、黑洞动画） | **≥ 50 + 4**（新章出来前拿不全） | 2 / 献祭那步 4 | 50 局是三条里最重的一段纯累积；不靠概率 |
| 刹那 | 7（倒转节点撤离 → 沙子 → 三碎片 → 书架沙漏 → 三次钟房 → 必败战 → 动画） | 7（倒计时倒转、沙子改商店权重、仓库清空 + 书架第六格、钟房节点 + 时段判定、机关图三档大小、必败战 + 失败结算动画、三件特殊道具） | **7–10**（最短） | **5** | 「对应的节点」怎么出没写；商店「大概率」；时段无提示；三碎片凑齐**仓库全清**是隐蔽的毁灭性代价 |
| 断水 | 6（河边 50 次 → 打捞 → 河边 30 胜 → 三次抉择 → 两连战 → 变形） | 6（河边节点标记、跨局两种计数、打捞事件、抉择事件 N 递增、强回复敌人 + 必然第二战、开战变形动画） | **30–40**（最长：50 次 ≈ 15–20 局，30 胜 ≈ 15–20 局） | 3 | 两段纯刷；「有几率打捞」是唯一的小概率门 |

逐条：

- **寂灭**：过程全可见（10 次就变色，玩家自己会发现在养它），试炼节点带着全黑法杖才出、每局一次、败不掉血，都不机械。两处可改：① 50 局只按「带进带出」算，法杖放包里当乘客也算——建议**只算它出过手的局**（这局用它打过至少一场），和作者的「反复使用」一致，也堵住白蹭；② 「没激活信仰才能开神坛献祭」是全程唯一没有任何提示的一步，隐蔽度从 2 跳到 4——建议全黑法杖 + 四材料在包里时，神坛在信仰激活状态下仍出「献祭」项但按不下去（灰），提示只有一句（作者写），其余照旧。
- **刹那**：最短、最独特，也最隐蔽，四处要补：① **「对应的节点」出现条件没写**——若随机刷就是小概率依赖。建议固定：机关沙漏的核心节点（`with_core`，每局都在）进去即倒转，不靠概率；隐蔽性留给「必须在倒计时满前撤离」这个反直觉的规则。② 商店「大概率出碎片」——建议持有沙子时**每次刷新必出一块、最多一块，直到三块**；刷新本来要钱（40 + 20 × 次），代价已经够，别再叠概率。③ **机关沙漏现在没有大小分档**（只有魔法废墟有小 / 中 / 大，步限 36 起）——要么给机关沙漏加三档，要么改成**同一张图、三个不同的倒计时时段窗口**（沙漏道具上画着这次该在哪一段去钟房）；推荐后者，不动地图。④ 「凑齐三碎片后所有道具从仓库里消失」——玩家买第三块时不知道会清仓，这是三条里唯一**无法预见的毁灭性代价**。建议顺序改一下：凑齐三块 → 书架第六格先出现沙漏 → **点击时**才清仓并给【完整的沙漏】，点击前一句确认（作者写）；献祭的味道保留，但变成知情的选择。⑤ 必败战 + 失败结算动画是好的：不靠概率，情绪点在最后。
- **断水**：河在底图上明摆着，玩家会好奇河边有什么，隐蔽度最合适；「丢剑换 N 宝箱 / 保留」三次递增是真诱惑，不机械。三处要改：① **「有几率打捞」**——50 次经过本身已是门槛，建议 50 次后**下一次**进河边事件节点必触发，不叠概率。② 两段纯刷（50 次经过 + 30 胜）是三条里最长的——建议把刷变成选路：河边节点在图上可辨（靠河的节点带一笔水纹，奥卡姆：图说话、不写字），玩家主动走河边；数字先不动，等落地后看战记里实际局数再调。③ 两段计数都没提示——建议【水中长剑】的图随胜场变（每 10 胜剑身多一道水纹，30 胜满），和寂灭变黑同一种语言；经过次数不提示。
- **作者 12:33 答**：① 提示一律不另加——后期道具说明文本会带提示，所以寂灭的「献祭灰掉」、刹那的时段提示、断水的「长剑随胜场变图」都**不做**；② 河边节点**不标**，地图样式本身就是重点；③ 刹那凑齐三碎片清的只是三碎片和沙子，不是整个仓库，「毁灭性代价」一条**作废**。仍待作者定的：刹那倒转节点怎么出、碎片是否必出、机关沙漏三档 / 三个时段；断水打捞是否必触发；寂灭是否只算出过手的局。
- **横向**：三条都不靠 BOSS 之类的极小概率事件，这点好。小概率只剩两处（刹那碎片、断水打捞），按上面改掉就没有了。纯刷最重的是寂灭的 50 局，但它的过程可见、不靠运气，可以保留；断水靠选路化解；刹那没有刷。隐蔽度最该补提示的是刹那（时段、清仓）。

## 五、极端武器（两条线，6 把，蓝到橙）

设计口径：**单次伤害 = 同带普通武器的 4–5 倍，冷却 4.4–5.0 秒，一下的耐力 = 基线上限的六到十成**。基线（50 / 回 4）下第一下必出、第二下常常付不起（跳过且冷却照走），实际 DPS 只有标称的六成左右；配上耐力上限 / 回复的件就能每次冷却都出手——这是它们的 build 条件，不是 bug。每一下都是「大锤」：对格挡（按下吸收）和护甲都比碎刀划得多。红不在这两条线里（红只有 §四 的八把，「崩山」就是红里的极端件）。
