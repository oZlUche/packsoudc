# 290 局内商店重做：商人一张大棋盘、一次性展出、天秤称价、以物易物（087 / 263 补充）

> 作者 2026-11-07 15:11（UI设计线程，附现在商店截图）：「重做整个局内商店的界面，改成类似博德之门3那样，商人也是有一个大的棋盘，里面的道具不再刷新，而是一次性展出，中间下方有一个天秤，用于衡量价值，玩家可以以物易物或者用金钱购买，双方的钱袋子分别移动到左右下角，点击钱袋可以在天秤不平衡时快速补齐，商人头像放左上角」。直接指派：规则本篇定、待定按推荐派执行；整屏布局与天秤 / 钱袋美术由 UI设计 出样作者挑。

## 〇 一句话

商店屏变成**一桌买卖**：左边商人的棋盘（8 × 6，一局一次摆满、卖掉就空、不刷新），右边自己的背包（照旧）；**拖过去就是放上桌**（商人的货拖进自己的包、自己的东西拖进商人的棋盘，东西真的挪过去但染成「待成交」色），中下一座天秤：左盘 = 你拿的货的售价之和，右盘 = 你给的东西的收购价之和 + 你放上的钱；**右 ≥ 左「成交」才亮**。点自己的钱袋 = 差多少补多少，点商人的钱袋 = 多出来的他付你（他袋里有多少付多少）。离开没成交，东西各回各家。

## 一、现状（读码）

- `ShopSession`（`core/run/shop_session.gd`）：四个**栏位**（`shop_slots` 4，每格一块 ≥ 3×4 的小棋盘），按 `shop_rarity_weights` × 深度抽（`shop_depth_gain`），30% 一格换包、35% 一格换金银；花钱刷新（10 起步）；卖 = 拖进出售区，回定价 × `shop_sell_ratio`（标准 / 序章都 0.3）；277 第 4 条「回购」= 本次卖的最近一件原价买回；160 补一「随身」一排（随身技能 `belt_stock` 抽 1–2 种，按钮买直接进腰带）。货架由 `content_seed` + 刷新次数决定，存档只记刷新次数与卖掉的格（`node.content["shop"]`）。
- 屏（`ui/game/shop_screen.gd`）：左店右包（087），帐篷框（233），木货匣框（263 A）；拖进自己的棋盘 = 买（放手收钱，钱不够弹回），双击 = 买（自动找位）；钱袋 `CoinPouch` 在货架右下角之下（263）；282 店主 `NpcBadge` 在货架那块。
- 天平已经有一座：256 求饶屏的 `BalanceScale`（`ui/widgets/balance_scale.gd`，青铜四层图 1000 × 724、`ransom/ransom_layout.json`，左盘托盘 + 金币堆、右盘开价、梁上差额牌「还差 N / 够了」）—— 这回**同一个类换一套小尺寸布局**，不另写。
- 一张图上商店点的数量由节点规则随机权重定（`shop` 1），每个点一家店、各自的货。

## 二、做法

### 2.1 商人的棋盘与货（一次性展出）

| 事 | 定法 |
|---|---|
| 棋盘 | 一块 **8 × 6** 的 `GridInventory`（容器 id 新定），木货匣框（263 A）照用；UI设计 按真实格尺寸核一遍，摆不下就 8 × 5 |
| 货量 | `EconomyRules.shop_stock` = **10 件**（替代 `shop_slots` 4），按现在的稀有度 × 深度权重不重复抽，再按 `shop_bag_slot_chance` 加一个包、`bullion_slot_chance` 加一件金银（同现在）；按抽到的顺序自动找位摆上棋盘（大件先放），放不下的丢掉不补 |
| 不刷新 | 删刷新键与 `shop_refresh_cost / step`；卖掉就空着，这一局这家店不再上货 |
| 存档 | 棋盘整块存进 `node.content["shop"]`（道具实例 `to_dict`，和别的容器一样），不再靠种子重算（买卖之后内容变了） |
| 随身 | 「随身」小匣留着（棋盘下面两格，同现在），不是道具不拖：点一格 = 放上桌（它的价进左盘，格子染色），成交才进腰带 |

### 2.2 桌上的买卖（以物易物）

- **放上桌** = 拖过去：商人的货拖进自己的棋盘 / 地上，自己的东西拖进商人的棋盘（空格随便放）。挪过去的东西染**待成交**色（半透明金边，UI设计 定），右键「收回」或拖回去就撤销；双击 = 拖过去（自动找位，先包后地上 / 商人棋盘空位）。
- 不能上桌：锁住的（230）、独一的红武（281）、随身之物（255）、包里还装着东西的包（先倒空）。
- **天秤**：左盘 = Σ 你拿的货的**售价**（`price_of`，含 buff 倍数）+ 随身格的价；右盘 = Σ 你给的东西的**收购价**（`sell_price_of`：定价 × 0.3，碎了再打折）+ 你放上的钱；梁按差额倾斜，差额牌写「还差 N」/「够了」/「找你 N」。
- **钱**：自己的钱袋（右下角）写余额，**点一下** = 把还差的那么多钱放上右盘（够了就放差额、不够就把能放的全放上，牌子仍写还差）；再点一下 = 收回。商人的钱袋（左下角）写他袋里的钱，右盘比左盘重时点一下 = 他把多出来的放上左盘（不超过他袋里的钱）；再点一下收回。
- **成交**（右 ≥ 左才亮）：钱从你钱包进他钱袋、他放的钱进你钱包；待成交色褪掉，东西归新主人；随身格进腰带（腰带满了那一格退回桌上、不成交）。**找零不自动**：右盘重出来的那部分，你不点他的钱袋就是白送（和博德之门一样，牌子会写「找你 N」提醒）。
- **离开**（Esc 同）：桌上的东西各回各家，钱也收回。「收起」键删掉：离开再回来是同一张棋盘，不需要「店还开着」的半状态。
- **回购**（277 第 4 条）自然成立：你卖给他的东西摆在他棋盘上，**这次进店内**挂的售价 = 你拿到的收购价（原价买回）；离开再来就按正常售价挂。

### 2.3 商人的钱袋

- 一家店开张带 `EconomyRules.shop_purse_base` **100** + `shop_purse_depth` **200** × 深度（深处的商人有钱）；你付的钱进袋、他付的钱出袋；一局内不回填。存进 `node.content["shop"]`。
- 他付不起时「找你 N」变「他只付得起 N」，成交照样能按（你认了就按）。

### 2.4 布局（UI设计 出样，这里只定件与位置）

- 商人在左：左上角店主头像（282 `NpcBadge`，现在就有）、下面 8 × 6 棋盘、棋盘下随身两格、左下角商人钱袋。
- 自己在右：背包面板照旧（棋盘 + 地上），右下角自己的钱袋（263 的位置挪到角上）。
- 中下：天秤（`BalanceScale` 换小布局 `shop/scale_layout.json`，两盘各写总价，梁上差额牌）；底部只两枚键「成交」「离开」。
- 帐篷框（233）与木货匣框（263）照用。

## 三、改动清单（执行）

1. `ShopSession` 重写：`board: GridInventory`（8 × 6）、`shop_stock` 一次抽满、`purse`、`offer`（桌上的两份清单 + 两盘的钱）、`left_total / right_total / can_deal / deal / cancel`；删 `shelves / refresh / sell_box / buyback`；回购 = 本次卖出的实例记一张「原价表」。存档：棋盘与钱袋进 `node.content["shop"]`，老档没有就按种子摆一次。
2. `EconomyRules`：`shop_stock` 10、`shop_purse_base` 100、`shop_purse_depth` 200；删 `shop_slots / shop_refresh_cost / shop_refresh_step`；两份 json 跟着改；导入校验。
3. 屏：左棋盘 + 随身格 + 商人钱袋、右背包 + 自己钱袋、中下天秤、两枚键；拖拽规则 `_allow_drop` 改成「上桌 / 回家」；待成交色；双击；右键「收回」；钱袋点击；差额牌三种字。
4. `BalanceScale`：布局文件可换（构造传 layout 名），差额牌多一种「找你 N」/「他只付得起 N」。
5. 文案 `UiText`：「成交」「离开」「还差 %d」「够了」「找你 %d」「他只付得起 %d」「收回」「这个不能上桌」；删 `shop.refresh*`、`shop.buyback*`、`shop.sell_box*`、收起。
6. 帮助页「商店」改写；店主台词 284 §3.1 第 1、3 句照旧成立（卖给我 / 公道价）。
7. 测试：一次抽满不重复、不刷新；买（钱够 / 不够补齐 / 补不齐灰）；以物易物（货换货、右盘重找零、不点钱袋白送）；商人钱袋付不起；离开全退；锁 / 红武 / 随身之物不上桌；随身格进腰带 / 腰带满退回；回购原价只在本次；存档读回棋盘与钱袋；老档按种子摆一次。
8. UI设计：整屏样图 + 天秤小布局 + 两只钱袋位置；作者挑定后交执行；执行先用 256 的青铜天平缩放占位。
