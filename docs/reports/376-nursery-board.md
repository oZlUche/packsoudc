# 376 苗圃改棋盘：一片地是 4×4 格子盘，作物按形状摆，各自成熟

> 作者 2026-11-21 19:07 三条答复的落地记录。接报告 375（灰灯食堂第三批下）。

## 作者原话

1. 不设上限
2. 一畦地能种多少个作物？另外这个量词有点生僻，改成【片】
3. 作物的具体摆放和容纳数量都可以用棋盘系统来管理，每种作物用不同的成熟时间，后期还可以在田里加上特殊道具用于增产或者催熟相邻作物

## 落地

1. **蜜柚回血不设上限**：报告 355 里蜜柚每秒回 40% 体力这一条照旧，不加每秒上限，也不减半。代码不动。
2. **量词「畦」改成「片」**：苗圃页、片键、委托文案（《第一畦》改叫《第一片地》，「种一畦」改成「种一株」，「收一畦」改成「收一次」）都改了。
3. **苗圃改成棋盘**：
   - 每片地是一块 **4×4** 的格子盘，带边框和格线（和全项目的棋盘规则一样）。
   - 一株作物按它收成那件食材的形状占格子（酸麦 1 格、山薯 1×2、长葱 1×3、蜜柚 2×2 等），摆得下几株就能种几株，一片地最多 16 格。
   - 每株自己算成熟：种下时记着还差几局，每局正式出征结束推一格（和原来一样：空跑不推，同一局不推两次）。
   - 【收获】一次收掉这一片里所有熟了的，没熟的留在地里。仓库放不下就整批退回，地里照旧。
   - 一株收一件（苦叶草一株收两束）；酸麦、山薯、粗麦捆每株照旧有机会多收一件优良的。

大致规律：占格越多、食材越好，熟得越慢。

### 怎么种（占位界面，等 UI设计 出样）

- 纸条上的【种下】：自动摆到这片地第一个放得下的位置（会转方向）。
- 纸条上的【选中】：再点地里的空格，种在那一格（放不下会自己试转方向）。
- 没熟的一株画暗，角上写还差几局；熟了的描金边。悬停写作物名和还差几局。
- 片键上熟了的那片写「可收获」，【收获】悬停写「熟了 N 株」。

### 存档

- 新存档存每片地的格子盘和每株的成熟进度。
- 老存档里每畦种着的，读档时摆一株进对应的那片地，还差几局照旧；认不得的作物当空地。

## 暂不做

- 作者第 3 条后半句「田里加特殊道具，增产或者催熟相邻作物」：这一版不做。棋盘已经能认出相邻格子，以后加道具时直接用。
