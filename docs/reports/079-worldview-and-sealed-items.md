# 079 · 世界观（待确认）、封存现代道具、小说里的第一批剑与魔法道具

> 第 8 阶段 8-4 的起步 ｜ 架构文档 0、3.1、16（v1.77）｜ 前一步：[078 沙漏与塔](078-lattice-templates.md)｜ 世界观文档：[docs/worldview/worldview.md](../worldview/worldview.md)

作者给了小说的前四章（第四章只有一行），说：正式游戏的世界观是**剑与魔法**，以小说为基底；需要先确认世界观，再以此定道具；
**现有的枪械等现代道具保留数据、不再使用，标签改成 `sealed`**。

## 一、世界观文档

作者随后补了两句：**小说只是参考背景，不用完全一致，神话背景才是重点**；**帝国作为背景也是必要的，但角色可以有各种身份**。文档按此改成五节：
**神话**（众神造人各赐一福、诸神争端人类分裂、种族天赋 = 赐福、已知的四位神与祂们的赐福、神弃与诅咒之地、眷顾变成学问 —— 从小说里读出来的，不添）；
**神话怎么撑起游戏**（道具一级分类 = 哪位神的赐福、角色 = 种族 = 赐福、侵蚀 = 神弃加深、敌人 = 别的神的信徒与失控造物、事件 = 祭坛 / 神迹……全是提议）；
**帝国与诅咒之地**（必要的背景；角色的身份与种族天赋是两层：身份定立场与开局，赐福定天赋）；**小说里的参考背景**（军功、奴隶的日常、系统、物件表 —— 可取可不取）；
**要作者拍板的八个问题**（神明清单与域、赐福的形式、诸神争端的现状、玩家的信仰、神弃的表现、魔法、身份清单与身份影响什么、封存是否永久）。

## 二、封存：一处拦

- `ItemDef.SEALED = &"sealed"`、`is_sealed()`。带这个标签的道具**数据保留、按 id 取得到**（旧存档、仓库里的照认），**但不进任何候选**。
- **只在 `ItemDatabase.ids()` 里拦**：搜索候选、商店候选、敌人的流派 / 通用道具、珍宝候选、图鉴、事件编辑器的道具下拉都从它拿清单，所以别处一行没改。
  要全部的（导出工具、资产测试、存档校对）用 `all_ids()`；`sealed_ids()` 列封存的；`size()` 数全部。
- 导入器多拦四处：开局装备、角色初始包、敌人的招牌道具、事件「给道具」引用封存的都报「已封存」。
- 封存了十五件：手枪、步枪、冲锋枪、霰弹枪、狙击枪、弹匣、电池、无人机、防弹衣、防弹装甲、高级防弹衣、能量核心、兴奋剂、医疗包、撬棍。
  留着：匕首、剁刀、口粮、药水带、三种包（都不违和）。
- 这不是「删」：作者要的是保留数据。`data/authoring/items/` 里的十五份 JSON 只多了一个标签，数值一个没动。

## 四、测试

新套件 `tests/test_sealed_items.gd`（两组）：封存的数据还在、`ids()` 不含、`all_ids()` 含、能用 + 封存 = 全部；搜索 / 商店 / 敌人流派 / 敌人通用 / 珍宝 r3 / r4 六张候选清单非空且一个封存的都没有；
十九件新道具在库里、异化黑曜石小而贵、项链不参战；三套开局装备、角色初始包、敌人招牌都没封存的；导入器拦开局装备与事件给封存的、没封存的照过。
老测试里直接按 id 用枪的（`get_def("rifle")`）一条没改 —— 数据还在；从清单推的改成从 `all_ids()` 推（管线往返、资产合法性），开局装备的样例换成短剑。
标准开局装备的形状得能装进两个皮革包（导演测试把仓库里的第一套全带上），所以圆盾没放进标准套。

**通过 8745 项断言，55 个套件。**（080 改暂存区规则后 8749 项）
