### 产出

- `core/battle/faith/earth_heaven.gd`（新，[EarthHeaven]）：分层（纯函数）+ 战斗里的那一半（开战、受伤前、伤害）。
- `core/run/faith/perks/earth_heaven_perk.gd`（新，[EarthHeavenPerk]）：奉神即有；编译时按牌和摆放填数；进点（苦劳、锻炼、修行、万象、西西弗斯）。

### 读法对照（作者只回不同意的）

| # | 牌表里的词 | 我的读法（已经这样做了） |
|---|---|---|
| 1 | 【大地】「边缘贴近棋盘边界」 | 道具至少一格在棋盘最外一圈（整张棋盘的边框，不是包的边），或者挨着缺格 |
| 2 | 【穹顶】「贴近棋盘中央」 | 从边界往里数圈，不是大地、至少一格落在最里面那一圈的道具（8×6 的棋盘是中间 4×2 那一块） |
| 3 | 【支柱】 | 既不是大地也不是穹顶的（夹在中间几圈）。分层总是算，【支柱】牌只是让支柱有用 |
| 4 | 谁算「道具」 | 棋盘上所有非包的道具（素材也算）；战斗里的牌不算标了不参战的 |
| 5 | 「新节点」/「旧节点」 | 这一局第一次踩上的点 / 踩过的点再踩一次 |
| 6 | 苦劳「等同于负重」 | 进点那一刻的负重（背包重量合计），换成金钱 |
| 7 | 锻炼「耐力或生命上限」 | 每次随机二选一，涨大地件数 × 50%（小数攒着，开战取整） |
| 8 | 磐石「重量 +50%」 | 拿着这张牌时，大地道具在负重里多算一半；护甲 = 每件大地的格子数 × 8，开战加在护甲上限和当前护甲上 |
| 9 | 天光 | 每件穹顶格子数 × 5 的真实伤害，开战一次打出 |
| 10 | 「随机增益」 | 自然之神【枯荣】那张表里随机一条标准轴的有利方向（急速、增伤、减伤、回复、暴击……）；【支柱】每件支柱抽一种给 5 层，【脚踏实地】每件大地抽一层；只在这一场 |
| 11 | 举重若轻「越重越低」 | 每件武器每 1 点重量耐力消耗 −2%（最多 −100%）；升级版另外每 1 点重量急速 +1% |
| 12 | 修行「负重盈余」 | 负重上限 − 当前负重（超重算 0），换成经验值（照常乘难度系数） |
| 13 | 修行升级「满级时此牌变为一次质变机会」 | 到满级后进下一个新节点，多欠一次质变选牌（和蛮神献祭同一种），只给一次，之后不再给经验 |
| 14 | 万象「不同类型的节点」 | 这一局进过几种点（战斗、精英、搜索、休息……按实际类型），从奉神开局就记；每种经验 +10%、金钱 +10% |
| 15 | 万象「获得的金钱」 | 打赢的钱、事件给的钱、苦劳的钱；卖东西不算（不然能倒买倒卖） |
| 16 | 万象升级「满级时经验增益的一半变为金钱增益」 | 满级后经验加成减半，减掉的那份加到金钱上（每种 +10% 经验、+30% 金钱） |
| 17 | 生机 | 大地件数 × 50% 的每秒生命恢复（拿几张乘几） |
| 18 | 自强不息 | 每件穹顶全部道具伤害 +1%（拿几张乘几） |
| 19 | 「固定伤害」（冲撞、万钧）与玉石俱焚的「伤害」 | 开战打一下，数是固定的（不吃自己的增伤、不暴击），照常被敌人的护甲吸收；不算直接伤害，格挡挡不到 |
| 20 | 冲撞「道具数」 | 参战的非包道具件数 |
| 21 | 玉石俱焚「最高价值道具价值」 | 棋盘上最贵那一件的价值（按包的倍率算） |
| 22 | 厚实「固定减伤」 | 一个格挡来源，数 = 最大那件道具的格子数；和盾的格挡取最高、只挡直接的非真实伤害（11-26 格挡规则） |
| 23 | 反震「受到攻击时」 | 被敌人直接打中一下（被层峦挡掉的不算）；真实伤害 = 大地件数，冷却 6 秒 |
| 24 | 擎天一柱「随机元素」 | 灼烧 / 冰寒 / 中毒 / 麻痹里每件支柱抽一层 |
| 25 | 层峦「每有一对」 | 对数 = 穹顶件数和大地件数里少的那个；每对挡一次敌人的攻击（视为没发生，真实伤害也挡；持续伤害不是攻击，不挡） |
| 26 | 西西弗斯「所有属性」 | 同困兽：伤害、急速、生命上限、耐力上限、两种回复、暴击率、暴击伤害；每进一次旧节点 +1%，整局累积 |
| 27 | 专属牌「只能拿一次」、作者备注「中稀有度」 | 专属牌拿过就不再出；玉石俱焚出牌权重 0.5 |
