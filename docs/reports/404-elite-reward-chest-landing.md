# 404 落实记录：精英的额外奖励改成宝箱

> 2026-11-28。照 [404](404-elite-reward-chest.md) 第二到第四节落实；第五节四处待定都按推荐（A）做，作者改了再跟着改。

## 对照表

| 报告里写的 | 实际做法 |
|---|---|
| 二.1 打赢精英，那一件不再进战利品，原地留精英宝箱 | `DropResolver.roll` 不再放精英那一件。`NodeEvents._settle_won` 收尾时调 `_leave_elite_chest`：在这个点的内容里写 `chest = {rarity, skin, elite: true, prize}`。必出的那一件这时就定好（挑法和原来的保底一样，随机数另起一条 `elite_chest`）；没信仰的局不出归神的东西 |
| 二.1 开法和地图宝箱一样 | 用现有的宝箱屏、宝箱图、长按开锁（按住秒数按宝箱的档），开了是一次搜索会话（只搜一次、不遭遇） |
| 二.2 战利品之后接宝箱；不开就走，宝箱留在点上 | 宝箱屏排在战利品屏后面。不开就走回地图，点上还留着；站在点上能再打开，走开再回来（`RunState._arrived_again` → `NodeEvents.offer_chest`）也会再弹 |
| 二.3 宝箱的档 = 难度表 H 列 | 取 `DropResolver.elite_rarity_of`（难度写了用难度，没写用掉落规则），H 列不用改 |
| 二.4 必出一件同档 + 随机 1～2 件、不设下限、能出珍宝、不遭遇 | 随机的几件按这个点当地的搜索规则掷（环的产物表照样加权）。必出的那一件排在随机件后面，不换赐福版（原来那一件也不换） |
| 四.2 小表单独一份，数字写在数据里 | `ChestRules` 新加两项 `elite_random_items = [1, 2]`、`elite_include_treasure = true`。标准与切片的节点规则 JSON 里多了一整块 `chest`（导出器把地图宝箱原来的默认值也一起写出来了，数值没变）。导入时校验件数不为负、min ≤ max。编辑器字段名：「精英宝箱随机几件」「精英宝箱能出珍宝」；`elite_rarity` 的字段名改成「精英宝箱稀有度」 |
| 三 局外科技【精英奖励】 | 不动，照旧另掉一件进战利品 |
| 三 首领、A12 守卫的失效联动道具 | 不动。守卫也是精英，照样留宝箱 |
| 三 蛮神秒杀精英 | 走同一条收尾，照样留宝箱 |
| 三 自然之神跳过的精英兽 | 没打，没有宝箱 |
| 三 撤离结算、战利分 | 宝箱里拿出来的和别的战利品一样算 |
| 三 切片、序章 | 同一条规则。切片必出的那一件仍然只从 `guarantee_pool` 里挑（测试照旧是涂毒匕首） |
| 三 存档 | 宝箱在节点内容里，跟着存档走；旧存档里打过的精英不补 |
| 四.4 说明页、难度说明 | 百科「节点类型」加了一句（中英）：打赢精英原地留一个精英宝箱，开法一样，里面必有一件好东西，不开就走也行，回来还能开。**难度说明里原来没有写「精英额外掉落」的地方**（A4、A8、A12 的说明都没提这一件），所以没改，也没新加 |
| 四.5 校准 | 见下一节。变化在一成以内，随机件数保持 1～2 件 |

顺带修的一处：回放屏收起来（不看完）就走开时，排在后面的宝箱屏会在下一个点弹出来、开不了也关不掉。现在宝箱屏只在站在那个点上时弹，走开了就不弹（回去还能开）。

## 校准：带回价值，改之前 / 改之后

`tools/sim/encumbrance_sim.gd`，每组 10 局，规模 small、medium，拿法 greedy，角色三个，四档难度各 60 局，共 240 局；玩家血量 10000（必赢，只看搜刮）。两边用同一组种子。

| 难度 | 局数 | 撤离局 前 / 后 | 每局打的精英 | 带回价值（战利分）前 | 后 | 变化 | 撤离时棋盘价值 前 | 后 | 变化 |
|---|---|---|---|---|---|---|---|---|---|
| A0 | 60 | 36 / 36 | 1.4 | 1413 | 1367 | -3.3% | 2597 | 2557 | -1.5% |
| A4 | 60 | 36 / 37 | 0.9 | 2405 | 2455 | +2.1% | 3678 | 3792 | +3.1% |
| A8 | 60 | 9 / 10 | 1.1 | 794 | 932 | +17.4% | 4701 | 4741 | +0.8% |
| A12 | 60 | 10 / 11 | 1.2 | 1144 | 1154 | +0.9% | 5833 | 5666 | -2.9% |
| 合计 | 240 | | | 1439 | 1477 | **+2.6%** | 4202 | 4189 | **-0.3%** |

- 「带回价值」是结算的战利分（保险箱 + 撤离时带出的；战败只算保险箱）。A8 那一行 +17% 是因为 60 局里只有 9～10 局撤出来，多撤一局就差很多；看棋盘价值（每局最后背着的东西）只差 +0.8%。
- 合计两项都在一成以内，所以随机件数不降到 1 件。

**机器人修了一处**：`encumbrance_sim` 以前在回放屏走「收起」，排在后面的战利品没拿就走了（打仗的战利品一件都没进过账）。现在回放看完接着看战利品与宝箱。上表「前」「后」都是修过的机器人跑的；没修之前那一份（改动前带回 1355、棋盘 3904）不能和这份直接比。

对比表脚本：`python3 tools/sim/compare_haul.py before.jsonl after.jsonl`。重跑：

    godot --headless --path . --script res://tools/sim/encumbrance_sim.gd -- 10 before.jsonl small,medium greedy normal,ascension_4,ascension_8,ascension_12
