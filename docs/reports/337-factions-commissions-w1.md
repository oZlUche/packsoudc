# 337 阵营与委托 W1：三张原型单走通（占位美术）

> 日期：2026-11-19。接[报告 336](336-factions-commissions-w0.md)（W0）。规格见[报告 335](335-factions-commissions-exec-spec.md) 第四、五节与第七节 W1。
> 基线：main `c9f1714`（v6.57）。**这一批做完先请作者试玩，再往下做 W2。**

## 目标

335 第四节的循环在真界面里走得通：同时接《两条回路》和《无人署名的信》，交完信、查了一处出口后败退；回营看到灰灯那份已办成、军团那份还差一处；结算屏分别写出来。读档、重进节点、重复结算都不重复记账。

## 一、先更正报告 336 的一处判断

336 第一节说「撤离点到点走 `extract_reached`、不弹事件屏，【查验】【交信】改做成确认框上的键」。这一句**说反了**：

- 撤离点按节点规则挂着 `extract_default` 事件，到点就弹这个事件屏，玩家选「撤离」→ `NodeEvents` 走 `hooks.request_extract()` 直接撤离。
- 地图上的撤离**确认框**（`map_screen._open_confirm`，有【托付】的那个）只有 `map_screen.extract()` 会开，而游戏里没有任何地方调它，只有测试在调。

所以 W1 回到 335 原来的做法：「查验这处出口」「把信交给接应员」加进 `extract_default` 事件，选完回到同一个事件（还能接着撤）。确认框上也挂了同样两颗键，确认框哪天接回来时不用再改。

**顺带发现（不是这一批引入的，请协调确认）**：287 的【托付】只在这个确认框上，按上面的判断，真玩时可能根本点不到托付。我没有改它，因为这是托付那条线的事，改法也要作者定：是把托付加进撤离点事件，还是把确认框接回来。

## 二、做了什么

| 部分 | 内容 |
|---|---|
| 委托物 | 新标签 `commission`（委托物）。带这个标签的东西不能卖（出售键灰着写原因）、不献祭、不赐福、不附魔、不合成、不进任何随机来源（掉落、商店、事件、`ItemDatabase.ids()`），图鉴也不列、不受侵蚀，撤离也不带回仓库 |
| 任务信 | `commission_letter`：未署名的信，1 格，没画图（画板自动用占位），说明留空给作者写。接着《无人署名的信》出征时发进背包，背包满了放脚下并说一句 |
| 局内模块 | `CommissionModule`（标准模块表里，所有章节都装）：开局拿到带进来的委托，记这一局的进度，跟局档一起存读。查验、交信都按「这一局 id + 节点 / 道具 uid」记，同一处不会记两次 |
| 撤离点事件 | `extract_default` 多两项，不满足就不显示：查验（带着查验委托、这处没查过）；交信（带着信、是免费撤离点、倒计时没关）。付费撤离点查验不收钱 |
| 打造记账 | 基地铁匠铺打成一次，如果是《照抄也要做得出》选的那张配方就办成。成品照常归玩家，酬金只是劳动报酬 |
| 结算并账 | `GameFlow._settle_run` 里和 `absorb` 同一次结算并进局外：现场的（查验、交信）败退也算；`settled_runs` 挡住重复结算 |
| 委托簿 | 基地第五个页签「委托」，排在「出征」后面。左列三方各一颗键，右边是这一方的牌头（几级、声望、离下一级还差几点）、任务卡和回执。卡上五栏：替谁办、做什么、在哪完成、报酬（金币图 + 声望），然后是状态和键（接下 / 暂缓 / 接着做 / 放弃）。配方实验接单前要从下拉里选一张现在打得出的配方，没选时「接下」灰着 |
| 局内小牌 | 新 HUD 小件「委托」，放在地图左上（右边会把地图往左挤，也避开 334 的悬停预览）。每份一行：名字　做到几 / 要几，办成写「已办成」。旧的 HUD 布局档打开时自动补上这一件 |
| 结算屏 | 第一页的「洞察」下面多一段「委托」，羊皮纸条，每份带进去的委托一句：办成了 / 这一步办成了 / 要重做 / 还差几处 / 这一局没有进展 |
| 隐藏 | 统一教程没走完、试玩切片档案：不显示页签、出征不带委托、接不了 |

## 三、和 335 不一样的地方（都是候选，作者可以改）

1. **查验跨局累计**。335 写「同一局里两处不同出口」。我做成了跨局累计：每次查一处新的就记一处，两处查完就办成。原因是标准图一局里通常只有一处免费、一处付费出口，要求同一局查两处会逼玩家绕路去付费点再折回来；跨局累计也不影响「败退也算」的手感。要改回同一局，只要败退时把进度清零即可。
2. **《两条回路》暂时不要熟面**。这张是调查（+2），按 W0 的规矩要「熟面」才能接，可军团的入门委托 W2 才有。所以先写了 `min_tier: 0`，W2 加上入门委托后删掉。
3. **出征页还没有「已选的两份」**，也没有「这章撤离点不足两处，换一章」的提示。真玩时要看带了什么，可以看委托簿，或者进图后看左上小牌。打算放到 W2，和现场请求一起做。
4. **每方只展开推荐的下一步**还没做：首版每方只有一张，折叠没意义，W2 有五张后再做。

## 四、新文字（候选，作者可以改）

- 道具：未署名的信 / Unsigned Letter。标签：委托物。
- 事件选项：查验这处出口 / Inspect this exit；把信交给接应员 / Hand the letter to the contact。
- 等级：陌生、熟面、受托、代言。
- 委托簿键：接下、暂缓、接着做、放弃；状态：已接、暂缓中、已办成。
- 灰键原因：还接不了、已经办成、已经接着、同时最多接两份、声望不够、要先办完前一份、这件事已经交给了别人、要先选一张现在能打的配方（一张都没有时写「没有现在能打的配方」）。
- 结算 / 回执：「……：办成了」「……：这一步办成了」「……：没带回，这一步要重做」「……：还差 N 处」「……：这一局没有进展」。
- 局内提示：信已送达、查验了这处撤离点、委托办成，回营领酬；出售键：委托物不能出售。

三张委托的委托人原话照抄方案原文。

## 五、占位与美术

委托簿的卡、牌头、回执和结算段落都是现成的羊皮纸条（浅底墨字，声明为亮面）；左列键是基地现成的键；「委托」页签的小图是我画的占位（墨色信封，和另外四枚同样 36×36）；局内小牌用的是 HUD 默认底。都不是定稿，样张已请 UI设计（新）出给作者挑。
