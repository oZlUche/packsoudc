# 060 · 暂存区按点清空：走出发生过事的点时清，走之前按档位提醒

> 058 / 059 顺序里的第 1 项 ｜ 架构文档 3.4、15 节第 7 项（v1.58）｜ 前一步：[059 设想](059-event-layer-and-buffs-proposal.md)

作者定的（058 第五节）：暂存区不跨节点保留，它是在一个点上搜索或打完时腾出来的空间；**在离开发生过事的点时清**，只是路过的不算；
走之前如果里面有东西或贵重的东西才提醒，提醒分档位、以后放进设置。

## 产出

| 文件 | 职责 |
|---|---|
| `core/run/node_events.gd` | `last_handled_id`：最近一次发生过事的点（打了、搜了、开了店、休息了、出了事件；随机点按揭成的类型算）。出生点、岔路、撤离点、路过的不算。跟着存档 |
| `core/run/run_state.gd` | `step_to` 走出它时清暂存区、发 `storage_dropped(node_id, items)`、把它清回 -1；走不成（不相邻）不清；`will_clear_storage()` 给界面问 |
| `core/settings/game_settings.gd` | `GameSettings`：提醒档位（`any` / `rarity` / `value` / `never`，一张表）与两个阈值；`user://settings.json`，带版本号，读不到就是默认 |
| `core/run/storage_warning.gd` | `StorageWarning.at_risk(items, settings)`：按档位挑出值得提的；`describe` 一句话 |
| `ui/game/map_screen.gd` | 走之前弹面板：几件、值多少、几件稀有以上，列出来；照走（不要了）/ 先整理背包 / 取消；日志记「离开点 X，暂存区里的 … 留在了那里」 |
| `ui/game/settings_screen.gd`、`main_menu.gd`、`game_flow.gd`、`game_director.gd` | 设置屏（档位四选一、两个阈值，改了就存）；主菜单多一个「设置」；flow 持有设置 |
| `tests/test_storage_rule.gd` | 4 组（见下） |

## 几条决定

**「发生过事」由 `NodeEvents` 说了算，不由节点类型说了算。** 用过的战斗点再路过一次，`handle` 不会跑，`last_handled_id` 不会指向它，走了就不清；
同一个点第一次踩上去打过，走了就清。这样规则只有一句话：清的是「刚才在这里腾出来的空间」。离开之后把 `last_handled_id` 清回 -1，回头再路过不会又清一遍。

**走不成不清。** `step_to` 先看目标在不在可走的邻居里，不在就交给旅程去拒绝、发 `refused`；清东西只发生在真的要走的时候。

**清在关会话之后、迈步之前。** 商店 / 搜索先关（随时可以离开），搜索的收获走的是待拾取而不是暂存区，不受影响；然后清暂存区，再迈步 ——
新的点上事件给的东西（直接进暂存区）不会被这一步误清。

**提示是数据里的一张表。** 档位列在 `GameSettings.WARN_MODES`，`at_risk` 按档位挑；加一档是加一行表、一个分支，界面按表画按钮。默认「有东西就提醒」——
开发期先把每一次遗落都摆到眼前，定数时再调默认。

**没做的**：商店 / 事件 / 休息屏里还开不了背包（战利品屏旁边就有棋盘），事件层重做那三屏时一起加；提示面板只列出「值得提的」，不列全部。

## 验证

```
bash tools/test.sh
通过  6664 项断言，40 个套件，耗时 72 秒
```

- 走出发生过事的点才清：出生点上放东西走了不清；走上战斗点打完，`last_handled_id` 指着它、`will_clear_storage` 为真；走回出生点暂存区清空、`storage_dropped` 带点与件数、
  `last_handled_id` 回 -1；用过的点上放东西穿行来回都不清；走不到的走不了、不清；存档带着「发生过事的点」，读回来的也知道走了要清。
- 四个档位：有就提全部、从不一件不提、稀有度 ≥ 2 与价值 ≥ 60 各挑对了件数、空的不提、没给设置按默认。
- 设置：默认有就提、往返、不认识的档位与不对的版本回默认、没有文件就是默认、写文件读回来。
- 地图屏：在战斗点上、暂存区有东西，按走先问一句、人没动；取消面板关了；照走走了、暂存区清了；档位「从不」不问直接走。
- 现有全部套件不变：读档签名、走到撤离点撤离（走的路上提示看过了照走）。
