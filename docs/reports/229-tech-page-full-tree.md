两种新构件：
- **`tech_sell_ratio { amount: float }`**：`MetaState.sell_ratio_bonus += amount`（读档按级数重算，同 `safe_bonus`）。读的地方两处：`ShopSession` 卖价（`EconomyRules.shop_sell_ratio + bonus`）、基地出售页 `MetaState.sell_price`。面板那句「卖价 50% → 60%」。
- **`tech_rack_fallback { bag: StringName }`**：`MetaState.fallback_bag` = 最高已点亮级的 `bag`（默认 `sack`）；225 补充一的「包架空且没选预设 → 发一只」读它。面板那句「军需官发的包：小包」。**依赖 225 包架先落**；225 没落前这个节点先不进数据（或进了但兜底逻辑不存在就等于没效果 —— 推荐随 225 一起落）。

不进这一批、留作下一列的（需要先加系统钩子）：**信仰**（信力增速、献祭价值 —— `FaithPower` 没有倍率入口）、**铸炉**（铸牌费用、附魔保留 —— 铸炉规则没有倍率入口）、**倒计时**（免费撤离点多开几步 —— `CountdownModule` 的关门步数按章节写死）。各加一个 `RunEffect` 和一处读法就能开第五列，另写补充。
