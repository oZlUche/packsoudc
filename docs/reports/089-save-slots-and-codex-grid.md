# 089 · 三个存档位、主菜单顺序、图鉴缩略图网格

> demo 打磨 ｜ 架构文档 8、8.2、16（v1.94）｜ 前一步：[088 作者第十二批](088-author-twelfth-batch.md)

## 一、作者定的

1. 主菜单「新的游戏」= **开一份新存档**，不是继续现有的。三个存档位；已有的老存档算第 1 位。有存档时第一项是「继续」（读当前位接着玩），第二项「读取存档」（换位），「新的游戏」挪到第三项。
2. 图鉴跟棋盘的格子无关：做成**网格排列的缩略图**（每行 N 个，能上下滚，不强求一页放完），没获得的灰的。

## 二、存档位（[SaveSlots]，`core/settings/save_slots.gd`）

- 三位，每位一个目录 `user://slots/<n>/`：`meta.json`（局外）+ 可能有的 `run.json`（进行中的一局）。`exists(n)`（局外文件在就算有）、`has_run(n)`、`first_empty()`、`remove(n)`、`summary(n)`（第几局、撤离 / 战败、有没有进行中的一局、最后改动时间）。
- **老存档搬家** `migrate_legacy()`：单文件的 `user://run.json` / `user://meta.json` 第一次进游戏时搬进第 1 位（第 1 位空着才搬）。
- 当前位记在 `GameSettings.save_slot`。
- [GameFlow]：`slots`（null = 老的单文件模式，测试与沙盒照旧）、`use_slot(n)`（路径指过去、局外读进来，没有就一份新的，第一次存盘才落地）、`profile_exists()`、`continue_game()`（有局内存档读档；教程打到中途开下一张；都没有按这份存档开新的一局）、`start_new_game()`（挑空位开；三位都满了去读取存档屏并提示）、`new_game_in(n)`、`load_slot(n)`、`delete_slot(n)`、`show_slots()`；新屏 `Screen.SLOTS`。
- 导演：用默认路径（正式游戏）时进存档位模式：搬家、切到设置里记的那一位；测试 / 演示改了路径的走单文件模式。
- **主菜单顺序**：继续（当前位有存档才显示）→ 读取存档（任何一位有存档才显示）→ 新的游戏 → 仓库 → 设置 → 语言 → 开发工具 → 退出。
- **读取存档屏**（`ui/game/slots_screen.gd`）：三行，各写摘要与「当前」标记；有存档的「载入」「删除」（点两次确认），空位「在这一位开新的游戏」；回主菜单。

## 三、图鉴缩略图（[CodexTile]，`ui/game/codex_tile.gd`）

基地的图鉴页改成 `GridContainer`（每行 `CODEX_COLS = 8`）放在 `ScrollContainer` 里：所有能获得的道具按稀有度各一格 96×112 的缩略图 —— 形状按比例缩进格子、底色 = 稀有度、下面写名字、右上角写累计件数；**没获得的画灰的**（形状灰、名字灰）。停在一格上开悬浮窗：亮的是完整的道具说明（含词条侧窗），灰的只写名字与「未获得」。特殊道具另起一段同样的缩略图（拿到过的亮）。原来那块只读棋盘删了。

## 四、测试

`tests/test_author_087.gd`：`run_save_slots`（全空 → 搬家 → 切位 → 新的游戏挑空位、第 1 位没被动 → 读第 1 位 → 空位读不了 → 三位满了新的游戏去读取存档屏并提示 → 删除、删当前位换成空的 → 读取存档屏两次确认删除）；`run_spyglass_and_codex` 改验缩略图（每件一格、点亮数、匕首累计 3、望远镜亮、亮的悬浮窗完整、灰的只写未获得）。全套 **63 个套件、11214 项断言**通过。

## 五、留给作者

- 三位都满了时「新的游戏」会跳到读取存档屏让你删一个；要不要直接覆盖某一位，等作者定。
- 图鉴缩略图每行 8 个（96 像素宽），分辩率小的屏可能要把 `CODEX_COLS` 调小。
