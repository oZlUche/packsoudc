# 270 方案：集市分摊位 —— 五个固定摊位按分类卖白 → 绿 → 蓝，散货摊沿用随机、只卖战斗道具、能花钱换货与锁货

作者 2026-10-31 12:01：「关于集市，我想的并不是完全随机，而是这样：1. 集市有多个摊位，大部分摊位出售的道具固定，且根据分类来（药物 / 食物 / 武器 / 防具等等），初始只有白色品质的道具，后面根据科技升级开始出售绿色到蓝色的道具。2. 和当前一样随机的摊位保留，里面出售的一定是和战斗有关的道具，且稀有度最低绿色，最高可能是红色（即使当前没有红色战斗道具，也先保留这个设定），稀有度越高概率越低，玩家可以花费金币手动刷新货物，也可以锁定一个或多个货物使其不会被刷新。3. 为此也要更新美术设计，随机摊位延续现有的，固定摊位直接改成一张通用集市背景图 + 格子界面和列表」。

## 〇 一句话

集市页左边一列摊位键：**药铺 / 粮铺 / 兵器铺 / 甲胄铺 / 杂货铺** 五个固定摊（货单按标签自动列、按集市级数放到白 / 绿 / 蓝、不断货、通用集市底图 + 货格）+ **散货摊**（现在的木凉棚，只进战斗道具，绿到红按递减权重抽，【换货 ◎ N】花钱刷、货上可挂锁不被刷）。集市级数仍是「高级货物」那两阶（默认 1 级 = 白，2 级 = 绿，3 级 = 蓝），正好对上。线框：https://claude.ai/artifact/TYXLvMqSmKBruuApg8ZEwg（源文件 [270-market-stalls.html](/mnt/project-files/architecture/270-market-stalls.html)）。

一处要先说的：**库里白色货很少** —— 药只有绷带一件白，武器只有小刀一件，甲胄与饰品一件白都没有（表见 §2.4）。按「初始只有白」硬来，三个摊位开局是空的；§五待定 1 给两条路。

## 一、现状（读码）

- 一个集市，一张木凉棚大平桌，货位 4 / 6 / 8（按级），`MarketRules`：允许标签 remedy / food / ammo / material，素材占一半，稀有度上限按级 0 / 1 / 2，权重 [40, 30, 20]，一局一换货，3 级最后一格换成一只包，**不能花钱刷新、不能锁**。货存 `MetaState.market_stock`（{id, sold}）+ `market_seed`。
- 集市级数 = 1 + 科技「高级货物」阶数（262），上限 3。
- 稀有度六档：白 普通 / 绿 优良 / 蓝 稀有 / 紫 史诗 / 金 传说 / **红 神话**（`text_colors.json` 第 6 档 `#ee6253`，现有神话道具两件，都不是战斗道具）。

## 二、摊位

### 2.1 固定摊位（五个，货单固定）

| 摊 | 标签 | 货单怎么来 |
|---|---|---|
| 药铺 | `remedy` | 库里带该标签、稀有度 ≤ 本级上限的全部道具，按稀有度再按价排 |
| 粮铺 | `food`、`supply` | 同上 |
| 兵器铺 | `weapon`、`ammo` | 同上 |
| 甲胄铺 | `armor`、`shield` | 同上 |
| 杂货铺 | `material`（素材从散货摊搬过来） | 同上；仍排除 treasure / valuable / bullion / keepsake / token / sealed 与 `excluded_ids` |

- 级数上限：1 级只有白、2 级白 + 绿、3 级白 + 绿 + 蓝（= 现有 `rarity_cap_per_level` [0, 1, 2]，不改）。
- **不断货**：固定摊卖的是货单，买一件不减；价 = 定价 × `price_mult`（1.0）；买到的进仓库（包进包架），钱不够 / 仓库满照旧说一句。
- 货单是数据，不是手写清单：`data/authoring/market_stalls/<id>.json`（`StallDef`：id、名、标签、排除、顺序、`fixed: true`）；加新道具贴对标签就自动上架，想不上架写进 `excluded_ids`。

### 2.2 散货摊（随机，沿用木凉棚）

- 只进**战斗道具**：标签 `weapon` / `armor` / `shield` / `trinket` / `ammo` / `remedy`（药算不算战斗道具 = 待定 2），素材不再在这儿。
- 稀有度 **1 ～ 5（绿到红）**，权重 [50, 30, 14, 5, 1]，不受级数上限；级数只管货位 4 / 6 / 8。现在没有红的战斗道具 → 抽不到，规则先放着（作者原话）。
- **【换货 ◎ N】**：钱牌旁一颗木牌键，花钱重抽没锁的格；N = 40 + 20 × 本次在家已换的次数（回一局归零）；钱不够压灰、说一句。一局回来照旧免费换一批（现有）。
- **锁货**：货的悬浮窗加「锁定 / 解锁」（230 那套按钮，右键也行），锁上的画 230 的小锁角标；换货不碰锁着的，一局回来的免费换货也不碰（待定 4）；买走就解锁。锁几件随意。
- 3 级最后一格的那只包照旧（待定 5）。

### 2.3 哪页、怎么走

一个「集市」页不拆：左边一列六颗摊位石键（同铁匠铺的分类键，170 × 44）：药铺 / 粮铺 / 兵器铺 / 甲胄铺 / 杂货铺 / 散货摊，记住上次看的摊。点固定摊 → 中间换成「通用集市底图 + 货格」；点散货摊 → 现在的木凉棚整块（货位、价签、已售章、便条、钱牌照旧）+ 【换货】键。营寨换景（264 §三）两边都在底下。

### 2.4 白色货的缺口（库里现状）

| 摊 | 白 | 绿 | 蓝 |
|---|---|---|---|
| 药铺 | 1（绷带） | 4 | 3 |
| 粮铺 | 4 | 6 | 5 |
| 兵器铺 | 2（小刀、箭） | 10 | 4 |
| 甲胄铺 | **0** | 6 | 1 |
| 杂货铺 | 15 | 17 | 19 |

## 三、排版（线框）

- **固定摊**（线框 1）：左列摊位键 170 × 44 × 6；中间 1100 × 760 通用集市底图（UI替换美术）上一块货架：货格 7 列 × 3 行、格 110、每格一件 + 底下金币价签（`PriceTag`），超过 21 件翻页（页签同仓库）；右上钱牌；摊名挂牌在货架上沿。
- **散货摊**（线框 2）：木凉棚原样（1300 × 950 舞台缩放），左列摊位键压在凉棚左柱外侧；钱牌右边加【换货 ◎ 40】（180 × 52）；锁着的货左上小锁。
- 待定 6：摊位键在左列（推荐）/ 挂在棚梁上的一排木牌（B）。

## 四、改动清单（执行；美术先出样）

1. 数据：`data/authoring/market_stalls/*.json` 六个 `StallDef`（五固定 + `loose` 散货摊 `fixed: false`）；`MarketRules` 加 `battle_tags`、`loose_rarity_weights` [50, 30, 14, 5, 1]、`loose_rarity_min` 1、`refresh_cost` 40、`refresh_step` 20；`allowed_tags` / `material_share` 退役（散货摊按 `battle_tags`）。导入器 `import_content.gd` 加 `market_stalls` 一类。
2. `Market`：`catalogue(stall, lv)` 固定摊货单；`restock` 只抽散货摊、跳过锁着的格；`refresh(meta, rules, items, paid: bool)` 扣钱 + 计数；`toggle_lock(i)`；`buy(i)` 固定摊走 `buy_listed(stall, id)`。`MetaState`：`market_stock` 每格加 `"locked"`，`market_refreshes` 回局归零（`after_run_market`），`market_stall` 记上次看的摊。
3. UI：`MarketPanel` 外套左列 `StoneChip.entry` 摊位键；新 `StallView`（通用底图 + 货格 + 翻页 + 挂牌），散货摊仍是 `MarketStage`；【换货】键 + 价；悬浮窗动作：固定摊「购买」，散货摊「购买」+「锁定 / 解锁」；小锁角标复用 `tip/lock_badge`。
4. 文案：六个摊名中英、`market.refresh`「换货」、`market.locked`「锁着的不换」、`market.refresh_poor`「钱不够换货」、科技「高级货物」描述改成「固定摊位进绿 / 蓝货，散货摊多货位」。
5. 测试：固定摊货单 = 标签 ∩ 稀有度 ≤ 上限，排除表生效，买不减；散货摊只出 `battle_tags`、稀有度 ≥ 1、权重分布 10000 次抽样在 ±2%；换货扣 40 / 60 / 80，回局归零；锁着的格换货不动、买走解锁；老档 `market_stock` 没 `locked` 当 false；帮助页更新。
6. 美术（UI替换美术，作者看样后定）：通用集市底图 1100 × 760（摊棚 / 货架，光面，和营寨换景同调）、摊位石键六枚文字版（图标以后再说）、货架格框（沿用 227 棋盘框）、【换货】木牌键、摊名挂牌。

## 五、待定（没回音按推荐）

1. 白货缺口：**过渡规则 —— 某摊本级货单不足 3 件时，从下一档补到 3 件**（推荐，甲胄铺开局能卖 3 件绿的；等白色道具补齐自然退场）/ 严格只卖白，先派 美术设计 + 执行补一批白货（药膏、木棍、皮帽、木盾、粗布甲等 8 件）再上线。
2. 药（`remedy`）算战斗道具、散货摊可出：**算**（推荐）/ 不算。
3. 换货价：**40 + 20 × 次**，回局归零（推荐）/ 固定 50。
4. 一局回来的免费换货：**也不碰锁着的**（推荐）/ 全换。
5. 3 级散货摊最后一格的包：**照旧**（推荐）/ 去掉（包不算战斗道具）。
6. 摊位键：**左列石键**（推荐）/ 棚梁上一排木牌。
