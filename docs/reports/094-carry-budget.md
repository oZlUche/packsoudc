# 094 · 开局：预设是底线，带入是预算，超带换倒计时

作者问：开局是预设还是自由搭配？自由搭配玩法多但强度可能过高；预设简单但丢了「用自己的仓库组成战力」这一搜打撤要素。我的建议（作者「可以，开工」）：**保留自由搭配，做成带入预算**——

1. **预设是底线**：仓库空的第一局发标准套、角色初始包永远在（都已有）。
2. **带入是预算**：从仓库带进一局的道具**总价值**（`ItemValue`）≤ 预算；预算写在规模档（`MapScaleProfile.carry_budget`，第一章小 600 / 中 900 / 大 1200）或章节（`ChapterDef.carry_budget` 兜底 600）。预设与角色初始包不算。
3. **超预算是赌注**：允许超带，每超 `ChapterDef.carry_over_cost`（50）价值全局倒计时 −1（有倒计时的至少留 1）；关闭的撤离点按罚后的倒计时算一半。这一章没有倒计时就只提示。

## 落地

- `RunState.carry_in_value`（进存档）；`RunState.start(..., p_carry_value)`；静态 `carry_budget_for / carry_over_for / carry_penalty_for / countdown_limit_for / base_step_limit_for / scale_profile_of`（开局屏与一局共用同一份算法）；`countdown_limit()` 改走它。
- `GameFlow.begin(..., carry_value)`：按 uid 从仓库带的自动加价值；开局屏摆好的棋盘由屏算好传进来（`SetupScreen.carry_value()` = 棋盘上非包道具的价值之和）。
- 开局屏读数多一行：「带入预算 600：已带 420」（绿）/「带入预算 600：已带 750，超出 150 → 倒计时 −3（36 → 33）」（琥珀）；地图屏开局日志写一句超带扣了几步。
- 角色的件数 / 稀有度上限（082）照旧是硬限制，预算是软的。

## 数（占位，作者调）

| 在哪 | 数 | 说明 |
|---|---|---|
| 规模档 `carry_budget` | 小 600 / 中 900 / 大 1200 | 标准套一件大约 40～150 价值；600 约等于 5～8 件普通货，或两件紫 |
| `ChapterDef.carry_over_cost` | 50 | 每超 50 价值 −1 步；小图 36 步，超 300 价值就少 6 步 |

## 要盯的指标

demo 阶段看撤离率：带预设 30～40%、带满预算 50～60%。高了收预算或倒计时，低了放宽。
