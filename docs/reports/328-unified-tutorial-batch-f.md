# 328 统一教程 F 批：局内也能跳过剩余教程，切片老档能体验统一教程

> 日期：2026-11-18。依据：[统一教程方案](../plans/2026-11-18-unified-tutorial-and-base-return.md) §8.2、§12（PR #651）；接[报告 327](327-unified-tutorial-batch-e.md)。作者 2026-11-18 09:24：「根据 PR651 的新增方案，优化切片 demo」。
> 这一批补报告 324 §四列的两个缺口。方案 §12.2 的真实界面走查交给游戏测试线程。

## 一、局内暂停菜单「跳过剩余教程」

- 教程局里按 Esc 打开暂停菜单，多一个「跳过剩余教程」。只在教程还没全通、这一局是教程时出现。
- 点了先弹确认页。确认页和基地出征页是**同一张**，共用的代码挪到 `GameScreen.skip_tutorial_page`。说明多一句：「这一局身上的东西不会带出来，直接回基地。」
- 【接着学】或 Esc：什么也不动。
- 【跳过】走开场一问【不需要】那条路（`GameFlow.decline_tutorial`）：
  - 这一局悄悄结束，不进结算，不记场次；
  - 补齐没领的固定奖励；
  - 回基地，不开下一局。

## 二、切片老档「体验统一教程」

- 玩过切片的老档（`slice_legacy_open`）仍然不锁出战。
- 「上回出征」木牌右下多一个「体验统一教程」，点了直接开最早一段没通的教程（`GameFlow.try_tutorial`）。打完照账本领那一段的固定奖励，原来就有的东西不追溯。
- 正式版和新切片档没有这个键：它们的教程本来就锁在出征页上。

## 三、顺手修（游戏测试在 v6.43 报）

- 在基地里快速连切页签（间隔短于背景淡入的 0.25 秒）时，每切一次报两条脚本错误。原因是上一张背景还在淡入就被释放了，但淡入的补间绑在基地屏上，回调照样去碰已经释放的那张。
- 修法：`MetaScreen._swap_backdrop` 的补间改用 `top.create_tween()`，那张被释放时补间跟着停。不影响通关。

## 四、测试

新增 `tests/ui/test_unified_tutorial_f.gd`，23 项断言：

- 暂停菜单：
  - 确认页列出奖励、写明这一局的东西不带出来；
  - Esc 取消不动；
  - 确认后三段都通、补 450、场次不变、回基地。
- 切片老档：
  - 有体验键，点了开第一段；
  - 正式版和新切片档没有这个键。

截图核对：确认页压在暂停的地图上，奖励小纸和两个键都在。

## 五、交给走查的部分

方案 §12.2 要求的真实界面走查请游戏测试线程做：

- 三条路径：正常三段、部分跳过、失败重试；
- 两版各跑一遍；
- 中文、英文，各配默认、大字号。

另需作者找新玩家验证几件事：

- 是否分清生命和体力；
- 会不会合成；
- 能不能找到仓库和科技；
- 是否知道可以留在基地；
- 能不能主动开始下一段。
