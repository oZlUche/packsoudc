# 231 · 方案：界面过渡动画 —— 开战一镜到底（战旗展开 → 沙场显出 → 纹章下移、双剑对攻、分胜负 → 「继续」旗落下）+ 全游戏可加过渡的清单

> 架构设计线程，2026-10-21。作者原话（19:12）：「顺便给现有的 ui 过渡做动画，比如战斗界面的旗子按钮有展开动画，开始战斗时背景渐变成沙场，战前中央的圆形纹章下移，里面的两把交叉的剑开始互相攻击，最终左边或者右边胜利，再展示出我定位旗子形状的【继续】按钮」「顺便列一个表，看看还有哪些地方可以加入这种过渡动画」。
> 本文只做方案，不实施。承接 157（换屏淡入、战报）、167（回放控件）、220（反应首见暂停）、v3.79 铜面板三屏（`PrebattleLane` 铜章、`BattleView.bronze`）、战旗 / 纸卷（PR #242）。

## 〇 一句话

先立一个小小的动效工具 `UiMotion`（淡、升、展旗、开卷、弹出、滑入，六个函数，都听 `GameSettings.ui_fades` 和测试开关），再用它做两件事：**一、开战这一段做成一镜到底**（§二，作者点名的那串）；**二、按 §三 的清单给其余二十来处过渡各配一个一行能写完的动效**，分三批落。

## 一、现状（v3.80 核过）

- 换屏：`GameDirector._fade_in`（157）—— 新上来的一屏从透明淡到不透明（叠层 / 底屏各一个时长），设置 `ui_fades` 能关，测试与截图 `fades_allowed = false` 全关。157 的注释里写着「墨水扫过那种 shader 等美术方案」，一直没做。
- 战前 → 战斗是**两个屏**（`PREBATTLE` → `BATTLE`，`flow.start_battle()` 换屏），同一块铜面板底图（`panel_bronze`）；战前屏中缝 `PrebattleLane` 正中压一枚交叉双剑铜章 `medal_swords`（132 px，纯装饰）；战斗屏 `BattleView.bronze` 把斗技场图 `battle_bg` 铺满面板里面，双方名牌、条、棋盘、时间轴、底栏战报；「继续」纸卷在回放 `finished` 后才建、直接出现在底栏正中（`_next_slot` 246 × 94）。
- 已有的动效（十四处 `create_tween`）：主菜单背景轮换、挑战卷轴、难度牌、翻页计数器、地图跟随平移（`FOLLOW_SEC`）、战利品落袋（162）、战斗面板的闪 / 抖 / 条（`combatant_panel` 四处）、腰带格、休息营地、节点提示卡；宝箱开锁的抖 + 环形进度（代码画）；账单逐行滚数（224）；悬浮窗钉住的黄铜线（170）；226 已定告示签横向开卷、228 已定结算两页交叉淡入淡出。
- 回放的硬规矩（4.8）：**结果在开打那一瞬已定**，回放只移动游标；倍速 / 跳过只改表现。所有新动效都得服这一条：跳过 = 直接到终态，倍速 = 时长除以倍速（≥ 4 倍只闪不演）。

## 二、开战一镜到底（作者点名的那串）

### 2.1 分镜（时间按一倍速；`t` 从按下「开战」算起）

| t（秒） | 画面 | 实现 |
|---|---|---|
| 战前屏进场 | **战旗展开**：「开战」战旗从旗杆横档往下**展开**（上→下裁切显出 0.35 s，ease-out，末尾两下轻摆 ±2°、0.25 s）；灰态（打不起来）不摆 | `UiMotion.unfurl(btn)`：`clip_contents` + 高度 0 → 全高的 tween，摆动用 `rotation` 绕旗顶中点（`pivot_offset`）；不要帧图 |
| 0 | 按下「开战」 | 旗面按下态（已有）；两排属性签、两块棋盘外的地上栏 0.2 s 淡出；旗 0.2 s 收回（展开的倒放） |
| 0.2 → 0.8 | **背景渐变成沙场**：铜面板不动，面板里面从战前的素铜面交叉淡到 `battle_bg` 斗技场（0.6 s） | 战斗屏先于战前屏出现在底下、铜面板同图同位，所以只需战斗屏的 `BattleBackdrop` 从 `modulate:a` 0 → 1；157 的整屏淡入对这一对屏关掉（`GameDirector` 给 `PREBATTLE → BATTLE` 一条专用过场，其它换屏照旧） |
| 0.3 → 0.9 | **纹章下移**：战前中缝正中的铜章顺着中缝**下滑**到战斗屏双方名牌之间、棋盘上方的位置（新的 `DuelMedal` 槽位，132 px 不变），刻线跟着缩短 | 战前屏 `open` 之后把 `lane().medal_rect()` 写进 `start_battle` 的 payload；战斗屏建好后 `DuelMedal` 先摆在那个全局矩形上、tween 到自己的槽位（ease-in-out 0.6 s）；战前屏的铜章同时隐掉，视觉上是同一枚 |
| 0.9 | 名牌、条、棋盘淡入（0.25 s，已是 157 风格）；回放开始 | `BattleView.play` 延到这里起跑（`hold` / `release` 已有） |
| 回放中 | **双剑对攻**：铜章里两把交叉的剑拆成三层（盘、左剑、右剑）。左方出手（`ITEM_FIRED side 0`）→ 左剑向右**劈** 0.12 s（绕剑柄转 +14°、位移 6 px）再回；右方同理镜像。挨打（`DAMAGE` 到某方）→ 被打那把剑**后仰** 0.1 s（−8°）+ 剑身白闪一帧；大伤（≥ 该方生命上限 15%）→ 交点冒一簇火星（6 粒、0.3 s，代码画）。反应（`STATUS_APPLIED` 带反应 id）→ 盘面按元素色晕一圈 0.3 s | `DuelMedal` 接 `BattleView` 的事件（新增信号 `event_applied(e)`，在 `_apply` 末尾发）；时长 ÷ 倍速；`_feedback_scale` 那套（≥ 4 倍缩短、新的打断旧的）照用 |
| 终局 | **分胜负**：`DIED` → 输的那把剑**落下**（转到水平 −70°、滑出盘沿 10 px、褪成铁灰 0.5 s），赢的那把**举起**（转到竖直、0.4 s）+ 剑尖一道金光扫过 0.3 s；平局两把同时放平。胜负方向随 `result.winner`：左赢举左剑，右赢举右剑 | 跳过 / 拖到头 → 直接摆终态（`DuelMedal.set_final(winner)`），不演 |

### 2.2 代码落点

- `ui/ui_motion.gd`（新，静态）：`fade(c, from, to, sec)`、`rise(c, dy, sec)`、`unfurl(c, sec)`（上→下裁切 + 两下轻摆）、`unroll(c, sec)`（226 告示签那种左右开卷，复用一处）、`pop(c, sec)`（0.96 → 1 + 淡入，叠层窗用）、`slide(c, dx, sec)`；每个都先看 `UiMotion.enabled()`（= `GameDirector.fades_allowed and settings.ui_fades`），关着就直接置终态、返回 null；返回 Tween 便于串接。
- `ui/widgets/duel_medal.gd`（新，`Control`，`_draw` 三层贴图：盘 / 左剑 / 右剑 + 火星 / 金光）：`strike(side)`、`hit(side, big)`、`react(color)`、`set_final(winner)`、`fly_from(global_rect)`。倍速由 `BattleView` 传入。
- `ui/battle/battle_view.gd`：新增 `signal event_applied(e: BattleEvent)`；`_build` 的 `arena` 行上方给 `DuelMedal` 一个槽（双方名牌之间）；`skip_to_end` / `seek` 到头时调 `set_final`。
- `ui/game/prebattle_screen.gd`：进场 `UiMotion.unfurl(_start_btn)`；`start_battle` 的 payload 加 `medal_from: Rect2`、`lane` 刻线可缩；按下后属性签 / 地上栏淡出。
- `ui/game/battle_screen.gd`：`open` 按 §2.1 排时间（`_view.hold()` → 过场完 `release()`）；「继续」换成战旗图（`continue_win_*` / `continue_lose_*`，执行已收到）后再套 `unfurl`。
- `ui/game/game_director.gd`：`PREBATTLE → BATTLE` 这一对换屏不走 `_fade_in`，由战斗屏自己过场；其它不变。
- 美术（UI替换美术）：① `medal_swords` 拆三层（盘 / 左剑 / 右剑，同一 132 画布对位）+ 剑尖金光一帧；② 「继续」战旗**不用再要**：UI替换美术 19:15 已切好 `continue_win_*` / `continue_lose_*` 四态中英（216 × 134，热区同「开战」），已交执行；③ 火星不用图（代码画 6 个小菱形）。战旗展开**不要帧图**（裁切 + 摆动够了；要是作者想要布料的皱褶再出 4 帧）。

## 四、守则（写进 `UiMotion` 的文件头）

1. 一倍速下任何单步 ≤ 0.6 s、一串 ≤ 1.5 s；玩家能点的东西出现后立刻可点（展开中的旗除外）。
2. 回放相关动效**不改结果、不改时序**：跳过 = 终态，倍速 = 除以倍速，≥ 4 倍只闪。
3. `ui_fades` 关 / `fades_allowed` 关 → 全部 0 秒直接终态；所有屏幕测试照旧绿。
4. 动的只有位移 / 透明 / 裁切 / 旋转 / 缩放五种；不做帧动画，除非美术另出帧（宝箱开盖、墨迹）。
5. 古风：ease-out 为主、幅度小（位移 ≤ 24 px、缩放 ≤ 4%）、不弹跳（`TRANS_CUBIC`，不用 `BACK` / `ELASTIC`）。

## 七、派工（作者 19:20 改：动画单开线程）
