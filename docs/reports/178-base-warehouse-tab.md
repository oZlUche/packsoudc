# 178 · 基地左列加「仓库」页签：带回未清的棋盘搬到这里；图鉴、成就页不显示右侧仓库

> 作者 2026-10-16 14:11：「关于基地界面，左边也要加入仓库选项卡，如果从局内带出的东西还没从棋盘里拿走，那就要显示在这里。在【图鉴】【成就】选项卡点开时不显示仓库」。性质：界面 · 实施。待定按推荐。关联 164（三列基地屏）、163（仓库分页）、139（图鉴按宽算列）、177（结算屏两步）。

## 1. 现状（164）

`ui/game/meta_screen.gd` 三列：左列「基地」+ 四个页签（图鉴 / 成就 / 出售 / 科技，`TABS`；再点选中的回「家」）+ 再来一局 / 回主菜单；中列当前页，默认「家」= 刚才这一局、战绩、**带回来的棋盘**（`WarehousePanel` 基地用法：棋盘 + 一键置入 / 整理）；右半边 `WarehousePages` 仓库**常驻**，所有页都显示。`show_tab("warehouse")` 现在被硬改成 `"home"`。双击仓库按页：家 → 置入、出售 → 卖、科技 → 上交、图鉴 / 成就 → 不做事。

## 2. 方案

### 2.1 页签表

`TABS` 改五项，顺序 **仓库、出售、科技、图鉴、成就**（仓库相关的三页挨着，右半边在这三页都在；图鉴 / 成就两页右半边收起，放在后面——待定 1）。「家」仍不在表里，再点选中的回家。

### 2.2 「仓库」页（中列）

- 有带回来的棋盘（`meta.has_pending_board()`）：中列 = 现在家里那块 `WarehousePanel`（棋盘 + 一键置入 / 整理 + 提示行），从「家」页**搬过来**，家里不再画它。双击右侧仓库 → `quick_move`（现在家页的行为，改挂到 `"warehouse"`）。
- 没有带回来的棋盘：中列只一行「没有带回来的东西」+「整理」按钮（整理仓库当前页，109），双击仓库不做事。
- 「再来一局」灰着时的提示（「清空背包再配置」）改成指向这一页：「带回来的背包还没清空，去『仓库』页置入」，点提示直接 `show_tab("warehouse")`。

### 2.3 「家」页

去掉棋盘那块；留刚才这一局、战绩、一键出售提示。家页右半边仓库**照旧显示**（作者只点名图鉴 / 成就不显示；家的美术套件本来就把木架当右半边的景，164 §4）。家页双击仓库：不做事（棋盘不在这儿了）。

### 2.4 右半边的显隐

`_right.visible = _tab not in ["codex", "achievements"]`；收起时 `layout()` 把 `half` 记为 0、中列吃满（`mid_w = screen.x − 2·MARGIN − LEFT_W − COL_GAP`），图鉴按新宽度重算列数（139 的 `fit_codex_to_width`）、成就列表变宽；调试台抽屉（139）钉在屏幕右上，不随右半边收。切回仓库 / 出售 / 科技时右半边原样回来，**翻到的仓库页不变**。拖拽层是整屏那一层（164），右半边隐藏时它的视图 `_drag.register_view` 不需要注销——视图不可见就收不到拖放。

### 2.5 进基地时落在哪一页

从结算屏「继续」回基地：有带回未清的棋盘 → 直接落在「仓库」页（待定 2）；否则落「家」。从主菜单进基地照旧「家」。

### 2.6 实现要点

- `TABS` 加 `["warehouse", "仓库"]`；`show_tab` 删掉 `name == "warehouse" → "home"` 那行；`_build_warehouse_page()` 建中列那页，`_wh` 挂在它下面；`_on_shelf_double_clicked` 的 `"home"` 分支改 `"warehouse"`；`layout()` 按 `_right.visible` 算 `half`；`open(payload)` 按 2.5 选初始页。
- 美术：左列木牌多一块「仓库」（`home/tab_mark.png` 共用，字是文字不是图），不需要新图。

## 3. 测试

`tests/meta/test_base_home_164.gd` 改 + 新用例：五个页签顺序；有棋盘时「仓库」页有 `WarehousePanel`、家页没有；无棋盘时「仓库」页是一行提示 + 整理；图鉴 / 成就页 `_right` 不可见且中列宽 = 全宽减左列，切回出售页右半边可见且页码不变；双击仓库在仓库页置入、家页不动；结算后带棋盘回基地落在仓库页，清空后进基地落家；`show_tab("warehouse")` 不再被改成家；Esc 在仓库页回家。
