# 247 法杖敌人四阶：魔法学徒 / 熟练的魔法师 / 魔导师 / 大魔导师；装晶的法杖不耗耐力

作者 2026-10-24 09:25（架构设计线）：「增加会使用魔杖的敌人，装配不同等级的魔晶石，这种敌人的强度定位为高，且存在不同类型（魔法学徒、熟练的魔法师、魔导师、大魔导师）。另外，当法杖装配有魔晶石时，攻击不消耗耐力」

## 〇 一句话

211 已有一个「学徒法师」（`apprentice_mage`，法杖 + 两颗晶石）。把它改名归入四阶，再加三阶，**四阶的区别就是 246 的三品魔晶石**：学徒装下品、熟练法师装中品、魔导师装上品、大魔导师装两颗上品还穿法袍，本色档位 2 / 3 / 3 / 3，只在深处与核心环出现。法杖规则加一条：装载格上有晶石时出手不扣耐力——法杖玩家、法师敌人一体适用。

## 二 装晶的法杖不耗耐力

- 现在 `magic_staff` 的出手规则 `costs: ["@resource_5"]`，不管有没有晶石都扣五点耐力。
- 改：`AbilityRule` 加 `free_when_loaded: bool`（默认关）——规则所属的件有装载格且至少一格站着有供给的东西（`has_feed()`，耐久归零的不算）时，`costs` 不收。`magic_staff` 这条规则打开它。空杖照旧扣五点（「不放晶石就是根木棍」）。
- 151 估算：`Cost.estimated_factor` 看到 `free_when_loaded` 按「有晶石」算（法杖的战斗力本来就按装满估）。
- 法师敌人同样受益：它们永远装着晶石，所以不断气——这正是「强度高」的一部分。

## 三 不做

- 不给法师新的法术效果：威力差全在晶石的品（246 §6.1），法师只是「谁装什么」。
- 不加新池、不改档位表。
- 果果之心不出现在任何敌人身上。

## 四 测试

四个定义能载入、builds 的晶石落在装载格上（211 骨架逻辑）、学徒两颗都是下品、大魔导师两颗上品不同元素；装一颗晶石的法杖出手耐力不变、空杖扣五；`EnemyPlacer` 在外环（档 0）抽不到四阶中的任何一个。

## 五 落地（v4.29）

- `apprentice_mage` 改名「魔法学徒」，两套路都换成下品（`fire_crystal_low` + `ice_crystal_low`；坏套路也是这两颗，摆成散件）。新 `adept_mage`「熟练的魔法师」（档 3、生命 44，三套：两颗不同元素中品 + 浓缩伤药）、`magus`「魔导师」（档 3、56，六套：一上品 + 另一元素中品）、`grand_magus`「大魔导师」（档 3、72，三套：两颗不同元素上品 + 第三元素中品一颗）。三阶的套路限档位 2～3（外环档位的稀有度上限装不下中 / 上品）。
- **法袍**：现有道具里没有带 `magic` 的布甲，`rune_pouch` 是包，导入器不让包写进套路（「包由档位表给」）。所以套路里没写；装着晶石的敌人本来就会从包池抽到符文囊（它收晶石）。要真有件法袍得先画一件布甲，交架构 / 作者定。
- 池（`standard_ruins`）：学徒 2（ruins / depths）、熟练 1.5（depths / core_ring）、魔导师 1（depths / core_ring，只进精英点）、大魔导师 0.6（core_ring，精英 / 核心点）。**多写了 `inner`**：另一种地图的内环叫 `inner`（守卫、穴熊都这样写），不加的话那种图里见不到后三阶。
- 晶石品按套路写死，次数照 246 随机；余数照抽来的晶石照常换品。
- `AbilityRule.free_when_loaded`（默认关）：规则所属的件在 `CombatantSpec.loads` 里是宿主（装载格上有在供给、没碎的东西）时，`RuleEngine._settle` 只留条件、不收消耗；`CombatantRuntime.is_loaded(uid)`。`magic_staff` 的出手规则打开了它，说明加一句；悬浮窗轮读句写「装着魔晶石不耗耐力」，空杖写「每下消耗 5 耐力（装上魔晶石就不耗）」。`AbilityRule.estimated_factor` 对它按有晶石算（消耗不打折）。
- 肖像：美术设计的三张（青铜币侧像，和学徒一套）已放进 `assets/portraits/enemies/`（开了 mipmaps）。四条百科文案没写：敌人现在没有说明字段（百科也不列敌人），要加得先定放哪里。
