# 247 法杖敌人四阶：魔法学徒 / 熟练的魔法师 / 魔导师 / 大魔导师；装晶的法杖不耗耐力

作者 2026-10-24 09:25（架构设计线）：「增加会使用魔杖的敌人，装配不同等级的魔晶石，这种敌人的强度定位为高，且存在不同类型（魔法学徒、熟练的魔法师、魔导师、大魔导师）。另外，当法杖装配有魔晶石时，攻击不消耗耐力」

## 〇 一句话

211 已有一个「学徒法师」（`apprentice_mage`，法杖 + 两颗晶石）。把它改名归入四阶，再加三阶，**四阶的区别就是 246 的三品魔晶石**：学徒装下品、熟练法师装中品、魔导师装上品、大魔导师装两颗上品还穿法袍，本色档位 2 / 3 / 3 / 3，只在深处与核心环出现。法杖规则加一条：装载格上有晶石时出手不扣耐力——法杖玩家、法师敌人一体适用。

## 二 装晶的法杖不耗耐力

- 现在 `magic_staff` 的出手规则 `costs: ["@resource_5"]`，不管有没有晶石都扣五点耐力。
- 改：`AbilityRule` 加 `free_when_loaded: bool`（默认关）——规则所属的件有装载格且至少一格站着有供给的东西（`has_feed()`，耐久归零的不算）时，`costs` 不收。`magic_staff` 这条规则打开它。空杖照旧扣五点（「不放晶石就是根木棍」）。
- 151 估算：`Cost.estimated_factor` 看到 `free_when_loaded` 按「有晶石」算（法杖的战斗力本来就按装满估）。
- 法师敌人同样受益：它们永远装着晶石，所以不断气——这正是「强度高」的一部分。

## 三 不做

- 不给法师新的法术效果：威力差全在晶石的品（246 §6.1），法师只是「谁装什么」。
- 不加新池、不改档位表。
- 果果之心不出现在任何敌人身上。

## 四 测试
