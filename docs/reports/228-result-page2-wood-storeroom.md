# 228 结算第二页换木质背景：「回到基地」的储物间

作者 2026-10-21 17:27（美术设计线）：「结算页面的第二页我认为需要换成一个木质背景，体现回到基地的感觉，具体风格让架构设计出方案」。

## 〇 一句话

第一页是营门口的石碑账单（官家、石头、墨字），第二页是**回到家、把东西往架子上放**。所以第二页不该再是同一块石板：换成基地「家」那套的木头 —— 推荐 **丙 储物间**：一张新画的木屋储物间当整屏背景，带回的棋盘像挂在墙上的皮件，仓库木架靠右，按钮改木牌。两页之间淡入淡出，就是「从营门走回屋里」。

## 一、现状（核过）

- 第二页（`result_screen._build_store`）和第一页同一块 `_slab_screen()` 白灰大理石；内容：带回的棋盘（皮带框 + 格缝）靠左、仓库分页（棕底 + 木架页签）靠右、一键置入 / 整理石钮靠左、继续石钮靠右（224 落地 v3.77，见 `art/ui/ledger/continue/mocks/page2_right.png`）。
- 基地屏已有一整套木头美术（`assets/ui/home/`，164 §4，美术设计 2026-10-12）：`bg_home.png` 1920×1080 木屋内景（木板墙、壁炉、窗、灯、右侧木架），`shelf.png` 厚木边仓库框（tone dark），`panel_cloth.png` 粗布文本框，`btn_wood*.png` 木牌按钮（常态 / 悬停 / 按下 / 禁用 / 主档琥珀木），`tab_mark.png` 页签小木牌。基调「炉火、木头、粗布、暖光」。
- 仓库分页的棕底格（`GROUND_WAREHOUSE`）本来就是木头色，放到木屋里反而比放在大理石上顺。

## 二、三个方向

| | 甲 木板底纹 | 乙 直接用基地的木屋 | **丙 储物间（推荐）** |
|---|---|---|---|
| 做法 | 一张平铺的木板纹（九宫格 / 平铺 256）替换这一页的石板板身，其余不动 | 第二页背景就用 `bg_home.png`（压暗 15%），棋盘和木架压在壁炉前 | 新画一张 1920×1080 **储物间**：同一间木屋的另一面墙 —— 木板墙、木地板、一盏油灯、墙上几枚挂钩和一只挂着的空包、角落一两只麻袋；中间留空给两块棋盘 |
| 像不像「回到基地」 | 只是换了材质，不像回家 | 很像，而且零新画；但壁炉、地毯被棋盘挡一半，画面打架 | 像：和基地同一间屋子（同色木板、同一盏灯），又不和基地屏撞画面 |
