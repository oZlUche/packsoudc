# 讨论稿：材料越来越多之后，怎么「定向」拿到某种材料 —— 六个方案与推荐（266）

> 作者 2026-10-29 16:43：「未来随着材料种类和数量增加，是否可以考虑增加专门出某种材料的节点 / 地图？比如开局界面选择地图倾向（正好加在出征界面），又或者搜索节点从地图上就显示出现某种材料的概率提高？结合现有设置，以及市面游戏头脑风暴一下，给我几个方案」。本篇只摆方案，作者挑定后写实施篇。

## 一、现状（v4.71 核过）

- **搜索点出什么**：`SearchSession.candidates` = 道具库全部 id 减 `exclude_tags`（珍宝），权重只看稀有度 × 深度 × 危险（`SearchRules.rarity_weight`），**和地图、环、区、节点无关** —— 哪个搜索点都是同一口锅。宝箱、敌人掉落（`DropRules` 按稀有度）、事件给的东西同理。
- **材料**：157 种道具里 75 种带 `material` / `crystal` 标签，三系 【自然】`nature` 49 / 【工艺】`crafted` 36 / 【魔法】`magic` 19（有重叠），还有 `beast_part` 14、`reagent` 8、`bullion` 6 等细标签。铁匠铺配方 `inputs` 点名要具体材料（钢锭、硬木板、铆钉盒…），科技升级也点名要材料。
- **地图**：环形生成（`RingMapConfig`）三到五环 `outskirts / ruins / depths / core_ring / inner`，各环有 `type_weights` 与配额；高危区（`DangerZoneSpec`）长在路线旁；节点类型只有 `MapNodeTypes.ALL` 那 13 种，搜索点一种。章节 `free_mode` 一张图、一套 `drop_rule` / `node_rules`。
- **玩家能看到的提示**：节点悬浮句 `MapNodeTypes.HINTS`（「有值得翻一翻的东西」）、182 的出生点提示窗、开局第三页地图预览；没有任何「这里出什么」的信息。
- **已有的定向渠道**：集市（白～蓝材料随机上货）、事件后果 `grant_item`、保险箱带回。

## 二、市面上怎么做

| 游戏 | 做法 | 可借的点 |
|---|---|---|
| 逃离塔科夫 / 三角洲 | 每张图固定「出什么」（海岸线出药、储备站出军备），图内还有**标志性刷新点**（药柜、工具箱） | 图与区有产物；点位类型化 |
| 怪物猎人 | 采集点分 矿脉 / 骨冢 / 草丛，图上有图标；每张图产物表公开 | 节点按材料类型画成不同图标 |
| 泰拉瑞亚 / Dead Cells | 生态区（biome）决定掉落；Dead Cells 每关选下一关的分支 | 区 = 产物；玩家在岔路选倾向 |
| 杀戮尖塔 | 地图节点图标就是内容（商店 / 篝火 / 宝箱 / ?），路线选择 = 资源选择 | 节点图标即承诺 |
| 暗黑地牢 | 出发前选地区与任务类型（采集 / 清剿），采集任务多给材料 | 出发前的「倾向」 |
| Hades | 出门前看每扇门上的奖励图标再选 | 进门前就知道奖励种类 |
| 黎明杀机 / 明日方舟 | 「今日 / 本周」特定材料掉率提高 | 轮换倾向，低成本 |

共同点：**要么把产物绑在地理上（区 / 点位），要么在出发前让玩家选倾向，最好两者都有且在地图上看得见。**

## 三、六个方案

| 项 | 一句话 | 改什么 | 玩家看到什么 | 成本 | 风险 |
|---|---|---|---|---|---|
| **A 出征倾向** | 出征页（264）加一块「倾向」木牌：无 / 自然 / 工艺 / 魔法 三选一，整局搜索与宝箱对该系材料权重 ×2.5、其它材料 ×0.6 | `SearchRules` / `DropRules` 加 `tag_bias`，`RunState.bias` 由开局写入；出征页一块木牌 | 出征页一块牌 + 局内顶栏一枚小徽记 | 小（1 单） | 只是「概率」，玩家感知弱；三系粗，拿不到具体某一件 |
| **B 环 / 区产物** | 每一环、每个高危区带一张 `produce`（标签 → 倍率）：外环 自然、遗迹 工艺、深处 魔法、高危区 稀有件；搜索 / 宝箱按所在节点的产物表加权 | `RingSpec.produce`、`DangerZoneSpec.produce`，`MapNode` 记 `produce`；`SearchSession.draw_items` 带倍率 | 地图纸边上一张「产物图例」（环色 + 材料图标）；节点悬浮句加一句「这一带多半翻出【自然】材料」 | 中（1 单 + 美术图例） | 和 259 刚调好的环权重无关，不影响节点数；但只在环级，同一环内还是一锅 |
| **C 材料节点** | 搜索点细分四种：**矿脉**（矿石 / 金属）、**林地**（木 / 草 / 兽部件）、**遗骸**（工艺件 / 容器）、**符文堆**（魔晶 / 符文），各自只从那一类标签里掷；普通搜索点照旧一锅。分配时每环按配额出几个 | `MapNodeTypes` 不加新类型，搜索点加 `content.search_kind`；`node_rules.search_kinds`（id → 标签 + 权重 + 图标）；类型分配器按环配额点几个 | 地图上**不同的节点图标**（矿镐 / 树 / 骸骨 / 符文），悬浮句点名材料类；事件屏标题也换 | 中（1 单 + 4 枚节点图标 + 4 句文案） | 要新图标；配额调不好会挤普通搜索点（259 的坑） |
| **D 勘探情报** | 不改生成，只改「看见」：科技「勘探」或角色能力，揭示每个搜索点的产物类（图上角标），没点的看不到 | `MapNode` 预掷产物类并存；科技构件 `tech_scout` | 节点角标 + 悬浮句 | 小 | 没有 B / C 就没东西可揭示，只能搭配 |
| **E 定向地图** | 章节多开几张：矿区 / 林区 / 废墟 / 魔境，开局第三页像选地图一样选 | 新章节 JSON（地图配置 + 敌人池 + 掉落表），每张一套 | 开局第三页多几张地图 | 大（每张图是一次 257 级的活：底图、敌人、事件） | 内容摊薄，做一张图的成本最高 |
| **F 订货 / 契约** | 集市「订货」：付钱点名一种材料，下一局必在某个搜索点出现 1～2 件；或「契约」：带回 N 件某材料给奖励 | `Market.orders`、搜索点 `scripted_finds`（已有 `_scripted_finds` 钩子） | 集市一张订货单；地图上那个点有订货角标 | 小～中 | 是「经济」不是「地理」，解决的是「要这一件」而不是「这一带出什么」 |

## 四、怎么搭

推荐 **B + C 打底，A 做玩家的旋钮，F 以后补**：

1. **先 B**（地理有产物）：三环各一系 + 高危区稀有件，地图纸边一张图例，节点悬浮句加一句。改动全在数据与 `draw_items` 的倍率，259 的权重不动。
2. **再 C**（点位类型化）：每环配额 1～2 个材料节点（从搜索点配额里分，不加节点总数），图标是最大的收益 —— 玩家看地图就能规划路线去拿铁矿。
3. **A 放出征页**：作者点名「正好加在出征界面」—— 一块「倾向」木牌三选一，对 B 的产物表再乘一层；默认「无」。
4. D 等有科技树位置再说；E 不建议现在做；F 等集市有了「订货」需求再做。

## 五、要作者定的

1. 方案组合：**B + C + A**（推荐）/ 只 A / 只 C / 其它组合。
2. C 的材料节点几种：**四种**（矿脉 / 林地 / 遗骸 / 符文堆，推荐）/ 三种（跟三系）。
3. A 的倾向粒度：**三系**（自然 / 工艺 / 魔法，推荐）/ 细标签（矿石 / 兽部件 / 魔晶…）。
4. 要不要先做 B 一单看效果，再决定 C：**先 B + C 一起**（推荐，图标才是感知）/ 分两单。
