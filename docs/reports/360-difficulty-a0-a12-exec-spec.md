## 一、新表和现状的差别

现在游戏里是「普通 + 进阶一到十」（报告 320）。新表是 A0 到 A12，其中三档机制不变，其余都换了：

| 档 | 新表的新增机制（累计生效） | 现在这一档是什么 | 差别 |
|---|---|---|---|
| A0 | 普通规则 | 普通 | 不变 |
| A1 | 普通敌人的道具变好 | 普通敌人生命 +10% | 换 |
| A2 | 侵蚀开启，每层深度扣 1 体力 | 同 | 不变 |
| A3 | 猎手出现，强度随行动步数分段渐变 | 同 | 不变 |
| A4 | 普通敌人和精英敌人的装备变好 | 约 15% 的普通战换成更强的一种敌人 | 换 |
| A5 | 休息点变少，只剩一个半途关闭的撤离点 | 猎手生命 +10% | 换 |
| A6 | 首领生命 +25%，加速 20% | 信仰门槛 +10% | 换 |
| A7 | 侵蚀蔓延加速 | 倒计时消耗 +10% | 同一类，沿用现有做法 |
| A8 | 和猎手战斗失败时多扣 1 体力 | 猎手伤害 +10% | 换 |
| A9 | 深度 ≥2 的侵蚀点随机一件叠层，满 3 层永久损毁；正常撤离清掉未损毁道具的层数 | 叠层与损毁已有 | 核对「撤离清层」，没有就补 |
| A10 | 首领变成强化版（增加独有道具） | 猎手追得更快 | 换 |
| A11 | 只能看到周围 N 个节点内的敌情；远处仍显示节点类型，隐藏具体敌人 | 没有这一档 | 新增 |
| A12 | 守卫核心：一名精英守卫为核心首领提供增援，先击败守卫可解除 | 没有这一档 | 新增 |

**被换掉的六条旧机制**（敌人生命 +10%、换更强敌人、猎手生命 +10%、信仰门槛 +10%、猎手伤害 +10%、猎手追得更快）新表里没有，按「新表是本版设计基准」处理：从各档数据里拿掉，代码里的开关留着不删，以后想用还能用。

结算积分倍率：A0 到 A10 和现在一样（1、1.05、1.15、1.35，之后每档 +0.05 到 1.7），新增 A11 为 1.8、A12 为 1.9。

### 2. 普通敌人持有物的最低掉落占比（G 列）

A0 20%、A1 25%、A2 30%、A3 35%、A4 40%、A5 50%、A6 60%、A7 70%、A8 起 80%。

照「来源与读法」表的两轮算法：

1. 第一轮照现在的做法，每件持有物按自身稀有度单独掷骰，幸运照常加成。掉了 K 件。
2. 第二轮补足：敌人持有 M 件可掉的道具，下限为 r，再补抽 max(0, ⌈M × r⌉ − K) 件。只从第一轮没掉的里面抽，抽中一件移出一件。M 为 0 直接结束。

- 「可掉的道具」：武器、护甲、食物、药品、饰品、材料都按件数算；另行发放的奖励（珍宝、精英保底）不算在内。
- **补抽的权重表里写「待定」**。建议初值：用第一轮各稀有度的基础掉率当权重，也就是越常见的越容易被补到，高稀有度不会因为保底变得好拿。
- 只对普通敌人生效。精英、首领、猎手的持有物掉落这一批不变。

### 3. 精英额外掉落一件（H 列）

A0 到 A3 优良及以上，A4 到 A7 稀有及以上，A8 到 A11 史诗及以上，A12 固定传说。精英节点打赢后额外发这一件，和持有物掉落分开结算。现在的精英保底是规则里的一个固定值，改成随难度取。科技给的额外奖励照旧另算。

## 三、各档机制的落地口径

表里只有一句话的几档，落地需要具体数。下面是建议初值。

- **A1「普通敌人的道具变好」**：普通战的敌人配装稀有度上限抬一档（敌人池各强度档的道具上限和武器上限各 +1，不超过史诗）。精英、首领不变。
- **A4「普通敌人和精英敌人的装备变好」**：在 A1 之上，普通战和精英战的配装上限再抬一档；精英的道具件数 +1。
- **A5「休息点变少，只剩一个半途关闭的撤离点」**：标准图现在是一个会随时间关闭的免费撤离点加一个常开的付费撤离点，A5 起去掉付费的那个。休息点数量减半，向下取整，至少留 1 个。打完首领直接撤离的规则不受影响。
- **A6「首领生命 +25%，加速 20%」**：只对核心节点的首领。加速按行动间隔缩短 20% 算（冷却和回气一起），不是移动。
- **A7「侵蚀蔓延加速」**：沿用现在进阶七的做法和数值（侵蚀倒计时快 10%），只改说明文字。
- **A8「和猎手战斗失败多扣 1 体力」**：只对猎手战。普通战失败扣的不变。
- **A9**：叠层、3 层损毁已有。核对「正常撤离时清掉未损毁道具的层数」，没有就补上；阵亡或紧急脱离不清。
- **A10「首领变成强化版（增加独有道具）」**：每个首领各配一件只有强化版才带的独有道具，打赢可掉。现在有两个首领（标准废墟的核心守卫、机关池的大钟）。**这两件道具还没有设计**，需要我另出一份小方案给作者定，执行线程先把「强化版首领多带一件指定道具」的口子做好，道具用占位。
- **A11「敌情可视距离 N」**：表里 N 待定，建议初值 N = 2（从当前所在节点算两步以内看得到具体敌人）。走近后揭示，揭示过的保持可见。远处节点照常显示是普通战、精英战还是首领战。已有的侦察类效果（扩大侦察范围）在这一档上叠加到 N 上。
- **A12「守卫核心」**：照「来源与读法」表的四行做：
  - 每局从可绕行支路上的已有精英里指定一名守卫，带一件联动道具，给首领一种增援效果；击败守卫解除。
  - 地图上公开守卫标记、增援效果和它是否还在生效。
  - 击败守卫按 A12 精英规则结一次传说保底；两条路线的首领宝箱保底相同。
  - 表里的例子：机关池的守卫带「备用发条」，直攻时首领生命第一次降到一半获得一次限时护盾（强度和时长待校准）。
  - **标准废墟的守卫联动道具和增援效果表里没有**，和 A10 的独有道具一起放进那份小方案。
  - 地图上没有可绕行支路上的精英时，这一局不设守卫，照 A11 的规则打。

## 四、分批

1. **第一批：掉落与搜索**（第二节 1、2、3）。只动规则和数据，不动机制，先在现有十档上生效。风险最低，玩家最先感到「难度越高东西越好」。
2. **第二批：A1 到 A9 的机制换档**（第三节到 A9）。拿掉六条旧机制，换上新的。改各档名字下面那一行说明。
3. **第三批：A10 强化首领的口子、A11 敌情距离**，新增 A11 档和解锁链（在 A10 撤离一次后解锁）。
4. **第四批：A12 守卫核心**，新增 A12 档。等独有道具和标准废墟守卫的小方案定了再做。

每批落地后重跑现有的校准工具（普通敌人、猎手渐变、负重与侵蚀的模拟），把各档的通关率、平均掉落件数和稀有度分布列进落地报告，再通知测试线程。

## 五、实现要点（给执行线程）

- 各档数据在 `data/authoring/difficulties/`，一档一个文件，每档写全到这一档为止的所有机制（一局只持有一个难度定义，不叠加）。新增 `ascension_11`、`ascension_12`，解锁链用现有的 `grants_unlock`。
- 掉落：第二轮补足加在 `core/loot/drop_resolver.gd` 的持有物掷骰之后；下限和精英额外稀有度做成难度定义上的字段，规则文件里的固定值作为 A0 的默认。期望件数的预览函数一起改。
- 说明文字里不能出现数字（导入检查），数值字段写成能当占位符用的整数。新增汉字先查字集。
- 旧存档：局外的解锁记录不动。进行中的局带着开局时的规则快照（`RunState.difficulty_rules`），不受影响；局内存档版本要不要升由执行线程看实际改动定。
- 开局屏的挑战卷轴现在按十档排，加到十二档后核对排版；每档一行不超过十个字的规则照旧。
- 新面板和图标（守卫标记、增援状态、远处隐藏敌情的节点样子）请 UI设计 出样张，先用占位。无裸文字、面板声明明暗这些规则照旧。
- 测试：每档的字段和说明对得上表；两轮掉落的下限在各档、各持有件数下都成立（含 M 为 0 和 1）；精英额外稀有度；A5 撤离点和休息点数；A6 首领数值；A8 只对猎手；A11 揭示与保持；A12 击败守卫前后增援的有无、无支路精英时不设守卫。

## 六、担忧

1. **掉落抬得很多。** A8 起普通敌人至少掉八成持有物，加上搜索三件全是史诗。高难度下一局带回的东西会明显多于现在，仓库、负重、经济（出售和炼金）都会被带着走。第一批落地后请先看「每局带回总价值」这一个数再往下做。
2. **A1、A4 让敌人拿更好的装备，等于同时抬了难度和掉落。** 和 G 列叠在一起，玩家的装备成长会被拉快。
3. **A5 一下拿掉两样安全垫**（休息点和常开撤离点），是十二档里体感最陡的一级，可能需要拆开或把数值放缓。
4. **拿掉的六条旧机制里有两条是专门校过的**（猎手追击、换更强敌人）。代码留着，但对应的测试和校准工具要改成不再依赖各档数据。
5. **A10 和 A12 缺内容**：强化首领的独有道具、标准废墟守卫的联动道具都没设计，是新的道具和美术量。
