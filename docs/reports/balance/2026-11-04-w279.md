## 四 结论

1. **0 档阶梯大体在带里，两头各有出格的。** 绿平均 11.9（目标 10–12），蓝平均 18.2（目标 14–17，略高）。出格的：手斧 9.0（白，高于 8）、双斧 15.7 / 战斧 13.7（绿，高于 12）、钢枪 26.0、戟 25.6、兽骨战斧 24.8、兽骨双斧 24.6（蓝，已到紫的 20–24）。
2. **2 档品质把每下叠层的件打穿了。** 只有伤害的涨约 20%（就是伤害 ×1.2），合乎补充二；每下施加流血、或每下叠易伤（`damage_taken` 轴）的涨 40%～106%：层数每档 +1，每一下都多叠，再和伤害 ×1.2 乘在一起。蓝件 2 档平均 26.0，已经越过紫（20–24）；戟 52.8、钢枪 51.4 越过橙（28–32）。
3. **敌人变强了，★ 胜率普遍降 2～21 点。** 降得最多的是快攻（段 0 −21、段 1 −20）、盾（段 0 −19、段 3 −21）、护甲（段 0 −17、段 2 −17）；流血基本没动。原因推断：新的绿 / 蓝武器进了敌人的流派池，敌人手里的平均 DPS 抬高了，木桩那边没有新件。同一段改动里还有 v5.05 的敌人摆件改动（武器组先摆、大的先摆），这张表分不开两者。

## 五 交架构设计定（执行这边先不改数）

- A. 品质的层数加成：每下都触发的施加（流血、易伤）不随品质加层，只有「开战一次」「够层追加」这类一次性的个数才 +1；或者只在 2 档 +1
- B. 出格的几把直接按阶梯回调（钢枪、戟、两把兽骨双持 / 战斧回到 14–17；双斧、战斧回到 10–12）
- C. 敌人那边：新件在敌人池里先降权，或档 0 的稀有度上限从绿改成白，等玩家这边也拿到新件再放开

## 六 定调后复测（架构设计 20:35 的 ① ② ③，v5.12）

- ① 出格的七把只压伤害数、句子不动：钢枪 23 → 14、戟 22 → 13、兽骨战斧 14 → 7、兽骨双斧 7 → 3（每下）、双斧 5 → 3（每下）、战斧 10 → 8、手斧 6 → 5。复测：钢枪 15.8、戟 15.4、兽骨战斧 16.6、兽骨双斧 15.4（蓝带 14–17 内），双斧 11.1、战斧 11.4（绿带内），手斧 7.9（白 ≤ 8）。兽骨战斧 / 兽骨双斧的一下比绿的还轻，强在流血
- ② 品质对每下都触发的规则（出手、命中、别的件出手、施加时）不再加施加层数和轴层数，只有一次性的（开战、加时）照 +1；伤害 ×1.1、写死的点数 +1、暴击 +5 点不变（架构设计 21:15：不等卡、先按推荐做，作者改口再回）。2 档品质的涨幅从 +40%～106% 回到约 +20%
- ③ 三个敌人池（standard_ruins、clockwork、hunters）的档位多了一个「武器稀有度上限」：武器档 0 白、档 1 绿、档 2 蓝（档 3 不限）；别的道具照旧（档 0 绿、档 1 蓝、档 2 起不限）。先试过把整档的稀有度上限一起压，毒的流派在档 0 没东西可抽、毒蛇 / 电鳗凑不够件数，内容检查不过，所以只压武器

### 4. 结论

1. 白绿回到带里（白均 7.2、绿均 11.8），蓝均 17.4 略高于 17（最高的还有骨牙双刀 22.9、钢双斧 20.1、钢双手剑 19.9、钢斧 19.3，不在 ① 的名单里，没动）。
2. **紫、橙按表写的数整体越档**：紫均 28.1（带 20–24），龙骑枪 47.9、斩马戟 36.0、血誓斧 33.9；橙均 45.1（带 28–32），霜纹龙骑枪 64.8、焰牙 / 霜牙 / 霜纹血誓斧约 57～59。原因和蓝一样：每下易伤 2 层、每下流血 2 层再叠一层元素，复利。② 之后 2 档品质平均涨约 +20%（白 7.2 → 8.5、蓝 17.4 → 21.2、紫 28.1 → 34.1、橙 45.1 → 53.3），紫最高 57.4、橙最高 77.8（② 之前 84.9 / 118.2）。
3. ★ 胜率（平均比 279 前 −5.4）：段 0 / 段 1 大多回到 ±10 内，快攻还低（段 0 −10、段 1 −18）；段 2 / 段 3 还低（段 3 盾 −27、段 2 护甲 −21、段 2 盾 / 刃钻 −15、段 3 爆发 −15），推断是档 3 不限稀有度，紫件进了敌人的池子。按 ③ 的后半句「仍低 5 点以上再给新件降权」，要降权；但敌人抽件现在是池里等概率抽，没有按件的权重，要新开一个口子。
4. 交架构设计：紫橙要不要照 ① 的办法按阶梯压（只压伤害数不够，焰牙这类大头在流血和元素上，要动层数）；降权怎么做（档 3 也设上限紫、还是给 279 新件一个敌人抽中的权重）。

## 七 紫 / 橙回调与档 3 武器上限（架构设计 22:31，v5.13）

- 紫橙每把最多留一句「每下叠层」（流血 / 易伤 / 元素），留这一线材质那句：橙的元素（魔晶加的）一律改成「开战施加」，层数 = 原来每下的 3 倍（灼烧 / 冰寒 / 麻痹 1 → 3，焰纹陨铁大锤 2 → 6）；斩马戟、雷纹斩马戟留流血，易伤改成开战 2 层。慢（攻速轴）不算叠层，没动
- 先试过反过来（留元素、流血改开战）：焰牙 / 霜牙伤害压到 1 还有 30 以上 —— 快武器每下的元素和开局流血起反应，复利最大；按「这一线材质」留流血之后数才正常
- 伤害数照扫表压回带中间（紫 22、橙 30），22 把：龙骑枪 31 → 14、霜纹龙骑枪 42 → 19、焰牙 / 霜牙 14 → 10、霜纹血誓斧 28 → 18、血誓斧 21 → 12、噬血骨刺 9 → 5、噬血双刀 8 → 5 等（全列表见 PR）。弓弩台架不装箭，没动
- 三个敌人池档 3 武器上限紫（橙只能锻造，本来就不进敌人池；这一条拦下的是 279 之前的传说武器）
