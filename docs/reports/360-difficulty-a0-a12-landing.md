# 360 难度 A0 到 A12：落地记录

> 依据：[360 落地说明](360-difficulty-a0-a12-exec-spec.md)、作者的难度设计表 `balance/difficulty/2026-11-20-difficulty-and-drops.xlsx`。每批落地后在这里追加一节。

## 第一批：掉落与搜索（v7.30）

### 改了什么

1. **搜索逐件下限**（表 D、E 列）：A1 到 A10 每档写全常规 / 进阶两行下限（难度定义的 `search_floors`）。A0 沿用规则里的阶梯表，和表一致。
2. **普通敌人持有物最低掉落占比**（G 列，两轮算法）：
   - 第一轮照旧逐件掷。第二轮补抽 max(0, ⌈M × r⌉ − K) 件，只从没掉的里抽，抽中一件移出一件。
   - M 只数能随机掉的持有物（包、红武、劣化版、券、信物不算）；珍宝、精英额外那件不算。
   - 补抽权重用各稀有度的基础掉率（待定项，按建议初值）。
   - 只对普通战和搜索遭遇生效；精英、首领、猎手不变。
   - A0 的 20% 写在标准掉落规则上（`held_floor_percent`），A1 起写在各档（25 / 30 / 35 / 40 / 50 / 60 / 70，A8 起 80）。
3. **精英额外掉落一件**（H 列）：标准掉落规则 A0 起给优良（以前标准版不给），A4 起稀有，A8 起史诗（难度定义的 `elite_rarity`）。科技的额外奖励照旧另算。
4. 开发版地图预览的「预计掉几件」按同一套规则算（精英、普通敌人都对上）。

F 列「进阶搜索下限」、首领宝箱这次没做。A11、A12 两档还不存在，它们的数在第三、四批补。

### 校准：每局带回总价值

用负重模拟（`tools/sim/encumbrance_sim.gd`，必赢血量、只看价值的机器人、三名角色 × 小 / 中图 × 每组 6 局，同一批种子）分别跑合并前的 main 和这一批。**更正（第二批时发现）**：第一次报的数被一件价值十万的彩蛋道具拉偏了，下面是去掉它之后的数：

| 难度 | 撤离率（前 → 后） | 带回总价值均值（前 → 后） | 中位数（前 → 后） | 带回件数（前 → 后） | 稀有度分布，后（普 / 优 / 稀 / 史 / 传） |
|---|---|---|---|---|---|
| A0 | 63% → 63% | 2078 → 2120（+2%） | 1696 → 1701 | 26.8 → 26.8 | 7% / 34% / 42% / 12% / 2% |
| A1 | 63% → 63% | 2336 → 2308（−1%） | 1987 → 1966 | 26.4 → 26.5 | 4% / 31% / 47% / 13% / 3% |
| A4 | 55% → 61% | 3364 → 2977（−12%） | 2782 → 2442 | 22.9 → 23.7 | 3% / 19% / 47% / 23% / 6% |
| A8 | 50% → 55% | 3332 → 4085（+23%） | 2777 → 3489 | 22.8 → 23.4 | 1% / 8% / 35% / 46% / 8% |
| A10 | 58% → 66% | 3248 → 4221（+30%） | 2822 → 3834 | 22.7 → 22.9 | 1% / 9% / 24% / 56% / 8% |

读法：

- 带回的件数几乎不变：背包装满是瓶颈，多掉的东西机器人拿不走，只是换成了更好的。
- 高档位带回的总价值多两到三成，稀有度明显往史诗挪。A4 少了一成，因为旧的 A4 搜索阶梯（第一件史诗）比新表松一档。
- 没有到「抬得太猛」的程度，按计划继续第二批。
- 撤离率的变化是随机波动（每档 36 局，机器人不打输）。

## 第二批：A1 到 A10 换机制（v7.39）

### 改了什么

| 档 | 新机制（累计） | 怎么做的 |
|---|---|---|
| A1 | 普通敌人的道具变好 | 普通战（含随机点、搜索遭遇）敌人配装的道具和武器稀有度上限各抬一档，不限的仍不限，封顶史诗 |
| A4 | 普通和精英的装备变好 | 普通战再抬一档（共两档）；精英抬一档、多带一件；低档敌人「不背真实伤害武器」放开（367 裁定） |
| A5 | 休息点变少，只剩一个半途关闭的撤离点 | 休息点留一半（向下取整，至少一个）；不设付费撤离点，只留倒计时过半关闭的那个，其余撤离点变成路口 |
| A6 | 首领生命 +25%，加速 20% | 只对核心点首领；出手间隔缩短 20%（每件的触发速度和耐力回复一起 ×1.25） |
| A7 | 侵蚀蔓延加速 | 沿用倒计时多扣 10% |
| A8 | 输给猎手多扣 1 体力 | 只对猎手战；另按 367 裁定，所有敌人的武器品质 +1（掉下来的也是那一把） |
| A9 | 侵蚀叠层、正常撤离清层 | 已有，核对过：正常撤离清掉幸存道具的层数，战败不清 |
| A10 | 首领变成强化版 | 核心守卫叫「誓约守卫」、大钟叫「永动大钟」（365 裁定），名牌换名；独有道具「守誓徽记」「永动摆心」进了道具库就自动多带一件、打赢必掉，现在还没进库，只换名 |

六条旧机制（敌人生命 +10%、换更强敌人、猎手生命 +10%、信仰门槛 +10%、猎手伤害 +10%、猎手追击）从各档数据拿掉，代码开关留着，老测试改成在定义副本上补回旧数来测。各档名字下面那一行和说明都按新机制重写。

### 校准

同一个模拟，这次用正常血量（会打输），每组 5 局，对比第一批合并后的 main：

| 难度 | 撤离率（前 → 后） | 带回总价值均值（前 → 后） | 中位数（前 → 后） |
|---|---|---|---|
| A0 | 63% → 63% | 1936 → 1936 | 1802 → 1802 |
| A1 | 63% → 63% | 2341 → 2400 | 1984 → 2172 |
| A4 | 56% → 53% | 3110 → 3159 | 2672 → 2762 |
| A5 | 60% → 16% | 3223 → 3341 | 2858 → 3470 |
| A6 | 56% → 16% | 3416 → 3262 | 2978 → 3188 |
| A8 | 50% → 23% | 4113 → 3889 | 3874 → 4340 |
| A10 | 60% → 23% | 4146 → 4390 | 3801 → 4657 |

- A1 到 A4 的配装变好基本没让机器人多输。
- **A5 是断崖**：撤离率从六成掉到一成多。原因是只剩一个撤离点，而且它过半就关；机器人不会提前算关门时间，过了一半就出不去了，只能靠打首领。真人会看着关门时间提前撤，掉得不会这么多，但这一档仍是十二档里最陡的一级（落地说明第六节担忧 3）。
