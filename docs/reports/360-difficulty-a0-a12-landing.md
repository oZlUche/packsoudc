# 360 难度 A0 到 A12：落地记录

> 依据：[360 落地说明](360-difficulty-a0-a12-exec-spec.md)、作者的难度设计表 `balance/difficulty/2026-11-20-difficulty-and-drops.xlsx`。每批落地后在这里追加一节。

## 第一批：掉落与搜索（v7.30）

### 改了什么

1. **搜索逐件下限**（表 D、E 列）：A1 到 A10 每档写全常规 / 进阶两行下限（难度定义的 `search_floors`）。A0 沿用规则里的阶梯表，和表一致。
2. **普通敌人持有物最低掉落占比**（G 列，两轮算法）：
   - 第一轮照旧逐件掷。第二轮补抽 max(0, ⌈M × r⌉ − K) 件，只从没掉的里抽，抽中一件移出一件。
   - M 只数能随机掉的持有物（包、红武、劣化版、券、信物不算）；珍宝、精英额外那件不算。
   - 补抽权重用各稀有度的基础掉率（待定项，按建议初值）。
   - 只对普通战和搜索遭遇生效；精英、首领、猎手不变。
   - A0 的 20% 写在标准掉落规则上（`held_floor_percent`），A1 起写在各档（25 / 30 / 35 / 40 / 50 / 60 / 70，A8 起 80）。
3. **精英额外掉落一件**（H 列）：标准掉落规则 A0 起给优良（以前标准版不给），A4 起稀有，A8 起史诗（难度定义的 `elite_rarity`）。科技的额外奖励照旧另算。
4. 开发版地图预览的「预计掉几件」按同一套规则算（精英、普通敌人都对上）。

F 列「进阶搜索下限」、首领宝箱这次没做。A11、A12 两档还不存在，它们的数在第三、四批补。

### 校准：每局带回总价值

用负重模拟（`tools/sim/encumbrance_sim.gd`，必赢血量、只看价值的机器人、三名角色 × 小 / 中图 × 每组 6 局，同一批种子）分别跑合并前的 main 和这一批：

| 难度 | 撤离率（前 → 后） | 带回总价值（前 → 后） | 带回件数（前 → 后） | 稀有度分布，后（普 / 优 / 稀 / 史 / 传） |
|---|---|---|---|---|
| A0 | 63% → 63% | 7633 → 7676（+1%） | 26.9 → 26.9 | 7% / 34% / 42% / 12% / 2% |
| A1 | 63% → 63% | 7892 → 7863（0%） | 26.4 → 26.6 | 4% / 31% / 47% / 13% / 3% |
| A4 | 55% → 61% | 6142 → 5755（−6%） | 22.9 → 23.7 | 3% / 19% / 47% / 23% / 6% |
| A8 | 50% → 55% | 6110 → 6863（+12%） | 22.9 → 23.4 | 1% / 8% / 35% / 46% / 8% |
| A10 | 58% → 66% | 6025 → 6998（+16%） | 22.8 → 22.9 | 1% / 9% / 24% / 56% / 8% |

读法：

- 带回的件数几乎不变：背包装满是瓶颈，多掉的东西机器人拿不走，只是换成了更好的。
- 高档位带回的总价值多一到两成，稀有度明显往史诗挪。A4 略降是因为旧的 A4 搜索阶梯（第一件史诗）比新表松了一档。
- 「抬得太猛」没有出现，按计划继续第二批。
- 撤离率的变化是随机波动（每档 36 局，机器人不打输）。
