## 一、石刻的规矩

1. **外框和格子只用一种材质：浅色石。** 顶端栏、窗框、格子、页签（没选中）、小签都用浅石，墨色字（tone light）。
2. **放数据的地方用深色石板。** 属性卡、神恩区、名牌、图例、腰带框、悬浮窗、选中的页签都用深石板，白字（tone dark）；加成数字照旧用金色 #FFC928。
3. **强调色只有黄铜 #C9A04E。** 石板里的细线、悬浮窗边、神恩图标边、层数小圆点都用它。红色只留给提醒红点。
4. 日晷不动。

## 三、A12 守卫小旗

- `assets/ui/map/guard_flag_clockwork`（备用发条，铜色旗 + 发条钥匙）、`guard_flag_horn`（求援号角，红旗 + 号角）、`guard_flag_beast`（兽王之契，绿旗 + 兽爪）。1x 48×64，`@2x` 96×128；json 里的 `anchor` 是旗杆脚，放在节点圆的右上沿。
