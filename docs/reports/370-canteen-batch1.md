# 370 灰灯食堂第一批：锅、食材仓库、饱腹度（报告 355 落地）

> 日期：2026-11-21。方案见[报告 355](355-canteen-free-cooking.md)（342 的 B4，取代 352）。本批按第四节「先做数据、食材仓库、锅盘、逻辑、存档、饱腹度和占位页面，食材先上每类一格和两格的各两件」。
> 数值、名字、档位都是报告 355 的建议初值；水果按作者 16:41 抬高后的那版（一格每秒 0.5 起）。

## 一、做了什么

- **开放**：灰灯到受托（25）、办完许可单后，剧情《开伙》（`greylamp_canteen`）自动接上，在委托页【办理】一次就开食堂。后勤一直列着「食堂」键（灰灯一开始就在营地），没开时点进去是说明板，和别的设施一样。教程、试玩切片不列。
- **食材**：新标签「食材」（`ingredient`，类别标签）。第一批 16 件：每类一格、两格各两件，一件固定值一件百分比。14 件新的，薄荷叶束、蜂蜜罐原来是占位的「材料」，改成「食材」（一件道具只能有一个类别标签）。说明文字全部留空，图标先用占位。
- **食材表**：`data/authoring/base_rules/canteen.json`，道具 id → 类别、固定值或百分比、饱腹值；导入器查：类别认得、固定值和百分比只写一样、带「食材」标签的道具都在表里。
- **食材仓库和锅**：都是现有的格子盘，只收食材。灰灯受托时仓库 6×6、锅 4×4，信赖 8×8 / 5×5，代言 10×8 / 6×6；只长不缩，东西原位不动。开放那一刻，主仓库里已有的食材搬进食材仓库一次。
- **自动入库**：带回来的棋盘一键置入时，食材先进食材仓库，满了才进主仓库；苗圃收获同样（现在的两种作物都不是食材，第三批的作物用得上）。
- **一锅的效果**：同一属性固定值相加、百分比相加。负重上限、耐力上限、耐力回复和科技同一条算式；水果的每秒回血单独一项，不吃治疗、回复加成，也不被燃血这类打折。每条汇总后封顶，防溢出。
- **出征**：开局成功那一刻吃掉锅里这一锅，取消准备不扣。局里每走到一个新节点饱腹减 1，回头走、出生点不扣。剩 1 提醒一次；到 0 全部加成失效，负重上限那份多留一步，下一个新节点才卸。顶端栏第二行多一个「饱腹 N」读数，饿了写「饿了」。
- **占位页面**：后勤「食堂」页左边食材仓库、中间锅，两块盘都套外框画格线，拖来拖去和仓库拖背包一样；右边一张纸条写这一锅每条属性（固定值、百分比分开列）和饱腹度。食材的悬浮窗多一行「下锅：耐力上限 +5% · 饱腹 +5」。
- **存档**：局外加 `canteen`（两块盘 + 搬没搬过旧食材），局内加 `modules.meal`（这一锅、剩几点、负重多留一步没有、提醒过没有）。都是带默认值的新键，按项目规矩不升版本（报告 355 第四节写的「版本升一」没有照做）；读档不重算、不重扣。

## 三、强力搭配记录（第一批的件）

两格主食（酸麦 + 黑豆，饱腹 10，约走 10 个新节点）之后，剩下的格子全放同一件：4×4 剩 14 格，6×6 剩 34 格。

| 属性 | 最强一件 | 4×4 | 6×6 |
|---|---|---:|---:|
| 耐力上限（固定） | 兽肉，每格 1.5 | +21 | +51 |
| 耐力上限（百分比） | 禽腿，每格 2.5% | +35% | +85% |
| 耐力回复（固定） | 香根，每格 0.125 | +1.75 / 秒 | +4.25 / 秒 |
| 耐力回复（百分比） | 苦苣，每格 3% | +42% | +102% |
| 每秒回血（固定） | 山梨，每格 0.6 | 8.4 / 秒 | 20.4 / 秒 |
| 每秒回血（百分比） | 蜂蜜罐、红果串，每格 1% | 生命上限 14% / 秒 | **生命上限 34% / 秒** |

- **最该先看的是「整锅百分比水果」**：6×6 摆满蜂蜜罐或红果串，每秒回生命上限的三成多，生命 85 的角色每秒回 29 点，基本打不死。4×4 也有每秒 14%。按作者「特别强的先记录」没设上限，等你定要不要压（比如回血单独一个上限，或者百分比线每格减半）。
- 固定值回血 6×6 每秒 20 点，和报告 355 第五节第 8 条的估计一致。
- 科技、信仰叠在一起的总量第三批的核对工具再算（报告 355 第五节第 7 条）。
