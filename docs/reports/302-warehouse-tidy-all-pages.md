# 302 仓库「整理」改成跨页全局整理（109 / 163 补充）

> 作者 2026-11-11 13:34（架构设计线程）：「目前仓库的整理按钮只能整理当前页，我希望的整理是跨页的，或者说是全局的」。直接指派，派执行。

## 〇 一句话

「整理」不再只排当前页，而是把**所有页**的东西收起来按同一套顺序重排，从第一页往后填：同类挨在一起、前面的页填满、空页都在最后。

## 一、现状（读码）

- `WarehousePanel.tidy()` → `GridTidy.tidy(当前页)`：只动当前页（109 作者定、163）。顺序：先同类（`KIND_ORDER`：武器 → 盾 / 防具 → 饰物 / 特殊 → 药剂 / 食物 → 弹药 / 试剂 → 魔晶石 / 素材 / 零件 → 贵重品）→ 同类里先大后小 → 稀有度高的先 → id、uid。放不下就整批放回原位，绝不丢东西。
- 仓库是一摞页（`Warehouse.pages`，每页一块 `GridInventory`）。东西是哪页有空进哪页，久了每一页都是杂的，一页一页整理也合不拢。

## 二、做法

1. 新 `GridTidy.tidy_all(pages)`：所有页的东西全部取下 → 照**现在同一套顺序**排成一队 → 从第一页起逐件放，这一页放不下这件就试后面的页（小件仍会回头填前面页的缝：每件从第一页开始找第一个放得下的位置）。
2. 结果：武器都在最前面的页，往后依次是各类；空格集中在最后。翻到哪一页都不用再点一次。
3. 不丢东西：有任何一件放不下（异形件装箱理论上可能），全部页整批放回原位，说一句「排不开」（现有句）。整个过程每页只发一次变化。
4. 不动的东西：带回来的背包棋盘（玩家摆的阵）、包架，照旧不归整理管。锁定（230）的道具照样参加整理 —— 锁定只挡出售和丢弃，不挡挪位。收藏（265）的同理。
5. 临时加出来的页（仓库满了临时多出的页）：整理后空了的照现有规矩收掉。
6. 按钮：还是一枚「整理」，不另加「整理本页」（先少再多）。亮灭条件从「当前页不止一件」改成「整个仓库不止一件」。整理完留在当前页不跳页，提示句从「这一页整理好了」改成「仓库整理好了」。
7. 哪些地方：基地「仓库」页和结算屏第二页的仓库是同一个面板，一起生效；出发整备页的仓库若有同一枚键，同样改。

## 三、改动清单（执行）

1. `core/inventory/grid_tidy.gd`：`tidy_all(pages: Array[GridInventory]) -> bool`（复用现有排序键；失败整批回滚）。
2. `ui/game/warehouse_panel.gd`：`tidy()` 改调 `tidy_all`；按钮亮灭、提示句；`UiText` 的 `wh.page_tidied` 改字（中英）。
3. 测试：三页各放杂物，整理后武器全在最前、类别按 `KIND_ORDER` 连续、空页在最后、件数与 uid 一个不少；塞一件哪页都放不下的假件时全部回到原位；带回来的棋盘不动；整理两次结果一样。
