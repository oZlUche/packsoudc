# 091 · 附录 A：中国肉鸽 / 搜打撤玩家对「剧情」的态度 —— 证据汇编（2019–2026）

> 计划书 [091](091-career-vs-roguelike-plan.md) 的资料底稿（国内一路）。区分【硬数据】（有来源、可量化）与【观点 / 社区言论】。第 4 节的 Steam 中文评测关键词统计是调研时用 Steam 公开评测接口抓样计算的（抓取日 2026-09-27），方法与局限见该节。多数知乎页面无法直接抓取，相关内容来自搜索摘要或转载页，已标注。

## 2. 案例与接手数据

### 2.1 暖雪（Warm Snow，2022-01）
- 2022 上半年国游销量榜第一：70 万套、4100 万元（[游戏陀螺](https://www.youxituoluo.com/529588.html)）；2024-05 全端 300 万份，Steam 好评 92%（[游戏陀螺](https://www.youxituoluo.com/532246.html)）。抓样：Steam 简中评测 36,501 条，92.9% 好评。
- TapTap 玩家标签计数（2026-09）：操作流畅 582、画面优秀 476、**剧情跌宕 280**、音效 149（[TapTap](https://www.taptap.cn/app/240587/review)）—— 剧情是第三高的正向标签。
- 叙事载体：36 页「见闻录」碎片（[游民](https://www.gamersky.com/handbook/202201/1455035_34.shtml)）；发行方另做 3 话前传动画，B 站播放 543 万（2022-01）。
- 制作人李梓复盘（[机核 2022](https://www.gcores.com/articles/146899)、[茶馆 2023](https://lingyuq.com/news/408756.html)、[TGDC 2022](https://news.qq.com/rain/a/20220829A0557300)）：「立项初期准备了丰富的世界观与剧本，很想做经典 RPG……因经费与人力限制未能实现，因此叙事比较隐晦」；「暖雪的剧情是围绕 Rogue 玩法做补全，比如主角为什么能无限复活」；「Rogue 游戏没办法深度表演刻画角色，用历史人物影子让玩家快速联想」；把成本投在 Boss 战而非剧情演出；「人手不足、资金短缺去做一个有大量剧情演出同时还有丰富战斗玩法的游戏本身就不现实」。
- 游民评测 7.8 分：优点全是打击感 / Build，剧情只提「非线性叙事，不看细碎文档根本不知道发生了什么」（[游民](https://www.gamersky.com/review/202202/1461157.shtml)）。
- 社区：知乎有答「玩家对剧情感知特别低」（搜索摘要，[知乎](https://www.zhihu.com/question/512323064)）。Steam 简中样本里提到剧情的评测 7/8 是正向，差评几乎全是手感 / 难度 / Bug，无一条以剧情为差评理由。

### 2.2 背包乱斗 Backpack Battles（2024）
- EA 上线 2 天 10 万份、首月 64 万份、累计破 100 万；**中国约占销售额一半**（[腾讯新闻](https://news.qq.com/rain/a/20240312A0A9CO00)）。抓样：简中评测 8,359 条，88.2% 好评。
- 零剧情。100 条近期简中评测中仅 1 条提「剧情」：「一般游戏的剧情我都是咔咔跳过」。

### 2.3 背包英雄 Backpack Hero（1.0 于 2023-11 追加故事 / 城镇模式）
- 简中评测 1,261 条，**79.3%（多半好评）**，是本表最低；TapTap 手游版标签：有趣好玩 1108、剧情跌宕 15（[TapTap](https://www.taptap.cn/app/238437/review)）。
- 近期 100 条样本中 13 条提剧情 / 故事模式 —— 比例第二高，但多为批评：「剧情貌似比较粗糙没啥必要，模拟村庄摆装饰也挺无聊」「故事模式把有趣的设计揉碎了放在平庸的局外养成里，太拖沓」「剧情模式不如快速模式好玩」。少数称「略有深度的背景叙事」是加分。
- 繁中长评：「城镇建设半成品、刻意用农资源与解锁拉长时间」（[巴哈](https://home.gamer.com.tw/artwork.php?sn=6310847)）；海外媒体评「story mode falls flat」「town is tacked-on padding」。
- **这是最接近「肉鸽追加生涯 / 剧情模式」的可查案例，反馈偏负。**

### 2.4 小丑牌 / 杀戮尖塔（零剧情）
- 杀戮尖塔简中评测 82,741 条、97.7% 好评；小丑牌 28,751 条、96.6%。近期 100 条简中评测中提到剧情的均为 **0 条**。
- 中文媒体：「没有剧情、角色成长，纯靠玩法获得口碑」（[3DM](https://www.3dmgame.com/score/3712995.html)）。未发现「无剧情」被当作缺点；小丑牌被诟病的是「运气占比大、重玩后期乏味」。

### 2.5 哈迪斯 Hades（剧情成功案例）
- 简中评测 58,516 条、96.9% 好评。文本量「超过三十万字」「约 8000 行配音台词」，主线需至少击败 Boss 10 次（[机核](https://www.gcores.com/articles/189926)；[GameGeeker](https://gamegeeker.com/zh/games/hades/review)）。
- 简中评测提剧情比例 **16～18%**（本表最高），约 3/4 正向：「一开始就是奔着剧情来的」「再死一次看看他们说什么 —— 这个念头比任何数值奖励都能留住人」。负向：「主线剧情得通关十次才能解锁，同一副本来回刷，玩的心累」「更适合体验剧情而非重度肉鸽爱好者长期刷 build」。
- 机核 2020 短评定为「Roguelike 叙事方法的革新」—— 剧情放在局外圣殿、按行为映射对话（[机核](https://www.gcores.com/articles/129463)）。2025 机核用户吐槽：「剧情和内容很难重样，但每局流程又如此重复」（[机核机组](https://www.gcores.com/talks/1151931)）。

### 2.6 其他肉鸽在中文社区被提及剧情的程度
- 死亡细胞、吸血鬼幸存者、Brotato：近期 100 条简中评测提剧情 0 条；以撒 1 条（正向）。
- 循环英雄：10% 提剧情，全部正向（「把循环机制融入世界观」），但也有「本身就不是靠剧情取胜」。
- 霓虹深渊：1 条差评「剧情没有，打击感没有」；TapTap 无限版标签 剧情跌宕 66 vs 画面优秀 1174。
- 元气骑士 TapTap 前 8 标签无剧情。
- 月圆之夜：有剧情的卡牌肉鸽，TapTap 曾 9.3 分（[GameRes 2020](https://www.gameres.com/875382.html)）；标签 有趣好玩 2.3 万、画面 3305、**剧情跌宕 2378**（第 3）（[TapTap](https://www.taptap.cn/app/58885/review)）。老玩家长评：「游戏性在卡牌游戏里算不上顶尖……更吸引我的是故事剧情」，并因官方转向联机、后续故事不讲而扣分 —— 剧情是该作留存老玩家的核心资产之一。
- 不思议的皇冠：简中 3,967 条、85%；4% 提剧情，正负两极。
- 火山的女儿（非肉鸽，重剧情养成，两人团队）：20 万字、50+ 结局、销量超 100 万、Steam 4 万+ 评测 97%；3% 差评中超过 1/3 是骂某条角色线（[TapTap 访谈](https://www.taptap.cn/moment/740234750135897824)）—— 中国玩家愿为剧情买单，但剧情一旦有瑕疵会集中挨打。

### 2.7 搜打撤：剧情 / 任务线 / 世界观
- **逃离鸭科夫**（5 人，2025-10）：回本预期 30 万份，4 天 50 万、23 天 300 万，首周好评 96%（[机核](https://www.gcores.com/articles/205984)）。抓样：简中评测 76,396 条，好评已降至 81.2%（差评集中在恶意 MOD / 运营）。团队自述「剧情没有详细展开，主要通过碎片化方式讲述……有 4 个结局」；乐子彩蛋（尿素袋、烤鸭）是传播主力（[腾讯新闻](https://news.qq.com/rain/a/20251030A02BB500)）。评测样本：正向 100 条中提剧情 1～2 条、提「任务」8 条（多为「又臭又长、重复」）、提 MOD 21 条。
- **暗区突围**：2024 追加 PVE 剧情战役「深渊行者」，剧情 PV 登 B 站全站第 7；结局「背刺」引发大量二创（[游研社](https://www.yystv.cn/p/11914)）。策划把剧情 PVE 定位为「休闲零食」不是主菜（[知乎专栏 2026](https://zhuanlan.zhihu.com/p/2065401431541168104)）。
- **三角洲行动：黑鹰坠落**（2025-02，剧情战役）：Steam 好评率 44% → 35%；中文区好评率仅 29%。差评主因是技术与宣传问题，剧情本身「高度还原电影」被认可（[3DM](https://www.3dmgame.com/news/202502/3915135.html)）。
- 观点：搜打撤是「公路片逻辑 / 玩家自叙事」，剧情战役的实际价值是「当高级新手教程」。

### 2.8 「肉鸽 + 大量剧情」的国内翻车案例
- 《无尽梦回》（2024-11）：主线剧情绑定肉鸽战斗，「许多玩家对剧情的评价是无聊；对肉鸽玩家来说点跳过键都点得手累」（[腾讯新闻](https://news.qq.com/rain/a/20241128A0708O00)）。
- 《克瑞因的纷争》（2022）：卡牌玩家嫌跑图和剧情多，发售一周在「多半好评 / 褒贬不一」徘徊（[游戏学院网](https://www.bjgamecollege.cn/youxipingce/2022101017856.html)）。
- 《明日方舟》集成战略「界园」（2026）：NGA 主流回复「肉鸽是给人玩的，玩法拉了剧情写再好也没法吸引人」「一把两个小时就为了看几分钟剧情，肉鸽剧情才是最没用的」（[NGA](https://bbs.nga.cn/read.php?tid=46931203)）。

## 4. Steam 中文评测关键词统计（自行抓样）

**TapTap 正向标签计数（辅证）**：暖雪「剧情跌宕」280（第 3）；月圆之夜 2378（第 3）；霓虹深渊无限 66（第 7）；背包英雄 15；元气骑士 / 鸭科夫 / 暗区突围 前列标签无「剧情」。

**解读**：中文评测提剧情的比例与游戏「投入了多少剧情」高度相关（0% → 18%），而不与好评率相关 —— 零剧情的尖塔 / 小丑牌 / 细胞好评率反而最高。剧情被主动提及且正向的只有哈迪斯、暖雪、循环英雄、月圆之夜这几款「剧情与循环机制自洽」的作品；被提及但负向的是「追加的独立剧情 / 城镇模式」（背包英雄）和「看不懂 / 推进太慢」（哈迪斯差评）。

## 5. 成本侧参考

- 文案 / 剧情外包：兼职文案常见 80～200 元 / 千字；文字游戏平台招剧本写手公开报价 45～50 元 / 千字（[招募帖](https://www.yeyulingfeng.com/259346.html)）；工作室「中小项目剧情文案包装 3 万元起全包」（[陌巷工作室 2020](https://www.douban.com/note/763243559/)）。
- 本地化：中英游戏基础翻译 150 元 / 千字符起（[雅言翻译 2026](https://www.artlangs.cn/newsDetail/translation-newsdetail/35986.html)）；英 → 中欧洲报价约 120 欧元 / 千字（[indienova](https://indienova.com/indie-game-development/localiztion-of-your-games/)）。
- 中文配音（[游研社 2025-02](https://www.yystv.cn/p/12583)）：可靠录音室每句 70～100 元；独立游戏约「50 元左右一句」；「25 万字文本 AVG 配知名国配约 25 万元」。业内共识：「准备充分的字幕比准备不足的配音更好」。
- 参照体量：哈迪斯 30 万+ 字 / 8000 行配音；火山的女儿 20 万字（2 人 3 年）；暖雪 36 页见闻录；鸭科夫「碎片化 + 4 结局」（5 人）。

**低成本叙事的国产做法**：暖雪（见闻录碎片 + 历史人物影子 + 预算砸 Boss 演出 + 发行方做动画补前传）；鸭科夫（道具 / 彩蛋 / 梗承载世界观，多结局由两个关键选择组合生成）；月圆之夜（每个角色一段短故事 + 三选一互动事件，用「书」的 UI 装订碎片）；哈迪斯（上限：局外 NPC 对话表 + 行为映射，代价是数十万字与全程配音）；机核 2026 总结「故事是奖励而非主线」—— 结局文本、藏品描述、结局补充文本是常见载体。

## 6. 小结：证据说明了什么

1. **中文肉鸽玩家不因「没剧情」扣分。** 零剧情的杀戮尖塔 / 小丑牌 / 死亡细胞 / 吸血鬼幸存者 / 背包乱斗简中好评率 88～98%，近期评测提剧情 0～1%；「没剧情」未出现在任何差评理由中。
2. **剧情做好了会被提及并加分，但比例上限约 15～20%。** 哈迪斯 16～18%、循环英雄 10%、暖雪 8～9% 是正向提及。剧情是「少数人强需求 + 多数人不在意」的结构。
3. **「追加独立剧情 / 生涯模式」的直接先例反馈偏负。** 背包英雄 1.0 的故事 + 城镇模式多被评「拖沓、不如快速模式」；三角洲黑鹰坠落中文区好评 29%（主因技术）。暗区突围的剧情战役是正例，但它是千万 DAU 大厂产品，定位「零食 / 教程」。
4. **剧情要「长在循环上」而不是「挂在外面」。** 被夸的（哈迪斯、循环英雄、暖雪）都把剧情推进绑定在死亡 / 重开机制上；被骂的（无尽梦回、背包英雄、界园）都是剧情迫使玩家做重复或额外内容。
5. **搜打撤玩家对剧情基本无感，对「任务线」敏感且多为负面。** 鸭科夫 100 条好评中剧情 1～2 条、任务 8 条（「又臭又长」）、MOD 21 条。世界观在暗区突围的价值主要是 PV / 二创传播。
6. **成本量级差距巨大。** 碎片化文本外包几千到几万元；哈迪斯式 30 万字 + 全配音在国内数十万元起。
7. **证据薄弱处**：没有针对中国肉鸽玩家的正式剧情偏好调研；Steam 关键词统计是单日 100 条近期样本、以词频代态度；知乎原帖依赖摘要；追加剧情 DLC 的独立评分缺失。
8. **相互矛盾处**：海外独立玩家调研（Humble 2024）把剧情列为「重中之重」，而中文肉鸽评测数据显示剧情几乎不影响评分 —— 可能是文化 / 品类差异，也可能是「声称偏好」与「实际行为」的差距；火山的女儿、月圆之夜又证明中国玩家愿为剧情买单且会因剧情瑕疵集中差评 —— 「做了就必须做好」，风险不对称。
