# 324 统一教程 D 批第一步：出征页教程木牌和「跳过剩余教程」

> 日期：2026-11-18。依据：[统一教程方案](../plans/2026-11-18-unified-tutorial-and-base-return.md) §8.1、§8.2、§5 B9（PR #651）；接报告 [321](321-unified-tutorial-batch-a.md)～[323](323-unified-tutorial-batch-c.md)。作者 2026-11-18 09:24：「根据 PR651 的新增方案，优化切片 demo」。
> D 批拆成三步：D1 出征页（本篇）、D2 切片基地开后勤与书架、D3 第一局休息点与基地导览。

## 一、出征页

- 教程没全通时，「上回出征」那块木牌换成「教程」木牌，写三样：
  - 下一段的图名；
  - 一张小签，写「教程 n/3」；
  - 右下一个「跳过剩余教程」。
- 「开始探索」还是开这一段（A 批的规矩不变），点了才出发，不会自动开局。
- 教程全通或跳过之后，木牌换回「上回出征」。

## 二、跳过确认页

- 点「跳过剩余教程」先弹确认页：
  - 一张羊皮纸说明三件事：没打的几段算通了、固定奖励补进仓库、玩家留在基地；局里随机掉的东西不补。
  - 下面一张「教程奖励」小纸，写要补的金币和道具图，用的是结算屏同一张，只列还没领的。
- 两个键：
  - 【跳过】走 `GameFlow.skip_remaining_tutorials`，和开场一问的【不需要】是同一个服务：记下问过、补奖励、存盘，留在基地。
  - 【接着学】什么也不动。
- 开场一问的说明改成：「每段打完回基地整理。老手可以跳过：每段的固定奖励（金币和道具）照样补进仓库。」

## 三、测试

新增 `tests/ui/test_unified_tutorial_d.gd`，23 项断言，正式版和切片各走一遍：

- 木牌写着「教程 1/3」；
- 点跳过先弹确认页，确认页列出奖励；
- 取消什么也不动；
- 确认后三段都通、补 450、留在基地，再进基地木牌换回「上回出征」；
- 第一段通了再看：木牌写「教程 2/3」，跳过补 350。
