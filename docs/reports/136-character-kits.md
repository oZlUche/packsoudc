- 早期角色文档指的是：082 第一节作者定的三人表（擅长逃跑的奴隶安德烈乌斯 / 擅长生存的奴隶布鲁图斯 / 擅长战斗的军团士兵马库斯）、

## 一、现状：三个人实际差在哪（`data/authoring/characters/*.json`）

| | 安德烈乌斯 | 布鲁图斯 | 马库斯 |
|---|---|---|---|
| 定位（082） | 擅长逃跑的奴隶 | 擅长生存的奴隶 | 擅长战斗的军团士兵 |
| 生命（基线 + 被动） | 50 | 60 **+ 20 = 80** | 55 |
| 耐力 | 50（默认） | 50 **+ 15 = 65** | 65 |
| 体力上限 | 5 | 5 + 1 = 6 | 5 |
| 初始包 | 两个皮革包（12 格） | 两个皮革包（12 格） | 皮革包 + 小背包（**10 格**） |
| 负重上限（129） | 28 | 40 | 34 |
| 被动 | 逃跑 +25%、头一回输给节点敌人不扣体力 | 上面三项加成 | 无 |
| 主动 | 躲避：接下来三步猎手够不着，两次，冷却四步 | 无 | 突击：下次战斗先扣对方三成生命，三次，冷却三步 |

查出来的问题：

1. **安德烈乌斯的整套能力都挂在猎手上**（躲避、逃跑 +25%），而猎手只在「进阶 1」难度开（`data/authoring/difficulties/normal.json` 的机制清单是空的）。
   普通难度下他实际只剩「免一败」—— 和科技「不屈」一模一样。生命最低、负重最低，没有任何正向的东西能感觉到。
2. **布鲁图斯双重计算**：基线已经是三人最高的 60，被动再 +20 → 80，比安德烈乌斯高六成；耐力 +15 之后 65，**正好追平马库斯**，
   马库斯「耐力更高」这唯一的数值特色被抹掉了。
3. **布鲁图斯的三条被动就是三个科技**（筋骨 = `stat_bonus`、耐久 = `vitality_max_bonus`、不屈 = `free_losses` 对应安德烈乌斯）。
   科技买几级之后三个人趋同 —— 「科技买得到的，不该是角色的特色」。
4. **马库斯**只有突击一件事，初始格子反而最少（10 格），086 也记过：主动技能从没教过，玩家不知道右栏那个按钮是什么。
5. 身份这一层（奴隶 / 军团士兵）现在**只是一句介绍**，不影响开局、报酬或文字；worldview 第三节写的「身份 = 立场与开局」没有落下来。

## 二、设计原则

- **每人四样东西**：一句话定位 + 身份被动（来自「奴隶 / 士兵」）+ 擅长被动（来自「逃跑 / 生存 / 战斗」）+ 一个主动；外加一条**明确的短板**。
- **角色给的是科技买不到的东西。** 数值类（生命、耐力、体力上限）只保留在基线里拉开差距，不再做成被动；被动改成机制类。
- **普通难度就要能感觉到。** 每人至少两样能力在没有猎手、没有侵蚀时也起作用。
- **全走现有管线**：`CharacterDef.skills` → `RunSkill`（被动 `passive: Array[Effect]` + 主动子类），效果构件进 `RunRegistry.RUN_EFFECTS` / `RUN_SKILLS`，编辑器自然能编；一条新规则只在一处读 `RunContext`。

### 安德烈乌斯 —— 擅长逃跑：少打、少挨、走得远

| 槽 | 名字 | 效果 | 实现 |
|---|---|---|---|
| 基线 | | 生命 50、耐力 50、体力 5、两个皮革包、负重 28 | 不动 |
| 身份被动 | **熟门熟路**（奴隶探索者月月进来） | 地图上每走四步，下一步不花行动点 | 新 `RunEffect` `travel_discount`（`every: int = 4`）→ `RunContext.free_step_every`；`MapTravel` 记步数计数器（进存档），`cost_of` 到第 N 步返回 0 |

## 四、身份这一层要不要再往下做

worldview 第三节还写了身份影响「进出的口、报酬的形式、事件的文字」。这一步**只做报酬的形式**（军功 = 钱更多），进出口与事件分支留到有第二套地图 / 事件变量再说。
为将来留一个字段：`CharacterDef.identity: StringName`（`slave` / `legion`），事件条件已有 `has_flag`，开局时把 `identity:<id>` 写进一局的旗标，事件作者就能按身份分支 —— 本方案只加字段与旗标，不写任何用到它的事件。

## 七、测试

- 熟门熟路：走四步第五步行动点不扣；读档后计数接着数。
- 脱身：有待打的节点战时可用 → 点用过、无战利品、体力不变、次数减一；核心点不可用；猎手处用 → 逃跑成功；搜索遭遇用 → 会话收掉、不弹「被赶跑」。
- 野地里长大：休息回 `rest_restore + 1`；侵蚀扣体力 2 → 扣 1，扣 1 → 扣 0。
- 咬牙：体力 4/6 用 → 5/6；满了不能用；冷却六步内再用被拒。
- 军功：同一场打赢的钱 = 原来 ×1.25 取整。
- 操练：编译出的玩家 `regen_stamina` 比默认高 1。
- 坚韧：战斗里生命掉到三成以下时护盾出现一次。
- 三份 JSON 导入导出逐字节不变；布鲁图斯被动里不再有 `stat_bonus` / `vitality_max_bonus`。
