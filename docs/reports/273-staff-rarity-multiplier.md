# 273 法杖按稀有度加成威力（晶石是消耗品）

作者 2026-11-04 14:56：「不同稀有度的法杖应该按系数增幅威力，而且考虑到魔晶石的消耗性，威力应该更高」。

## 〇 一句话

法杖加一个按稀有度来的威力系数，整下（杖基础 + 晶石）相乘：1 / 1.2 / 1.4 / 1.6；晶石本身的加值再抬一档（+6 / 9 / 13 → +7 / 10 / 14）。改完用 242 的台架扫一遍法师原型确认胜率。

## 一、现状（读码）

| 项 | 现状 | 出处 |
|---|---|---|
| 四根杖 | 魔法杖 白 基础 6 / 1.2 s / 2 槽；法师杖 绿 8 / 1.1 s / 2 槽；魔导杖 蓝 10 / 1.0 s / 3 槽；大魔导杖 紫 12 / 0.9 s / 3 槽。装着晶石时出手不耗耐力 | `data/authoring/items/*_staff.json` |
| 晶石 | 下品 绿 +6（150 币）/ 中品 蓝 +9（320）/ 上品 紫 +13（650），三元素同价；每颗供给 27 场，用完碎 | `fire_crystal*.json` `feed_mods.amount` / `wear.max_charges` |
| 一下伤害 | = 杖基础 + 轮到那颗的加值（**加法**），属性换成晶石元素，打中叠元素状态 | `effects/fire_loaded.gd`，编译器 `CompiledItem.loaded` |
| 稀有度 | 只影响掉落 / 商店 / 价格，战斗里没有任何系数 | — |
| 近战参照（每秒伤害） | 白：长剑 16 / 1.6 s = 10、弯刀 7.5；绿：放血刀 13.6、钟摆刃 11.5；蓝：秘银附魔长剑 32 / 1.4 s = 22.9 | 道具表 |
| 法杖现在（每秒） | 白杖 + 下品 (6+6)/1.2 = 10；绿杖 + 中品 (8+9)/1.1 = 15.5；蓝杖 + 上品 (10+13)/1.0 = 23；紫杖 + 上品 25/0.9 = 27.8 | 算得 |
| 晶石折成每场 | 下品 150 / 27 ≈ 5.6 币、中品 11.9、上品 24 一颗一场；2 ～ 3 颗一场 12 ～ 72 币 | 算得 |

结论：法杖现在的每秒伤害和同稀有度近战持平，优势只有「不耗耐力 + 元素状态」；而晶石要花钱、会碎、还占地（1×2），高一级的杖只多 +2 基础 / 快 0.1 s，稀有度几乎不值钱。作者的两点都成立。

## 二、方案

### 2.1 威力系数（A，推荐）

每根杖加 `combat.power_mult`（数据字段，不写默认按 1）：**白 1.0 / 绿 1.2 / 蓝 1.4 / 紫 1.6**。一下伤害 = (杖基础 + 这颗晶石加值) × 系数，向下取整；没装晶石的木棍一下 = 基础 × 系数。元素状态层数不乘（叠层是晶石的事）。

### 2.2 晶石加值（消耗品溢价）

晶石 +6 / +9 / +13 → **+7 / +10 / +14**（约 +15%，再往上就压过近战太多；溢价主要靠系数）。供给 27 场、价格不动。

### 2.3 结果（每秒伤害，不耗耐力）

| 搭配 | 一下 | 每秒 | 同稀有度近战 |
|---|---|---|---|
| 白杖 + 下品 | 13 | 10.8 | 10（长剑） |
| 白杖 + 中品 | 16 | 13.3 | — |
| 绿杖 + 下品 | 15 × 1.2 = 18 | 16.4 | 13.6（放血刀） |
| 绿杖 + 中品 | 18 × 1.2 = 21 | 19.1 | — |
| 蓝杖 + 中品 | 20 × 1.4 = 28 | 28 | 22.9（秘银剑） |
| 蓝杖 + 上品 | 24 × 1.4 = 33 | 33 | — |
| 紫杖 + 上品 | 26 × 1.6 = 41 | 45.6 | （无紫近战） |

白杖只比长剑强一点（不耗耐力 + 灼伤就是它的溢价）；每升一级杖约 +25 ～ 30% 每秒伤害，晶石升一品约 +15 ～ 20%，两条线都值得追。

### 2.4 敌方法师

247 的三阶法师用同样的杖和晶石，系数对他们同样生效（魔导师蓝杖 ×1.4、大魔导师紫杖 ×1.6）；用台架重扫后若太凶，调他们的套路（降一品晶石）而不是给敌人另一套规则。

## 三、改动清单（执行）

1. `combat.power_mult` 字段：四根杖 json 写 1.0 / 1.2 / 1.4 / 1.6；编译器把轮读表每颗的 `damage`（基础 + 加值）和木棍基础都乘上去（`StatMath` 定点，向下取整）；`PowerBench` 估力同样乘。
2. 晶石九颗（三元素 × 三品）`feed_mods.amount` → 7 / 10 / 14；描述里的 `{amount}` 自动跟上。
3. 杖的描述加一句「威力 ×{power_mult}」（白杖 ×1 不写）；悬浮窗的伤害行显示乘后的数。
4. 台架：`tools/bench_matrix.gd` 扫法师原型（242）改前 / 改后各一遍，表放 `docs/reports/balance/2026-11-04-staff.md`；目标：法师原型同档胜率和近战原型差 ±10 个点以内。
5. 测试：编译法杖 + 晶石后 `loaded[i].damage` = floor((基础 + 加值) × 系数)；木棍一下 = floor(基础 × 系数)；无字段 = ×1。
6. 百科 / 图鉴若列杖的伤害，显示乘后的区间。

## 四、待定（没回音按推荐）

1. 系数乘整下还是只乘晶石加值 —— **推荐乘整下**（作者原话是「增幅威力」；只乘加值时木棍状态没差别）。
2. 系数数值 1 / 1.2 / 1.4 / 1.6 —— **推荐这组**，台架扫完若法师明显压过近战再回调到 1 / 1.15 / 1.3 / 1.45。
3. 晶石加值 +7 / 10 / 14 —— **推荐**；不想动晶石就只做系数。
4. 敌方法师同规则 —— **推荐同规则**，靠套路调强弱。
