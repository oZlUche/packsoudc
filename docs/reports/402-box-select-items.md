# 402 · 框选多件道具

## 目标

作者 11-27：「加入一个新设计，按住左键可以拖拉选择框，选中多件道具」。作者直接提的，按推荐默认值直接做进游戏；
需要作者拍板的细节列在最后，作者只回不同意的。

## 做法（已经这样做了）

| # | 细节 | 现在的做法 |
|---|---|---|
| 1 | 从哪儿起拖算框选 | **从空格**（没有道具、也不是包的空处）按下左键、拖开 6 像素以上 = 拉框。从道具上按下照旧是单件拖动；从包的空处按下照旧是拿起整个包，**按住 Shift**（新动作 `box_select`，可改键）从包的空处起拖也是拉框 |
| 2 | 框到哪些 | 框里压到一格就算（形状有意义：长条只压到一头也算进来）。包不框（包带着内容物，走原来那套）；扎根的、随身之物不框（本来就拿不起来 / 离不开棋盘） |
| 3 | 选中长什么样 | 每件沿占格外缘描一圈金边（`e8c46a`）；拉框时画半透明金色框。只有画面，没有字 |
| 4 | 取消选中 | 点一下空格；按在没选中的道具上（那就是单件拖动）；翻仓库页 |
| 5 | 整组拖动 | 按在选中的任一件上拖 = 整组一起走，**相对位置不变**（摆好的阵型原样搬走）。落点预览把几件的占格拼在一起：全都放得进空位才绿，否则红 |
| 6 | 整组落到格子 | 只放进空位，**不顶替**、不合成、不附魔（这些只对单件）；任一件放不下或这一屏不许放，整组弹回原位 |
| 7 | 整组放到棋盘外 | 这一屏「棋盘外 = 地上」时整组落地，每件从自己残影的位置掉下去；不许落地的一屏整组弹回 |
| 8 | 整组旋转 | 先不转（R / 滚轮在整组拖动时不起作用） |
| 9 | 放下之后 | 选中跟着道具走（放进哪块棋盘就在哪块接着选中，可以接着挪）；弹回 / 取消还是原来那几件选中；落了地就不再选中 |
| 10 | 跨棋盘 | 一次只在一块棋盘里框；整组可以拖到另一块棋盘（仓库 ⇄ 带回来的背包、背包 ⇄ 战利品箱等，照各屏原来的落点规则逐件判） |
| 11 | 快速出售（仓库勾选模式） | 框 = 把框到的、还没勾的都勾上（已勾的不取消） |
| 12 | 哪些棋盘能框 | 登记到拖拽层的棋盘（能拖东西的那些）。战前的敌人棋盘、只看不拿的棋盘不框 |
| 13 | 地上 | 地上的道具不框（地上不是棋盘） |

和并行的改动不冲突：地图拖动改左键只在地图屏（不是棋盘）；悬浮窗的改动不碰按键。

## 产出

- `ui/inventory/inventory_view.gd`：框选（`box_select` / `selection` / `items_in_box` / `select_box` / `group_for` / 金边与框的画法），空格按下起框、松手结算。
- `ui/inventory/drag_layer.gd`：整组拖动（`_grab_group` / `_preview_group` / `_drop_group` / `_restore_group` / 整组残影）；登记视图时打开框选。
- `tests/inventory/test_box_select_402.gd`：框选、整组拖到另一块棋盘、放不下整组弹回、不顶替、取消、整组落地、落点规则拦一件 = 整组不放、包不框、勾选模式框 = 全勾。

## 作者答复（11-27 13:51，确认台转来）

| # | 问题 | 作者 | 结果 |
|---|---|---|---|
| 1 | 包的空处起拖 | 平时不能框，按住某个键时可以，键看现有热键占用 | 已做：**Shift**。棋盘上 Ctrl = 整包、Alt = 藏说明、R = 转向，Shift 只在地图屏用，棋盘上空着。登记成可改键的动作 `box_select`；按键一览加了半句 |
| 2 | 整组旋转 | A 先不做 | 不变 |
| 3 | 整组顶替 | A 不允许 | 不变（弹回） |
| 4 | 批量按钮 | A 先不做 | 不变 |
| 5 | 地上框选 | A 先不做 | 不变 |

## 原先列给作者的问题


1. 从**包的空处**起拖：现在照旧是拿起整个包（Ctrl 点包也是拿整个包）。要不要改成从包的空处也能框？（推荐：不改，背包里棋盘外缘一般有空格可以起框）
2. 整组旋转：现在不转。要不要按 R 整组绕按住的那件转 90°？（推荐：先不做，先少再多）
3. 整组压到别的道具上：现在整组弹回、不顶替。要不要允许整组顶替（被顶的全部挤到地上）？（推荐：不允许，一次挤走好几件容易误操作）
4. 选中之后的批量按钮（整组出售 / 整组放进仓库 / 整组丢地上）：现在只有拖。要不要在选中时给一排按钮？（推荐：先不做）
5. 地上的道具要不要也能框？（推荐：先不做）
