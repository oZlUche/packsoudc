# 095 · 赐福：信仰道具的三种生效方式、普通道具变信仰道具、只有信物激活

作者的想法变了：信仰道具的强化可以随等级变，也可以激活即生效，或者跟信力值挂钩；并且**道具有概率变为信仰道具**——给符合某信仰的道具一个带信仰标记的版本，从战利品 / 搜索替代、包内转化、特定事件来。五条建议作者都点了头。

## 一、功能三种生效方式（`FaithBonus.mode`）

| mode | 意思 | 字段 |
|---|---|---|
| `tier`（默认，现状） | 过了第 `tier` 阶 | `tier` |
| `active` | 激活即生效 | — |
| `scaled` | 按信力：每 `per_points` 一份、最多 `max_stacks` 份（0 不限） | `per_points` `max_stacks` |

编译器多吃一份「信仰 → 点数」（`BattleCompiler.compile(..., faith_tiers, faith_points)`，`FaithPower.points_by_tag`），修饰按份数 `apply_to(stats, times)`，规则一份。同一件道具上三种可以混。导入器校验 mode 与数；浮窗写「激活即 / 第 n 阶 / 每 50 信力一份」。

## 二、赐福版：按模板派生，不手写

- `FaithDef.blessings: Array[Blessing]`：哪些道具符合（标签任一 / 最少格子 / 体积档 / 或点名 `items`）、名字前缀（中 / 英）、多出的标签、稀有度 +`rarity_up`（1）、价值 ×`value_mult`（1.5，只对写了 value 的）、赐福版的 `faith_bonuses`。
- `Blessings.derive_all`：`ItemDatabase.load_dir()` 加载完按每位神的模板给每件能赐福的道具**派生真实定义**：id `<原 id>_<神>`（`shortsword_brute`），标签加 `faith` / `faith:<神>` / `blessed`，`blessed_of` 记原件。它是普通道具：图鉴（独立条目）、存档、出售、编辑器都不用改。**不进生成池**（`ItemDatabase.ids()` 排掉 `blessed`）：搜索 / 掉落 / 商店 / 敌人的随机抽不会直接抽到，只从下面三条路来。
- 能赐福的：不是包、本来不是信仰道具、不是封存 / 特殊、没赐福过。护符、符号、胫骨大棒这类手写的信仰道具照旧。
- 第一版模板：蛮神 → 武器（激活即伤害 +10%；每 50 信力伤害 +1，最多 6）；日神 → 金属（激活即急速 +5%；2 级耐力消耗 −10%）；自然 → 防具 / 自然（激活即生命 +3；每 50 信力护甲 +1，最多 5）；大地 → 中体积及以上（激活即耐力上限 +5；每 50 信力护甲 +1，最多 5）。数都是占位。

## 三、三条来路（都是数据，同时开）

1. **战利品 / 搜索替代**：掉落定了、搜索翻出来之后，每件能赐福的按概率换成赐福版 —— 激活了信仰只换那位神的（`bless_chance_active` 0.2），没激活随机一位有赐福版的神（`bless_chance` 0.05）。数在 `DropRule` 与 `SearchRules` 上；`NodeEvents._bless_rolled`、`SearchSession.substitute`，两处都走 `RunState.bless_ids → Blessings.substitute`。
2. **包内转化**：激活信仰时每走一步，棋盘上每件能被那位神赐福的道具独立掷一次（`FaithDef.convert_chance` 0.03 + 每级 `convert_per_tier` 0.01），中了原地换成赐福版（uid / 位置 / 朝向不动，形状一样），发 `item_blessed`、日志一句。随机数按种子 + 步数 + uid 派生，可复现。
3. **神坛与事件**：各神 1 级起神坛多一个特殊操作「祈求赐福」（`altar_bless`，花 40 信力，赐福棋盘里能被赐福的最值钱的一件，其次暂存区）—— 献祭攒的信力有了第二个花处；事件后果 `bless_item`（空 = 激活的信仰）给事件用。

## 四、只有信物能激活信仰

`FaithState.active_tag` 只看带 `faith_anchor` 的道具（护符四枚、力量的符号、赐福的长弓 / 盾牌加了这个标签）。赐福的武器防具只跟着当前信仰生效或休眠（休眠留通用效果），从战利品捡一把别的神的赐福短剑不会把信仰跳过去。胫骨大棒是武器，也不抢激活。

## 五、献祭

自己神的赐福版献回来算双倍（`FaithDef.offering_value` ×2）；献给别的神照普通算。

## 六、图鉴（作者追加）

派生的赐福版**并进原件那一格**：`ItemDatabase.variants_of(id)`（原件 + 各神的赐福版）；`CodexTile.variants / variant_lit / variant_counts`，有异体的格子画成**一叠**（后面错位垫两层、按那位神赐福版的稀有度描边，点亮的才有色）+ 左上角角标「点亮几个 / 共几个」，任一异体带出过格子就亮；**点开**（`pressed`）弹出异体列表：「原件 / 蛮神版 / 日神版…」各一小格（`MetaScreen.show_variants / close_variants / variant_tiles`），停上去看属性，再点「关闭」。图鉴抬头的「点亮 x / y」含赐福版。
