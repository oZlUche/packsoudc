# 383 万神院第一批：信仰开关、第 3 次撤离后到来、在万神院选神

> 报告 377（作者 2026-11-21、11-22 定稿，拉丁文名 Senatus Panthei）第一批的落地记录。
> 第二批（删序章三、解锁链改接序章二、带截图的信仰帮助页、第一次升级的讲解）另起一份报告。
> 数值都是报告 377 的建议初值，作者可以改。

## 做了什么

1. **信仰开关**：一局有没有信仰，看万神院到没到营地（试玩切片永远没有；教程章照旧有）。没有信仰的局：
   - 地图上不铺「无名的祭坛」（faith_call 那一组事件）；
   - 休息点没有神坛：不能献祭（本来就要奉神），也没有「在神坛前祷告」；
   - 战利品、搜索翻到的东西不换成赐福版；敌人掉落里拿掉信物和赐福道具（敌人照样带着用）；
   - 随机来源（宝物、额外奖励这些）把所有归神的道具锁上。
   - 这三个值（有没有信仰、有没有赐福、经验加成）开局定下，跟着局内存档走；老档没有这一格 = 照旧有信仰、有赐福。
2. **万神院什么时候来**：新档在教程之后，**第 3 次成功撤离**结算时来（失败的不算，没走出起点的不算）。阵营数据里新增一种到来方式「第 N 次成功撤离后」，N 写在数据里（`arrive_after: 3`）。委托簿多记一个「正式探索成功撤离了几局」。
3. **出征时选神**（作者 2026-11-22 22:53 改：不在营地里选）：万神院到了营地以后，点【开始探索】先跳出选神界面，选完再进开局屏；到来之前没有这一步。第一项是【无信者】（不奉神，只是一个选项，不做神龛），再按档位列六位神；没解锁的神写「？？？？」、不露神像、点不了（键上写「信赖 N」）。选神不要代价。
   - 营地后勤里的「万神院」页只看：徽、名字、信赖菱点，一排已解锁的神和「？？？？」（这一页留不留是架构设计的初值，等作者看样张时定）。
   - 【以人为本】按作者同一条改名【无信者】（界面字、帮助页、日志都改了；「以人为本」留给以后解锁）。
4. **出征**：按选神界面选的神，把这位神的信物放进背包（照旧占格、照旧是赐福道具的锚点），并定下这一局奉祂。局结束（撤离、战败、保险箱）信物都不带回仓库。
5. **五档信赖**（服务写在阵营数据的 `services` 里，服务 id → 第几档）：
   | 档 | 给什么 |
   |---|---|
   | 一（到来即有） | 蛮神、日神、技巧之神可选；神坛、无名的祭坛开放 |
   | 二（10） | 狩猎之神、大地之神、自然之神也可选 |
   | 三（25） | 奉神的局所有来源的经验值 +10%（以人为本的局不加） |
   | 四（50） | 神坛上出现「赐福」这一项（每座神坛一次，沿用 372 的献祭 / 特殊操作二选一） |
   | 五（100，要结案） | 开局选一次质变牌 —— 等报告 372 第二批的质变牌，这一批没做 |
6. **万神院的委托**（初值，候选文字待作者过目）：
   - 剧情三份共 25 点：《初次奉神》（选一位神出征，奉着祂升三级并撤离，+10）→《供奉》（在两座神坛献祭，+5）→《入院登记》（奉着神再升八级并撤离，+10，是许可单）。
   - 告示栏常规三种：献祭（在 N 座神坛献祭）、修行（奉着神升 N 级，要撤离）、护道（打赢 N 场普通的仗）。
   - 新加两种目标：「神坛献祭」（现场算，每座神坛记一次）、「奉神升级」（每升一级记一次，撤离才算；以人为本升级不记）。
7. **到来通知**（作者选 B「牌子亮起」，以后别的阵营、功能解锁共用这一种）：万神院来了以后第一次回营地，阵营的牌子（徽 + 名字）淡入亮起，下面一句说明和【知道了】，每份存档每一方只放一次。做成了通用的 `show_arrival(阵营 id)`，现在只有万神院写了说明的字。正式图等 UI设计。
8. **老存档**：读档时做一次迁移（新档建档时就标过，不做）。通过过序章三、仓库或带回的背包里有信物、或者对局记录里奉过神的存档，直接算万神院已到来（信赖一档起）；对局记录里奉过的神、图鉴里点亮过信物的神，全部不论档位都能选；仓库和带回的背包里的信物按价值折成金币。什么都没有的老档不来，照新档的规矩等第 3 次撤离。
9. 占位美术：阵营徽 `commission/emblem_pantheon`（柱廊圆章）、纸条钉子 `pin_pantheon`（借协会的）；神龛借各神的徽。作者 22:53 定了徽章 A 神殿、紫色珠钉、页面风格 B 大理石、到来通知 B，正式图由 UI设计 出，这里先占位。

## 关键决策

- **教程章照旧有信仰**：序章三还在（第二批才删），它要教信物、神坛和赐福，所以教程章不受开关影响。第二批删掉序章三之后，教程里就没有信仰内容了。
- **测试直接建的局外照旧有信仰**：测试和工具直接 `MetaState.new()`、没走过读档迁移的局外，当成老规矩（有信仰、开局屏的神照旧用）；真玩家的老档读档时一定会走迁移，按第 8 条处理。
- **三档的 +10% 乘在经验系数上**（`LevelModule.mult()`，和局内成长线程商定），所有来源都经过它；神坛献祭的封顶照旧按没乘系数的数算。
- **赐福按档开关**：四档以下神坛特殊操作里滤掉赐福那一项（列表和执行两处都拦）。
- **掉落过滤放在打赢结算那一步**：敌人身上的东西照样参与掷骰、照样在战斗里起作用，只是掉下来之前拿掉归神的那几件。
- **局结束信物不带回仓库**：所有信物都这样（不只万神院发的那枚），因为信物以后不再是仓库道具。
