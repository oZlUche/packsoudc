## 二、第 1 条：出征页

作者：「给基地添加一个包含了军功碑的界面和对应选项卡，将【再来一局】的按钮放到这里，按钮文本改为【开始探索】。具体还能添加什么功能，选项卡上面写什么名字由你头脑风暴，可以参考同类或相似游戏。最后发给我排版」。

### 2.1 页签叫什么

同类游戏里这一页的名字：Darkest Dungeon 的 Embark（出发）、Slay the Spire / Hades 没有基地页签直接「开始」、Backpack Hero 的村子里是一扇门、Moonlighter 是出门、Rogue Legacy 是城堡门口。中文古风里能用的词：

| 项 | 名 | 读起来 | 评价 |
|---|---|---|---|
| **A（推荐）** | **出征** | 军团开拔 | 和「军功碑」「军功牌」一个语境，两个字，图标好画（旗 / 鹰旗 `aquila`） |
| B | 点将 | 点兵点将 | 偏「选角色」，但选角色在开局屏里，不在这页 |
| C | 营帐 | 将军的帐篷 | 像个地点，和「仓库」「后勤」「书架」并列顺，但不说明「从这里出发」 |
| D | 军务 | 公事 | 太文，和碑不搭 |

页签顺序：**出征 / 仓库 / 后勤 / 书架**（出征第一、默认选中）。英文 `Expedition`（页签）、按钮 `Set out`（和开局屏第三页「出发」同词，见 2.4）。

### 2.2 页里放什么（头脑风暴 → 取舍）

参考：Darkest Dungeon 出发前看「队伍 + 补给 + 任务」；Slay the Spire 开局看「角色 + 上局记录 + 今日种子」；Hades 出门前看「镜子加成 + 契约」；Backpack Hero 看「背包 + 村子等级」。本游戏对应的东西，哪些已经有、哪些值得放到这页：

| 东西 | 来源 | 放不放 | 为什么 |
|---|---|---|---|
| 军功碑 | 260 | **放**，页左半 | 作者定的 |
| 【开始探索】主档木牌 | 替换「再来一局」 | **放**，页右下 | 作者定的 |
| 上次配置：角色、地图、规模、难度 | `MetaState.flag(last_map / last_scale / last_difficulty)` 已有；角色要新存一项 `last_character` | **放**，「上回出征」木牌，三行小字 | 让玩家一眼知道按下去默认是哪一套；开局屏本来就按这些预选 |
| 随身与加成：科技发的随身技能（`belt_grants`）、首次赠包、局外 buff | `MetaState.belt_grants`、`MetaRules.first_kit`、`RunBuffs` | **放**，「军需」木牌，图标 + 数量一行 | 玩家出发前最想确认的是「我带什么」；现在只有在开局屏第二页才看得到 |
| 本局目标 / 悬赏（每日契约、今日种子） | 没有这个系统 | 不放（记到待做） | 新系统，另开报告 |
| 上一局概括 | 作者 10-27 定「不再显示」 | 不放 | 对局记录在书架里 |
| 「沿用上回配置直接出发」小键 | 新 | **待定 2** | 省三页点击；但首次赠包 / 带回来的棋盘那些逻辑在开局屏里，直接出发要绕过去 |
| 角色肖像大图 | 256 肖像低优先 | 不放 | 没图 |

## 六、第 4 条：仓库页左边

作者：「我认为当前【仓库】页面里，排在左边的除了包架以为也可以加入其他元素，头脑风暴一下，参考其他游戏布局」。

参考：生化危机的道具箱（只有格子）、暗黑的储物箱（分页签 + 搜索）、逃离塔科夫的仓库（筛选 + 搜索 + 按价值排序）、Backpack Hero 的储物间（格子 + 一键整理）、Moonlighter 的箱子（格子 + 价钱）。可放的东西：

| 东西 | 值不值 | 说明 |
|---|---|---|
| 筛选牌：标签下拉 + 稀有度下拉（出售页那两颗复用）+「清除」 | **值** | 七页仓库找东西靠翻；筛选 = 右边不匹配的格压灰（不挪位），翻页签上显示匹配件数 |
| 账牌：件数 / 总价值 / 空格 | **值** | 总价值现在只在碑额；件数在仓库挂牌悬浮窗里，露出来更直接 |
| 「新到」托盘：上一局带回来、已置入的那几件 | 可以 | 置入后就混进仓库，玩家忘了哪些是新的；需要存一份「上局进仓的 uid」 |
| 一键出售白装 | 不放 | 出售在后勤页，别两处卖 |
| 包预览台：点包架上的包看形状与词条 | 不放 | 悬浮窗已有 |
| 称重 / 容量条 | 不放 | 局外没负重 |

排版（线框 2）：

- **A（推荐）工具列**：包架（原样，上）→ 筛选牌 200 × 150（标签、稀有度两颗下拉 + 清除小键）→ 账牌 200 × 120（三行读数，金币图标）；带回来的棋盘仍在右边，没有时这一列就是整页内容，粗布缩成一根 260 宽的窄布（不再大片空白）。
- **B 新到托盘**：包架 → 账牌 → 「新到」托盘 200 × 300（上局置入的件，缩略图列，点一下右边仓库翻到那页并亮格）。筛选不做。
- 代码（A）：`WarehousePanel` 左列加 `FilterPlate`（`_sell_pick` / `_sell_tag_pick` 的做法搬过来）与 `LedgerPlate`；`WarehousePages` 加 `set_filter(tag, rarity_max)` → 不匹配格 `modulate` 压灰、页签计数改匹配数；账牌读 `warehouse.size()`、`warehouse_value()`、空格 = 页数 × 格数 − 占用。
- 测试：筛选后匹配 / 不匹配格的 modulate；账牌三数；清除还原。
