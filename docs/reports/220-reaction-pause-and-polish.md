## 二、反应第一次触发：回放暂停、解释一句

### 2.1 规则

- **每种反应、每个存档只解释一次**。判断用 `MetaState.reactions_seen`（175 已有，现在只在打完一场记）；回放里碰到一个没见过的反应就停。
- **停在反应那一刻**：`BattleView._on_reaction(e)` 弹字之后，若这个反应 id 没见过，`hold()`（166 补充二的那套，倍速下也停），盖一层 `CoachOverlay` 一步，目标 = 挨反应那一边的 buff 行（新增教练目标 `buffs_enemy`，和 `buffs_mine` 对称），点任意处 `release()` 接着放。
- **文字由反应定义生成**，不手写十份：「{名字}：{元素甲}碰上{元素乙}。{description}　百科里点亮了这一页。」—— 名字走 `Names.of`，元素名走 `DamageTypes.name_of`，正文就是 `ReactionDef.description`（175 补充四的表里已经是玩家能读的句子）。
- **当场记进 `reactions_seen`**（不等打完），所以同一场里第二次同样的反应不再停；`note_reactions` 打完那次照旧，多记一次没副作用。
- 跳过（直接看结尾）不停、不解释，但打完照旧记为见过 —— 玩家自己选了跳过。
- 不限序章：自由模式里第一次打出淬裂、过载也一样停一下。十种反应一共最多停十次。

### 2.2 序章一能打出哪一种

反应表（175 补充四）里带「血」的只有燃血（火 + 血）、冻疮（冰 + 血）、激荡（雷 + 血）、菌血（毒 + 血）。序章一的道具里**没有火、冰、雷**（火只在日神护符、火晶、火焰腺、蒸汽阀上），所以第一场打不出燃血；序章一能自然打出的只有**菌血**：弯刀（流血）+ 涂毒匕首（中毒）同时在包里，对手身上两种印一碰就是菌血。

- 第一场（拾荒者，只有短剑）什么都打不出；第三个点翻出弯刀和毒药瓶、合成涂毒匕首之后，**遭遇战（蛮兵）或精英（守卫）那一场**能打出菌血，这就是序章一的「第一次反应」。
- 为了让它大概率发生，`tut_search_2_again_1`（翻出弯刀和毒药瓶那条）末尾加一句：「{item:scimitar}也带上：放血和毒碰在一起会起反应，到时候看。」—— 只提示不强制，精英门禁仍只认涂毒匕首。
- 执行用战斗模拟验一次：涂毒匕首 + 弯刀对守卫，在战斗时限内菌血至少触发一次（毒每刀一层、流血按弯刀的节奏，两边都在前几秒就能上）。

**如果作者要的就是燃血**：得给序章一加一件火源（一支火把或一瓶火油之类的新投掷物），并在第三个点翻出来；那是新道具 + 第一张图的改动，另开一节，这次不做。

## 四、落地（执行，2026-10-21，v3.65）

按 §一 / §二 落了，待定三条都按推荐（菌血、不限章节每种一次、D 不做提示行）。和方案不一样的地方：

1. **「当场记」不用另做**：`GameFlow` 在战斗算完那一刻（回放之前）就 `note_reactions` 了，所以 `reactions_seen` 本来就先于回放记下。新的做法是开战时把「这一场头一回打出的反应」装进回放屏的载荷（`new_reactions`），回放屏照它停 —— 跳过、读档回来都不停，但已经记为见过，和 §2.1 的结果一样。
2. **暂停的接法**：`BattleView` 只发信号 `reaction_shown(id, side)`（弹字那一刻，跳转 / 跳过不发），停不停、纸条写什么由战斗屏管（`BattleScreen._on_reaction_shown`）。回放浏览器、沙盒用的也是 `BattleView`，它们不停。`BattleView._drain_until` 在被停住后不再往下走，同一刻排在后面的事件等放开再放（一刻两次同样的反应也只停一次）。纸条指 `buffs_mine` / `buffs_enemy`，看挨反应的是哪一方。
3. **解释文字**：`Encyclopedia.reaction_intro(def)` —— 「菌血：毒碰上血。{说明}　百科里点亮了这一页。」元素名走 `ReactionResolver.element_name`（和百科反应页的「火 + 毒」同一份），不走 `DamageTypes.name_of`（「血」在伤害类型里叫流血）。
4. **E 的入口统一成一层**：方案写局内走暂停菜单、局外走 `show_encyclopedia`。实际上词条小窗出现在战斗回放、背包窗、各叠层、开局屏、基地里，暂停菜单只在地图底屏有，`show_encyclopedia` 会把开局屏 / 基地换走。所以改成导演 `GameDirector.open_codex(page)` 在整个屏栈和地上之上盖一层百科（z 200），「返回」/ Esc 关掉回原处，底下哪一屏都不动。`HoverTip` 只挂两个静态钩子（`codex_page` 词条名 → 页、`open_codex`），导演进场挂、离场撤；没挂（单独造的悬浮窗）就不画那一行。页按词条名查（`Encyclopedia.page_for`），查不到的词不画。
5. **链接写「百科 >」**：`›` 不在字库里，没为一个符号重新子集化字体。
6. **§2.2 的弯刀句**加在正文第一段末尾（「…正好用它。{item:scimitar}也带上：…」），「下面还压着东西，再翻一次」仍是最后一句，好接按钮。
7. 测试：`test_battle_coach` 新增反应暂停一组（停、一步、文字、指对手、停着不偷跑、点后接着放、第二次不停、跳过不停、见过的不停、载荷带新反应且局外已记）；`test_prologue` 走完序章一时把弯刀放进包里，精英战确认打出菌血；`test_tutorial_text_112` 查序章三章无规则卡、沙漏三条无数字；`test_map_screen_166` 查序章暂停菜单没有「本图规则」；新套件 `test_codex_link_220`。两份教练的步数断言改成四步。
