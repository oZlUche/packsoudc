# 主菜单组件重绘验收

基线为 `2635ca5c`。行军登记簿以浅色纸页承载深色文字，皮脊和包角在操作区之外。中英文标题分别保留「背包搜打撤」和「PACK & EXTRACT」，用皮革与铜面区分前后半段。红色皮签承载主操作，次级索引分别使用读档、百科和设置图标，页脚单列语言与退出。

## 复核路径

1. 新存档打开主菜单，检视「新的游戏」。使用已有存档重开，检视「继续」及「读取存档」。将鼠标移入主键、按住、移出，再用 Tab 选中主键，比较每种状态。
2. 以中文、英文大字号分别打开菜单，核对标题、选项、页脚及操作热区。查看夜营、军团登记口和地图桌三种背景。
3. 在临时存档环境同时触发两条存档提示。英文大字号下，两段长文本均能在右下纸签中换行，纸签完整落在视口内，与左侧按钮分开。
4. 导出玩家资源包，独立读取双语字标、登记簿封面、皮签、纸边、三个索引图标与提示纸纹。

缩略图复核时，初版浅金焦点线与纸面较接近。已换成外扩的深褐描边并用实际 Tab 输入复拍。

Godot 4.7.1 主菜单套件在小、中、大字号下各通过 85 项断言，字体覆盖通过 42 项。全项目脚本加载完成，玩家资源包中的 9 张组件贴图均可独立加载。部分进程在退出时报告渲染资源仍在使用。本轮覆盖主菜单与提示卡片，未运行全量套件。
