# 主菜单、局外与节点搜索重绘验收

对照基线为 `db5b78ed`。使用 Linux、Godot 4.7.1、OpenGL Compatibility 的 1280×800 玩家视口，同存档拍摄主菜单、基地、出征准备和同一林地的搜索。另在中英文大字号下确认控件和焦点位置。存档页另以 Godot 4.6.3 验证。[局外三屏对照](../../../handoff/art-review/field-guide-fronts-comparison.jpg) · [局内对照](../../../handoff/art-review/field-guide-search-comparison.jpg)

| 操作 | 验收结果 |
|---|---|
| 从无进度与已有进度的主菜单进入 | 两种状态分别突出「新的游戏」和「继续」，继续、读档与语言切换可用。三张地景沿用慢镜头与淡入切换。 |
| 打开基地、选择出征与角色 | 默认与中英文大字号下，Tab 能到达各屏可见操作。角色信息和棋盘预览独立于场景背景。 |
| 打开存档夹 | 中英文大字号各验证 15 项，含切档、创建、两次确认删除与键盘焦点返回。 |
| 更改设置 | 1280×800 中文大字及 920×720 英文大字布局可读。窄屏分组上下排列，退出键保持可见；键盘可以改音量，改字号后焦点留在选中的字号上。 |
| 基地书架打开五条记录，选择第三局并返回 | 用确认键打开详情，返回按钮取得焦点。返回记录列表时焦点回到第三行。实心金星与空心星分别代表已收藏和可收藏。 |
| 种子 780613 从入口 6 到林地 5，收起面板并点击当前节点 | 恢复同一窗口与会话。累计行动 2 步、搜索 1 次、收获 2 件，收起和重开前后一致。 |
| 在搜索面板使用 Tab 与 Shift+Tab | 基线会跳到地图图例。重绘后初始焦点在「全部拾取」，可正反绕行收取、收起、关闭三个可用动作。 |

主菜单、基地、选角整备、科技、记录、设置、搜索板、节点与字体均进行了定向回归。设置相关七组共 502 项断言。对局记录 149 项，成绩计算 40 项，战绩板 139 项，搜索板与棋盘美术 86 项，字体覆盖 42 项。科技页通过 133 项定向断言。中英文最大字号下都实走选角、配装短剑、选图并返回选角，先前的选择得以保留。另做全项目脚本加载和作者数据一致性检查。从玩家版导出的 PCK 独立加载 18 张轮播、界面与部件贴图，全部可读。悬浮窗原有测试使用了已加入配方的纱布，基线复现后用独立的无配方物品验证相同操作。修正后相关 498 项断言通过。本轮未做全量套件和硬件 GPU 性能评测。部分进程退出时引擎报告仍有图形资源在用。
