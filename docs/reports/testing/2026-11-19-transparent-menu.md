# 透明主菜单验收

以 `967492c1` 的登记簿菜单为对照，沿用同一存档和同一夜营画面。新版恢复原画上方的居中字标，并将文字菜单放回左下。三个背景仍依次显示夜营、军团登记口与地图桌。[同档对照](../../../handoff/art-review/menu-interface-comparison.jpg) · [轮播实机](../../../handoff/art-review/game-menu-three-landscapes.jpg)

## 操作与读数

- 在 1280×800 玩家视口检查中英文菜单。新档提供「新的游戏」，已有存档提供「继续」及「读取存档」。主操作字重和字号均高于次级入口。页脚提供语言与退出。
- 将指针移入主选项、按住再移出。使用 Tab 切换到主选项和页脚语言键；选项沿用透明字面，焦点以金色底线与字前标记显示，按下显示铜色文字。切换语言后焦点回到语言键。[主选项四态](../../../handoff/art-review/menu-button-input-states.jpg) · [字号与存档状态](../../../handoff/art-review/menu-large-type-and-new-game.jpg)
- 在英文大字号下构造同时出现版本提示和修复提示的存档。两条消息在右下纸签内完整换行，纸签与左下菜单的矩形互不相交。
- Godot 4.7.1 的主菜单套件在小、中、大字号下各通过 88 项断言，字体覆盖通过 42 项。另用独立进程从玩家资源包读取中英文菜单字标、启动字标和三张背景。验收范围为主菜单及其导出资源。部分进程结束时引擎报告仍有图形资源在用。

三幅画中，地图桌的羊皮纸与标题金属字面色相最接近，右半字形靠原字标的深色外沿分开；夜营的暗蓝天空与标题反差最强。
