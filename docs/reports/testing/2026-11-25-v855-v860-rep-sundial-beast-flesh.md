## 常规委托：声望过 50、过 100（`cm926`）

走法：

1. 新档。
2. 用测试辅助把灰灯互助会的剧情办到能接常规纸条，声望设成 45。
3. 在委托页的「常规」上真点【接下】。
4. 用测试辅助记满进度，再在卡上真点【完成】。交货那种纸条记满就直接结案，不出【完成】。
5. 做到 53 以后，用测试辅助把声望跳到 97，接着照上面的步骤真做，一直做到 101。

| 检查项 | 中文常规 | 英文大字号 |
|---|---|---|
| 每份纸条 | 声望 +1（短单、常规单、长单都是 +1） | 同左 |
| 49 → 50 | 跨过「锅 5×5」「仓库 8×8」，食堂变成 5×5 / 8×8，可领赠礼 1 → 2 | 同左 |
| 50 → 53 | 照涨，没有停在 50 | 同左 |
| 99 → 100 | 跨过「锅 6×6」「仓库 10×8」，食堂变成 6×6 / 10×8，可领赠礼 3 → 4 | 同左 |
| 100 → 101 | 照涨 | 同左 |
| 节点通知 | 7 条，最后两条是 pot_6、store_10 | 同左 |
| 声望页 | 灰灯写 101；【赠礼】亮着，悬浮写「可领 4 份 / 每 25 点多一份 / 下一份还差 24 点」；不溢出 | 同左 |
| 真点【赠礼】→【领取】 | 金币 +30，还可领 3 | 同左 |
| 存档里的声望 | 101 | 101 |

## 观察（低优先级，不算问题）

- **常规纸条每份只给 1 点声望。** 短单、长单都一样。剧情加起来每方 25，从 25 做到 100 要 75 份，手头一次最多拿 3 份，至少要走二十多局。数是 v8.55 以前就定的，这里只是记下来，节奏请作者看。
- **日月盘的悬浮窗会盖住敌人的名字。** 悬浮窗开在盘的右下方，正好压在对手名牌上。截图 `*-sd927_08_dial_hover.png`。
- **日月盘压在顶端栏的表盘下沿。** 盘心按设计压在铜框顶，上半截和顶端栏正中的表盘叠在一起，截图上看着还算清楚。
- **英文大字号的常规页，手头托盘那一行在页面底下被切掉一截。** 页面能往下滚，滚到底就能看全，点得到【Complete】。
- **永昼、永夜那种「∞」的盘面这次没走到。** 要先把【日长夜短】叠到黑夜 0 秒。全量里的 `test_faith_sun` 查了，这一项已通过。
- **器官下食堂的锅这次没真做菜。** 只看了钉住悬浮里「下锅」那一行写着特性。全量里的 `test_canteen_355`、`test_beast_flesh_394` 都通过了。
