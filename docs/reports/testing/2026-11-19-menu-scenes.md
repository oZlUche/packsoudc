# 主菜单背景按原场景重绘

构图基线取自原始美术定稿 `bf2e3c3a`。第 197 号菜单方案规定了三处地点、时辰和道具，世界观说明了休息点地面法阵压制诅咒的用途。[原场景表](../197-main-menu-and-title-brainstorm.md) · [世界观](../../worldview/worldview.md) · [原图与重绘，上排为原图](../../../handoff/art-review/menu-originals-and-repaint.jpg)

| 地点 | 画面核对 |
|---|---|
| 诅咒之地边缘的夜营 | 月牙下有两顶低帐，火旁有人整理行装，木路牌在右前景。近地火光勾出休息点的阵线。 |
| 帝国军团边营 | 黄昏从营内向外看，栅门悬军旗，门洞露出落日和枯树，前景桌上摊着名册，旁有墨盏与蜡烛。 |
| 行前地图桌 | 俯视图保留羊皮路线、背包、油灯、匕首和骨骰，灯光落在纸面。 |

在 Godot 4.7.1 的 1280×800 玩家视口核对左侧菜单与三张背景的裁切，并检查复用地图桌的存档页。三张画使用 2112×1320 贴图，保留 1920×1200 的中心可见区和原有推移、淡入设置。[菜单轮播实机](../../../handoff/art-review/game-menu-three-landscapes.jpg) · [存档页](../../../handoff/art-review/game-slots.jpg)

主菜单定向套件通过 78 项断言，字体覆盖通过 42 项。使用独立进程加载导出的玩家资源包，读取三个背景资源及各自的 JSON，尺寸和可见区均与源文件一致。本次验收集中于主菜单、共用背景和导出贴图。
