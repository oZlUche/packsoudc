## 四、要执行线程看的问题

1. **开局屏：右键信物是「放回仓库」，说明窗脚注却写「右键奉为主信仰」**
   - 现象：在开局屏的初始包里右键蛮神信物，它直接回了仓库。按下右键还没松开，信物就已经不在棋盘上了。
   - 原因：`hover_tip.gd` 的 `pin_on` 有 300 §2.5 的规则，「右键 = 第一动作」。开局屏棋盘上一件道具的第一动作是「放回仓库」。
   - 能走通的路：悬停约两秒，说明窗展开后点「奉为主信仰」。
   - 问题在脚注：信物说明窗的脚注写「信物 · 右键奉为主信仰」（`tip.anchor_right_click`）。在开局屏照着做，信物会被收回仓库。局内右键是钉住说明窗，也不是直接奉神。
   - 建议：脚注改成指向按钮的说法，或者干脆去掉（按钮已经写了「奉为主信仰」）。
   - 图：`v650-setup-tip-stale-hint.jpg`。

2. **英文大字号：「风险」键的悬浮说明盖住「Normal / Links」**
   - 英文大字号下，三个查看签折成两行，「Risk」单独在下一行。
   - 鼠标停在「Risk」上时，悬浮说明 "Highlight eroded and benched items only" 正好压在上一行的「Normal / Links」上面。
   - 接着直接点「Normal」没有切回去：日志里点完还是 risk，同一步中文默认和中文大都能切。
   - 真人把鼠标挪过去时，说明窗可能先收掉，所以这一条要在真机上确认。
   - 图：`v651-bag-risk-en-large-tip-covers.jpg`。

3. **自然之神在战记里看不到**
   - 奉自然、三阶，一场 58 行的战斗（打了好几秒），战记里没有一行和生息、守护有关，`last_mechanic` 里也没有自然的条目。
   - 报告 333 说过「自然在不受伤的短战里看不到，符合定位」。可这一场不短，也受了伤（有流血）。
   - 要确认的是：周期治疗是不是不写战记？还是这一场根本没触发？如果是前者，玩家在战记里就没有办法知道自然做了什么。

## 五、观察（交作者判断）

1. **结果页不显示信仰**：本局奉的神、阶、祈愿收支都没有（只有开发设置里的信力节奏一行）。方案 §10.2 把结果页列进了走查，但没写结果页该显示什么，所以这里只记录现状。
2. **蛮神信物的赐福行写「获得 1 层血怒」**：开局屏的说明窗里，信物自带的赐福是【血怒】，D 批的基础机制是【怒气】。两个名字很像，又同属蛮神，新玩家可能分不清。
3. **背包东西多时，信物可能被别的道具盖住**：六神那局在全部拾取之后，大地信物那一格上叠着一块纱布，右键只点得到纱布（图 `v651-earth-charm-covered.jpg`，右上角）。走查最后改用测试辅助直接奉大地。这局是测试辅助硬塞了六件信物和三件武器，超重 82 / 48，也可能是测试局特有的情况，没有单独复现。
