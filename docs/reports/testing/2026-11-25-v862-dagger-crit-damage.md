# 测试 v8.62：匕首按稀有度加暴击伤害

- 日期：2026-11-25
- 对象：v8.62（PR #928，main 1d78332）。带 `dagger` 标签的 13 把武器写上暴击伤害，按稀有度递增：普通 160%、优良 170%、稀有 180%、史诗 190%、传说 200%、神话 210%。暴击率不动。

  - **没有发现问题。** 全量全过。

  - **模拟战斗里，暴击那一下就是普通伤害乘新的暴伤。** 例如匕首 3 → 4.8，刹那 199 → 417.9。
  - **仓库页真悬停：** 悬浮窗写「暴击伤害 160%」到「210%」，两套都不溢出。

## 界面悬停（`wh928`）

新档。用测试辅助往仓库放匕首、淬火匕首、钢刺、无声短刃、焰牙、刹那，然后在仓库页逐件真悬停。

| 道具 | 中文常规 | 英文大字号 |
|---|---|---|
| 匕首 | 「暴击伤害 160% / 每 0.6 秒造成 3.2 点伤害」 | 「Crit damage 160% / Every 0.6s, deals 3.2 damage」 |
| 淬火匕首 | 「暴击率 15% / 暴击伤害 170% / 每 0.6 秒造成 6.6 点伤害」 | 悬浮没抓到（见「测试工具问题」） |
| 钢刺 | 「暴击率 15% / 暴击伤害 180% / … 9.6 点伤害」 | 同左 |
| 无声短刃 | 「暴击率 20% / 暴击伤害 190% / … 9.4 点伤害」 | 同左 |
| 焰牙 | 「暴击率 15% / 暴击伤害 200% / … 13.2 点伤害」 | 同左 |
| 刹那 | 「暴击伤害 210% / 每 0.5 秒造成 220.9 点伤害」 | 「Crit damage 210% / … deals 220.9 damage」 |

- 每一件的悬浮窗都不溢出。截图 `*-wh928_07_tip_chana.png`。
- 「每 X 秒造成 Y 点伤害」里的 Y 是算上暴击以后的平均数，已经按新的暴伤算了。
  - 匕首：3 × (1 + 10% × 0.6) ≈ 3.2。
  - 淬火匕首：6 × (1 + 15% × 0.7) ≈ 6.6。
  - 刹那：199 × (1 + 10% × 1.1) ≈ 220.9。

## 观察（低优先级，不算问题）

- **两件【刹那】都是神话。** `chana` 和 `chana_lesser` 名字一样，稀有度也都是 5，所以都是 210%。按名字看，`chana_lesser` 像是弱一档的那件。稀有度是这次以前就有的，这里只是记下来。
- **这次没真打一场。** 只看了模拟和悬浮。全量里各武器的契约测试都通过了。

## 测试工具问题

- `wh928` 的仓库里本来就有一把开局带的匕首，所以匕首悬停了两次。
- 英文那遍悬停淬火匕首时，悬浮窗没弹出来，那张截图里也没有悬浮窗。别的五件都正常。中文那遍淬火匕首正常。这一件的英文写法由 `dg928` 的英文悬浮内容补上了：「Crit chance 15% / Crit damage 170%」。
