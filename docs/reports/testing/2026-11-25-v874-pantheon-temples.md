## 升级选牌：【重选】【跳过】（同一趟，两套语言）

奉蛮神开局，声望 150。用测试辅助加经验，升到 5 级。

| 检查项 | 结果 |
|---|---|
| 万神院给的次数 | 重选 4（40 起 1，70 加 1，90 加 2），跳过 4（60 起 1，70 加 1，90 加 2）；科技给的重选 0 |
| 键 | 「重选 4」「剔牌 0」（灰）「跳过 4」；英文 Reroll / Cull / Skip |
| 质变那一批 | 先挑第一张 |
| 真点【跳过】 | 换成 4 张，提示多一句「上次跳过了：这次多一张」；跳过 4 → 3；欠选 4 → 3（跳过的这一级算选过了） |
| 真点【重选】 | 还是 4 张，换了一批；重选 4 → 3 |
| 挑一张以后 | 下一批回到 3 张，跳过加成清零 |
| 存档退出再继续 | 跳过用了 1、剩 3；重选剩 3；解锁的神殿还在 |
| 排版 | 四张也排得下，不溢出 |

## 观察（低优先级，不算问题）

- **红点可能一直消不掉。**
  - 老档 C，以及新档声望到 150 解锁了三位以后，手里都剩 1 次机会。
  - 剩下的三座（技巧、狩猎、大地）都写「神殿尚未落成」，这次机会用不掉。
  - 「后勤」和「万神院」的红点会一直挂着，直到作者写好其中一位的牌表。
  - 要不要在没有能解锁的神殿时不挂红点，留给作者。
- **六个剪影一模一样。** 都是一个黑圆（神的徽记压黑），看不出是哪位。已知是占位，等 UI 设计的样张。
- **神殿页和出征屏的悬浮窗写的是两段不同的字。**
  - 神殿页是作者新写的一句，例如「热衷战斗、牺牲与鲜血之神」。
  - 出征屏写的是信仰的说明，例如「自然的概念（石头砸下也是暴力）……」。
  - 这是设计如此，记下来。
- **英文大字号下，「God of Nature」刚好顶着神殿卡的边**，没有出框。
