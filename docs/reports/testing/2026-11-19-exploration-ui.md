# 探索主屏与行装界面重绘验收

对照基线为 `481427a5`。两版均在 Godot 4.7.1、Linux OpenGL Compatibility 下运行，以 1280×800 截取真实视口。使用独立存档、自由探索种子 780613、同一套十件配装。下文的组件尺寸均为设计像素。验收集中在探索与背包。

## 从地图到背包

1. 进入地图。顶栏内应能看到完整的日晷、指针、左端菜单与右端背包。将日晷移到另一个栏位，悬停与教程定位应随图形一起移动。
2. 左下打开图例，再次触发后收回。收起时只保留折签，展开后列出本图节点与区域产物。右下空腰带只显示容量，按铜扣可看空槽；取得随身技能后直接显示图标，双击使用。
3. 打开背包，查看右侧持有者、属性与剩余格位。关闭人物档案时，面板宽度从 1056 收到 732，棋盘仍在相同的位置。拖动、旋转、取消与关闭按键继续使用游戏原有绑定。打开背包时按回正、看全图或原比例快捷键，背景地图应停在原处。
4. 给图例或腰带按钮键盘焦点。连续用空格打开、收起，按钮状态改变，镜头位置保持；释放焦点后按相同的键，地图回正到玩家。
5. 用鼠标点击人物档案开关，再以中文、英文大字号（1.25 倍）打开背包。核对姓名牌、数值、棋盘、速查及关闭按钮。第一版暗沉的整屏遮罩已减淡，可透过遮罩辨认地图方位。

## 测试与取样限制

通过入口 `godot --headless --path . --script res://tests/run_tests.gd -- 套件名`。运行的定向套件包括 hud_150、pawn_184、topbar_235、hud_189、map_screen_166、map_backdrop_192、belt_slots_160、bag_window_232、ctrl_whole_bag_274、drag_markers、stats_strip_216 和 character_card_223。这 12 组共通过 748 项断言。全项目脚本加载检查使用 `res://tools/check_scripts.gd`。

折起图例后可用视区的比例发生变化。镜头测试分别建立「图纸小于两轴」与「图纸覆盖两轴」的条件，验证前者居中，后者在边界处仍盖住视区。查看全图继续以容纳整张图纸为目标。

部分测试与截图进程在退出时仍打印对象或 GLES3 资源释放日志。此次未做完整章节通关、硬件 GPU 性能或所有自定义 HUD 布局组合测试。
