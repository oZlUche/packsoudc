# 092 · 全局倒计时、过半关闭的撤离点、保险箱点、离开结算一键出售暂存区

作者第十六批（2026-09-30）。原话：

> 添加一个非常显眼的全局倒计时，每走一步 -1，归零时视为本局行动失败。给一个撤离点添加在全局倒计时降为一半时关闭的设计并在地图上显示。添加一个新类型节点【保险箱】，玩家可以将背包里的部分道具转移进去并视为已经带出（即使失败也能带出，可以在结算画面看见，有独立格子），保险箱的大小初始为 3×3。添加一个离开结算界面时一键出售所有暂存区的东西的设计，并提示玩家。

四件都做了。数值是占位（见文末），规则都在数据里。

## 一、全局倒计时

- **数据**：`ChapterDef.step_limit`（行动点；0 = 这一章没有倒计时）。第一章写了 **36**（占位）；序章两张没有 —— 教程按脚本走，不该被时间催。
- **算法**：不另开计数器，倒计时 = `step_limit − ActionClock.total`（`RunState.countdown_left()`）。走一步扣边的 `action_cost`（通常 1，作者说的「每走一步 -1」）；事件里「原地耗时」也扣。所以**存档不用加字段**，读回来自然对。
- **归零**：`RunState._check_countdown()` 在走一步 / 传送 / 原地耗时之后看一眼：剩 0 → 关掉会话、丢掉没拿的战利品、清掉等着的战斗与事件、`DEFEATED(&"time_out")`。场景流照战败走：结算屏写「倒计时归零：行动失败」，钱与棋盘都没了 —— **只有保险箱里的带得出**（下面）。
- **显眼**：地图屏顶上一行 34 号大字「倒计时 n / 36」，带边框的面板；剩一半以内琥珀、四分之一以内（或 ≤ 5）红，边框跟着变色。日志：剩 ≤ 5 步每步喊一句、归零一句。

## 二、倒计时过半关闭一个撤离点

- **挑哪个**：`PaidExtracts.mark_closing(graph, step_limit)` 在开局那一遍标 —— 离出生点最近的**免费**撤离点（最容易到的那个先没了：逼人往里走或早撤）。`closes_at = step_limit / 2` 记进 `node.content`，跟着图存。`ChapterDef.closing_extract`（默认开）关掉这条设计。
- **关**：`RunState.extract_closed(node)`：倒计时剩 ≤ `closes_at` 就关。`try_extract` 拒绝；地图屏「撤离」按钮灰、按了说「已经关闭（倒计时过半）」；到那一刻日志喊一声。
- **地图上显示**：`MapView.closing`：那个点下面一小块牌子「剩 n 步关闭」（琥珀）；关了画红叉 + 「已关闭」。倒计时那一行也带着「撤离点 12 剩 6 步关闭 / 已关闭」。节点浮窗补一句。

## 三、保险箱点（`safe`）

- **类型**：`MapNodeTypes.ALL` 加 `safe`；样式「箱」淡紫；地图文字符号 **K**（预设图直接画）；**不写进** `RingMapConfig` 的类型风险 / 回报表（校准会把表里的类型当成可分配的往图里换，第一版就踩了这个坑：几个种子多出一个挨着出生点的保险箱）。编辑器的类型下拉自动多一项。
- **放哪**：`SafePlacer.mark(graph, count)`（`core/run/safe_placer.gd`，生成之后的一遍，和付费撤离点同一条思路）：可换的类型是战斗 / 事件 / 随机 / 搜索 / 精英，不挨着出生点、不是终点；按「深度最接近一半」排、同深按 id，两个保险箱不相邻。换掉的点内容清空，**在放敌人之前**换，所以保险箱点没有敌人。个数 `ChapterDef.safes`（第一章 1，序章 0）。
- **容器**：`RunState.safe`（`GridInventory`，id 3，不要求包），大小 `MetaRules.safe_size`（**初始 3×3**，局外成长改它），`GameFlow.safe_size()` 传进开局；进存档（`"safe"`，老存档没有就按 3×3 新开）。
- **踩上**：`NodeEvents._proceed` 的 `safe` 分支发 `safe_opened`，**不标用过**（每次踩上都开、走了再回也开）；`GameFlow` 推 `Screen.SAFE` 叠层；站在点上 `can_reopen / reopen_node` 也能再开（Esc 收起是最小化）。
- **保险箱屏**（`ui/game/safe_screen.gd`）：左边保险箱格子 + 「已视为带出」的读数，右边棋盘 + 暂存区（复用 `InventoryPanel`）；拖着放、棋盘双击进箱、箱里双击回棋盘（放不下进暂存区）；**包放不进去**（局外不留包，`MetaState.keeps`）。
- **结算**：`RunResult.safe_items / safe_size / safe_value / safe_layout` **不管撤离还是战败都记**；`MetaState.absorb` 把它们各计一次图鉴、进带回来的棋盘（战败时新开一块，所以战败的结算屏也有「带回来的背包」面板可以一键置入），放不下直接进仓库；`last_absorbed["safe"]` 计几件。结算屏**单独一格**按记下的布局重画保险箱（只看），标题「保险箱带出 n 件、值 v 币」；战败那行加「保险箱里的 n 件带出来了」；局外屏「刚才这一局」也说。

## 四、离开结算界面时一键出售暂存区

- 撤离时暂存区里没背出来的那几件以前只是「留在了里面」（`left_behind`）。现在 `RunResult.left_items` 记着实例；**结算屏上先说清楚**：「暂存区里还有 n 件（值 v 币）没背出来：离开这一屏时会一键出售，得 s 币（按基地出售比例）」（琥珀）。
- 离开（「继续」或「进入下一张」）时 `GameFlow._sell_left_behind()`：按 `MetaRules.sell_ratio` 卖、钱进局外、清单清掉（只卖一次）、`last_absorbed["stash_sold"]`；局外屏顶上提示「上一局暂存区里没背出来的 n 件已一键出售，得 s 币」。战败的暂存区照旧全丢（作者定的战败规则没动）。
