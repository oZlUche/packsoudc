# 方案：基地重排 —— 左列页签与大按钮、中列当前页、右半边常驻仓库；基地专用的「家」UI 套件（164）

> 作者原话（2026-10-12，架构设计）：「基地布局改为：按钮（图鉴、成就、出售、科技）左上角竖向排列，再来一局和回主菜单放在左下角。仓库棋盘放在右侧，占据整个右半边，缩放到保证可以显示所有棋盘，另外让美术设计一套用在基地的UI，包括背景、按钮和文本框，重点突出家的安心和温馨」
> 性质：架构 · 实施（1 ～ 3 节）+ 美术清单（4 节，转美术设计）。待定按推荐。关联 058 / 088（基地页签）、139（抽屉、格子按宽放大）、157（石板框、深浅字色）、163（仓库分页）。

## 1. 现状

`ui/game/meta_screen.gd`：一列竖排 —— 头部（「基地」+ 五个页签横排 + 调试台箭头）、「刚才这一局」、战绩一行、「再来一局 / 回主菜单」横排、然后是当前页占满下面；仓库是五页之一（`warehouse_panel`，139 按宽放大格子、滚动框钉四行 —— 作者截图里仓库只露四行，下面大片空）。出售页与科技页各自再画一块仓库视图。

## 2. 布局：三列

```
┌──────────┬─────────────────────┬──────────────────────────┐
│ 基地      │  当前页               │  仓库（163 的分页组件）       │
│ 图鉴      │  默认「家」：刚才这一局   │  ┌一┐                       │
│ 成就      │  战绩、带回来的背包      │  │二│  10 × 8 整块可见、不滚   │
│ 出售      │  （一键置入 / 整理）     │  │三│                       │
│ 科技      │  图鉴 / 成就 / 出售 /   │  └─┘                       │
│          │  科技 各自的内容         │                            │
│ 再来一局   │                      │                            │
│ 回主菜单   │                      │                            │
└──────────┴─────────────────────┴──────────────────────────┘
```

- **左列**（固定宽 220）：顶部「基地」标题，下面四个页签**竖排**（图鉴、成就、出售、科技；`toggle_mode`，选中态用 `UiTheme.mark`），再点一次选中的页签回到「家」页。底部贴着左下角：「再来一局」（主档、大号）在上、「回主菜单」（次档）在下，两颗同宽。带回来的背包没清空时「再来一局」灰的（现有规则），提示行写在它上面。
- **中列**（剩余宽度）：
  - 「家」页（默认）：「刚才这一局」、战绩一行、带回来的背包（`WarehousePanel` 里那块 `_board_view`，连同「一键置入 / 整理」两颗按钮；「剩下的不要了」已去掉）。没有带回来的背包时这一块不显示。
  - 图鉴 / 成就：现有内容搬进来（139 的按宽算列数照旧，宽度换成中列的）。
  - 出售：只剩筛选档位、一键出售按钮与预览文字；**卖的对象是右半边的仓库**（双击右边一件 = 卖一件），不再另画一块仓库视图。
  - 科技：树与上交区；上交从右半边的仓库拖过来或双击，不再有收起式仓库视图（`tech_panel` 的 `_warehouse_toggle` / `_warehouse_box` 删）。
- **右半边**（屏宽一半，固定）：163 的 `WarehousePages`（左侧竖排页选项卡 + 一页格子）常驻，所有页都在时显示；格子大小 = `min((右半宽 − 选项卡列 − 边距) / 10, (可用高 − 标题行) / 8)`，夹在 **40 ～ 80**（`CELL_MIN` 从 60 降到 40，保证 10 × 8 整块可见、不滚动；1280 × 720 下约 44 一格，1920 × 1080 下 80）。双击仓库一件的含义按当前页：家 → 置入带回来的背包（有的话）；出售 → 卖；科技 → 上交；图鉴 / 成就 → 不做事。
- 调试台抽屉（139）照旧：箭头在右上角、抽屉盖在右半边之上。
- 结算屏（`result_screen`）里的仓库面板不走这一套（它只是收尾），格子 60 不变。

## 4. 美术清单：基地的「家」套件（转美术设计）

基调：**安心、温馨** —— 回到自己的营地 / 木屋：炉火、木头、粗布、暖光；仍在 A 方向（墨线平涂、羊皮纸与石板）之内，但颜色比地图屏和叠层屏暖、亮。全部图按 157 的交付方式：图 + 同名 json（九宫格边距、`tone` 深浅 —— **每张都要写**）。

| 文件 | 规格 | 用在哪 |
|---|---|---|
| `assets/ui/home/bg_home.png` + json | 1920 × 1080，整屏背景：木屋 / 帐篷内景，左三分之一留给页签与按钮（暗一些、少细节），右半边留给仓库（素一些、木架或货架质感），`tone` 自定（推荐 light：浅木 + 墨字） | `MetaScreen._backdrop` 换成贴图（`UiTheme.PANEL_ART` 加 `PANEL_HOME`） |
| `assets/ui/home/btn_wood.png` + json | 九宫格 96 × 48，木牌按钮：常态 / 按下 / 禁用三态（三张或一张三列），主档再加一张暖金边（「再来一局」） | 左列页签与两颗大按钮（`BUTTON_HOME`、`BUTTON_HOME_PRIMARY` 变体） |
| `assets/ui/home/panel_cloth.png` + json | 九宫格 128 × 128，粗布 / 羊皮纸文本框底，`tone` light | 中列的「家」页读数、出售预览、科技说明（`PANEL_HOME_BOX` 变体） |
| `assets/ui/home/shelf.png` + json | 九宫格 128 × 128，木架边框（仓库格子的外框） | 右半边仓库的框 |
| `assets/ui/home/tab_mark.png` | 32 × 32，页签选中标记（钉子 / 挂牌钩） | 左列页签选中态 |

- 文字：浅底墨字、深底浅字（157 补的 `tone` 规则），美术只管写 `tone`，字色代码按它挂。
- 尺寸都按 1920 × 1080 画，代码按比例缩；九宫格边距写在 json 里（`margin` 四个数），和 `frame_stone.json` 同一格式。
- 交付到 `/mnt/project-files/art/ui/home/`，落到仓库由执行线程接（`UiTheme` 加三个变体、`PANEL_ART` / `BUTTON_ART` 两张表各加一行；没图时回落现有平面底，不挡实施）。
