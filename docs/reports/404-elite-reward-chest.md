# 404 精英的额外奖励改成宝箱

> 2026-11-28。作者 00:16：「我想了想，还是让精英的额外奖励变为一个宝箱，而不是固定的额外掉落」。
> 作者直接提的改动，按推荐的初值交给落实；第五节的几处同时发到确认台，作者改了再跟着改。数字都是初值。

## 一、现在是什么样

打赢精英点，除了它身上掉的东西，还保底多掉一件固定稀有度的道具（`DropRule.elite_rarity`，难度表 H 列）：

| 难度 | 多掉的那一件 |
|---|---|
| A0 到 A3 | 优良 |
| A4 到 A7 | 稀有 |
| A8 到 A11 | 史诗 |
| A12 | 传说 |

这一件直接出现在战利品里，没有悬念。

另外两样和它无关、这次不动：

- 局外科技【精英奖励】（319）：点了以后再多掉一件稀有及以上的。
- 首领保底一件传说（087）、A12 守卫掉的失效联动道具。

## 二、改成什么样

打赢精英点后，那一件固定掉落不再给，改成原地留下一个**精英宝箱**。

1. **怎么开**：和地图上的宝箱一样，长按开锁（154、155 的规则，按稀有度 1 到 3 秒），开了以后是一次搜索画面，东西摆在容器里自己拿。用现有的宝箱画面和宝箱图。
2. **什么时候开**：战利品画面收完以后接着出现宝箱。可以不开直接走，宝箱留在这个点上，回来还能开。
3. **宝箱的稀有度**：等于这个难度原来多掉那一件的稀有度（上表），所以难度表 H 列不用改，含义从「多掉一件」变成「宝箱的档」。
4. **里面有什么**（推荐的初值，和地图宝箱不同，用一张自己的小表）：
   - 必出 1 件和宝箱同档的道具，就是原来那一件。
   - 另外随机 1 到 2 件，按这个点当地的搜索规则掷，稀有度不设下限。
   - 能开出珍宝（和地图宝箱一样）。
   - 不遭遇敌人。

为什么不直接套地图宝箱的表：地图宝箱一个史诗箱出 4 到 5 件、件件不低于稀有，传说箱 4 到 6 件、件件不低于史诗。精英每局要打好几个，直接套上去，A8 以上每个精英都会多出四五件高档道具，成型速度会明显变快。用小表的话，保底那一件和原来一样，多出来的是一两件随机的东西，悬念有了，强度基本不变。

## 三、和其他东西的关系

| 东西 | 处理 |
|---|---|
| 局外科技【精英奖励】 | 不动，照旧另掉一件，说明文字不改 |
| 首领 | 不动（作者只说了精英） |
| A12 守卫 | 守卫也是精英，照样留宝箱；失效联动道具照旧直接掉 |
| 蛮神【神罚】升级版战前击杀精英 | 算打赢，照样留宝箱（原来那一件也是给的） |
| 自然之神【动物交谈】跳过的精英兽 | 没打，不给宝箱（原来也不给那一件） |
| 大地之神【大地共鸣】 | 只管材料节点的搜索，不管精英宝箱 |
| 撤离结算、战利分 | 宝箱里拿出来的东西和别的战利品一样算 |
| 切片、序章 | 照同一条规则改成宝箱；切片里必出的那一件仍然只从切片允许的道具里挑 |
| 回放、存档 | 宝箱开没开要进存档；旧存档里已经打过的精英不补宝箱 |

## 四、落实时要做的

1. 精英点打赢后，在这个点上放一个精英宝箱（稀有度取难度的 `elite_rarity`，没有就取掉落规则的），原来 `rarity_guarantee` 那一件不再进战利品。
2. 精英宝箱的收获表单独一份（必出一件同档 + 随机 1 到 2 件 + 可出珍宝），数字写在数据里，不要写死。
3. 战利品画面之后接宝箱画面；不开直接走的，这个点保留宝箱，再进来能开。
4. 说明页「节点类型」里精英一条、难度说明里「精英额外掉落」的文字，改成宝箱的说法（中英文）。
5. 校准：跑一遍带回价值的基准，和改之前比。目标是每局带回总价值的变化在一成以内；超过就把随机件数从 1 到 2 件降到 1 件。
6. 落地后给一份对照表（照这份报告逐条写实际做法）。

## 五、发到确认台的几处

1. 宝箱里的东西。A（推荐）小表：必出一件同档，另加随机 1 到 2 件；B 直接用地图宝箱的表（件数多、有稀有度下限，强度明显上升）。
2. 局外科技【精英奖励】。A（推荐）不动，照旧另掉一件；B 改成「精英宝箱高一档」，这样精英的额外奖励只有宝箱一样东西。
3. 不开就走。A（推荐）宝箱留在点上，回来还能开；B 离开就没了。
4. 首领要不要也改成宝箱。A（推荐）不改；B 一起改。

不回复就按推荐的做。
