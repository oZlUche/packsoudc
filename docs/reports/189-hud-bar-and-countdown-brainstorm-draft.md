# 189 · 讨论稿：顶端栏的读数「凹槽」不自然，和倒计时一起怎么处理 —— 三个方向，交美术起方案

>
> 这是头脑风暴，不是实施方案：给美术三个方向、一组约束和我的推荐，美术出样张、作者挑，之后再写实施篇给执行。

## 1. 现状（截图）

- 栏是一条浅色大理石长板（`PANEL_HUD_BAR` / `slab_bar`，高 88，`ui/hud/widgets/hud_bar.gd`，tone light）。
- 左槽三件各自一块**深色凹槽**（`HudWidget` 默认变体 `PANEL_HUD` = 157 的 inset 图）：心（`vitality_widget.gd`，红心 / 黑心 28 px）、金币（36 px 币 + 数字）、信仰（32 px 徽记 + 「Lv.0　5 / 25」）。凹槽是矩形、圆角一致、深度一致，三块等距排开 —— 像三张卡片贴在石头上，不像石头上长出来的东西。
- 中槽倒计时是**另一套**：`StyleBoxFlat` 深底 + 2 px 琥珀边（`countdown_widget.gd:10-15`），边色随剩余变（过半琥珀、四分之一以下红）。和凹槽不是一家。
- 右槽三个图标按钮（背包、放大镜、调试台箭头）也是各自一块小凹槽。186 落地后箭头在玩家包里没有。
- 字：读数 DOUBLE 档（小档 200%），`LABEL_HUD_DOUBLE`，墨色。

问题归纳：**三种底（凹槽、平底框、按钮槽）、一个节奏（等大等距矩形）**，所以看着像网页工具栏而不是一块石碑。

## 2. 三个方向

### 甲 · 刻在石上（无槽）

读数不坐槽，直接**刻**在大理石带上：心、币、徽记是浮雕小件（和现在的图差不多，去掉底），数字是凿刻的墨字；件与件之间用一道**竖刻线**（或一枚小的铜钉）分隔，不用矩形底。倒计时在正中，字号比左边大一档，凿得更深（两层阴影），颜色变化改成**数字本身**由墨 → 琥珀 → 朱砂（`#8E2A22`）填色，不再画框。

- 好处：和 157 补充三「控件是板上的凹槽 / 黄铜镶嵌、不是第二块板」最贴；改动最小（去掉 `PANEL_HUD` 底、倒计时去框）。
- 风险：浅底上红心 / 金币没有深底衬托会发飘，需要美术给件加一圈薄阴影或凿痕。

### 乙 · 一条长槽

整条栏只有**一道**贯通的浅凹槽（像石碑上刻字的凹带，两端黄铜包角），所有读数都坐在这一道里，按钮也在里面。倒计时在槽正中，用一块**嵌入的黄铜小牌**（铜底刻数字）区分出来，边色变化改成铜牌上的字色变化。

- 好处：一个节奏、一种材质；槽把浅底问题解决了（槽内略暗）。
- 风险：读数能「摆」（150 的摆读数）—— 长槽是栏的一部分，拖出栏的读数就没有底了；需要规定「拖出栏的件自带小槽」。

### 丙 · 物件化

每个读数换成**一件挂在石带上的东西**：心 = 一串挂在皮绳上的小心（或一条红绸，掉血剪短）；币 = 挂着的小钱袋 + 数字；信仰 = 挂在钉子上的徽章牌；倒计时 = **沙漏**（沙量 = 剩余比例，数字在沙漏旁）或**刻度蜡烛**（罗马计时蜡）；按钮 = 挂在钩上的小工具。栏本身可以不再是整条石板，而是一根横木 / 石檐。

- 好处：最有「古代」味，倒计时第一眼就是时间（沙漏比数字直观，颜色变化可以是沙色）。
- 风险：件数多、每件一套状态（心掉、沙漏流、徽章换神）；布局件大小不一，摆读数的网格要重调；和 180 开局屏、名牌的「铜 + 石」风格要对齐。

## 3. 倒计时单独说

不管选哪个方向，倒计时都该和左边的读数**同一种材质语言**，差别只在**位置（正中）和字号（大一档）**。三个画法任美术挑：

1. 纯数字「77 / 90」，颜色三段（墨 / 琥珀 / 朱砂），到红阶轻微呼吸（现有 `color()` 逻辑不变）。
2. 数字 + 一道**弧形刻度**（半圆日晷状，剩余段镀铜、用掉的段只剩刻痕），颜色同上。
3. 沙漏（丙）：沙量 = 剩余 / 总，数字写在沙漏右侧；红阶沙变红。

「撤离点 12 剩 N 步关闭」那半句（186 改成「最近的撤离点剩 N 步关闭」）**不在栏里写**：挪进倒计时的悬浮窗（栏上只剩数字）。

## 4. 约束（给美术）

- 栏高 88（`HudHost.BAR_HEIGHT`），1600 × 1000 画布，栏贯通整宽；读数是可拖的「件」，每件有小档 / 大档 / 双倍档三种字号（`HudWidget.Tier`），美术只按双倍档画即可，但要说明小档怎么缩。
- 浅底墨字规则（157 补）：栏 tone light；件的底若是深色要在交付 json 里写 `tone: dark`。
- 现有件图：心（红 / 黑）、币 36 px、信仰徽记 7 枚 32 px（`assets/ui/faith/`）、背包 / 放大镜图标、`slab_bar` 板边。
- 数字永远是字段来的实时数（心数、币、信力、剩余步数），美术别把数字画死在图里。
- 交付：`art/ui/hud/v2/` + README（九宫格切法、每件的尺寸与锚点、状态图），样张 2–3 版给作者挑（「UI替换美术」线程的惯例）。

## 5. 我的推荐

**甲 + 倒计时画法 2**：去掉所有矩形凹槽，读数刻在石带上、竖刻线分隔，倒计时居中大一档、下面一道弧形铜刻度。理由：改动最小、最贴 157 的「一块板」原则、倒计时的形状能一眼读出「还剩多少」而不用看数字。丙的沙漏很好看，但一次换掉整条栏的所有件，风险在摆读数与状态图数量；若作者偏爱丙，建议只把倒计时先做成沙漏（画法 3），其余件留到道具图之后一起物件化。

## 7. 作者定案（2026-10-18，在「UI替换美术」线程）

美术按本篇出了甲 / 乙 / 丙 / 丁（丁一 = 乙的长槽 + 半圆日晷，丁二 = 另一版日晷）五张样张，在 `/mnt/project-files/art/ui/hud/v2/`。作者原话：「乙的整体风格，但是倒计时要换成日晷样式」「去掉数字倒计时，而是设计成鼠标移动上去时出现悬浮窗」「日晷记住要刻上去的，而不是额外的部件」。

定下来的：

1. **整条栏 = 乙**：一道贯通的浅凹槽、两端铜包角、铜点分隔，所有读数和按钮坐在槽里。
2. **倒计时 = 半圆日晷（丁一的日晷）**，但**刻进槽底**：日晷是石带上刻出来的半圆刻度 + 晷针投影，不是嵌上去的一块铜牌 / 铜片；走过的扇面是刻痕，剩下的扇面镀铜（或反过来，由美术定），颜色三阶（墨 / 琥珀 / 朱砂）落在扇面与晷针上。
3. **栏上不写数字**：「77 / 90」整个去掉，剩余只靠日晷的扇面表达。**鼠标停上去弹悬浮窗**：第一行「还剩 N 步」（数字 `val`，颜色随三阶），第二行「最近的撤离点剩 N 步关闭」（186 那句从栏里挪来的）；满 / 过半 / 不到四分之一只改颜色不改字。悬浮窗走 `HoverTip.show_text`，和别的件一样。
4. 其余读数（心、币、信仰徽记、背包 / 放大镜）照乙，不另改。
