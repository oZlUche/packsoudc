# 152 · buff 包含标准轴（血怒 = 每层一层强攻 + 一层加速）

> 状态：已落地（2026-10-10，作者在「架构方案执行」里直接定的做法）

## 作者原话

> 关于标准轴buff，我的想法是让非标准轴buff，以血怒为例，包含它们，比如每层血怒等于施加一层【增伤】和【加速】，而不是每层血怒直接增加3%的伤害和3%的急速。修改buff编辑器以通过我设定的途径实现

（作者说的【增伤】就是轴表里的 `damage_dealt`，正名【强攻】、反名【虚弱】。）

## 做法

- **数据**：`BuffDef.axes: Array[BuffAxis]`，每项 `{axis, stacks}` =「这个 buff 每一层带几层哪条轴」，层数带符号（负数用反名，如【减速】）。JSON：
  ```json
  "axes": [{"axis": "damage_dealt"}, {"axis": "attack_speed"}]
  ```
  （`stacks` 默认 1，写 1 的时候省略。）
- **结算**：这些层是「被包含」的，**跟着 buff 走**，不另外记在单位的轴上。`CombatantRuntime.axis_carried(axis)` = Σ 身上每个 buff 的「每层带几层 × buff 层数」，轴的合计 = 内容层 + 系统层 + buff 带的。所以：
  - 叠一层 buff 多一份，掉一层少一份，到期、净化、吃层都不用另管；
  - 和道具 `shift_axis` 给的层、别的 buff 带的层直接相抵（两层血怒 + 被上三层虚弱 = 强攻 −1）；
  - `axis_condition`、伤害管线读的都是合计，看得见 buff 带的层。
- **不发 `axis_shifted`**：buff 栏画的是这个 buff 自己（血怒 ×1），不另画「强攻」「加速」两格，悬浮窗的词条里写着它带什么。代价是 `on_axis_at_least` 等下一次真正的轴变动才会看见 buff 带的层 —— 现在的内容里没有这样组合的，以后要再说。
- **词条**：「每层带【强攻】1 层（造成的伤害 +3%）、【加速】1 层（攻速 +3%）」—— 不可叠层的也这么写，读作「这一层带」。
- **预估**：开战即上身的 buff 带的轴进预估 DPS（`CombatantSpec.opening_axes`），落法和运行时一样（公式的最后一步）；151 的战斗力估算把 buff 带的轴按 `PowerContext.axis_value` 计值。
- **导入器**：`axes` 里写了轴表没有的轴报错、写 0 层提醒；buff 的 `mods` 里落在标准轴属性上的（伤害、攻速、回血、暴击……）每条提醒「改写成 axes」。防护（`armor`）先不提醒 —— 作者另提了「格挡只归盾牌、只取最高」，那件另出方案，弹开 / 久弹 / 标记三个 buff 也留到那时一起改。
- **buff 编辑器**：表单的「效果」第一栏就是「每层带的标准轴」，「＋」加一行，轴是下拉（「强攻 / 虚弱 (damage_dealt)」），层数可正可负，下面一行灰字说清每层折多少。右栏摘要多一行「每层带……」。所有叫 `axis` 的字段（改轴、扣轴、轴条件、轴扳机）一起换成了这个下拉。

## 内容改动

- **血怒**：作者在本地已经把它从「伤害 +10%」改成「伤害 +3%、攻速 +3%」（分支 `claude/project-thread-p35e44`，并进来了）；这次再改写成 `axes`：每层一层强攻 + 一层加速，数值相同（轴步长都是 3%），只是走轴。仍是不可叠层、持续 10 秒。
- 其余 buff 没动。

## 落地记录

- 新文件 `core/battle/buff_axis.gd`；改 `BuffDef`（`axes`、`axis_stacks_per`、估值）、`CombatantRuntime`（`axis_carried`、合计、`_apply_axes` 也结算 buff 带的轴）、`CombatantSpec`（`opening_axes`）、`StatAxes`（`what_of`、`effect_text`）、`Glossary.describe_buff`、导入器、`PropertyForm`（轴下拉）、`FieldText`、buff 编辑器摘要。
- 和「轴 + 乘区」的先后：buff 带的轴和别的轴一样是公式的最后一步，所以「+3% 伤害」从原来 buff 的乘算（和别的乘算相加）变成了轴因子（乘在终值上）。血怒和别的乘算同时存在时数值会略有差别（例如再有 +15% 乘算：原来 ×1.18，现在 ×1.15 × 1.03 = ×1.1845）。
- 测试：`tests/battle/test_buff_axes_152.gd`（结算、相抵、掉层 / 到期、内容、导入往返与提醒、预估、编辑器）；`test_author_087` 的血怒词条与开战预估改成新写法。
