# 方案：道具悬浮窗 —— 深底白字、图标排版、固定式悬浮窗（170）

> 讨论稿 2026-10-13 出样张后，作者 2026-10-14 定稿（九条原话见附录，第 1–5 条落在本篇，第 6–9 条见 171）。性质：架构 · 实施 + 美术。待定按推荐。关联 084 / 087（悬浮窗与词条）、107（哪些词弹）、157（纸底）、168（字体）、169（字色按底）、171（标签 / buff / 装载槽的数据模型）。

## 1. 作者定的

1. 楷体和魔幻风不搭 → **换正文字体**；排版引入**图标**；明度提升 → 悬浮窗改**深底**，普通文字**白字**，带色的字一律**描边**。
2. 说明文字**斜体**，名称**粗体**；版式用样张 **A**（区块分隔）；加 **十字军之王式的固定悬浮窗**：鼠标停在悬浮窗上一段时间（沿外框顺时针走一圈的进度条），悬浮窗钉住，玩家可以移到带下划线的关键词上再唤起新悬浮窗。
3. 不写格数；「值」换**货币图标**，重量换**秤砣图标**。
4. 武器行改成「**每 X 秒造成 Y 点伤害，消耗 Z 耐力**」，不写出手 / 冷却。
5. 增益槽、受益槽各一个**图标**，既画在邻居格上（替换半透明方框）也写在说明里（替换关键字）→ 美术。

## 2. 版面

深色底（美术给深色九宫格，`tooltip_dark.png` + json `tone: dark`；没给就是现在的半透明深底），宽 340。自上而下：

| 层 | 内容 | 字体 / 字号 | 颜色 |
|---|---|---|---|
| 名字 | 道具名 | 正文字体 **粗体** 18 | 稀有度色 + 描边 |
| 副行 | 稀有度名 · 标签（107：只列给玩家看的；171：按大类排序，用途 → 属性 → 材料 → 归属） | 12 | 稀有度名稀有度色 + 描边；标签 `dim`；有词条的标签带下划线 |
| 说明 | 道具说明（有才有） | **斜体** 13 | `dim` |
| 分隔线 | | | 底色提亮一档 |
| 正文 | 一行一条，行首是图标（有的话）：武器句 / 属性 / 【增益】句 / 【受益】句 / 【装载】句 / 附加 / 效果 / 耐久 / 信力 / 信物 / 包 | 14 | 白；数字粗体；语义色的词描边 |
| 脚注 | 【货币图标】N　【秤砣图标】N　右侧套装名 | 12，上面一道虚线 | `dim` |

- **武器句**：「每 **X** 秒造成 **Y** 点伤害，消耗 **Z** 耐力」。X = 编译后的实际周期（原「冷却」），Y = 伤害面板，Z = 每次出手的耐力；带附加效果时句尾接「，附带【中毒】」。不再写「出手」「冷却」「约 N DPS」（待定 1）。
- **增益 / 受益 / 装载句**：行首图标 + 171 §3 生成的句子（例：【增益】武器增伤 10%）。
- **描边**：所有非白色的字（稀有度色、语义色、词条色）`[outline_size=2][outline_color=#000000c0]`（RichTextLabel 的 BBCode 自带这两个标签），常量 `OUTLINE_SIZE / OUTLINE_COLOR` 在 `UiTheme`；白字不描。169 的 `resolve_styles` 在 `tone = dark` 且目标是悬浮窗时顺手包上描边（`outline := true` 参数）。
- **斜体**：正文字体没有斜体字形，用 `FontVariation.variation_transform` 斜切 0.2 做 `italics_font`（主题里设一次）。
- **粗体**：换字体后用它的 Bold 字重（见 §5），不再是 Medium。
- **图标行内**：`[img=16x16]res://assets/ui/tip/<id>.png[/img]`，缺图退回文字（「增益」「受益」「装载」「值」「重」）。

## 3. 固定式悬浮窗（十字军之王式）

- **跟随态**（现在）：悬停道具出现，跟着鼠标；鼠标**从道具移进悬浮窗**不消失（给 0.15 秒宽限，且鼠标落在悬浮窗矩形内就算仍在）。
- **钉住**：鼠标在悬浮窗内停满 `PIN_SEC = 0.6` 秒 → 钉住。进度 = 一道 2 px 黄铜色线，从左上角起沿外框**顺时针**走一圈（`_draw` 按周长比例画折线，四条边依次），走完即钉；中途移出就退回。钉住后右上角画一个小钉子（图，缺图画一个小方点）；悬浮窗停在原地不再跟鼠标。
- **关键词**：钉住前关键词只带下划线不响应；钉住后鼠标停在带下划线的关键词（`[url=term:xxx]` 包着的词条 / buff 名 / 标签）0.25 秒 → 在旁边开**子悬浮窗**（同一个 `HoverTip` 类，深度 +1，位置优先右侧、放不下换下方、再夹回屏幕内）。子悬浮窗同样可钉、可再开子窗，深度封顶 3。
- **解除**：鼠标离开钉住的窗及其所有子窗 0.4 秒、按 Esc、点窗外任何地方、开始拖拽 → 整串收掉。
- 087 的**词条侧窗取消**：词条只以下划线关键词存在，`describe_full` 的 `terms` 改成 `{id: 文本}` 供子窗查。
- 文字层：`TextTemplate` 的 `{term:xxx}` / buff 名 / 有 `tip` 的标签输出 `[url=term:<id>][u]…[/u][/url]`，颜色照 169。

## 5. 换字体

楷体不要了。请美术在**深底白字 + 描边**构图上出样张，候选（都 OFL）：思源宋体 Regular / Bold（字重全，粗体现成）、朱雀仿宋（已打包，偏古籍）、寒蝉锦书宋、京华老宋体（先核授权）。推荐**思源宋体**：有真粗体，深底上笔画够硬。作者挑定后按 168 的流程重裁、换 `wenkai_*` 两个文件（`FONT_REGULAR / FONT_MEDIUM` 改名 `FONT_BODY / FONT_BOLD`），标题仍朱雀仿宋、大标题仍马善政。

## 附录：作者原话（2026-10-14）

> 1. 我发现楷体和魔幻风格很不搭，需要更换，另外排版需要引入图标，颜色明度需要提升。改成深色底，普通文字改成白字，其他颜色字体用描边方案。
> 2. 描述文本用斜体，名称用粗体。排版形式用A，也就是将几个区块分隔。另外增加一个类似十字军之王的悬浮窗停留系统——鼠标放在悬浮窗上一段时间后（用沿着外框顺时针的进度条显示），悬浮框会固定在原地，这时玩家可以将鼠标移动到拥有下划线的关键词上，再次唤起新的悬浮窗。
> 3. 不用写格子，"值"用货币图标代替，重量用一个秤砣图标代替。
> 4. 关于伤害和出手描述，改成【每X秒造成Y点伤害，消耗Z耐力】，什么出手冷却都不要。
> 5. 让美术设计一个用于增益槽和受益槽的图标，既显示在当前物体的邻居格（替换目前的半透明方框），也显示在道具说明（替换增益槽关键字）。
> 6–9 见 171。
