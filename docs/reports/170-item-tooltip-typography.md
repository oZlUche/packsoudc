# 讨论稿：道具悬浮窗的排版 —— 名字进悬浮窗后的层级、字体与加粗规则（170）

> 作者原话（2026-10-13）：「未来的道具不再直接显示名字，而是有图案代替，所以道具的名字会在悬浮窗里，设计一套合理的带有适当加粗的排版用于说明，先发给我让我审阅」。
> 性质：**讨论稿，待作者审**；审定后再写实施细节交执行。关联 084 / 087（悬浮窗内容与词条侧窗）、107（哪些词弹）、157 补（纸底墨字）、168（字体）、169（字色按底）。样张：`170-tooltip-typography-mock.png`（真字体渲染，同目录有 html 源）。

## 1. 现状

悬浮窗（`ItemTooltip.describe_full` → `HoverTip`）是一个 13 号的富文本块，所有行同一字号、同一字体，只有第一行名字加粗：`名字　稀有度　N 格　值 N　重 N` / 说明（灰）/ 标签（灰）/ 属性 / 出手 / 附加 / DPS / 效果 / 耐久 / 增益槽 / 受益槽 / 供给 / 信力 / 信物 / 套装。名字一旦不再画在格子上，这一行就是玩家认东西的唯一入口，但它和下面的行长得一样，一眼找不到。

## 2. 排版（样张 A）

四层，自上而下：

| 层 | 内容 | 字体 / 字号 | 颜色 |
|---|---|---|---|
| **名字** | 道具名 | 朱雀仿宋 19（标题字体，169 的 `title_font`） | 稀有度色（按底取版） |
| **副行** | 稀有度名 · 标签（107 规则：只列给玩家看的） | 文楷 12 | 稀有度名用稀有度色，标签用暗褐 `dim`；有词条的标签按词条色 |
| **说明** | 道具的说明（有才有） | 文楷 13 | `dim` |
| 分隔线 | 一道细线 | | 纸色压暗 |
| **正文** | 属性 / 出手 / 增益槽 / 受益槽 / 供给 / 附加 / 效果 / 耐久 / 信力 / 信物，各一行 | 文楷 14（比现在大一号） | 段首词按语义色（增益 `grant`、受益 `receive`、信仰 `faith`），正文墨色 |
| DPS | 「约 N DPS」 | 文楷 13 | `dim` |
| **脚注** | `N 格 · 值 N · 重 N`，右侧套装名 | 文楷 12，上面一道虚线 | `dim` |

**加粗规则**（适当 = 一行最多两处，整句永不加粗）：

1. **段首词**加粗：属性、出手、增益槽 ×N、受益槽 ×N、供给、附加、效果、耐久、信力、信物、包。段首词 + 一个全角空格 + 正文，不用冒号。
2. **决定取舍的数字**加粗：伤害、冷却秒数、耗耐力、槽数、剩余次数、信力阈值、加成值。「值 / 重 / 格数」在脚注里不加粗（它们是查，不是比）。
3. **词条**不加粗，只上词条色（107：弹窗的词才上色），和加粗是两条独立的通道：粗 = 数字与段首，色 = 语义。
4. 名字不靠加粗靠字体：朱雀仿宋本身比正文重一档，再加粗会糊。
5. 灰色行（说明、DPS、脚注、休眠的信仰行）里**没有**加粗 —— 灰 + 粗自相矛盾。

字体来源：加粗 = 文楷 Medium（168 已打包），比 Regular 只重一档，样张里看得出但不扎眼；要更明显见待定 2。

## 3. 两种变体（样张 B）

- **左**：稀有度名挪到标题行右端当角标，副行只剩标签；不画分隔线，靠间距分层；DPS 挪进脚注右侧。更松、更像卡牌。
- **右**：段首不用加粗词，只加粗数字（「伤害 6」「冷却 2.0 秒」直接起头）。更短，但增益 / 受益 / 信力这些行少了可扫的锚点。

推荐 **样张 A**：段首词是扫读的锚点，分隔线把「这是什么」和「它怎么用」分开。

## 4. 配套（审定后进实施）

- 名字不再画在格子上后，悬浮窗要**零延迟**出现（现在 `HoverTip` 的延迟值待查），地上 / 战利品 / 搜索容器 / 仓库 / 图鉴里一样。
- `describe_full` 的返回加结构：`{"name", "sub", "desc", "body": [行], "foot", "terms"}`，`HoverTip` 按层拼 BBCode（`[font=朱雀][font_size=19]` 名字、`[font_size=12]` 副行与脚注、`[b]` = 文楷 Medium），颜色走 169 的 `style_color(name, tone)`。
- 图鉴格、商店行、奖励行、战报里引用道具名的地方（`{item:id}`）不变，仍按稀有度色。
- 测试：各层出现顺序、加粗只落在段首与数字、灰色行无 `[b]`、名字行用标题字体。
