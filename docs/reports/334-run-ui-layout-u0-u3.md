## 2. U2：行动与背包决策

### 2.1 行动代价预览（方案 §4.2，待办 `2026-11-14-action-danger-preview`）

新 `core/run/action_preview.gd`（`ActionPreview`）在副本数上把这一步（或连走的一串）走一遍，不改状态、不抽随机数：

- 倒计时：按 `MapTravel` 的同一套行动点（熟门熟路的免费步、负重倍数）和 `CountdownModule.spent` 的累计取整算。显示的是这一步真扣的数，例如进阶七在 9 点时走一步扣 2，在 10 点时扣 1。
- 侵蚀：这一步之后侵蚀推进到哪一档，经过的点和终点各扣多少体力和金币，会不会侵蚀或毁掉一件道具。有概率的写「可能」，侵蚀挑中哪一件不说。
- 猎手：只说看得见的（`visible_hunters`），而且只说这一步之后可能够得着终点的。
- 负重：已经翻倍的写倍数；离下一档只差上限一成以内才写「再重 n 就 ×m」，平时不上地图。

地图悬停浮窗里加这几行，钱用金币图。操作不变：点一下照样走，没有加二次确认。

测试 `tests/run/test_action_preview.gd` 拿真走一步的结果对预测：4 个种子 × 有无全图侵蚀，比对倒计时、侵蚀扣的体力和金币。另测了取整、免费步、负重倍数，以及不提看不见的猎手。

### 2.2 日晷读数（方案 §4.1）

- 剩得少（危险档）时，晷面下方刻出剩余数。剩得多时不刻，停上去或键盘聚焦看浮窗。
- 设置里加「日晷读数」开关：「剩得少时显示 / 始终显示」，默认是前者。

### 2.3 图例、腰带（方案 §4.3）

- 图例默认收起，只剩一列图标。停上去浮窗写全名，点一下展开，展开与否记进设置。教程可以临时展开，不写设置，收起后回到玩家选的样子。
- 腰带三格全空时淡到 50%。有一格装了东西就恢复。

### 2.4 背包的三种查看方式（方案 §6）

背包窗角色卡下面加「普通 / 联动 / 风险」三个小石钮：

- 联动：画出全棋盘真正连上了的邻接格位，没连上的道具压灰。
- 风险：只亮有侵蚀、或标了不参战的道具，图下沿压一块深色小牌，写「侵蚀n/3」（n 是层数，3 是上限）。再侵蚀一次就毁的写红字。
- 切换只改画法，不动道具。测试比对了切换前后的棋盘。

## 9. 离开时提醒地上的东西（作者 2026-11-19 16:48）

§5 第一条原本没做（和设计 109 冲突）。作者定：加进设置，可以弹窗提醒，弹窗上能勾「不再提醒」。

- 在地图上点要走的点时，如果脚下地上还有东西，先弹「地上还有东西」：留在地上几件、值多少，「走了也留在这个点上，回来还能拿」。按钮是「走」和「先收拾」，Esc 等于「先收拾」。
- 勾上「不再提醒」再点「走」，就把设置关掉，以后直接走。
- 设置里加开关「离开时提醒地上的东西：开 / 关」，默认开（`GameSettings.leave_ground_warn`，旧设置文件没有这一项也按开算）。
- 只拦玩家点地图。`MapScreen.step` 本身照旧直接走，连走途中经过的点也不问。地图日志那一行「地上的 N 件留在了那里」保留。
- `docs/architecture.md` 里 109 那段补了这次的改动。
- 测试 `test_run_ui_layout` 的 `frame_ground_warn`（12 项断言）：地上空时不问；有东西时先弹窗、还没走；Esc 收起不走；勾「不再提醒」再走，走到了、设置关了、存得回来；旧设置文件默认开。
