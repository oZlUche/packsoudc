# 359 魔晶石退出配方：改用晶石素材加属性素材（方案，交执行线程）

> 日期：2026-11-21。基线：main，v7.06。只有文档，没有改代码。
> 作者 16:41：「魔晶石不是只能作为法杖的配套镶嵌吗？现在还能作什么的素材吗？」
> 作者 16:45：「用碎晶/雾晶这些素材代替魔晶石，如果涉及属性就加入属性素材（火焰腺之类）」「协会任务那个保留」。
> 上面两句是作者定的；下面具体换成哪一件、几件，是我填的建议初值。

## 一、现状（查配方文件所得）

魔晶石在战斗里只能镶法杖，但现在还被当成材料用在三处：

| 用处 | 张数 | 现在要的魔晶石 |
|---|---:|---|
| 铁匠铺的元素金武 | 14（火 7、冰 3、雷 4） | 对应元素、史诗以上的魔晶石 ×1，另加金属或骨料 ≥稀有 ×2 |
| 铁匠铺的秘银附魔长剑 | 1 | 火焰晶石（低阶）×1，另加秘银锭 ×2、金属 ×1 |
| 局内拼合 | 3 | 噬血骨刺 + 火焰魔晶石 = 烈焰之牙；噬血骨刺 + 寒冰魔晶石 = 霜之牙；重弩 + 雷电魔晶石 = 雷霆重弩 |

另有协会的鉴定委托要上交两颗晶石，作者说保留，不动。

手头能替它的素材：

- **晶石素材**：碎晶（普通）、雾晶和烟晶（优良）、棱晶（稀有）、紫晶柱（史诗，1×2）。
- **属性素材**：火焰腺（火）、霜腺（冰）、电囊（雷），都是稀有，各自只从一种敌人身上掉（焰狼、霜蟾、电鳗）。

## 二、规则（建议初值）

换料的原则：原来那颗魔晶石拆成两样，**晶石素材**顶它的档次，**属性素材**顶它的元素。

### 1. 元素金武（14 张）

原来的「对应元素的魔晶石 ≥史诗 ×1」换成：

- 晶石素材 ≥史诗 ×1（材料格；目前合格的只有紫晶柱）
- 对应元素的属性素材 ×2（火系要火焰腺，冰系要霜腺，雷系要电囊）

金属或骨料的那一格、工钱、铁匠铺等级都不变。

### 2. 秘银附魔长剑

原来的「火焰晶石 ×1」换成：棱晶 ×1 + 火焰腺 ×1。其余不变。

### 3. 局内拼合（3 张）

拼合是两件贴在一起，所以只换一件：

- 噬血骨刺 + 火焰腺 = 烈焰之牙
- 噬血骨刺 + 霜腺 = 霜之牙
- 重弩 + 电囊 = 雷霆重弩

### 4. 不动的

- 协会的鉴定委托照旧收晶石（作者 16:45）。
- 魔晶石本身不改：照旧掉落、镶法杖、能卖、能炼金。敌方法师的配装不变。
- 魔法杖用碎晶、法杖工艺用雾晶和棱晶的那几张（报告 345）本来就是晶石素材，不动。

## 三、会出问题的地方

1. **属性素材的来路很窄。** 三种腺体各自只有一种敌人掉。14 张金武每张要两件，局内拼合还要再用一件。落地时请执行线程列出这三种敌人在哪些图、哪些池里出现，掉率是多少；不够的话建议让集市偶尔卖，并让地图协会的「兽类」素材倾向覆盖到它们。
2. **金武变便宜了。** 一颗史诗魔晶石的基础价是 650；紫晶柱加两件腺体合计 210 左右。打造的门槛从「找到一颗史诗魔晶石」变成「打特定的兽」。这是换料必然带来的，是否要用工钱或件数补回来请作者看落地后的数。
3. **和万物之尘的关系。** 报告 354 规定魔晶石不能用尘补，是为了保住金武最难的那一步。换料以后那一步是史诗晶石素材加腺体，它们都是普通素材，按现在的规则打过一次之后就能全用尘补。建议就按现规则走（这正是万物之尘「不用反复刷特定素材」的目的）；如果作者想保住金武的门槛，可以把属性素材列为不能用尘补。核对工具的两张表（买来就炼、打造再炼）改完配方后重跑一遍。
4. **局内拼合更难凑。** 魔晶石在搜索里能翻到，腺体只能打出来。局内想拼烈焰之牙，得先在这一局里打到焰狼。如果觉得太苛刻，可以改成「噬血骨刺 + 任一火属性素材」，蒸汽阀这类带火属性的零件也算。
5. **旧存档**：不用迁移，只是配方数据变了。玩家手里为金武攒的史诗魔晶石不再有打造用途，可以镶法杖、卖掉或炼成尘。更新说明里提一句。
