## 2. 战斗回放控件（交新开的「UI 替换」美术线程，第一单）

### 2.1 现状

`ui/battle/battle_view.gd` 底部一行：`[暂停/播放/重播]`（文字按钮，MINOR）· `ReplayTimeline`（横杆，高 34，伤害刻度朝上 / 朝下、倒下的刻度长一半、游标一道竖线，可点可拖）· `[1× / 2× / 4×]`（文字按钮循环）· `[跳过]`；下面一行灰字说明。倍速档是 `GameSettings.BATTLE_SPEEDS = [1, 2, 4]`。

### 2.2 要画什么

四样都要**石板 + 魔幻**风格，坐在 157 补充三的石板上（控件本身是刻进石板的凹槽 / 嵌在板上的铜与宝石，不是另一块石板）。每样出 **两到三个版本**（例如：铜嵌件版、刻痕版、符文版），同一张预览图上按真实排布（按钮 · 进度条 · 倍速 · 跳过 一行）拼好给作者挑。

| 控件 | 要求 | 状态 |
|---|---|---|
| 播放键 | 三态：播放（三角）、暂停（双竖）、**重播 = 逆时针旋转的箭头**（一圈带箭头，逆时针） | 常态 / 悬停 / 按下 |
| 倍速 | **罗马数字** Ⅰ、Ⅱ、Ⅳ（对应 1 / 2 / 4 倍）；一个按钮循环切，数字刻在铜牌或石面上 | 三档各一张 + 悬停 / 按下 |
| 跳过 | 常用跳过符号（三角 + 竖线 ⏭ 那一类），风格与播放键同一套 | 常态 / 悬停 / 按下 |
| 进度条 | 石板上一道凹槽（或符文刻线），已播部分有光 / 有色，未播部分暗；伤害刻度仍要分「我打的（朝上）/ 挨的（朝下）」与「倒下（长刻度）」，游标是一个可拖的嵌件（宝石 / 铜钉） | 九宫格槽体 + 游标 + 刻度两色 |

尺寸：按钮 40 × 40（和 166 的 `IconButton` 48 同一套比例即可，交 2× 图）；进度条槽高 34，长度可拉（九宫格，左右端头不拉伸）；颜色沿用美术基准图的铜 `#C9A54C` 与墨线。深浅：控件在浅色大理石上，json 标 `light`。

交付路径：`art/ui/replay/{play,pause,replay,skip,speed_1,speed_2,speed_4}.png` 三态各一、`timeline_groove.png` + json 九宫格、`timeline_cursor.png`、`timeline_tick_{mine,theirs}.png`；先出预览给作者挑版本，挑定再切图。

### 2.3 接入（作者挑定后交执行）

- 播放 / 倍速 / 跳过改用 166 的 `IconButton`（图标 + 悬浮窗名字；缺图退回现在的文字），主题变体 `BUTTON_ICON`，不加 `add_theme_`。倍速按钮的文字退路用「Ⅰ / Ⅱ / Ⅳ」（Unicode 罗马数字，不写阿拉伯数字）。
- `ReplayTimeline._draw` 有图时：槽体九宫格 `StyleBoxTexture`、已播段用 `draw_texture_rect_region` 裁出亮段、刻度与游标贴图；无图照现在画。`SIDE_COLORS` 改从图读或保留作退路。
- 底部那行灰字说明挪进悬浮窗（播放键悬停时说「结果开打那一瞬已定」），不再常驻。
- 测试：`test_battle_view`（三态文字退路、倍速循环显示罗马数字）、`test_replay_timeline`（有图 / 无图两条路径都能画）。UI 棘轮不涨。
