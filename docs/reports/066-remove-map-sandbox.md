# 066 · 删地图沙盒

> 作者拍板 ｜ 架构文档 v1.64 ｜ 前一步：[065 事件屏改版](065-event-screen-layout.md)

作者问：沙盒里进节点没有跳出内容、也没有棋盘，是没做还是 bug。答：沙盒是 `RunState` 的一层皮，踩点只写日志，本来就没有屏、没有棋盘。
再问：只保留生成，沙盒和地图编辑器的区别是什么。答：没有区别 —— 生成编辑器全覆盖且更强，沙盒独有的只有「走」和路线预览，而这两样正式游戏已经完整。作者：删吧。

## 删了什么

| 文件 | 处置 |
|---|---|
| `ui/map/map_sandbox.gd`、`.tscn` | 删除 |
| `ui/launcher.gd` | 少一项；剩正式游戏、背包沙盒、战斗沙盒、道具编辑器、事件编辑器、地图编辑器 |
| `tests/test_map_layout.gd` | `frame_sandbox` 删除。它验的是挑出生点、走一步、行动点、换种子，这些在 `test_map_travel` / `test_run_state` 里各有自己的用例 |
| `ui/game/map_screen.gd` | 头注释改一句 |
| 架构文档 11 节目录树、status.md | 去掉它 |

`ui/map/` 下的 `MapView`、布局、样式都留着 —— 正式游戏的地图屏和地图编辑器都在用，删的只是那一层皮。

## 以后

单独试地图上的机制（第 7 阶段的侵蚀）在正式游戏里加「开发者开局」（指定章节、种子、装备、直接落到地图），比再养一套壳子便宜。
