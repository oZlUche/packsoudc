# 226 全游戏「裸露文字」清查：每个字都要坐在一个 UI 件上

作者 2026-10-21 16:32（美术设计线）：「去掉所有界面里的裸露文字（即没有UI的文字）」。美术设计把结算屏处理掉了（224 末条：标题牌、副标题与说明行删），全游戏的清查交到这里。

## 〇 一句话

全游戏 38 个界面脚本加 HUD / 战斗 / 背包部件逐行看完：**约 150 处**文字直接写在背景画、地图纸、石板板身或粗布页身上，没有局部的牌。它们只分五类，**五件公共的事做完，九成就没了**；剩下的逐屏删或并进现有控件。本文 §二 是逐屏清单，§四 是派工。

怎么判的（和美术设计 `no-bare-text` 的口径一致）：
- **算在控件上**：按钮、页签、悬浮窗、名牌（`PANEL_NAMEPLATE`）、火漆签（`StatsStrip`）、道具格、`CapTile` 牌、`PANEL_DIFF_TITLE` 铜牌、翻页计数器、羊皮纸（`PANEL_PARCHMENT`）、便条（`PANEL_SUMMARY_NOTE`）、节点纸签（`PANEL_NODE_HINT`）、地图墨路签（`tag_paper`）、顶端栏（`slab_bar`）、`OverlayFrame` 的**标题条**、账目行、存档行（`PANEL_DARK` 一位一行）、铸炉底图里专门画给字的石带。
- **裸**：背景画、地图纸、`_slab_screen` 整屏石板、`OverlayFrame.content` 的板身、基地中列的粗布页身（`PANEL_HOME_BOX` 整列铺满那种）、`PANEL_GROOVE` / `PANEL_PACK_LEATHER` / `PANEL_STASH_FRAME` 这类装格子的大框的板身、`PANEL_BARE`（`StyleBoxEmpty`）、代码画的纯色块。
- **豁免**：`DevGate.on()` 才造的调试台、编辑器、沙盒；只在美术缺图时才出现的退路字（主菜单字标、便条）。
- 文案都在 `core/text/ui_text.gd` 的 `TEXT` 表（没有 text.json）。

## 一、五件公共的事

### 1.1 告示层：全游戏一种「回话」载体（最大的一块）

现状：地图屏的 `say / warn` 走顶端栏下面的提示行 `notice_widget`，它的变体是 `PANEL_BARE`，**字直接写在地图纸上**（map_screen 约 20 处调用）；而商店、神坛、科技页、仓库面板、保险箱、铸炉、出售页、开局屏、读档屏各自又养了一行裸的 `_line / _status / _hint`（`shop._line`、`altar._line`、`tech._line`、`warehouse_panel._line`、`safe._line`、`forge._line`、`meta._sell_line`、`setup._status`、`slots._hint`），腰带还有一个飘字 `belt.flash`，战斗面板底部有「▸ 刚出手的那件」。十一种载体，全裸。

定：
- 提示行从 HUD 挪到 **`GameDirector` 一层的「告示层」**（叠在所有屏之上、悬浮窗之下），`GameScreen.say(text) / warn(text)` 成为基类方法，任何屏都能喊；地图屏的 `say / warn` 改成转发；`HudHost.notice` 保留为转发（测试 `notice_widget()` 照旧能拿到）。
- 每一句告示坐在一张 **告示签** 上（美术设计出图：窄条羊皮 / 皮革签，浅、深两种底各一张九宫格，要紧的那种加朱红封蜡或红边），一句一签、上下叠、按秒淡出，位置仍在顶端栏下方居中；没有顶端栏的屏（基地、开局、读档、商店这类叠层）同一位置。
- 上面那十一处本地的回话行**全部删掉**，调用改成 `say / warn`。各屏列表见 §二。
- `InventoryPanel.hint_sink` 不再接各屏的本地 Label，默认就是宿主屏的 `say`。

### 1.2 统一标题牌

结算屏已定的标题牌（`art/ui/ledger/out/title_plate.png`，332×72 含边、字由代码写）**全游戏共用**：开局屏三页标题、设置屏「设置」、读档屏「读取存档」、结算第二页「置入仓库」。开局屏的页标题 「开局 · 一 / 三　选角色」 十二个字，28 号就要 340 宽，请美术设计出一张 **加宽版**（480×72）同款；或把页码拿掉只留 「选角色 / 配道具 / 选地图」（推荐，页码在页签上本来就有）。副标题一律删。基地「基地」二字删（左列页签已说明在哪）。标题需要但没有标题条的叠层（读档屏）也可以直接改走 `OverlayFrame` 的标题条。

### 1.3 段头签

段头（「角色」「预设装备」「仓库 N 页」「效果」「费用」「出售区」「祭品台」「显示」「声音」……）**默认删**：下面的控件自己说明自己。真要留的（设置屏的五个分区、图鉴页「特殊道具」、百科目录的分类名）用一张 **段头签**（小石牌 / 铜牌，美术设计出一张九宫格，字由代码写）。

### 1.4 正文垫纸

成段的正文不能删，也不能并进按钮：事件正文与结果行、章节规则卡、百科页、科技说明板、读档屏的修复报告。它们**垫一层羊皮纸**（`PANEL_PARCHMENT` 已有，挑战卷轴在用；科技说明板和百科页整块垫，事件正文的滚动框垫）。标题刻在纸头。

### 1.5 读数归位

读数不删，并进本来就该装它的控件：负重 → 火漆签（`StatsStrip` 的 LOAD 签已经在写）；每秒回 / 一块十点 → `StatBlocks` 的悬浮窗；带入上限 → `CapTile`；敌方生命 / DPS / 免疫 → 名牌副行（战前屏已由 UI替换美术做成签，核落地）；撤离确认的三行 → 三行账目（借 224 账单的行样，小号）；商店钱数 → 标题条右槽里的钱币牌（`OverlayFrame.add_slot`）；科技的钱和材料 → 账目行；音量 → 和 −/+ 合成一个步进件（同翻页计数器的做法）；出售预览 → 「一键出售」按钮第二行。

另外两件要美术设计出图：**商店价签**（挂牌，写价和尺寸；「已售」是同款盖戳）；**拖拽合成提示**和地图上猎手名、撤离点关闭字一起改用现成的 `tag_paper` 纸签（不用新图）。
