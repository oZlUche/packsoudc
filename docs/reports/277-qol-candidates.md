## 二、每条的边界

- **1**：键走 `InputMap` 的 `confirm`（已能改键），不新加动作；悬浮窗钉着、拖着东西、教程遮罩开着时不接。回放没播完时 Enter = 跳到结尾（同跳过键），再按一次才继续，免得一下按过头。
- **2**：「上回」= 上一次按「出发」时棋盘上从仓库带进去的那几件的 id + 位置 + 朝向，记在局外存档（`MetaState`），换角色后棋盘不一样就只摆得下的那些。预设装备不受影响。
- **3**：只在 `ON_MAP` 且没有待打的仗时生效；路线按步数最短；每走一步走现在的 `step_to`，不新写旅程逻辑，所以存档、动画、计数都不变。
- **4**：回购价 = 卖出价（不赚差价）；锁定 / 收藏的规则照旧。
- **5**：滚轮在拖拽时由拖拽层吃掉，不会同时缩放地图。
- **6**：不碰锁着的、不碰包；排法用现成的自动找位（`InventoryService.transfer_all_prefer`）。
