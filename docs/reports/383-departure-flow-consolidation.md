# 383 出征流程整合：四到五页并成两屏，每一项都能快速选（方案，待作者定）

> 日期：2026-11-22。基线：main，v7.87。只有文档，没有改代码。
> 作者 22:57：「删掉军需牌，具体的状态应该在出征中的每一步选择并确认，另外看看当前出征流程需要跳转的页面是否太多，考虑将复数功能塞进一个界面（选人/吃饭/选神）且都要有快速选择的功能」
> 作者 22:53（万神院样张）：「选择神明的界面应该是出战时才跳到的才对」。
> 上面是作者定的方向。下面怎么并、每一项怎么快速选，都是我填的建议初值。

## 一、一句话

出征从「基地出征页，再翻四页，万神院来了还要多一个选神界面」并成两屏：第一屏「出征准备」把选人、吃饭、选神、选地图难度放在一起，默认全是上回的选择，要换就在原地换；第二屏「配道具」摆棋盘，摆完出发。军需牌删掉，它上面的内容挪到用得着的那一步去看。

## 二、现状（查代码所得）

从点【开始探索】到真正出发，现在要经过：

| 步 | 页面 | 在这页做什么 |
|---|---|---|
| 0 | 基地「出征」页 | 军功碑、上回出征、军需、【开始探索】 |
| 1 | 选角色 | 角色列表、角色卡、棋盘预览（只看） |
| 2 | 配道具 | 预设装备、棋盘、地上、仓库、带多少现金；有「照上回带」 |
| 3 | 选地图与难度 | 地图、规模、难度、地图预览、出发摘要 |
| 4 | 本次准备（食堂或地图协会开了才有） | 材料倾向；这一锅只能换收藏，配菜要回营地的食堂页做 |
| 5 | 选神（万神院到来以后，报告 377，还没做） | 选这一局奉哪位神 |

问题有三个：

1. **页数多。** 老玩家每局要按四到五次「继续」，其中大多数页他什么都不改。
2. **只有道具能「照上回」。** 角色、地图、难度会默认上回的，但每一页仍然要翻过去；这一锅、材料倾向、神没有统一的「照上回」。
3. **军需牌放错了地方。** 它在基地出征页上列出科技发的随身技能和局外加成，但那时玩家还没选人、没配道具，看了也用不上，也没法在那里改。

## 三、方案

### 1. 两屏

**第一屏「出征准备」：一屏里并排几块，每块是一项选择。**

| 块 | 内容 | 什么时候有 |
|---|---|---|
| 角色 | 一排头像点选，下面是选中角色的卡（生命、耐力、体力、技能） | 一直有 |
| 地图 | 地图、规模、难度，带地图预览 | 一直有 |
| 这一锅 | 当前这一锅的名字、效果、饱腹；一排收藏点选 | 食堂开了以后 |
| 信仰 | 一排神的徽记点选，没解锁的显示「？？？？」；另有【无信者】一项 | 万神院到来以后 |
| 材料倾向 | 一排方向点选 | 地图协会的委托办成以后 |

- 没解锁的块整个不出现。新玩家的第一屏只有角色和地图两块，很干净；营地越建越全，这一屏才慢慢变满。
- 每块都是「看得见现在选的是什么，点一下就换」，不弹新页面。
- 这一屏不摆棋盘，所以放得下。

**第二屏「配道具」：和现在的第二页一样**，预设装备、棋盘、地上、仓库、现金。它需要整屏的地方给棋盘和仓库，所以单独一屏。右下角就是【出发】。

顺序是先准备、后配道具，因为棋盘的形状由角色决定，这一锅的效果也按角色算。

### 2. 快速选择

- **默认全是上回。** 进第一屏时，角色、地图、规模、难度、这一锅、神、材料倾向都已经是上回出征的选择。什么都不想改的人，按两次确认键就出发了（第一屏一次，第二屏一次）。
- **每块自己的快速选**：
  - 角色、神、材料倾向：一排图标，点哪个是哪个，不用进二级页。
  - 这一锅：一排收藏，点一份就照它重做；缺料的那份标出缺几样。要配一锅全新的，才需要回营地的食堂页，这是整个流程里唯一保留的跳转，而且不常用。
  - 地图：上回的图和规模默认选中；难度是加减两颗键。
  - 道具：现有的「照上回带」保留。
- **第一次用某一块时没有「上回」**：角色默认第一位，神默认【无信者】，这一锅默认空锅，材料倾向默认无。

### 3. 军需牌删掉以后，上面的东西去哪

作者：「具体的状态应该在出征中的每一步选择并确认」。

| 原来在军需牌上 | 挪到 |
|---|---|
| 科技每局发的随身技能 | 第二屏配道具，和棋盘放在一起（它们本来就是随身带的东西） |
| 科技给的局外加成 | 第一屏角色卡。加成直接算进角色卡的数字里，悬停看「基础加多少」，和状态界面的写法一致（报告 381） |

基地出征页只剩军功碑、上回出征、【开始探索】。

### 4. 选神放在这里，和报告 377 怎么接

作者 22:53 定了选神是出征时的一步，不是营地里的常驻页。按这份方案，它不再是单独跳出来的一个界面，而是第一屏里的「信仰」块。万神院刚到来后的第一次出征，这一块第一次出现，教练层在这里指一下，帮助页的截图也截这一块。

## 四、三个方向

- **A 两屏：出征准备一屏，配道具一屏（建议）。** 上面写的就是它。
- **B 一屏到底：** 把棋盘和仓库也塞进同一屏。只按一次确认，但棋盘、仓库、地图预览、角色卡、这一锅、神全挤在一起，1920 宽也放不下不缩小的仓库，内容多时一定越界，和作者刚提的「信息完整不杂乱、组件不越界」冲突。
- **C 页数不变，只加总的「照上回」：** 基地出征页多一颗【照上回出征】，一键出发。改动最小，但想改一项的人仍然要翻四五页。

我建议 A，再加上 C 里那颗键作为可选项（见下面第 2 个问题）。

## 五、要改的地方（给执行线程）

- 开局屏从四页改成两页：原第一、三、四页的内容并成一页的几块，原第二页不变；翻页、返回、回车和 Esc 的规则照旧。
- 「上回的选择」现在只记了角色、地图、规模、难度、带的道具；要补记这一锅用的哪份收藏、材料倾向、奉的神。

- 万神院执行线程的选神界面改成这一屏里的一块（它还没做到这一步，正好接上）。
- 统一教程里指着「第一页、第三页」的教练步骤要跟着改位置。
- 样张请 UI设计 出：第一屏在「只有两块」和「五块全开」两种情况下各一张；无裸文字、面板声明明暗照旧。

## 六、担忧

1. **第一屏五块全开时会不会挤。** 每块都只留「当前选择加一排可点的图标」，细节放悬停窗，应当放得下，但要看样张。放不下的话，这一锅和材料倾向可以收成一行、点开再展开。
2. **默认上回，会不会让人不看就出发。** 比如上回那份收藏这次缺料了。所以缺料、神被换了档位之类和上回不一样的地方，要在那一块上标出来，并且在出发前的摘要里提一句。
3. **流程改动碰到教程。** 序章一、二里有指着开局屏的教练步骤，要一起改，不然新玩家会被指到不存在的地方。
