## 〇、先答作者的两问

### 0.1 「初始包」确实和现行设计冲突

| | 原设计（136 / 179） | 现行（[225](225-carry-in-freedom.md) 补充一，v3.8x 起） |
|---|---|---|
| `CharacterDef.starting_bags` 干什么 | 每局开局摆在棋盘上，带入的东西只能放进它们 | **只在第一次选这个角色时发进包架**（`MetaState.grant_starting_bags`，每个存档位每个角色一次）；之后每局的包全由玩家从包架拖上棋盘，棋盘上的包撤离后回包架 |
| 选角色卡上怎么显示 | 「背包：皮革包 × 2」一行（179 §2.4 已删） | 什么都没显示 |
| 和「角色 = 初始面板 + 技能」的关系 | 包是角色身份的一部分 | 包是**玩家的财产**，不再是角色的；`run_state.start` 里 `p_character.starting_bags + kit` 那一支只在没有开局屏摆盘（`p_layout` 空：测试、直开）时才走 |

所以 254 把「初始包」列为角色维度是**过时的**，这里改正：**包不再算角色的一样东西**。`starting_bags` 字段留着，意思改成「首次见面礼」：第一次选他时送进包架的包。选角色卡上用一枚小签「首次赠包：皮革包 ×1、小包 ×1」说明一下，而且**只在还没送过时显示**（送过了这一行消失）。棋盘预览**只画形状**，不画包。

要不要干脆删掉 `starting_bags`：不删。它解决「新档没包开不了局」的问题（225 §9.4 第二条的兜底 `sack` 也在），零成本。

### 0.2 「开局就有、拿不下、丢不掉」的道具 —— 叫它【随身之物】

正合角色设计的空缺：254 的十二个草案里有好几个本来就该是这种东西（失控造物的「核心」、弃信者的「断裂的信物」、血斧蛮族的「血斧」、军团魔法师的「军团法印」）。它一次给三样：**特色**（这件东西的规则）、**代价**（占格、拿不下）、**棋盘形状感**（和缺格一起让每个角色的棋盘一眼能认）。像 Backpack Hero 的角色固有物与诅咒格、以撒的角色初始道具。

机制写在 §三，排版写在 §二。

## 一、现状（v4.47 核过代码）

`ui/game/setup_screen.gd` `_build_character_page()`：三栏 `_hbox(36)`。左 皮革板 `_framed(PANEL_PACK_LEATHER, FRAME_INSET=44)` 宽 260，装角色列表；中 皮革板撑满，装 `_card`；右 凹槽 `_groove(10×4)`，装棋盘预览，宽 = `board_size.x × 60 + 2 × (10 + frame.inset())`，`SIZE_SHRINK_END`。

`_rebuild_card()` 自上而下：头像 160 + 名牌（名 / 「角色」/ 头像 96）→ 生命 / 耐力（+「每秒回 N」）/ 体力 三行 `StatBlocks` → `setup.block_note` 灰字 → `CapTile` 小牌（负重、棋盘 N × M；开局金币那块 2026-10-22 删了）→ `carry_caps_text`（带入件数 / 稀有度上限，有值才出）→ 技能两条（名 22 黄铜描边 + 说明折行 300）。右栏 `InventoryView`（`show_adjacency=false`）套 `BoardFrame.wrap`。

**没有的**：短板一栏；任何「钉死」的道具；棋盘缺格（`GridInventory.set_blocked` 只给自由容器用，`CharacterDef` 没有形状字段）；法力等别的面板项（`base_stats` 任意键都能写，卡上只读三项）。

### 2.3 右栏棋盘预览

1. 棋盘框 `frame_player` + 格线（227 规矩）。**缺格**画成深色实心格（像现在的「不可用」格 `COLOR_BLOCKED`，不是空洞），**随身之物**按它在 `fixed_items` 里的位置、朝向、尺寸实画道具图，加一道描边角标（钉）。
2. 框下题字一行（板上，不裸）：「棋盘 8 × 6 格　可用 46 格」—— 可用 = 总格 − 缺格 − 随身之物占格。缺格与随身之物都没有时只写「棋盘 8 × 6 格」。
3. 图例两枚小字签：「不可用格」「随身之物」，只在棋盘上有对应东西时显示。
4. **羊皮小签「首次赠包」**（新，0.1）：「首次选他：皮革包 ×1、小包 ×1 进包架」，`MetaState.bag_grants` 里已有他就不显示。

## 三、要补的数据与机制

### 3.1 短板 `flaw`

`CharacterDef.flaw: RunSkill`（一条，被动型；没有主动部分）。它和 `skills` 里的被动走**同一套构件**（`RunEffect` / `AbilityRule` / `LootEffect`），只是编进 `run_effects()` / `combat_rules()` 时一并算进去，界面上单列。这样「穿不了防具」= `banned_tags: ["armor"]`（254 要补的构件），「侵蚀 ×1.5」= 现成的倍率效果，不必再发明一层。
导入器：`flaw` 必填（`report.error`，像 `starting_bags` 那条）；现有三人要补文（待定一）。

### 3.2 随身之物 `fixed_items`

```json
"fixed_items": [
  {"id": "legion_sigil", "origin": [2, 0], "rot": 0}
]
```

| 环节 | 规矩 | 落点 |
|---|---|---|
| 开局 | `RunState.start` 在 `place_layout` **之前**先摆 `fixed_items`（它们不经开局屏布局、不进 `layout_of`），然后 `board.pin(uid)` | `run_state.gd` 开局段 |
| 覆盖 | 随身之物**自带底板**：它占的格视为被自己覆盖（`_bag_owner` 写成自己的 uid 或新开一张 `_pinned` 表让 `is_covered` 放行），不需要包；包**不能**压到它的格上（当障碍绕开）；相邻效果照常跨过去（它和旁边包里的东西算相邻） | `grid_inventory.gd` |
| 拖拽 | `GridInventory.is_locked(uid)` 对它答真（207「扎根」已有这条路：`drag_layer.gd` 166 直接拒绝），提示换一句「它是你的随身之物，拿不下来」（新键 `notice.pinned`） | `drag_layer.gd`、`ui_text.gd` |
| 右键菜单 | 不参战 / 锁定 / 出售 / 丢到地上 / 献祭 / 进铸炉 全灰，理由「随身之物」 | `item_actions.gd` |
| 开局屏第二页 | 棋盘上已经有它，`InventoryService` 搬家（一键置入、拖回）跳过它 | `inventory_service.gd` 231 那条分支 |
| 撤离 | 棋盘带回基地时**不收它**（`absorb` 跳过，不进仓库、不进包架、不进图鉴）；下一局开局再发 | `meta_state.gd` |
| 战败 | 无事（本来就不保存） | — |
| 结算页 | 第二页「带回来的棋盘」里画着但发灰，题字「随身之物随你回营」；不计价值 | 结算第二页 |
| 战斗 | 正常编译参战（它是角色能力的载体）；**不能标不参战** | `combatant_spec` 无改 |
| 画法 | 棋盘上一枚小钉角标（像 230 锁定的小锁、244 不参战的小字）；工具提示末尾一行「随身之物：拿不下、丢不掉」 | `item_painter.gd`、`item_tooltip.gd` |
| 存档 | 开局重建，不进存档结构；`fixed_items` 改动走 `IdAliases`（173） | — |

**一件随身之物也可以是「坏东西」**：比如 2 × 2 的「诅咒偶像」什么都不做只占格 —— 那就是纯短板。它和 3.1 的 `flaw` 可以是同一个角色的两面：法印既给法阵，又占三格。

### 3.3 棋盘形状 `board_mask`

`CharacterDef.board_mask: Array[Vector2i]`（缺格坐标，默认空 = 整块矩形）。`RunState.start` 建棋盘后 `set_blocked` 这些格（作战棋盘现在 `set_blocked` 只给自由容器用，要放开给 `requires_bag` 的板；逻辑本来就通用）。基地带回来的棋盘照原样带回（它就是这块板）。预览与第二页都用同一块 `GridInventory`，自然一致。导入器：缺格不得与 `fixed_items` 重叠、不得超界。

## 五、待定（默认按推荐）

1. **现有三人补短板文**：推荐 **补**，各一条轻的、和描述里已有的弱点一致 —— 马库斯「不懂药」（治疗类药水效果 ×0.5）、安德烈乌斯「身子薄」（护甲上限 −20%）、布鲁图斯「回气慢」（已是面板，可改成明写「耐力低于两成时不触发任何回气效果」）。文案另开补充一，等作者点头再写进 json。
2. **随身之物能不能被敌人打坏 / 磨损**：推荐 **不坏**（`wear` 不写，耐久不计），否则「拿不下」就成了死局。
3. **随身之物相邻规矩**：推荐 **算相邻**（它和邻格包里的东西互相触发），这是它当「法阵核心」的前提。
4. **包能不能盖住随身之物**：推荐 **不能**（当障碍），实现最简，也让占格真的是代价。
5. **名牌里放回角色说明那一句**：推荐 **放**（179 当时是嫌挤，现在名牌宽 ≥ 416）。
