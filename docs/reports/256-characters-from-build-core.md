# 256 角色重梳（第二稿）：先定每个角色的玩法流派核心，再推能力与机制

作者（2026-10-26 13:59）：「我并不认为给每个角色设计短板是必须的，因此初始的三个角色没必要有短板。短板是用于改变游玩决策的设定，不要盲目的添加。重新梳理现有的角色和角色方案，从一个核心玩法要素开始，然后拓展并落实机制」。
作者（14:37，否了第一稿）：「你说的这个所谓一格是架构，更像是角色该如何跟游戏底层机制结合，我的意思是角色本身的玩法流派核心是什么，先从这里出发」。

第一稿从「棋盘一格」出发，被作者指出那是接底层的方式，不是角色。第二稿改从**流派**出发：先说清一个角色**靠什么打赢、靠什么赚、专门找什么东西**，再推被动，最后才说怎么接到棋盘与战斗。第一稿的三条棋盘构件留在附录，谁的流派用得上就用。

本篇只写方案，不实装。三人短板已撤（255 补充三，v4.51）。

## 〇、规矩（据作者原话改 136 / 254）

1. **短板不是必备项**（136 那条作废）。只给「改了它玩家就换打法」的角色。
2. **先流派，后能力。** 一个角色先写一句「流派核心」= 打赢靠什么 + 赚钱靠什么 + 专门找什么；被动必须让这句话成立，不服务这句话的被动退掉。
3. **流派要有货。** 道具池里得有够多的东西喂它（下面每条都数了现有件数）；不够的列成要补的内容，不靠被动硬撑。
4. 其余不变：角色 = 初始面板 + 技能（136），科技全局（149），主动藏着（166），包是玩家的（225），随身之物 / 缺格可用（255）。

## 二、现有三人：流派核心一句话，再配被动

面板沿用现值。每人**两条被动**：一条是引擎（让流派转起来），一条是出路（这派怎么赚、怎么撤）。原来三条里和流派无关的退掉（待定一）。

### 2.1 马库斯 · 兵刃

**流派核心**：堆近战武器，一排刀一起出手；靠打赢拿钱，所以主动找敌人。专门找：快武器（rapid）、第二第三把刀。

| | 内容 | 实现 |
|---|---|---|
| 面板 | 生命 55、耐力 65、回气 5、体力 5、8 × 6、负重 48 | 不动 |
| 引擎 **军阵**（新） | 同一横排左右相邻的武器互为战友，每有一个战友急速 +{haste_per_ally}%（推荐 8） | 附录 A `row_allies` |
| 出路 **军功**（留） | 战斗胜利金币 +25% | 现成 `battle_reward_mult` |
| 退 | 操练（耐力低于两成回 30，每场一次） | 和「多刀成阵」无关；要留就当第三条（待定一） |
| 为什么是流派 | 玩家会为了凑一排刀而不拿更好的单件；路线上专挑有敌人的点 | |

### 2.2 布鲁图斯 · 铁壁

**流派核心**：穿满防具、举盾，靠护甲层把伤害吃掉，慢慢磨死对手；靠扛得久走得深，撤得晚。专门找：防具、盾、修甲的东西。

| | 内容 | 实现 |
|---|---|---|
| 面板 | 生命 70、耐力 55、回气 3、体力 7、9 × 6、负重 56 | 不动 |
| 引擎 **披挂**（新） | 棋盘上每一件防具或盾，护甲上限额外 +{armor_per_piece}（推荐 4）；多穿多得，不叠格挡 | 附录 A `tag_count`（tags armor / shield → `max_armor` flat） |
| 出路 **坚韧**（留） | 生命低于一定比例时立即获得护甲，每场一次 | 现成 |
| 退 | 野地里长大（休息多回体力） | 体力 7 已是「扛得住」 |
| **要补的内容** | 防具只有 3 件、盾 4 件，撑不起一派：至少补 **防具 3（锁甲 / 皮护腿 / 铁头盔）+ 盾 1（小圆盾 1 × 1）**，含 1 × 1、1 × 2、2 × 2 各形，让「披挂」有东西挂；铁匠铺配方各一条（252 的路） | 另开补充 |

### 2.3 安德烈乌斯 · 毒刃

**流派核心**：一刀见血就走，让流血和中毒替他打；少打硬仗，多搜、多走、溜得掉。专门找：带流血 / 中毒的武器与药、远程。

| | 内容 | 实现 |
|---|---|---|
| 面板 | 生命 45、耐力 55、回气 4、体力 5、7 × 6、负重 40 | 不动 |
| 引擎 **淬毒**（新） | 本方施加的流血与中毒造成的伤害 +{dot_percent}%（推荐 50） | `AbilityRule`：`on_before_damage`（本方、伤害来源为 bleed / poison 状态）→ `modify_damage` +50%；不新开构件。注意导入器拦「听 X 施 X」自环，所以不用「每层多叠一层」那种写法 |
| 出路 **溜得掉**（留） | 逃跑 +25%、猎手感知 ×0.75、首次战败不扣体力 | 现成 |
| 退 | 熟门熟路（每走四步免一步） | 和毒无关；要留就当第三条（待定一） |
| 为什么是流派 | 他不比谁刀快，比谁的状态挂得多；打一下就撤也划算 | |

|---|---|---|---|---|---|---|

## 四、落实（第一批：三人）

1. 构件 `BoardEffect`（附录 A）两种：`row_allies`（军阵）、`tag_count`（披挂）。编译玩家时跑一遍，拿 `GridInventory` 产 `StatModifier`；注册 `RunRegistry.BOARD_EFFECTS`，`RunSkill.passive` 允许混放。
2. 安德烈乌斯「淬毒」用现成 `AbilityRule`，不新开构件。
3. 三人 json：换被动（退掉的三条按待定一处理）；选角色卡自动跟着（255 的一种行）。
4. 技能图标三枚新（军阵 / 披挂 / 淬毒）→ 美术设计；执行先占位。
5. 内容：布鲁图斯那一派补 **防具 3 + 盾 1**（另开补充，含形状、重量、价、配方；道具图 → 美术）。
6. 数值全走 `{占位}`；242 台架跑三人各 200 局再调。

## 五、待定（默认按推荐）

1. 退掉的三条（操练 / 野地里长大 / 熟门熟路）：推荐**退**，两条都服务流派；作者要留就各当第三条。
2. 披挂叠护甲上限还是格挡：推荐**护甲上限**（153：护甲是层、格挡是盾专属的减伤，叠格挡会让盾卫味太重）。
3. 第四人先做谁：推荐**军团魔法师**（池最满、255 的缺格 / 法印正好用上）。
4. 第七人弃信者还是虔信者：推荐**弃信者**。

## 六、测试

1. 军阵：三把剑横排 → 中间 +16%、两侧 +8%；竖排 0；隔一格 0；悬浮窗「军阵 ×N」。
2. 披挂：棋盘上 2 防具 + 1 盾 → 护甲上限 +12；地上的不算。
3. 淬毒：流血每跳伤害 ×1.5；对方自己中的毒不算。
4. 三人开局无短板 buff；卡上各两条技能。

## 附录 A：棋盘被动构件 `BoardEffect`（第一稿留下的接底层方式）

```json
{"type": "row_allies", "tag": "weapon", "mods": [{"stat": "haste", "mult_category": 3, "mult_percent": 8}]}
{"type": "tag_count", "tags": ["armor", "shield"], "mods": [{"stat": "max_armor", "flat": 4}]}
{"type": "board_fill", "per_cells": 10, "mods": [...]}      // 第一稿的满载，暂不用
{"type": "board_empty", "per_cells": 4, "flee_percent": 5}   // 第一稿的轻身，暂不用
```

`row_allies`：对每件命中 `tag` 的物品，看它占的每一行左右紧邻（x ± 1、同 y）是否有另一件命中 `tag` 的物品，战友数 = 不同物品数，`mods` × 战友数挂到这一件。`tag_count`：数棋盘上命中任一标签的物品件数，`mods` × 件数挂到单位。都在 `BattleCompiler.compile(board, …)` 里跑，随身之物算、地上不算。
