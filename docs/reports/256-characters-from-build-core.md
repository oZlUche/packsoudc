# 256 角色重梳（第二稿）：先定每个角色的玩法流派核心，再推能力与机制

作者（2026-10-26 13:59）：「我并不认为给每个角色设计短板是必须的，因此初始的三个角色没必要有短板。短板是用于改变游玩决策的设定，不要盲目的添加。重新梳理现有的角色和角色方案，从一个核心玩法要素开始，然后拓展并落实机制」。
作者（14:37，否了第一稿）：「你说的这个所谓一格是架构，更像是角色该如何跟游戏底层机制结合，我的意思是角色本身的玩法流派核心是什么，先从这里出发」。

第一稿从「棋盘一格」出发，被作者指出那是接底层的方式，不是角色。第二稿改从**流派**出发：先说清一个角色**靠什么打赢、靠什么赚、专门找什么东西**，再推被动，最后才说怎么接到棋盘与战斗。第一稿的三条棋盘构件留在附录，谁的流派用得上就用。

本篇只写方案，不实装。三人短板已撤（255 补充三，v4.51）。

## 〇、规矩（据作者原话改 136 / 254）

1. **短板不是必备项**（136 那条作废）。只给「改了它玩家就换打法」的角色。
2. **先流派，后能力。** 一个角色先写一句「流派核心」= 打赢靠什么 + 赚钱靠什么 + 专门找什么；被动必须让这句话成立，不服务这句话的被动退掉。
3. **流派要有货。** 道具池里得有够多的东西喂它（下面每条都数了现有件数）；不够的列成要补的内容，不靠被动硬撑。
4. 其余不变：角色 = 初始面板 + 技能（136），科技全局（149），主动藏着（166），包是玩家的（225），随身之物 / 缺格可用（255）。

## 附录 A：棋盘被动构件 `BoardEffect`（第一稿留下的接底层方式）

```json
{"type": "row_allies", "tag": "weapon", "mods": [{"stat": "haste", "mult_category": 3, "mult_percent": 8}]}
{"type": "tag_count", "tags": ["armor", "shield"], "mods": [{"stat": "max_armor", "flat": 4}]}
{"type": "board_fill", "per_cells": 10, "mods": [...]}      // 第一稿的满载，暂不用
{"type": "board_empty", "per_cells": 4, "flee_percent": 5}   // 第一稿的轻身，暂不用
```

`row_allies`：对每件命中 `tag` 的物品，看它占的每一行左右紧邻（x ± 1、同 y）是否有另一件命中 `tag` 的物品，战友数 = 不同物品数，`mods` × 战友数挂到这一件。`tag_count`：数棋盘上命中任一标签的物品件数，`mods` × 件数挂到单位。都在 `BattleCompiler.compile(board, …)` 里跑，随身之物算、地上不算。

## 七、补充一（作者 2026-10-26 15:06）：布鲁图斯回容错、马库斯做勋章、安德烈乌斯先出方向

作者原话：「布鲁图斯的方案不好：1. 背包空间有限，大部分的盾牌和护甲都非常占格子，这也是你提到的要补，在我看来是根本性原因，护甲和盾牌的体积不可能缩小 2. 护甲不能抵消鏖战的百分比扣血，拖入加时反而不利。布鲁图斯应该延续之前的高体力值设计，作为一个纯粹的容错角色。马库斯的军功和军阵可以结合，设计一个独立的特殊道具【勋章】（或者更加符合时代的东西），每场胜利累积荣誉点，一定点数可以升级，每次升级提升道具周围的武器伤害/急速/耐力降低幅度，增益槽也可以从周围四格升级成八格/十二格。安德烈的设计应该更倾向于避战，所以可以不受惩罚的逃跑，但要和布鲁图斯的容错作出差异，先头脑风暴几个方向给我看一下」。

**流派核心**：犯错不死。打输一场、走错一条路、背太重，他都缓得过来；靠体力值走最深。专门找：回体力的、休息点。

### 7.2 马库斯 · 军功牌（勋章）

**流派核心**：打赢一场，牌上记一笔；牌越亮，牌边的刀越狠。靠连胜滚雪球，所以主动找敌人。专门找：能放进牌边格子的武器。

**名字**：罗马军团的勋章就是挂在胸甲皮带上的青铜圆牌 phalera，中文照字面叫 **军功牌**（推荐）；另两个备选：**鹰徽**（军团鹰 aquila，更像旗不像奖）、**橡叶冠**（corona civica，救袍泽者的荣誉，和「打赢」不对）。下面按军功牌写。

为什么是流派：第一场打谁、要不要绕路多打一场、刀往牌边摆还是往成套摆 —— 都因为这块牌而变。

### 7.3 安德烈乌斯 · 避战：六个方向（作者挑）

和布鲁图斯的分界：**布鲁图斯是打输了也扛得住（事后），安德烈乌斯是不该打的根本不打（事前）**。所以他的东西都在「开打之前」和「打到一半」，不在「打输之后」。六个方向都以 248 的逃跑（现 0.5 几率、失败扣体力 + 虚弱）与 136 的脱身为底，每条一句核心、靠什么赚、差在哪、怎么做。
