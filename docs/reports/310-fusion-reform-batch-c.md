## 二、第二步：9 张拖合配方迁为贴着点锤（v5.97）

照方案 §4.1：9 张拖合配方（涂毒匕首 + 八条生存道具）recipe_id 与输入、成品都不变，只改成 `adjacent`，和 279 的拼接走同一条路：贴着放 → 接缝浮出小锤 → 确认窗（A 批那张纸条，未知成品打问号）→ 合成。

| 改了什么 | 说明 |
|---|---|
| 配方 9 张 | `adjacent: true`；note 里「把 A 拖到 B 上」改成「A 贴着 B 放、点锤」，后半句照旧 |
| 删拖合 | `CraftingModule.craft / output_of / note_of`、拖拽层的 `craft*` 接口、拿起时「能合的那几件亮一圈」都删了；拖到能合的那件上放手 = 普通顶替 |
| 只剩一种配方 | `RecipeDef.find` 只找贴着的；导入器拒绝 `adjacent: false`，测试查全部配方都是贴着的 |
| 商店 | 原来「没成交的货不能压上去合」（审查 A1）挂在拖拽层上，现在挂到背包面板 `fuse_filter`：没成交的货旁边不浮锤、点了也不合；成交后重算 |
| 文案 | 帮助「合成」页、词条「合成」、序章三处教程字句（tut_elite 提示、tut_search_2_again_1、tut2_search_2_again_1）改成贴着点锤；流程不变 |

要知道的：

- **序章里匕首旁边常常没空格。** 走查测试按种子走到精英时，匕首四周都占着，要先把挡着的一件挪到地上才摆得下毒药瓶。玩家照提示也得这么做；教程的具体指引由「实装常规事件第一批」那边写（切片 S2 的「配方统一确认」也接在这一步后面）。
- 拖合时地上的那件可以直接压到棋盘上那件上合；现在两件都得在棋盘上贴着。
- 拿起一件时的高光删了：贴着才出锤，未知配方本来也不该提前点亮（方案 §6.2）。
- 测试：test_tutorial2（两个合成用例改成点锤 / 拖上去是顶替）、test_prologue（两条走查改成摆旁边点锤）、test_fusion_lore_305、test_upgrade_tiers、test_author_087（商店过滤）、test_anvil_recipes_279、test_fusion_reform_c。

## 三、第三步：铁匠铺材料带件数，15 件金武可打造（v5.98）

照方案 §5.1 和 307 第四节：

| 改了什么 | 说明 |
|---|---|
| `SmithRecipeDef.material_slots` | 新字段，一格一条 `{material, min, count}`：门槛和件数分开写；同一类可以写两格不同的门槛。旧的 `material_inputs` 照旧读作「一件、最低稀有度」 |
| `slots()` | 两样合在一起的全部材料格，界面、扣料、审计都走它 |
| 分配 | `Smithy.slot_picks`：一件只顶一格；要求高的格先分、候选从低档到高档；用增广路找最大分配，不会因为先占了稀缺的那件而打不了（测试里帝国佩剑：苍白碎片留给 ≥金 格，紫格用秘银锭） |
| 品质 | 写在新格里的材料不升品质，出件固定 0（方案 §5.3）；旧的一类一件格照旧按「高几档升几档」 |
| 导入 | 新格只认 material / min / count 三个键，件数至少 1，要有能顶的道具；只写材料格、不写 inputs 的配方也能导 |
| 铁匠铺界面 | 每格一个材料位，数牌「有几 / 要几」照件数写 |

新配方（全部铁匠铺 3 级、300、不要科技、固定品质 0）：

| 配方 | 需求 |
|---|---|
| 14 张元素金武 `forge_*`（火 7、冰 3、雷 4） | 同族魔晶石 ≥紫 ×1 + 成品材料（金属或骨）≥蓝 ×2 |
| `forge_imperial_sword` 帝国佩剑 | 金属 ≥金 ×1 + 金属 ≥紫 ×1（≥金 的金属只有苍白碎片，打过 Boss 才进掉落，同 307 §五.1） |

两张吃前驱武器的旧打造配方：

| 配方 | 原来 | 现在 |
|---|---|---|
| 秘银剑 `smith_mithril_sword` | 长剑 + 秘银锭 ×2 + 低阶火晶 | 秘银锭 ×2 + 低阶火晶 + 金属 ≥绿 ×1（长剑是绿金属，同档补） |
| 大魔导杖 `smith_grand_magus_staff` | 魔导杖 + 秘银锭 ×2 + 高阶火晶 | 秘银锭 ×2 + 高阶火晶 + 木 ≥蓝 ×2（魔导杖是紫木，但库里没有紫木，用两件蓝木补） |

要知道的：

- 这两处补料是我按「同档补足」定的初值，作者想改直接改 json。
- 15 件金武的旧砧升级配方还在，D 批统一关；现在两条路都能拿到。
- 测试：新增 `tests/meta/test_smith_counts_310.gd`（件数、两档同类、一件不顶两格、锁定、品质 0、导入报错、15 张内容）；test_smithy_251、test_recipe_techs_252、test_anvil_recipes_279 相应更新。没有截铁匠铺界面图。

## 四、第四、五步：改名「不进随机来源」，首轮经济对照（v5.99）

**改名。** 标签 `forged_only`（只能锻造）改成 `no_random_source`（不进随机来源），`ItemDef.is_no_random_source()`；意思从「只从砧上来」变成「只从合成或打造来」。18 件道具（3 件局内限定 + 15 件材料打造）跟着改；标签是道具定义上的，存档不受影响。

**来源核对。** 生成池（搜索、掉落、商店、敌人装备、集市都从 `ItemDatabase.ids()` 抽）照旧拦；另加测试扫 `res://data` 下全部作者数据：这 18 件除了道具本身、拼接配方、铁匠配方，没有别处点名（事件奖励池、集市、地图、章节开局、敌人固定装备都没有）。信仰赠物与赐福只从已有的东西派生，碰不到它们。

**首轮经济对照**（方案 §9.3 的「打造 → 出售套利」那一项）：新工具 `tools/forge_economy.gd`，结果在 [research/evidence/2026-11-12-fusion-reform-c/forge_economy.csv](research/evidence/2026-11-12-fusion-reform-c/forge_economy.csv)。按最便宜的一套料算，比较「打了在基地卖」和「料直接在基地卖」：

| 成品 | 基地卖价 | 打了再卖多赚（资金 300 时） |
|---|---|---|
| 处刑巨刃、刽子手巨斧、陨铁大锤（焰纹）、霜纹骨钢双手剑、雷纹骨铁大棒 | 900 | **+410** |
| 焰纹复合弓 | 600 | +110 |
| 骨钢矛、龙骑枪、斩马戟、破城矛（各元素） | 500 | +10 |
| 其余五件、帝国佩剑 | 400 / 600 | −90 / −138 |
| 秘银剑、大魔导杖 | 225 / 300 | −212 / −635 |

卖价 900 的五件每打一次净赚约 410，等于一颗紫魔晶石加两件蓝料就能在基地刷钱。**我把这五张的资金从 300 提到 750**（多赚变成约 −40）；其余照 307 的 300 不动。这是我按「打了再卖不该比卖料赚」定的初值，作者想换别的口径（比如按成品定价算资金）直接改 json，再跑一次工具。

还没做的（方案 §9.3 其余几项）：本局遇见可合成机会、完成比例、q0/q1/q2 战力对照、地图供给统计，留到 F 批联合验收，和执行（二）的难度复测一起跑。
