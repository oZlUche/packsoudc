# 开局带入要不要放开：预算、自由度、乐趣与难度（225）

> 架构 thread，2026-10-21。作者：「思考一下是否需要放开开局的背包限制，让玩家可以自由将仓库里的东西全部带上。以三角洲行动为例，玩家可以出门带上高级装备，虽然提升战斗力但是也有丢失的风险，这跟我们的游戏风格相似吗？我们要这么做吗？其他搜打撤类游戏呢？头脑风暴一下取舍、自由度、乐趣、难度。记住未来我们也会开放更高难度。」
> 这一份只讨论和给建议，不改代码；作者定了再派执行（若按推荐，落地只是改两份章节 JSON）。

## 一、现在到底限了什么

「开局的背包限制」其实是五层，硬软不一：

| 层 | 规矩 | 硬 / 软 | 出处 |
|---|---|---|---|
| 棋盘 | 角色棋盘 7×6 / 8×6 / 9×6，放得进的就是带的 | 硬（物理） | 067 / 149 |
| 包 | 仓库不收包，所以**包进不了局**；包的格子只能在局里捡 | 硬 | 090 / 093 |
| 件数 / 稀有度 | `CharacterDef.carry_max_items` / `carry_rarity_cap`，现在三个角色都是 −1（不限） | 硬（但没启用） | 082 |
| 负重 | 角色上限 40 / 48 / 56（科技「扛重」加），超 1.2 / 1.6 / 2.2 倍三级减急速、耐力回复、耐力上限，最后一级走路翻倍 | 软 | 129 / 161 补充一 |
| **带入预算** | 从仓库带的道具总价值 ≤ 600（自由模式、沙漏章都是 600），每超 50 价值全局倒计时 −1，有倒计时的至少留 1；预设套与初始包不算 | 软 | 094 |

丢失的那一面：死了棋盘上的东西全没（保险箱 3×3 + 科技加格的除外，保险箱里的视为已带出）；地上的东西撤离时就没了（224 刚把 092 的「一键出售」撤掉）；仓库里的东西卖只值一半；没有保险、没有找回。

所以作者问的「放开」，具体就是一件事：**要不要去掉 094 的价值预算**。棋盘、包、负重三层本来就在，放开之后「全部带上」的物理上限仍是一块 9×6 的棋盘加 56 的负重，不是整个仓库。

## 二、别人怎么做（我的理解，按记忆写，没查新资料）

| 游戏 | 带入 | 丢失 | 安全阀 | 带得多之后 |
|---|---|---|---|---|
| 三角洲行动 · 烽火地带 | 完全自由，带什么都行 | 死了全掉 | 安全箱（小格、死了也带出）、装备保险（没被人捡走就退回）、每日免费套 / 便宜「鼠鼠」局、配装码一键买 | 地图分 常规 / 机密 / 绝密，深图有入场门槛和更贵的战利品；对手（真人）也带得多 |
| 逃离塔科夫 | 完全自由 | 全掉 | 安全箱、保险、Scav 局（免费角色、免费装备）、藏身处成长 | 没有分档，靠真人互相制衡；「装备恐惧」是核心体验 |
| 暗区突围 | 自由，但**入场有装备价值门槛**（封锁区要带够） | 全掉 | 安全箱、保险 | 按装备价值分区匹配，带得多进贵的区 |
| Hunt: Showdown | 猎人 + 装备自由 | 猎人连同装备一起没 | 免费猎人、威望重置 | 靠真人、靠血线等级分段 |
| Dark and Darker | 自由 | 全掉 | 免费新手套（Squire）、按装备分（普通 ≤ 某装备分 / 高注局） | 装备分决定进哪一档，带得多就遇到带得多的 |
| 单机搜打撤（Zero Sievert 这类） | 自由 | 全掉（难度选项可改成不掉） | 存档 / 难度开关 | 靠地图分区与敌人强度表 |
| 背包类 roguelike（Backpack Hero 等） | 没有局外带入 | 一局即一局 | — | 不是搜打撤 |

共同点很清楚：**搜打撤没有一家在开局用「预算」限制带入**。它们都是「带什么随你，死了全没」，然后用三样东西防止玩家被自己的恐惧或贪婪压垮：① 安全箱（保底），② 免费 / 便宜的轻装局（翻身），③ **分档**（带得多就进更贵、更险的图，而不是在同一张图上更轻松）。带入和风险的平衡是由「图的档」和「对手」来做的，不是在出发前收税。

## 三、和我们像不像

像的地方：局外仓库、带进去的会丢、保险箱、撤离点，骨架是一样的；「用自己攒的东西组战力」正是 094 当时坚持保留自由搭配的理由。

不像的地方有三处，决定了不能照抄：

1. **我们是单机 PvE，战斗是自动结算**。三角洲里带高级装备仍可能死在真人枪下；我们这边一旦棋盘够强，战斗几乎没有悬念。「全带上」在同一张图上会从「冒险」变成「碾压」，死亡损失这把刀就砍不到人了，紧张感随之消失。
2. **我们的「图」现在不分档**。自由模式只有规模（小 / 中 / 大）和难度（普通 / 进阶一），没有「带得多就该去更深的图」这一层；没有这一层，放开就等于单向降低难度。
3. **我们的安全阀已经齐了**：保险箱（092）、预设套免费（096）、仓库空了发标准套（067）。缺的不是保底，而是**上面的台阶**。

## 四、放开之后，自由度 / 乐趣 / 难度分别怎么变

- **自由度**：涨。配装从「预算内填空」变成「我这包要怎么打」，棋盘与负重仍是真正的约束，玩家会在 9×6 和 56 负重里做取舍，这比「总价 600」更可读、更像背包游戏。
- **乐趣**：涨在决策，跌在悬念。「要不要带那把紫武器」是搜打撤最好的一口；但如果带了就稳赢，这口甜只甜一次。乐趣要靠「带得多 → 去更深 / 更难 → 赚得更多也丢得更多」撑住。
- **难度**：普通难度对老手会明显变低；新手反而受益（第一局就能用上上一局捡的东西，不被预算卡）。更高难度要接住这个落差：**进阶一已经有侵蚀会损坏包里的东西、猎手会循着脚步追来** —— 这正是对「带好装备进来」天然的税，比出发前扣倒计时更有戏剧性。

预算这条规则的本质是「出发前收税」。它的问题：① 看不见（180 补二后开局屏只剩两行读数，玩家很难把「少 6 步倒计时」和「多带了 300 价值」联系起来）；② 它惩罚的是「带」，而搜打撤要惩罚的是「死」；③ 它把自由搭配做成了填空题。

## 五、取舍：四条路

| 路 | 做法 | 好 | 坏 |
|---|---|---|---|
| 甲 维持 | 预算 600、超带扣倒计时 | 普通难度不会被老手打穿 | 和品类通例相反；税看不见；配装是填空 |
| **乙 放开，税收在死亡上**（推荐） | 去掉价值预算；保留棋盘 / 包 / 负重 / 件数 / 稀有度；死了全没照旧；把「带得多」的平衡交给**更高难度与更深的图** | 和搜打撤通例一致；决策回到「赌不赌」；普通难度成为上手台阶 | 普通难度老手变轻松；要靠后续难度阶梯兜住 |
| 丙 放开 + 轻装奖励 | 乙之上，带入价值低于某线（比如 300）给点甜头：多几步倒计时、搜索点浮层好一档、或者「轻装」buff | 保住「鼠鼠局」这种翻身与挑战玩法；奖励比惩罚讨喜 | 多一条规则要解释；数值要调 |
| 丁 预算进难度阶梯 | 普通不限；进阶 N 起把「带入上限」「不许带某稀有度以上」做成难度机制（`DifficultyDef.mechanics`） | 预算代码不浪费；高难度的刀口清楚 | 单独不够，要和乙一起 |

推荐 **乙，现在就做；丙、丁作为更高难度那条线的一部分，另开方案时再定**。理由：
- 作者自己点出的方向（三角洲）和整个品类一致，而我们的安全阀已经齐了，缺的是台阶不是税。
- 乙落地只是数据：自由模式和沙漏章的 `carry_budget` 改 0（0 = 不限，代码已这么写），开局屏那一行预算读数自动消失。094 的代码留着给丁用。
- 未来的难度阶梯本就要加机制，「带入上限」「侵蚀更重」「猎手更勤」「保险箱更小」「卖价更低」都是现成的刀，可以一级一刀。

## 六、放开后要盯的

- 撤离率：094 当时定的目标是预设 30～40%、带满预算 50～60%；放开后看「带入价值 ≥ 1000」的那批人撤离率，若 > 80% 说明普通难度对老手已无风险，提前推更高难度，而不是把预算加回来。
- 仓库总价值的增长曲线：若直线上涨、没有回落，说明死亡损失没发生过，要在更高难度上加刀。
- 死亡时带入价值的分布：死得多的到底是轻装还是重装，决定丙的奖励线放哪。

## 九、补充一：包也得带出局 —— 卷起来，还是进包架（作者 2026-10-21 16:48 问）

作者：「这样需要将包也带出对局，你看看是采用搜打撤那样包拿出后可以卷起来的设定，还是将包直接放在一个列表里不占用空间的设定」。

### 9.1 现在包怎么流转（核过）

| 环节 | 现状 | 出处 |
|---|---|---|
| 开局 | 棋盘先铺角色的 `starting_bags`（两件皮包 / 皮包 + 小包），预设套（`loadouts/*.json`）自带包；仓库里没有包 | `setup_screen.gd` 1287、`characters/*.json`、`loadouts/*.json` |
| 局内 | 包是掉落（209 包池，15 种 `is_bag`），拖上棋盘就「铺开」覆盖格子；在尸体 / 货架这种自由容器里只是一件普通形状的物品 | 007、209、`grid_inventory.acts_as_bag` |
| 撤离 | 棋盘「原样带回」，但 `MetaState.keeps` 把包筛掉（作者早先定的「包只计图鉴」，信仰护符例外）；包的图鉴照计 | `meta_state.gd` 91、153–188 |
| 战败 | 棋盘连包全没；保险箱不收包 | 092、`safe.no_bags` |

所以「放开预算」之后缺的那一环正是：仓库里的好东西要带进局，得先有包铺在棋盘上；而包现在局外一件都没有、每局只靠角色发的两个。

### 9.2 两条路

| | 甲 卷起来（搜打撤式） | 乙 包架（列表，不占格） |
|---|---|---|
| 做法 | 空包可以「卷」成一件小东西（比如 1×2 / 2×2），进仓库格子、进别的包；拖上棋盘自动铺开 | 局外新开一个 **包架** `MetaState.bags`（包 id → 数量），不占仓库格；开局屏第二页从包架拖包上棋盘；撤离时棋盘上的包进包架 |
| 像谁 | 塔科夫把背包塞进更大的背包；Backpack Hero 包就是棋盘块 | 三角洲 / 暗区：背包是**装备栏**，不是格子里的货；我们的棋盘本身就是「这一套背包」，包架 = 装备柜 |
| 玩家要学的 | 「卷 / 铺」一对新动作；卷起来的包什么时候能卷（必须空）、在仓库里怎么认（卷起形状） | 没有新动作：拖包上板和现在从预设拿包一样 |
| 美术 | 15 种包各一张「卷起」图（或一张通用包裹按包色着色）+ 卷起形状数据 | 包架一列格子（可借仓库页签 / 腰带圆槽的做法），不用新画包 |
| 仓库压力 | 卷起也要占格：一页 10×8，攒五六个包就吃掉一行多 | 零 |
| 代码 | `ItemDef.rolled_shape`、棋盘上卷 / 铺的交互与动画、仓库准入放开包、存档形状迁移 | 一个字典 + 两处 UI（开局屏第二页、基地仓库页）+ `absorb` 多一条分支 |
| 风险 | 规则多一层；卷起的包和普通物品混在仓库里不好找 | 包脱离「物品」语义：卖包、包的耐久（没有）这些要单独写；图鉴照旧 |

### 9.3 推荐：乙 包架

理由：
1. **和品类一致**：搜打撤里背包是装备位，不是货；塔科夫的「包塞包」是为了多层容器，我们没有多层容器的需求。
2. **不加新动作**：作者刚去掉预算是为了「自由」，再教玩家「卷 / 铺」是把复杂度搬了个地方。
3. **省美术、省仓库格**：仓库格留给能卖的货，包攒多少都不挤。
4. **带回来的棋盘更顺**：撤离时棋盘原样带回（现在就这样），只是包不再被筛掉；第二页「一键置入」时货进仓库、包进包架，一次完成。

### 9.4 乙 的规则（派执行时的口径）

1. **包架** `MetaState.bags: Dictionary`（包 id → 数量），存档 v3 加一个键，缺省空（不升版本）。`keeps()` 对包仍答「不进仓库」，另加 `absorb` 的分支：撤离时棋盘上的包计入包架；战败时棋盘上的包随棋盘一起没（保险箱照旧不收包）。
2. **第一次保底**：角色的 `starting_bags` 不再每局白送，而是**第一次选这个角色时发进包架**（像 `first_kit`）；预设套自带的包照旧随预设发（它们上了棋盘、撤离后也进包架，等于预设是免费拿包的途径，正合「轻装局」的意思）。**兜底**：包架空、又不选预设时，开局屏自动发一只小包（`sack`，最差那只），保证不会因为没包而卡死 —— 丢一句「军需官发的」。
3. **开局屏第二页**：包架是一列（放在棋盘和仓库之间的中栏顶部，「地上」在它下面），每种包一格、角标 ×n；拖到棋盘铺开，从棋盘拖回包架收起；棋盘上现有「初始包留在棋盘上」那条规矩（`setup.starting_bag`）作废 —— 包都能拿下。
4. **基地仓库页**：同一列包架显示在仓库页签那一侧；「出售」页可以卖包（按包的 `value` × 卖价比例）—— 这样多出来的包有去处。
5. **结算第二页**：带回来的棋盘连包一起显示；「一键置入」把货放进仓库、包收进包架；`wh.board_label` 那句 224 已删。
6. **局内不变**：包池掉落、铺包规则、包重 0、负重都不动。图鉴照旧「每件各计一次（包也算）」。
7. **测试**：撤离带两只包 → 包架 +2、仓库里没有包；战败 → 包架不变；第一次选角色 → 包架得 `starting_bags`；包架空且无预设 → 棋盘有一只 `sack`；开局屏从包架拖包上板、拖回。

甲 若作者更想要「卷起来」，再写一份：`rolled_shape` 字段、卷 / 铺交互、15 张卷起图（可请美术设计出一张通用包裹按包色着色）。
