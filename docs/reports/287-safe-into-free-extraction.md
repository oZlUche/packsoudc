# 287 保险箱并入免费撤离点：踩上出口选【撤离】或【托付】（092 / 284 §四 C）

> 作者 2026-11-07 14:43（架构设计线程，看 284 第一版）：「第五条需要先根据世界观修改【保险箱】的概念，改成魔法阵或者撤离部队？或者跟免费撤离点合并，改成进入时可以选择【撤离】或【托付道具】」。14:56 在卡片「保险箱改成什么」上选 **C 并入免费撤离点**。直接指派：待定按推荐派执行。

## 〇 一句话

图上不再单放「保险箱」点。踩上**免费撤离点**先问一句：【撤离】结束这一局，或【托付】把东西交给出口那儿接应的人、自己接着走。托付屏就是现在的保险箱屏（格子大小照旧、科技照扩），放进去的东西视为已带出，走开就交出去了、不能再拿回，**空格留着**，出口还开着就能回来再托一次；免费出口过半关门，托付也跟着关 —— 正好接店主那句「待得越久，就越出不去」。付费出口不接托付（那是花钱买路，不是自家人）。

## 一、现状（读码）

## 二、做法

### 2.1 规则

| 事 | 定法 |
|---|---|
| 在哪托付 | 只有**免费**撤离点（`PaidExtracts.fee_of(node) == 0`）。付费出口的确认框照旧只有撤离 |
| 什么时候能托 | 出口没关（`closes_at` 没到）。关了踩上去只有「撤离点已关」那句，托付也没了 |
| 容量 | 一局一块格子，大小照 `GameFlow.safe_size()`（3×3 + 科技）；**整局共用**：这回放两件走了，下回回来剩下的格子还能放 |
| 放进去 = 交出去 | 走开（离点）或关屏时，格子里的东西**锁死**（`SafeModule.lock` 照旧），不能拖回；空格不锁。锁了的东西结算照 `safe_items` 走：撤离、失败都回仓库 |
| 包 | 照旧放不进（`safe.no_bags`） |
| 撤离时 | 托付过的东西和背包一起结算，两处合计（现在就是这样，不动） |
| 寂灭计数 | 「经保险箱回家」改成「经托付回家」，判法不变（`safe_items` 里有法杖） |
| 图上 | 两章 `safes` = 0；`SafePlacer` 退役（文件删、`RunState` 179 那行删、校验不再认 `safe` 类型）；`node.*.safe` 文案、地图图标、节点悬浮句一并删 |

### 2.2 界面

- 踩上免费出口的确认框（`_open_confirm`）：标题照旧，按钮从「撤离 / 取消」改成三枚 **【撤离】【托付】【取消】**；付费出口和关了的出口不出【托付】。托付格子里已经有东西时，【托付】键下一行小字「已托 %d 件」。
- 【托付】→ 开现在的保险箱屏（`safe_screen.gd`），标题改「托付　%d × %d 格」，`safe.intro` 改成「交给出口接应的人，他们比你先到家：放进来的就算带出去了，撤离或失败都回仓库。包放不进。走开就交出去了，拿不回来。」；关屏键「交出去」（`safe.close`）。
- 结算屏那一格、流水账、战记、科技页、右键菜单：文案里的「保险箱」全改「托付」（键名不改，只改字）：`ledger.items_safe`「%d 件 · 托付 %d 件」、`records.detail_safe`「托付」、`act.to_safe`「托付出去」（右键菜单只在托付屏开着时出现，照旧）。
- 科技 `safe_box`：名字改「接应队的背囊」，说明改「接应的人多背一些：托付的格子多一行。」（英文同改）；id、效果、价钱不动，存档不动。
- 帮助页 `safe_box.json`：名字「托付」，正文改写成 §2.1 的规则（放在「撤离与失败」页后面）；`node_types` 页删保险箱一条。
- 店主第五句（284 §3.1 guide_5）照 C 写，已定：「拿不动的先托付给出口那儿接应的人，他们比你先到家」。

### 2.3 存档与兼容

- `SafeModule` 名字、容器 id 3、`to_dict / restore` 不动（存档字段不改、不升版本）；老档里图上若还有 `safe` 点（这版之前存的），`NodeEvents` 对 `safe` 类型照旧能开，这一局打完就没了 —— 不写迁移。
- `RunResult` 字段名 `safe_*` 不改（战记、入账都认它）。
