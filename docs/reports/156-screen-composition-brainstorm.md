# 讨论稿：各个界面应该由什么构成 —— 一屏一屏的头脑风暴（156）

> 作者原话（2026-10-12，架构设计）：「道具图不急，先头脑风暴一下你觉得各个界面(搜索，事件，战斗等等)应该由什么构成」。
>
> 性质：架构 · **讨论稿**，不是实施方案，不派发。作者挑中哪些，再并进正式美术方案（候补 157）与各屏的改法。
> 前提：美术方向 A（墨线 + 平涂，羊皮纸地图，石板面板）；逻辑与表现分离不变 —— 下面说的全是表现层，没有一条要改 `core/`。

## 0. 先定一套所有屏共用的「语法」

现在每一屏都是各自长出来的（地图屏 M6、事件屏 063、商店 087……），能用的部件已经不少（棋盘 `InventoryView`、容器 `LootView`、地图 `MapView`、回放 `BattleView`、读数组件 `HudWidget`、浮窗 `FloatingWindow`、序列帧 `FrameStrip`、悬浮窗 `ItemTooltip` / `HoverTip`），缺的是一条**每屏都按同一个结构搭**的规矩。我建议把任何一屏都拆成五层，从下往上：

| 层 | 是什么 | 由谁出 | 例子 |
|---|---|---|---|
| **场** | 这屏发生在哪：整幅背景图或压暗的地图 | 美术一张图 / 代码压暗 | 宝箱屏的章节背景、事件屏底下压暗的地图 |
| **主体** | 玩家盯着看、伸手去碰的那个东西 | 现有部件 | 棋盘、容器、地图路网、宝箱、对手 |
| **读数** | 数字与状态，不可碰 | `HudWidget`，布局 JSON | 体力心、倒计时、钱袋、信力 |
| **操作** | 按钮、选项，能按的 | 主题变体 | 开战、快速搜索、撤离、事件选项 |
| **反馈** | 一瞬间的东西：飘字、环、闪光、翻页 | 画布 + `FrameStrip` | 开锁环、揭示时的噪点消散、伤害飘字 |

两条配套的规矩：

1. **叠层屏共用一个「石板框」**：事件、战前、回放、容器、商店、保险箱、神坛、宝箱都是叠在地图上的一层。它们的外框（边、标题栏、关闭 / 收起的位置）应该是同一块皮，只换里面。这样换皮时一张石板框图换掉八个屏的外观。现在各屏的框各画各的。
2. **地图屏是常驻的「世界」**：叠层开着的时候底下的地图压暗但不消失，玩家永远知道自己在哪个点。现在已经这么做了，保持，别让任何一屏变成全黑的独立场景（宝箱屏例外，作者定了整屏背景）。

下面按屏说：现在有什么、我觉得该由什么构成、还缺哪张图。「想加的」是头脑风暴，不是承诺。

## 1. 地图屏 —— 一局的主屏

**现在**：圆点 + 字（155 落地后是图标）、直线路网、读数组件按 `map.json` 摆、右侧一列部件按钮（背包 / 撤离 / 菜单 / 路线 / 日志）。

**构成**：
- 场：**章节羊皮纸**一整张（四章四张：遗迹 / 帝国营地 / 诅咒之地深处 / 北方林地，和宝箱皮肤同一套章节 id），地图边缘留一圈纸边。
- 主体：路网 = 墨线（走过的变实线、没走的虚线或淡线）；节点 = 图标圆（155）；**当前位置 = 一枚印章或靴印**，比圆略大；侵蚀 = 从边缘往里晕开的墨渍（现在是颜色叠层，换成一张可拉伸的晕染图就够）；猎手 = 一个跟着走的标记。
- 读数：四角各一组石板条 —— 左上体力心 + 护甲 / 格挡，右上倒计时 + 侵蚀，左下钱袋 + 信力，底部腰带。位置已经是数据（150），只是换皮。
- 操作：右侧那列按钮改成**一排蜡封 / 徽记按钮**，或者收进一个「行囊」浮窗 —— 作者说过背包不要锁死在一处，整列按钮也不必。
- 反馈：走一步时墨线从上一点「画」到下一点（0.2 秒），到点时图标轻轻一跳。

**缺的图**：四张章节羊皮纸、侵蚀晕染、当前位置标记、猎手标记、十三张节点图标（155 已列）。

## 2. 战前准备 —— 对阵

**现在**：左对手棋盘 + 读数（生命 / DPS / 几件），右自己棋盘与地上，底下「开战」，腰带可用件一个按钮一件。

**构成**：
- 场：压暗的地图 + 石板框。
- 主体：**对阵式** —— 左半是对手，右半是自己，中间一道竖缝（可以是一把交叉的武器线稿），两边各一张**名牌**：名字、阵营徽记（帝国军 / 诅咒生物 / 游荡者）、几件。
- 读数：双方各一条生命 + 护甲框 + 格挡层；可以加一个**天平**：估算器算出的双方战斗力比（151 已有 `PowerEstimate`，不用新算），只画一个倾斜角，不写数字。
- 操作：「开战」是整屏最大的按钮，居中偏下；腰带件排在它旁边。
- 反馈：拖东西到地上时那件在棋盘位置留一道灰影一瞬。

**想加的**：对手一张**肖像**（半身线稿），没有就画阵营徽记。敌人现在只有棋盘与名字，这是「敌人长什么样」的第一处。

**缺的图**：敌人肖像（每种敌人一张，可以先只画阵营徽记三张）、交叉武器分隔、名牌底。

## 3. 战斗回放 —— 看戏

**现在**：双方缩小的棋盘 + 冷却遮罩、血条、buff 图标行、飘字、倍速 / 跳过 / 继续。

**构成**：
- 场：同战前（对阵式的延续，位置不变，玩家不用重新找）。
- 主体：上半是**两张肖像面对面**（和战前同一张），中间是打击感的地方；下半是双方棋盘与冷却遮罩。棋盘是信息，肖像是戏。
- 读数：血条 + 护甲框 + 格挡（153 已在悬浮窗里列层）、体力条、buff 行。**时间轴**：一条横着的进度，每条日志事件在轴上一个刻度，拖它就是跳转（`BattleView` 本来就是游标重演，拖轴是零成本的交互）。
- 操作：倍速 / 跳过 / 继续三件，靠时间轴右端。
- 反馈：**只做三种**，别多：出手（出手方的那件格子亮一下）、挨打（挨打方的肖像抖一下 + 飘字）、buff 上身（图标行冒出来）。回放是重演，表演越少越容易读。

**想加的**：战报 —— 回放结束时在时间轴下面滚一张「战报卷轴」：谁打了多少、谁被谁打倒、几秒。这些数日志里都有，只是没人汇总着画。

**缺的图**：肖像（同战前）、时间轴刻度、三种反馈的小帧（可以全是画布画的，不用图）。

## 4. 搜索 / 战利品 —— 容器屏（含宝箱屏作为前置）

**现在**：左容器渐进揭示（灰剪影 + 噪点），右棋盘与地上；快速搜索 / 全部拾取 / 收起（或关闭）。宝箱屏（154）在它前面：背景 + 宝箱 + 环。

**构成**：
- 场：压暗的地图 + 石板框；**容器格子底下垫一张「容器是什么」的图**：尸体容器垫一具倒着的轮廓、宝箱垫打开的宝箱（154 作者定箱内全黑，所以这张就是宝箱屏开完的那张，连起来）、搜索点垫一堆瓦砾 / 一个箱笼。格子盖在图上，图只是场。
- 主体：容器格子（`LootView`），揭示动画从「噪点消散」换成**擦去尘土**（一张尘土遮罩按时间擦掉），同一套揭示逻辑，只换画法。
- 读数：**搜索风险**一行 —— 时间线上还剩几次、遭遇概率几档（已经有规则，只是没画成读数）；珍宝提示（容器里有珍宝时框边发一圈淡金）。
- 操作：三个按钮不变；「快速搜索」给一个代价提示（花时间 / 冒险）。
- 反馈：亮出一件时那件格子翻一下（`FrameStrip` 两三帧），拖走时格子留灰影。

**缺的图**：三种容器垫图（尸体、瓦砾、箱笼）× 章节（可以先不分章节）、尘土遮罩一张。

## 5. 事件屏 —— 读与选

**现在**：两栏框（参考杀戮尖塔），左图右文，选项条件不过灰掉写原因，结果页「继续」。`EventImage` 已能按事件 id 读图。

**构成**：
- 场：压暗的地图 + 石板框（这一屏的框最大，占大半个屏幕）。
- 主体：左栏整张图，右栏标题 + 正文 + 选项。加一张**说话的人**：事件有 NPC 时在图下角一枚名牌（名字 + 身份 / 阵营）；没有 NPC 的事件（环境、遗迹）就不画。
- 读数：选项上**标出会花什么** —— 用图标不用字：耗体力画一颗心、要钱画钱袋、要道具画那件的缩略格；信仰相关的选项用信仰色描边（事件数据里已经有条件与后果，图标可以从里面长出来）。
- 操作：选项条；灰掉的仍然列着写原因（现在就这样，好）。
- 反馈：结果页**收获行**：给的东西按真实格子形状画一排缩略格，可以直接拖进棋盘 —— 这一屏结束后本来就要去容器屏 / 回地图，收获直接拖走省一屏。

**想加的**：正文里认得的词链接到百科（114 的百科屏已经这么做，事件正文复用同一套富文本标词）。

**缺的图**：事件图按事件来（已有钩子）、NPC 名牌底、选项代价图标四五枚。

## 6. 商店 —— 买与卖

**现在**：左店（四个栏位小棋盘，底下写价），右棋盘与地上；拖进棋盘 = 买，拖进出售区 = 卖；刷新 / 收起 / 离开。

**构成**：
- 场：压暗的地图 + 石板框；店的那半垫一张**柜台 / 货架**图，四个栏位就是货架的四格。
- 主体：货架 + 商品真实尺寸；**店主**一枚肖像或徽记在货架上方（流动商贩 / 帝国军需官 / 遗迹里的怪人，按章节换）。
- 读数：钱袋大字在店主旁边；每件价签改成**挂着的墨签**（现在是底下一行字）；出售区是一只**秤**，东西拖上去秤盘沉下去、显示能卖多少。
- 操作：刷新按钮写明代价；离开 / 收起不变。
- 反馈：买到时钱袋数字飘红一行、商品从货架「拿起」的一帧；钱不够放手弹回时价签抖一下。

**缺的图**：货架 / 柜台一张、店主三到四枚、墨签底、秤一张。

## 7. 休息处与神坛

**现在**：休息屏只有一句话 + 继续；神坛屏（093）：信仰 / 等级 / 信力、祭品台、献祭按钮、特殊操作一列。

**构成（休息）**：
- 场：**篝火**一整张（章节换色调即可，不必四张）。
- 主体：篝火本身就是主体；旁边列出这个休息处能做的事：休息（回多少体力写在上面）、神坛（有信仰才亮）、以后的其它选项（修理 / 整理）。现在是一句话一个按钮，太薄，但它确实是喘气的地方，别塞满。
- 读数：体力心在火边放大一份，回复时一颗颗亮。
- 反馈：回体力时火光亮一下。

**构成（神坛）**：
- 场：篝火屏的延续，神坛在火的另一边（同一张场图的右半，或叠一层）。
- 主体：**信仰的徽记**居中（神的符号，美术设计已在画），祭品台在徽记下方；特殊操作一列在右。
- 读数：信力条绕徽记一圈（可以复用宝箱屏的 `UiDraw.ring`），等级在环上打刻度；献祭预览直接画「环会走到哪」。
- 反馈：献祭时祭品从台上消失、环走到预览位置。

**缺的图**：篝火一张、神坛台一张、每位神一枚徽记（美术设计在做）。

## 8. 保险箱

**现在**：左保险箱格，右棋盘与地上；关上（有东西）送回基地。

**构成**：场同其它叠层；主体 = 保险箱格子垫一只**铁箱**图，关上时盖子合上 + 一枚**封蜡 / 帝国印**盖下去（作者定的「关上不能改」正好用一个视觉说清楚）；读数 = 箱子大小（局外规则）；反馈 = 盖下印的一帧。**缺的图**：铁箱开 / 合两张、印一枚。

## 9. 结算

**现在**：撤离 / 战败两种，棋盘原样带回、拖或一键进仓库，保险箱格子另画一份，账在进屏前记好，继续。

**构成**：
- 场：全屏，不是叠层（一局结束了，地图该消失）。撤离 = 天亮的营地；战败 = 暗的，只有一盏灯。
- 主体：撤离时左棋盘右仓库（拖或一键），底下保险箱格子；战败时**只有保险箱格子**（唯一带回的，092 已经画了）—— 战败屏可以把它放大居中，让「还好存了」成为这一屏的主体，而不是角落一格。
- 读数：**账单卷轴**：这局走了几步、打了几场、新点亮几件图鉴、价值合计、钱 —— 账已经记了，只差一张清单把它们列出来。
- 操作：继续（或下一张教学图）。
- 反馈：一键置入时东西依次飞进仓库格。

**缺的图**：撤离 / 战败两张场图、卷轴底一张。

## 10. 局外 / 基地

**现在**：页签 —— 仓库、图鉴、成就、出售、科技；调试台抽屉在右。

**构成**：页签就够了，**别把基地场景化**（每个页签一座建筑那种）：这里是整理与翻看的地方，玩家一局结束要快进快出。改的是皮：石板页签、仓库格子垫木架、图鉴每格一张**卡**（点亮 / 未点亮 = 线稿 / 灰剪影，正好是方向 A 的两种画法）、科技树的连线改墨线。

**缺的图**：几乎不用新图，图鉴卡的底一张即可；道具图是以后的事（作者定不急）。

## 11. 开局

**现在**：左章节与角色，中棋盘（初始包摆好），右仓库格子；拖进棋盘 = 带。

**构成**：
- 主体：章节 = 一排**地图缩影卡**（那张章节羊皮纸缩小，加名字与难度）；角色 = 一列**肖像**（身份定立场与开局，肖像是说这件事最省字的方式）；中间棋盘不变。
- 读数：选中的角色旁一行：种族赐福 + 身份 + 带入限制。
- 操作：出发大按钮；种子在角落小字。

**缺的图**：角色肖像（每个角色一张，和敌人肖像同一套画法）、章节卡用羊皮纸缩图不用新画。

## 12. 主菜单、存档、设置、百科

- **主菜单**：一张标题图 + 一列按钮 + 局外一行数字。只缺标题图。
- **存档位**：三行不变，每行加那一局的章节缩图。
- **设置**：不动皮，功能屏。
- **百科**：现在是左目录右页，已经像一本书；换皮时做成**翻开的书**（左页目录、右页正文），上一页 / 下一页就是翻页。只缺书页底一张。

## 13. 横切的几件

| 件 | 现在 | 建议 |
|---|---|---|
| 道具格子 | 稀有度色块 + 文字 | 淡洗 + 同色深边（美术设计已定），图以后再说；**格子底纹**先做：空格、占用格、不可放格三种底纹就能让棋盘像棋盘 |
| 悬浮窗 | `ItemTooltip` / `HoverTip` 深底 | 一张羊皮小签底，统一所有悬浮窗（道具、buff、格挡层、节点） |
| 浮窗 | `FloatingWindow` 标题栏 + 面板 | 同石板框，标题栏是框的上边 |
| 飘字 | 画布画 | 字体换成手写体一类，颜色不变 |
| 光标 | 系统 | 抓取 / 可放 / 不可放三种光标图，这是拖拽游戏里最便宜的质感 |
| 换屏 | 直接切 | 叠层进出用 0.15 秒的淡入；整屏切换（结算、局外）用一道墨水从边上扫过 |

## 14. 先做哪些（如果作者只挑一部分）

按「玩家待的时间 × 改动小」排：

1. **石板框 + 悬浮窗底 + 光标** —— 一次换掉所有叠层屏的外观，不碰任何一屏的内部。
2. **地图屏**：章节羊皮纸 + 当前位置标记 + 走一步的墨线动画。
3. **容器屏**：容器垫图 + 尘土揭示。
4. **战前 / 回放**：对阵式 + 肖像（敌人第一次有脸）+ 时间轴。
5. **事件屏**：选项代价图标 + 收获行可拖。
6. 其余按 6 ～ 12 节顺序。

## 15. 想请作者拍的几件（头脑风暴阶段，不急）

| # | 问题 | 我的倾向 |
|---|---|---|
| 1 | 敌人与角色要不要**肖像**（半身线稿），还是只用阵营 / 种族徽记 | 肖像。这是整个游戏「有人」的唯一地方；徽记可以先顶着 |
| 2 | 回放要不要**表演层**（肖像抖动、出手亮格），还是纯读数 | 要，但只三种反馈 |
| 3 | 战败结算屏要不要把保险箱格子放大居中当主体 | 要 |
| 4 | 地图屏右侧那列部件按钮：蜡封按钮一排，还是收进一个浮窗 | 一排蜡封，浮窗多一次点击 |
| 5 | 基地要不要场景化 | 不要，页签 |
| 6 | 事件屏收获行能不能直接拖进棋盘 | 能，省一屏 |

这些定了以后：美术方案（候补 157）写风格约束 + 图清单 + 钩子；各屏的改法按 14 节的顺序一屏一个小方案，派给执行。
