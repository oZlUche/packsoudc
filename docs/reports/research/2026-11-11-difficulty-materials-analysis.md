## 一、核心判断

1. 当前共有 **普通、进阶一、进阶二、进阶三，四档难度**。三档进阶的最终体力上限修饰均为 −1，不是累计扣到 −3。
2. 可选进阶主要增加生存和路线压力，没有给所有普通敌人统一加生命或伤害；敌人另有四档强度表，不能混淆。
3. 素材基础定义共 **62 种**，白 / 绿 / 蓝 / 紫 / 橙 / 红为 **15 / 17 / 19 / 6 / 1 / 4**。其中四种红核是独一内容，普通供给分析应单列。
4. 当前按材质类要求的配方都有静态候选，但木材和骨材的高阶缺口限制了部分升级的品质提升。候选存在不代表能在正常流程中合理取得。
5. 进阶一的搜索保底提高、敌人不随所选难度统一变强；进阶二突然引入侵蚀和直接毁物。档间实际体验可能不平滑，尚未通过本次真人试玩证实。

## 二、难度档位与实际效果

来源：[难度目录](../../../data/authoring/difficulties)、[DifficultyDef](../../../core/run/difficulty_def.gd)。

| 所选难度 | 最终体力上限修饰 | 侵蚀 | 猎手 | 解锁 |
|---|---:|---|---|---|
| 普通 | 0 | 无 | 无 | 无进阶要求 |
| 进阶一 | −1 | 无 | 无 | 一局带出价值至少 300 的成就 |
| 进阶二 | −1 | 开启 | 无 | 在进阶一成功撤离 |
| 进阶三 | −1 | 同进阶二 | 追猎者 | 在进阶二成功撤离 |

配置是每档独立的最终清单，不会把进阶一、二、三的 effects 相加。解锁依据见 [big_haul](../../../data/authoring/achievements/big_haul.json) 与 [GameFlow](../../../core/run/game_flow.gd) 的结算流程。

### 2.1 侵蚀的实际强度

[默认机制参数](../../../core/run/mechanics/erosion_mechanic.gd)为首次行动点 18、间隔 12、预警提前 4。难度 JSON 没有覆盖这些时间值。

| 效果 | 当前配置与实际行为 |
|---|---|
| 体力 | 在被侵蚀的目的地结算时额外扣 `1 + depth`，减去侵蚀抗性，最低不扣；depth 是该点已被侵蚀的深度 |
| 毁物 | depth ≥ 2 后，每次结算 25% 概率从背包棋盘候选中移除最贵的一件；默认不含包 |
| 扣钱 | 配置 amount=10、only_total=true，但 enabled=false，实际关闭 |

“损坏”当前并非减少耐久，而是从容器移除整件物品。[毁物实现](../../../core/run/erosion/effects/erode_damage_item.gd)与 [ItemPick](../../../core/run/item_pick.gd) 所示候选筛选主要排包，没有按玩家锁定、独一或任务标签额外筛除；具体物品能否被移除还需连同容器限制做用例核验。因此不能把“锁定”当作已确认的侵蚀保护。

这是配置行为与保护覆盖风险，不是本次复现的物品丢失 bug。首次推进和后续结算次序见 [ErosionField](../../../core/run/erosion/erosion_field.gd)。

### 2.2 猎手

进阶三当前配置一只追猎者；按地图规模的数量覆盖表未填，采用默认数量 1。默认 spawn_after_steps=0，即开始移动后很早出现；出生最小距离 3 个图步。出现不等于立即交战。

段位阈值为总步数 0 / 5 / 10 / 20，追猎者强度对应 0 / 1 / 2 / 3。见 [HunterMechanic](../../../core/run/mechanics/hunter_mechanic.gd) 与 [hunter_1](../../../data/authoring/hunters/hunter_1.json)。

## 三、敌人增益：与玩家可选难度分开

常规敌人强度由归一化深度、节点危险等级、节点类型、章节 difficulty、地图规模及探索度计算。这里的 `ChapterDef.difficulty` 与 `DifficultyDef.level` 是两个概念；当前五份章节定义的前者均为 0。

当前魔法废墟与机关敌人池的档位表相同。倍率作用于敌人基础属性，不表示“进阶一比普通多这么多”。

| 敌人强度档 | 基础生命倍率 | 基础格挡倍率 | 装备件数范围（不含包） | 棋盘 | 常规武器上限 |
|---|---:|---:|---|---|---|
| 0 | ×1.15 | ×1 | 2～3（默认） | 5×3 | 白 |
| 1 | ×1.50 | ×1 | 3～4 | 6×4 | 绿 |
| 2 | ×1.90 | ×1.25 | 4～6 | 6×5 | 蓝 |
| 3 | ×2.40 | ×1.75 | 6～8 | 8×6 | 紫 |

前三档常规武器还排除了真实伤害武器；实际面板与效果继续受到敌人身份、装备、摆放和组装规则影响，不能由生命倍率推导固定胜率。

猎手专属池的基础生命倍率为 **×1 / ×1.25 / ×1.6 / ×2**，最高档格挡 ×1.5，武器上限同为白 / 绿 / 蓝 / 紫。不能将常规池的 ×2.4 套到最高档猎手。

来源：[常规池](../../../data/authoring/enemy_pools/standard_ruins.json)、[机关池](../../../data/authoring/enemy_pools/clockwork.json)、[猎手池](../../../data/authoring/enemy_pools/hunters.json)、[StrengthTier](../../../core/enemies/strength_tier.gd)、[StrengthRule](../../../core/enemies/strength_rule.gd)。

### 3.1 随进阶增加的特殊武器概率

核心战与猎手在满足强度门槛 ≥3 等条件时，可能实际装备红武劣化版。它是持有后再交战，并非仅在战后掉落池里出现。

| 难度 | 理论持有掷骰概率 | 已持有且战胜后的掉落概率 |
|---|---:|---:|
| 普通 | 1% | 20% |
| 进阶一 | 2% | 30% |
| 进阶二 | 3% | 40% |
| 进阶三 | 4% | 50% |

以上不是每场普通战斗的概率；没有合适武器或摆不下等情况下也可能不持有。普通敌人样本与特殊持有样本应分开统计。[RedSources](../../../core/run/red_sources.gd) 与 [NodeEvents](../../../core/run/node_events.gd) 的 core 调用门限定了适用范围。

## 四、难度收益与可能的不平滑

[标准搜索规则](../../../data/authoring/node_rules/standard.json)逐件稀有度下限为：

| 所选难度 | 普通搜索点每次的保底位 | 高危／高级搜索点默认保底位 |
|---|---|---|
| 普通 | 白、白 | 绿、白 |
| 进阶一 | 绿、白 | 绿、绿、白 |
| 进阶二 | 绿、绿、白 | 蓝、绿、绿 |
| 进阶三 | 蓝、绿、绿 | 紫、绿、绿 |

这表示各位置的最低稀有度，不是限定只能出这几档；保底还会影响最低件数。节点自身覆写、固定教程掉落及候选池约束优先。进阶三高危点超出阶梯表后，第一项再抬一档，因此是紫而不是仍为蓝。见 [SearchRules.floor_row](../../../core/run/search_rules.gd) 和 [SearchSession.floor_for](../../../core/run/search_session.gd)。

**风险推断：** 进阶一减一点体力，同时获得更好搜索下限，可能让构筑更快成形、战斗更轻松；进阶二则增加侵蚀体力支出与高价值物品永久损失。当前资料不能证明难度实际倒挂，但有必要分离战斗、路线与资产压力验证。

| 金属 | 1 | 5 | 7 | 2 | 1 | 0 | 16 |

## 六、配方供应与品质缺口

[SmithRecipeDef.material_fits](../../../core/meta/smith_recipe_def.gd)对普通材质要求素材标签、材质匹配和稀有度达到门槛；晶体要求对应家族与门槛。按这些条件、排除 sealed 与 unique 后的静态候选为：

| 材料要求 | 使用该要求的配方数 | 静态候选数 |
|---|---:|---:|
| 骨 ≥绿 | 13 | 5 |
| 骨 ≥蓝 | 15 | 3 |
| 金属 ≥绿 | 13 | 15 |
| 金属 ≥蓝 | 14 | 10 |
| 金属 ≥紫 | 1 | 3 |
| 金属 ≥橙 | 1 | 1 |
| 木 ≥绿 | 3 | 2 |
| 木 ≥蓝 | 4 | 2 |
| 石 ≥绿 | 1 | 3 |
| 火焰魔晶石家族 ≥紫 | 8 | 2 |
| 冰霜魔晶石家族 ≥紫 | 4 | 2 |
| 闪电魔晶石家族 ≥紫 | 5 | 2 |

配方数按“包含该类要求”计，不是消耗需求量或互不重叠的配方总数。候选不扣存档解锁、不考虑商店库存、科技、资金和掉落路径；不能从本表推导实际取得概率。固定 id 输入及其获得路径也需另核。

当前品质公式为：

```text
出件品质 = clamp(max(原武器品质, 材料稀有度 - 配方最低稀有度), 0, 2)
```

来源：[Anvil.quality_of](../../../core/run/anvil.gd)。这使高阶材质缺口产生实际差异：

| 配方要求 | 当前最高材料 | 本次升级可新提供的最高品质 |
|---|---|---:|
| 木 ≥绿 | 蓝木：硬木板、铁木枝 | 1 |
| 木 ≥蓝 | 蓝木 | 0 |
| 骨 ≥绿 | 紫骨：骨骰子 | 2 |
| 骨 ≥蓝 | 紫骨：骨骰子 | 1 |
| 金属 ≥蓝 | 橙金属：灰白色的金属碎片 | 2，受解锁与取得路径限制 |
| 金属 ≥橙 | 同一橙金属 | 0，可保留原品质 |

原有品质可以继承，因此不能断言木系或骨系最终完全无法有高品质；后续其他材料步骤也可能抬品质。本表只说明相应升级本身的能力。

**评价：** 无需让十种材质六档完全对称，但木、骨、金属在“通过材料提升品质”的机会不对称。若作者希望各类升级路线具有相近品质上限，先补有实际配方用途的缺口。紫织物已有两种，而绿门槛配方的材质需求集中在骨、金属、木；增加无使用目标的高阶素材未必改善体验。

## 七、建议补充的材料清单

以下名称仅为便于讨论的暂名，不是作者定稿；不写入道具数据或描述。数量是建议新增的基础种类数，需另定形状、价格、功能、掉落与获取节奏。

| 优先级 | 建议新增 | 数量 | 补充理由与预期作用 | 投放方案候选／约束 |
|---|---|---:|---|---|
| P1 | 紫木材，例如“铁木心材” | 1 | 木 ≥绿可新提供品质 2，木 ≥蓝可提供品质 1，补现有升级用途 | 林地深层或材料节点；与现有蓝木区分获取阶段 |
| P1 | 橙木材，例如“古树髓芯” | 1 | 木 ≥蓝可新提供品质 2 | 深层精英或多步加工候选；避免初期无限量商售 |
| P1 | 橙骨材，例如“古兽脊骨” | 1 | 骨 ≥蓝可新提供品质 2 | 强力兽类或骨材加工候选；需按地图与敌人来源设计 |
| P2 | 第二种紫骨材，例如“巨兽骨板” | 1 | 当前紫骨只有骨骰子；降低高阶骨材来源的单点依赖 | 与骨骰子采用不同来源，不仅换名字和贴图 |
| P2 | 第二种橙金属素材，例如“精炼合金锭” | 1 | 当前橙金属只有带 treasure 的解锁碎片；为常规高端工艺提供可规划路径 | 优先评估基地加工；要维持现有橙金属配方的门槛 |
| P3 | 第二种紫木材 | 0～1 | 仅当首批材料在两张地图的可得性仍过分集中时增加 | 先看获取数据，不作为首批必做 |
| 暂缓 | 蓝织物、紫皮革、蓝石、高阶草药等全面补档 | 不预设 | 缺色不等于缺玩法；先确认配方、战斗功能或销售用途 | 有明确消耗／用途后再立项 |

首批建议最小集为 **P1 三种**；P2 两种解决来源多样性与规划性问题。若全部 P1、P2 落地，且不删除既有素材，则素材定义由 62 增为 67；这只是计划数量，不是当前统计。

素材新增也会扩大抽选池，可能稀释其他掉落，不能只加定义而不核对节点标签、稀有度权重、解锁与配方来源。若各武器品质不对称是作者有意设计，可保留差异，并明确哪些路线通过继承品质或其他材料步骤补偿。

## 八、难度调整建议

### 8.1 主推荐：先保持四档，分别验证压力来源

| 编号／优先级 | 当前风险 | 建议的独立试验 | 验证后才决定什么 |
|---|---|---|---|
| D1／P1 | 进阶一仅 −1 体力，但搜索收益上升，可能战斗变轻松 | 固定地图、角色、带入、种子，对比当前进阶一与仅把普通搜索保底覆写为普通档的变体；其他参数不变 | 保留现收益，还是调整奖励曲线；不能凭配置直接认定倒挂 |
| D2／P1 | 进阶二同时增加侵蚀扣体力和最贵物品移除，压力跳变大 | 首选对照：只将 damage_item.enabled=false，其余保持；对比损失原因、撤离决定、失败后再出发意愿 | 是否用侵蚀的路线／体力压力承担本档主要挑战 |
| D3／P1 | 进阶三猎手出现早，可能叠加未成形构筑压力 | 先比较 spawn_after_steps=0 与候选 3；如再试 5，须记录它已进入第二段位，不能只按“晚出”解释 | 初次接触时机及段位是否需要一起设计 |
| D4／P2 | 极少数红武劣化版遭遇造成强度突变 | 按是否持有特殊武器分层；基础敌人标定先单列无特殊持有样本 | 特殊武器的预警、绕行和奖励是否足够 |
| D5／P2 | 同一侵蚀时间表跨两张图和多个规模可能压力不同 | 逐图、逐规模记录首次侵蚀时资源、剩余撤离路程和步数 | 是否需要按地图／规模配参数，不能只增大全局间隔 |

上表是候选实验，不将这些参数直接视为新默认值，也不把未经实测的目标胜率写成验收标准。当前普通 / 精英目标带仍应按既有作者决策处理。

### 8.2 如果作者决定保留毁物

先核验并明确锁定、独一、任务物品的保护规则，再让玩家在踏入区域前知道损失类型。可以另测 `from_depth=3, chance=0.10`，对比当前 2 / 0.25；这是第二阶段参数候选，不能与 D2 的禁用变体混为同一个试验。

如果改为随机或最便宜物品，需评估玩家用廉价物品吸收惩罚的行为；当前接口支持这些挑选模式，不代表它们必然更合理。更改毁物形式属于规则变更，应先交作者决定。

### 8.3 是否给所有敌人增加百分比强化

本轮不优先建议统一加生命／伤害：当前已有敌人强度档、装备升级、探索度、侵蚀和猎手，多处同时改会难以归因。先完成 D1～D5 与现有平衡基线的衔接；若仍缺乏稳定战斗梯度，再把单独的敌人基础属性修饰作为备选，不与奖励、毁物和猎手同时上线。

### 9.2 材料清点的最小复现

在固定基线的独立 checkout 根目录运行 Python 3：

```python
import json
import pathlib
import re

root = pathlib.Path(".")
items = [
    json.loads(p.read_text(encoding="utf-8-sig"))
    for p in sorted((root / "data/authoring/items").glob("*.json"))
]
materials = [x for x in items if "material" in x.get("tags", [])]
print("items", len(items), "materials", len(materials))
for kind in sorted({x["material"] for x in materials}):
    print(kind, [
        sum(x["material"] == kind and x.get("rarity", 0) == r for x in materials)
        for r in range(6)
    ])
print("rarity_totals", [
    sum(x.get("rarity", 0) == r for x in materials) for r in range(6)
])
diffs = []
for x in materials:
    text = (root / "data/items" / (x["id"] + ".tres")).read_text(
        encoding="utf-8-sig"
    )
    rarity = re.search(r"^rarity = (\d+)", text, re.M)
    material = re.search(r'^material = &?"([^"]+)"', text, re.M)
    tags = re.search(r"^tags = (.+)", text, re.M)
    if (
        (int(rarity[1]) if rarity else 0) != x.get("rarity", 0)
        or not material or material[1] != x["material"]
        or not tags or '&"material"' not in tags[1]
    ):
        diffs.append(x["id"])
print("runtime_material_field_differences", diffs)
```

实际输出摘要：`items 267 materials 62`、`rarity_totals [15, 17, 19, 6, 1, 4]`、`runtime_material_field_differences []`。完整素材名单与配方候选见附带 JSON。
