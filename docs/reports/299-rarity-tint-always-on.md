# 299 棋盘里的道具常显稀有度淡底（239 补充）

> 作者 2026-11-11 13:16（架构设计线程）：「你认为是否有必要让道具在棋盘里始终显示半透明的稀有度颜色背景？」13:20 卡片选 **A 淡底常显**（平时每格约 12% 稀有度淡底、不描边，拿起时加深成现在的样子）。直接指派，派执行。

## 〇 一句话

道具占的每一格，平时就垫一层 12% 的稀有度色；拿起道具时照 239 加深到 26%。不描边、不加字。

## 一、现状（读码）

- 239（v4.20）：只有拖拽中 `InventoryView.footprints` 才开，`draw_footprint` 每格铺 `FOOTPRINT_FILL 0.26` 的稀有度色（白档用偏灰的白 `FOOTPRINT_WHITE`，包铺 `FOOTPRINT_BAG_FILL 0.12` 的包灰），画在道具图**上面**、邻接标记下面。
- 平时棋盘上分不出稀有度：有图的道具只看图，绿和蓝要停上去才知道；279 之后武器五档近百把，这个问题变明显了。

## 二、做法

1. 平时：每件道具（不含包）的占格铺一层 `FOOTPRINT_IDLE_FILL 0.12` 的稀有度色，颜色照 `footprint_color`（白档偏灰白），每格同样向内缩 `FOOTPRINT_INSET`，所以格线和外框都看得见（10-21 的规矩不破）。
2. 画的次序：淡底画在**道具图下面**、格线上面 —— 它是背景，不压图。拖拽时 239 那一层照旧画在图上面、26%，两层不叠（拖拽开着时不画淡底）。
3. 包：平时不铺（包有自己的图和框，里面的东西各有淡底）；拖拽时照 239 铺包灰。
4. 哪些棋盘：所有 `InventoryView`（背包、仓库、局内商人棋盘、敌人棋盘、结算页）。地面上的道具不铺（239 也没画地面层）。集市货格照作者 10-31 保持透明，不铺。
5. 别的标记都压在它上面、不改：290 待成交的金色（22% + 虚线）、邻接标记、品质金菱、收藏星。
6. 不加设置开关。

## 三、改动清单（执行）

1. `InventoryView`：新常量 `FOOTPRINT_IDLE_FILL := 0.12`；`_draw` 里在画道具图之前铺淡底（`footprints` 关着时）；`draw_footprint` 加一个透明度参数或另起 `draw_idle_tint`，复用 `footprint_cells` / `footprint_color`。
2. 集市货格的视图关掉淡底（一个开关属性，默认开）。
3. 测试：平时棋盘上蓝武器的格子取到蓝色淡底、包不铺、集市货格不铺；拿起时淡底换成 239 那层；格线仍在。`test_footprints_239` 照过。
4. 落地后请 UI设计 过一眼深浅两种棋盘底上的 12% 是否读得出；读不出由 UI设计 在 10–16% 之间定数。
