# 203 讨论稿：音频怎么接、现在要不要占位、素材从哪来

作者问（2026-10-19 16:25）：「音频播放器后续插入会不会很麻烦？需要现在提前占位修改吗？素材来源呢？用工具生成还是购买付费或免费可商业化的素材？」

本篇只回答这三问，不是实施方案；作者定了方向再出正式方案。

## 1 后插麻不麻烦：不麻烦，因为挂点都已经是信号

音频在这个项目里不需要「插进」各处逻辑，只需要**一个监听者**。现在能挂的点：

| 想响什么 | 现成的信号 / 事件 | 在哪 |
|---|---|---|
| 战斗命中、暴击、元素反应、buff 上下、倒下 | `BattleEvent`（回放已经按它驱动画面：`_on_damage` / `_on_reaction`） | `ui/battle/battle_view.gd:544-557` |
| 回放倍速 / 暂停 | `speed_changed`、播放 / 暂停按钮 | `battle_view.gd:21` |
| 拿起、放下、顶出、掉到地上 | `drag_started` / `drag_finished` / `items_displaced` / `items_shed` | `ui/inventory/drag_layer.gd:24-30` |
| 落地、弹开、翻倒 | `GroundLayer` 的落地结束与弹开收尾（`_finish_bumps`） | `ui/inventory/ground_layer.gd` |
| 战利品翻牌、翻完 | `item_revealed` / `reveal_finished` | `ui/game/loot_view.gd:14-15` |
| 换屏（配乐切换）、进战斗、结算 | `GameFlow.screen_changed` | 导演听它换屏，音频听它换曲 |
| 按钮、翻页、开关 | `pressed`（Godot 自带） | 统一在 `UiTheme` 的按钮工厂里挂一次即可 |

所以后插的改动是：一个自动加载 `Audio`（总线、两档音量、`play(cue)` / `music(track)`）+ 一张 **cue 表**（`data/authoring/audio/cues.json`：cue 名 → 文件、音量、随机变体、冷却）+ 在上面这些信号上各一行 `Audio.play("battle.hit")`。约 300 行 + 一天，**什么时候做都一样**。唯一会「越晚越贵」的是事件文本里没法标音效 —— 但事件屏本来也只要一首底乐 + 翻页声。

两处要留意、但也不用现在动：
- 回放 ×2 / ×4 时命中声会挤成一片：cue 表里给「冷却」和「每秒上限」，倍速时只响大的（暴击、反应、倒下）。这是 cue 表的字段，不是代码结构。
- 无头测试：`Audio` 在 `OS.has_feature("headless")` 或没有音频设备时整个变空操作，测试不响也不报错。

## 2 现在要不要占位：不用改代码，只要一张 cue 清单

代码层面没有「不先占位以后就难改」的地方。真正该现在做的是**定 cue 清单**（§3 的表就是第一版）：有了清单，美术 / 作者找素材才有靶子，到时候文件名对上就响。清单里每个 cue 写清「什么场合、什么质感、几个变体」。

如果想要一个最小占位，就只加三样（半天）：`Audio` 自动加载的空壳（`play` / `music` 什么也不做）、设置里「音乐 / 音效」两条音量（存进 `GameSettings`，现在就有 UI 位置）、`cues.json` 空表。好处是设置屏和存档格式先定下来；坏处几乎没有。**推荐：先只定清单，壳子等素材来源定了一起做**。

## 4 素材来源：三条路对比

| 路 | 适合 | 优点 | 代价 / 风险 |
|---|---|---|---|
| **免费可商用素材**（CC0 为主） | 音效几乎全部 | 零成本，许可最干净；CC0 不用署名。来源：Kenney（CC0 音效包）、Sonniss「GDC Game Audio Bundle」（每年免费放出，可商用）、freesound 按 CC0 筛、OpenGameArt 按 CC0 筛 | 风格要自己挑、自己剪；CC-BY 的要在游戏里放致谢页（成本很低）；配乐质量参差 |
| **付费素材 / 定制** | 配乐 | 6 首曲子找同一位作者或同一个包，整体气质统一；买断许可清楚 | 一个包几十到几百美元；定制每首几百美元起；要先定风格（剑与魔法、墨线平涂 → 偏民乐 / 中古弦乐而不是交响） |
| **工具生成** | 补缺的音效；配乐**先不要** | 音效：sfxr / ChipTone 一类合成器出的是 8-bit 质感，和这个美术风格不搭；用 AI 音效（ElevenLabs SFX、Stable Audio 等）出「皮革摩擦」「金属落地」这类补缺可以。配乐：AI 生成的曲子**版权归属在多数司法区还不明确**，Steam 上架要在商店页披露 AI 生成内容，平台与玩家反感度高 | 法律与平台风险落在配乐上，音效风险小 |

**推荐**：音效走 **CC0 包 + freesound 补缺**（美术设计 thread 按 §3 清单挑、剪、命名，交执行接入 —— 和道具图一样一批一批来），配乐 **买一个风格统一的包或定制**（等玩法定型、音效接上再买，免得风格改了白花）。AI 只用来补个别找不到的音效，不用来做配乐。

一个限制：云端 thread 下载素材受网络策略限制（之前字体只能从 GitHub raw 拉到），freesound / Kenney 能不能直接拉要试；拉不到就作者本机下载放进 `/mnt/project-files/art/audio/`，thread 再整理。
