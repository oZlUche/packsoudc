# 248 不打不罚、跑才罚：战前屏「退回」+ 三种遭遇统一的「逃跑（几成）」

作者 2026-10-24 10:38（架构设计线）：「另外如果经过节点可以不战斗，似乎没有什么惩罚，但如果逃跑也要损失什么，那不战斗的选项又没有意义了，如何取舍？」；10:41 对下面的取舍说「可以」。

## 〇 一句话

**看见了再躲是计划，不收直接代价；被缠上了再跑是应急，要付代价。** 两者能用的场合不同，所以不冲突：绕开只在你提前看见敌人时有（地图上的战斗点 → 战前屏「退回」），被缠上（搜索遭遇、伏击、猎手）就没有绕开，只有「逃跑（几成）」。不打的代价本来就有：没有战利品、钱和分，步数照走、撤离点在关，猎手和踩上去才造的敌人随步数变强。

## 一 现状

| 场合 | 现在 | 代价 |
|---|---|---|
| 地图上看得见的战斗 / 精英点 | 踩上去只有「开战」，战前屏「必须过」（084） | 不想打只能一开始就换路 |
| 伏击事件 | 「上去看看」/「绕开」 | 绕开必成，背一层虚弱 |
| 搜索遭遇 | 只有「迎战」 | — |
| 猎手 | 「逃跑（几成）」 | 失败扣一点体力，成功猎手歇几步 |
| 技能「脱身」（136，安德烈乌斯，隐藏） | 战前屏「溜走」/ 猎手事件「脱身」必逃 | 点算用过、没有战利品；有次数与冷却 |

## 二 退回（打之前，不罚）

- 战前屏加一颗平的小石键**「退回」**（Fall back），放「开战」战旗对面的下角；230 规则：平的，无斜面。
- 按下：`NodeEvents.retreat_pending_battle()`——清掉 `pending_battle`，**不**标 `_visited`，玩家回到上一个点（`travel` 退一步，**再走一步**：踩进来已经走了一步，退回又一步，这两步就是时间代价），敌人留在原地，节点内容不变（同一种子），回来再踩还是这一场。
- 只给**战斗 / 精英**点；核心点不给（和 136 一致，首领不能退）；搜索遭遇和猎手的战前屏不给（它们走 §三 的逃跑）；序章的强制战斗不给（章节 `skip_setup` 的序章里按钮不出现，教程步骤不变）。
- 「脱身」仍在：它是不退步、节点作废的版本，只有安德烈乌斯有，和退回并排不冲突。
- 084「战前屏必须过」改成「必须过，但可以退回」。

## 三 逃跑（打起来之后，要付）

三种被缠上的场合统一一条规则，数在 `node_rules.standard.json` 新节 `flee`：

| 键 | 占位值 | 意思 |
|---|---|---|
| `chance` | 0.5 | 基础成功率，加 buff 的 `flee_bonus`，夹在 0～1 |
| `fail_vitality` | 1 | 失败扣几点体力 |
| `fail_buff` | `weakened` | 失败背的 buff（虚弱：五步内伤害 −10%） |

| 场合 | 改成 | 成功 | 失败 |
|---|---|---|---|
| 搜索遭遇 | 「迎战」/「逃跑（几成）」 | 会话按 `slipped` 收（收获照交，点用过，不弹「被赶跑」） | 扣体力 + 虚弱，然后照样开打 |
| 伏击 | 「上去看看」/「逃跑（几成）」（原「绕开」） | 走人，**不再背虚弱** | 扣体力 + 虚弱，然后开打 |
| 猎手 | 「逃跑（几成）」照旧 | 照旧（猎手歇 `flee_cooldown` 步） | 原来只扣体力，**加上虚弱**，然后开打 |

- 新事件结果类型 `flee_encounter`：掷骰、记日志（沿用 `hunter.flee_ok / flee_fail` 两条文案，键挪到通用）、成功走 `skip_pending_battle` 那条路、失败扣体力 + 上 buff 再 `start_battle`。猎手的 `HunterSystem.flee` 改成调同一个函数，自己的 `flee_chance / flee_fail_vitality / flee_cooldown` 仍按猎手定义（覆盖通用值）。
- 「脱身」在这三处仍是必逃（136 不变）。
- 选项文案「逃跑（%.0f%%）」是现有键，百分数由程序填，不算正文里的阿拉伯数字。

## 四 为什么这样分

- 不打不罚：打仗的理由是有赏，不是不打挨罚；罚不打会把搜打撤变成清版。
- 跑才罚：被缠上说明你已经付了「没看见」的代价，跑是赌一把，赌输再付一点。
- 退回要走步：唯一的硬代价是时间，而时间在这个游戏里就是钱（撤离点关、敌人变强）。

## 五 测试

退回后 `pending_battle` 空、节点不算用过、`travel.clock` 多两步、再踩同一点是同一场；核心点与序章没有退回；三种遭遇的逃跑掷到成功 / 失败各一次的状态（体力、buff、是否开打）；猎手逃跑失败背虚弱；脱身仍必逃。
