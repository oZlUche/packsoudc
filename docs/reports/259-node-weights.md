## 二、原因

1. **路线外的点不认路线。** 一张图 28～47 个点里 10～21 个（约四成）不在任何路线上，它们由所在环的 `type_weights` 抽：battle 3 / search 3 / event 3 / random 2 / elite 1 / chest 1（`ring_type_assigner.gd` `_assign_by_weights` → `_weights_for`）。这张表全环一样、不看旁边是哪条路线，搜索天然占 3/13，再加宝箱与随机折算到 30%。
2. **高危区只从战斗 / 常规路线岔出**（搜索路线 `spawns_zones = false`），每片至少 2 搜索 + 1 精英、小型一片只有 3～4 个点 —— 等于给战斗路线旁边固定挂两个搜索点。这是 053 的「诱惑」设计，本身没错，但和第 1 条叠在一起。
3. **路线自己的点被喘气处吃掉一半。** 战斗路线独占 7.5 个点里，出生 1 + 商店 0.9 + 休息 1.6 + 撤离 0.3 占 3.8，`mix` 只分到 3.7 个点，战斗感本来就薄。
4. **休息点有四个来源在叠加**：① 每环配额 `rest: [1, 2]` —— **每环至少一个**，5 环就至少 5 个（114 定的，`free_mode.json` 六个环与 `ring_template` 都是这个数；代码里的 `sample()` 与机关沙漏都是 `[0, 1]`）；② 每条路线中点放一个（`haven_at`，小型 0.5 / 中型 ⅓）；③ 覆盖 `coverage.rest = 3`，任何点三步内要有休息，不够就贪心补；④ 随机点揭出休息 1/11。`no_adjacent` 只禁精英—精英、商店—商店，**没有休息—休息**，所以 ① 的「本环必须有」挨着 ② 的「路线中点」就是截图那样。

## 三、方案：三个旋钮，各管一件事

### 3.1 旋钮 ①：路旁的点跟路线走（管「战斗路线旁边为什么是搜索」）

`_weights_for`：不在任何路线上、也不在高危区里的点，先找**最近的路线**（沿边走，最多 4 步，第一次碰到路线点为止）。只碰到一种风格，就把那条路线的 `mix` 和所在环的 `type_weights` **各占一半**混成这个点的权重（mix 按环权重的总量归一再对半）；碰到两种风格（两条路线之间的夹缝、换乘区）或 4 步内没碰到路线，照旧用环权重。配额、覆盖、禁止相邻、校准一个都不改 —— 只是换了抽签用的权重表。顺手把「最近路线风格」写进 `node.layout.near_style`，图的 JSON 跟着带，编辑器与将来的随机点揭示都能用。

沙盒先试过「纯 mix」（表里第 ① 行）：战斗路线旁搜索确实少了、战斗多了，但全图搜索总数**不降反升** —— 它只是把搜索挪到搜索路线那一侧（搜索路线旁 1.0 → 1.7）。所以改成对半混合，再配下面的 ②。

### 3.2 旋钮 ②：全图搜索份额（管「整张图搜索多」）

- 六个环与 `ring_template` 的 `type_weights`：battle 3 → 4、search 3 → 2（event 3 / random 2 / elite 1 / chest 1 不动）。
- `node_rules/standard.json` 的 `random_weights.search` 3 → 2。
- 高危区 `zone_spec.min_search` 2 → 1：小型的高危区只有 3～4 个点，「2 搜索 + 1 精英」就是整片区；改成 1 精英 + 1 搜索 + 剩下按旁边路线长，精英守的东西还在。

路线 `mix`（战斗 5 / 1 / 1，搜索 4 / 1 + 八成保底）不动 —— 搜索路线还是搜索路线。想再砍，见 B。

### 3.3 旋钮 ③：休息点三改（管「休息多、休息挨着休息」）

- `free_mode.json` 六个环与 `ring_template` 的 `rest` 配额 `[1, 2]` → `[0, 1]`（和 `sample()`、机关沙漏一致）：不再「每环必有」，每环最多一个。
- `no_adjacent` 加 `["rest", "rest"]`。休息旁有商店是合理的歇脚处，不禁。
- `coverage.rest` 保持 3（沙盒试过 4：休息只剩路线中点那三个、覆盖一个都补不上；3 会再补半个）。
- 随机点：揭开时若相邻已有休息点，`rest` 权重按 0 算（`NodeEvents.reveal` 传一个排除表给 `random_pick`）。沙盒数字不含这一条（它在运行时）。

### 3.5 推荐

- **A = ① + ② + ③ 一起做**（推荐）。三个旋钮互不打架：① 定「旁边长什么」，② 定「全图各占几成」，③ 定「休息几个、不挨着」。作者玩过还嫌搜索多，再加 B 那一刀。
- **B = A + 搜索路线 3 / 1 / 1、保底六成**：全图搜索最少，但「沿途大多是搜索点，战斗很少」那句路线介绍得改。
- **C = 只做 ② + ③**：改数字就完，三条路线旁边还是一个样，和「路线有风格」（5.4.2）背道而驰。
