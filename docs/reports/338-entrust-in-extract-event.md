# 338 · 撤离时能点到【托付】

> 来源：报告 337 第一节的顺带发现，协调 2026-11-19 20:46 派发。v6.59 落地。

## 目标

报告 337 指出：真玩时撤离点走的是 `extract_default` 事件，地图上那个带【托付】的撤离确认框只有测试会打开。玩家在真玩里点不到【托付】。

## 一、在真实流程里确认

- 走上撤离点，`NodeEvents` 弹 `extract_default`，选项只有「撤离」「再看看」（加上 W1 的两项委托，不满足就不显示）。
- 带【托付】的确认框只有 `map_screen.extract()` 会开，游戏里没有调用方。
- 结论：问题属实，真玩点不到托付。

## 二、怎么修

撤离点事件**末尾**多一项「托付」（Entrust），只在能托时显示：

- 条件 `entrust_ready`：免费撤离点、出口没关、托付还开着（新钩子 `entrust_open`，在 `SafeModule` 里接；`GameFlow.entrust_open` 也改用它，一套判断）。
- 后果 `open_safe`：打开托付屏（就是原来的保险箱屏）。这个点不算用过，关了托付屏站着点节点（或走开再回来）就再弹撤离事件，照样能撤。
- 付费出口、出口关了、没装托付的图：这一项不显示。

放在末尾，W1 的「查验这处出口」「把信交给接应员」位置不动（还是第 3、4 项）。W1 测试里「四项」改成「五项」。
