## 二、要改的五件事

### 1. 跳字时长与暂停跟随回放

- 伤害跳字的时长按倍速缩短：1 倍 0.9 秒，2 倍 0.45 秒，4 倍 0.3 秒（设下限 0.3 秒，再短就看不清了）。上飘距离不变。
- 反应名弹字用同一套倍速系数（现在 2 倍速不缩短），下限 0.5 秒。
- 抖动和格子弹一下这两种反馈维持 157 的做法不动（只在 4 倍速缩短），这次只管字。
- 回放暂停（含反应讲解停住）时，场上所有跳字都停在原地，继续时接着飘。做法照 309 给反应名做的那样：每条字把自己的补间存下来，面板提供「全部暂停 / 继续」。
- 中途切换倍速：已经飘出来的字按原速飘完，新出的字按新倍速。
- 跳转、拖动进度时不弹字，维持现状。

### 2. 冰和雷有自己的颜色

- 建议初值（深底 / 浅底）：冰 `#7fd0ff` / `#1f5f8a`，雷 `#f2e36b` / `#6b5a10`。
- 雷的黄和暴击金接近；第 3 条落地后暴击不再用金色，冲突就没有了。
- 颜色由作者定：请 UI设计 出一张八种伤害色加治疗色并排的样张（深底、浅底、战斗沙地背景上各一行），作者挑定前先用上面的初值。
- 这两色改的是 `text_colors.json`，说明文字、战报里凡是用伤害色的地方会一起变；执行时过一遍这些地方有没有不合适的。

### 3. 暴击保留类型色

- 暴击不再换成金色，颜色仍然是伤害类型的颜色。
- 暴击靠三样区分：字号大一档（现有的 22 / 28 不变）、描边加粗一倍、出现时先放大到 1.3 倍再弹回（约 0.12 秒，跟倍速）。末尾的「!」保留。
- `UiPalette.CRIT` 这个颜色别处还在用，不删。

### 4. 反应伤害与反应名用双色渐变

- 反应名弹字：从左到右由第一种元素色过渡到第二种元素色（例：火加冰的反应，橙到浅蓝）。
- 反应打出的伤害数字（事件上带 `reaction` 的那一下）：同样用这两色渐变，这样一眼能看出这个数是反应打的。
- 两色从反应定义里的两种元素读，顺序用定义里的顺序；十种反应都自动得到，不逐个配。
- 做法建议：给这条字挂一个很小的画布着色器，按字的横向位置在两色之间插值，描边不受影响。要在三种文字大小、中英文下各看一眼。字只有一两位数时渐变区间很窄，可以让过渡集中在中间三分之一，保证两头颜色都看得出。
- 着色器不可用或出问题时退回第一种元素色（现状）。

### 5. 伤害数字加细描边

- 所有伤害与治疗跳字加一层细描边（`UiTheme.OUTLINE_SIZE`，暴击两倍），颜色用现有的 `UiTheme.OUTLINE_COLOR`。
- 目的只是在亮背景上看得清，不要粗到发黑。

## 三、执行时要守的既有规则

- 跳字是画面效果：保留 `exempt_bare_text` 标记；字号继续走 `UiTheme.sz`。
- `add_theme_` 覆盖数有上限（当前 75）：`popup` 里已有的两处不算新增；描边那两处尽量合进一个共用的跳字样式或做成一个小的跳字控件，不要让总数上涨。
- 深浅底：跳字画在战斗面板上，按面板声明的明暗取 `damage_color` 的对应一版（现在一律取深底版，顺手核对一下浅底面板上的效果）。
- 测试里不能等补间：用 `Tween.custom_step` 推时间。
- 代码注释里不要出现字库子集之外的新汉字；GDScript 警告保持 0；不要同时跑两个 Godot。

## 四、验收

1. 1 / 2 / 4 倍速下各录一小段：跳字时长分别约 0.9 / 0.45 / 0.3 秒；暂停时字停住，继续时接着飘。
2. 八种伤害类型加治疗各打一下的截图：冰、雷和白字能分开；浅色字在沙地背景上看得清。
3. 一次火属性暴击：颜色是火的橙色，更大、描边更粗、有一下放大。
4. 十种反应各触发一次：反应名和反应伤害数字都是对应两色的渐变；非反应的伤害仍是单色。
5. 新增测试：倍速对应的时长、暂停时补间停住、暴击取类型色、反应伤害取到两种元素色、没有反应的事件不挂渐变。全量测试通过。
