# 276 冷兵器扩充与武器进化路线

作者 2026-11-04 15:34（接 275 丰度评估）：「关于武器的添加，目前考虑加入更多类型的冷兵器（比如长柄武器和重武器），并且给现有的和未来的武器都设计至少两层进化路线」。

## 〇 一句话

进化就用铁匠铺现成的「改铸」配方（秘银附魔长剑 = 长剑 + 秘银锭 ×2 + 火晶，已经是这个形态）：**每把武器一条线，三层，每升一层稀有度至少 +1，且每层加一句新效果，不只是改数字**。新增四个冷兵器家族（长矛 / 巨斧 / 钉头锤 / 手斧）各一条线，再给现有 9 条线补齐缺的层。首批 25 把新武器，武器 19 → 44，正好落在 275 建议的 40 上下；不新开机制，全部用现有效果构件拼。

## 二、设计

### 1. 进化线的规则

- **一线三层**：基础 → 二层 → 三层；每升一层稀有度至少 +1（允许跳档，比如匕首 r0 → 淬火匕首 r1 → 涂毒匕首 r3）。
- **改铸配方**：`inputs` = 上一层那把 + 1–2 件材料 + 金币；分组沿用那把的组。二层配方铺子 2 级，三层 3 级；秘银线仍要「秘银冶炼」，其余不加新科技（先少再多）。
- **每层一句**：二层 = 数字上调 + 一句新效果；三层 = 再加一句或换触发。只改数字的升级不算一层。
- **形状**：同线形状同族，升层最多加一格（匕首线永远 1×2；长矛线 1×4 → 1×5 封顶）。
- **打法标签不变**：快攻线永远快攻，重击线永远重击，玩家认准线再投入。
- 已有三把一线齐的（剁刀线）改成改铸：放血刀吃剁刀、溃烂之刃吃放血刀（待定 1）。
- 信仰物（猎神长弓、胫骨大棒）：胫骨大棒作为蛮神线基础可以改铸；猎神长弓保持信仰奖励，弓线另起三层。

### 2. 新家族（四个，各一条线）

| 家族 | 打法 | 识别效果（全线共有） | 用的构件 |
|---|---|---|---|
| 长柄 · 长矛线 | 中速，1×4–1×5 | **起手**：开局先免费刺一下；命中给对手「易伤」1 层 | `on_battle_start` + `deal_damage`；`shift_axis(damage_taken, +1, 对手)` |
| 重武器 · 巨斧线 | 重击，2×3 | **劈砍**：命中流血 2 层；血多打得狠 | `apply_status(bleed)`；`per_target_stack` 加伤 |
| 钝器 · 钉头锤线 | 中速，1×3 / 2×3 | **破甲**：一部分伤害直伤，不吃护甲 / 格挡 | `deal_damage(direct_override)` 两段 |
| 斧 · 手斧线 | 快攻，1×2 / 2×2 | **见血**：命中流血 1 层，流血 ≥4 层时追加一下 | `apply_status(bleed)`，`on_stacks_at_least` |

重武器家族再把现有战锤线收进来（识别效果 **震慑**：命中对手减速 1 层，`shift_axis(attack_speed, −1, 对手)`），和巨斧线构成「重武器」两条线。

### 4. 玩家怎么看到线

- 道具说明窗加一行「可改铸为：{下一层名}」（铺子级数不够时灰字）—— 只一行，不画树。
- 铁匠铺配方卷轴里改铸配方排在同组末尾，图标用输出物的图；已有的「需要 X 级 / 需要科技」提示照旧。
- 图鉴（261 书架）不改；线的关系靠说明窗那一行就够（奥卡姆）。

### 5. 敌人

247 的 builds 可直接领新武器：长矛给帝国步兵，伐木斧给蛮族，钉头锤给机关卫兵 —— 执行按现有敌人池分三把即可，不要求全部。

## 三、改动清单（执行，作者确认清单后）

1. 25 个道具 json（形状、稀有度、材质、标签 `weapon / melee / rapid|burst / 家族 tag`、`combat`、中英文名；**说明字段留空给作者**，作者 16:04「生成道具时，不要写说明，永远留空给我」）；战锤数值与识别句；剁刀线两条配方改改铸。

3. 道具说明窗「可改铸为」一行（zh / en，UiText 键 `tip.reforge_into`）。
4. 家族 tag：`polearm 长柄` / `axe 斧` / `mace 钝器`（`heavy` 已有）—— 内部标签，不出提示。
5. 美术：25 张道具图 → 「美术设计」按 [[item-art-rules]] 出图，执行先用占位；图标不新增（配方用输出物图）。
6. 三把新白武器进敌人池；242 估力台跑一遍 → `docs/reports/balance/2026-11-xx-weapons.md`。
7. 测试：每条配方的输出稀有度 ≥ 输入 + 1；每把武器 DPS 在档位区间内；改铸扣走上一层。
