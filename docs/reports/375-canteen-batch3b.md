# 375 灰灯食堂第三批（下）：苗圃种食材、第二三畦、食材仓库接炼金（报告 355 落地）

> 日期：2026-11-21。方案见[报告 355](355-canteen-free-cooking.md) 第八节；上一半见[报告 374](374-canteen-batch3a.md)。到这里报告 355 的三批都落地了。

## 一、做了什么

- **苗圃作物**：主食六种（酸麦、黑豆、山薯、糙米袋、大南瓜、粗麦捆）、蔬菜六种（野葱、香根、长葱、大头菜、苦苣、卷心菜）、水果五种（野莓、山梨、蜜瓜、红果串、蜜柚）。灰灯食堂开了才能种，种苗由垦户社给，收成先进食材仓库。
- **周期和产量**（我按报告 353 的口径给的初值）：一格的两局收 4 件，两格的两局收 3 件，三格的长葱三局收 3 件，四格的三局收 2 件。
- **少量额外收成**：酸麦每件 15% 多收一件金穗麦，粗麦捆 25%；山薯每件 15% 多收一件白玉薯。多收几件按流水号定，读档重收一样多。
- **第二、三畦**：垦户社到信赖（50）开第二畦，代言（100，要结案）开第三畦。报告 355 只说「声望往上走时开」，这两个门槛是我的默认，要改就是一个数。老档读回来照旧一畦。
- **苗圃页**（占位排版，等 UI设计 出样张）：两畦以上时顶上一排「第 N 畦」键，熟了的写「可收获」。食堂开了以后，空地下面多一排栏键：药材 / 主食 / 蔬菜 / 水果。药材栏还是原来那两张大纸条；食材那几栏一排三张小纸条，写收成、几局、偶尔多收什么、【种下】。食材作物还没有作物图，先拿收成的图标顶着，长得越熟画得越大。
- **炼金**：食材仓库里的东西现在也能炼。炼金页的标签筛选多一个「食材」，选它再点一键炼金就会勾上食材仓库里的食材。还不能在炼金页上一件件点食材仓库，要的话得把右边那块盘换成食材仓库，等 UI设计 的样张一起做。
