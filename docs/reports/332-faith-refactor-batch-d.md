# 332 信仰重构 D 批：蛮神「怒气」、日神「烈日」、自然「生息」

- 来源：作者 2026-11-19 要求按 `handoff/2026-11-19-faith-system-implementation.md`（PR #663）实施信仰系统重构。
  - 本文是 D 批（方案 §6.1–§6.3、§9 D）。
  - A、B、C 批见报告 329、330、331。
- 版本：v6.48
- 范围：三位神换上新机制，换三阶阈值（候选 20 / 60 / 120），换新的信力行为。
  - 旧的等级效果按规格收掉，不和新机制叠。
  - 技巧、狩猎、大地不动。

## 1. 共同做法（沿用 C 批）

- **单位级规则**：一位神的整套战斗机制是一条单位级规则，扳机是 `FaithMechanicTrigger`，状态在 `RuleContext.state()`。
- **节拍**：这批扳机多了 `pulse`，频率层用新的 `FaithPulseCadence`。
  - 事件来了总放行；另外按战斗时间轴的整格自发一次，自发那一下 `event` 为空。
  - 日神的窗口、自然的周期治疗靠它。
- **信仰窗一阶一行**：perk 按 `part` 写几条，只有 part 0 编译。
- **信力**：三位神都是「打赢 +6」加机制次数（`MechanicDeed`）。
  - `MechanicDeed` 多了 `per_count` / `cap`，用来「按次给、封顶」，日神用它。
  - 每场合计不超过 10：蛮神 6 + 2 + 2，日神 6 + 4，自然 6 + 2 + 2。
- **低血打赢**：战斗账 `battle_summary.mechanic` 多了 `low_hp_won`。
  - 打赢时本方最后一次生命变化之后低于上限的 35%（`RunState.LOW_HP_WON_PERCENT`）就记一笔。
- **秒杀不记战斗信力**：秒杀（蛮神三阶）不再记战斗信力，所有神都一样。
  - B 批已经不给祈愿；这批连「打赢」那份也不给，不能拿跳过战斗换胜利分。
- **命名**：方案里的「怒势」改叫「怒气」，因为「势」不在字库子集里。

## 2. 蛮神：怒气（方案 §6.1）

| 阶 | 效果（候选数） |
|---|---|
| 基础 | 受到对手造成的生命伤害积怒气：按累计量，每失去最大生命 5% 一层，最多 5 层。下一次武器打出的直接伤害先取出并清零，每层 +6% |
| 一阶 | 一次用掉 ≥ 3 层的那一下穿透护甲 |
| 二阶 | 生命低于 35% 时怒气积得快 50%，上限不变。另有神坛献祭生命上限（照旧） |
| 三阶 | 一场一次，首次生命归零后坚持 3 秒（封顶）。另有战前秒杀（照旧，花体力或祈愿） |

- 什么不算积怒气：
  - 自伤、环境伤害（没有攻方）不算。
  - 护甲吸收的不算，只看真掉的血。
  - 一下伤害按最大生命封顶，超额致死不多给。
- 攒满之后不攒余量，反击用掉再从头积。
- 用掉怒气写战记（`brute_strike`，带用了几层）。
- 摘掉的旧效果：
  - 一阶「低血增伤（随信力涨）」。
  - 四阶「随信力涨的不屈 2～20 秒」。三阶不屈改成定 3 秒，走现有的 `CompileInput.keep_undying`，不能改信重置。
- 信力行为：
  - 打赢 +6。
  - 一场里用怒气反击过 +2。
  - 低血打赢 +2。
  - 原来「伤害 × 0.2」「失去体力」取消。

## 3. 日神：烈日（方案 §6.2）

| 阶 | 效果（候选数） |
|---|---|
| 基础 | 第 6 秒起每 6 秒烈日 2 秒，半开区间 [6k, 6k + 2)。窗口里每件武器打中的头一下追加这一下 20% 的火焰伤害 |
| 一阶 | 窗口外的原始出手给下一个窗口蓄力，全单位最多 3 次，每次 +10%，开窗时结算清零 |
| 二阶 | 神坛祈祷火焰加成（**过渡**，见 §5） |
| 三阶 | 每第 3 个窗口的追加 ×1.5 |

- 在不在窗口只按战斗时间算（`SunCycle.window_at`）。节拍只负责写「烈日开始 / 结束」进战记。
- 开窗时结算蓄力：节拍先到还是出手先到都只结算一次。
- 追加的来源是 0，不再引发追加，也不算原始出手。
- 摘掉的旧效果：
  - 一阶「随机 3 把武器附火」。
  - 三阶「全部武器附火」「开战 5 层灵巧」。
  - 四阶「按点类型必掉额外一件」。
  - 这样新旧全武器火焰不会同时叠满。
- 信力行为：
  - 打赢 +6。
  - 有追加的窗口每个 +2，最多 4。
  - 原来「火焰伤害 × 0.5」「道具出手 +2」取消。

## 4. 自然：生息（方案 §6.3）

| 阶 | 效果（候选数） |
|---|---|
| 基础 | 每 6 秒恢复最大生命 2%（自启动）。实际回上来的生命（治疗与每秒回血）20% 存进生息，最多最大生命的 15% |
| 一阶 | 生命低于 50% 时放出生息补血（补到满为止，按实际回的扣），两次至少隔 6 秒 |
| 二阶 | 棋盘上每件有效食物让容量 +2%，最多算 3 件。另有神坛献祭食物回体力（照旧） |
| 三阶 | 进加时的第一下得到【守护】：3 秒受到伤害 −20%，一场一次 |

- 生息放出的那口治疗不再存（`skip` 记着），没有「治疗 → 生息 → 治疗」的循环。
- 满血时治疗回不上来，也就不存、不算信力。
- 生息的层数 = 存着的整点生命，走现有的 buff 栏。
- 食物件数在编译时按棋盘数：包、不参战、整件休眠的不算。
- 摘掉的旧效果：
  - 一阶「每秒回血 +1」。
  - 三阶「按食物给护甲」。
  - 四阶「食物翻倍」。
  - 五阶「加时回春」。三阶守护替换掉它，不叠。
- 信力行为：
  - 打赢 +6。
  - 一场里实际回的生命到最大生命 10% +2（生息放出的不算）。
  - 放出过生息 +2。
  - 原来「自然道具触发 +3」「回血每点 +1」取消。

## 5. 与方案的差异

- **蛮神一阶「有限破甲」**：做成「一次用掉 ≥ 3 层那一下穿透护甲」，用现有的穿透旗，没另造减伤算法（同 C 批技巧）。
- **蛮神「单次有代价的献祭」**：用现有的二阶神坛献祭生命上限，没另做。
- **日神二阶「延迟首击（战前设置）」**：没做。要在战前屏加设置，那个文件归「落实局内界面布局方案」线程。先留旧的「神坛祈祷火焰加成」过渡，等战前屏样张定了再接。
- **日神一阶蓄力**：每次 +10% 是这批定的候选数，方案没给。蓄力没做成 buff，免得再要一张图；开窗时直接结算。
- **自然「过量治疗的 10% 计为生息」**：没做。资源变化事件只记实际回了多少，过量部分看不到，只按实际治疗的 20% 存。
- **自然「真正消耗食物恢复体力，每节点最多一次」**：没做。现在没有「吃食物回体力」的局内动作，只有神坛献祭食物（照旧）。
- **祈愿「满足该神特色条件再 +2」**：没做（B 批也没做），跟 E 批回归再看。
- **新 buff 的图标**：怒气、生息、守护三个先放占位图（复制现有的血怒、回血正层、坚韧），正式图另找美术。
