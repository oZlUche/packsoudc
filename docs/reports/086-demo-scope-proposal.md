## 二、提案：序章三「摆位与营地」（教「怎么摆、怎么花、怎么回来」）

一张分叉再归一、比序章二长一点的预设图（`line` 布局带 row），布鲁图斯，浮窗开着，intro 说清「这一次东西够多，决定胜负的是摆法」。

```
生 ── 搜(邻接件) ── 战(A) ── 休息 ── 商店 ┤ 战(B1: 强，掉套装最后一件) ├── 事件(总结) ── 撤(免费)
                                          └ 战(B2: 弱，无掉落) ── 付费撤离点
```

| 段 | 教什么 | 数据怎么做 |
|---|---|---|
| 搜索点 | **邻接槽**：搜到「内甲」（上方一格给护具 +1 甲）、「箭」（上方一格给远程 +20%）、一把短弓、一块「力量印记」（四邻的武器 +15%）。事件文字教「槽是道具轮廓外的格子，把对的东西放上去就亮」 | 已有道具，`search_finds` 写死；事件屏能开背包整理 |
| 战 A | 验证摆位：敌人中等，摆对了轻松、摆错了打得久。**打赢进账** | 敌人 `base_stats` 写死；经济规则 `battle_reward` |
| 休息点 | **体力**：先让战 A 扣一点（设一个「必输一场」？不 —— 改成事件后果 `spend_vitality 1` 说「路上崴了脚」），休息回 1。教「体力是命，输一场扣一点，归零就没了」 | `rest_default` 事件已有；体力扣在事件里做 |
| 商店 | **花钱**：货架上摆一件**套装第 2 件**（价格 = 进账刚好够）、一件诱惑品。教「套装两件亮一档、三件亮两档」 | 新套装 `imperial_kit`（制式短剑 + 圆盾 + 内甲：2 件 +1 甲，3 件 +10% 伤）；`ShopSession` 的货架现在按稀有度随机抽 —— **要加「节点内容 `shop_stock` 写死货架」**（小改） |
| 岔路 | **风险取舍**：B1 强敌、掉套装第 3 件、之后是免费撤离；B2 弱敌无掉落、之后是**付费撤离点**（费用 = 商店没花的钱）。浮窗写清两边 | `guaranteed_drops`；`PaidExtracts` 已有，预设图里撤离点 `content.fee` |
| 总结事件 | 摆位、套装、钱与体力三句 | 事件 |
| 撤离 | **仓库**：撤离确认里已经写「棋盘上的带回仓库」；通关解锁第一章，第一章开局屏第一次允许从仓库带入 —— 开局屏加一行提示（`ChapterDef` 加 `setup_hint` 文字） | 小改 |

需要新做的**机制**只有两个小口子：商店货架写死（`shop_stock`）、开局屏提示文字；其余全是数据。需要新做的**内容**：一套套装数据（三件都是已有道具）、四个敌人（复用已有 + `base_stats`）、约十二个事件、一张图。工作量与序章二相当。

## 三、序章之外，demo 还值得放的东西（按性价比排）

1. **第一章开浮窗、事件文字过一遍**：7 个占位事件的文字 + 浮窗一开，第一章立刻像正式关卡。半天。
2. **信仰一露脸**：第一章的搜索 / 商店里让「祝福长弓 / 祝福盾 / 力量印记」出现，浮窗与道具悬浮窗已经会写信仰与阶；再配一个「祭坛」事件（已有 `event_altar`）给信力。作者定的一级分类不出场，demo 就少了世界观的味道。一天。
3. **角色三选一**：第一章开局屏已能选；给安德烈乌斯「躲避」与马库斯「突击」各配一句开局屏说明和一个开局事件提示，让主动技能被按到。半天。
4. **进阶难度 / 猎手只露一眼**：第一章通关解锁「进阶 1」，开局屏灰字写「猎手会在图上追你」，不再多做。已有。
5. **战斗回放的可读性**：现在是日志重演，demo 观众看不出谁在打谁 —— 至少把双方的棋盘并排画出来、出手的那件闪一下。一到两天，是 demo 观感最大的洼地。
6. **道具图标**：全是色块 + 名字。作者有美术再换；没有就先统一一套占位符号。
