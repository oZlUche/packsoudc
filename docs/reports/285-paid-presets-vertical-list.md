## 〇 一句话

开局第二页的预设从行囊板里那一小排按钮，搬到**行囊板和仓库框之间那块空木板**上，做成一列挂牌（和右边仓库页签同一副皮）；预设分三档：**免费**（现有的强攻 / 坚守，094 的底线不动）、**收费**（一套白到蓝的装备，出发时按定价之和付钱、东西是真的，带得回来也丢得掉）、**高级**（要一张对应的**券**：仓库里有【制式券】才能选「制式」一套，出发时券消耗、整套新造进包 —— 三角洲行动的新兵券 / 制式券）。

## 一、现状（读码）

- 预设 = `LoadoutDef.preset = true` 的开局装备（096）：现在两套，`preset_offense` 强攻（长剑 / 剁刀 / 匕首 / 伤药）、`preset_defense` 坚守（圆盾 / 皮甲 / 剁刀 / 纱布 / 伤药），全免费；挑一套就把道具**免费**放进初始包，不占带入预算与件数上限、拖不进仓库 / 地上、出发带着走（`setup_screen.gd` 36–40、1025–1066；`GameFlow.presets()`）。
- 位置：第二页左边行囊板（背包皮框）顶上横着一排石刻纸条按钮「不带预设 / 强攻 / 坚守」（`_choice_column`，`PRESET_ENTRY_H` 52），226 批二把段头删了。
- 截图里的空白：行囊板（左）和仓库框（右，挂牌页签「一」「二」……）之间整块木板是空的 —— 180 补二定的三栏里，中栏「地上」255 补充二并进了仓库页签，中栏就空出来了。
- 277 第 2 条的【照上回带】在仓库下面，拉的是上回从仓库带的东西，不动。
- 定价：`ItemValue.of`（稀有度 × 尺寸，`ItemDef.value` 覆盖）；集市按 `MarketRules.price_mult`（现在 1.0）卖白到蓝的战斗道具。
- 带入预算（094）：从仓库带的东西按定价累计，超了换倒计时；预设套不算。

## 二、做法

### 2.1 三档预设（`LoadoutDef` 加一个字段 `tier`：`free` / `paid` / `advanced`）

| 档 | 东西从哪来 | 付什么 | 算不算带入预算 | 出发前能不能拖回仓库 | 回来之后 |
|---|---|---|---|---|---|
| 免费 `free` | 新造（现在的路，`give_kit`） | 不付 | 不算（094 底线不变） | 不能（只能在棋盘上挪，照旧） | 带回来就是你的 |
| 收费 `paid` | 新造 | **出发时**从仓库账上扣 **清单定价之和 × 集市倍数**（`ItemValue.of` × `MarketRules.price_mult`） | **算**（付了钱的也是带进去的东西，不算就绕开了预算） | 不能（还没付钱，不是你的；换一套就整套换掉） | 撤离带回来就是你的，死了就没了 |
| 高级 `advanced` | 新造（和免费一样） | **出发时**从仓库里消耗一张这套对应的**券**（`LoadoutDef.ticket` = 券的道具 id，锁住的券不算） | **不算**（券本身就是门槛，和免费的一样当底子） | 不能（券还没扣，不是你的；换一套整套换掉） | 撤离带回来就是你的，死了就没了；券不退 |

- 高级预设**没券选不了**：挂牌灰态加小锁 + 「要【制式券】」，悬停写券从哪来；有券就和免费一样点了即上棋盘，出发那一刻才扣券。
- **券**是普通道具：1×1、标签 `ticket`、材质 工艺、不能卖（集市不收、一键出售跳过）、不进掉落池与商店，`description` 空着。先两张：【制式券】`ticket_standard`、【精锐券】`ticket_elite`。
- 券从哪来（待定 3，推荐）：章节配置 `boss_ticket`：打赢核心 BOSS **必掉一张**（魔法废墟 → 制式券，机关沙漏 → 精锐券；序章不掉）；其余来源（成就、事件）以后再加。
- 价格不写进数据，由清单现算，道具调价预设跟着变。
- 序章（`allow_carry_in = false`）只列免费两套 —— 序章没有钱也没有仓库可拉。
- 付款时机是出发那一刻：钱不够，挂牌照样能点进去看，出发键灰、状态行写 `[coin_short]`（CoinShort 那套）；返回基地什么都不扣。

### 2.2 界面：中栏一列挂牌

- 位置：行囊板和仓库框之间（截图的空白），竖排、顶边和两块板对齐；每块挂牌和仓库页签同一副皮（180 定稿的挂牌：选中按下态、不可用灰态，高 60）。
- 一块挂牌两行：上行名字（两个字），下行小字：免费 = 不写（奥卡姆，牌上没有钱就是免费）；收费 = 硬币图标 + 价钱；高级 = 券的小图标 + 「×1」，没券时整牌灰态加小锁。
- 第一块是「不带预设」（照旧第 0 个）。清单一屏放 8 块（不带 + 7 套）；再多就这一列竖着滚，不缩牌。
- 悬停：这一套的清单（道具名，按顺序）；高级的多一行「要【制式券】×1（核心 BOSS 掉）」；预设的说明句（`description`）空着不显示。
- 点一块 = 换成这一套（现在的 `choose_preset`）；收费 / 高级的选中后出发摘要（第三页右边）多一行「预设：名字　价钱」。
- 行囊板顶上那一排按钮删掉，板子高度回收。

- 清单是草案，作者改 json 就行；`description` / `descriptions.en` 空着（道具说明那条规则同理，作者要写再写）。
- 校验（`ContentImporter`）：`tier` 只许三个值；`advanced` 必须写 `ticket` 且那件道具存在、带 `ticket` 标签；`paid` / `free` 不许写 `ticket`。

### 2.4 存档与结算

- 收费预设的道具出发时才造实例，和免费预设走同一条路（`_preset_uids` → `RunState.give_kit`），只是多扣一笔钱（`MetaState.spend_funds`）并把定价累进带入预算。
- 高级预设 = 免费那条路多扣一张券（`MetaState.warehouse` 里找一件 `ticket` id、`remove`）；存档不加字段。券掉落走 `core` 战胜结算（和 281 `_lesser` 掉落同一处挂钩）。
- 战记 / 结算不改：带进去的东西本来就按实例记。

## 三、改动清单（执行）

1. `LoadoutDef.tier`（默认 `free`，老数据不改也对）+ 导入校验；五套新 json（§2.3）。
2. `GameFlow.presets()` 按章节过滤（序章只免费）；`preset_price(def)`、`preset_ticket_ok(def, warehouse)` 两个纯函数（core）；两张券道具 + `ChapterDef.boss_ticket` + 核心战胜必掉。
3. 开局屏：中栏挂牌列（复用 180 挂牌皮 + `_mark_choice`）、悬停清单、没券灰锁、出发时扣钱 / 扣券 / 预算、第三页摘要一行；删行囊板顶上那排。券的 1×1 图先用占位，样张走 美术设计。
4. 测试：免费照旧；收费出发扣钱、钱不够出发灰；收费算预算、券换的不算；高级没券选不了、有券出发扣一张且券不退；核心 BOSS 掉券；券不能卖；序章只有两套；换套不重复扣钱。
5. `UiText` 新键：「要%s ×1」、摘要行「预设：%s　%d」；两张券的名字【制式券】【精锐券】。
