# 316 合成与锻造改造 D 批：拆掉休息点的砧和全部升级配方

> 日期：2026-11-13。作者 2026-11-13 16:53：「根据最新方案，局内的休息点铁砧已经没有存在的必要，删掉吧，确认一下是否已经删除所有局内升级道具的配方路线」。
> 方案：[合成与锻造改造](../plans/2026-11-11-fusion-and-forging-reform.md) §3 的 D 批、§7 来源门禁。前置：B 批清单（[307](307-fusion-reform-batch-b.md)）、C 批替代来源（[310](310-fusion-reform-batch-c.md)）都已落地。

## 一、结论

局内已经没有任何「拿一件道具升成更好一件」的路线了：

| 路线 | 现在 |
|---|---|
| 休息点的砧（上一把武器 + 一类材料 → 高一档，免费一次） | **删了**。营地「铁炉」只剩铸炉（附魔），铸过就关 |
| 82 条 `anvil_*` 升级配方（砧和基地铁匠铺共用） | **删了**（数据和导入后的资源都删） |
| 铁匠铺里「吃一把武器」的配方 | **没有了**。新测试逐条查：铁匠铺 34 张配方都不吃武器 |
| 别的局内入口（事件、商店、神坛等） | 查过，没有改品质或升档的效果；唯一会写品质的只有铁匠铺打造 |

留下的局内合成是**拼接**（两件拖到一起合成一件，23 张），按方案保留，不算升级路线。

## 二、删了什么

- 代码：`Anvil`（core/run/anvil.gd）、`AnvilColumn`（铁炉屏左栏）、`UpgradeCompare`（砧和铁匠铺的升级前后两窗）、`Smithy.preview`、`GameFlow.anvil_open / anvil_strike`、`HoverTip.show_meta`（只给两窗用）。
- 悬浮窗：「可升为」一行，以及砧配方的子窗（要什么、品质一句、在哪锤）。「可拼为」的配方词和子窗照旧。
- 数据：82 条 `anvil_*` 配方；图 `assets/ui/anvil/`（锤键、铁板、槽位字形）和棋盘框 `frame_anvil`。
- 文本：`anvil.*`、`camp.anvil`、`tip.upgrades_to`、`tip.recipe_material / recipe_crystal / recipe_quality / recipe_where`；「砧和铸炉都不收这件」改成「铁炉不收这件」。
- 铁匠的提示句 guide_3（讲的是休息点的砧），换成一句新的「旧家伙我不回炉了，料凑齐了拿来，给你打把新的」。真池子测试要六句，所以没有直接删。

## 三、来源门禁（方案 §7）

1. **82 条逐条有处置**（307 清单）：60 条成品本来就有随机来源；4 条另加了合成；3 把局内限定合成；15 把金武改为铁匠铺材料打造。新测试再查一遍：每件「不进随机来源」的武器都有打造或合成来源。
2. **限定物不漏出**：`no_random_source` 的过滤没动（C 批的测试照旧通过）。
3. **旧物不受影响**：武器 id、图、存档里的实例和品质都不变。旧档里锤出来的带品质武器照样读。
4. **旧档**：节点内容里的 `used_anvil` 没人读，直接忽略。砧的槽本来就不进存档，离开铁炉时东西会退回背包，所以没有要归还的东西。旧档 `discovered_fusion_recipes` 里可能留着 `anvil_*` 的 id，没有入口读它们，不清理。
5. **只拆砧**：铸炉附魔、休息、神坛、寂灭法杖计数、法杖装填都没动。
6. **没有死链接**：「可升为」、砧的说明、铁匠那句台词都拆了。帮助页、教程、科技文本里没有提到砧。

## 四、要作者知道的

- 铁匠铺少了 82 张升级配方，现在是 34 张：普通打造 19 张、金武材料打造 15 张。
- **四件材料没了打造用处**：砧要过「石 ≥ 绿」「木 ≥ 绿」，现在铁匠铺的材料格只有金属、骨 ≥ 蓝、木 ≥ 蓝、魔晶石。所以玄武岩、花岗岩研钵（石，绿）、风干木料、梣木枝（木，绿）只能卖或进铸炉附魔。可以给几张普通打造配方加石 / 绿木格，或者就这样（推荐先这样，等打造配方一起看）。测试暂时按「没有配方认」记。
- 执行（二）的难度候选 D4、D5 一直等这一批：局内拿不到升级以后，玩家战力会变，难度终值最好在这之后再测。
- `SmithRecipeDef.material_inputs`（旧的「一类一件、最低稀有度」写法）现在没有数据在用，但材料审计工具还读它，所以先留着。
