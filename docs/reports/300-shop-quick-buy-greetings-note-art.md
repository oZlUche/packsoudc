# 300 局内商店：双击 / 右键 / 拖进包都算买，商人问候语，纸条重画（290 / 284 补充）

> 作者 2026-11-11 13:29（架构设计线程）：「关于局内商店的交易，我希望左键双击/右键单击/将道具拖动到自己棋盘的空间内，都可以视作购买，前两种方法在物品放不下时会让东西掉到地上。然后给局内商人添加一些问候语，另外让美术设计一下消息框，目前的形式太简陋了」。直接指派：待定按推荐派执行；纸条美术走 UI设计 出样、作者挑。

## 〇 一句话

商人棋盘上的货，**左键双击、右键单击、拖进自己的棋盘**三种手法都是「买这件」；前两种自动找位，包里放不下就落到地上。进店时商人先说一句问候。NPC 说话的纸条由 UI设计 重画，出 A / B / C 给作者挑。

## 一、现状（读码 `ui/game/shop_screen.gd`）

- 拖：商人的货拖进自己的棋盘或地上 = 拿过来（染待成交色），按「成交」才结账（290）。
- 左键双击：`_double_merchant` → `take`，先进包、放不下落地（落在天秤和「离开」之间）。已经是作者要的样子。
- 右键单击：现在是「立刻钉住悬浮窗」（230），不买。**缺这一条。**
- 自己这边：双击自己的东西 = 放上桌（`offer`）；右键同样只是钉窗。
- 问候：没有。头像要点一下才弹纸条，掷一句提示（284）。
- 纸条：`NpcBadge.note` 是一块通用小牌皮（`PANEL_HOME_CHIP`）的方框，名字 + 一句话 + 「……」，没有专门的图。

## 二、做法

### 2.1 三种手法都算买

| 手法 | 对商人的货 | 放不下时 |
|---|---|---|
| 拖进自己的棋盘 | 买这件，落在你放的位置 | 放不下不让落（照旧弹回） |
| 左键双击 | 买这件，自动找位 | 落到地上 |
| 右键单击 | 买这件，自动找位（新） | 落到地上 |

- 「买」在 290 的规矩里 = **拿到自己这边、染待成交色、天秤左盘加上它的价**，按「成交」一起结账（待定 1：作者要是想「钱够就当场扣钱成交」，是另一种做法 B）。
- 对称的另一半（推荐，待定 2）：自己的东西右键单击 = 放上桌（和双击一样）；待成交的东西右键单击 = 收回（和双击一样）。这样商店屏里右键和双击处处同义，不用记两套。
- 右键原来的「立刻钉窗」在商店屏里让位；悬浮窗照旧停满时间自己钉住，窗里的「拿过来 / 放上桌 / 收回」按钮不变。别的屏右键不变。
- 拖到地上也算买（290 已经如此，不改）。

### 2.2 商人问候语

- `NpcLine.kind` 加一种 `greet`；`greet` 句不进点头像掷的提示池。
- 进店时头像旁自动弹一次纸条，掷一句问候（同一次进店只弹一次；点别处收起，之后点头像照旧是提示句）。专属对话条件满足时不抢：进店只说问候，专属对话仍然要点头像。
- 只给局内商人（哈基姆）写；基地两位这次不加（作者只点了局内商人）。
- 问候五句（照 284 的规矩：不带【】、不说术语、嘴甜心黑带「嘿嘿」；作者可以直接改）：

### 2.4 休息点铁炉屏同理（作者 13:30 补）

> 作者 2026-11-11 13:30：「休息点铸造同理，也让左键双击和右键单击成为快速置入道具的方法」。

- 现状：铁炉两栏屏（砧 | 铸炉）里，槽里的东西双击 = 取回、出件双击 = 拿走；包里的东西要放进槽只能拖（或用悬浮窗按钮）。
- 改成：包里（和地上）的东西**左键双击或右键单击 = 快速置入**。去哪个槽：**先砧后炉** —— 砧上有收得下它的空槽（武器槽收有升级配方的武器；材料槽收材料）就进砧；否则进铸炉第一个收得下它的空槽；哪边已经用过就跳过哪边；都不收就说一句原因（照现有的拒收句）。
- 槽里的东西、出件：右键单击和双击同义（取回 / 拿走）。
- 这一屏里右键同样不再钉窗（悬浮窗停满时间照旧自己钉）。
- 基地铁匠铺不涉及（那边是点配方，不放槽）。

### 2.5 全游戏排查：哪里该接这套快捷（作者 13:31）

> 作者 2026-11-11 13:31：「或者让一个线程专门负责检查哪里可以应用这个快捷选择」。本线程读码排了一遍（`item_double_clicked` / `actions_for` / `quick_target` 的全部接线）。

结论：**双击几乎处处都有了，缺的是右键**。右键现在全游戏只做一件事 —— 立刻钉住悬浮窗（230，`hover_tip.gd` 里统一接的）。所以不用一屏一屏补，定一条总规矩：

**右键单击 = 这件道具的双击动作**（悬浮窗按钮里排第一的那个）。唯一例外：双击动作是「放到地上」时（背包里没有别的去处），右键不丢，照旧钉窗 —— 丢东西不该一下就发生。钉窗改靠停留（照旧）。

| 界面 | 双击现在做什么 | 右键 | 要补的 |
|---|---|---|---|
| 局内商店 | 他的货 = 拿过来；自己的 = 放上桌；待成交 = 收回 | 没有 | 接总规矩（§2.1） |
| 铁炉屏 · 铸炉 | 包里的 = 进第一个空槽；槽里 = 取回；出件 = 拿走 | 没有 | 接总规矩 |
| 铁炉屏 · 砧 | **没有**（只能拖） | 没有 | 双击和右键都补（§2.4 先砧后炉） |
| 战利品 / 箱子 | 箱里 = 拿；包里 = 放进箱 | 没有 | 接总规矩 |
| 事件收获 | 拿进包 | 没有 | 接总规矩 |
| 祭坛 / 赎金盘 | 包里 = 放上去；台上 = 取回 | 没有 | 接总规矩 |
| 地上（局内） | 进包 | 没有 | 接总规矩 |
| 出发整备（仓库 / 包架 / 暂存 / 棋盘） | 快速置入 / 放回 | 没有 | 接总规矩 |
| 基地仓库（货架 / 包架 / 归来的棋盘） | 快速置入 | 没有 | 接总规矩 |
| 基地集市货摊 | 买（当场扣钱） | 没有 | 接总规矩 |
| 局内背包、没开别的屏 | 放到地上 | 钉窗 | 不动（例外） |
| 敌人棋盘、图鉴、结算页只看的棋盘 | 没有 | 钉窗 | 不动 |

## 三、改动清单（执行）

1. `shop_screen.gd`：商人棋盘、自己的棋盘和地上的右键单击接到和双击同一件事（`take` / `offer` / `withdraw`）；商店屏里右键不再钉窗。
2. `NpcLine.kind` 认 `greet`；`NpcChatter.open_lines` 排除 `greet`，新 `NpcChatter.greet(def, rng)`；`NpcBadge` 加「进屏自动说一句问候」开关，局内商店打开。
3. `data/authoring/npcs/shopkeeper.json` 加五句 `greet_1–5`（中英）；字集重做（`tools/font_charset.py` → `tools/subset_fonts.sh`）。
4. 测试：右键商人的货 = 待成交且进包，包满落地；右键自己的东西上桌、右键待成交的收回；进店自动出一句 `greet_*`、同一次不弹第二次、点头像掷的句里没有 `greet_*`；基地两位不问候。
5. 纸条定稿到了再换皮（UI设计 交接）。
7. 总规矩（§2.5）：`HoverTip` / `ContainerView` 那一处统一接 —— 右键单击 = 这件的第一动作；第一动作是「放到地上」或没有动作时照旧钉窗。逐屏测试：右键与双击结果一致（表里每一行各一条）；背包无去处时右键不丢东西。
6. 铁炉两栏屏（`forge_screen.gd` + `anvil_column.gd`）：包里 / 地上的东西双击或右键 = 快速置入（先砧后炉）；槽里与出件右键 = 双击。测试：有升级配方的武器右键进砧武器槽、配得上的材料进砧材料槽、砧用过了的进铸炉槽、都不收说原因、槽里右键取回。
