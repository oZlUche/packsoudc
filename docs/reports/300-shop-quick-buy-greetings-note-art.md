# 300 局内商店：双击 / 右键 / 拖进包都算买，商人问候语，纸条重画（290 / 284 补充）

> 作者 2026-11-11 13:29（架构设计线程）：「关于局内商店的交易，我希望左键双击/右键单击/将道具拖动到自己棋盘的空间内，都可以视作购买，前两种方法在物品放不下时会让东西掉到地上。然后给局内商人添加一些问候语，另外让美术设计一下消息框，目前的形式太简陋了」。直接指派：待定按推荐派执行；纸条美术走 UI设计 出样、作者挑。

## 〇 一句话

商人棋盘上的货，**左键双击、右键单击、拖进自己的棋盘**三种手法都是「买这件」；前两种自动找位，包里放不下就落到地上。进店时商人先说一句问候。NPC 说话的纸条由 UI设计 重画，出 A / B / C 给作者挑。

## 一、现状（读码 `ui/game/shop_screen.gd`）

- 拖：商人的货拖进自己的棋盘或地上 = 拿过来（染待成交色），按「成交」才结账（290）。
- 左键双击：`_double_merchant` → `take`，先进包、放不下落地（落在天秤和「离开」之间）。已经是作者要的样子。
- 右键单击：现在是「立刻钉住悬浮窗」（230），不买。**缺这一条。**
- 自己这边：双击自己的东西 = 放上桌（`offer`）；右键同样只是钉窗。
- 问候：没有。头像要点一下才弹纸条，掷一句提示（284）。
- 纸条：`NpcBadge.note` 是一块通用小牌皮（`PANEL_HOME_CHIP`）的方框，名字 + 一句话 + 「……」，没有专门的图。

## 二、做法

### 2.1 三种手法都算买

| 手法 | 对商人的货 | 放不下时 |
|---|---|---|
| 拖进自己的棋盘 | 买这件，落在你放的位置 | 放不下不让落（照旧弹回） |
| 左键双击 | 买这件，自动找位 | 落到地上 |
| 右键单击 | 买这件，自动找位（新） | 落到地上 |

- 「买」在 290 的规矩里 = **拿到自己这边、染待成交色、天秤左盘加上它的价**，按「成交」一起结账（待定 1：作者要是想「钱够就当场扣钱成交」，是另一种做法 B）。
- 对称的另一半（推荐，待定 2）：自己的东西右键单击 = 放上桌（和双击一样）；待成交的东西右键单击 = 收回（和双击一样）。这样商店屏里右键和双击处处同义，不用记两套。
- 右键原来的「立刻钉窗」在商店屏里让位；悬浮窗照旧停满时间自己钉住，窗里的「拿过来 / 放上桌 / 收回」按钮不变。别的屏右键不变。
- 拖到地上也算买（290 已经如此，不改）。

### 2.2 商人问候语

- `NpcLine.kind` 加一种 `greet`；`greet` 句不进点头像掷的提示池。
- 进店时头像旁自动弹一次纸条，掷一句问候（同一次进店只弹一次；点别处收起，之后点头像照旧是提示句）。专属对话条件满足时不抢：进店只说问候，专属对话仍然要点头像。
- 只给局内商人（哈基姆）写；基地两位这次不加（作者只点了局内商人）。
- 问候五句（照 284 的规矩：不带【】、不说术语、嘴甜心黑带「嘿嘿」；作者可以直接改）：

| id | 中文 | English |
|---|---|---|
| greet_1 | 哟，来客人了。慢慢看，都是好东西，嘿嘿 | Well, a customer. Take your time, it's all good stuff. Heh. |
| greet_2 | 又是你？活着就好，活着才能照顾我生意 | You again? Good, you're alive. The living make better customers. |
| greet_3 | 这种地方还能碰上活人，真是缘分。看看货？ | A living soul in a place like this. Must be fate. Care to browse? |
| greet_4 | 别光站着，看上什么尽管拿，价钱好商量 | Don't just stand there. Take what you fancy, the price can be talked over. |
| greet_5 | 朋友，你来得正好，我刚把摊子摆好 | Friend, perfect timing. I've only just laid out the stall. |

- 作者：「目前的形式太简陋了」。三位 NPC 共用同一张纸条，所以一起换。
