# 406 道具与信仰牌的联动设计

2026-11-28 · 与[报告 405](405-item-faith-integration-directions.md)对照，供 Claude 设计评审 · 候选方案，待作者取舍

## 一、希望玩家做出什么选择

同一件战利品，今天值得占两格带走，明天适合吃掉，换一套信仰又可能值得为它绕去祭坛。建议把这种估价变化作为融合的主要目标。信仰可以在后期贡献大部分伤害。判断背包有没有存在感，更直接的办法是看玩家换武器、拆邻接、腾格装货以后，下一场战斗和这趟撤离会发生什么变化。

以 11 月 28 日仓库主线为设计基线。以下示例覆盖蛮神、自然、技巧、大地及狩猎候选。前四者可从已有牌和道具出发，狩猎示例按已定的标记与兽材方向讨论。本文中的新牌效、配方和投放均为评审提案。

## 二、四种联动如何分工

| 做法 | 现有依据 | 适合的用途 |
|---|---|---|
| 道具和牌读取同一场战斗里的事件 | 技巧【收式】每 10 秒让下一次攻击按清零结算，连击层数保留。武器各有攻速与耗耐。 | 作为多数装备的默认关系。换武器会改变谁接上收式，无信者也能使用这把武器。 |
| 一张牌给一类战利品增加用途 | 蛮神【啖肉吮血】让血肉可以进食。大地【压缩】在祭坛把符合条件的物品转换为可堆叠结晶。 | 用于改变搜集与路线。一张牌就能让多个地图掉落变得值得捡。 |
| 手里的装备反过来影响选牌 | 自然【育种】看已有种子，技巧【徒手大师】会让拳头强化牌进入后续选择。 | 在选牌当下说明受益物。允许玩家因偶然捡到好东西，改走原先没打算玩的流派。 |
| 一件特定道具与一张特定牌共同解锁进化 | 参考《吸血鬼幸存者》先拿配件、投入武器、再找机会兑现的节奏。项目已有拖拽拼接和祭坛操作。 | 少量用于有辨识度的成品。适合让玩家记住一次特殊经历，同时保留使用原件的理由。 |

【基石】锁住装备和包的位置、【压缩】又能替一部分货物腾出位置。两张牌分别增加和释放空间压力，足以产生两种背包玩法。今后先检查已有机制能否承担这种选择，再决定要不要增加掉落种类。[大地落地记录](401-earth-god-landing.md) · [现有物品供给评估](400-item-faith-fit-assessment.md)

## 三、组合进化如何放进搜打撤

**基础件值得带，信仰牌单拿有用，进化由玩家在知道代价后主动兑现。** 搜到部件时告知对应的牌和地点，选牌时点亮已有部件，同时预览成品形状、占格、要交出的原件及会失去的旧效果。两样齐了就给确定的兑换机会。继续深入、绕路或者带原件撤离，本身已经提供了风险。

出征允许玩家从仓库配装，因此定向带件是合理策略。若每一局都从仓库拿同一件，为它留同一张牌，则要检查成品是否在所有场景都更强。能撤出的成品尤其要定清楚下一局的通用用途、改信后的状态以及是否还能再次兑换。已有局内拼接与局外锻造各有分工，优先沿用合适的入口。[局内拼接与锻造分工](316-fusion-reform-batch-d-remove-anvil.md) · [出征流程](383-departure-flow-landing.md)

### 用一个配方讨论取舍：铁木苗 ×【护佑】

**候选成品【铁木护符】。** 已持有【护佑】、背包里有长成的铁木苗时，可在祭坛把这株苗采制为一件两格护符。原件被消耗，失去其成长收益，这株苗造成的扎根随之解除；若同包另有锁定来源，仍按该来源处理。牌保留。先预览能否摆下成品，再确认兑换。

- **通用效果**：每场首次有武器直接伤害实际扣到自身生命后，回复一小部分已损失的防具护甲，以防具护甲上限为限。无防具时，预览直接写明本次收益为零。
- **与【护佑】配合**：本场的这一次修复可以改为在首次消耗新生时触发。摆包时选择触发方式。一次战斗只有一份修复，原牌照其牌文正常结算。
- **玩家为什么选或不选**：包已扎根、接下来想捡大件或换阵型时，采制能换回布局自由。离撤离很近、当前种植布局已经能赢，或没带防具时，继续留苗更合算。成品可随撤离带出，改信或下局缺少【护佑】时仍可用通用效果。
- **首要疑点**：持牌、种子成熟、途经祭坛三个条件能否在普通路线自然相遇？若试玩中总要专门带苗出门，先把输入放宽到任一成熟种子；若玩家只是想解开扎根，就应单独讨论采收规则。

这个例子用来评审“值得为进化改变什么决定”。修复量、获取频率和形状均待试玩。铁木苗的原有成长仍应按实际数据对照。[种子与扎根规则](392-seed-growth-for-nature-cards.md)

## 四、除了进化，各神可以怎么接道具

| 信仰 | 候选方向 | 想观察的决定 |
|---|---|---|
| 蛮神 | 先让战利品界面并列展示某块血肉的进食回报、售价和占格，沿用已经区分的肉与器官。 | 准备深入时愿意吃，临近撤离时愿意留；两次选择都讲得通。 |
| 自然 | 在普通档试一颗快熟草籽，长成可采为药材并腾出格子。成熟步数先试 3 步，普通搜索和【培育】都可获得。 | 是否值得多走几步，或中途为一件好装备放弃这株草？这条通用入口也能检验种子流前期是否可见。 |
| 技巧 | 用已有快慢武器与耐力件配【收式】，战后直接点出触发收式的武器、当时层数以及随后联动的效果。 | 玩家能否据此换掉一把面板更高的武器，且在下一场看见变化？ |
| 大地 | 【磐石】选牌预览列出当前哪些物品贴边、总共能得多少开场护甲及增加多少重量。拖动时更新预览。 | 一件新捡的大件，值得挤掉几件小物吗？回城前是否愿意拆掉一段阵型装货？ |
| 狩猎 | 候选【诱饵】让玩家战前消耗一件自选兽材，重掷一次标记，在新旧布局中择一。与带兽材行走得经验、留作战利品竞争。 | 愿意为哪种敌人花掉兽材？原阵型已经能打时，保留原料也是收益。 |

## 五、试玩与取舍

先用已落地的【收式】与【压缩】各走一局，作为低成本对照，再选择一个确切配方做纸面演练。记录三件事：玩家哪次因信仰捡了原本会丢的东西，哪次为组合挪过包或改过路线，哪次材料齐全却主动放弃进化。对没成型的局，也记下是缺牌、缺物、错过地点，还是主动撤离。

战斗贡献可用同一敌人种子、同一套信仰牌，分别比较认真配装、同档随手配装和腾格带货三种情况。记录胜负、剩余生命、占格、负重和实际撤离价值。武器与回复量已在报告 403 调整，旧对照仅用于选观察项。若换包始终无关紧要，先查具体哪张牌在何时接管战斗；若配方总是必做，先改进化代价或用途；若配方很少被看到，先查来源和提示。[数值调整](403-weapon-damage-and-heal-upscale.md)

**交给 Claude 的评审重点**：从四种关系中挑出能让现有道具产生新用途的一项，说明哪类普通掉落会受益；再判断示例配方的获取门槛、扎根处置和跨局价值是否值得增加一个实体成品。两项分别给出保留、调整或放弃的理由，供作者取舍。
