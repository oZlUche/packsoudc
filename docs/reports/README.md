# 开发报告索引

当前状态的总览在 [../status.md](../status.md)；这里是每一步的记录。

每完成一个实施步骤，在本目录下追加一份报告，文件名为 `NNN-<英文短名>.md`。

报告的固定结构：

| 小节 | 内容 |
|---|---|
| 目标 | 本步骤要达成什么，对应架构文档的哪一节 |
| 产出 | 新增／修改了哪些文件，各自的职责 |
| 关键决策 | 做了哪些非显而易见的选择，以及为什么 |
| 验证 | 怎么证明它能跑（命令 + 实际输出） |
| 遗留 | 本步骤未解决、留给后续的事项 |
| 下一步 | 紧接着要做什么 |

架构设计见 [../architecture.md](../architecture.md)。报告只记录「做了什么、为什么、验证结果」，设计本身的变更一律回写架构文档并在其变更记录里留痕，不要让两边的说法产生分歧。
