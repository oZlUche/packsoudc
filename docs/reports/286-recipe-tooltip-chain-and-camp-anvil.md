# 286 悬浮窗里点配方开子窗、休息点「铁炉」找不到砧子（279 补充）

> 作者 2026-11-07 15:02（架构设计线程）：「增加一个悬浮窗可以显示配方的设计，比如【骨牙匕首】可以升级为【嗜血骨刺】，那就让【骨牙匕首】的悬浮窗里可以唤起新的配方悬浮窗（鼠标移动到【嗜血骨刺】上面时）。同时我发现休息点的铁炉不能升级道具」。直接指派：待定按推荐派执行。

## 〇 一句话

道具悬浮窗「可升为：嗜血骨刺 / …」那一行的每个名字改成**可停留的词**（和 193 的关键词同一套机制）：停上去开一块**配方子窗**，写这把升成什么样（整段道具说明，按品质 0）、要什么材料、在哪锤；子窗里再有「可升为」就能接着往下开（深度照 `MAX_DEPTH` 封顶 3）。休息点升不了级不是坏了，是**入口没在作者点的地方**：休息屏的「铁炉」是 175 的附魔炉，砧（279）藏在背包窗底下一枚占位键「砧」里。改成点「铁炉」进一块两栏屏：左**砧**（升级）右**铸炉**（附魔），占位键删掉。

## 一、现状（读码）

### 1.1 「可升为」那一行

- `ItemTooltip.upgrades_line`（`ui/inventory/item_tooltip.gd` 412–422）：拿 `Anvil.upgrades_for(def, Anvil.recipes())`，把每张配方的 `output` 名字用「 / 」连起来，套 `tip.upgrades_to`（「可升为：%s」），整行 `@dim` 色。名字是死文本，停上去没反应。
- 悬浮窗子窗（193 / `ui/inventory/hover_tip.gd`）：只有 `[url=term:<id>]` 包着的词能开子窗，而且**窗得先钉住**（1024–1030 看 `parent.pinned`）：鼠标在源上或窗里停满 `PIN_DELAY_SEC 0.5 + PIN_SEC 0.6` 秒才钉（右键立刻钉，230）；没钉住的窗鼠标一离开道具就收（作者 10-27 定），进窗也算离开。词停 `TERM_SEC 0.25` 秒开子窗，深度封顶 `MAX_DEPTH 3`，离开整串 `AWAY_SEC 0.4` 秒收掉。
- 配方本身：`Anvil.upgrades_for` 只收「吃这一把 + `material_inputs`」的升级配方；`recipe_for` 配材料（`SmithRecipeDef.material_fits`：标签 `material`、`def.material == 材质`、稀有度 ≥ 要求；水晶写成 `crystal:<族>`）；`quality_of` 材料比要求高几档就几档品质。82 张砧配方的材料要求：骨 ≥ 绿 15 张、金属 ≥ 绿 14、金属 ≥ 白 13、骨 ≥ 白 13、木 ≥ 绿 4、木 ≥ 白 3、水晶（族）3、石 ≥ 白 1、金属 ≥ 蓝 / 紫各 1。比如 `anvil_bloodbone_spike` = 骨牙匕首 + 金属 ≥ 绿（钢锭 r2 配得上）。

### 1.2 休息点为什么「升不了」

- 休息屏（`ui/game/rest_camp_screen.gd`）的造物：篝火 / 祭坛 / **铁炉**（`forge_lit` 图，键 `camp.forge`，点了走 `flow.open_forge` → 175 的附魔屏 `forge_screen.gd`，只做附魔）。
- 砧（279 §四.3）走的是另一条路：休息屏底下一排按钮里一枚**占位键「砧」**（`camp.anvil`，221–224，注释「等营地造物图」），点了 `bag_window.open_anvil` 在背包窗右边开一栏 `AnvilColumn`（武器槽 + 材料槽 + 锤）。每个休息点免费一次（`Anvil.USED_KEY`）。
- 读码没找到配对逻辑的 bug（`GameFlow.anvil_strike` 1083 用 `smith_recipes`，测试 `tests/run/test_anvil_279.gd`、`tests/meta/test_anvil_recipes_279.gd` 都过）。最可能的两种情况：① 作者点的是「铁炉」（附魔），根本没进砧；② 进了砧但材料稀有度不够（骨牙匕首要**绿**以上的金属，白的铁锭配不上，槽里放了也不亮锤）。两种都是**找不到 / 看不出**，不是算错 —— 所以改入口和提示，不改配方逻辑。执行顺手核一下 `NodeEvents.effective_type` 对休息点不会翻成别的类型。

## 二、做法

### 2.1 「可升为」改成可停留的配方词

- `upgrades_line` 里每个名字包成 `[url=recipe:<配方 id>]名字[/url]`（下划线和关键词一样）；`HoverTip` 认 `recipe:` 前缀，和 `term:` 同一条路：停 `TERM_SEC` 开子窗、可钉、可再开、深度封顶 `MAX_DEPTH`。
- **配方子窗**（新 `RecipeCard`，走 `ItemTooltip` 的排版）从上到下：
  1. 出件那把的**整段道具悬浮窗**（名字、稀有度、各句、按品质 0；它自己的「可升为」一行照样是配方词 → 能一路点到橙）。
  2. 要求一行：「要　这把 + 【金属】≥ 蓝 ×1」—— 材料写**类**（材质名）和最低稀有度（颜色字），不写具体哪件；水晶配方写「【火系水晶】×1」。
  3. 品质一行（补充二的规则，一句）：「材料比要求高几档，出件就几档品质」。
  4. 在哪锤一行：「休息点的砧（每处免费一次）／ 基地铁匠铺（%d）」—— 铁匠铺价钱按 279 的 60 / 150 / 300 取这档。
  - 不写配方的说明文字（道具说明本来就是作者的，配方不另造文案）。
- **钉住的例外（推荐，待定 1）**：没钉住的窗，鼠标从道具**直接挪进窗里**本来要收（作者 10-27）—— 对「可升为」这行是死路：没钉住就点不到词。改成：鼠标从源进了窗，且窗里**有配方词**，窗不收、按 `PIN_SEC` 继续走钉住进度（进度线照 193 画）；进了窗又离开窗，`AWAY_SEC` 后照收。只有带配方词的窗享这个例外，别的窗行为不变。
- 第二页「图鉴」里的道具悬浮窗同样生效（同一个 `ItemTooltip`）。

### 2.2 休息点：点「铁炉」进两栏屏

- 「铁炉」造物点了不再直接进附魔屏，而是一块两栏屏 **砧 | 铸炉**：左栏 = 现在的 `AnvilColumn`（武器槽、材料槽、锤、预览），右栏 = 175 的附魔屏内容；两栏共用底下的背包棋盘（和现在砧栏开在背包窗右边一样的布局，附魔也从棋盘拖）。标题一行「铁炉」。
- 底下那枚占位键「砧」（`camp.anvil`）删掉；`camp.anvil` 键名改成两栏屏左栏的标题「砧」。
- 砧那一栏顶上一句状态：这处还没锤过 → 「免费一次」；锤过了 → 「这处的砧用过了」（灰）。槽里武器放上但材料配不上 → 材料槽红框 + 一句「要【金属】≥ 绿」（从 `upgrades_for` 取这把能配的第一类）；武器没有任何升级配方 → 「这把没有可升的」。
- 美术：两栏屏不要新图（A，推荐，待定 2）；要是作者想把砧做成营地里单独一个造物，就是 B（新造物图，走 美术设计），以后再说。

### 2.3 基地铁匠铺

- 不动：同一批配方当普通配方打（279），铁匠铺里的配方卡已经有材料行。只把 2.1 的配方子窗在铁匠铺屏里也开起来（道具悬浮窗是同一个）。

## 三、改动清单（执行）

1. `ItemTooltip.upgrades_line` 名字包 `[url=recipe:<id>]`；`HoverTip` 认 `recipe:` 开 `RecipeCard` 子窗（出件整段悬浮窗 + 要求行 + 品质行 + 在哪锤行）；深度照 `MAX_DEPTH`。
2. `HoverTip` 钉住例外：没钉住、鼠标从源直接进窗、窗里有配方词 → 不收，继续走钉住进度。
3. 休息屏：「铁炉」→ 两栏屏 砧 | 铸炉；删占位键「砧」；砧栏状态句与配不上的提示。
4. `UiText` 新键：「要　%s + %s」（这把 + 材料类 ≥ 色）、「材料比要求高几档，出件就几档品质」、「休息点的砧（每处免费一次）」、「基地铁匠铺（%d）」、「免费一次」、「这处的砧用过了」、「这把没有可升的」、「铁炉」标题、「铸炉」栏名。
5. 测试：配方词开子窗、子窗里再开（到 3 层停）、钉住例外只对带配方词的窗生效、别的窗照旧收；休息屏点铁炉两栏都在、占位键没了；材料配不上提示一句、锤不亮；锤过一次第二次灰。
6. 执行顺手查：`NodeEvents.effective_type` 对休息点返回的类型；`resolved_type` 不翻。
