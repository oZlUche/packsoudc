## 一 参考游戏的角色手法（抽出来的招，不是照搬）

| 游戏 | 它怎么做角色 | 能借什么 |
|---|---|---|
| 以撒的结合 | 一项面板走极端 + 一条**改规则**的机制：The Lost 没血但飞、Keeper 用钱当血、Lilith 自己不开火靠随从、Eden 全随机；**堕化（Tainted）版**把老角色的核心反过来；用成就解锁 | 规则改写比数值更有身份；老角色的「反面版」是最省美术的新角色；解锁条件挂成就（`data/authoring/achievements/` 现成） |
| 吸血鬼幸存者 | 角色 = 起手武器 + 一条随等级走的面板曲线（每级 +1% 伤害、Poe 磁力 +25% 但血 −30）；几个纯搞笑角色 | 起手装备定早期套路；**随一局推进成长的面板**（我们没有等级，用「全局倒计时走的步数」或「打赢的场数」当时钟）；短板写成负数 |
| 杀戮尖塔 | 职业 = 专属卡池颜色 + 起手遗物 + **专属资源**（机器人的球、观者的姿态） | 专属道具池 / 禁用池；一条专属资源（法力 `max_mana` 轴还是占位）；姿态 = 一局内可切的状态 |
| 搜打撤（塔科夫、Dark and Darker、Zero Sievert） | 职业靠起手包、仓库 / 保险、商人声望、专属行动（盗贼开锁、野蛮人破门）、专属撤离点 | 带入上限（正好用上那两个空字段）、撤离点规矩（免费点开更久 / 多一个口）、商人价、保险（战败保钱已是科技「行囊」，角色可以保**东西**） |
| 背包英雄 / Backpack Battles | **棋盘形状与摆放规矩就是职业**：机器人靠能量、钱包用钱、植物角色靠生长 | 我们是背包游戏，棋盘的形（缺角、分块、会长）、「包才算格」「贴边加成」是最有身份的差异；207 的【生长】、信仰的「训练棋盘」祭坛（`altar_train_board`）都是现成的雏形 |
| 暗黑地牢 / 哈迪斯 | 英雄 = 职业 + 怪癖；武器即职业 | 「怪癖」= 随机抽一条小被动 + 一条小短板，给同一角色不同的局 |

## 二 可以拉开差异的十二个维度

按「现成 / 要加构件」标：

1. **面板**（现成）：除三项外还能写伤害、急速、暴击、格挡、护甲上限、生命回复。
2. **棋盘的形**（要加 `board_mask`：缺角 / 分成两块 / 中央法阵格；「会长的棋盘」可借 `altar_train_board` 的加格逻辑）。
3. **包与摆放规矩**（部分现成）：初始包的数与种类；「只有包里的格才算」「贴棋盘边的件 +X」（`AbilityRule` 的邻接条件要加「贴边」）。
4. **专属资源**：法力（`RES_MANA` / `max_mana` / 充盈·枯竭轴都在，用法没定）、护甲代血、以血为代价（自伤效果现成）、钱当血。
5. **行程**（现成多）：免步、多搜、侦察、潜行、猎手关系、倒计时长度、出生在第二环、免费撤离点开得久（要加）。
6. **经济 / 局外**（部分现成）：开局钱、战利品倍率、商店价、**局内卖价**（251 的 0.3 可按角色乘，要加 `sell_ratio_mult`）、保钱、**带入上限**（两个空字段）、保东西。
7. **信仰**（要加）：开局自带信力、只能信一位（锁信仰）、**无信者**（世界观里现成的身份：不进祭坛、不受神罚、信物不休眠）。
8. **战斗规则**（`AbilityRule` 现成）：低血增伤、受击反击、每几下必暴、元素标记不衰减、反应的 N 取大不取小（175）。
9. **道具池**（要加）：专属掉落 / 禁用标签（`banned_tags`，像杀戮尖塔的卡色）。
10. **一局内成长**（要加 `grow_per_steps`）：每走几步 +1 生命上限、每打赢一场 +1 伤害——吸血鬼幸存者的曲线。
11. **随机性**：开局面板在区间里随机、起手包随机（以撒 Eden）。
12. **反面版**：老角色的堕化版，核心机制翻转，成就解锁。

主动技能先不设计（166 对玩家隐藏）；新角色以**两条被动 + 一条短板**立身，主动留空。

## 四 要补的构件（按几条草案共用的程度排）

| 构件 | 谁用 | 一句话 |
|---|---|---|
| `CharacterDef.unlock`（成就 id） | 全部新角色、堕化版 | 选角屏灰卡 + 条件一句；`Achievements` 现成 |
| `banned_tags` / `allowed_tags` | 1 / 2 / 9 | 编译器与拖拽拒收带该标签的件（像 249 的 `drop_filter`） |
| `grow_per_steps`（`RunEffect`，订 `ActionClock.advanced`） | 9 / 11 | 每 N 步给一条面板 +X，存进 `RunState`，和 207 的生长同一口时钟 |
| `faith_rules`（锁信仰 / 无信者） | 2 / 5 | `FaithState` 开局锁或禁；信物休眠（244 补一）按角色免 |
| `sell_ratio_mult` | 3 | 251 的 0.3 乘一个角色系数 |
| `board_mask` | 1 | 棋盘某些格有标记 / 不可用；`GridInventory` 要会读 |
| 按标签的额外掉落 | 7 | 现有 `extra_drop_by_node` 改成按标签 |
| 随机面板 | 10 | 开局屏抽、写进存档 |

## 五 推荐先做哪三个

挑**三个互不重叠、各站一个维度**的，各写一篇方案（面板、棋盘、被动、短板、美术）再派执行：

1. **军团魔法师**（草案 1）——接上 246 / 247 / 252 的晶石与法杖线，给法杖一个「主人」；法力轴顺便有了用法。
2. **血斧蛮族**（草案 2）——信仰锁 + 禁装备，是第一条「改规则」的角色，也让蛮神有个脸。
3. **行商**（草案 3）——经济轴，用上 251 的卖价与集市。

堕化版（草案 12）最省美术，可以在三个之后作为「老玩家内容」一批做。

## 六 不改

- 三个现有角色的面板与技能（149 / 136 已定）；科技不跟角色绑定；主动技能继续隐藏。
