# 080 · 信仰体系（提议，等作者拍板）与暂存区新规则（已实施）

> 第 8 阶段 8-4 ｜ 架构文档 3.4、16（v1.78）｜ 前一步：[079 世界观与封存](079-worldview-and-sealed-items.md)｜ 世界观：[docs/worldview.md](../worldview.md)

作者对世界观第五节的回答，一次给了道具体系的核心机制：

> 各种神明、魔法（现在的魔法独立于神明）、修士（皇帝扶持的全新一神教信仰，用以对抗诸神信仰）、士兵对应不同流派。目前考虑做两个大类，比如剑术大师对应暴力之神信仰，
> 军团士兵对应战争之神信仰，火焰（魔法）对应太阳与火之神信仰等等。玩家可以通过选择道具切换信仰，但只能激活最后一个置入背包的信仰体系道具（可以通过将道具挪出到暂存区再挪入背包切换，
> 任何时候哪怕在地图移动前都可以打开背包并将东西放入暂存区，但一旦进入就会失去 —— 也就是说进行双重检查，离开节点一次，进入节点一次，如果这个对前面的修改很大，那就放弃）。
> 在未来会加入完整的新教系统，和诸神信仰不能同时激活，玩家也可以选择「不信者」系列，每个体系都有自己的武器、饰品、防具、珍宝、小道具等等。

两件事：**暂存区的双重检查**改动很小，本报告一并实施了；**信仰体系**是道具、敌人、角色的一级分类和一套新机制，先把理解与方案写清，等作者答几个问题再动手。

## 一、暂存区：只是节点内的临时区（已实施）

060 定的是「走出发生过事的点才清；出生点、岔路、路过的点不清」。作者改成：任何时候都能开背包把东西挪进暂存区（换信仰道具的置入顺序就靠它），
**但一旦移动就没了 —— 离开清一次、进入清一次**。改动三处：

- `RunState.will_clear_storage()`：暂存区有东西就清，不再看这个点发没发生过事。
- `_drop_storage_if_leaving()` 走之前清（离开的那一次）；`_on_arrive()` 包在节点事件外面，头一回踩上一个点时**先清再让事发生**（进入的那一次）——
  顺序不能反，不然事件给的东西刚进暂存区就被自己清掉。空的不发信号。
- 走之前的提示照旧按设置档位（`StorageWarning`），只是「会清」的判断变宽了。`last_handled_id` 仍记着（事件层要用），只是不再决定清不清。

测试 `test_storage_rule` 的那一组按新规则重写：离开出生点也清、穿行也清、走不成不清、进入头一回踩上的点先清再发生事、空的不发信号。
**对前面的修改不大**：三个函数，没有别的系统读那条旧规则。

## 二、信仰体系：我的理解

- **信仰是道具的一级分类。** 每个信仰体系（暴力之神、战争之神、太阳与火之神……）有自己的武器、饰品、防具、珍宝、小道具。
  三个大类互斥：**诸神信仰**（各位神各一个体系）、**新教**（皇帝扶持的一神教，将来加）、**不信者**（也是一个系列）。魔法独立于神明 ——
  但「火焰对应太阳与火之神」说明魔法的各个元素还是各归一位神。
- **流派 = 信仰。** 剑术大师 / 军团士兵 / 火焰魔法这些「流派」各对应一个信仰，敌人的流派标签（现在的 melee / rapid / burst / bleed）可以换成信仰 ——
  一个蛮族剑术大师就是暴力之神的信徒，掉的也是那一系的东西。
- **激活规则**：任何时刻只有一个信仰激活 = **最后一个置入背包的信仰道具**所属的那个。切换 = 把一件那一系的道具挪到暂存区再挪回来。
  没有信仰的道具（口粮、伤药、包、材料……）不参与。
- **「目前考虑做两个大类」** —— 我读成「先做两个体系当样板」（比如暴力之神与战争之神），机制做通、内容再铺。要是指「诸神 / 不信者两个大类」，请指出。

## 三、方案

### 数据

- 新内容种类 `faiths`：`FaithDef { id, display_name, camp（gods / church / faithless）, god, description }`。走管线、进注册表式的清单（作者加一位神 = 加一份 JSON）。
- `ItemDef.faith: StringName`（空 = 无信仰之物）。现在的十九件按它归类：制式短剑 / 长剑 / 圆盾 / 内甲 → 战争之神（军团）；弯刀 / 皮甲 / 力量的符号 → 暴力之神（蛮族 / 剑术大师）；
  技巧之神的盾、狩猎之神的长弓各归各的神；魔晶石、附魔长剑 → 元素（待定归哪位神）；伤药 / 纱布 / 口粮 / 包 / 材料 / 战利品 → 无信仰。
- 世界观标签那一层（imperial / barbarian / blessed……）由 `faith` 取代，不再另立。

### 机制

- **置入顺序**：`GridInventory` 记一个只增的计数，每次放进棋盘（包括从暂存区挪回来）给那件实例盖一个 `placed_seq`；存档带着。
  **激活的信仰** = 棋盘上有信仰的道具里 `placed_seq` 最大的那件的信仰。开局屏的棋盘同一条规则（带哪件最后放，进图就是哪个信仰）。
- **别的信仰的道具怎么办**：默认**休眠** —— 编译战斗单位时跳过它们的战斗数据与邻接（占格照占、价值照算），套装也不计它们。
  这是一条数据：`FaithRules.dormant_mode`（inert / 按比例削弱），数值不写死。
- **互斥**天然成立：只有一个激活，诸神与新教不会同时；不信者也是一个 `faith` id（camp = faithless）。
- **切换的代价**：作者没说，默认没有（挪一次就换）。可以是数据：切换时扣体力 / 扣行动点 / 一局限几次。

### 界面

棋盘面板与开局屏标出激活的信仰，休眠的道具灰掉并写「休眠：信仰不同」；HUD 一句「信仰：战争之神」；图鉴按信仰分组。

### 顺带的

- 敌人：`EnemyDef.schools` 改成信仰 id（或两者并存一段时间）；敌人池按信仰组装备。
- 猎手 / 木桩校准不受影响（它们只看编译后的战斗单位）。
- 角色：种族的赐福（技能）和激活的信仰是两回事 —— 一个蛮族（暴力之神的天赋）可以拿着战争之神的剑；要不要「本族信仰有加成」是数据。

### 性价比与矛盾

- 代码量中等：置入计数与存档、编译器一处门、界面标记、导入器校验、内容种类一个。一步能做完。
- 矛盾一：**套装**（019 / 020）与**邻接**（星形 / 菱形）跨信仰怎么算 —— 休眠的道具不给邻接、不计套装，最简单也最好解释。
- 矛盾二：**顶替式放置**（3.3.1）：把一件信仰道具顶进来会顶掉别的，被顶出的进暂存区、一走就没 —— 这正是作者要的取舍，但界面得提醒。
- 矛盾三：无信仰之物太多则信仰没意义，太少则前期没得选 —— 内容的事，等体系铺开再调。
