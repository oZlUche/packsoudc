# 389 阵营奖励改成「声望到了某个数，触发某个效果」

> 2026-11-24。作者 16:10：「将阵营奖励改个形式，不再是达到多少升级，而是声望到了某个阈值触发某个效果」。
> 这份是方案，涉及所有阵营。里面的数字和做法都是我的初值，不是裁定；第五节是要作者定的。

## 一、现在是什么样

每个阵营都是同一把梯子：五档（初识 / 熟面 / 受托 / 信赖 / 代言），门槛都是 0 / 10 / 25 / 50 / 100。好处全部写成「到第几档」：

| 阵营 | 现在挂在档位上的东西 |
|---|---|
| 所有阵营 | 熟面（10）能接调查委托和许可单；受托（25）能接结案委托，办完许可单后告示栏出这一方的常规委托；代言（100）还要先做完这一方的结案 |
| 万神院 | 到来：蛮神、日神、技巧之神；熟面：狩猎、大地、自然；受托：信神时经验 +10%；信赖：祭坛【赐福】；代言：空着（作者 11-24 定先留空） |
| 魔法师协会 | 信赖（50）能接炼金术那份委托；代言（100）炼尘折损 40% → 25% |
| 灰灯互助会 | 受托（25）能接食堂那份委托；信赖（50）锅 4×4 → 5×5、食材仓库 6×6 → 8×8；代言（100）锅 6×6、仓库 10×8 |
| 河滩垦户社 | 熟面开第一片地；信赖（50）第二片；代言（100）第三片 |
| 后勤部队、地图协会 | 只有委托的门槛，没有别的档位效果 |
| 使团、北境猎盟 | 还没开放 |

问题在这把梯子本身：每个阵营必须正好五级、门槛必须一样，一级里塞几样东西还是空着都得迁就它。万神院第五档现在就是空的。玩家看到的是「熟面」「受托」这种名字，得再去查这一档到底给什么。

## 二、改成什么样

**去掉档位，换成每个阵营自己的一串「声望节点」。** 一个节点 = 一个声望数 + 一个效果。声望涨到那个数，效果就触发。

- 每个阵营的节点各写各的：几个节点、落在哪个数上，互相不用对齐。
- 一个节点只放一个效果。同一个数上要给两样，就写两个节点。
- 声望怎么涨不变（委托给的声望照旧），存档里的声望数不用换算。
- 「初识 / 熟面 / 受托 / 信赖 / 代言」这五个名字不再用。

### 节点的三种效果

| 种类 | 例子 | 触发时 |
|---|---|---|
| 开放 | 开放一位神、开放一份委托、祭坛多一个选项 | 立刻生效，之后一直在 |
| 提升 | 锅变大、多一片地、折损降低、经验 +10% | 立刻生效，之后一直在 |
| 赠礼 | 送一件道具、一笔钱、一张配方 | 节点亮起，玩家点【领取】才拿到（和委托不自动发奖是同一条规矩） |

第三种是新的。有了它，节点之间可以放一些小甜头，不必每个节点都是一项功能。

### 界面

委托簿里每个阵营现在是一行五个小点。改成一条声望刻度：

- 一条横槽，按声望数填充，旁边写当前声望数。
- 每个节点是槽上的一个图标，位置按它的声望数排。到了的亮，没到的暗。
- 鼠标放上去看这个节点给什么、还差几点。
- 还没到的节点，效果照样看得见，玩家知道在为什么攒声望。要藏起来给惊喜的节点可以单独标成「？？？？」。
- 节点到了的那一刻，用万神院到来时的那种通知（招牌亮起），以后别的解锁也是这个样式。
- 有赠礼没领时，委托簿入口上亮红点。

版式由 UI 线程出样。

## 三、现有的东西怎么搬过去

第一步原样搬，一个效果都不增不减，玩家手里的东西不会变：

| 阵营 | 节点（声望数：效果） |
|---|---|
| 所有阵营 | 10：开放调查委托和许可单；25：开放结案委托，办完许可单后出常规委托 |
| 万神院 | 0：蛮神、日神、技巧之神；10：狩猎之神、大地之神、自然之神；25：信神时经验 +10%；50：祭坛【赐福】 |
| 魔法师协会 | 50：开放炼金术委托；100：炼尘折损降到 25% |
| 灰灯互助会 | 25：开放食堂委托；50：锅 5×5、仓库 8×8；100：锅 6×6、仓库 10×8 |
| 河滩垦户社 | 10：第一片地；50：第二片地；100：第三片地 |
| 后勤部队、地图协会 | 只有上面通用的两个节点 |

万神院 10 点那一个节点一次开三位神，按「一个节点一个效果」应该拆开。拆不拆、拆到哪几个数上，见第五节第 3 条。

搬完以后，再往每条刻度上加新节点就只是加一行数据。后勤部队和地图协会现在最空，最需要补。

## 四、要改的地方（给执行）

- 阵营数据：`thresholds` 和 `services` 换成一张节点表（声望数、效果种类、效果内容、是否隐藏）。
- 所有读「第几档」的地方改成问「某个节点到了没有」：委托接取门槛、常规委托、万神院的几项服务、炼尘折损、食堂的锅和仓库、苗圃的地。
- 委托上的 `min_tier` 改成要多少声望。
- 赠礼节点的领取状态进存档。老存档读进来：已经过了的开放、提升节点直接算数；赠礼节点算没领，可以补领。
- 委托簿的五个小点换成声望刻度；节点触发的通知。
- 字表里五档的名字和用到它们的句子清掉。
