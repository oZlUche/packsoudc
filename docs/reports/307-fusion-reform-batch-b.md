## 四、18 件金武的新来源

| 金武 | 新来源 | 需求（建议初值） | 资金 | 解锁 |
|---|---|---|---|---|
| 炎牙、霜牙、雷霆重弩 | 局内相邻合成（限定） | 两件具体输入 | — | 第一次合成即发现 |
| 14 件元素金武（火 7 + 冰 3 + 雷 4，按成品自己的材料） | 材料打造 | 同族魔晶石 ≥紫 ×1 + 成品材料（金属或骨）≥蓝 ×2 | 300 | 铁匠铺 3 级 |
| 帝国佩剑 | 材料打造 | 金属 ≥金 ×1 + 金属 ≥紫 ×1（不再吃秘银剑） | 300 | 铁匠铺 3 级 |

逐件的每一格合格材料见 `gold18_sources.csv`。品质一律固定 0：高档材料只满足资格，不提升成品品质（方案 §5.3）。

**建议初值怎么来的**：留下原升级里那颗魔晶石（同族、门槛不变）；去掉「上一把武器」，换成成品自己材料的两件蓝档；不沿旧链递归累加前驱材料（方案 §4.3 明文不要）。资金 300 比旧的最后一步升级（200）高，因为不再先要一把蓝 / 紫前驱武器；整条旧链的花费没有逐件算，C 批做出来后用实验对照。

## 五、要作者知道的取舍

1. **帝国佩剑的 ≥金 金属只有一种：苍白碎片**，而它要成就 ach_boss 解锁才进掉落。也就是打过 Boss 之前做不出帝国佩剑（旧路线里也卡在同一处：秘银剑要 ach_extract_3）。推荐照这样；若不想卡，改成「金属 ≥紫 ×2」。
2. 打造需求的件数（×1 / ×2）要 C 批先给 `SmithRecipeDef` 加独立的数量字段，旧 `material_inputs` 照旧读作「1 件、最低稀有度」。
3. 两张吃前驱武器的打造配方：秘银剑（长剑 + 秘银锭 ×2 + 低阶火晶）、大魔导杖（魔导杖 + 秘银锭 ×2 + 高阶火晶）。建议 C 批去掉前驱武器、用同档材料补足；大魔导杖本身有多个来源，方案说不随本批改成 Boss 专属。
4. 难度终值：v5.84 改了护甲顺序，D 批关掉升级后玩家局内战力还会变；执行（二）在重跑 D1–D3，D4、D5 等 D 批。终值最好 D 批之后再定。

## 六、和执行（二）的分工

开工前对过文件：执行（二）不动配方、道具、材料池和 `MaterialSupplyAudit`；它只改难度候选那几份。C 批若在审计工具上加材料数量审计，可以直接加。

## 七、未覆盖

- 只是清单：没有新增配方、没改任何稀有度、没加材料。
- 经济只给了资金初值；真实材料 / 资金消耗和打造→出售套利要 C 批做出来后用实验对照（方案 §9.3）。
- 「仅合成」标记（替代 forged_only 的明确来源策略）在 C 批落实，届时逐一核对搜索、敌人、商店、集市、事件池、信仰赠物、铁匠都不漏出。
