## 怎么读这张表、怎么改

| 表里的列 | 落在数据里的字段 | 改了要跑什么 |
|---|---|---|
| 阶数与阈值 | `thresholds`（非递减正数；阶 = 过了几道阈值） | 改 xlsx → `tools/gods_xlsx_to_json.gd` → `tools/import_content.gd` |
| 升级途径（信力行为） | `deeds[]`（`FaithDeed` 构件，16 种见 `RunRegistry.FAITH_DEEDS`） | 同上 |
| 献祭 | `offerings[]`（`OfferingRule`：`tags / min_cells / exact_grade / has_stat` 圈道具，`multiplier` 默认 ×1，`per_cell` 再乘格子数） | 同上 |
| 等级效果 | `perks[]`（`FaithPerk` 构件，`tier` 默认 1；17 种见 `RunRegistry.FAITH_PERKS`） | 同上；新效果要加构件 |
| 赐福模板 | `blessings[]`（`Blessing`：圈哪些道具、名字前缀、`rarity_up` 默认 +1、`value_mult` 默认 ×1.5、按阶 / 激活即 / 按信力的 `faith_bonuses`） | 不在 xlsx 里：直接改信仰 JSON → `tools/import_content.gd` |
| 包内转化 | `convert_chance`（默认 3%）+ `convert_per_tier`（默认每阶 +1%）：激活时每走一步，包里每件能被赐福的道具独立掷一次 | 改 xlsx → 同第一行 |
| 信物 | 道具标签 `faith:<id>`（250：带它的就是信物，派生赐福版除外；玩家显式「奉为主信仰」，棋盘上有它的信物才联系正常，3.8） | 道具 JSON |
| 道具按阶功能 | 信仰道具的 `faith_bonuses[]`（`tier` 从 1 起） | 道具 JSON |

信力只记**此刻激活**的信仰；各神各一个池子，切换不清（继承还没做，082）。

**信力与祈愿**（信仰重构 B，报告 330）：每位神两笔 —— 信力（devotion，累计成长，阶只看它，不花）与祈愿（prayer，可花的余额，上限 `prayer_cap`，没配 = 100）。祈愿来源：打完一场有效战斗 +8（输赢都算，秒杀不算），献祭 min(2V, 余量)。花祈愿的：祈求赐福 40、蛮神秒杀 30。花了不扣信力、不掉阶。数都是候选。神坛只在休息点、只在激活信仰时出现；常规献祭不限次数，特殊操作与献祭共享休息点的这一次机会（093 七）。

**六神战斗机制**（信仰重构 C / D / E，报告 331 / 332 / 333）：六位主神都是 3 阶 · 20 / 60 / 120，奉神即有一条基础机制（单位级规则，`core/battle/faith/`），一、二、三阶各加一句。信力统一是「打赢 +6」加这位神的机制在这一场真发生了几次（`mechanic` 行为），每场合计不超过 10；输了不给打赢那份，已经做到的照给；秒杀不记战斗信力。数都是候选，对照台架见报告 333。

## 二、升级途径：信力行为（`deeds`）

六位主神统一：打赢一场 +6（`battle{won_only}`），再加下面的机制行为（`mechanic`：按战斗账 `battle_summary.mechanic` 数）。每场合计不超过 10。

| 神 | 机制行为 | 给多少 | 另外 |
|---|---|---|---|
| 蛮神 | 用怒气反击过（`brute_strike`）；打赢时生命低于 35%（`low_hp_won`） | 各 +2 | — |
| 日神 | 每个借烈日追加过火焰的窗口（`sun_window`，`per_count`） | 每个 +2，最多 4 | — |
| 自然 | 实际回的生命到最大生命 10%（`nature_heal`，生息放出的不算）；放出过生息（`nature_release`） | 各 +2 | — |
| 大地 | 有大件受承托（`earth_support`，按件）：1 件、2 件 | 各 +2 | — |
| 技巧 | 攒到巧劲（开战送的不算）：1 次、3 次 | 各 +2 | 本局头一回得到一种工艺道具 +3（`item_acquired{first_kind_only}`） |
| 狩猎 | 拆到第一档（`hunt_stage1`） | +2 | 本局头一回置入一种兽材 2^稀有度 + 1（`first_place`） |
| 新教 | — | — | 事件里做任何选择 +1（`event_choice`） |

作者给的节奏（093 七）：前两场战斗到 1 级、4～6 个战斗节点到 2 级、小图一般升不到最高级、中图最后升到最高级；倍率、上限、阈值都是数据，不写死。
没被任何信仰用到的行为构件还有 `place_item` / `travel` / `earn_money` / `spend_money` / `explore`（082 占位时代的，留着可配）。

## 三、献祭（`offerings`，神坛，信力 = 2^稀有度 × 倍率）

每条规矩单独算 `2^稀有度 × 倍率`（`per_cell` 再乘格子数），一件道具**满足几条就加几条**（`FaithDef.offering_value`）；自己这位神的赐福版献回来再 × 2（095）。

| 神 | 收什么 | 倍率 |
|---|---|---|
| 蛮神 | 兽材（`beast_part`，250） | × 5 |
| 蛮神 | 武器（`weapon`） | × 2 |
| 蛮神 | 大及以上体积（≥ 9 格） | × 10 |
| 日神 | 魔晶石（`crystal`）、火焰（`fire`）、贵重品（`valuable`）（250） | 各 × 5 |
| 日神 | 体积**正好为中**的道具（`exact_grade: 2`） | × 5 |
| 自然 | 自然（`nature`）、食物（`food`）、防具（`armor` / `shield`） | 各 × 5 |
| 大地 | 大及以上体积（≥ 9 格） | × 5 **× 格子数**（`per_cell`） |
| 技巧 | 武器（`weapon`，250）、防具（`armor` / `shield`）、工艺（`crafted`，122） | 各 × 5 |
| 技巧 | 带暴击属性（`has_stat: crit_chance`） | × 8 |
| 狩猎 | 兽材（`beast_part`，250） | × 10 |
| 狩猎 | 食物（`food`，250） | × 5 |
| 新教 | 没有献祭规矩（神坛只有「返回」） | — |

## 四、等级效果（`perks`，过了第 N 阶起生效）

数值是现在的 JSON / 构件默认值（候选）。「基础」= 奉神即有（tier 0）；机制是一条单位级规则，信仰窗一阶一行（同一种 perk 按 `part` 写几条，只有基础那条编译）。各神 1 级都另有神坛「祈求赐福」（`altar_bless`，40 祈愿）。

### 蛮神「怒气」（`brute_rage`）

| 阶 | 效果 |
|---|---|
| 基础 | 受到对手造成的生命伤害积怒气：每失去最大生命 5% 一层（按累计量，一下按最大生命封顶），最多 5 层；下一次武器打出的直接伤害先取出清零，每层 +6% |
| 1 | 一次用掉 ≥ 3 层的那一下穿透护甲 |
| 2 | 生命低于 35% 时怒气积得快 50%；神坛献祭生命上限（`altar_sacrifice_hp`：−5 生命上限 → +20 信力，或这局全体造成伤害 +5%、急速 +5%） |
| 3 | 一场一次，首次生命归零后坚持 3 秒（`CompileInput.undying_sec`）；战前秒杀（`smite`：1 体力或 30 祈愿，不给祈愿、不记战斗信力） |

信物与按阶功能：力量的符号（稀有度 2）1 阶 = 开战时血怒；胫骨大棒（蛮神道具，不是信物）激活即暴击加成：暴伤 +20、暴击率 +10（116 起）。赐福（武器）：激活即增伤，再按信力累计加攻击。
