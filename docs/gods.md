## 怎么读这张表、怎么改

| 表里的列 | 落在数据里的字段 | 改了要跑什么 |
|---|---|---|
| 阶数与阈值 | `thresholds`（非递减正数；阶 = 过了几道阈值） | 改 xlsx → `tools/gods_xlsx_to_json.gd` → `tools/import_content.gd` |
| 升级途径（信力行为） | `deeds[]`（`FaithDeed` 构件，16 种见 `RunRegistry.FAITH_DEEDS`） | 同上 |
| 献祭 | `offerings[]`（`OfferingRule`：`tags / min_cells / exact_grade / has_stat` 圈道具，`multiplier` 默认 ×1，`per_cell` 再乘格子数） | 同上 |
| 等级效果 | `perks[]`（`FaithPerk` 构件，`tier` 默认 1；17 种见 `RunRegistry.FAITH_PERKS`） | 同上；新效果要加构件 |
| 赐福模板 | `blessings[]`（`Blessing`：圈哪些道具、名字前缀、`rarity_up` 默认 +1、`value_mult` 默认 ×1.5、按阶 / 激活即 / 按信力的 `faith_bonuses`） | 不在 xlsx 里：直接改信仰 JSON → `tools/import_content.gd` |
| 包内转化 | `convert_chance`（默认 3%）+ `convert_per_tier`（默认每阶 +1%）：激活时每走一步，包里每件能被赐福的道具独立掷一次 | 改 xlsx → 同第一行 |
| 信物 | 道具标签 `faith:<id>` + `faith_anchor`（最后置入的信物决定激活，3.8） | 道具 JSON |
| 道具按阶功能 | 信仰道具的 `faith_bonuses[]`（`tier` 从 1 起） | 道具 JSON |

信力只记**此刻激活**的信仰；各神各一个池子，切换不清（继承还没做，082）。神坛只在休息点、只在激活信仰时出现；常规献祭不限次数，特殊操作与献祭共享休息点的这一次机会（093 七）。

## 三、献祭（`offerings`，神坛，信力 = 2^稀有度 × 倍率）

每条规矩单独算 `2^稀有度 × 倍率`（`per_cell` 再乘格子数），一件道具**满足几条就加几条**（`FaithDef.offering_value`）；自己这位神的赐福版献回来再 × 2（095）。

| 神 | 收什么 | 倍率 |
|---|---|---|
| 蛮神 | 骨制品（`bone`） | × 5 |
| 蛮神 | 血肉（`flesh`） | × 5 |
| 蛮神 | 武器（`weapon`） | × 2 |
| 蛮神 | 大及以上体积（≥ 9 格） | × 10 |
| 日神 | 金属（`metal`）、火焰（`fire`）、宝石（`gem`） | 各 × 5 |
| 日神 | 体积**正好为中**的道具（`exact_grade: 2`） | × 5 |
| 自然 | 自然（`nature`）、食物（`food`）、防具（`gear` / `armor` / `shield`） | 各 × 5 |
| 大地 | 大及以上体积（≥ 9 格） | × 5 **× 格子数**（`per_cell`） |
| 技巧 | 金属（`metal`）、防具（`gear` / `armor` / `shield`）、工艺（`crafted`，122） | 各 × 5 |
| 技巧 | 带暴击属性（`has_stat: crit_chance`） | × 8 |
| 狩猎 | 血肉或骨制品（`flesh` / `bone`） | × 5 |
| 狩猎 | 战利品（`trophy`） | × 10 |
| 狩猎 | 皮革（`leather`） | × 5 |
| 新教 | 没有献祭规矩（神坛只有「返回」） | — |
