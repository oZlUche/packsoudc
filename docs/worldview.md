## 一、神话（重点）

- **众神造人，各赐一福。** 最初的人类是众神最得意的造物，每位神明都赋予人类独一无二的、专属于祂的赐福。
- **诸神争端，人类分裂。** 诸神陷入争端，人类因此分裂成不同群体：语言、肤色、体格乃至赐福都不再相同。**不同种族各有天赋**，天赋就是那位神的赐福。
- **已经出现的神与祂们的赐福**
  - **元素之神**：魔法天赋。拥有者建立了魔法王国，曾是世上最强的国家。
  - **暴力之神 / 力量之神**：北境蛮族的信仰。赐福让人短时间内更快、更强、更耐痛，**受伤会激发**（狂暴）。蛮族的图腾与「力量的符号」相似。
  - **技巧之神**：赐福的盾牌 —— 对手的第一次攻击必定被弹开，后续的攻击也更容易招架或弹开。
  - **狩猎之神**：赐福的长弓 —— 射出的箭矢自带追踪，对兽类效果更佳。
- **神弃与诅咒。** 某个瞬间起魔法师再无法控制魔法，所有进行中的仪式暴走；人们认为是「傲慢的魔法师被元素之神抛弃，失去了眷顾」。
  魔法王国灭亡（约七百年前），旧领土成了**诅咒之地**：荒芜、充斥诅咒、难以久留，残留着魔法暴走的副作用与失控的魔法造物，也埋着后世无法复原的魔法道具。
- **眷顾变成学问。** 三百年前的秘密：魔法已经不是神明的眷顾，会写、会念就能在不同程度上驱使。从此魔法是人人可学的学问 ——
  古代魔法师一次庞大仪式就能永久赋予飞艇飞行；现代魔法用铭刻的符号、特定材料的阵盘、蕴含元素之力的魔晶石，替代与神明沟通的仪式，要几百个阵、定期维护。
  魔晶石粉尘掺进油脂点火，配简易魔法阵，能压制诅咒。
- **信仰的格局。** 帝国多民族、多信仰，倡导信仰诸神一视同仁，但诸族之间冲突频发；魔法师一族曾自恃力量、想替代皇室。

## 二、神话怎么撑起游戏（提议）

| 游戏里的 | 神话里的 | 说明 |
|---|---|---|
| 道具的一级分类 | **哪位神的赐福** | 每位神一个「域」：力量 / 技巧 / 狩猎 / 元素……赐福的道具带那位神的标签；没有赐福的是凡物（制式、蛮族、古王国遗物） |
| 角色 | **种族 = 赐福 = 天赋** | 「不同种族各有天赋」正好是角色的技能（067 的 `CharacterDef.skills`）；狂暴、侦察、施法各是一位神 |
| 一局的地方 | 被神抛弃的土地（诅咒之地） | 出生点 = 进去的口，撤离点 = 出来的口 |
| 侵蚀 | **神弃的加深** | 诅咒逐层推进；侵蚀的效果（扣体力、损坏道具、掉钱）是神弃的表现 |
| 敌人 | 信仰别的神的族群、失控的魔法造物 | 蛮族 = 暴力之神的信徒；造物 = 元素之神被抛弃前的残留 |
| 猎手（伪 PVP） | 别的神的信徒队伍 | 各有领地、行为模板 = 各自的神性 |
| 核心（BOSS） | 失控的巨大造物、神弃之地的中心 | 塔、高塔 |
| 事件 | 祭坛、神迹、神谕、图腾 | 现有的祭坛事件已经是这个方向 |
| 休息点 | 有压制诅咒的魔法阵的地方 | 眷顾还留着的角落 |
| 魔法道具与「能量」资源 | 魔晶石 = 元素之力的容器 | 现在战斗里的 power 就是它；名字改成魔力 |
| 商店点 | 待定 | 神庙的交换？走私商人？系统商城？ |
| 局外货币与成长 | 待定 | 军功只是小说里的一种；也可以是神的青睐、供奉 |

### 道具的分类（提议）

1. **凡物**：制式短剑、长剑、弯刀、匕首、长弓与箭；皮甲、内甲、盾。
2. **赐福之物**：技巧之神的盾、狩猎之神的长弓、力量的符号……**每位神一类**，标签就是神的名字。
3. **元素之物**：魔晶石（破碎 / 完整）、附魔的兵器（秘银附魔长剑）、阵盘 —— 元素之神那一脉，魔法变成学问之后人人可用。
4. **神弃之物**：异化黑曜石（被魔法乱流浸染）、失控造物的残片 —— 危险、值钱。
5. **遗物**：古王国的金属碎片这类超出理解的东西。
6. **消耗与战利品**：伤药、纱布、口粮；项链、头颅这类只值钱的。
7. **包**：行囊、药水带。

**封存的现代道具**（数据保留，`sealed` 标签，不再出现）：手枪、步枪、冲锋枪、霰弹枪、狙击枪、弹匣、电池、无人机、防弹衣、防弹装甲、高级防弹衣、能量核心、兴奋剂、医疗包、撬棍。
留着的：匕首、剁刀、口粮、药水带、三种包。

## 四、要作者拍板的（围绕神话）

1. **神明清单与各自的域。** 元素、暴力 / 力量、技巧、狩猎之外还有谁？每位神管什么？—— 这就是道具与角色的一级分类。
2. **每位神的赐福长什么样。** 道具（赐福之物）与人（种族天赋 / 角色技能）各是什么形式；一个人能不能有两位神的赐福。
3. **诸神争端的现状。** 还在争吗？会不会影响一局（某位神今天占上风 = 某类赐福更强，某类敌人更多）？
4. **玩家的信仰。** 玩家是某个种族（固定一位神），还是可以在一局里改信 / 兼信？
5. **神弃的表现。** 诅咒之地 = 被元素之神抛弃的地方，侵蚀 = 神弃加深，这样对不对？别的神在诅咒之地里还灵吗？
6. **魔法。** 元素之神的旧眷顾（古代仪式）与后世的学问（阵、魔晶石）在游戏里怎么分：魔法道具要不要消耗魔晶石（= 现在的能量资源）？玩家自己施不施法？
7. **参考背景里哪些留。** 帝国 / 军功 / 奴隶 / 系统 —— 哪些进游戏，哪些只当调味。
8. **封存的东西**永远封存，还是留作彩蛋。
