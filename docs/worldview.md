## 一、神话（重点；作者 2026-09-24 定的主线，以此为准）

### 主线

1. **概念 → 神 → 物质与生物。** 世界先拥有概念，概念诞生神明，神明创造物质和生物。每位神就是一个概念的化身，祂的权柄就是那个概念。
2. **诸神的争端体现为造物之间的厮杀。** 神不亲自动手；造物竞争只是出于秩序的需求 —— 按能力分配资源 —— 没有私情。
3. **人类的由来。** 上一次大战后，诸神决定合力创造一个种族，让它自己选择信仰，看哪位神明能获得最多信徒。所以人类天生就是「能选、能换信仰」的种族。
4. **信力反噬。** 令诸神始料未及的是，人类的信仰之力（**信力**）非常强大，甚至能反过来影响神明：原本只有神性的神明堕落、拥有了人性。
5. **元素之神的诞生。** 世界上**不是只有四种元素**：先是四种概念被人类用自然现象绑定了 —— 大地 = **物质**、风 = **移动**、水 = **吸收**、火 = **释放** —— 于是诞生了「元素」这个概念，
   元素之神随之诞生。作为**被人类推动诞生的神**，祂充满人性（构成祂的四位神明也在被推动的过程中沾染了人性）：有欲望，又恐惧被诸神发现。
6. **欺骗与吞并。** 元素之神试着欺骗诸神。诸神从未被同类欺骗过，所以让祂得逞：祂吞并了其他神明（具体是哪些权柄未定），正式制造了名为**魔法**的权柄；对应的魔法王国在人类之中变得无比强大。
7. **神陨与魔法王国的灭亡。** 祂的行动终究败露。原本就被人性影响的诸神感到恐惧，联手击杀了祂，通过分裂夺取权柄的方式让祂彻底陨落 —— 魔法王国因此灭亡。
8. **魔法为什么独立于诸神。** 元素之神陨落后，一部分元素被诸神回收，**更多的被祂死前的一击落在人间**；因为过于庞杂又混杂人性，诸神不敢浸染，只能任其自然降解。
   于是随着时间逝去，魔法的概念可以被人类消化，完全独立于诸神。

### 神性与人性（作者定义）

- **神性 = 绝对的理智。** 神清楚自己的边界，认可秩序的价值：自认弱的神安心居于其下，不想变强；强的神也不欺压弱神，因为没有必要 ——
  没有情绪需要抒发，强者不渴望更强，也不恐惧变弱。
- **人性** 是信力带来的：欲望、恐惧、情绪。沾染人性的神开始为了信仰以外的目的和其他神明竞争、伤害、欺骗、恐惧。元素之神是第一个「生来就充满人性」的神。

### 新神的诞生（作者定义）

必要条件有二：**人类有这个概念**，以及**人类信仰这个概念的神明** —— 或者说人类为这个概念造神，并有一定传播度和持续时间（具体不写明）。
所以还没有谎言或欺瞒之神：人类还没把它当作值得信仰的概念。人类诞生前的生物也有谎言的概念，但它们的能力不足以创造神明。

### 要点（给设计用）

- **信力是世界的核心变量**：它让神堕落，也能造神。作者已经说过切换信仰可以继承积攒的信力 —— 它该是玩家积攒的资源，所有体系都要它；
  「人类为概念造神」还意味着信仰的名单不是封闭的（新教、将来的体系都能在这条规则下解释）。
- **人类天生可换信仰**，这是「道具决定激活信仰」的世界观依据：信仰是选择不是血统。
- **神性的神是静的，人性的神是戏。** 只有神性的神不会主动出手、不会偏心；一切阴谋、报复、收买、恐惧都来自人性 —— 事件、神谕、祭坛、猎手的行为模板写谁，先问那位神沾了多少人性。
- **元素 = 物质 / 移动 / 吸收 / 释放**（大地 / 风 / 水 / 火）是人类绑定的四个概念，不是世界的全部元素：魔法的四个面向，也是元素之物（魔晶石、阵盘、附魔）的分类骨架。
- **诅咒之地 = 神陨之地**：元素之神死前一击落在人间的那些庞杂又混着人性的元素，在自然降解。侵蚀 = 残留的活化，失控的造物 = 祂的遗物，埋着的魔法道具 = 祂鼎盛时的产物。
  越靠近核心越浓 —— 那正是「越往里越危险」的理由。
- **魔法独立于诸神**：不是被分走，是**降解到人类消化得了**。所以魔法道具、阵盘、魔晶石不带信仰标签（元素之物是凡物的一类），会写会念就能用。
- **神吞神与神骗神都有先例**：诸神知道权柄能被吞并也能被分裂，还知道同类会骗人 —— 恐惧从此常驻，这就是「诸神联手」的动机。
- **概念会被人类推着走**：恒常之神被推向太阳、四个概念被绑成元素 —— 神的权柄不是固定的，人类的象征与信仰会改写它。这是「信仰 = 人类的选择」在神那一头的镜像，也是将来新体系（新教）的解释空间。
- **不信者有来历**：宣扬不信任何神、或被信仰剥夺资格，原本是死罪；尼禄·马古斯的制度让他们活下来并成为皇帝的核心部队。游戏里「没激活任何信仰」的玩家就站在这条线上，新教从这里长出来。
- **凡物与信仰之物**：现实里也能存在的东西（皮甲、短刀、弓箭、圆盾……）不归任何信仰；只有赐福之物、符号、神的遗物这类才带信仰标签（作者定）。

### 已经出现的神与祂们的赐福（小说里的）

- **元素之神**（已陨落，人类推动诞生、充满人性）：魔法天赋；拥有者建立了魔法王国。
- **暴力之神 / 力量之神**：北境蛮族的信仰。赐福让人短时间内更快、更强、更耐痛，受伤会激发（狂暴）。蛮族的图腾与「力量的符号」相似。
- **技巧之神**：赐福的盾牌 —— 对手的第一次攻击必定被弹开，后续更易招架。
- **狩猎之神**：赐福的长弓 —— 箭矢自带追踪，对兽类更佳。
- **战争之神**（作者提到：军团士兵）。
- **太阳神 / 太阳与火之神**（作者定）：原本是**恒常之神**，代表「周期循环」这一概念，被人类主观推向了太阳这一象征物；在和元素之神的战斗中**不由自主夺取了火的概念** ——
  所以祂和被人类绑定成「火 = 释放」而融进元素之神的那位**不是同一位**，火如今归祂（西方蛮族的信仰、火焰魔法）。

### 小说里还写了的

- 眷顾变成学问：三百年前的秘密 —— 魔法不再是神的眷顾，会写会念就能驱使。古代一次庞大仪式永久赋予飞艇飞行；现代用铭刻的符号、阵盘、魔晶石，要几百个阵、定期维护。
  魔晶石粉尘掺进油脂点火配简易魔法阵，能压制诅咒。
- 信仰的格局：帝国多民族、多信仰，倡导信仰诸神一视同仁，诸族冲突频发；魔法师一族曾自恃力量想替代皇室。

## 二、帝国与诅咒之地（必要的背景）

- **帝国。** 魔法王国灭亡后周边国家蚕食旧领土、彼此厮杀，十余国合纵连横，唯一的胜者。**多民族、多信仰**，倡导信仰诸神一视同仁，但诸族冲突频发。
  三百年前魔法师叛乱灭皇室，一位军团长靠「魔法不再是神的眷顾、会写会念就能用」的秘密培养军团魔法师、屠尽叛乱者、加冕 —— 魔法皇帝尼禄·马古斯，从此魔法是学问。
  帝国有四大军团、飞空艇（几百个魔法阵维持）、隶属协会的正式魔法师、边境军区。
- **诅咒之地。** 帝国边境旁的无主之地 —— 魔法王国的旧领土：荒芜、充斥诅咒、难以久留、没有占领价值，埋着帝国至今无法复原的魔法道具，残留失控的魔法造物。
  帝国的做法：军队在诅咒影响范围的边缘驻扎，把探索者送进去、几天后接回；收获按价值换报酬。军团偶尔全军出击。
- **在诅咒之地里活动的人。** 帝国的探索者（奴隶、自由民、组队的任务队伍）、北境蛮族（血斧酋语，暴力之神的信徒）、军团的精锐、失控的造物。
- **帝国史：尼禄·马古斯与无信者**（作者定）。上一个王朝的皇帝从诸族中选拔，更像联邦制，和贵族没有矛盾。贵族们和其他阶层是隔离的（横向分层），但信仰的力量让他们能聚在一起（垂直联通），
  在民间有许多势力。新王朝的开创者尼禄·马古斯（Magus = 魔法师）见证了魔法一族为了权力不择手段，自己又拥有更强的力量所以野心更大 ——
  **不是被魔法的混沌力量蛊惑：那份混沌来自人性，人类免疫，一切只是人性使然** —— 于是想要更高的集权，用**新教**打压信仰诸神的贵族。
  他开创了**允许无信者的制度**：原本任何人只要宣扬自己不信任何神、或被原本的信仰剥夺了资格，就处以死刑，位高权重也会失势；新制度让他们活了下来，
  没有可投靠的势力、又对皇帝心存感激，成了皇帝最核心的一支部队。制度引来贵族的围攻，他虽有强大军队与死士保护、又擅长魔法，仍死于层出不穷的暗杀。
  他死后贵族清算无信者部队，引发大战：尼禄不像凯撒那样有民心，但军队对他更忠诚（对神明的信仰也更弱），直属于他的魔法军团在正面战场击败贵族联军，却因缺乏后勤陷入险境；
  最后在他胞弟的劝说下，恐惧于那支军团的贵族联军接受和谈，奉他的弟弟为第二任皇帝（名字待作者定，候选见第六节）。
- **角色可以有各种身份**（作者定）：奴隶探索者只是小说主角的身份；自由民、军团士兵、军团魔法师、协会的魔法师、蛮族、修士……都可以是角色。
  身份决定的是开局（带什么、从哪进）、立场（谁是敌人、谁给报酬）与文字；天赋（赐福）由种族决定，两者独立 —— 一个蛮族也可以是帝国的奴隶。

### 道具的分类（提议）

1. **凡物**：制式短剑、长剑、弯刀、匕首、长弓与箭；皮甲、内甲、盾。
2. **赐福之物**：技巧之神的盾、狩猎之神的长弓、力量的符号……**每位神一类**，标签就是神的名字。
3. **元素之物**：魔晶石（破碎 / 完整）、附魔的兵器（秘银附魔长剑）、阵盘 —— 元素之神那一脉，魔法变成学问之后人人可用。
4. **神弃之物**：异化黑曜石（被魔法乱流浸染）、失控造物的残片 —— 危险、值钱。
5. **遗物**：古王国的金属碎片这类超出理解的东西。
6. **消耗与战利品**：伤药、纱布、口粮；项链、头颅这类只值钱的。
7. **包**：行囊、药水带。

**封存的现代道具**（数据保留，`sealed` 标签，不再出现）：手枪、步枪、冲锋枪、霰弹枪、狙击枪、弹匣、电池、无人机、防弹衣、防弹装甲、高级防弹衣、能量核心、兴奋剂、医疗包、撬棍。
留着的：匕首、剁刀、口粮、药水带、三种包。

## 五、信仰体系（作者定，已实施 —— 报告 081）

- **信仰是道具的一级分类，靠标签。** 信仰道具先带一个 `faith` 标签，再按信仰对象带对应标签（`faith:violence`……）；新教也是 `faith` + 专属标签。
  用不用带信仰标签的道具，就决定了玩家有没有选信仰 —— 这是「两个大类」的真正含义。无信仰之物（伤药、口粮、包、材料、战利品……）信仰者可以用。
  **现实里也能存在的东西（皮甲、短刀、弓箭、圆盾……）不归任何信仰**；带信仰标签的只有赐福之物、符号、神的遗物这类。
- **各种神明、魔法（现在的魔法独立于神明）、修士（皇帝扶持的新教，用以对抗诸神信仰）、士兵各成体系**，每个体系都有自己的武器、饰品、防具、珍宝、小道具。
  已登记的：暴力之神、战争之神、太阳与火之神、技巧之神、狩猎之神，新教占位。
- **激活规则：只能激活最后一个置入背包的信仰道具所属的信仰。** 别的信仰的道具通常情况下完全不起作用（休眠）。切换 = 把道具挪到暂存区再挪回，没有代价；将来甚至可以继承积攒的信力。
- **不信者**目前只是「没激活任何信仰」，将来加专门体系，同样走标签。新教与诸神天然互斥（只激活一个）。
- **敌人按出身信仰**（信暴力之神的北境蛮族、信火焰之神的西方蛮族），掉的是那一系的东西；一个敌人只信一个神。
- **不提倡除套装以外的明确流派，不写在纸上**：道具的联动让玩家自然组成流派。信仰不是流派，敌人组装备的偏好标签也不是。

## 六、要作者拍板的（围绕神话与身份）

1. **神明清单与各自的概念。** 元素（已陨落）、暴力 / 力量、战争、技巧、狩猎、太阳（恒常 → 周期循环 + 火）之外还有谁？每位神是哪个概念？—— 这就是道具与角色的一级分类。元素之神吞并了哪些权柄？
2. **每位神的赐福长什么样。** 道具（赐福之物）与人（种族天赋 / 角色技能）各是什么形式；一个人能不能有两位神的赐福。
3. **诸神争端的现状。** 还在争吗？会不会影响一局（某位神今天占上风 = 某类赐福更强，某类敌人更多）？
4. **玩家的信仰。** 玩家是某个种族（固定一位神），还是可以在一局里改信 / 兼信？
5. **神陨的表现。** 诅咒之地 = 元素之神死前一击落下的、还在降解的元素，侵蚀 = 残留的活化，这样对不对？别的神在诅咒之地里还灵吗？
   新教起初是尼禄用来打压贵族的制度，现在它信的「唯一神」是什么 —— 按「新神诞生」的规则造出来的神（皇帝扶持 = 传播度与持续时间）？哪个概念？
   **第二任皇帝的名字**（作者要一个带历史梗的）候选：**奥古斯图·马古斯**（Augustus —— 凯撒遇刺后收拾局面、以和谈与妥协开创和平的继承人，最贴「胞弟劝和、贵族奉之」）；
   **克劳狄·马古斯**（Claudius —— 被当作软弱的家族成员，靠军团拥立登基，实际治理不差）；**安东尼努斯·庇护**（Antoninus Pius —— 「虔诚者」，给一个庇护无信者的皇帝正好反着用）。
6. **魔法。** 元素之神的旧眷顾（古代仪式）与后世的学问（阵、魔晶石）在游戏里怎么分：魔法道具要不要消耗魔晶石（= 现在的能量资源）？玩家自己施不施法？
7. **信力与不信者的体系。** 切换时继承的「信力」是什么、怎么攒、花在哪；不信者的专门体系长什么样。
8. **身份清单。** 角色能是哪些身份（奴隶 / 自由民 / 军团士兵 / 魔法师 / 蛮族……）？身份影响什么：开局装备、进出的口、报酬的形式、谁是敌人、事件的分支？
   军功与系统这些小说里的具体设定，哪些进游戏、哪些只当调味。
9. **封存的东西**永远封存，还是留作彩蛋。
