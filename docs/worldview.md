## 一、小说里写明的

### 1. 世界与历史

- **诸神与人类。** 最初的人类是众神最得意的造物，每位神明赋予人类专属于祂的赐福。诸神陷入争端，人类因此分裂成不同群体：语言、肤色、体格乃至赐福都不再相同。
  不同种族各有天赋。已经出现的神：**元素之神**（魔法天赋 = 祂的祝福）、**暴力之神 / 力量之神**（北境蛮族的信仰，赐福让人短时间更快、更强、更耐痛 —— 受伤会激发）、
  **技巧之神**（赐福的盾：对手第一次攻击必定被弹开，后续更易招架）、**狩猎之神**（赐福的长弓：箭矢自带追踪，对兽类更佳）。
- **魔法王国。** 魔法师们建立，约一千五百年前建、七百年前亡。某个瞬间起魔法师再无法控制魔法，所有进行中的仪式暴走；人们认为是「傲慢的魔法师被元素之神抛弃」。
  幸存者改信、流亡。古王国的通用语叫**露西卡语**。
- **诅咒之地。** 魔法王国的旧领土：荒芜、充斥诅咒、难以久留、没有占领价值；但埋着帝国至今无法复原的魔法道具，还残留着魔法暴走的副作用与失控的魔法造物。
- **帝国。** 周边国家蚕食旧领土、彼此接壤后互相厮杀，十余国合纵连横，唯一的胜者是帝国：多民族、多信仰，倡导信仰诸神一视同仁，但诸族冲突频发。
  三百年前魔法师叛乱、灭皇室；一位军团长靠叛逃魔法师带来的秘密（魔法不再是神的眷顾，会写会念就能驱使）培养出军团魔法师，屠尽叛乱者、加冕 ——
  **魔法皇帝尼禄·马古斯**。从此魔法是人人可学的学问。
- **古今魔法。** 古代魔法师一次庞大仪式就能永久赋予飞艇飞行；现代魔法用提前铭刻的符号、特定材料的**阵盘**、蕴含基本元素力量的**魔晶石**，
  替代冗长的神秘仪式 —— 飞艇要刻几百个不同功能的魔法阵，定期检查、补材料。魔晶石粉尘掺进油脂点火，配底部的简易魔法阵，能压制诅咒。
- **语言。** 帝国通用语、坎希佩尔行省语、血斧酋语（北境蛮族）、古王国露西卡通用语。

### 2. 主角所在的地方：边境军区与奴隶探索者

- 沈金：肉身穿越（不是魂穿），被修士送进奴隶营地，三年。体力差、不快、没力气；眼力与记忆力好（在飞艇上记住了魔法阵的样式，靠它认出真正的魔法道具）。
  用军功换了学习战法的课程、兵器与物品。习惯独行。同伴：安德烈（四十来岁、高大随和）、马库斯（失散于高塔任务）。
- **军区不与蛮族领地接壤**，旁边是诅咒之地。奴隶的任务：每月至少探索一次；军队在诅咒影响范围的边缘驻扎，把奴隶送进去，**三天后开放、接回**。
- **军功。** 返回营地后按收获算军功，兑换奖励：自由民许可（所有人的目标）、兵器、伤药、课程。一无所获的人没见过回来。军团**允许奴隶保管缴获的兵器，前提是得到批准**。
  蛮族的头颅换的军功最高；蛮族的兵器与项链用来佐证身份。
- **营地。** 接应处门外两个大火堆（压制诅咒）；亮身份、上交全部东西、粗暴搜身、军官记军功；食堂（土豆炖牛肉那种）；领号码牌睡床。
- **别的人也在诅咒之地。** 北境蛮族（弓、弯刀、皮甲、项链，狂暴的赐福）；组队执行军团任务的奴隶（高塔）；军团偶尔全军出击、奴隶组敢死队探路（沈金靠认出魔法符号躲进一个房间活下来）。
- **系统。** 灰白色金属碎片（超古代、极锋利）浮现符号后绑定：翻译器、万用以太感应器、可视化数据、信息识别、万物图鉴、雷达、商城、回收、析理、修炼体系……
  商城按分数卖东西（长剑 10 分、秘银附魔长剑 50、技巧之神的盾 100、狩猎之神的长弓 200、位面分析桩 1000），提供外形自定义；回收要接触、耗时、有距离与体积限制。

## 二、和游戏的对应（提议，待确认）

| 游戏里的 | 世界观里的 | 说明 |
|---|---|---|
| 一局 | 一次进诅咒之地的探索 | 出生点 = 军队送进去的入口；撤离点 = 接应处开放的出口 |
| 行动点 / 侵蚀 | 诅咒 | 侵蚀 = 诅咒逐层深入，「三天后接回」是它的期限感；侵蚀效果（扣体力、损坏道具、掉钱）都是诅咒的表现 |
| 撤离结算的价值、局外货币 | 军功 | 带出去的东西按军功算；仓库 = 军团批准保管的缴获 |
| 仓库、图鉴 | 军团营地里的寄存、系统的万物图鉴 | 图鉴是系统的功能之一 |
| 商店点 | 待定 | 诅咒之地里没有店。候选：系统商城（小说里有）、流浪的走私商人、军团的补给站 |
| 休息点 | 有压制诅咒的魔法阵的房间、避风的废墟 | 第三章沈金躲过一劫的那种房间 |
| 搜索点 | 废墟、蛮族的尸体与行囊 | 「翻得越久越可能惊动附近的人」 |
| 事件点 | 陌生人、祭坛、裂隙…… | 文字与配图按世界观重写 |
| 敌人 | 北境蛮族、失控的魔法造物、敌对的探索队伍 | 现有敌人（蛮兵 / 屠夫 / 神射手 / 看守 / 核心守卫）改名换装即可 |
| 猎手（伪 PVP） | 在诅咒之地里游荡的蛮族队伍 | 或军团的敢死队、其他奴隶 |
| 核心（BOSS） | 失控的魔法造物、高塔 | 第二章的塔 |
| 角色 | 不同种族的奴隶 | 「不同种族各有天赋」= 角色的技能与赐福；沈金本人是不是可选角色，待定 |

| 道具的流派标签 | 帝国制式 / 蛮族 / 古王国遗物 / 神明赐福 | 现在的 melee / rapid / burst / bleed 是机制标签，保留；世界观标签另加一层 |

### 道具的分类（提议）

1. **兵器**：制式短剑、长剑、弯刀、匕首、长弓与箭；秘银附魔的；神明赐福的。
2. **护甲**：皮甲、贴身内甲、盾牌。
3. **消耗**：伤药、纱布、口粮、（魔晶石粉尘的火把 —— 压制诅咒？）。
4. **魔法道具**：符号（力量……）、阵盘 —— 需要魔晶石作燃料的，对应现在的「能量」资源。
5. **材料与宝物**：魔晶石（破碎 / 完整）、异化黑曜石、古王国的金属碎片 —— 本身值军功，不参战或只微弱参战（6.4「战斗力与价值是两回事」）。
6. **战利品**：项链、头颅 —— 只值军功。
7. **包**：行囊、药水带。

**封存的现代道具**（数据保留，`sealed` 标签，不再出现）：手枪、步枪、冲锋枪、霰弹枪、狙击枪、弹匣、电池、无人机、防弹衣、防弹装甲、高级防弹衣、能量核心、兴奋剂、医疗包、撬棍。
留着的：匕首、剁刀、口粮、药水带、三种包。

## 三、要作者拍板的

1. **玩家是谁？** 沈金本人（带系统），还是「某个奴隶」（角色 = 不同种族的赐福，沈金只是其中一个可选角色）？
2. **系统要不要进游戏？** 商城 / 回收 / 图鉴 / 雷达都是小说里系统的功能 —— 商店点当系统商城、结算当回收、图鉴照旧，是最省事的对应；但那样「军功」和「分数」是两种货币。
3. **诅咒 = 侵蚀？** 「三天后接回」怎么体现：行动点上限、侵蚀的时间表，还是不体现？
4. **神明清单。** 元素、暴力 / 力量、技巧、狩猎之外还有哪些？赐福是道具的一个分类，也是种族天赋（角色）的来源。
5. **敌人清单。** 蛮族之外，失控的魔法造物长什么样？敌对奴隶 / 军团要不要当敌人？
6. **魔法的表现。** 魔法道具要不要消耗魔晶石（= 现在的能量资源）？玩家自己会不会施法（角色技能）？
7. **军功与自由。** 局外成长（8-5）的出口：军功换什么？「自由民许可」是通关条件吗？
8. **封存的东西**永远封存，还是留作彩蛋（3721 位面、系统商城里的热武器「不好交代来历」）？
