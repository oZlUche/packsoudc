# 分层稿的独立复审

本轮每位审核者均以 `fork_turns="none"` 新建，收到中性路径下的单幅待审图与阶段题。制作、正审、复验和成品来源盲审分开派发；修稿意见单独交给画师。下列为主审汇总，非原始逐字评语。旧版的分数仅适用于当时的图。

| 稿件 | 独立审查结果及处理 |
| --- | --- |
| 结构 | 首审 74 分，指出车辙会聚与眼平线不合。第一次复验认可会聚，但仍退回，因为路直指门左实墙，棚脚缺少接地参照。调整为同轮距的转弯双辙穿门，并补柱脚短线。第三位审图者判通过，明确光照投影留待黑白稿核验。 |
| 黑白稿 | 修订前的独立检查为 82 分，通过。随几何更新后的浅门框版本另由新审核者复查，通过。车辕细影与车厢大投影分开，右旗影落在栅上；右前浅色器物边缘与亮地面明度接近。 |
| 一级细化 | 初审退回，指出两侧棚下空，交易用途与踩实的地表分区较弱。补齐货台与货物后，新审核者判通过，认可中央 UI 留白和主光；指出两摊货品相近。 |
| 二级细化 | 分层合成稿独立审查通过。木纹、桶箍高光与陶器肩部反光可区分；门内地面接入近景，中央沙地未出现可见接缝。 |
| 三级细化 | 独立审查通过。货罐、车帮与轮子的遮挡，轮子接地，帐钉与布褶均可读。两摊陈列相似，记作非阻断观察。 |
| 终审 | 此前的单张局部修稿被退回，原因是门楣下出现了与外侧山脊不相接的亮蓝天空。改用完整远景、地面与透明物件层。分层稿由另一位审核者终审通过，证据包括道路穿门、围栅收口、梯脚接地与布面受力。 |
| 额外盲审 | 盲审者只看成图，认为不能凭图确认 AI 来源；常开入口未画门扇和横闩，若作可关闭寨门理解，操作方式不明。塔、旗与摊位形制重复，亦可解释为同营制式。未发现能证实物理矛盾的证据。 |

## 图层核验

三级源文件分别重读 OpenRaster 的图层清单，并按顺序合成。各阶段结果与对应的 1920 × 1080 导出图逐像素一致。三个阶段各抽检同一门洞内矩形，共 5,360 像素，栅栏、营地及货物层在其中均完全透明。金色圆章与月桂纹顺旗面斜褶压缩、遮断并跨越明暗交界。此次核验针对独立设计稿与源文件。

## 岗楼木梯局部校准

在 1920 × 1080 原图上，按同一横向扫描线量两根梯梁的中心距。修前左梯上段约 11 px、下段约 25 px；右梯约为 10 px 和 25 px。两梯的位置和倚靠角度不足以支持这种幅度的收窄。修后采用等宽投影近似，在原尺寸下两架梯子的上、下跨度均为 25 px。左梯顶、底两根梁同步向画面左侧偏移 23 px，右梯偏移 21 px，梯身仍有倚靠角度。校准后的建筑层用于二级材质与最终细化，复合后仅两处梯边区域的像素有差异。
