# 集市背景分层源文件

使用 GIMP、Krita 等支持 OpenRaster 的绘图软件打开。一级细化、二级细化与最终细化分别保留源文件。第八步与第九步共用同一成品源文件，第九步另存的是相同像素的审查通过版。

| 阶段 | 可编辑画稿 | 合成图 |
| --- | --- | --- |
| 一级细化 | [06-local-color.ora](06-local-color.ora) | [大色块](../06-local-color.png) |
| 二级细化 | [07-materials.ora](07-materials.ora) | [材质](../07-materials.png) |
| 三级细化与终审 | [09-final.ora](09-final.ora) | [成品](../09-final.png) |

从底到顶依次为远景、地面、营防建筑、营地摊棚、近处货堆。底层绘制完整天空与远山，地面层含远处平原向沙地的过渡。木栅和门框在同一层，透过门洞和塔窗可见背景。隐藏营地层可看见帐篷与棚架后方补全的木栅；隐藏建筑层可以看见连续的地形和路径。两侧军旗随建筑层显示，旗纹跟随布褶转折。

导出时按 OpenRaster 的 stack.xml 自底向上执行普通透明叠合。重新读取档案各层后，核对重合结果与相应 PNG 的所有像素。在每个阶段的原尺寸画布中另抽查营门内部矩形（左上 1100,438，右下 1180,505，不含右下边界），其中 5,360 个像素在三层物件上的透明度均为零，与远景和地面两层的合成完全相同。
