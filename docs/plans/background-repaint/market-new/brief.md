# 白日交货时分 · 边境集市
原画为 assets/ui/market/scene.png，1920×1080，用作基地后勤集市的交易背景。交易信息由界面叠加；让中央走道保持开阔，货物压到画框两角，山脊和云与栅栏分开。以斜射暖日光、清澈的蓝天和砖红旗帜表达晴日营业中的边境补给站。木构、货车、棚布用真实搭接、重力和视距表现。

|景深|原画要素与用途|本次取舍|
|---|---|---|
|远|天空、散云、低丘提供天气与纵深|天际线跨越整画，淡蓝山影与地面连续穿过门洞|
|中后|两座望楼、木栅、门、成对旗帜表示营地入口|保留偏右入口。原稿的主路偏左碰墙，移正两条路缘；望楼梯轨同向抵达平台。使用共面形变的旗徽。|
|中|左侧一近一远的帐篷、右侧帐篷提供存货空间；两顶小货棚表示交易|左帐拉开进深，门帘落地、脊线与底边同轴；桌腿落地，台面在棚布以下。右前单旗标示交易区。|
|近|左车与袋货、陶罐、箱、桶；右边箱、桶、袋形成边框|车把成对轮廓同形、车轮同轴，停车用轮边垫木。罐落地、袋货压在车厢内。砾石与草只在路肩零星出现。|

坐标与未知结构为本稿设计假设。单位米，X向右，Y向北，Z向上。相机 (0,-22,4.2)，朝 (0.7,12,2.25)，水平视场约65°。木栅在 y=11，门中心 x=4.2，门净宽4.4米，道宽3.35米。前景路心 x=0.7，平滑过渡至门内外 x=4.2。交易台面向路肩，旗杆独立立于 (7.6,-1.65)。左前帐 (-10,0)，左后帐 (-8,5)，右帐 (11,2)，摊位在 (-4.1,3) 和 (7.55,6.9)。前景货车在 (-6.0,-7)，右侧货物在 (7,-7)。摄影视图独立于三张正投影。日光来自画面左上前方，天空漫射填充；现场没有灯火。精修逐步增加板缝、褶皱、使用痕迹，再以偏暖、较暗、较高对比度收束。

首轮结构审查后，把左侧交易台前移并朝车道旋转约 19°，商品占位随台面一起旋转；右旗从帐篷与货堆的投影之间移至右侧路肩。相机下俯约 3.3°。正侧视图以设施区为取景范围。场景按原版 MetaScreen 的 market/scene 全屏 cover 用途设计。

细化取舍：日轮旗徽沿旗布同一表面采样；帐篷接缝限定在分幅处；车轮铁箍、板边和绑扎绳用于解释接榫与载荷。路中留给车轮，只在肩部加入石粒和草。天空远景、土壤和彩布分别按其空间尺度使用绘景纹理。入口以宽面暖补光近似日照土面的反射，没有设置篝火或灯具。

三级近景以载荷、使用和接地为准。两根车把有相同的收细握区；货绳沿袋面截面的上包络绷紧，侧边回到车厢。双停车脚以横撑组成可辨认的架体。木箱之间有两道垫条，麻袋增加收口绳头和布缝；立于平整场坪的支点接到最终土面。地面回光限定在篷内和车上，避免回光代理再照亮路面。
