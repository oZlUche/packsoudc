# 背景重绘文字构图稿

保留原始像素画幅与相机。先描原图地平线、建筑外缘、主要负形、椭圆长短轴及接地线；按近、中、远三层标遮挡。通过门窗厚度、拱券进深、地砖收缩和物体接触阴影交代空间。色彩借用参考封面中朱红斗篷、金黄甲片、蓝绿色远山与乳白石材的明快关系；每景用亮面、局部色、彩色阴影三组大色块，远景降低对比。夜景的高饱和色集中在小面积光源和受光面。保留界面叠加区域的明度范围。

## 集市代表图：交给线稿与色稿的坐标

以 1920 × 1080 原幅为准，以下为距左／上边缘的画幅百分比。

- 远景：上方四朵云分立；草脊约在 37% 高度，被木栅遮住下沿，天空和山脊之间采用淡蓝、青绿两个色阶。
- 中景：栅顶约 38%、栅底 50%；两座斜顶哨塔塔尖约 (46%,21%)、(77%,23%)。朱红双旗约 (55%,32%)、(67%,32%)。门洞中心约 (60%,45%)，入深处最暗。塔柱背面与栅桩间隙画连贯的冷紫灰阴面。
- 前景：左帐群横跨 0–27% 宽，右帐在 89–100% 宽；两边白帐的亮面和投影方向一致。左下手车、陶壶、木箱、桶互相遮挡，底部约到 94% 高；右下桶、箱、袋约占末端 12% 宽。
- 空场：原有两条车辙从底边约 32%、75% 宽处收向栅前约 50–54% 宽处。门洞位于道路汇聚处右侧，保留这段偏移。画面中下部沙地为暖杏黄，接触阴影为橙褐至蓝紫灰；把高纯度朱红留给旗面。
