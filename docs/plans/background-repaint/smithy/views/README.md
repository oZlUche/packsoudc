# 铁匠铺的三视图与主机位

每张组图左上为俯视、右上为朝北看后墙的正视、左下为朝西看的侧视、右下为成品机位。俯视沿 Y 轴向上，正视沿 X 轴向右，侧视沿 Y 轴向右。左下角的标尺代表 2 m，俯视、侧视上的红线标出主机位的视野边界。

01 的四个机位从同一组简报体块投影。03 起从各阶段的 Blender 场景输出三个正投影，第四幅配入该阶段独立透视相机的导出稿。俯视剖开室内顶板，侧视再剖去两端返墙，以便看到炉体和储料之间的前后关系。正视剖去挡住炉体的画外门柱。黑白稿起，剖开的构件仍参与光照和投影。

铁砧木墩位于 (−4.28, −1.40) m，砧面离地约 0.99 m，长轴相对 X 轴旋转 −20°。短柄锤横放在砧面上，柄尾朝画面左侧，木柄升向右侧锤头的柄孔。炉旁长铲的刃口跨在两块铺板的高差处，由较高一侧承托，铲杆向后上方斜靠炉沿。俯视可辨两件工具的朝向，正视和主机位可核对砧面、炉沿及地面上的接触位置。各阶段使用相同的砧位和机位。08 与 09 共用几何、材质与光源，09 的三个正投影施加与主机位相同的终稿调色。
