# 背景画的分阶段绘制与审查

每个场景建立独立设计目录。把下表作为一张画从需求分析到成品的顺序。通过的版本保留原文件，审查退回时从最近一次通过的版本重做。评语应指出具体物件、受影响的空间关系、修正结果与复验结论。结构或光影出现矛盾时，即使总分达到及格线，也需要退回。

| 步骤 | 作画与检查 | 留档 |
| --- | --- | --- |
| 1　场景说明 | 查阅实际使用场景和界面叠加关系。逐项列出原图中的场景与道具，写明作用、保留或删减的理由和需要纠正的地方。分近、中、远景说明构图与光源。 | Markdown 说明、原图、三视图与独立镜头草案 |
| 2　结构稿 v1 | 独立从文字说明搭建几何。区分可见天际线与透视视平线，确定建筑体块、平行线族、在地面或平台上的落点及前后遮挡。用文字定位光源。 | 待审结构稿 |
| 3　结构审查 | 以美术考试阅卷方式，逐项检查构图、透视、承托、遮挡和简化是否得当，给出分项意见、总分和通过结论。 | 通过的 v1 与评语 |
| 4　黑白光影稿 v2 | 在通过的几何上建立光源。按距离、入射方向和强弱画出明暗与投影。物体或墙面截住光线时，投影随承接平面改变方向。天光、日光、灯火按现场实际来源分别处理。 | 待审黑白稿 |
| 5　光影审查 | 按物件检查受光面、背光面、接触阴影、投影落点与转折；核对各光源的共同影响和前后层次。 | 通过的 v2 与评语 |
| 6　一级细化 | 明确建筑的材质与承重构造、天空的主要光源、地表分区与路径，铺大色块。 | 一级细化图 |
| 7　二级细化 | 按空间远近处理云量与形状、建筑表面、地表质感，再加入受光渐变和反光。 | 二级细化图 |
| 8　三级细化 | 逐项判断细节是否说明受力、用途、年代或空间。按需加入褶皱、磨损、砾石和杂草，维持交互区的视觉安静。 | 三级细化图和细节取舍 |
| 9　终审 | 查看全幅、缩略图及原尺寸局部。沿物件轮廓检查是否存在均匀描边，检验相邻色面、反光和投影能否独立塑形，并复核透视、接地、遮挡及画面的实际用途。 | 通过的独立成品与终审结论 |

## 开工与逐步放行

主 agent 先写明画面的用途、原画幅、需保留的构图锚点、哪些原稿错误允许纠正、界面遮挡和交付范围。把风格拆成两个可评价的目标。以集市为例，色彩和光影取鲜明、概括的插画效果，透视、空间层次、承重与物品的使用关系遵循真实世界。封面参考只提供美术方向。生成任务的交付物是独立美术稿与可编辑源。

1. **场景说明**。看原图和实际使用画面，按远、中、近景列出每件物体的位置、使用者、用途、保留或移动的理由。把无法从草稿确认的背面构造和尺寸写作设计假设。画场地占位及三视图，存原图与方案例图。结构画师收到通过的文字方案、布局尺寸和镜头约定，从空白搭建。
2. **结构 v1**。用简化体块确定地面、平台、天际线和视平线。给同一组空间平行边标方向，按相机判断它们在画面上平行或向同一消失点汇聚。核对物件的底面、接触点和遮挡顺序。天空与地面只划边界；光源用文字标位置。
3. **结构审查**。分别在俯视图查占地、立面查承托、成品镜头查可读性。沿人物或货物的完整使用路径走一遍。集市要沿两条路缘从前景穿过门槛、沿梯脚走到平台内、从停车位找到柜台交付点。任何一段被堵住，都要明确指出位置。通过后保存 v1。
4. **黑白 v2**。固定相机和几何，按场景列出主光、天光及实际存在的灯火。区分远距离日光与近距离灯火的方向变化、衰减和影缘；多光源时可分别关闭各灯，核对补光对暗部的影响。让地面、墙面、货物共同接收投影。
5. **光影审查**。从物体接地点追踪一条影缘，看它在地面延伸、遇到立面时如何折转。复查棚下货物、柱脚和门洞的明度。在全幅及原尺寸局部都能辨认后保存 v2。若问题来自几何穿插，退回结构稿。
6. **一级细化**。从连续远景、地表、道路画起，再覆盖建筑和近景物件。用色块交代天空主光、室内外、草地、压实路径与荒地；给建筑落实支柱、梁、开口和材质。把场地底板单独打开检查，再从成品镜头检验门内外的道路线形与两肩余量。通过后存合成图和可编辑层。
7. **二级细化**。决定云量、云形与密度，区分布、木、石、陶和土的纹理尺度，在已通过的明暗上加受光渐变与反光。同一材料随距离减少细节；在游戏显示尺寸核对视觉重心。通过后存材质稿。
8. **三级细化**。每次添加前先说明它解释了哪种用途、受力或使用历史。布纹跟随褶皱，旗徽与旗布共用形变，握把磨光出现在手握处，运输陶罐能看到隔垫与固定点。对改善阅读没有作用的细节可以省去。通过后存细节稿。
9. **终审和交付**。检查全幅、游戏尺寸、原尺寸局部及图层开关效果。确认成品用相邻色面、明暗和材质塑形，清除残留描边。另做来源与常理盲审。通过后导出最终图、可编辑源、阶段索引和审查记录，在对话里依次展示第 1、3、5、6、7、8、9 步的通过图。

每个待审版本单独保存。主 agent 收齐本步技术核对与独立意见，记录通过或退回，才派发下一步绘制；同一步的独立图层可并行。退回时，从最近通过的源文件另存修订版，保留旧图和失败理由。问题若源于更早的几何或机位，就回到最早受影响的步骤，重出并复验所有依赖它的阶段。交付索引用步骤、版本、源文件、对应镜头和审查结果把图片配对，防止旧版的分数被用于新版。

## 从第一步起维护三视图和独立镜头

第一步从同一场地坐标导出俯视、正视、侧视三张等比例正投影，标明正北、地面标高、尺度、通道净宽、承托及出入口。另设一台成品透视相机，记录位置、高度、朝向、俯仰、焦距、画幅和画面偏移。在俯视图画出相机位置与视锥，用实际游戏裁切比例预览第四幅画面。根据场景选取略带俯视和侧视的视点，每张构图使用自己的镜头参数。

第一步及第 3、5、6、7、8、9 步的留档都附三视图与镜头对照。几何、布局、道路或相机发生变化时，一起重新导出受影响的全部视图，退回最早受影响的审核项。相邻阶段复用完全相同的状态时，在索引中注明。平面图检验能否通行，成品机位检验玩家能否看懂通行路线。

道路、桥或门廊先画出地面占地。道路中心线和两侧路缘共用一套几何穿过门槛；检验门柱、柱脚、门扇和墙体占地与实际路宽的间隙。同时复查近景到门槛的走向及门内外延续；门洞的透明像素检查只验证图层关系。

## 每次审查独立建会话

结构评分、明暗审核、各级细化验收、终审和 AI 痕迹盲审均由新建的独立子 agent 执行。每个审查项和每次复验都使用新的 agent，调用时指定 `fork_turns="none"`。主审只传入中性命名的本轮待审图、阶段名称、场景用途与该阶段统一的审查题。AI 痕迹盲审只传图和盲审题。审核者只能打开提供的材料；不可读取仓库、制作记录、旧分数、上轮失败原因、其他审查者意见或对话。画师的自检单独记录。主审在收齐独立意见后汇总，并另行向画师派发修订。复验同样从空上下文开始。

## 从一级细化起分层制作

先画完整的远景和地表，再在透明层上制作中景建筑、营地设施及近景货物。建筑后的地平线、山体轮廓和地面在底层连续铺设。门框、塔窗、架子间的空隙应透出下层；确有厚度的门柱只绘可见的内侧面。旗纹用旗布的同一组弯折、遮挡和亮暗塑形。成稿保留可开关的分层源文件及合成预览。

交付时隐藏各物件层观察底板，换对比底色查透明边沿，抽查门洞内部各物件层的 Alpha，核对合成图与底板同位置的像素。按层顺序重新合成并与交付 PNG 做逐像素对照。

## 终审增加无上下文盲审

成品导出后，新建一个不继承对话历史的子 agent，只提供成图。请它先看全幅、再看原尺寸局部，独立回答：“能否确认这张图为AI生成的？有哪些不符合常理的纰漏”。记录其原始判断和位置，把可验证的错误与可能由遮挡、视角或画外结构解释的疑点区分开来。来源判断不计入美术分数。发现实质错误时退回相应阶段，修订后交给另一位未看过原图和旧评语的盲审者。

## 子 agent 的分工与能力边界

| 环节 | 当前可执行的操作 | 成立条件与限制 |
| --- | --- | --- |
| 分析与派工（1） | 主 agent 阅读原图、界面与需求，作画子 agent 按用途提出布置。主 agent 确定同一坐标系、尺度、相机与光源。 | 单张图不能唯一决定被遮住的结构或作者意图。新设计的背面、支撑和尺寸须写入方案，供三视图检验。 |
| 空间与相机（1–3） | 通过 Blender 场景从同一几何导出正投影、透视图、平面截面，量门宽、路宽、梯脚落点和间隙。 | 结果只覆盖建模和测量过的部分。纯图像生成可以画三视图草案，但多次生成可能各自改变结构。几何可通行也可能在成品中被棚布遮住。 |
| 生图与布光（4–8） | ImageGen 可生成绘景、局部图像和带透明背景的素材。画师可分担远景、建筑、货物；关键结构由同一场景投影。渲染器可分别输出光源效果、材质和遮挡。 | 多次生成无法保证每个像素、道具数量、旗徽形变或笔触一致。跨物体投影要在共同场景中求取或用承影层校正。透明素材本身仍需检查孔洞与边缘。 |
| 分层、留档与回退（1、3、5–9） | 用脚本保存 PNG、源模型和带透明通道的分层文件；逐层开关、抽查 Alpha、按层序重组合成并比较像素。 | 独立图层必须在绘制时留下。扁平 PNG 丢失的遮挡区和原始笔触无法无损恢复。像素一致仅证明交付图可重组；画错的路也可以精确重组。 |
| 独立审查（3、5–9） | 用新子 agent 看中性命名的候选图；作画者的自检单列。记录可定位的纰漏、依据和是否通过，复验再开新会话。 | 不继承聊天历史可以实现。各 agent 仍共享工具和工作区，也可能有相同的模型偏差；只读指定图片是任务约束，无法据此承诺物理隔离或统计独立。并发名额不足时顺序审查。 |
| 终审与来源盲评（9） | 对照成品检查无描边、风格、动线、常理；盲审者列出可见疑点和可能解释。 | 美术评分是判断，不能保证零错误。仅凭像素通常不能确认是否用过 AI；若问题是实际制作来源，应查制作记录。 |

**可复用的结构审查题**

> 你是一名严格的美术考试阅卷老师。题目为〔场景主题与实际用途〕。只查看所附本版结构图、三视图和成品机位图。请从构图与透视、接地与承重、遮挡与层次、物件用途及完整通行路线分别评价。每项指出画面位置、观察依据和无法确认之处，给出综合分与通过或退回的结论。退回时写清哪一处要改、改后如何看出它成立。

光影和细化审查沿用这个输出格式，换成本步的检查项。主 agent 对有分歧的意见先做可复核的测量或局部读图。例如门槛处量两侧路缘到石基的距离，再请读图者从画面下缘指出进门路线。对颜色偏好、笔触统一程度等难以测量的事项，保留具体画面依据与尚存分歧。
