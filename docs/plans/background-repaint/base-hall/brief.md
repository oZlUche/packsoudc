# 边堡值房 · 夜间交接

这间值房供守夜人与补给人员清点物资、交接记事。基地的仓库、科技与书架页面在它前方显示菜单。场景设定参考帝国时期不列颠北部辅助军营堡，属于游戏中的历史想象。

**时代依据。** 豪斯特兹堡的百夫长住处，一期改建以两段墙围出 L 形炉区，炉床由一块大石板坐在黏土基层上（发掘报告卷一，图 4.19，遗迹 1:118）。文多兰达的早期木构营房有铺草木的夯土地面，后期石堡营房亦有用黏土铺设的卵石、石板地面。设计选用低砌明炉和连续的不燃地面。屋架、具体排气口和器物陈列由本次设计推定。[豪斯特兹堡报告](https://historicengland.org.uk/images-books/publications/housesteads-roman-fort/housesteads-roman-fort-vol1/) · [早期营房](https://romaninscriptionsofbritain.org/tabvindol/vol-IV/arch-context-pt-3) · [石堡地坪](https://www.cambridge.org/core/journals/britannia/article/england-3-hadrians-wall/5D872C0641EF05F4D56964FB68A19871)

| 景深与原稿要素 | 功用、取舍与绘制约束 |
|---|---|
| 远景月窗 | 告知夜深。保留偏左月窗、窗台和两幅暗红短帘；真实窗洞让同一片靛蓝天和远山透入，两侧内壁遵循镜头透视。 |
| 中景左侧炉火 | 原稿的拱口壁炉与装饰搁板使人联想到后世厅堂。保留火光所在位置，改为低矮砖石围边、焦木炭床、炉前铺石和用于值夜的陶器。明火周围保持宽敞；烟气上升至靠近屋顶的排气口。 |
| 后墙、灯具 | 把原稿满墙木板换成石灰抹面、低调赭红墙裙与显露的木构件。原稿的悬灯换为托架明确的陶油灯。省去壁炉架上的小像框和蜡烛，以墙灯作为独立高位暖光。 |
| 中景右侧物品 | 搁架上放书卷、记事物与小木匣，说明物资交接功能；双托架承重。控制亮度使其从属于热源。仓库打开时右架会被不透明物品格挡住，保留裸图所需的完整形体。 |
| 近景地坪和织物 | 保留原图下边缘的暗红毯弧，铺在靠近观看者的一侧，和炉床之间留出不燃铺面。大面积地面采用碎砖石灰或石板，地表随实际受光变化。 |
| 画幅与镜头 | 原画 1920×1080；游戏背景采用 cover。按原图保留窗、火、灯、右架和毯的左右次序。炉心位于画宽约 37% 的仓库界面可见缝。日夜以冷窗、低位炉火与墙托油灯表达；视平线与实见墙脚分开处理。 |

略俯、略侧的成品机位独立于三正投影。使用鲜明暖红、琥珀与靛青，按实体关系处理前后遮挡、支承和投影。通过的阶段逐步增加材质和使用痕迹，成品压低明度、拉开明暗并向暖调色。[原稿](01-original.png) · [原始仓库页](ui-original-warehouse.jpg) · [场景映射](../../../../ui/game/meta_screen.gd)

**镜头与尺度。** 后墙宽 18 米，成品相机从 (1.35, −16.00, 4.85) m 朝 (0, −0.45, 2.77) m 看，36 mm 焦距配 36 mm 传感器。织毯近炉边与炉前铺石边相隔 0.97 m 的不燃地面，明火还在铺石边缘以内。具体门位在画外。罗马器物与材质来自时代研究和艺术推定，整间值房并非某座已发掘建筑的逐件复原。[视图索引](views/README.md) · [屋面剖面](roof-section.png)
