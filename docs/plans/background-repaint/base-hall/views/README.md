# 基地公用厅的三视图与游戏机位

后墙内侧为 Y = 0 m，地面为 Z = 0 m。后墙宽 18 m。窗中心 X = −4.85 m，炉心 X = −2.00 m。壁灯墙托在 X = +0.05 m，油盏向室内挑出至 Y = −0.78 m。右架中心 X = +5.33 m。炉床火心位于 (−2.00, −1.38) m，正上方的屋顶开口配有架空雨盖。炉前铺石止于 Y = −2.66 m，地毯最近端到 Y = −3.63 m，其间留有 0.97 m 的不燃地坪。织毯中心为 (−1.10, −4.93) m。入画地面从南侧向北延伸，门位在画外，图中没有指定门宽。

游戏相机位于 (1.35, −16.00, 4.85) m，朝向 (0.00, −0.45, 2.77) m。镜头从正北向西偏 5.0°，俯角 7.6°，36 mm 焦距，36 mm 传感器宽度。画幅为 16∶9，镜头位移为零。

01 的四幅图由同一组简化体块投影。03 起，正投影取自该阶段的 Blender 场景。俯视移开屋面及雨盖，用青灰虚线标出屋面口的投影。正视剖去顶板与两侧返墙，保留高墙口和雨盖。侧视取穿过火心的纵向窄带，保留远侧一对雨盖支柱作为参照，便于从炉床核对上方出口。灯光阶段保留被剖开构件的遮光。游戏镜头显示未剖开的场景。

08 与 09 共用几何、光源与机位。09 的正投影应用与成品相同的调色曲线。各组图右下角取自同一行的全幅 PNG，缩至图框大小后排入。
