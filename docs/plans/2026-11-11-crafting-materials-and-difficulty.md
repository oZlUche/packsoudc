# 制作材料补充、获取路径与难度调整执行方案

> 日期：2026-11-11。供 Claude 分批执行。
> 用户范围已确认：“材料”指游戏内制作材料及其获取来源，不是测试附件或美术素材清单。
> 本次只编写并提交方案；下列新增物品、供应规则和调参实验尚未实施。

## 1. 目标与优先顺序

让玩家能够沿可理解的来源收集材料、完成有意义的升级，再依据升级后的真实战力校准敌人与节奏。

顺序：**制作需求与来源审计 → 补低阶缺口与定向来源 → 验证实际升级可达性 → 隔离测试难度调整 → 联合验收**。

不同时普遍增加高级材料、降低敌人属性和提高玩家生命；这会使结果无法归因。每批记录基线、改变的字段和未改变的规则。

## 3. 材料缺口判断：按配方资格，不按物品名字

当前 `SmithRecipeDef.material_fits`：普通材质必须同时有 `material` 标签、材质相同、稀有度达到配方门槛；魔晶格另认 crystal 标签、元素家族和门槛。

因此武器“是木做的”、石雕“是石头”、巨兽獠牙根名字像骨头，都不能直接认定为该类材料：例如獠牙根当前 material 是 flesh；石雕小像若只有 valuable/treasure 而没有 material 标签，就不能顶石材料格。

当前清单提示的重点：

| 类别 | 既有代表 | 判断与处理 |
|---|---|---|
| 木 | 白：橡木原木、木棍、松脂；蓝：铁木枝、硬木板 | 绿色专用木材缺口最明确。蓝件可以顶绿门槛，所以不是绝对死配方，而是入门来源稀疏且一用就可能带品质 |
| 石 | 白：燧石、墓碑碎块、粗盐；绿：磨刀石、花岗石臼、创口盐 | 绿色自然矿材来源不足，现有绿石多偏加工品；专用蓝石缺口影响品质选择，但不能误称所有石路线都无法升级 |
| 骨 | 绿：鹿角、兽牙；蓝：兽爪、碎骨串；紫：骨骰子 | 档位已有基础，先补自然/制造来源和频率，不再堆同档骨料 |
| 金属 | 绿铜锭/铁矿石，蓝钢锭/黄铜齿轮等，紫秘银锭，橙灰白碎片 | 数量不是主要缺口；核查高阶解锁、搜索排除、专用掉落与冶炼路径 |
| 魔晶 | 火、冰、雷已有分档 | 先查家族命中、档位、磨损状态与用途竞争，不新造元素或通用替代晶石 |
| 皮革、药材、布 | 鞣皮、草药、亚麻等已有 | 审计白武拼接及生存配方的具体 id 需求，不因“同类很多”就认为有稳定来源 |

首轮不要把所有材质强行补齐白绿蓝紫橙。没有对应用途的高档材料会挤占掉落池，且品质对每下叠层的提升可能显著增加战力。

正文描述初稿：

- 梣木枝：“纹理笔直，削开表皮便能看见紧密的木纤维。适合做受力的长柄。”
- 风干木料：“从旧支架上拆下的干燥木料。铁钉已经锈坏，木芯还很结实。”
- 玄武岩：“断口细密而坚硬，拿在手中比外表更沉。适合加工成耐冲击的部件。”

属性不是定稿：实施时用现有相邻档材料检查占格、负重和价格。不得添加未实现的“降低耐力”等材料自带战斗效果；武器效果仍由配方出件定义。

价格初始使用既有稀有度/占格规则，记录实际 value；不得使买入材料→出售或打造后的回收形成无风险套利。明确是固定价值还是默认推导，不能写两套不一致的数。

## 5. 获取来源设计

### 5.1 地图与材料分布

| 来源 | 主要供给 | 调整方式 |
|---|---|---|
| 废墟外层林地 | 绿色木料、绿色骨料及少量基础药材 | 保留 plant/beast_part 身份；补梣木枝候选，不把绿色武器一起全局提权 |
| 废墟/沙漏矿脉 | 绿色矿石与绿石，中深逐渐增加蓝金属/蓝石（若启用） | 稀有度按实际节点深度及危险度；材料节点溢到外环时使用实际落点产物表 |
| 两图遗骸 | 风干木料、磨刀石、加工金属/布皮 | crafted 范围很宽，统计命中材料比例；必要时仅在材料节点的既有筛选层细分，而非把所有 crafted 物品加权 |
| 符文堆 | 魔晶家族与档位供给 | 分火/冰/雷统计；保留装填与升级的用途竞争，不能所有低阶晶石都满足橙配方 |
| 敌人掉落 | 符合身份的骨料、机关零件 | 先核实实际携带→可掉落链；不凭击杀敌人名字自动凭空给材料，不全局提高所有稀有掉率 |
| 局内商店、散货摊 | 自然资源的付费备用渠道 | 保留一次性库存与有限资金；给候选资格不等于每店保证出现全部类别 |
| 基地冶炼 | 现有合法转化路线 | 复用 smith_recipes smelt；先画配方依赖图，检查科技门槛和循环，不新增通用合成机 |
| 事件 | 按明确叙事给确定材料 | E05 铸槽、E06 油槽等沿前一方案；新事件未上线时不计为已存在的供应来源 |

报告 283 的已定限制必须保留：沙漏两侧矿脉/遗骸、颈部符文堆，不增加林地；废墟不可为了补材料而破坏战斗/混合路线身份，不恢复已取消的出征倾向。没有合法落点时记录缺额，不静默修改保护节点。

### 5.2 先修“资格不通”，再调“频率不足”

特殊审计点：`pale_shard` 当前带 treasure、需要 ach_boss；standard 搜索排除 treasure，standard 的 treasure_chance 又是 0。**这不直接证明灰白碎片绝对不可获得**：还可能来自其他敌人携带、固定奖励、商店或其他规则。必须把全部入口查完，再确定是否为断供。

若确认没有合法来源：为已解锁玩家配置一个符合世界观的深层/首领相关来源，保留解锁门槛；优先复用已有具名奖励/候选配置。不通过全局取消 treasure 排除、提高所有橙物掉率或让普通商店无限供货解决。

秘银被散货摊 excluded_ids 排除是已存在规则；不能为方便而直接删。检查其既有冶炼/搜索/掉落来路，必要时补可获取的矿源，不绕过科技。

### 5.3 保底策略

首轮不加跨局隐藏保底或无限刷新。先确保目标渠道候选合法、入口可达，并统计断供尾部。若定向探索仍经常完全无料，实验一个**每节点首次搜索的一次类别保障**：只保障该节点身份对应的一个合法材料，不保证指定 id、不保证高品质；与既有搜索保底合并设计，不能两个保底重复发奖。

保底是候选实验，不与第一批新材料同时上线；先分别量供给变化。表明保障在哪一次触发以及读档是否仍只触发一次。

## 6. 必须补充的检测工具：材料与配方可达性

新增建议 `tools/audit_material_supply.gd`，核心逻辑放 authoring 或 calibration 层，输出 JSON/CSV/Markdown。调用生产 `material_fits`、候选筛选与掉落函数，不复制规则。

### 6.1 静态需求图

读取 recipes、smith_recipes（含 material_inputs、固定 id、级别、科技、smelt）、items、章节产物、搜索、掉落、商店/集市、敌人携带和固定事件奖励。

对每个“配方需求槽”输出：可匹配物品、是否解锁、来源列表、来源适用图/阶段、是否纯理论候选、实际候选排除原因、可能产出的品质范围。必须区分：

1. 库中无合格物品。
2. 有物品但所有来源排除或未实现。
3. 来源存在但需科技/成就/前置配方，尚不可用。
4. 来源可用但概率或路线成本可能过低。
5. 已在背包/仓库但被锁定，不能消费。

检测配方依赖环：某材料只能由一个需要自身的配方产出且无外部来源时标断路。允许设计明确的可选稀有路线，不把“不是每局都能做”当错误。

### 6.2 随机供给实验

两图 × 小/中/大 × 当前各难度，用固定开发种子集生成；每图档组合初筛 100 个种子，验证集另存不参与调数。调用真实节点搜索与库存生成，记录条件概率和样本数。

区分三层统计：

- 地图机会：地图上是否存在相应来源，假设检查所有节点，仅是供给上限。
- 路线机会：在明确行动预算和已知信息下到达哪些来源，不看隐藏内容作弊。
- 实际转化：拿到前置武器及合格材料、放得下、到达未用砧，或带回基地且满足工钱与科技。

输出每类材料的首次取得步数分布、指定检查点未获得比例、数量、重量/占格、材料实际等级、配方准备完成步数、成功打造与带出比例、失败原因。未获得样本标 censored/null，不能剔除后声称取得速度很快。

“收集到一件材料”不等于“完成升级”。仓库已有资源与空档开局分组；跨局成长和单局路线分别统计。

### 6.3 测试与验收

夹具覆盖：名字似骨但 material=flesh、无 material 标签的雕像、缺解锁的灰白碎片、已锁定材料、魔晶家族不符、蓝料顶绿门槛的品质变化、循环配方、候选概率为零、满包落地、耗时到终局。

报告必须能列出每条核心升级路线至少一个当前可用来源，或明确设计门槛/真实断路。不能以目录里存在物品 JSON 作为来源已通的证明。

## 7. 难度调整：实验矩阵，而非直接全局改数

### 7.1 固定实验口径

保留当前 108 份木桩不重造；新增“合法完整”“常见缺件”“材料受限”“完成一次升级”的场景作为追加集合。8 份历史丢件单独标识，不能把它们从分母移除后宣称游戏变简单。

主比较使用相同地图/敌人实例、配装、种子、引擎与构建。新材料导致配置变化时另列“供给变化”，不能混成同配装战斗加强。

使用已实现 `bench_matrix --out-dir --mode=frequency/coverage`；frequency 目前不含搜索遭遇与揭示随机点，需补独立实验或明确未覆盖。猎手和核心分别统计。

### 7.2 候选实验

| 实验 | 唯一主要改变 | 初轮幅度/选择 | 目的与禁区 |
|---|---|---|---|
| M1 材料补齐 | 三个首批材料及局部来源资格 | 不改战斗属性 | 测绿木/绿石路线可达性与品质分布 |
| M2 来源提高 | 只改目标来源内的材料份额 | 与基线相比相对 +25%、+50% 两档，保持归一化并报告其他物品被挤出的量 | 不提高全局橙稀有度；参数是实验点不是承诺上线值 |
| D1 brute 局部突变 | 单独改变对应实例的某一项缩放 | 原值、生命缩放 -10%、格挡缩放 -10% 分开跑 | 检查是谁造成短板；不得移除档 3 真伤身份来保护所有盾流 |
| D2 猎手曲线 | wanted 档映射或猎手池缩放，分别实验 | 先比较当前档和相邻档；无合适离散档时才试小幅缩放 | 目标五成已有定案，但比较对象须是同阶段合理配置；不把最强/最弱都压到五成 |
| D3 节奏拉长 | 实验副本中双方基础生命同比例 | ×1.15、×1.30；只作候选 | 检查时长、血线、耐力与状态构筑；不直接上线、不同步改伤害。若只增加等待而无决策反馈，弃用 |
| D4 处决武器诊断 | 测试靶子的生命阶段 | 满血、低血、真实敌人 | 不根据不死木桩 DPS 低直接给 flame_execution_blade 加伤害 |
| D5 品质上限影响 | 同件品质 0/1/2 与可取得成本 | 遵守每下叠层照加的既有决定 | 查高品质材料增加后是否让少数叠层路线独占优势；先调获取/局部基数建议，不擅自废除品质规则 |

D1 对池级参数做变更会影响多个敌人，离线单敌人试验成功后还要测整个池。若需要新增敌人专用 override 字段，先检查既有配置是否足够，避免为一个异常堆新开关。

猎手初筛每格 100 场，候选复核按预先固定的 400 场及至少数份不同合法配装进行，报告区间和配装间差异。不能把相同敌人实例的重复随机当成大量独立构筑证据。

普通约七成、精英约五成仍是历史建议，未获正式定案；本次方案将其用作观察参考，不作为必须自动收敛的验收线。核心首领也不强行对齐普通战。

### 7.3 节奏与 UI 验证

2.2 秒模拟时长只是旧样本观察，必须重新读取 viewing 记录区分模拟与屏幕观看时长。选择“换装前后”“耐力见底”“反应击杀”等可复现战斗，请测试线程检查玩家是否能说出原因和得失。

报告 301 的反应归属修正若尚未合并，应先完成/等待正确归属，或在统计中将该部分标未知；不得据错归属数据削弱某武器。报告 298 的配方与升级对比若未落地，材料获取提示只能算计划，不能声称玩家已经能看懂。

## 8. 材料提示与剧情一致性

- 配方显示准确的材质、最低稀有度、实际将消耗的件和最终品质，复用 298 的对比方案，不另建整套配方 UI。
- 来源提示只写实际存在的类型和地图，例如“废墟林地”“机关遗骸”；概率性来源不写成必得。
- E05 铸槽可以提供风干木料或硬木板，但成本与价值必须相称；E06 机关油槽给齿轮/铆钉，不能给天然树心材。
- 材料标签参与神明行为、图鉴、商店筛选，新增标签需回归信仰计数与价格；避免通过重贴现有物品标签绕过门槛。
- 新材料需中英文名字、用途说明、占格一致的图、字库覆盖；素材未齐时允许开发占位，但报告说明，不宣称玩家版完成。

## 9. 分批交付与停止条件

| 批次 | 产出 | 验收 |
|---|---|---|
| A 审计 | 最新配方需求矩阵、来源图、断供/低概率列表；材料审计工具 | 全库可解释，精确需求和泛材质分开；不重复已有平衡工具 |
| B 低阶补齐 | 三件首批材料、实际来源、JSON/TRES、双语与图；相关小测试 | 新件真的可获得并被正确配方消费，锁定/满包/读档无复制或吞物 |
| C 材料供给复测 | M1/M2 与基线分离报告、升级可达性、经济机会成本 | 难度数据未同步改动；不将全图资源总量当真人可取得量 |
| D 难度建议 | D1～D5 中有证据需要的实验、前后配对结果与保留种子验证 | 每项给具体字段 diff、受影响范围、收益与副作用；正式值待据结果选定 |
| E 联合验收 | 选定材料版本与难度版本组合的回归及 UI 走查 | 排除供给叠加导致整体失衡，保留失败仍有恢复空间与地图身份 |

以下不阻塞独立工作：无真人数据时继续合成实验并如实标注；无配图时先做开发验证；未获目标时长/普通战目标定案时先交候选表，不擅自选全局正式值。

新增候选材料在最新库已出现则直接复用，删除重复方案项；如果审计证明某“缺口”已由稳定现有来源解决，交证据后不再新增。
