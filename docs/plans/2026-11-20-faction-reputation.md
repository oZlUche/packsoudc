# 阵营声望与基地功能开放 · 讨论大纲

2026-11-20 修订。教程后的三份剧情委托负责把玩家带进铁匠铺、科技和集市。此后玩家可以直接出征、交易、打造或研究。剧情提供长期功能，常规委托提供可选的物资收入。[Excel 浏览表](2026-11-20-faction-reputation.xlsx)

## 常规委托

| 类型 | 目标与计数 | 期限 | 难度随发布方等级变化 | 报酬示例 |
|---|---|---|---|---|
| 访问 | 到达指定类别的不同节点；同局同节点只记一次 | 接单后可跨局 | 提高所需处数、开放较深区域 | 后勤发金币或补给 |
| 击杀 | 胜利时核对目标敌人，按有效击杀数累计 | 接单后可跨局 | 提高数量或抽取较强的合法目标 | 协会发魔法材料和／或金币 |
| 上交物品 | 营地选择合格实例，确认后扣物并累计 | 接单后可跨局 | 提高数量或材料档次，按实际可获得性筛选 | 灰灯发民用物资和／或金币 |
| 交付 | 接取后携信件或道具进指定地图，生成可达交付点并标注；现场交给收件人立即完成 | N次出征内（试行3次） | 按目的地风险、占格和N调档 | 按发布方奖励池和风险预算发放 |

## 推进规则

| 议题 | 设计决定或试行口径 |
|---|---|
| 入口 | 教程结束引导进入委托子菜单。剧情区一次自动接取三份初始单，分阵营展示，均可独立完成。另设常规区，声望页从同一子菜单进入。 |
| 展示 | 剧情单出现后永久保留至完成，不占常规钉位和手头上限。常规区锁定时直接指出需要哪一方的哪份剧情。 |
| 等级候选 | 五档累计门槛已定：0 初识、10 熟面、25 受托、50 信赖、100 代言（称谓暂定）。剧情发声望，累计达级且对应剧情已完成时永久授予功能；明确显示两个条件。 |
| 高阶可达 | 首单10＋三份后续剧情各5＝25，全程在常规池开放前可完成。两份基础剧情候选：后勤查验材料／领取工具，协会辨认矿样／登记产地，灰灯送收条／核对药包。25→50差25，可用五份高难常规各+5达到；50→100差50，可用十份各+5达到。实际可混合剧情与常规；代言功能仍须结案。 |
| 常规刷新 | 回营结算先撤下到期的未接单，再按空位补单；已接普通单保存。只抽已解锁阵营与当前可达章节。目标、数量、期限、奖励在贴出时固定。 |
| 报酬 | 各阵营首份指定剧情+10，后续剧情每份+5；低难常规+2～3，高难常规+4～6。公告生成时按实际工作量定分并展示；同一张委托读档或重复领奖只记一次。先由发布阵营确定金币／物品组合与合法池，再按目标数量、稀缺程度、路程和难度确定总价值。高等级可抽更难的单，保留低档选择。 |
| 限次交付 | 建议接取后每次正式出征都占一次，包括选错地图；出发前显示目的地和剩余次数。仅目标地图生成标点。最后一次先判交付再判到期，现场完成后败退仍有效。 |
| 异常 | 读档不重复扣次数，地图生成失败不耗机会；委托物遗失时在下次符合条件的出征前补发唯一任务实例。超期关闭该常规单，保留既有声望。 |
| 声望页 | 每方列累计声望、当前等级、下一门槛、已开功能、未开功能及所需剧情；可点到对应剧情或已开放设施。结算列出声望增量与新开放入口。 |
| 旧档 | 迁移时保留原等级对应的新门槛下限和累计进度，历史回执不重复发奖；保留已开放设施、已有难度和现存委托；旧军团接应队映射至后勤部队。教程已过的档首次回营补发缺少的引导单，重复进入不重发。 |
| 验收 | 新档走三条线各解锁一个可用设施；同阵营许可单后只开放本方常规池；剧情跨多局仍在；交付最后一次送达、超期和读档分别验证；声望页与实际入口一致。 |

## 声望速查

| 等级（称谓暂定） | 累计声望 | 距上一档 | 功能候选 |
|---|---:|---:|---|
| 初识 | 0 | 0 | 自动接取本方首单 |
| 熟面 | 10 | 10 | 开放本方基础设施 |
| 受托 | 25 | 15 | 完成许可剧情，开放本方常规池 |
| 信赖 | 50 | 25 | 开放高阶库存、研究或预设的入门档；可提高高难常规的出现权重 |
| 代言 | 100 | 50 | 配合高阶剧情结案开放本方完整专属功能 |

首份指各阵营指定的引导剧情，每档案每方只领一次。25点起可抽低难和高难委托；同一阵营的低难按工作量取2或3，高难取4、5或6。常规可累积至最高门槛；金币与物品仍按阵营和任务预算配置。
