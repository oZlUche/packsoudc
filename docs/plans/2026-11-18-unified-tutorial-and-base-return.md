## 2. 统一后的产品结构

正式版和切片共用**相同三张教学地图、角色、步骤、事件、操作判定与固定奖励**。第一版继续使用现有教程角色布鲁图斯，避免只为切片替换角色而重新制造难度差异；在选人卡注明“教学指定角色”。教程结束后，切片仍按自己的常规章节配置选择安德烈乌斯。

流程为：

```text
新档 → 简短开场 → 接受教程 / 跳过全部教程
接受 → 第一局：搜集、整理、战斗、合成、休息、撤离
     → 结算与入库 → 基地导览 → 自由停留
     → 玩家点出战 → 第二局：敌人与路线选择
     → 结算 → 基地自由停留
     → 玩家点出战 → 第三局：信仰与神坛
     → 结算 → 基地 → 正式版常规章节 / 切片常规章节
跳过 → 补齐未领取固定奖励 → 基地 → 相应版本常规章节
```

“统一”包括同一条操作规则，不只是同一句文字：仓库、交易、合成、休息、科技使用生产接口。两版本独立存档、独立进度，不自动继承对方资产。

**切片范围随本次目标扩大**：由“19 件物品的一张受控图”变为“共享三段教程 + 受限常规切片图 + 基地基础功能”。19 件清单继续约束原 `slice_ruins` 常规远征，不能拿它拒绝教程二的塔盾、教程三的信物。新建教学来源清单与基地可用内容清单，分别审计，不开放正式版全库。

总学习时间单独测量。原切片单趟 15～25 分钟目标不能当作三局教程加基地导览的总预算。

## 3. 暂停解说与动作教学的共同规则

1. **解说步骤**：等页面、揭示动画和目标控件稳定后，暂停回放或相关自动推进；压暗背景、高亮真实控件；一句解释一个目标。显式按钮“知道了 / 上一步 / 暂时收起”。不以任意键误触当确认，不让点击穿透到战斗或购买按钮。
2. **操作步骤**：解说收起后放开真实操作，保留一行目标提示。只有真实成功事件才完成，例如物品放进包、确认合成成功、仓库转移成功。点击“知道了”只记已读。
3. **机会教学**：第一次实际看到合成搭档、休息点、反应时才触发；不在出生点连播全部规则。未揭示物品、未购买商品、不可消费物品不能触发“现在可以合成”。
4. **暂停范围**：战斗教学暂停回放并保留原播放状态；地图本身按行动推进，不扣任何教学时间或步数；UI 输入、暂停菜单、设置、帮助保持可用。保存和必要布局不应被全局暂停卡住。
5. **弹窗优先级**：系统确认/错误处理 → 教程询问或跳过确认 → 当前页面解说 → 合成提示/反应教学 → 普通提示。一时只有一张教学卡，关闭一张不误恢复另一张仍持有的暂停。
6. **去重与重看**：同一存档两版本各自记录，三章共用 `step_id`；背包旋转、战斗回放等已学过的不再整组重复。暂停菜单提供“当前教程 / 已学操作”，重看不改奖励或进度。
7. **文字正确**：地图体力、战斗生命、战斗耐力分开；普通移动不能一概写成消耗体力。快捷键读取绑定；数值、价格、恢复量、扣除量来自当前配置。未知合成不提前泄露成品。
8. **中断可恢复**：关掉讲解可继续操作，返回相关页面可从未完成步骤继续；已完成动作即使未看提示也计入。退出游戏不触发下一局。

## 4. 第一局：完成一次搜打撤

保留序章一的搜索、战斗与合成资源，增加一个基础休息点。商店操作放第二局，避免把首局变成所有系统的目录。基础休息安排在首战后、第二搜索前，先教恢复，再让玩家承担后续风险；不要求先故意输一场。

| 步骤 | 触发点与暂停介绍 | 玩家实际操作 / 完成条件 |
|---|---|---|
| T0 选择是否教学 | 开场说明结束：“三段远征之间可以回基地整理，也可随时跳过并领取固定奖励。” | “开始教程”进入 T1；“跳过全部教程”展示奖励清单、确认后回基地；Esc 不代替选择 |
| T1 认识地图 | 出生点，分两张卡介绍当前位置/相邻点、体力与行动倒计时；说明本章不启用的读数 | 点击真实可达搜索点；不让解说卡关闭顺带移动 |
| T2 打开搜索 | 搜索面板首次出现：搜索次数、逐件揭示、容器与地面 | 开始一次搜索，等待至少一件真正揭示 |
| T3 包与棋盘 | 指包覆盖的可用格、物品轮廓、地面区 | 把制式短剑或另一件可用装备放入包；轮转与右键取消先提供练习，不要求把每个快捷操作都做一遍 |
| T4 带什么走 | 第二次搜索获得皮甲后，指出容量、耐力与输出读数；地面物品留在当前节点 | 自行决定装备；离开前若没有武器，提供返回整理提醒和明确继续选项，不悄悄代装 |
| T5 认识敌人 | 首次战前：敌方身份、装备、生命、防御；我方棋盘；估算不是胜率保证 | 悬浮查看一件敌方物品或展开等效详情；玩家主动开战 |
| T6 自动战斗与回放 | 回放开始前暂停一次，讲生命/护甲/格挡与自动攻击；播放控制后遇到时再讲 | 点击播放；第一次真实护甲吸收或格挡出现时解释对应证据；无此事件不凭空暂停讲实例 |
| T7 胜利与战利品 | 战斗胜利后出现战利品，解释搜索敌人装备、金币获得和地面 | 揭示并拾取一件物品，或明确选择放弃；战胜一名敌人不等于本局撤离成功 |
| T8 基础休息 | 新基础休息点：介绍恢复的是地图体力、耗时或费用、可用次数；生命会按战斗规则重置 | 有损失者可真实休息并看前后数值；满体力者选择“无需休息，继续”，也算理解入口；不强扣体力或强制消费 |
| T9 首次合成 | 第二搜索获得毒药瓶、已有匕首；已揭示且可操作后高亮搭档 | 拿起 → 拖到搭档 → 确认窗；讲消耗、未知结果、取消。取消不算完成，成功才记录；先学会的玩家直接略过讲解 |
| T10 整理与搜索风险 | 首次空间紧张、准备第三搜时解释保留/丢弃与遭遇风险 | 玩家选择是否继续搜；不要求为了上课强制触发遭遇；若继续，走真实遭遇流程 |
| T11 精英与反应 | 守卫前指出盾与精英败战代价；发生毒/血反应时暂停在真实反应画面 | 自主配置并战斗。缺合成材料沿用可解释的补救/继续路径，不把“不愿合成”变成永久锁死 |
| T12 撤离 | 出口解释“结束这一趟、带回什么、地面留下什么” | 查看带出预览，确认撤离；删掉“直接进下一张”的旧句 |

第一局失败也正常结算并回基地。保留已学操作，未获得第一段完成奖励；出战页可重试第一段或跳过剩余。仓库没有战利品时，不假装发生了成功带出，可先看部门，等首次成功或跳过奖励到账后再完成仓库练习。

## 5. 第一局成功后：结算、入库、整理与基地

这是本次必补的完整阶段，不能用 `store_all()` 后立即开新局替代。

| 步骤 | 页面与说明 | 实际动作 / 完成条件 |
|---|---|---|
| B1 看结算 | 点出撤离结果、金币、得分、实际见识奖励；区分正常战利品和固定教程奖励 | 账单显示完成后继续；如本局未到见识门槛，明确显示 0，不宣称每局必得 |
| B2 入库 | 结算整理页：带回棋盘、仓库、包架分别是什么；普通包与可存物品按现规则处理 | 优先引导拖入一件；也接受“一键入库”的真实成功。验证实例转移，不能复制教学示范品 |
| B3 整理与余物 | 仓库页：移动/旋转、分页、查看属性；指出剩余待整理物品 | 移动一件或使用已有整理操作；满仓时允许先处理空间，不删除或自动卖掉余物；返回基地后仍能接着整理 |
| B4 基地总览 | 出征、仓库、后勤、书架四处；提示“现在可以自由停留，想继续时再出战” | 玩家主动逐页打开；可以收起导览自由浏览，进度保留，不自动替玩家切完所有页面 |
| B5 后勤·集市 | 说明购买、出售实际入口、价格、仓库资产及局外金币；区分局内商店与基地集市 | 查看一件商品或自己的物品价格。购买/出售自愿，不以花钱作为完成条件 |
| B6 后勤·铁匠铺 | 说明配方、材料、金币、成品去向；区分“局外打造”和“局内两件合成” | 查看一条当前开放配方及缺少材料；制作自愿；不恢复已移除的砧升级教学 |
| B7 科技 | 从书架进入科技，介绍数值成长与机制成长两页：前者金币/材料，后者见识；说明局外成长的生效时点 | 各查看一个开放节点；可追踪一个目标，取消也可。升级自愿，不强花有限资源或要求攒够钱才能结束导览 |
| B8 其他书架功能 | 一张短卡指出图鉴、对局记录、特殊道具、成就及帮助入口 | 确认已读即可；不强制逐一翻完收藏 |
| B9 后续出战 | 点出战，展示“下一段：岔路”“教程 1/3”及跳过入口 | 可返回基地；只有点击“开始第二段”才进入第二局。之后的章节锁定是出战限制，不是基地导航限制 |

基地导览是可收起的推荐任务，不新增“买东西/升科技才能解锁出战”的硬门槛。主教程进度依据三段远征完成或明确跳过；导览单独记录，可之后补看。这样“只在出战界面锁定章节”不会变成“基地也被动作清单锁住”。

## 6. 第二局：敌人与路线选择

保留序章二的两次岔路，在第一分支合流后加入一家教学商店；商店与必要材料都可绕过，基础胜负不能依赖购物。后勤是局外资产服务，商店是本局钱包交易，两者不能只教一个。

| 步骤 | 教学内容 | 操作与判定 |
|---|---|---|
| S1 主动整备 | 只有第二段能开始；角色、教学补给、已有仓库及携入规则清楚展示 | 首版三段均保留固定教学装备，明确“教学远征使用固定补给”；不让基地买来的强装备跳过课程。预览必须等于实际入场装备 |
| S2 节点情报 | 望远镜与悬浮情报，地图缩放、看全图、出口位置 | 查看岔路两侧敌人详情；已有同一操作记录则不重复教学 |
| S3 防具与敌人 | 塔盾对轻快攻击、板甲对重击的示例；数值来自当前敌人和装备 | 自选护具和路线。教学解释相对适配，不承诺某件装备必胜 |
| S4 战后核对 | 用这一场的格挡次数/吸收或战记证据回看选择 | 可看回放或继续；不拿两种不同敌人的战果直接计算“提升百分比” |
| S5 局内交易 | 固定货架、上桌不等于成交、金币补差、找零、取消退回 | 查看交易预览，可成交也可取消；确认前展示代价；不强买后续唯一答案，不在这里强制教授科技刷新 |
| S6 合成与路线 | 另一搜索点提供毒/物理方向；敌人有叠防御或解毒差异 | 先看敌人、再选装或合成；不强走某条路线，不重复首局完整合成弹窗教学 |
| S7 回头与撤离 | 地面物品按节点保留、路线可以回头、继续探索有成本 | 自主撤离；完成后结算 → 基地，领取第二段固定奖励，绝不直接进入第三局 |

入库动作已学过则不再强提示。基地出战卡变为“下一段：祭坛”，玩家可停留、退出、回来继续。

## 7. 第三局：信仰、神坛与进阶理解

保留现有序章三资源与路线；共享教程允许这些物品在切片教学中出现，常规切片的随机来源仍受自己的清单限制。

| 步骤 | 暂停解释 | 玩家动作 / 完成条件 |
|---|---|---|
| F1 信物入包 | 信物和普通带信仰标签物品的区别；顶部信仰徽记 | 将蛮神信物放进包，真实激活后完成 |
| F2 战斗与信力 | 指出本场实际获得的信力及当前阶，不预言打完必到某阶 | 结束一次战斗，查看徽记或信仰详情 |
| F3 祭品与取舍 | 普通祭品、可用于战斗的骨武器；献祭会消耗实例 | 选择保留或献祭；必要教学材料保证在当前可达来源中，不强献唯一武器 |
| F4 休息与神坛 | 同一营地的休息和神坛是不同服务；神坛一次使用中的献祭/特殊操作限制 | 打开神坛，预览后确认一次献祭或明确略过此操作；基础休息已经学过，仅补区别 |
| F5 切换与休眠 | 日神信物入包后，旧神休眠；切回方式与独立信力记录 | 切换一次再查看状态；没有要求玩家花不可恢复代价 |

教程后的第一次常规整备，才补“仓库物品真正携入”的短操作提示：选真实实例、预览、取消不扣、出发才转移。切片若维持 `allow_carry_in=false`，只能解释固定补给，不能展示虚假的携入教学。本方案推荐同步为常规切片提供受限携入配置，具体允许类别与强度需另做对打校准，不在本次文档中宣称已解决平衡。

## 8. 出战锁定、失败、退出与跳过

### 8.1 锁定规则

- 教程未全完成：整备页只允许开始“最早未完成的一段”；显示其目标及进度。后续教程、普通地图不能开始，并写清原因。
- 第一、二段完成后，解锁的是下一段的**出战资格**，不是触发自动入场。
- 基地的仓库、后勤、科技、书架、设置始终可访问；教程期固定补给限制不等于隐藏仓库。
- 有进行中教程档时，“继续”恢复这一局；无进行中局时，“继续”进入基地，显示未完成阶段，不调用 `begin_direct`。
- 同一档“新的一局/出战”不再清空课程或回第一段；真正“新的游戏”创建新存档才从头。
- 失败后回基地，重试当前段；已完成阶段不回退，已学动作不重复；正常完成和跳过在显示上区分。
- 章节列表与出发后端使用同一规则。不要依赖 `available_chapters()` 空结果回退“全部章节”来绕过教程锁；配置错误给恢复入口，不静默全解锁。

### 8.2 跳过入口与去向

开场询问、局内暂停菜单、基地出战卡都提供“跳过剩余教程”。统一一个服务和一张确认页，列出将补发的金币、物品、特殊道具以及目的地“基地”。已完成阶段标“已领取”，不重新发。

“收起这一页讲解”与“跳过剩余教程”必须分开：前者不解锁课程、不发奖励；后者完成所有剩余阶段的跳过处理。首版不另加“只跳当前章”的第二套奖励流程。

进行中选择跳过时：明确告知本局尚未撤离的战利品不会按成功带出。安全归还本次从仓库实际借出的资产/携入本金（若该阶段允许），不发尚未赚取的探索收益；保留既有局外资产与已结算收益。固定奖励独立到账，不记一次胜利、死亡或伪造战绩。取消确认不改变任何资产或进度。

## 9. 固定教程奖励：正常完成和跳过使用同一账本

### 9.1 奖励口径

“教程奖励”定义为各阶段配置中的固定权益；正常玩法中的随机掉落、卖出收入、剩余钱包属于真实远征收益。跳过补固定权益，不伪造一整局随机战利品或得分。这个区别要直接写在跳过清单中。

建议初始表如下，金额是低成本验证起点，实施时按当前商品与科技价格校准，两版本同表：

| 奖励包 | 金币 | 固定物品 / 权益 | 正常领取时点 |
|---|---:|---|---|
| 起始包 | 沿用当前开局配置 | 当前 `first_kit`，改用领取标志，不以“仓库为空”判定是否已发 | 新档初始化一次 |
| T1 完成包 | 100 | 匕首 ×1、纱布 ×1、伤药 ×1 | 第一段成功结算 |
| T2 完成包 | 150 | 制式短剑 ×1、磨刀石 ×1；望远镜权益 ×1 | 第二段成功结算；望远镜可在段内提前授予，同一权益不可重领 |
| T3 完成包 | 200 | 蛮神信物 ×1、日神信物 ×1 | 第三段成功结算；段内带出的对应教学信物抵扣该包同源名额，缺失的补齐 |

全新档跳过三段：起始包按未领情况发放，三段金币共 **450**，物品按表到账，望远镜走特殊道具系统。完成第一段后跳过只发第二、三段的 **350** 及未领物品，不通过当前库存推断是否领过（卖掉、合成或花掉不补第二次）。

第一、二段完成包是额外的固定通关奖励，和普通战利品在结算页分栏；第三段信物是教学途中提前提供的同一奖励权益，需要记录来源，不能撤离一次又补一对。普通途径获得的同名物品不被扣除。

见识沿用真实总分阶梯；教程跳过不伪造积分、额外见识或科技等级。科技课程只要求理解与查看，不要求强制购买，因此无需用跳过赠点解决教学卡点。金币进入局外余额，不伪造一枚实体金币物品占仓库格。

### 9.2 到账与保存约束

- 账本至少区分课程状态 `pending / in_progress / completed / skipped`、步骤已读/已做、奖励版本与已发权益。旧解锁旗标可兼容，但不再兼任所有含义。
- 固定奖励由正常完成与跳过共用入口；以 `profile + slot + curriculum_version + stage/reward_id` 去重，重复点击、重开页面、读档、重试都不重复到账。
- 金币、物品、解锁、账本在一次可恢复提交中保存；存盘失败不得显示领取成功或先删除进行中存档。发生崩溃后能继续同一事务，而不是再造实例。
- 跳过时物品自动落仓库，满仓优先按既有仓库救援方式加临时页；仍不能落下则保存为已分配 UID 的待入库奖励、明确提示并允许稍后整理。不得静默丢弃或擅自折钱；“已到账待整理”与“已放入仓库”分别显示。
- 不直接使用 `MetaState.grant` 的“放不下则跳过”作为完成判据；加入无损发奖路径，并核对所有固定物品确实进入仓库或持久待入库区。
- 望远镜等特殊道具不硬塞普通格子；包按现有包架规则处理。

## 10. 切片基地的开放范围

要真正统一操作，切片开放同款出征、仓库、后勤和书架界面；基础购买、出售、打造与科技查看/升级都使用正式服务，不做不能保存的假演示。

建议首版范围：

- 后勤：少量基础货物与配方，至少能查看并在资源足够时购买伤药/基础材料、打造基础盾甲；来源和成品加入基地清单。
- 科技：两棵树都可查看，首版开放各一个有实际用途的根节点，例如数值树仓库扩建、机制树行囊；其余未开放节点明确试玩范围，不能让玩家付钱升级一个在切片永远无效的能力。
- 见识：移除当前“切片一律不发”的总开关，在切片真实远征中按同一计分/阶梯发放；固定跳过奖励仍不含见识。课程教学不保证首局就能升级。
- 教学章节可用信物、塔盾等通过教学来源进入仓库；常规 `slice_ruins` 携入与掉落另按自己的允许清单校验，不能因仓库存在就绕过内容范围。
- 教程局的战斗强度仍使用固定教学配置；局外战斗属性科技对教学是否生效必须显式配置并展示，推荐固定教学基线，教学外才应用相关加成。仓库容量等局外功能照常生效，不假装玩家没购买。

开放多少科技、基础货物不是共享教程的步骤分叉。课程讲相同规则，具体可买/可升项由内容配置决定，并据当前状态显示可用条件。
