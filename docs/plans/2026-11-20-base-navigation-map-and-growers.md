# 基地入口、地图协会与河滩垦户社联合实施方案

设计交付给 Claude。地图协会与垦户社列入同一实施批，食堂列入下一批设计储备。声望沿用[五档方案](2026-11-20-faction-reputation.md)，设施创意出处见[营地设施讨论](2026-11-20-frontier-facility-concepts.md)。本篇决定入口与批次，作物、倍率、菜价与解锁剧情是原型候选。

## 基地导航决定

科技升为**基地一级页签**，紧邻仓库。玩家会在结算获得见识后购买机制，或比较库存、材料与数值科技成本；放在后勤第一项也还需要猜它在哪。书架继续承担查阅职责。各设施按玩家要做的事归类，声望页负责解释解锁来历。

| 基地一级页签（从上至下） | 子菜单与落点 | 何时使用 |
|---|---|---|
| 出征 | 默认出征总览 → 开始探索 → 选章节．规模．难度 → 本次准备（装备预设、材料倾向、预订餐）→ 确认 | 选择章节后才展示该地图支持的倾向。已解锁时默认无倾向、无餐也能直接出发 |
| 仓库 | 保留现有仓库、包架、整理工具 | 查看库存与入库 |
| 科技 | 数值成长／机制成长，默认上次浏览的树；从解锁或奖励按钮进入时定位对应树 | 消费金币、材料或见识。未解锁显示魔法师协会首单《第一份勘察记录》，回执可直接打开科技 |
| 委托 | 剧情委托／常规委托／声望。默认剧情，有上次选择时可恢复 | 教程结束直接定位三份初始剧情；声望页按阵营显示累计值、门槛与设施入口 |
| 后勤 | 集市／铁匠铺／出售／苗圃／食堂。设施较多用页内设施列表，保留键盘焦点与最后访问项 | 管理营地设施。苗圃管理播种与收获；食堂查看菜单和预订 |
| 书架 | 图鉴／对局记录／特殊道具／成就 | 已知材料与章节图鉴可链接至对应地图说明 |

地图协会的长期档案放在「委托 → 声望 → 地图协会」，本次选项直接在出征准备修改。避免玩家为每次出发来回穿过三个页面。灰灯食堂的准备页快捷选择与后勤菜单共享同一份订单。回营只在后勤页签显示「可收获」；不弹窗打断入库。旧科技按钮、教程导览、快捷键和奖励链接统一转到新一级页签，书架原科技格改静物或重新排版。测试英文、大字号、窄屏和手柄焦点，六个一级项优先保证出征按钮可见。

## 两个后续阵营如何同时引入

保留三个初始阵营。建议完成教程后首次正式探索结算，营地同时收到地图协会《把路画回来》和垦户社《第一畦》两封常驻剧情。前者登记这局实际访问的一处地形，后者领取一包试种种苗；缺少材料或一次败退也有后续入口。两份独立完成，各自首单 +10。沿用后续剧情 +5、低难常规 +2～3、高难 +4～6 的计分。25 点许可前为每方提供三份可独立于常规池完成的后续剧情。

| 声望 | 地图协会 | 河滩垦户社 |
|---|---|---|
| 0 | 记录路线、接首单 | 认领试种种苗、接首单 |
| 10 | 开放基础勘测，出征前可选本章合法材料方向 | 开一畦地，种苗可当次播下 |
| 25 | 校对旧图、核实矿脉、提交路标三单后开本方常规池 | 试种、收获、登记留种三单后开本方常规池 |
| 50 | 可在出征页查看所选方向主要受益的分区与材料节点类型 | 开药材、纤维以外的厨房作物 |
| 100＋结案 | 候选：首度打开地图时标注一处本来就生成的相应材料点；空候选时在准备页说明可用范围 | 候选：第二块试种地；先验证两畦的总产量 |

## 地图协会的材料倾向

v4.76 曾把选中系权重乘2.5、其他两系乘0.6。v5.28 删除了出征倾向与存档字段，保留分区产物及章节材料节点。重做要保住「去哪里搜」的意义。[改动记录](../changelog.md)

首版选项为无倾向、矿物、草木，以及经当前标签库核实后可用的工艺材料。先选章节，根据该章现有候选显示方向。只在普通搜索已经抽到材料类别后，对合法材料候选重新分配相对权重；普通搜索总材料率、稀有度与搜索次数沿用原规则。以目标权重×1.25／×1.5做配对试验，其他权重保持1。专属材料节点、敌人、首领保底、宝箱、商店与事件奖励使用各自的既有池。例如在废墟选矿物后，普通搜索抽中材料时更易得到当地矿物，林地仍值得专程去采草木。

候选方向须实际能改变分布；零候选或候选全属同系时标为不可选并给原因。切换章节重验选择，正式开局锁定至本局结束。旧档缺字段按无倾向；读档不得重抽。按章节比较每局目标材料带出数、普通材料总量、稀有度分布和专属点访问率，再定倍率。

## 垦户社与灰灯食堂

苗圃从「后勤 → 苗圃」播种，卡片显示种苗成本、预计产物、距离成熟还差几局。用旧方案的一畦、三种候选作物起测，香根随厨房作物解锁；食堂开放前需有独立用途或暂缓投放香根。一次有实际探索的正式出征结算推进一次，胜败均计，重载与空跑不推进。成熟留田，仓库放得下才收获，扣种、入库与清畦防重复。例：同一局带回矿料用于铁匠铺，同时让上一局种的药草成熟。

灰灯食堂拟在灰灯25点并完成《开伙》后开放。初版三餐分别服务于高耗能武器、搬运矿物、长线休息。示例「盐渍根汤」让本局头两次超载移动按正常行动成本计算。菜价与实际收益以同章普通搜索作基准试调。后勤中选餐仅预订，出征确认页显示一道菜、实价与实际效果，开局成功统一扣费，取消准备免费；每局一餐，结算清除，用自家香根加料是后续选项。进入新餐厅、买不起菜、库中无作物时都保留正常出征路径。

## 交付与验收

1. 核对最新基地页签、教程导航、切片清单和解锁标记，先迁移科技入口。正式档保留原科技进度与阵营设施权限；切片按已有清单迁移导航。
2. 同批落地两方声望、首单、材料倾向和苗圃。存档分别记录本局选择、田块与最后并账局。验证「选矿物 → 播种 → 正式探索 → 回营收获 → 打开科技」整条入口；换图、败退、库满和结算重试各测一次。两个首单均可从真实新档完成。
3. 食堂单独交付菜单、预订与运行时效果。评估六页签是否易找，观察首次获得见识后的科技到达率、成熟后完成收获的路径、两处点餐入口的订单一致性。食堂上线前不展示可操作的空店。
